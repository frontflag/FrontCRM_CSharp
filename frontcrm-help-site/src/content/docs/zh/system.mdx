## 概述

系统模块供管理员配置用户、角色、权限和应用设置。

## 常用操作

### 管理用户

1. 进入 **系统 > 用户管理**。
2. 点击 **新增用户**。
3. 分配角色和权限。
4. 保存。

### 配置角色

1. 打开 **系统 > 角色管理**。
2. 创建或编辑角色。
3. 分配菜单和数据权限。
4. 保存。

## 常见问题

**Q：谁可以访问系统设置？**
A：只有具备管理员或系统配置权限的用户才能访问该模块。
