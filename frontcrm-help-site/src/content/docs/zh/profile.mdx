## 概述

个人中心用于管理账户信息、密码和偏好设置。

## 常用操作

### 更新个人信息

1. 点击右上角头像。
2. 选择 **个人中心**。
3. 更新姓名、电话或邮箱。
4. 点击 **保存**。

### 修改密码

1. 打开 **个人中心 > 安全设置**。
2. 输入当前密码和新密码。
3. 点击 **更新密码**。

## 常见问题

**Q：如何切换界面语言？**
A：使用应用右上角的语言切换器。
