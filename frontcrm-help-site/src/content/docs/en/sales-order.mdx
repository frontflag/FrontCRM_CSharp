## Overview

The Sales Order module records confirmed customer orders, tracks production and delivery status, and links to finance and inventory.

## Common operations

### Create a sales order

1. Navigate to **Sales > Sales Order List**.
2. Click **Add**.
3. Select the customer and add order lines.
4. Save and submit for approval if required.

### Track order status

- Use the status column to see whether an order is Draft, Confirmed, In Production, Shipped, or Closed.

## FAQ

**Q: Can a sales order be created from a quote?**
A: Yes, open the quote and click **Convert to Sales Order**.
