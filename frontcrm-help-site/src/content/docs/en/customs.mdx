## Overview

The Customs module manages export/import declarations and related documents.

## Common operations

### Create a customs declaration

1. Navigate to **Customs > Customs Declaration List**.
2. Click **Add**.
3. Select the related order or shipment.
4. Enter customs details and required documents.
5. Save and submit.

### Upload documents

1. Open the customs declaration.
2. Click **Upload Document**.
3. Select the file type and upload the file.

## FAQ

**Q: What documents are usually required for customs?**
A: Common documents include commercial invoice, packing list, and customs declaration form. Requirements vary by country.
