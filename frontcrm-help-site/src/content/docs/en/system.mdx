## Overview

The System module is used by administrators to configure users, roles, permissions, and application settings.

## Common operations

### Manage users

1. Navigate to **System > User Management**.
2. Click **Add User** to create a new user.
3. Assign roles and permissions.
4. Save.

### Configure roles

1. Open **System > Role Management**.
2. Create or edit a role.
3. Assign menu and data permissions.
4. Save.

## FAQ

**Q: Who can access system settings?**
A: Only users with administrator or system configuration permissions can access this module.
