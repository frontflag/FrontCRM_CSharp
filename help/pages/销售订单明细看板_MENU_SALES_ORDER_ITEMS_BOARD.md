## 页面功能

- 在「销售订单明细」列表点击 **看板** 进入本视图；再点 **列表** 可返回表格。
- 看板统计范围与上方 **搜索栏当前筛选结果** 完全一致（全量匹配行，不是当前页）。
- 顶部 Tag 为 **筛选**：表示「跟筛选走」，**不会**再额外只保留「已审核成单」订单（与报表分析「订单」页签不同）。
- 本看板 **不展示** 趋势图与按日/周/月分组；若需趋势与成单硬口径，请到「报表分析 → 销售分析 → 订单」。
- 金额类数字受销售金额相关权限控制；无权限时可能显示为「—」，部分占比改为按行数统计。

也可阅读：[销售订单明细（列表）](销售订单明细_MENU_SALES_ORDER_ITEMS.md) · [销售分析 · 订单页签](销售分析_MENU_SALES_ANALYTICS.md#help-sales-order)

## 共同口径（请先读）

| 约定 | 说明 |
| --- | --- |
| 统计集合 | 当前搜索条件筛出的全部销售订单明细行（含主单日期、客户、销售员、采购员、各进度多选等）。 |
| 不成单约束 | **不**强制主单必须「审核通过」；筛选结果里若含新建、待审核或取消明细，会进入看板（金额/排行规则以页面为准）。 |
| 日期 | 通常按订单 **创建日**（搜索栏日期）约束；未选日期则按其它筛选条件汇总。 |
| 与报表区别 | 销售分析「订单」页签固定为公司/部门/个人 + 统一日期 + **成单**集合，并含趋势；本页跟列表筛选、无趋势。 |

<h2 id="help-so-item-board-overview">订单概览</h2>

| 指标 | 口径说明 |
| --- | --- |
| 客户数 | 筛选结果中涉及的去重客户数。 |
| 订单数 | 筛选结果中涉及的去重销售订单张数。 |
| 明细数 | 筛选结果中的明细行数。 |
| 金额 | 筛选结果明细金额合计（折算美元为主；可对照原币分档）。无金额权限时为「—」。 |

---

<h2 id="help-so-item-board-profit">利润</h2>

| 指标 | 口径说明 |
| --- | --- |
| 采购利润 | 筛选结果明细上已沉淀的采购利润汇总（无金额权限时隐藏或为「—」）。 |
| 出库利润 | 筛选结果明细上已沉淀的出库利润汇总。 |

具体字段含义与列表金额列一致，以页面提示为准。

---

<h2 id="help-so-item-board-stock">在库</h2>

| 指标 | 口径说明 |
| --- | --- |
| 在库客户数 | 筛选结果中仍有在库数量的去重客户数。 |
| 在库明细数 | 仍有在库数量的明细行数。 |
| 在库金额 | 在库数量 × 关联销售订单明细折算美金单价后合计（历史成交折算）；无权限时为「—」。 |
| 最长在库天数 | 上述范围内在库天数的最大值。 |

---

<h2 id="help-so-item-board-receivable">应收</h2>

| 指标 | 口径说明 |
| --- | --- |
| 应收客户数 | 仍有应收的去重客户数。 |
| 应收明细数 | 仍有应收的明细行数。 |
| 应收金额 | 未收齐金额合计（展示单位以页面为准）。 |
| 最长账龄 | 上述范围内应收账龄的最大值（天）。 |

**注意：** 此处应收来自订单明细执行数据；与「财务分析」里财务应收台账口径可能不同。

<h2 id="help-so-item-board-breakdown">分解</h2>

在当前筛选结果上按维度看构成。有金额权限时金额类图按美元汇总；无权限时多改为按 **明细行数** 占比。

| 面板 | 用途 | 统计口径 |
| --- | --- | --- |
| 明细主状态 | 看行是否有效/取消 | 按明细主状态分组计 **行数**（正常 / 已取消等）。 |
| 采购进度 | 看采购执行进度 | 按明细采购进度分组（待采购 / 采购中 / 采购完成等），计行数或金额。 |
| 入库进度 | 看入库进度 | 按明细入库进度分组计行数或金额。 |
| 出库通知进度 | 看通知出库进度 | 按出库通知进度分组计行数或金额。 |
| 收款进度 | 看收款进度 | 按收款进度分组计行数或金额。 |
| 开票进度 | 看开票进度 | 按开票进度分组计行数或金额。 |
| 币别构成 | 看原币结构 | 按明细交易币别汇总金额（或行数）。 |
| 品牌数量（Qty） | 看品牌件数 | 按品牌汇总明细 **数量**。 |
| 品牌金额（USD） | 看品牌金额 | 按品牌汇总明细 **折算美元金额**。 |
| 生产日期/DC | 看批次/日期码分布 | 按明细生产日期文本分桶，计行数。 |
| 销售员（USD） | 看业务员贡献 | 按订单销售员汇总明细折算美元金额（或行数）。 |

---

<h2 id="help-so-item-board-rankings">排行</h2>

筛选结果内 Top10；可在「金额 / 数量（或明细数）」间切换；无金额权限时以数量或明细数为主。

| 面板 | 用途 | 统计口径 |
| --- | --- | --- |
| 客户 Top10（金额） | 金额贡献最大的客户 | 按客户汇总明细折算美元金额，降序前 10。 |
| 物料 Top10（金额） | 金额贡献最大的型号 | 按物料型号汇总折算美元金额，降序前 10。 |
| 物料 Top10（数量） | 件数最多的型号 | 按物料型号汇总数量，降序前 10。 |
| 品牌 Top10（金额） | 金额贡献最大的品牌 | 按品牌汇总折算美元金额，降序前 10。 |
| 品牌 Top10（数量） | 件数最多的品牌 | 按品牌汇总数量，降序前 10。 |
| 销售员 Top10（金额） | 金额贡献最大的业务员 | 按销售员汇总折算美元金额，降序前 10。 |

## 使用提示

<div class="help-op-block">

**先筛再看看板**

**说明：** 改搜索条件后看板会按新结果刷新。适合「筛完某客户 / 某进度 / 某段日期」后看构成与排行。

</div>

<div class="help-op-block">

**需要成单 + 趋势时去销售分析**

**说明：** 本看板 Tag 为「筛选」，跟列表条件、无强制成单、无趋势。管理层按公司/部门/个人看已审核成单与趋势时，请用 [销售分析](销售分析_MENU_SALES_ANALYTICS.md) 的「订单」页签。

</div>
