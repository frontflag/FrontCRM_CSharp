## 页面功能

- 在「需求明细」列表点击 **看板** 进入；再点 **列表** 返回表格。
- 顶部 Tag 为 **筛选**：统计范围与搜索栏（及快捷检索）当前结果一致，**无额外硬过滤**。
- **不展示**趋势图；含趋势的报表口径见 [销售分析 · 需求](销售分析_MENU_SALES_ANALYTICS.md#help-sales-rfq)。
- 列表帮助：[需求明细](需求明细_MENU_RFQ_ITEMS.md)

## 共同口径

| 约定 | 说明 |
| --- | --- |
| 统计集合 | 当前筛选下的全部需求明细行（全量，非当前页）。 |
| 成单明细 / 成单率 | 仍按「已关联审核通过销售订单」链路计算；成单率分母排除「查无报价」。 |
| 与报表区别 | 销售分析「需求」页签按公司/部门/个人 + 日期，并排除已取消主单，且含趋势。 |

<h2 id="help-rfq-item-board-kpi">需求概览</h2>

| 指标 | 口径说明 |
| --- | --- |
| 发布需求客户数 | 筛选结果中有需求的去重客户数。 |
| 复询需求客户数 | 发布过 2 个及以上需求主单的去重客户数。 |
| 复询需求数 | 复询强度相关主单数量（以页面统计为准）。 |
| 需求数 | 涉及的需求主单数。 |
| 需求明细数 | 明细行数。 |
| 成单明细数 | 已挂上已审核销售订单明细的需求明细行数。 |
| 需求成单率 | 成单明细数 ÷（需求明细中非查无报价部分）× 100%（分母为 0 时不显示）。 |

---

<h2 id="help-rfq-item-board-breakdown">分解</h2>

在当前筛选结果上按维度看构成。占比 = 该项数量 ÷ 同组合计 × 100%。

| 面板 | 用途 | 统计口径 |
| --- | --- | --- |
| 需求主状态 | 看主单状态结构 | 按 **需求主单去重** 后，依主单状态分组计张数（如待分配、报价中、已关闭等，以页面状态名为准）。 |
| 需求类型 | 看需求类型占比 | 按 **需求主单去重**，依需求类型分组计张数。 |
| 目标类型 | 看目标类型占比 | 按 **需求主单去重**，依目标类型分组计张数。 |
| 行业 | 看客户行业分布 | 按 **需求主单去重**，依客户行业分组；未填显示「未设置」。 |
| 币别 | 看明细报价币别 | 按 **需求明细行** 计行数，依明细币别分组。 |
| 品牌分布 | 看物料品牌集中度 | 按 **需求明细行** 计行数，依品牌分组；未填显示「未设置」；常见为前若干品牌 +「其他」。 |
| 分配采购员 | 看采购员负载 | 按 **需求明细行** 计行数；明细上两个分配采购员槽位合并计数；未分配显示「未分配采购员」。 |
| 报价分布 | 看报价覆盖三档 | 按 **需求明细行** 归入三档之一：**有报价** / **查无报价** / **采购未处理**（明细为待处理且尚无报价）。 |

<h2 id="help-rfq-item-board-rankings">排行</h2>

取筛选结果内 Top10；空型号/品牌显示为「未设置」。客户名受客户信息权限影响，可能脱敏。

| 面板 | 用途 | 统计口径 |
| --- | --- | --- |
| 客户 Top10（需求明细数） | 谁询得最多 | 按客户汇总 **需求明细行数**，降序取前 10。 |
| 业务员 Top10（需求明细数） | 谁跟进的明细最多 | 按需求主单业务员汇总 **需求明细行数**，降序取前 10。 |
| MPN Top10（需求明细数） | 哪些型号被询最多 | 按物料型号汇总 **需求明细行数**，降序取前 10。 |
| MPN Top10（需求数量） | 哪些型号件数最多 | 按物料型号汇总明细 **需求数量**，降序取前 10。 |
| 品牌 Top10（需求明细数） | 哪些品牌被询最多 | 按品牌汇总 **需求明细行数**，降序取前 10。 |
| 品牌 Top10（需求数量） | 哪些品牌件数最多 | 按品牌汇总明细 **需求数量**，降序取前 10。 |
