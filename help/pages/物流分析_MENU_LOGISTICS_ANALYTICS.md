## 页面功能

- 从「报表分析 → 物流分析」进入，按您可见的库存与采购相关范围查看在库与待入库情况。
- 上方可切换 **公司 / 部门 / 个人** 视角（部分账号仅按销/采归属查看，可能无「公司」），并选择 **库存类型**（全部 / 客单 / 采购）、**截至日期**、趋势区间与粒度。
- 金额类数字多为 **美元采购成本**；无采购金额相关权限时可能显示为「—」。
- 部分数字、排行可点击跳转到库存或采购相关列表（须具备目标列表权限）。

## 共同口径（请先读）

| 约定 | 说明 |
| --- | --- |
| 在库时点 | **在库概览、库龄、客户矩阵、排行** 按 **截至日期** 的在库存量统计（有数量的在库行）。 |
| 库龄起算 | 按 **入库日** 起算至截至日期的自然天数。 |
| 趋势区间 | **入库数量趋势** 只统计趋势开始～结束这段时间内、按入库日归入各时段的入库流量，**不是**期末在库存量。 |
| 待办例外 | **待入库数量** 为当前采购订单尚未收齐的数量，**不受**截至日期影响。 |
| 在库金额 | 在库数量 × 美元采购单价后合计；页面副标题已提示金额口径。 |
| 库存类型 | 「客单库存 / 采购库存 / 全部」会过滤可见在库与相关待入库范围，以页面选项为准。 |

---

<h2 id="help-logistics-todo">待办</h2>

| 指标 | 口径说明 |
| --- | --- |
| 待入库数量(PCS) | 有效采购订单明细上「订购数量 − 已收货数量」的剩余之和（只计仍有剩余的行）。表示当前还欠着入库的件数，与截至日期无关。 |

**注意：** 待入库是采购订单收货缺口，与「当前仓库里还有多少货」是不同概念。

---

<h2 id="help-logistics-snapshot">在库概览</h2>

截至所选日期的在库快照（有现存数量的库存行）。

| 指标 | 口径说明 |
| --- | --- |
| 在库商品数量 | 符合筛选条件的在库现存数量合计（件数）。 |
| 在库商品金额 | 上述数量按美元采购成本合计；无金额权限时为「—」。 |
| 加权平均库龄 | 按数量加权的平均在库天数；总量为 0 时不显示。库龄从入库日算到截至日。 |
| 客户数 | 有客户归属的在库行涉及的去重客户数（无客户的备货行不计入客户数）。 |
| 销售员数 / 供应商数 / 采购员数 / 品牌数 | 对应字段的去重主体数（空值不计入）。 |

### 库龄分布

按数量（不是金额）把在库商品分到库龄桶，例如：0–30 天、31–90 天、91–180 天、181–365 天、365 天以上。各桶数量之和应等于「在库商品数量」。

---

<h2 id="help-logistics-trend">入库趋势</h2>

| 指标 | 口径说明 |
| --- | --- |
| 入库数量趋势 | 按日 / 周 / 月，把趋势区间拆成多个时段；每个点是该时段内按 **入库日** 归入的库存数量合计。表示这段时间「进来了多少」，不是「期末还剩多少」。 |

改「截至日期」主要影响在库快照与库龄；改趋势起止主要影响本图。

---

<h2 id="help-logistics-matrix">客户矩阵</h2>

以 **客户** 为父行（无客户时显示为「无客户 / 备货」一类文案），可再按 **销售员 / 供应商 / 采购员 / 品牌** 展开子行。

| 列 | 口径说明 |
| --- | --- |
| 在库数量 | 该客户（或客户+科目）下的现存件数合计。 |
| 在库金额 | 对应美元采购成本合计；无金额权限时为「—」。 |
| 加权平均库龄 | 该范围内按数量加权的平均库龄。 |

切换「统计科目」会按所选维度重新拆分子行；同一客户下子行数量合计应等于父行数量。默认多按金额（或脱敏时按数量）从高到低排列。

---

<h2 id="help-logistics-rankings">排行</h2>

截至日在库 Top10；有金额权限时多按金额排序，否则按数量。

| 视角 | 排行内容 |
| --- | --- |
| 公司 | 客户在库 Top10 |
| 部门 | 销售员在库 Top10 |
| 个人 | 供应商在库 Top10 |

| 列 | 口径说明 |
| --- | --- |
| 名称 | 客户 / 销售员 / 供应商显示名 |
| 数量 | 在库件数（PCS），不是订单张数 |
| 金额 | 美元采购成本；无权限时为「—」 |

无对应归属（如空客户）的行一般不进入公司「客户」排行。

---

## 使用提示

<div class="help-op-block">

**时点存量 vs 期间流量**

**说明：** 在库概览、库龄、矩阵、排行看的是「截至某天还剩多少」；入库趋势看的是「某段时间进了多少」。不要把趋势点当成期末库存。

</div>

<div class="help-op-block">

**待入库不会跟着截至日变**

**说明：** 改截至日期应改变在库与库龄；待入库件数主要随采购收货进度变化，不应只因改截至日而变。

</div>
