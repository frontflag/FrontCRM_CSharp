## 页面功能

- 从「报表分析 → 物流分析」进入，按您可见的库存与采购相关范围查看在库与待入库情况。
- 上方可切换 **公司 / 部门 / 个人** 视角（部分账号仅按销/采归属查看，可能无「公司」），并选择 **库存类型**（全部 / 客单 / 采购）、**截至日期**、趋势区间与粒度。
- 金额类数字为 **折算美元（USD）**（在库为采购成本；出入库概况为过账时的美金单价快照）；无对应金额权限时可能显示为「—」。入库金额与出库金额的可见性可能不同。
- 部分数字、排行可点击跳转到库存或采购相关列表（须具备目标列表权限）。**入库金额**与**出库金额**整张卡片都不可点；在看全公司、库存类型为「全部」时，原币行右侧有「查看」。入库打开对应原币的已入库采购入库单；出库打开对应原币的已完成销售出库明细。客单 / 采购库存下没有「查看」。

## 共同口径（请先读）

| 约定 | 说明 |
| --- | --- |
| 在库时点 | **在库概览、库龄、客户矩阵、排行** 按 **截至日期** 的在库存量统计（有数量的在库行）。 |
| 库龄起算 | 按 **入库日** 起算至截至日期的自然天数。 |
| 趋势区间 | **出入库概况** 与 **入库/出库数量趋势** 只统计趋势开始～结束这段时间的期间流量，**不是**期末在库存量。 |
| 待办例外 | **待入库数量** 为当前采购订单尚未收齐的数量，**不受**截至日期影响。 |
| 在库金额 | 在库数量 × 关联采购订单明细当时落库的折算美金单价后合计（历史成交折算）；页面副标题已提示金额口径。 |
| 库存类型 | 「客单库存 / 采购库存 / 全部」会过滤可见在库与相关待入库范围，以页面选项为准。 |
| 数据源列 | 下文含「口径说明」的表格均附 **数据源**，表示统计对象对应的业务列表（便于对账）。分析页另有视角、库存类型与日期条件，与列表默认打开结果不必完全相同。 |

<h2 id="help-logistics-todo">待办</h2>

| 指标 | 数据源 | 口径说明 |
| --- | --- | --- |
| 待入库数量(PCS) | 采购订单明细 | 有效采购订单明细上「订购数量 − 已收货数量」的剩余之和（只计仍有剩余的行）。表示当前还欠着入库的件数，与截至日期无关。 |

**注意：** 待入库是采购订单收货缺口，与「当前仓库里还有多少货」是不同概念。

---

<h2 id="help-logistics-flow">出入库概况</h2>

按 **趋势区间** 统计这段时间实际发生的采购入库、销售出库金额（主数字为折算美元，可查看本币分档）。与「截至某天仓库里还剩多少」不是同一回事。

| 指标 | 数据源 | 口径说明 |
| --- | --- | --- |
| 入库金额 | 入库单 | 区间内已入库的采购入库：件数 × 采购单价；美元按入库当时记下的美金单价。不含报关、退货、报废、调拨入库。 |
| 出库金额 | 出库明细 | 区间内已标记「出库完成」的销售出库：件数 × 销售单价；美元按出库当时记下的美金单价。不含尚未完成的出库，也不含报关、退货、报废、调拨出库。 |

无对应金额权限时该卡显示「—」。**入库金额**请点原币旁的「查看」（仅全公司 + 库存类型「全部」时出现），会打开入库单列表，并带上采购入库、已入库、该原币和趋势区间的入库日期；筛选栏不会出现币别或状态下拉。一张入库单若含多种原币，可能同时出现在不同币别的「查看」结果里，列表合计不必等于卡片该币金额。**出库金额**同样用原币「查看」（条件相同），打开出库明细列表，并带上销售出库、出库完成、该原币和趋势区间的出库日期；状态下拉会显示为「出库完成」，币别不出现在筛选栏。客单或采购库存时两卡都没有「查看」。

**注意：** 这里的出库金额按「仓库出库完成日」统计，和销售分析里按「销售订单创建日」统计的已出库金额一般对不上，属正常差异。

<h2 id="help-logistics-snapshot">在库概览</h2>

截至所选日期的在库快照（有现存数量的库存行）。

| 指标 | 数据源 | 口径说明 |
| --- | --- | --- |
| 在库商品数量 | 库存明细 | 符合筛选条件的在库现存数量合计（件数）。 |
| 在库商品金额 | 库存明细 | 上述数量按关联采购订单明细折算美金单价合计（标注「折算美元」）；无金额权限时为「—」。 |
| 加权平均库龄 | 库存明细 | 按数量加权的平均在库天数；总量为 0 时不显示。库龄从入库日算到截至日。 |
| 客户数 | 库存明细 | 有客户归属的在库行涉及的去重客户数（无客户的备货行不计入客户数）。 |
| 销售员数 / 供应商数 / 采购员数 / 品牌数 | 库存明细 | 对应字段的去重主体数（空值不计入）。 |

### 库龄分布

按数量（不是金额）把在库商品分到库龄桶，例如：0–30 天、31–90 天、91–180 天、181–365 天、365 天以上。各桶数量之和应等于「在库商品数量」。

<h2 id="help-logistics-trend">出入库趋势</h2>

| 指标 | 数据源 | 口径说明 |
| --- | --- | --- |
| 入库数量趋势 | 入库单 | 按日 / 周 / 月，把趋势区间拆成多个时段；每个点是该时段内已过账采购入库行的 **入库数量** 合计。与「入库金额」同窗、同批单据，只是不乘单价。 |
| 出库数量趋势 | 出库明细 | 按日 / 周 / 月，把趋势区间拆成多个时段；每个点是该时段内 **出库完成** 的销售出库行 **出库数量** 合计。与「出库金额」同窗、同批单据；不含准备出库，也不含报关、退货、报废、调拨出库。 |

改「截至日期」主要影响在库快照与库龄；改趋势起止主要影响本区两图和出入库概况。

<h2 id="help-logistics-matrix">客户矩阵</h2>

以 **客户** 为父行（无客户时显示为「无客户 / 备货」一类文案），可再按 **销售员 / 供应商 / 采购员 / 品牌** 展开子行。

| 列 | 数据源 | 口径说明 |
| --- | --- | --- |
| 在库数量 | 库存明细 | 该客户（或客户+科目）下的现存件数合计。 |
| 在库金额 | 库存明细 | 对应美元采购成本合计；无金额权限时为「—」。 |
| 加权平均库龄 | 库存明细 | 该范围内按数量加权的平均库龄。 |

切换「统计科目」会按所选维度重新拆分子行；同一客户下子行数量合计应等于父行数量。默认多按金额（或脱敏时按数量）从高到低排列。

---

<h2 id="help-logistics-rankings">排行</h2>

截至日在库 Top10；有金额权限时多按金额排序，否则按数量。

| 视角 | 排行内容 |
| --- | --- |
| 公司 | 客户在库 Top10 |
| 部门 | 销售员在库 Top10 |
| 个人 | 供应商在库 Top10 |

| 列 | 数据源 | 口径说明 |
| --- | --- | --- |
| 名称 | 库存明细 | 客户 / 销售员 / 供应商显示名 |
| 数量 | 库存明细 | 在库件数（PCS），不是订单张数 |
| 金额 | 库存明细 | 美元采购成本；无权限时为「—」 |

无对应归属（如空客户）的行一般不进入公司「客户」排行。

## 使用提示

<div class="help-op-block">

**时点存量 vs 期间流量**

**说明：** 在库概览、库龄、矩阵、排行看的是「截至某天还剩多少」；出入库概况和入库/出库数量趋势看的是「某段时间进了/出了多少」。不要把期间金额或趋势点当成期末库存。

</div>

<div class="help-op-block">

**待入库不会跟着截至日变**

**说明：** 改截至日期应改变在库与库龄；待入库件数主要随采购收货进度变化，不应只因改截至日而变。

</div>
