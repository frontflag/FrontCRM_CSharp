# 出库运维检查

## 页面功能

给系统管理员、平台管理员和财务总监核对装箱到出库、再到应收是否对得上。只出检查结果，**不会改任何单据**。

一次检查会看：

- 装箱单已经出库完成，却找不到有效出库单
- 已经有出库单，装箱状态还停在已备货等
- 同一张装箱单或同一行被出了多次
- 销售出库已完成但没有应收（**销售行单价为 0 的除外**，样品赠送本来就不生成应收），或出库已经删掉、应收还在（现在强制删除出库时，未核销应收会一起去掉）
- 应收数量、金额、币别和销售行对不上
- 装箱 / 出库 / 应收 / 销售订单的客户不是同一家

销售出库不查供应商。调拨虚拟出库不参加检查。

## 操作说明

<div class="help-op-block">

**检查**

对全部装箱、出库、应收跑一遍。完成后标题下方会出现错误、警告、合计三张卡片，明细在更下面的表格。

</div>

<div class="help-op-block">

**筛选**

结果太多时，用卡片下方的条件栏只看一类问题。可按级别、检查类型、单据类型筛选，也可输入单号（匹配本行单号或关联单号，从左边开始匹配）。点「搜索」或回车生效；下拉选完即生效。筛选时第三张卡片会改成「显示」当前条数 / 全部条数。「重置」只清筛选，不会清掉这次检查结果，也不会改任何单据。

</div>

## 结果怎么看

| 列 | 含义 |
|---|---|
| 级别 | 错误必须处理；警告建议核对 |
| 单号 | 点进去打开对应单据 |
| 关联单号 | 同一条问题的另一张单 |
| 错误原因 | 哪里不对（写业务单号和客户编号，不写内部 ID） |
| 运维操作建议 | 按这一行的单据逐步写明：打开哪个页面、哪张单号、点哪个按钮。多步会换行编号。未收款核销的行不会让你去反核销 |

本页不提供一键修复。同一张装箱单出了多次时，一般留下出库单号最小的那张，删掉其余后再点装箱单「刷新」。若出库已完成但出库通知仍停在「已装箱」，也在装箱单详情点「刷新」同步通知状态。改完后再点一次「检查」确认是否消失。
