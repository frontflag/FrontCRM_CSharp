## 页面功能

- 从「报表分析 → 采购分析」进入，按您可见的采购数据范围查看汇总。
- 上方可切换 **公司 / 部门 / 个人** 视角，并选择日期区间；个人视角下还可指定采购员（有权限时）。
- 下方分为四个内容页签：**概况**、**供应商**、**报价**、**订单**。各页签共用上方筛选条件。
- 金额类数字受「采购金额」相关权限控制：无权限时可能显示为「—」，部分占比图会改为按订单数或行数统计。
- 部分数字、排行可点击跳转到对应业务列表（须具备目标列表权限）。

## 共同口径（请先读）

| 约定 | 说明 |
| --- | --- |
| 日期作用范围 | **概况**中的统计概览、趋势、分解、排行，以及 **供应商 / 报价 / 订单** 页签，均受上方日期区间约束。 |
| 待办例外 | **概况 → 待办** 两项表示「当前还欠着办的存量」，**不受**日期起止影响。 |
| 采购订单排除 | 统计时排除主单状态为「取消」「审核失败」的订单。 |
| 「成单」含义 | 主单已达「审核通过」及以上（含进行中、完成等），金额按订单折算后的 **美元** 汇总（页面副标题已提示）。 |
| 报价日期 | **报价**页签按报价单的 **创建日期** 落入区间；新建 / 成单 / 关闭等状态均纳入（不做额外状态硬过滤）。 |
| 订单日期 | **概况**采购侧与 **订单**页签，按采购订单的 **创建日期** 落入区间。 |
| 数据范围 | 只统计您数据权限内可见的报价与采购订单；切换公司/部门/个人只是在权限内换聚合视角。 |

<h2 id="help-purchase-overview">概况</h2>

域级总览：待办、统计概览、多条趋势、分解图，以及随视角变化的排行（不含供应商贡献排行，供应商见「供应商」页签）。

### 待办

| 指标 | 口径说明 |
| --- | --- |
| 应付款金额 | 当前权限范围内，有效采购明细上「尚未付齐」的金额合计。与所选日期无关。 |
| 待入库明细数 | 入库进度仍为「待入库」或「部分入库」的 **明细行数**（不是订单张数）。与所选日期无关。 |

**注意：** 「待办应付」与趋势里的「应付趋势」不同——趋势只看区间内、已审核订单按创建日归入各时段的未付款；待办是截至此刻的全部应付余额。

### 统计概览

| 指标 | 口径说明 |
| --- | --- |
| 报价条目数 | 日期区间内创建的报价 **明细行** 数量。 |
| 报价供应商数 | 上述报价涉及的去重供应商数。 |
| 报价→采购转化率 | 区间内已关联到采购订单明细的报价明细数 ÷ 报价条目数 × 100%。分母为 0 时不显示比率。按明细行计。 |
| 采购订单条目数 | 区间内创建的采购订单 **有效明细行** 数（含尚未审核的订单）。 |
| 采购供应商数 | 区间内采购订单涉及的去重供应商数（含尚未审核）。 |
| 成单金额（已审核） | 区间内创建、且已审核通过及以上的订单，美元折算总额合计。新建/待审核不计入。 |
| 已入库金额 | 已审核订单明细上，已入库数量 × 折算单价的合计。 |
| 已付款金额 | 已审核订单明细上「已付款」金额合计。 |

### 趋势

按日 / 周 / 月把区间拆成多个时段；每个点是该时段内的汇总值。

| 趋势图 | 口径说明 |
| --- | --- |
| 成单金额趋势 | 各时段内已审核采购订单的美元成单额。 |
| 已入库 / 已付款金额趋势 | 各时段内已审核明细的入库额、已付款额。 |
| 报价条目 / 报价供应商数趋势 | 按报价创建日归入时段；供应商数为时段内去重。 |
| 订单条目 / 采购供应商数趋势 | 按采购订单创建日归入时段。 |
| 转化率趋势 | 与概览转化率同算法，按每个时段单独计算。 |
| 应付趋势 | 各时段内、已审核采购明细的未付款合计。**不是**待办应付。 |

### 分解

| 图 | 口径说明 |
| --- | --- |
| 订单主状态 | 区间内非取消/失败订单，按主单状态汇总金额；无金额权限时改为按订单张数占比。含未审核订单。 |
| 币别构成（成单） | 仅已审核成单，按订单原币别看金额占比；无金额权限时按订单数占比。 |
| 全链路环节 | 已审核订单的每条明细只归入一个「当前卡点」（如待入库 → 待付款 → 待进项开票 → 已完结等，以页面图例为准）。 |
| 入库进度 | 区间内有效明细按入库进度计行数。 |

### 排行（Top10）

仅统计区间内 **已审核成单**；有金额权限时按金额排序，否则按订单数排序。

| 视角 | 排行内容 |
| --- | --- |
| 公司 | 各部门采购额 Top10（可下钻到部门视角）。 |
| 部门 | 部门内采购员 Top10（可下钻到个人或订单列表）。 |
| 个人 | 概况页不展示排行；供应商贡献见「供应商」页签。 |

<h2 id="help-purchase-vendor">供应商</h2>

看「谁在成单、谁在复采」，与概况共用日期与公司/部门/个人筛选。进入本页签后才会加载数据。

| 指标 / 面板 | 口径说明 |
| --- | --- |
| 成单供应商数 | 区间内已审核成单订单涉及的去重供应商数，与概况「采购供应商数」在成单口径下一致（只计成单供应商）。 |
| 复采供应商数 | 上述成单供应商中，成单 **订单张数 ≥ 2** 的供应商数。 |
| 供应商身份 / 等级 / 行业 | 按成单金额（美元）看构成；无金额权限时改为按订单数占比。 |
| 供应商 Top10（成单金额） | 区间内成单金额最高的供应商。 |
| 供应商 Top10（成单数） | 区间内成单订单张数最多的供应商。 |
| 供应商 Top10（复采订单数） | 复采订单数 = 成单订单数 − 1（至少成单 1 张时才有意义）；用于观察重复下单强度。 |

点击供应商排行可进入采购订单列表（带供应商等筛选条件）。

若要按 **供应商列表筛选结果** 看同类面板（且 **不限订单日期**），请使用 [供应商列表 · 看板](供应商列表看板_MENU_VENDOR_HOME_BOARD.md)。

<h2 id="help-purchase-quote">报价</h2>

与「报价列表」看板同一套统计逻辑；本页签标记为 **报表** 口径：按上方公司/部门/个人 + 日期（报价创建日）。进入本页签后加载；可切换按日/周/月看趋势。

### 报价概览

| 指标 | 口径说明 |
| --- | --- |
| 提供报价的供应商数 | 区间内有报价的去重供应商数。 |
| 有效报价条目数 | 区间内有效报价（非「查无报价」类）的条目数，以页面统计为准。 |
| 查无报价条目数 | 标记为查无报价的相关条目数。 |
| 需求报价率 | 有报价的需求明细占比（分母为 0 时不显示）。 |
| 报价平均响应时间 | 从需求到首条报价的平均耗时（分钟）。 |
| 报价平均数 | 平均每条需求明细对应的报价条数。 |
| 成单数 | 已关联到采购/销售成单链路的需求明细数（以页面提示为准）。 |
| 报价成单率 | 成单数 ÷ 有报价需求明细数 × 100%（分母为 0 时不显示）。 |

### 趋势

报价供应商数、需求明细数、有效报价数随时间变化（按报价创建日归入各时段）。

### 分解与排行

各面板用途与统计口径与「报价列表 · 看板」相同（报表集合为公司/部门/个人 + 报价创建日，并含趋势）。详见 [报价列表 · 看板 — 分解 / 排行](报价列表看板_MENU_QUOTE_LIST_BOARD.md#help-quote-board-breakdown)。

<h2 id="help-purchase-order">订单</h2>

与「采购订单明细」列表看板同一套统计逻辑；本页签标记为 **成单** 口径：按上方公司/部门/个人 + 日期（订单创建日），且只统计 **主单已审核通过及以上、明细有效** 的行。进入本页签后加载；可切换按日/周/月看趋势。

### 成单概览 / 在库 / 应付款

| 分组 | 指标含义（摘要） |
| --- | --- |
| 成单概览 | 成单供应商数、订单张数、明细行数、成单金额（美元）；并可对照原币分档展示。 |
| 在库 | 仍有在库数量的供应商数、明细数、在库金额（美元）、最长在库天数等。 |
| 应付款 | 仍有应付款的供应商数、明细数、应付款金额等。 |

### 趋势

成单订单数、成单明细数、成单明细金额（美元）随时间变化。

### 分解与排行

各面板用途与统计口径与「采购订单明细 · 看板」相同（报表集合为成单硬过滤 + 公司/部门/个人 + 日期，并含趋势）。详见 [采购订单明细 · 看板 — 分解 / 排行](采购订单明细看板_MENU_PURCHASE_ORDER_ITEMS_BOARD.md#help-po-item-board-breakdown)。

## 使用提示

<div class="help-op-block">

**切换页签看不同粒度**

**说明：** 「概况」看全链路经营总览与待办；「供应商」看供应商贡献与复采；「报价」看报价覆盖与响应；「订单」看成单后入库与应付。四者共用顶部视角与日期，改筛选后请点「查询」或进入页签自动刷新。

</div>

<div class="help-op-block">

**金额单位不要混加**

**说明：** 成单金额与多数排行为 **美元**；待办应付、部分入库/付款类数字可能按本币或页面单位提示展示。对比时请留意页面上的单位说明。

</div>

<div class="help-op-block">

**与列表页看板的区别**

**说明：** 报价列表、采购订单明细列表里的「看板」跟列表搜索条件联动，适合筛完再看；本页是管理层报表视角，跟公司/部门/个人与统一日期联动，订单页签固定为「成单」集合，报价页签按报价创建日统计。

</div>
