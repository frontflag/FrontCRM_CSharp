## 页面功能

- 在「采购订单明细」列表点击 **看板** 进入；再点 **列表** 返回表格。
- 顶部 Tag 为 **筛选**：与搜索栏结果一致，**无额外成单硬过滤**（可含取消等，以提示为准）。
- **不展示**趋势；成单硬口径 + 趋势见 [采购分析 · 订单](采购分析_MENU_PURCHASE_ANALYTICS.md#help-purchase-order)。
- 列表帮助：[采购订单明细](采购订单明细_MENU_PURCHASE_ORDER_ITEMS.md)

## 共同口径

| 约定 | 说明 |
| --- | --- |
| 统计集合 | 当前筛选下的全部采购订单明细行。 |
| 指标名称 | 界面可能仍显示「成单××」，在筛选模式下表示「当前结果集内」的汇总，不等于报表「仅审核通过」。 |
| 与报表区别 | 采购分析「订单」固定成单集合 + 公司/部门/个人 + 趋势。 |

---

<h2 id="help-po-item-board-overview">成单概览</h2>

| 指标 | 口径说明 |
| --- | --- |
| 供应商数 / 订单数 / 明细数 | 筛选结果中的去重供应商、订单张数、明细行数。 |
| 金额 | 明细金额合计（美元；可对照原币）。 |

---

<h2 id="help-po-item-board-stock">在库</h2>

在库供应商数、在库明细数、在库金额（美元）、最长在库天数等——均在筛选结果上统计仍有在库数量的行。

---

<h2 id="help-po-item-board-payable">应付款</h2>

应付款供应商数、明细数、应付款金额等——筛选结果中仍有未付清的行。

---

<h2 id="help-po-item-board-breakdown">分解</h2>

在当前筛选结果上按维度看构成。有金额权限时金额类图按美元汇总；无权限时多改为按 **明细行数** 占比。

| 面板 | 用途 | 统计口径 |
| --- | --- | --- |
| 明细主状态 | 看行状态结构 | 按采购明细主状态分组计 **行数**（或金额）。 |
| 申请付款状态 | 看请款进度 | 按明细关联付款申请进度分组计行数或金额。 |
| 付款进度 | 看付款执行 | 按明细付款进度分组计行数或金额。 |
| 采购进度 | 看采购执行 | 按明细采购进度分组计行数或金额。 |
| 入库进度 | 看入库执行 | 按明细入库进度分组计行数或金额。 |
| 开票进度 | 看进项开票 | 按明细开票进度分组计行数或金额。 |
| 币别构成 | 看原币结构 | 按明细币别汇总金额（或行数）。 |
| 品牌数量（Qty） | 看品牌件数 | 按品牌汇总明细数量。 |
| 品牌金额（USD） | 看品牌金额 | 按品牌汇总折算美元金额。 |
| 生产日期/DC | 看批次/日期码 | 按明细生产日期文本分桶，计行数。 |
| 采购员（USD） | 看采购员贡献 | 按订单采购员汇总折算美元金额（或行数）。 |

---

<h2 id="help-po-item-board-rankings">排行</h2>

筛选结果内 Top10；可在「金额 / 数量（或明细数）」间切换；无金额权限时以数量或明细数为主。

| 面板 | 用途 | 统计口径 |
| --- | --- | --- |
| 供应商 Top10（金额） | 金额贡献最大的供应商 | 按供应商汇总明细折算美元金额，降序前 10。 |
| 物料 Top10（金额） | 金额贡献最大的型号 | 按物料型号汇总折算美元金额，降序前 10。 |
| 物料 Top10（数量） | 件数最多的型号 | 按物料型号汇总数量，降序前 10。 |
| 品牌 Top10（金额） | 金额贡献最大的品牌 | 按品牌汇总折算美元金额，降序前 10。 |
| 品牌 Top10（数量） | 件数最多的品牌 | 按品牌汇总数量，降序前 10。 |
| 采购员 Top10（金额） | 金额贡献最大的采购员 | 按采购员汇总折算美元金额，降序前 10。 |
