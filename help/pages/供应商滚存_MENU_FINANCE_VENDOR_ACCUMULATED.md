# 供应商滚存

## 页面功能

- 在库存滚存口径基础上，按**供应商**维度统计各自然月的采购入库与销售出库数量、金额（美元）。
- **汇总页**：选择月份后分页列出有滚存数据的供应商；支持按供应商名称或编码关键词筛选。
- **明细页**：查看某一供应商在指定月份下的入库明细行滚存；支持物料型号、入库单号、入库日期筛选。
- 入库时未指定供应商的明细归入「**未指定**」行。
- 本报表为**只读**；无相关金额权限时金额列显示「—」。

## 数据来源与计算说明

### 一、供应商维度：数据从哪来

供应商滚存与「库存滚存」使用**同一套**采购入库、销售出库流水，额外按**供应商**归集：

| 环节 | 读取位置 | 规则 |
|------|----------|------|
| **入库归属供应商** | 采购入库单表头或库存层 | 优先取入库单表头上的供应商；表头为空时取库存层上的供应商；皆空则「未指定」 |
| **出库归属供应商** | 出库扩展信息或入库供应商 | 优先取出库扩展上的供应商；为空时视为与对应入库明细的入库供应商相同 |
| **维度匹配** | 出库供应商 vs 入库供应商 | 若出库侧供应商与对应入库明细的入库供应商**不一致**，该笔出库**整笔不计入**任何供应商 |
| **供应商名称** | 供应商主数据 | 按公司全称 → 简称 → 英文全称 → 供应商编码 顺序取显示名 |

入库、出库的单据类型、状态、删除标记、月份边界等与「库存滚存」一致。

### 二、汇总页各列含义

对**选定自然月 M**、**供应商 V**（含「未指定」）：

| 列名 | 如何读取与计算 |
|------|----------------|
| **供应商** | 供应商主数据显示名；无供应商 ID 显示「未指定」 |
| **上期数量 / 上期金额** | M 月之前、归属 V 的累计入库 − 累计出库 |
| **入库数量 / 本期入库(USD)** | M 月内、归属 V 的采购入库合计 |
| **出库数量 / 本期出库(USD)** | M 月内、归属 V 且通过供应商维度匹配的销售出库合计 |
| **结余数量 / 结余金额(USD)** | 上期 + 本期入库 − 本期出库 |

**列表出现条件：** 该供应商在 M 月有动静，**或**上期非零。按名称升序，「未指定」排最后。

关键词搜索在供应商主数据中匹配名称与编码，再过滤汇总结果。

### 三、明细页各列含义

在选定**月份 + 供应商**后，列出相关采购入库明细行：

| 列名 | 数据从哪来 | 说明 |
|------|------------|------|
| **入库单号 / 物料型号 / 入库时间** | 采购入库单及明细 | 与库存明细滚存相同 |
| **入库数量 / 本期入库(USD)** | 入库明细 | 仅入库日期落在所选自然月内计入本期入库 |
| **出库数量 / 本期出库(USD)** | 关联销售出库 | 仅统计供应商维度匹配的出库 |
| **上期数量 / 上期金额** | 本月前的关联出库 | 行级滚动，规则同库存明细滚存 |
| **结余数量 / 结余金额** | 行内公式 | 上期 + 本期入库 − 本期出库 |

若入库时间早于所选月但当月有匹配出库，该行仍会出现在明细中，本期入库为 0。

## 统计范围与过滤规则（摘要）

- 与库存滚存相同的入出库单据范围。
- **供应商专有条目**：出库供应商 ≠ 入库供应商 → 不计入。
- **权限**：须具备「库存滚存」查看权限；供应商名称链接另需供应商查看权限；入库单号链接另需库存查看权限。

## 金额列 (USD) 说明

供应商滚存的四列 **(USD)** 金额与「[库存滚存](库存滚存_MENU_FINANCE_STOCK_ACCUMULATED.md)」**完全相同**：均为**折算后的美元金额**，按入库/出库过账时写入的美元采购单价计算，报表查询时不再重新换汇。

### 折算与计算（摘要）

| 环节 | 说明 |
|------|------|
| **入库金额** | 入库数量 × 库存层「美元采购价」（入库过账时按财务基准汇率折算） |
| **出库金额** | 出库数量 × 出库扩展或库存层上的美元采购价 |
| **上期 / 结余** | 在供应商维度内，按自然月滚动：上期 + 本期入库 − 本期出库 |

四列含义：**上期金额(USD)**、**本期入库(USD)**、**本期出库(USD)**、**结余金额(USD)** — 详见库存滚存帮助中的「金额列 (USD) 说明」。

### 显示与权限

- 美元两位小数；无相关金额查看权限时显示「—」，数量不受影响。
