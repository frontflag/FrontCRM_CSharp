# 收款核销

## 页面功能

- 将客户来款（收款单明细）或预收池余额，与销售出库产生的 **应收款** 进行匹配核销。
- 核销结果写入 **核销流水**，可在本页右上角「收款核销流水」或销售订单明细的 **收款核销** 页签中查询。

## 左栏「待核销客户」说明

左侧列表是 **来款侧入口**。系统分两步确定您看到的内容：

1. **服务端**：找出所有 **有待核销收款** 的客户（按客户 + 币别一行），并标记该行是否有 **未清应收**（`hasOpenReceivable`）。
2. **页面展示**：默认显示全部；可通过勾选项隐藏无应收客户；无应收的行以灰色区分。

### 谁会出现在列表里（服务端）

须 **同时满足**：

- 已生成收款单，状态为 **已审核** 或 **已收款**；
- 至少有一条收款明细 **剩余可核销金额 &gt; 0**（已核销、已转预收池部分不计入）。

**不会出现**：

| 情况 | 说明 |
|------|------|
| 仅有未清应收，还没有可核销收款 | 请先在 **应收款** 模块跟进；来款录入并审核后再来本页 |
| 仅有预收池余额，没有待核销收款 | 不会单独因预收池出现在左栏 |
| 收款单仍为草稿/待审，或明细已全部核销 | 无待分配来款 |

### 列表字段

- **待核销收款总额**：该客户该币别下，所有待核销收款明细剩余金额之和（**不含**应收待收金额）。
- **待核销收款条数**：上述收款明细条数（至少为 1）。
- **收款日期**：相关收款单的最早/最近收款日期。

### 「去除无待核销应收客户」勾选项（默认不勾选）

| 状态 | 列表内容 | 右栏待核销应收 |
|------|----------|----------------|
| **不勾选** | 全部有待核销收款的客户 | 可能有，也可能没有（如仅来款、应收已结清） |
| **勾选** | 仅显示 **同时有** 待核销收款与该币别未清应收的客户 | 选中后 **一定有** 可核销应收 |

- **灰色行**：有待核销收款，但该币别 **没有** 未清应收（例如来款余额待转预收、或应收已全部核销）。不勾选时可见；勾选后被隐藏。
- 勾选后若当前选中的客户被隐藏，系统会自动选中第一条或清空选中。

### 选定客户后

- **中间栏**：该客户的待核销收款（与左栏行 **币别** 一致）。
- **右侧栏**：该客户该币别的待核销应收（及预收池，若有）。

## 操作说明

<div class="help-op-block">

**选择客户**

**说明：** 在左侧列表搜索（中文名 / 英文名 / 客户编号 / 业务员）或双击/点击「选中」。默认显示全部有待核销收款的客户；无未清应收的行为灰色。勾选「去除无待核销应收客户」可只显示能立即核销的客户。

**前置条件：** 客户须存在待核销收款明细；账号具备 `finance-receipt.read`。

</div>

<div class="help-op-block">

**勾选收款并填写核销金额**

**说明：**

1. 在中间栏勾选一条或多条 **待核销收款**（收款单须已审核或已收款）；
2. 在右侧「待核销应收」的 **本次核销** 列填写分配金额；
3. 也可使用客户 **预收池** 对右侧应收分配（无需勾选收款明细）；
4. 点击提交完成核销。

**前置条件：** `finance-receipt.write`；同一批次须同一客户；收款币别与应收币别一致。

</div>

<div class="help-op-block">

**销售单不一致确认**

**说明：** 若预收关联的销售订单与应收关联的销售订单不一致，系统会列出差异，确认后可继续核销。

</div>

<div class="help-op-block">

**查看核销流水**

**说明：** 点击页头「收款核销流水」进入列表；支持按应收号、收款单号、出库单号、客户等关键字检索。

</div>

<div class="help-op-block">

**销售订单明细 · 收款核销页签**

**说明：** 在销售订单详情中双击某条订单明细，底部 **收款核销** 页签展示该明细相关的全部核销记录（与流水表同源）。

**注意：** 单条应收款全部核销，只表示该次出库对应应收已收清；销售明细上的「收款状态」按整行销售金额与累计已核销判断，一行订单可多次出库、产生多条应收。

</div>
