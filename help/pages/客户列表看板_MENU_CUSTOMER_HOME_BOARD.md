## 页面功能

- 在「客户列表」点击 **看板** 进入；再点 **列表** 返回表格。
- 客户集合与上方 **搜索栏当前筛选结果** 完全一致（含状态、等级、类型、行业、结算币、业务员、创建日、左栏快捷检索、仅收藏等）。
- 面板布局与「报表分析 → 销售分析 → 客户」相同；差别在于：**列表看板不限订单日期**，只在筛选出的客户内统计其全部已审核销售订单。
- 金额类数字受销售金额相关权限控制；无权限时占比改为按订单数统计，金额列可能不展示。

也可阅读：[客户](客户_MENU_CUSTOMER_HOME.md) · [销售分析 · 客户](销售分析_MENU_SALES_ANALYTICS.md#help-sales-customer)

## 共同口径

| 约定 | 说明 |
| --- | --- |
| 客户集合 | 当前搜索栏筛出的全部客户（不是当前页）。 |
| 订单集合 | 上述客户的 **全部已审核** 销售订单；**不按订单创建日再裁剪**。 |
| 列表「创建日」 | 只筛 **客户建档日**，不作为订单时间窗。 |
| 与报表区别 | 销售分析「客户」页签按公司/部门/个人 + **订单日期区间** 统计成单。 |

<h2 id="help-customer-board-kpi">客户概览</h2>

| 指标 | 口径说明 |
| --- | --- |
| 成单客户数 | 筛选客户中，至少有一张已审核销售订单的去重客户数。 |
| 复购客户数 | 上述成单客户中，已审核订单张数 ≥ 2 的客户数。 |

---

<h2 id="help-customer-board-breakdown">分解</h2>

在「有成单的筛选客户」上按维度看构成。有金额权限时按成单金额（美元）占比；无权限时按订单数占比。

| 面板 | 用途 |
| --- | --- |
| 客户类型 | 看 OEM / 贸易商等类型构成 |
| 客户等级 | 看等级构成 |
| 客户行业 | 看行业构成 |

---

<h2 id="help-customer-board-rankings">排行</h2>

取筛选客户内 Top10；点击行可进入销售订单列表（带客户条件，**不带订单日期**，便于看该客户全部订单）。

| 排行 | 口径说明 |
| --- | --- |
| 客户 Top10（成单金额） | 已审核订单金额合计最高的客户 |
| 客户 Top10（成单数） | 已审核订单张数最多的客户 |
| 客户 Top10（复购订单数） | 复购订单数 = 成单订单数 − 1（仅成单 ≥ 2 的客户） |
