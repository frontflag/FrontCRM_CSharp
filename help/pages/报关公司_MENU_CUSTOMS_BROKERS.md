# 报关公司

## 页面功能

- 维护本公司使用的 **报关代理公司**（关务服务商）主数据：编号、中英文名称、服务方向、代理费率等。
- 报关公司在 **报关装箱** 创建时必选，并写入 **报关单** 头信息，用于关务费用试算（代理费等）；**不是** 物料采购供应商，不会写入库存行的 `vendorId`。

---

## 在报关链路中的位置

| 顺序 | 本页 | 后续使用 |
|------|------|----------|
| **前置（建议）** | 新建并启用报关公司 | — |
| 装箱 | — | [装箱单](装箱单_MENU_PACKING_LIST.md) 创建 **报关出库** 类装箱单时 **选择报关公司** |
| 关务 | — | [报关单](报关单_MENU_CUSTOMS_DECLARATIONS.md) 头展示报关公司；费用试算引用 **代理费率** |

若尚无可用报关公司，须先在本页维护，否则无法保存报关装箱单。

---

## 字段说明

| 字段 | 说明 |
|------|------|
| 报关公司编号 | 系统自动生成（流水号 `CustomsBroker`，前缀 CBR），无需手工填写 |
| 公司中文名 | 必填 |
| 公司英文名 | 选填 |
| 服务方向 | 深圳 / 香港，标识代理服务地域 |
| 代理费率 | 必填，存 **1+纯费率**（如 `1.03` 表示 3%）；用于报关费用试算 |
| 状态 | 启用 / 停用；停用后新建装箱时通常不可选 |
| 备注 | 选填 |

---

## 操作说明

<div class="help-op-block">

**新建报关公司**

**说明：** 点击「新建报关公司」，填写中文名、服务方向、代理费率等后保存；编号由系统分配。

**前置条件：** 具备 **物流数据可写** 权限。

</div>

<div class="help-op-block">

**编辑（双击行）**

**说明：** 双击列表行打开编辑弹窗，可修改名称、服务方向、代理费率、备注等；编号不可改。

**前置条件：** 物流数据可写。

**注意：** 已关联报关单的报关公司，修改费率仅影响 **后续** 费用试算，不会自动重算历史已保存快照。

</div>

<div class="help-op-block">

**启用 / 停用**

**说明：** 操作列切换启用状态。停用后该代理公司不宜再用于新业务。

**前置条件：** 物流数据可写。

</div>

<div class="help-op-block">

**删除**

**说明：** 软删除报关公司，列表不再显示。

**前置条件：** 物流数据可写；若已被报关单引用，以系统校验为准（可能禁止删除）。

</div>

---

## 注意事项

1. **报关公司 ≠ 供应商：** 物料供应商仍在采购/库存维度维护；报关公司仅表示关务代理，详见报关单帮助中的业务口径。
2. **先维护再装箱：** 报关类装箱单保存前必须选择已启用的报关公司。
3. **代理费率格式：** 须 ≥ 1；`1.000000` 表示无额外代理费加成。
4. **权限：** 报关模块入口与写操作受关务/物流权限控制；无写权限时仅可查看列表。
