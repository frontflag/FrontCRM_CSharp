## 页面功能

- 在「报价列表」点击 **看板** 进入；再点 **列表** 返回表格。
- 顶部 Tag 为 **筛选**：与搜索栏结果一致（含状态等；**无**额外成单硬过滤）。
- 列表日期多为 **需求创建日**；**不展示**趋势。报表口径见 [采购分析 · 报价](采购分析_MENU_PURCHASE_ANALYTICS.md#help-purchase-quote)。
- 列表帮助：[报价列表](报价列表_MENU_QUOTE_LIST.md)

## 共同口径

| 约定 | 说明 |
| --- | --- |
| 统计集合 | 当前筛选下的报价及相关并联需求（方案与列表看板一致）。 |
| 状态筛选 | 若筛选了报价状态，主要影响报价侧指标；并联需求类指标仍按看板规则可见。 |
| 与报表区别 | 采购分析「报价」按公司/部门/个人 + **报价创建日**，含趋势。 |

<h2 id="help-quote-board-kpi">报价概览</h2>

| 指标 | 口径说明 |
| --- | --- |
| 提供报价的供应商数 | 筛选内有报价的去重供应商数。 |
| 有效报价条目数 | 有效报价条数（非查无类，以页面为准）。 |
| 查无报价条目数 | 查无报价相关条目数。 |
| 需求报价率 | 有报价的需求明细占比。 |
| 报价平均响应时间 | 需求到首条报价的平均分钟数。 |
| 报价平均数 | 平均每条需求明细的报价条数。 |
| 成单数 / 报价成单率 | 已转入成单链路的明细数及比率（分母规则以页面为准）。 |

---

<h2 id="help-quote-board-breakdown">分解</h2>

在当前筛选结果上按维度看构成。占比 = 该项数量 ÷ 同组合计 × 100%。

| 面板 | 用途 | 统计口径 |
| --- | --- | --- |
| 报价主状态 | 看报价单状态结构 | 按 **报价主单** 计条数，依状态分组（新建 / 成单 / 关闭等）。筛了状态时，本图会随筛选收缩。 |
| 报价分布 | 看关联需求的报价覆盖 | 按并联 **需求明细** 归入三档：**有报价** / **查无报价** / **采购未处理**（待处理且尚无报价）。状态筛选一般不裁剪这组需求分母。 |
| 涂标 | 看涂标策略占比 | 按 **报价主单**；取该报价 **首条报价行** 的涂标（不涂标 / 涂标 / 待确定）。 |
| 晶圆产地 | 看晶圆产地构成 | 按 **报价主单**；取首条报价行的晶圆产地（如美产 / 非美产 / 待确定）。 |
| 封装产地 | 看封装产地构成 | 按 **报价主单**；取首条报价行的封装产地。 |
| 包邮 | 看是否包邮 | 按 **报价主单**；取首条报价行是否包邮（是 / 否）。 |
| 品牌分布 | 看报价品牌集中度 | 按 **报价主单**；取首条报价行品牌；常见为前 20 品牌 +「其他」；未填显示「未设置」。 |
| 分配采购员 | 看需求侧分配负载 | 按并联 **需求明细** 计行数；两个分配采购员槽位合并；未分配显示「未分配采购员」。 |
| 报价采购员 | 看谁做了报价 | 按 **报价主单** 计条数，依报价单上的采购员分组。 |

<h2 id="help-quote-board-rankings">排行</h2>

取筛选结果内 Top10；供应商名可能按权限脱敏。

| 面板 | 用途 | 统计口径 |
| --- | --- | --- |
| 供应商 Top10（需求明细数） | 哪些供应商覆盖的需求最广 | 经报价行关联供应商，按去重 **需求明细** 数降序取前 10。 |
| 报价采购员 Top10（条目数） | 谁报价条数最多 | 按报价单采购员汇总 **报价主单条数**，降序取前 10。 |
| 报价采购员 Top10（报价率） | 谁覆盖分配需求更充分 | 报价率 = 该采购员报价条数 ÷ 其被分配到的需求明细数 × 100%（明细上两个分配槽各计 1）；按报价率降序取前 10。 |
| MPN Top10（报价条数） | 哪些型号报价最多 | 按报价上的物料型号汇总 **报价主单条数**，降序取前 10。 |
| MPN Top10（需求数量） | 哪些型号对应需求件数最多 | 按型号关联需求明细的 **需求数量** 汇总，降序取前 10。 |
| 品牌 Top10（报价条数） | 哪些品牌报价最多 | 按报价首条行品牌汇总 **报价主单条数**，降序取前 10。 |
| 品牌 Top10（需求数量） | 哪些品牌对应需求件数最多 | 按首条品牌关联需求明细的 **需求数量** 汇总，降序取前 10。 |
