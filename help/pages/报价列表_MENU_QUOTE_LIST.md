# 报价列表

## 页面功能

- 报价单查询、状态统计、分页。列表含供应商名称与**供应商等级**（S/A/B/C，取自供应商主数据当前等级）。
- 新建或编辑报价时，供应商旁可选择等级；保存报价会把新等级写到该供应商资料（与在供应商页改等级相同）。
- 搜索栏可切换 **看板 / 列表**：看板统计口径见 [报价列表 · 看板](报价列表看板_MENU_QUOTE_LIST_BOARD.md)。
- 操作列可 **复制** 报价摘要；悬停「复制」可再选 **带标题复制**（右侧不够时会改到左侧展开）。
- 若报价型号与需求原型号不一致，列表中型号会标红提示。

## 操作说明

<div class="help-op-block">

**供应商等级（新建/编辑报价）**

**说明：** 先选供应商，再选等级（S / A / B / C）。保存报价后，该供应商的等级一并更新；报价列表上的等级始终显示供应商当前档。选供应商时可在下拉中查看编码，并可展开右侧概况。

</div>

<div class="help-op-block">

**新建供应商联系人（新建/编辑报价）**

**说明：** 选好供应商后，可在右侧 **操作** 页签（或表单旁「+」）新建联系人；保存后会自动选中该联系人。未选供应商时入口不可用。

</div>

<div class="help-op-block">

**复制 / 带标题复制**

**说明：** 复制把报价摘要写入剪贴板；带标题复制会带上字段名。鼠标移到「复制」上可选带标题方式。

</div>

本页以通用列表操作为主（打开**编辑**、**删除**等；删除需二次确认）。
