## 页面功能

- 在「付款记录」列表点击 **看板** 进入；再点 **列表** 返回表格。
- 统计范围与上方搜索条件完全一致（全部匹配的付款单，不是当前页）。状态、付款方式、单号、采购订单、采购员、日期怎么筛，看板就怎么算。
- 顶部标签为 **筛选**：表示跟当前检索走，不会再偷偷只留「已付款」。若只要已付完的单，请自己在搜索栏或页签选「付款完成」。
- **付款金额** 是实际付给供应商的 **货款**，不含银行手续费、运费等费用。按原币分开看，**不折成美金**，也不把人民币和美元加在一起。还没付的明细金额为 0。
- 条数是 **付款单数**（一张付款单一计），不是明细行数。
- 无金额相关权限时，金额可能显示为「—」，饼图和排行改为按付款单数。

列表帮助：[付款记录](付款记录_MENU_FINANCE_PAYMENT.md)

## 共同口径

| 约定 | 说明 |
| --- | --- |
| 数据来源 | 付款记录每一张，与列表同一批结果。 |
| 付款金额 | 各明细已付货款合计，不含费用；按付款币别各自合计。列表「付款金额」列在含费用时可能略大。 |
| 日期 | 上方日期筛的是 **付款日期**。趋势也按付款日期。没有付款日的单仍计入概览和排行，但不进趋势图。 |
| 采购员 | 按付款明细对应采购订单上的采购员拆分。一张付款单可以拆到多名采购员。没填的归「未分配采购员」。 |
| 核销状态 | 整张单未核销 / 部分核销 / 核销完成。 |
| 供应商数 | 筛选结果里头表有供应商的去重家数。 |

<h2 id="help-fp-board-trend">趋势</h2>

| 趋势图 | 数据源 | 口径说明 |
| --- | --- | --- |
| 付款单数 | 付款记录 | 按付款日落入天 / 周 / 月，统计付款单张数。 |
| 付款金额 | 付款记录 | 同上时间轴，每个原币一张图。 |

日期分组以页面「按天 / 按周 / 按月」为准。

---

<h2 id="help-fp-board-breakdown">分解</h2>

| 图 | 数据源 | 口径说明 |
| --- | --- | --- |
| 核销状态 | 付款记录 | 按整张单的核销状态统计付款单数。 |
| 采购员 | 付款记录 | 按采购员、分原币汇总已付货款。无金额权限时按单数。 |

每块图同时显示数值和占比。

---

<h2 id="help-fp-board-rankings">排行</h2>

| 面板 | 数据源 | 口径说明 |
| --- | --- | --- |
| Top10 供应商 | 付款记录 | 每个原币各自按已付货款取前 10。 |
| Top10 采购员 | 付款记录 | 每个原币各自按已付货款取前 10。 |

有权限时，排行可在「付款金额」与「付款单数」之间切换。
