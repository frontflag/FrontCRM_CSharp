# 库存滚存

## 页面功能

- 按**自然月**滚动统计全公司采购入库与销售出库的**数量**与**金额（美元）**，展示上期结余、本期入/出与期末结余。
- **汇总页**：选择年份后固定显示 1～12 月共 12 行；单击选中月份，双击或点「明细」进入该月明细。
- **明细页**：按所选月份列出每条采购入库明细行的滚存指标，支持按物料型号、入库单号、入库日期筛选。
- 本报表为**只读**，不修改任何业务单据。
- 无采购/销售金额查看权限时，金额列显示为「—」；有权限时显示美元两位小数。

## 数据来源与计算说明

### 一、系统从哪些单据读取数据

| 业务对象 | 用途 | 读取方式概要 |
|----------|------|----------------|
| **采购入库单** | 本期/历史上入库数量与时间 | 仅统计**采购入库**类型、且状态为**已过账**的单据；入库时间取单头「入库日期」 |
| **采购入库明细行** | 统计粒度（一行一物料） | 每条明细行的数量为入库数量 |
| **库存层记录** | 美元采购单价 | 与入库明细行关联的层记录上的「美元采购价」，用于计算入库金额 |
| **销售出库单** | 出库时间与归属 | 仅统计**销售出库**（含历史销售类型）、且状态为**已出库**或**已完成**的单据；出库时间取出库日期，为空时取出库单创建时间 |
| **出库明细及扩展信息** | 出库数量、关联哪笔入库 | 通过扩展信息中的「关联入库明细」把出库数量归集到对应入库行；美元单价优先取出库扩展上的采购美元价，为 0 时回查库存层上的美元采购价 |

已删除的单据与明细不参与统计。移库、报关、退货、报废等入库类型，以及移库类虚拟出库，均**不计入**本报表。

月份按**业务自然月**（默认东八区）划分：例如 2026-03 表示 3 月 1 日 0 点至 4 月 1 日 0 点（不含）之间的入出库。

### 二、汇总页（按年 12 行）各列含义

| 列名 | 数据从哪来 | 如何计算 |
|------|------------|----------|
| **年月** | 所选年份 | 固定生成 1～12 月；未到月份各指标为 0 |
| **上期数量** | 入库明细 + 出库明细 | 1 月：该年 1 月 1 日之前累计入库数量 − 累计出库数量；2～12 月：等于**上月结余数量** |
| **入库数量** | 采购入库明细 | 该自然月内过账的采购入库数量合计 |
| **出库数量** | 销售出库明细 | 该自然月内、已关联入库明细的销售出库数量合计 |
| **结余数量** | 由上三项滚动 | 上期数量 + 入库数量 − 出库数量 |
| **上期金额(USD)** | 同上（金额侧） | 1 月：该年 1 月 1 日之前累计入库美元金额 − 累计出库美元金额；2～12 月：等于**上月结余金额** |
| **本期入库(USD)** | 入库明细 × 美元采购价 | 该月每条入库：数量 × 库存层美元采购价，再求和 |
| **本期出库(USD)** | 出库明细 × 美元单价 | 该月每条出库：数量 × 对应美元单价（规则见上），再求和 |
| **结余金额(USD)** | 由上三项滚动 | 上期金额 + 本期入库 − 本期出库 |

系统一次性加载符合范围的入出库流水，在服务端按自然月切分后逐月滚动计算，固定返回 12 行（不分页）。

### 三、明细页（按月 + 分页）各列含义

明细以**采购入库明细行**为主体：默认列出**所选月份内过账**的入库行；筛选条件允许按入库单号、入库日期等缩小范围。

| 列名 | 数据从哪来 | 如何计算 |
|------|------------|----------|
| **入库单号** | 采购入库单表头 | 显示入库单编号；有权限时可点击进入入库单详情 |
| **物料型号** | 入库明细行 | 优先取明细行上的采购型号，否则取库存层上的型号 |
| **入库时间** | 采购入库单表头 | 入库日期 |
| **入库数量** | 入库明细行 | 等于该明细行数量（仅统计落在所选自然月内的过账入库） |
| **出库数量** | 关联的销售出库 | 所选自然月内、通过扩展信息关联到**本入库明细行**的出库数量合计 |
| **上期数量** | 关联出库（历史） | 0 −（本月之前已关联到本行的出库数量合计）；新入库行期初入库视为 0 |
| **结余数量** | 行内滚动 | 上期数量 + 入库数量 − 出库数量 |
| **上期 / 本期入库 / 本期出库 / 结余金额(USD)** | 数量 × 美元单价 | 与汇总相同口径，在单行维度计算；无金额权限时显示「—」 |

## 统计范围与过滤规则（摘要）

- **入库**：采购入库、已过账、未删除。
- **出库**：销售出库（含历史销售类型）、已出库或已完成、未删除；须能关联到具体入库明细行。
- **范围**：公司全量，不按部门或个人过滤。
- **权限**：须具备「库存滚存」查看权限（财务 → 库存报表）；另受财务数据可见范围约束。

## 金额列 (USD) 说明

表头带 **(USD)** 的四列金额（上期金额、本期入库、本期出库、结余金额）均为**折算后的美元金额**，不是把原币（如人民币）在报表查询时再临时换算，而是使用业务过账时已写入的**美元采购单价**计算。

### 折算发生在何时

| 环节 | 说明 |
|------|------|
| **采购入库过账** | 系统按过账时**财务基准汇率**，将采购原币单价折算为美元，写入库存层上的「美元采购价」 |
| **销售出库** | 优先使用出库扩展上记录的美元采购价（通常来自对应入库库存层）；若为空或为 0，则回查该入库行的库存层美元采购价 |
| **本报表查询** | 直接读取上述已折算的美元单价，**不在报表里重新换汇** |

因此，USD 金额反映的是**入库/出库过账当时**的折算结果；与旧系统「折算美金单价」口径一致，便于跨月、跨年汇总对比。

### 四列金额如何计算

| 列名 | 含义 |
|------|------|
| **上期金额(USD)** | 本月初之前的滚存结余（累计入库美元金额 − 累计出库美元金额）；汇总页 2～12 月等于上月结余金额 |
| **本期入库(USD)** | 本月采购入库：**入库数量 × 库存层美元采购价**，再合计 |
| **本期出库(USD)** | 本月销售出库：**出库数量 × 对应美元采购价**，再合计 |
| **结余金额(USD)** | 上期金额 + 本期入库 − 本期出库 |

明细页中「上期 / 本期入库 / 本期出库 / 结余」金额列与上表**同一口径**，只是在单条入库明细行上计算。

### 显示与权限

- 金额统一为**美元**，保留**两位小数**。
- 若账号无采购金额、销售金额、付款或收款等相关查看权限，金额列脱敏显示为「**—**」，数量列仍正常显示。
