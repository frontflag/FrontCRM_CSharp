# 采购订单明细

## 页面功能

- 采购单行：状态含新建/待审核/已确认/已付款/已入库等；通知到货与请款。
- 在采购订单详情页单击或双击某条明细，可在底部面板查看 **概况** 矩阵（付款～进项发票各环节进度汇总）。
- 打开右侧辅助栏并切到 **「操作」** 后，单击某行可查看摘要并发起到货通知或申请付款（无需进入详情）。
- 切到 **「流程」** 后，单击某行可查看该明细从采购申请到付款、到货、质检、入库、进项发票的业务链路时间轴（只读）。
- 搜索栏可切换 **看板 / 列表**：看板统计口径见 [采购订单明细 · 看板](采购订单明细看板_MENU_PURCHASE_ORDER_ITEMS_BOARD.md)。

##操作提醒
需要供应商确认采购单后，等待状态变更为"已确认"后，才可申请付款。

## 操作说明

<div class="help-op-block">

**采购订单详情 · 概况页签**

**说明：** 从本列表进入某张采购订单详情后，在「订单明细」页签 **单击或双击** 某行，底部「采购订单明细详情」面板默认打开 **概况**。矩阵展示该行的 **总数 / 已执行 / 待处理**：付款、到货通知、入库、进项发票。

**列标题颜色：** 灰=未开始，黄=进行中，绿=已完成，红=异常。仅标题文字变色。

**数值颜色：** 格子里的数字为 0（含 `0.00` 及币别）或空值「—」时显示浅灰色；有数量或金额时保持原来的颜色。

**注意：** 概况为汇总快照；付款单、到货通知等明细见同面板其他 Tab。亦可在 [采购订单](采购订单_MENU_PURCHASE_ORDERS.md) 帮助页查看同类说明。

</div>

<div class="help-op-block">

**列表 · 右侧「操作」面板**

**说明：** 请先打开右侧辅助栏并切到 **「操作」**，再 **单击** 某行，可查看订单明细、到货通知、申请付款三张卡片。若停在「帮助」等页签，单击会先选中该行，再点「操作」后加载内容。右侧栏收起时单击不会打开操作面板。**双击** 行仍进入采购订单详情。

**到货通知：** 展示已通知/可通知数量与进度；行状态为 **已确认** 时可点击「通知到货」（与列表操作列一致）。

**申请付款：** 展示已申请/可申请金额（含币别）与进度；显示可申请付款时可点击「申请付款」。

**已完成：** 对应环节完成后显示绿色「已完成」，并隐藏操作按钮。

</div>

<div class="help-op-block">

**列表 · 右侧「流程」面板**

**说明：** 请先打开右侧辅助栏并切到 **「流程」**，再 **单击** 某行，可按时间节点查看：采购申请、采购订单明细、申请付款、付款、到货通知、质检、入库、进项发票。各节点显示单号、状态、日期、供应商与采购员等信息；**入库**节点单号单独一行，下一行左侧为入库类型、右侧为状态。尚未发生的环节显示为「未开始」。本页签仅供查看，不含操作按钮。若停在「帮助」等页签，单击会先选中该行，再点「流程」后加载内容。

</div>

<div class="help-op-block">

**导出**

**说明：** 按当前页面上的筛选条件，把采购订单明细下载为表格文件（Excel 可直接打开）。看板和列表视图都可以导出，导出的是明细行，不是看板统计图。

**怎么用：**

1. 先设好日期、单号、进度或左侧快捷检索等条件，再点页面右上角的 **「导出」**。
2. 确认后开始下载。一次最多约 5 万行；超出部分不会写入本文件，可收窄条件后再导。
3. 导出的是**当前筛选下的全部行**，不是勾选篮子里的行。金额列仅在您有权查看金额时有数。
4. 系统「导出日志」可查到本次导出及当时的筛选条件。

</div>

<div class="help-op-block">

**通知到货**

**说明：** 打开新建到货通知弹窗。

**前置条件：** 行状态为**「已确认」**；账号具备采购订单读权限。

</div>

<div class="help-op-block">

**申请付款**

**说明：** 打开请款弹窗。

**前置条件：** 页面显示可申请付款。

</div>

### 列权限

| 列 | 权限 |
|----|------|
| 供应商 | 供应商信息读 |
| 采购员 | 采购员信息读 或 采购订单读 |
| 金额 | 采购金额读 |
