# 采购订单明细

## 页面功能

- 采购单行：状态含新建/待审核/已确认/已付款/已入库等；通知到货与请款。
- 在采购订单详情页（`/purchase-orders/:id`）单击或双击某条明细，可在底部面板查看 **概况** 矩阵（付款～进项发票各环节进度汇总）。
- 在本列表页单击某行，可在右侧辅助栏 **「操作」** 页签查看该行摘要，并发起到货通知或申请付款（无需进入详情）。

##操作提醒
需要供应商确认采购单后，等待状态变更为"已确认"后，才可申请付款。

## 操作说明

<div class="help-op-block">

**采购订单详情 · 概况页签**

**说明：** 从本列表进入某张采购订单详情后，在「订单明细」页签 **单击或双击** 某行，底部「采购订单明细详情」面板默认打开 **概况**。矩阵展示该行的 **总数 / 已执行 / 待处理**：付款、到货通知、入库、进项发票。

**列标题颜色：** 灰=未开始，黄=进行中，绿=已完成，红=异常。仅标题文字变色。

**注意：** 概况为汇总快照；付款单、到货通知等明细见同面板其他 Tab。亦可在 [采购订单](采购订单_MENU_PURCHASE_ORDERS.md) 帮助页查看同类说明。

**技术说明：** [采购订单明细概况-设计与实现](../document/System/采购订单明细概况-设计与实现.md)

</div>

<div class="help-op-block">

**列表 · 右侧「操作」面板**

**说明：** 在采购订单明细列表中 **单击** 某行，右侧辅助栏切换至 **「操作」** 页签，展示三张卡片：订单明细、到货通知、申请付款。双击行仍进入采购订单详情。

**到货通知：** 展示已通知/可通知数量与进度；行状态为 **已确认** 时可点击「通知到货」（与列表操作列一致）。

**申请付款：** 展示已申请/可申请金额（含币别）与进度；`canApplyPayment=true` 时可点击「申请付款」。

**已完成：** 对应环节完成后显示绿色「已完成」，并隐藏操作按钮。

**技术说明：** [采购订单明细列表-操作面板-设计与实现](../document/System/采购订单明细列表-操作面板-设计与实现.md)

</div>

<div class="help-op-block">

**通知到货**

**说明：** 打开新建到货通知弹窗。

**前置条件：** 行状态为**「已确认」**（与原 `itemStatus=已确认(30)` 一致）；账号具备 `purchase-order.read`。

</div>

<div class="help-op-block">

**申请付款**

**说明：** 打开请款弹窗。

**前置条件：** 行上 **`canApplyPayment=true`**（与列表/接口字段一致）。

</div>

### 列权限

| 列 | 权限 |
|----|------|
| 供应商 | `vendor.info.read` |
| 采购员 | `purchase.user.read` 或 `purchase-order.read` |
| 金额 | `purchase.amount.read` |
