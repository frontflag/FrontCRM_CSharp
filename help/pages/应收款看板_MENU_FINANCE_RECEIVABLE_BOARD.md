## 页面功能

- 在「应收款」列表点击 **看板** 进入；再点 **列表** 返回表格。
- 统计范围与当前搜索条件一致（含「仅待核销」等）。
- 金额按查询日财务汇率 **折算美金** 展示，并可看原币分档。
- 列表帮助：[应收款](应收款_MENU_FINANCE_RECEIVABLE.md)
- 域级票款总览见 [财务分析](财务分析_MENU_FINANCE_ANALYTICS.md)

## 共同口径

| 约定 | 说明 |
| --- | --- |
| 数据来源 | 财务应收台账（出库后形成的应收），不是销售订单「未收款」扩展字段的全部口径。 |
| 金额模式 | 分布/排行可在 **待核销** 与 **总额** 间切换；账期分布一般按待核销。 |
| 与财务分析 | 财务分析「应收」待办是当前余额总览；本看板跟列表筛选并可看趋势与排行。 |

---

<h2 id="help-recv-board-kpi">应收指标</h2>

| 指标 | 口径说明 |
| --- | --- |
| 应收款客户数 | 筛选结果涉及的去重客户数。 |
| 出库记录条目数 | 筛选结果中的应收/出库条目数。 |
| 待核销折算美金 | 待核销金额折算美元合计。 |
| 应收总额折算美金 | 应收总额（含已核销部分）折算美元合计。 |
| 最长账龄（天） | 筛选结果中账龄最大值。 |

---

<h2 id="help-recv-board-trend">趋势</h2>

应收客户数、出库记录条目、待核销金额、应收总额随时间变化（可按日/周/月；日期轴规则以页面为准）。

---

<h2 id="help-recv-board-breakdown">分解</h2>

在当前筛选结果上按维度看构成。分布金额模式可切 **待核销 / 总额**；**账期** 一般固定按待核销。

| 面板 | 用途 | 统计口径 |
| --- | --- | --- |
| 核销状态 | 看核销进度结构 | 按未核销 / 部分核销 / 已核销分组，计条目数或对应金额（待核销或总额模式）。 |
| 币别 | 看原币结构 | 按应收原币别汇总金额（或条目数）。 |
| 账期 | 看账龄桶 | 按待核销余额落入账龄桶（如 0–10 天、10–30 天、30–60 天、60–90 天、90 天–半年、更长），计金额或条目。 |
| 业务员 | 看业务员应收构成 | 按业务员汇总金额（待核销或总额模式）或条目数。 |

---

<h2 id="help-recv-board-rankings">排行</h2>

筛选结果内 Top10；排行金额可切 **待核销 / 总额**（单笔应收榜固定按总额）。

| 面板 | 用途 | 统计口径 |
| --- | --- | --- |
| Top10 单笔应收（总额） | 单笔金额最大的应收 | 按单笔应收 **总额** 降序前 10，可带核销状态。 |
| Top10 客户 | 客户应收集中度 | 按客户汇总金额（待核销或总额模式），降序前 10。 |
| Top10 业务员 | 业务员应收集中度 | 按业务员汇总金额（待核销或总额模式），降序前 10。 |

---
