## 页面功能

- 在「应收款」列表点击 **看板** 进入；再点 **列表** 返回表格。
- 统计范围与当前搜索条件一致（含「仅待核销」等）。
- 金额按查询日财务汇率 **折算美金** 展示，并可看原币分档；分档金额后的币别字母用系统标准颜色区分，分档上方的币别名称保持灰色。
- 列表帮助：[应收款](应收款_MENU_FINANCE_RECEIVABLE.md)
- 域级票款总览见 [财务分析](财务分析_MENU_FINANCE_ANALYTICS.md)

## 共同口径

| 约定 | 说明 |
| --- | --- |
| 数据来源 | 财务应收台账（出库后形成的应收），不是销售订单「未收款」扩展字段的全部口径。 |
| 金额模式 | 分布/排行可在 **待核销** 与 **总额** 间切换；账期分布一般按待核销。 |
| 与财务分析 | 财务分析「应收」待办是当前余额总览；本看板跟列表筛选并可看趋势与排行。 |
| 数据源列 | 下文含「口径说明」的表格均附 **数据源**，表示统计对象对应的业务列表（便于对账）。本看板与列表共用当前搜索条件。 |

<h2 id="help-recv-board-kpi">应收指标</h2>

| 指标 | 数据源 | 口径说明 |
| --- | --- | --- |
| 应收款客户数 | 应收款 | 筛选结果涉及的去重客户数。 |
| 出库记录条目数 | 应收款 | 筛选结果中的应收/出库条目数。 |
| 出库应收款 | 应收款 | 筛选结果中应收 **总额** 折算美金并按原币分档。**勾选「仅待核销」**：只含尚未 100% 核销的行（总额含行上已核销部分）。**取消勾选**：含已核销完成行，汇总全部应收总额。与「待核销应收款」的差额为当前行集已核销金额。 |
| 待核销应收款 | 应收款 | 与「出库应收款」同一批应收行上统计待核销余额（总额扣除已核销），折算美金并按原币分档。是对尚未 100% 核销的出库应收金额的待核销余额合计。无论是否勾选「仅待核销」，本卡数值不变化（已核销完成行余额为 0）。 |
| 最长账龄（天） | 应收款 | 筛选结果中账龄最大值。 |

<h2 id="help-recv-board-trend">趋势</h2>

| 趋势图 | 数据源 | 口径说明 |
| --- | --- | --- |
| 应收客户数趋势 | 应收款 | 按出库日（空则按创建日）落入日/周/月，统计去重客户数。 |
| 出库记录条目趋势 | 应收款 | 同上时间轴，统计应收/出库条目数。 |
| 待核销金额趋势 | 应收款 | 同上时间轴，待核销金额折算美元合计。 |
| 应收总额趋势 | 应收款 | 同上时间轴，应收总额折算美元合计。 |

日期轴与分组（日/周/月）以页面控件为准。

<h2 id="help-recv-board-breakdown">分解</h2>

在当前筛选结果上按维度看构成。分布金额模式可切 **待核销 / 总额**；**账期** 一般固定按待核销。

| 面板 | 数据源 | 口径说明 |
| --- | --- | --- |
| 核销状态 | 应收款 | 按未核销 / 部分核销 / 已核销分组，计条目数或对应金额（待核销或总额模式）。 |
| 币别 | 应收款 | 按应收原币别汇总金额（或条目数）。 |
| 账期 | 应收款 | 按待核销余额落入账龄桶（如 0–10 天、10–30 天、30–60 天、60–90 天、90 天–半年、更长），计金额或条目。 |
| 业务员 | 应收款 | 按业务员汇总金额（待核销或总额模式）或条目数。 |

---

<h2 id="help-recv-board-rankings">排行</h2>

筛选结果内 Top10；排行金额可切 **待核销 / 总额**（单笔应收榜固定按总额）。

| 面板 | 数据源 | 口径说明 |
| --- | --- | --- |
| Top10 单笔应收（总额） | 应收款 | 按单笔应收 **总额** 降序前 10，可带核销状态。 |
| Top10 客户 | 应收款 | 按客户汇总金额（待核销或总额模式），降序前 10。 |
| Top10 业务员 | 应收款 | 按业务员汇总金额（待核销或总额模式），降序前 10。 |
