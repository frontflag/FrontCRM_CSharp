# 用户等级

## 页面功能

- 为每位员工设置 1～20 的等级，新员工默认为 1。
- 各人等级单独维护，互不影响。
- 改等级时会记下开始日期，并留下变更记录（当时的账号、旧等级、新等级、备注、操作人）。

## 操作说明

<div class="help-op-block">

**查询**

**说明：** 可按用户名称、账号、部门、等级筛选；点「搜索」或回车查询，点「重置」清空条件。部门、等级下拉变更即查。

</div>

<div class="help-op-block">

**设置等级**

**说明：** 在操作列选择「设置等级」，修改等级和备注。等级变化时写入变更记录；只改备注不记一次改级。从未改过等级的人，变更日期显示为「—」。

**前置条件：** 需要有维护员工的权限。

</div>

<div class="help-op-block">

**变更日志**

**说明：** 展开右侧栏「变更日志」页签后单击一行，可查看该员工当前信息和历次等级变更。每次变更会显示当时的用户名称与账号、变更日期与操作人、旧等级 → 新等级；有备注时显示在变更等级下面。

</div>
