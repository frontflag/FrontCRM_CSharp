## 页面功能

- 从「报表分析 → 财务分析」进入，按您可见的财务或销/采归属范围查看票款类汇总。
- 上方可切换 **公司 / 部门 / 个人** 视角（部分账号仅按销/采归属查看，可能无「公司」），并设置 **截至**、**区间起**、趋势粒度等。
- 金额主数字一般为 **折算美元**，并可展开 **原币分档**；无相关金额读权限时可能显示为「—」。
- 部分数字可点击跳转到付款、收款、发票等列表（须具备目标列表权限）。

## 共同口径（请先读）

| 约定 | 说明 |
| --- | --- |
| 待办 | 当前尚未结清的余额（应付、应收、待开票等）。页面可能标注「截至所选日期」，实际多为 **查询时刻余额**，改「截至」通常 **不会** 改变待办数字。 |
| 已完成 | 在 **区间起～截至** 这段时间内实际发生的付款、收款、已开发票等；改「截至」或「区间起」会影响已完成与趋势。 |
| 区间止 | 页面若另有「区间止」控件，可能只影响下钻列表日期，**不一定**改变本页 KPI 与趋势（以实际刷新结果为准）。 |
| 美元折算 | 按查询时财务参数汇率等规则折成美元展示；不同单据的原币可能不同。 |
| 与销售/采购看板差异 | 本页「应收」取自财务应收台账（多为已出库后的待核销余额）；销售分析待办应收可能含订单上尚未出库部分的未收款，二者可以不一致。已付/已收以付款单、收款单为准，不是订单扩展上的累计已付/已收字段。 |
| 数据源列 | 下文含「口径说明」的表格均附 **数据源**，表示统计对象对应的业务列表（便于对账）。分析页另有视角与日期条件，与列表默认打开结果不必完全相同。 |

<h2 id="help-finance-todo">待办</h2>

当前未结清余额（主数字多为折算美元，并可看原币分项）。

| 指标 | 数据源 | 口径说明 |
| --- | --- | --- |
| 应付款 | 付款记录 | 有效采购订单明细上尚未付清的金额合计（与采购分析待办应付同源一类字段）。 |
| 应收款 | 应收款 | 财务应收台账上的待核销余额（通常对应已出库后形成的应收）。**不是**销售分析里「订单未收款」的全部口径。 |
| 待开进项发票 | 进项发票 | 采购明细上尚未开完的进项票金额合计。 |
| 待开销项发票 | 销项发票 | 销售明细上尚未开完的销项票金额合计。 |

---

<h2 id="help-finance-completed">已完成</h2>

统计窗口：**区间起～截至**（不是「区间止」）。

| 指标 | 数据源 | 口径说明 |
| --- | --- | --- |
| 已付款 | 付款记录 | 区间内、状态为付款完成的付款单金额合计（按付款日落入区间），再折算美元。 |
| 已收款 | 收款记录 | 区间内、状态为已收款的收款单金额合计（按收款日落入区间），再折算美元。 |
| 已开进项发票 | 进项发票 | 区间内开具的进项发票金额合计（按发票日），再折算美元。 |
| 已开销项发票 | 销项发票 | 区间内开具的销项发票金额合计（按开票日），再折算美元。 |

**注意：** 已付款 / 已收款看的是财务付款单、收款单，不是采购/销售订单上「已付款/已收款」累计字段按订单创建日汇总。

<h2 id="help-finance-trend">趋势</h2>

| 趋势图 | 数据源 | 口径说明 |
| --- | --- | --- |
| 已付款趋势 | 付款记录 | 与「已完成 → 已付款」同口径，按日 / 周 / 月落桶后的美元折算合计。 |
| 已收款趋势 | 收款记录 | 与「已完成 → 已收款」同口径，按收款日归入各时段。 |

待办类指标一般不在趋势区按期展示。

---

<h2 id="help-finance-currency">原币构成</h2>

对待办四项（应付款 / 应收款 / 待开进项 / 待开销项）分别查看各原币金额占比（饼图）。扇区金额为该待办指标下的 **原币合计**，不是美元。可切换下拉选择看哪一项待办的币别构成。数据源与对应待办指标相同（付款记录 / 应收款 / 进项发票 / 销项发票）。

## 使用提示

<div class="help-op-block">

**先分清「还欠着」和「这段时间发生了」**

**说明：** 待办是当前余额；已完成与趋势是区间内发生额。改「截至」应主要影响已完成与趋势，待办通常不变。

</div>

<div class="help-op-block">

**应收不要和销售看板直接对总数**

**说明：** 财务分析应收来自应收台账；销售分析待办应收来自订单未收款。覆盖范围不同，数字不一致是预期现象。

</div>

<div class="help-op-block">

**金额单位**

**说明：** 卡片主数字多为折算美元；下方或展开可见原币分档。对比时留意页面上的「折算 USD / 原币」提示。

</div>
