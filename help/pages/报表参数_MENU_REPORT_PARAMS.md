# 报表参数

## 页面功能

- 在参数管理中维护全站报表样式版本（V1 / V2）。
- 左栏进入「报表全局参数」，右栏选择版本后保存。
- 保存后，**采购订单打印**和 **装箱单打印**（竖版与横版）在 Semicore 站点会按所选版本换版式；改完后需要重新打开打印页才会看到新版式。
- 其他站点的采购订单和装箱单，即使选了 V2，仍是原来的样式。
- 销售订单、发票的打印版式**不受此项影响**。抬头、印章仍按公司信息。
- 未设置时按 **V1**（与现在线上采购订单样式一致）。
- 仅有查看权限时可看当前值，不能改、不能保存。

## 操作说明

<div class="help-op-block">

**选择报表样式版本**

**说明：** 在下拉中选择 V1 或 V2。

</div>

<div class="help-op-block">

**保存**

**说明：** 将所选版本写入系统参数。保存成功后刷新页面仍保持该选择。

**前置条件：** 具备报表参数维护权限。

</div>

<div class="help-op-block">

**刷新**

**说明：** 重新读取已保存的版本，丢弃未保存的改动。

</div>
