# 业务预计提成

## 页面功能

- 查看尚未锁定的业务员预计提成。
- 所有在职业务员都会列出；还没有参与行时，预计提成为 0。
- 已离职人员只有预计提成大于 0 时才出现。
- 出库完成、销售明细收款核销完成后，按出库时间和收款时间判断是否进入本期。
- 金额按自然月分别计算：该月毛利达到该业务员当月等级的第一档门槛后，才发该月的提成。各月互不影响。
- 毛利为负时按 0 参与计算，列表仍显示原来的毛利。
- 改档或改生效版本后，次日重算才会变；本页不能改金额。

## 操作说明

- 双击人员进入该业务员的各月列表，再双击月份查看该月出库行。
- 月份页显示是否达标、本月毛利、点数和提成。
- 明细页列出该月已参与计算的出库行；有库存权限时可打开出库单。
- 管理员可点「立即重算」，按当天规则覆盖未锁定结果。
