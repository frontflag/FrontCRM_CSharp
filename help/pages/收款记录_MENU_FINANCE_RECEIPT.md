# 收款记录

## 页面功能

- 登记客户来款。保存后为 **新建**；点 **确认** 后来款生效，才能做收款核销。
- 状态为 **新建 / 确认 / 取消**。可按状态、收款用途（普通 / 预收）、核销状态（未核销 / 部分核销 / 核销完成）、单号或客户、日期筛选。
- 搜索栏齿轮可开启 **页签模式**，把状态、收款用途或核销状态改成表格上方页签，点一下即筛选。
- 标题行右侧 **收款核销桌面** 可连续按客户做核销。
- 可按当前筛选 **导出** 收款记录（CSV，单次最多约 5 万条）。

## 操作说明

<div class="help-op-block">

**查询 / 页签模式**

**说明：** 按状态、收款用途、核销状态、关键词、日期筛选。齿轮 → **页签模式** 可将状态（新建 / 确认 / 取消）、收款用途或核销状态改为页签切换。列表「核销状态」按整张收款单汇总：全部明细未核销（或暂无明细）为「未核销」；全部核销完成为「核销完成」；其余为「部分核销」。

</div>

<div class="help-op-block">

**新建收款单**

**说明：** 点标题行右侧「新建」，填写客户、金额、币别、收款方式等后保存。保存成功后单据为 **新建**，此时还不能核销。请接着对这张单做 **确认**。勾选「预收款」或「货代付款」的，也要先确认才会进入预收或货代付款台账。

**前置条件：** 账号具备收款维护权限。

</div>

<div class="help-op-block">

**确认**

**说明：**

1. 在列表中找到状态为 **新建** 的收款单。
2. 在该行操作列点 **确认**。若操作列已收起，先点 **...** 再选「确认」。打开该单详情时，标题右侧也有「确认」。
3. 弹出框会带出收款单号，核对无误后点确定。
4. 成功后状态变为 **确认**。此后可做收款核销；预收款会进入客户预收；货代付款会进入货代付款台账。确认后不能再改单据内容，也不能改回「新建」。

看不到「确认」时：单据已经是「确认」或「取消」，或当前账号没有收款维护权限。

**前置条件：** 状态为「新建」，且账号具备收款维护权限。

</div>

<div class="help-op-block">

**取消**

**说明：** 作废这张收款单。新建可直接取消。已确认但还没核销的，也可以取消。已经核销过的，须先 **反核销** 再取消。预收已被用掉、或货代已经登记过付款的，不能取消。

**前置条件：** 状态为「新建」；或状态为「确认」且尚未核销。

</div>

<div class="help-op-block">

**收款核销桌面**

**说明：** 点标题行右侧「收款核销桌面」，按客户连续核销已确认的来款与应收。详见 [收款核销](收款核销_MENU_FINANCE_RECEIPT_WRITE_OFF.md)。

**前置条件：** 来款须已 **确认**。

</div>

<div class="help-op-block">

**导出**

**说明：** 按当前列表筛选条件导出为 CSV，文件名带导出时间。状态、核销状态、用途、收款方式为中文名称；客户拆成中文/英文两列；收款金额后跟币别。

**前置条件：** 导出进行中按钮暂不可用。单次最多约 5 万条，超出部分会在提示中说明。

</div>

<div class="help-op-block">

**反核销**

**说明：** 撤销本单已做的收款核销（单据仍为「确认」）。按提示输入收款单号确认。有预收入账时须先处理预收，才能反核销。

**前置条件：** 状态为「确认」，且账号具备收款维护权限。

</div>
