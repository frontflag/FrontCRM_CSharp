# 收款记录

## 页面功能

- 收款单维护与审核。
- 可按状态、收款用途（普通 / 预收）、**核销状态**（未核销 / 部分核销 / 核销完成）、单号/客户、日期筛选；列表「核销状态」列为整单汇总（与详情明细标签同一套取值）。
- 搜索栏齿轮可开启 **页签模式**，将状态、收款用途或核销状态改为表格上方页签后点击即筛选。
- 右上角 **进入收款核销** 打开核销桌面（连续按客户作业）；**收款核销** 打开原三栏核销页。

## 操作说明

<div class="help-op-block">

**查询 / 页签模式**

**说明：** 按状态、收款用途、核销状态、关键词、日期筛选。齿轮 → **页签模式** 可将状态（含已取消）、收款用途或核销状态改为页签切换。核销状态按整张收款单汇总：全部明细未核销（或暂无明细）为「未核销」；全部核销完成为「核销完成」；其余为「部分核销」。

</div>

<div class="help-op-block">

**提交审核**

**说明：** 将收款单提交至审核流程。

**前置条件：** 仅当单据处于**草稿 / 待提交审核**阶段（与列表「状态」列一致，可）时可用。

</div>

<div class="help-op-block">

**审核通过**

**说明：** 在审核节点通过该收款单。

**前置条件：** 仅当处于**待审核**阶段时可用。

</div>

<div class="help-op-block">

**取消**

**说明：** 终止或撤回当前流程节点。

**前置条件：** **草稿**或**待审核**阶段可取消。

</div>
