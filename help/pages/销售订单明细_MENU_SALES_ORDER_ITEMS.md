# 销售订单明细

## 页面功能

- 按行透视销售订单；发起采购申请、跳转申请出库。
- 列表可查看 **销售员**、**采购员**（来自该行关联的有效采购订单）；支持按采购员筛选。
- 在销售订单详情页双击某条明细，可在底部面板查看 **概况** 矩阵（采购～收款各环节进度汇总）。

## 列表列说明

<div class="help-op-block">

**销售员**

**说明：** 显示该销售订单主表上的销售员名称。

</div>

<div class="help-op-block">

**采购员**

**说明：** 显示该行关联的**有效采购订单**上的采购员**登录账号**。若一张销售明细对应多张采购订单且采购员不同，以逗号分隔展示（同一人只显示一次）。尚未生成采购订单时显示 **—**。

**注意：** 仅统计未取消的采购订单；已取消的采购单及其采购员不会出现在本列。

</div>

## 操作说明

<div class="help-op-block">

**列表右侧 · 操作面板**

**说明：** 在本列表 **单击** 某行，右侧辅助栏打开 **「操作」** 页签，展示该行的订单摘要、备货库存（有库存时）、采购申请与出库通知进度，并可直接 **申请采购** / **申请出库**。**双击** 行仍进入销售订单详情。

**右栏收起时：** 单击仅记住选中行，展开右栏后再加载库存等明细数据。

</div>

<div class="help-op-block">

**销售订单详情 · 概况页签**

**说明：** 从本列表进入某张销售订单详情后，在「订单明细」页签 **单击或双击** 某行，底部「销售订单明细详情」面板默认打开 **概况**。矩阵展示该行的 **总数 / 已执行 / 待处理**：采购申请、采购订单、入库、出库申请、出库、收款核销、发票。

**列标题颜色：** 灰=未开始，黄=进行中，绿=已完成，红=异常（如采购申请超量）。仅标题文字变色。

**注意：** 概况为汇总快照；核销流水、采购申请等明细见同面板其他 Tab。亦可在 [销售订单](销售订单_MENU_SALES_ORDERS.md) 帮助页查看同类说明。

</div>

<div class="help-op-block">

**批量申请采购**

**说明：** 对勾选行发起采购申请；多选时若产品提示改为逐条处理，以弹窗为准。

**前置条件：** 已勾选行；所选行对应的**销售订单主表**须已为「审核通过」「进行中」或「完成」状态。另需具备采购申请维护权限。

</div>

<div class="help-op-block">

**申请采购**

**说明：** 弹窗创建采购申请。

**前置条件：** 对应**销售订单主表**须已为「审核通过」「进行中」或「完成」状态；另需具备采购申请维护权限。

</div>

<div class="help-op-block">

**申请出库**

**说明：** 跳转销售订单详情并发起出库申请。

**前置条件：** 对应**销售订单主表**须已为「审核通过」「进行中」或「完成」状态；另需具备销售订单维护权限。

</div>

### 列权限

| 列 | 权限 |
|----|------|
| 客户名称 | 客户信息读 |
| 金额相关 | 销售金额读 |
| 销售员 | 销售订单读（敏感场景下可能隐藏） |
| 采购员 | 销售订单明细列表读 |

### 筛选 · 销售员 / 采购员

- **销售员**：输入销售员名称关键词（模糊匹配订单主表）。
- **采购员**：输入采购员**登录账号或姓名**关键词（模糊匹配）；仅匹配该行关联的**有效采购订单**上的采购员；一行多张采购订单时任一命中即保留。
- 切换为 **看板** 视图时，统计范围与上述筛选一致。
