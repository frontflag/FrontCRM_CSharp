# 销售订单明细

## 页面功能

- 按行透视销售订单；发起采购申请、跳转申请出库。
- 列表可查看 **销售员**、**采购员**（来自该行关联的有效采购订单）；支持按采购员筛选。
- 在销售订单详情页双击某条明细，可在底部面板查看 **概况** 矩阵（采购～收款各环节进度汇总）。
- 搜索栏可切换 **看板 / 列表**：看板统计口径见 [销售订单明细 · 看板](销售订单明细看板_MENU_SALES_ORDER_ITEMS_BOARD.md)（切换到看板后，本帮助会自动切换为该说明）。

## 列表列说明

<div class="help-op-block">

**销售员**

**说明：** 显示该销售订单主表上的销售员名称。

</div>

<div class="help-op-block">

**采购员**

**说明：** 显示该行关联的**有效采购订单**上的采购员**登录账号**。若一张销售明细对应多张采购订单且采购员不同，以逗号分隔展示（同一人只显示一次）。尚未生成采购订单时显示 **—**。

**注意：** 仅统计未取消的采购订单；已取消的采购单及其采购员不会出现在本列。

</div>

## 操作说明

<div class="help-op-block">

**列表右侧 · 操作面板**

**说明：** 用于在列表页查看当前行摘要，并直接申请采购 / 申请出库。

**怎么用：**

1. 先打开右侧辅助栏，并切到 **「操作」** 页签。
2. 在列表中 **单击** 某行，即可看到订单摘要、备货库存（有库存时）、采购与出库进度，并可申请采购 / 申请出库。
3. 若当前停在「帮助」等其它页签：单击行只会选中该行；再点「操作」页签后才会加载面板内容。
4. 右侧栏收起时：单击行不会打开操作面板。
5. **双击** 行仍进入销售订单详情。

</div>

<div class="help-op-block">

**列表右侧 · 流程**

**说明：** 用时间轴方式查看该销售明细从建立到收款、开票的完整业务环节（采购、质检、入库、出库通知、使用备货、装箱、出库等）。尚未发生的环节会显示为「未开始」。

**怎么用：**

1. 打开右侧辅助栏，切到 **「流程」** 页签。
2. 在列表中 **单击** 某行，即可从上到下查看各业务节点；同一环节若有多张单据，会按创建时间从早到晚叠放。
3. 单号一般可点进对应单据详情。
4. 与「操作」页签相同：右栏收起、或停在「帮助」时单击行不会加载流程内容。

</div>

<div class="help-op-block">

**销售订单详情 · 概况页签**

**说明：** 从本列表进入某张销售订单详情后，在「订单明细」页签 **单击或双击** 某行，底部「销售订单明细详情」面板默认打开 **概况**。矩阵展示该行的 **总数 / 已执行 / 待处理**：采购申请、采购订单、入库、出库申请、出库、收款核销、发票。

**列标题颜色：** 灰=未开始，黄=进行中，绿=已完成，红=异常（如采购申请超量）。仅标题文字变色。

**注意：** 概况为汇总快照；核销流水、采购申请等明细见同面板其他 Tab。亦可在 [销售订单](销售订单_MENU_SALES_ORDERS.md) 帮助页查看同类说明。

</div>

<div class="help-op-block">

**批量申请采购**

**说明：** 对勾选行发起采购申请；多选时若产品提示改为逐条处理，以弹窗为准。

**前置条件：** 已勾选行；所选行对应的**销售订单主表**须已为「审核通过」「进行中」或「完成」状态。另需具备采购申请维护权限。

</div>

<div class="help-op-block">

**申请采购**

**说明：** 弹窗创建采购申请。

**前置条件：** 对应**销售订单主表**须已为「审核通过」「进行中」或「完成」状态；另需具备采购申请维护权限。

</div>

<div class="help-op-block">

**导出**

**说明：** 按当前页面上的筛选条件，把销售订单明细下载为表格文件（Excel 可直接打开）。看板和列表视图都可以导出，导出的是明细行，不是看板统计图。

**怎么用：**

1. 先设好日期、单号、进度或左侧快捷检索等条件，再点页面右上角的 **「导出」**。
2. 确认后开始下载。一次最多约 5 万行；超出部分不会写入本文件，可收窄条件后再导。
3. 导出的是**当前筛选下的全部行**，不是勾选篮子里的行。金额、利润等列仅在您有权查看金额时有数。
4. 系统「导出日志」可查到本次导出及当时的筛选条件。

</div>

<div class="help-op-block">

**申请出库**

**说明：** 跳转销售订单详情并发起出库申请。

**前置条件：** 对应**销售订单主表**须已为「审核通过」「进行中」或「完成」状态；另需具备销售订单维护权限。

</div>

### 列权限

| 列 | 权限 |
|----|------|
| 客户名称 | 客户信息读 |
| 金额相关 | 销售金额读 |
| 销售员 | 销售订单读（敏感场景下可能隐藏） |
| 采购员 | 销售订单明细列表读 |

### 筛选 · 销售员 / 采购员

- **销售员**：输入销售员名称关键词（模糊匹配订单主表）。
- **采购员**：输入采购员**登录账号或姓名**关键词（模糊匹配）；仅匹配该行关联的**有效采购订单**上的采购员；一行多张采购订单时任一命中即保留。
- 切换为 **看板** 视图时，统计范围与上述筛选一致。
