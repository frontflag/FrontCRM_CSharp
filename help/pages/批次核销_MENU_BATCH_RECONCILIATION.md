# 批次核销

## 页面功能

- 以 **入库批次全局编号** 为主线，查询入库批次在采购入库、装箱出库过程中的 **数量消耗与剩余**。
- 支持按入库单、装箱单、采购订单、物料、LOT、SN、供应商、客户等维度检索，用于 **批次追溯、对账与合规核查**。
- 单击主表行可展开 **出库消耗明细**，查看该批次被哪些装箱单/出库消耗了多少。
- 支持 **导出入库批次**、**导出出库批次**（CSV，按当前筛选，最多约 5 万条）；导出可在系统「导出日志」中查看条件摘要。

> **说明：** 本页为 **查询与导出** 为主，不在此页录入或修改批次；批次在 [入库](入库_MENU_STOCK_IN.md) 单、装箱 [出库批次](装箱单_MENU_PACKING_LIST.md) 等环节维护。

---

## 数据含义

| 字段 | 说明 |
|------|------|
| 批次全局编号 | 跨单据唯一的批次标识，串联入库与出库消耗 |
| 入库数量 | 对应入库明细行的数量 |
| 批次数量 | 本批次记录上的数量（可能按片/盘等维度拆分） |
| 出库数量 | 本行关联的出库消耗量 |
| 已出库合计 | 该批次累计已出库总量 |
| 剩余可出 | 批次数量 − 已出库合计，供拣货/出库参考 |

## 操作说明

<div class="help-op-block">

**查询 / 重置**

**说明：** 按批次全局编号、入库单号、装箱单号、采购订单号、物料型号、LOT、SN、供应商、客户、备注等组合筛选。

</div>

<div class="help-op-block">

**查看出库消耗明细**

**说明：** 单击主表某行，页面下方展开 **出库消耗明细** 面板，列出该批次全局编号对应的装箱单号、出库数量、出库日期、客户等。

**前置条件：** 该行存在 全局批次号；点击后加载消耗数据。

**操作：** 点击「收起」关闭面板。

</div>

<div class="help-op-block">

**导出入库批次**

**说明：** 按当前筛选条件导出入库侧批次数据为 CSV，用于存档或外部对账。单次最多约 5 万条。

**前置条件：** 导出进行中按钮暂不可用。

</div>

<div class="help-op-block">

**导出出库批次**

**说明：** 按当前筛选条件导出出库消耗侧批次数据为 CSV。单次最多约 5 万条。

</div>

## 典型使用场景

1. **客户投诉追溯：** 用 SN / LOT 反查入库单、采购订单及后续装箱出库记录。
2. **批次余量核对：** 查看「剩余可出」是否与库存中心可用量一致（异常时联系库存管理员）。
3. **报关/销售出库审计：** 结合装箱单号、客户，核对某批物料流向。

---

## 注意事项

1. **只读为主：** 本页不修改批次；纠错须回到入库单批次维护或出库批次录入入口。
2. **敏感字段：** 部分角色可能看不到供应商/客户名称（显示为「—」）。
3. **数据依赖录入：** 入库时未录入批次、出库时未关联批次，则本页可能查不到或数量不完整。
4. **旧路径：** 菜单原「批次记录」已统一跳转本页。
