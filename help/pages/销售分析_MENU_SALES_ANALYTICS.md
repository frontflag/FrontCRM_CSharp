## 页面功能

- 从「报表分析 → 销售分析」进入，按您可见的销售数据范围查看汇总。
- 上方可切换 **公司 / 部门 / 个人** 视角，并选择日期区间；个人视角下还可指定业务员（有权限时）。
- 下方分为四个内容页签：**概况**、**客户**、**需求**、**订单**。各页签共用上方筛选条件。
- 金额类数字受「销售金额」相关权限控制：无权限时可能显示为「—」，部分占比图会改为按订单数或行数统计。
- 部分数字、排行可点击跳转到对应业务列表（须具备目标列表权限）。

## 共同口径（请先读）

| 约定 | 说明 |
| --- | --- |
| 日期作用范围 | **概况**中的统计概览、趋势、分解、排行，以及 **客户 / 需求 / 订单** 页签，均受上方日期区间约束。 |
| 待办例外 | **概况 → 待办** 三项表示「当前还欠着办的存量」，**不受**日期起止影响。 |
| 销售订单排除 | 统计时排除主单状态为「取消」「审核失败」的订单。 |
| 「成单」含义 | 主单已达「审核通过」及以上（含进行中、完成等），金额按订单折算后的 **美元** 汇总（页面副标题已提示）。 |
| 需求日期 | **需求**页签按需求主单的 **创建日期** 落入区间统计；已取消的需求主单不计入。 |
| 订单日期 | **概况**销售侧与 **订单**页签，按销售订单的 **创建日期** 落入区间。 |
| 数据范围 | 只统计您数据权限内可见的需求与订单；切换公司/部门/个人只是在权限内换聚合视角。 |

<h2 id="help-sales-overview">概况</h2>

域级总览：待办、统计概览、多条趋势、分解图，以及随视角变化的排行（不含客户贡献排行，客户见「客户」页签）。

### 待办

| 指标 | 口径说明 |
| --- | --- |
| 应收款金额 | 当前权限范围内，有效销售明细上「尚未收齐」的金额合计。按本币展示。与所选日期无关。 |
| 待出库明细数 | 出库进度仍为「待出库」或「部分出库」的 **明细行数**（不是订单张数）。与所选日期无关。 |
| 待开票金额 | 有效明细上「尚未开完票」的金额合计。按本币展示。与所选日期无关。 |

**注意：** 「待办应收」与趋势里的「应收趋势」不同——趋势只看区间内、已审核订单按创建日归入各时段的未收款；待办是截至此刻的全部应收余额。

### 统计概览

| 指标 | 口径说明 |
| --- | --- |
| 需求条目数 | 日期区间内创建的需求 **明细行** 数量。 |
| 需求客户数 | 上述需求涉及的去重客户数。 |
| 需求→销售转化率 | 区间内已「挂上销售订单明细」的需求明细数 ÷ 需求条目数 × 100%。分母为 0 时不显示比率。按明细行计，不是按客户或订单张数。 |
| 销售订单条目数 | 区间内创建的销售订单 **有效明细行** 数（含尚未审核的订单）。 |
| 销售客户数 | 区间内销售订单涉及的去重客户数（含尚未审核）。 |
| 成单金额（已审核） | 区间内创建、且已审核通过及以上的订单，美元折算总额合计。新建/待审核不计入。 |
| 已出库金额 | 已审核订单明细上，实际出库数量 × 折算单价的合计（本币口径）。 |
| 已收款金额 | 已审核订单明细上「已收款」金额合计（本币口径）。 |

### 趋势

按日 / 周 / 月把区间拆成多个时段；每个点是该时段内的汇总值。

| 趋势图 | 口径说明 |
| --- | --- |
| 成单金额趋势 | 各时段内已审核订单的美元成单额。 |
| 已出库 / 已收款金额趋势 | 各时段内已审核明细的出库额、已收款额（本币）。 |
| 需求条目 / 需求客户数趋势 | 按需求明细创建日归入时段；客户数为时段内去重。 |
| 订单条目 / 销售客户数趋势 | 按订单创建日归入时段。 |
| 转化率趋势 | 与概览转化率同算法，按每个时段单独计算。 |
| 应收趋势 | 各时段内、已审核订单明细的未收款合计（本币）。**不是**待办应收。 |

### 分解

| 图 | 口径说明 |
| --- | --- |
| 订单主状态 | 区间内非取消/失败订单，按主单状态汇总金额；无金额权限时改为按订单张数占比。含未审核订单。 |
| 币别构成（成单） | 仅已审核成单，按订单原币别看金额占比；无金额权限时按订单数占比。 |
| 全链路环节 | 已审核订单的每条明细只归入一个「当前卡点」：待采购 → 待入库 → 待出库 → 待收款 → 待开票 → 已完结。 |
| 出库进度 | 区间内有效明细按「待出库 / 部分出库 / 出库完成」计行数（不限是否已审核）。 |

### 排行（Top10）

仅统计区间内 **已审核成单**；有金额权限时按金额排序，否则按订单数排序。

| 视角 | 排行内容 |
| --- | --- |
| 公司 | 各部门销售额 Top10（可下钻到部门视角）。 |
| 部门 | 部门内业务员 Top10（可下钻到个人或订单列表）。 |
| 个人 | 概况页不展示排行；客户贡献见「客户」页签。 |

<h2 id="help-sales-customer">客户</h2>

看「谁在成单、谁在复购」，与概况共用日期与公司/部门/个人筛选。进入本页签后才会加载数据。

| 指标 / 面板 | 口径说明 |
| --- | --- |
| 成单客户数 | 区间内已审核成单订单涉及的去重客户数，与概况「销售客户数」在成单口径下一致（只计成单客户）。 |
| 复购客户数 | 上述成单客户中，成单 **订单张数 ≥ 2** 的客户数。 |
| 客户类型 / 等级 / 行业 | 按成单金额（美元）看构成；无金额权限时改为按订单数占比。 |
| 客户 Top10（成单金额） | 区间内成单金额最高的客户。 |
| 客户 Top10（成单数） | 区间内成单订单张数最多的客户。 |
| 客户 Top10（复购订单数） | 复购订单数 = 成单订单数 − 1（至少成单 1 张时才有意义）；用于观察重复下单强度。 |

点击客户排行可进入销售订单列表（带客户等筛选条件）。

若要按 **客户列表筛选结果** 看同类面板（且 **不限订单日期**），请使用 [客户列表 · 看板](客户列表看板_MENU_CUSTOMER_HOME_BOARD.md)。

<h2 id="help-sales-rfq">需求</h2>

与「需求明细」列表看板同一套统计逻辑；本页签标记为 **报表** 口径：按上方公司/部门/个人 + 日期（需求主单创建日），并 **排除已取消的需求主单**。进入本页签后加载；可切换按日/周/月看趋势。

### 需求概览

| 指标 | 口径说明 |
| --- | --- |
| 发布需求客户数 | 区间内有需求的去重客户数。 |
| 复询需求客户数 | 发布过 **2 个及以上** 需求主单的去重客户数。 |
| 复询需求数 | 同一客户在区间内第 2 张及以后的需求主单数量（复询强度）。 |
| 需求数 | 区间内需求主单数量。 |
| 需求明细数 | 区间内需求明细行数量。 |
| 成单明细数 | 已关联到已审核销售订单明细的需求明细行数。 |
| 需求成单率 | 成单明细数 ÷ 需求明细数 × 100%（分母为 0 时不显示）。 |

### 趋势

发布客户数、需求数、需求明细数随时间变化（按需求创建日归入各时段）。

### 分解与排行

各面板用途与统计口径与「需求明细 · 看板」相同（报表集合为公司/部门/个人 + 日期，并排除已取消主单）。详见 [需求明细 · 看板 — 分解 / 排行](需求明细看板_MENU_RFQ_ITEMS_BOARD.md#help-rfq-item-board-breakdown)。

<h2 id="help-sales-order">订单</h2>

与「销售订单明细」列表看板同一套统计逻辑；本页签标记为 **成单** 口径：按上方公司/部门/个人 + 日期（订单创建日），且只统计 **主单已审核通过及以上、明细有效** 的行。进入本页签后加载；可切换按日/周/月看趋势。

### 成单概览 / 利润 / 在库 / 应收

| 分组 | 指标含义（摘要） |
| --- | --- |
| 成单概览 | 成单客户数、订单张数、明细行数、成单金额（美元）；并可对照原币分档展示。 |
| 利润 | 采购利润、出库利润等（按明细上已沉淀的利润口径汇总；无金额权限时隐藏）。 |
| 在库 | 仍有在库数量的客户数、明细数、在库金额（美元）、最长在库天数等。 |
| 应收款 | 仍有应收的客户数、明细数、应收金额、最长账龄等。 |

### 趋势

成单订单数、成单明细数、成单明细金额（美元）随时间变化。

### 分解与排行

各面板用途与统计口径与「销售订单明细 · 看板」相同（报表集合为成单硬过滤 + 公司/部门/个人 + 日期，并含趋势）。详见 [销售订单明细 · 看板 — 分解 / 排行](销售订单明细看板_MENU_SALES_ORDER_ITEMS_BOARD.md#help-so-item-board-breakdown)。

## 使用提示

<div class="help-op-block">

**切换页签看不同粒度**

**说明：** 「概况」看全链路经营总览与待办；「客户」看客户贡献与复购；「需求」看询价漏斗；「订单」看成单后执行与利润/在库/应收。四者共用顶部视角与日期，改筛选后请点「查询」或进入页签自动刷新。

</div>

<div class="help-op-block">

**金额单位不要混加**

**说明：** 成单金额与多数排行为 **美元**；待办应收、待开票、部分出库/收款趋势多为 **本币**。对比时请留意页面上的单位提示。

</div>

<div class="help-op-block">

**与列表页看板的区别**

**说明：** 需求明细、销售订单明细列表里的「看板」跟列表搜索条件联动，适合筛完再看；本页是管理层报表视角，跟公司/部门/个人与统一日期联动，订单页签固定为「成单」集合，需求页签排除已取消主单。

</div>
