# 客户滚存

## 页面功能

- 在库存滚存口径基础上，按**客户**维度统计各自然月的采购入库与销售出库数量、金额（美元）。
- **汇总页**：选择月份后分页列出有滚存数据的客户；支持按客户名称或编码关键词筛选。
- **明细页**：查看某一客户在指定月份下的入库明细行滚存；支持物料型号、入库单号、入库日期筛选。
- 入库时未指定客户的明细归入「**未指定**」行。
- 本报表为**只读**；无相关金额权限时金额列显示「—」。

## 数据来源与计算说明

### 一、客户维度：数据从哪来

客户滚存与「库存滚存」使用**同一套**采购入库、销售出库流水，额外按**客户**归集：

| 环节 | 读取位置 | 规则 |
|------|----------|------|
| **入库归属客户** | 库存层记录上的「客户」 | 每条采购入库明细通过库存层确定归属客户；层上客户为空则归入「未指定」 |
| **出库归属客户** | 销售出库单表头上的「客户」 | 出库必须与客户维度一致才计入该客户 |
| **维度匹配** | 入库客户 vs 出库单客户 | 若出库单上的客户与对应入库明细的归属客户**不一致**，该笔出库**整笔不计入**任何客户（避免串户） |
| **客户名称** | 客户主数据 | 按公司全称 → 简称 → 英文全称 → 客户编码 顺序取显示名 |

入库、出库的单据类型、状态、删除标记、月份边界等与「库存滚存」一致（仅采购已过账入库、销售已出库/已完成出库等）。

### 二、汇总页各列含义

对**选定自然月 M**、**客户 C**（含「未指定」）：

| 列名 | 如何读取与计算 |
|------|----------------|
| **客户** | 客户主数据显示名；无客户 ID 显示「未指定」 |
| **上期数量 / 上期金额** | M 月之前、归属 C 的累计入库 − 累计出库（数量或美元金额） |
| **入库数量 / 本期入库(USD)** | M 月内、归属 C 的采购入库合计 |
| **出库数量 / 本期出库(USD)** | M 月内、归属 C 且通过客户维度匹配的销售出库合计 |
| **结余数量 / 结余金额(USD)** | 上期 + 本期入库 − 本期出库 |

**列表出现条件：** 该客户在 M 月有入库或出库动静，**或**上期数量/金额非零。按客户名称升序排列，「未指定」排在最后。

关键词搜索在客户主数据中匹配名称与编码，再过滤汇总结果。

### 三、明细页各列含义

在选定**月份 + 客户**后，列出相关采购入库明细行（与库存明细滚存列结构相同）：

| 列名 | 数据从哪来 | 说明 |
|------|------------|------|
| **入库单号 / 物料型号 / 入库时间** | 采购入库单及明细 | 与库存明细滚存相同 |
| **入库数量 / 本期入库(USD)** | 入库明细 | 仅当入库日期落在所选自然月内计入本期入库；早于该月入库的行仍可能出现（因当月有出库），本期入库显示 0 |
| **出库数量 / 本期出库(USD)** | 关联销售出库 | 仅统计出库单客户与该行入库客户一致的部分 |
| **上期数量 / 上期金额** | 本月前的关联出库 | 新入库行期初为 0，再扣减历史已出库 |
| **结余数量 / 结余金额** | 行内公式 | 上期 + 本期入库 − 本期出库 |

若某入库明细在 M 月有匹配出库，但入库时间早于 M 月，该行仍会出现在明细列表中（便于对账当月出库），本期入库按月份规则为 0。

## 统计范围与过滤规则（摘要）

- 与库存滚存相同的入出库单据范围。
- **客户专有条目**：出库单客户 ≠ 入库行客户 → 不计入。
- **权限**：须具备「库存滚存」查看权限；客户名称链接另需客户查看权限；入库单号链接另需库存查看权限。

## 金额列 (USD) 说明

客户滚存的四列 **(USD)** 金额与「[库存滚存](库存滚存_MENU_FINANCE_STOCK_ACCUMULATED.md)」**完全相同**：均为**折算后的美元金额**，按入库/出库过账时写入的美元采购单价计算，报表查询时不再重新换汇。

### 折算与计算（摘要）

| 环节 | 说明 |
|------|------|
| **入库金额** | 入库数量 × 库存层「美元采购价」（入库过账时按财务基准汇率折算） |
| **出库金额** | 出库数量 × 出库扩展或库存层上的美元采购价 |
| **上期 / 结余** | 在客户维度内，按自然月滚动：上期 + 本期入库 − 本期出库 |

四列含义：**上期金额(USD)**、**本期入库(USD)**、**本期出库(USD)**、**结余金额(USD)** — 详见库存滚存帮助中的「金额列 (USD) 说明」。

### 显示与权限

- 美元两位小数；无相关金额查看权限时显示「—」，数量不受影响。
