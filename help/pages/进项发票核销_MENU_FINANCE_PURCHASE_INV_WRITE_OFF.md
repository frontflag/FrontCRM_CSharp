# 进项发票核销

## 页面功能

- **进项发票核销桌面**：将待核销供应商队列、待核销进项发票与待核销入库合并为连续核销工作区。
- 适合同一供应商多张开票、多笔入库时逐张核销。

## 入口

- 侧栏 **付款管理 → 进项发票核销**
- 进项发票列表右上角 **进项发票核销桌面**

## 操作说明

1. 在左侧选择 **待核销供应商**（按供应商 + 币别；需同时有待核销发票与待核销入库）。
2. 顶栏 **上一供应商 / 下一供应商** 可切换队列；统计为全量待核销供应商与发票条数。
3. 中区左侧选择 **待核销进项发票**；右侧按 **入库单** 填写本次核销金额。
   - 入库单仅 1 条待核明细：在入库单行直接填写。
   - 多条待核明细：展开后逐行填写。
4. 点击 **提交核销**；成功后留在当前供应商 + 币别并刷新。
5. 右侧辅助栏 **入库单** 页签可查看当前聚焦入库单的采购员、货代单号等信息。

**说明：** 本页无反核销与核销流水；需查看台账请使用进项发票详情或相关报表。
