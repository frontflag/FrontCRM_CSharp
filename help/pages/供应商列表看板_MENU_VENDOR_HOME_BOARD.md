## 页面功能

- 在「供应商列表」点击 **看板** 进入；再点 **列表** 返回表格。
- 供应商集合与上方 **搜索栏当前筛选结果** 完全一致（含状态、等级、身份、归属、行业、结算币、采购员、创建日、左栏快捷检索、仅收藏等）。
- 面板布局与「报表分析 → 采购分析 → 供应商」相同；差别在于：**列表看板不限订单日期**，只在筛选出的供应商内统计其全部已审核采购订单。
- 金额类数字受采购金额相关权限控制；无权限时占比改为按订单数统计，金额列可能不展示。

也可阅读：[供应商](供应商_MENU_VENDOR_HOME.md) · [采购分析 · 供应商](采购分析_MENU_PURCHASE_ANALYTICS.md#help-purchase-vendor)

## 共同口径

| 约定 | 说明 |
| --- | --- |
| 供应商集合 | 当前搜索栏筛出的全部供应商（不是当前页）。 |
| 订单集合 | 上述供应商的 **全部已审核** 采购订单；**不按订单创建日再裁剪**。 |
| 列表「创建日」 | 只筛 **供应商建档日**，不作为订单时间窗。 |
| 与报表区别 | 采购分析「供应商」页签按公司/部门/个人 + **订单日期区间** 统计成单。 |

<h2 id="help-vendor-board-kpi">供应商概览</h2>

| 指标 | 口径说明 |
| --- | --- |
| 成单供应商数 | 筛选供应商中，至少有一张已审核采购订单的去重供应商数。 |
| 复采供应商数 | 上述成单供应商中，已审核订单张数 ≥ 2 的供应商数。 |

---

<h2 id="help-vendor-board-breakdown">分解</h2>

在「有成单的筛选供应商」上按维度看构成。有金额权限时按成单金额（美元）占比；无权限时按订单数占比。

| 面板 | 用途 |
| --- | --- |
| 供应商身份 | 看身份构成 |
| 供应商等级 | 看成单供应商等级（**S / A / B / C**） |
| 供应商行业 | 看行业构成 |

---

<h2 id="help-vendor-board-rankings">排行</h2>

取筛选供应商内 Top10；点击行可进入采购订单列表（带供应商条件，**不带订单日期**，便于看该供应商全部订单）。

| 排行 | 口径说明 |
| --- | --- |
| 供应商 Top10（成单金额） | 已审核订单金额合计最高的供应商 |
| 供应商 Top10（成单数） | 已审核订单张数最多的供应商 |
| 供应商 Top10（复采订单数） | 复采订单数 = 成单订单数 − 1（仅成单 ≥ 2 的供应商） |
