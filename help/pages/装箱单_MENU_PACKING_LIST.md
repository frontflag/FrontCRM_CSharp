# 装箱单

## 页面功能

- 管理出库前的 **装箱单**：从出库通知生成装箱、确认、拣货、备货、出库及打印箱单/Invoice。
- **报关进口** 场景须使用出库类型为 **报关出库** 的装箱单；**确认装箱** 后系统自动生成 [报关单](报关单_MENU_CUSTOMS_DECLARATIONS.md) 与明细，是关务链路的 **关键节点**。
- 普通 **销售出库** 装箱单走同一套状态机，但不生成报关单。

---

## 装箱单状态与推荐顺序

| 状态 | 含义 | 本阶段典型操作 | 下一状态 |
|------|------|----------------|----------|
| 新建 | 装箱单已保存，未确认 | **确认装箱单**；可删除 | 已确认 |
| 已确认 | 装箱内容已锁定 | **拣货**（报关类：此时已生成报关单） | 已拣货 |
| 已拣货 | 拣货任务完成 | **备货**（勾选检查项） | 已备货 |
| 已备货 | 可安排出库 | 勾选多张后 **出库** / 单张 **出库** | 待出库 → 出库完成 |
| 待出库 | 出库单已生成待执行 | 到 [出库单](出库单_MENU_STOCK_OUT.md) 完成过账 | 出库完成 |
| 出库完成 | 库存已扣减 | 报关类：到 [报关单](报关单_MENU_CUSTOMS_DECLARATIONS.md) 继续关务 | — |

**报关进口推荐顺序：**

```
待报关 → 报关出库通知 → 新建报关装箱单（选报关公司）→ 确认装箱单
    → 拣货 → 备货 → 出库（报关出库）→ 报关单：费用试算 → 结关 → 生成到货通知 → …
```

销售类装箱可省略报关单相关步骤；完整关务后续见 [报关单](报关单_MENU_CUSTOMS_DECLARATIONS.md) 帮助。

## 创建装箱单

<div class="help-op-block">

**从出库通知创建**

**说明：** 在 [出库通知](出库通知_MENU_STOCK_OUT_NOTIFY.md) 列表选择待装箱的出库通知（须同一客户、付款方、物料类型等规则），进入 **新建装箱单** 页维护明细与地址信息后保存。

**前置条件：** 出库通知处于可装箱状态；物流数据可写。

</div>

<div class="help-op-block">

**报关装箱 · 选择报关公司**

**说明：** 出库类型为 **报关出库** 时，新建页须选择 [报关公司](报关公司_MENU_CUSTOMS_BROKERS.md)；保存后生成报关类装箱单。

**前置条件：** 已维护至少一家 **启用** 状态的报关公司。

**注意：** 未选报关公司无法保存报关装箱单。

</div>

## 列表操作说明

<div class="help-op-block">

**查询 / 重置**

**说明：** 按装箱单号、状态、出库类型（可筛 **报关出库**）、物料类型、客户、业务员、创建日期筛选。

**前置条件：** 无

</div>

<div class="help-op-block">

**详情**

**说明：** 进入装箱单详情，查看/维护头信息、装箱明细、关联出库通知等。

**前置条件：** 无

</div>

<div class="help-op-block">

**确认装箱单**

**说明：** 将「新建」装箱单确认为「已确认」，锁定装箱内容。

**前置条件：** 状态 = **新建**；物流数据可写。

**报关出库特别注意：** 确认成功后系统 **自动生成** [报关单](报关单_MENU_CUSTOMS_DECLARATIONS.md) 及报关明细（无需手工建单）。若自动生成失败，可在「已确认」～「出库完成」前使用 **补生成报关单**。

</div>

<div class="help-op-block">

**拣货**

**说明：** 从已确认装箱单进入拣货页：分配库存批次、确认拣货数量、生成拣货单，完成拣货任务。

**前置条件：** 状态 = **已确认**；关联出库通知有效；境外仓等有可用库存。

**注意：** 若装箱单关联多条出库通知，须分别从出库通知侧拣货（系统会提示）。

</div>

<div class="help-op-block">

**备货**

**说明：** 拣货完成后，按弹窗逐项勾选来货、包装、标签、单据、快递等检查项，确认后将状态标为 **已备货**。

**前置条件：** 状态 = **已拣货**；物流数据可写。

</div>

<div class="help-op-block">

**出库（单张 / 批量）**

**说明：** 在列表勾选多张 **已备货** 装箱单，点击底部 **出库**，填写预计出库日期等后批量生成出库单并扣减库存。单张也可在操作列走相同逻辑。

**前置条件：** 所选装箱单状态均为 **已备货**；且 **同一客户、同一仓库、同一出库类型、同一送货公司与地址**；物流数据可写。

**报关出库完成后：** 境外库存扣减，方可到报关单 **生成报关到货通知**（还须结关、费用试算等，见报关单帮助）。

</div>

<div class="help-op-block">

**补生成报关单**

**说明：** 仅 **报关出库** 类装箱单显示。在已确认且未出库完成前，可重新触发报关单生成；若已拣货，系统会回写报关明细。

**前置条件：** 出库类型 = 报关出库；状态 ∈ [已确认, 出库完成)；物流数据可写。

</div>

<div class="help-op-block">

**出库批次**

**说明：** 为已确认及之后状态的装箱单录入出库批次信息（物流追溯用）。

**前置条件：** 状态 ≥ 已确认。

</div>

<div class="help-op-block">

**打印 Invoice / 装箱单**

**说明：** 打印商业 Invoice 或装箱单（含/不含验货信息）。须已有关联出库单或满足打印前置（以页面提示为准）。

**前置条件：** 无特殊写权限要求。

</div>

<div class="help-op-block">

**删除**

**说明：** 删除「新建」状态装箱单；关联出库通知恢复为 **待装箱**，装箱明细一并删除。

**前置条件：** 状态 = **新建**；物流数据可写。

</div>

<div class="help-op-block">

**强制删除**

**说明：** 系统管理员输入装箱单号确认后强制删除，仅用于异常数据清理。

**前置条件：** `SYS_ADMIN` 权限。

</div>

---

## 注意事项

1. **报关与销售分流：** 筛选「出库类型 = 报关出库」可只看报关装箱；列表「出库类型」列可跳转关联报关单号。
2. **确认装箱 = 生成报关单：** 报关链路不要在报关单列表手工建单替代此步骤（除非使用补生成补救）。
3. **顺序不可跳：** 新建 → 确认 → 拣货 → 备货 → 出库；跳过会导致按钮不可用或下游关务/库存校验失败。
4. **批量出库规则严格：** 客户、仓库、出库类型、送货地址不一致时无法合并出库。
5. **删除仅限新建：** 已确认后不可普通删除，避免与报关单、拣货数据不一致。
6. **权限：** 确认、拣货、备货、出库、删除等须 **物流数据可写**；销售敏感字段可能对部分角色脱敏显示。
