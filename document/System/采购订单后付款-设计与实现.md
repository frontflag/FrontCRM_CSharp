## 1. 业务含义

「后付款」表示本采购订单对供应商**先欠款**，等**客户付款后再给供应商结款**。

| 项 | 口径 |
|----|------|
| 挂载 | 仅采购订单**主单** |
| 与供应商账期 | **独立标记**，不改供应商 `Payment` 天数 |
| 申请付款 | **仅标记提醒，不拦截** |
| 明细 / 付款单 | 首期不同步标签 |
| 列表 | 首期不加列、不加筛选 |
| 历史数据 | 默认 `false`，不做回填 |
| 可改时机 | 与其它可编辑主表字段一致（能编就能改） |
| 权限 | 与 PO 编辑权限一致 |

## 2. 数据与 API

| 层 | 说明 |
|----|------|
| 列 | `purchaseorder.is_pay_later`（`boolean NOT NULL DEFAULT false`） |
| 实体 | `PurchaseOrder.IsPayLater` |
| 创建 | `CreatePurchaseOrderRequest.IsPayLater` |
| 更新 | `UpdatePurchaseOrderRequest.IsPayLater`（`bool?`，有值则写入） |
| 详情/列表 Mask | `MaskPurchaseOrder` 返回 `isPayLater` |
| 变更日志 | 主表字段 `isPayLater` /「后付款」，值「是」「否」 |

EF 迁移：`20260717120000_PurchaseOrderIsPayLater`。

## 3. 前端

### 3.1 新建 / 编辑（`PurchaseOrderCreate.vue`）

- 基本信息区「付款约定」：`el-checkbox` 文案 **后付款**
- 旁侧注释图标，hover tip：**客户付款后再给供应商付款**
- 勾选后勾选区域加**橙色底**强调

### 3.2 详情（`PurchaseOrderDetail.vue`）

- 标题区状态旁：橙色 Tag **后付款**（`isPayLater === true`）
- tip 同新建/编辑

### 3.3 首期不做

- 采购订单列表列/筛选
- 申请付款按钮禁用或强提示
- 付款单带出「后付款」标签
