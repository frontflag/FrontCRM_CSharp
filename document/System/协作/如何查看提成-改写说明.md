## 1. 重排章节

按读者操作顺序写，不要先讲完整算法。

1. 开头两句：这篇给业务员和采购员。先写去哪个菜单看，再写数字怎么来。财务、物流、商务等打不开提成菜单的人，开头就说明看不到这些页。
2. **怎么查看**：提成池 → 预计/正式（先定义差别）→ 汇总 → 月份 → 明细。每一层单独一节。
3. **提成怎么算**：放在查看之后。进池三条、Base / Other、算给谁、公式和梯度。用第 4 节那一行示例把梯度说完，不要再堆空表。
4. **计划提成**：放在最后。删掉夹在明细和计划之间的「控制台上的个人提成金额……」。桌面上的大数字就是本期预计提成，写进本节。

## 2. 预计和正式

在给出四个链接之前，用一句话写清：

- **预计提成**：尚未锁定，还会按当前规则重算。
- **正式提成**：锁定日之后写入，已锁定的出库行不再重算。

然后写角色入口，各只给自己的两个链接：

- 业务员：[业务预计提成](/commission/estimated/sales)、[业务正式提成](/commission/official/sales)
- 采购员：[采购预计提成](/commission/estimated/purchase)、[采购正式提成](/commission/official/purchase)

不要把四个链接排成读者四个都要打开。

## 4. 示例数字

月份或明细里用同一行例子，并在「提成怎么算」里用它说明公式。数字写成能手算对上的值，例如：本月 GP 1000，该档点数 2，提成金额 20.00（1000 × 2 / 100）。出库 GP 为负时按 0 参与本月 GP，这句话保留。

## 5. 计划提成

本节补一张图 `commission-plan.svg`：我的桌面、快捷入口下方的 **个人提成**、大数字（当前预计提成）、本期计划、完成进度、年度计划、年度已累计、**设置**。

正文保留这些事实：只能看和改自己的；销售看业务提成，采购主部门看采购提成；其他部门不显示。点 **设置**，对话框 **设置计划提成**，填 **本期计划提成** 和 **年度计划提成**，单位美金。填 0 或清空表示取消该目标。本期按提成双月窗口，不是自然月，窗口切换后要重设本期。点 **保存**。不保存就点 **取消**。
