## 1. 目的与范围

在已登录的业务页上提供一层统一的 AI 交互。用户按空格进入，按 Esc 或右上角按钮退出。当前页仍留在蒙版后面。

首期接这些事：

| 技能 / 动作 | 说明 | 权限 |
|-------------|------|------|
| 反馈与建议 | 复用顶栏反馈助手的会话与落库 | 任意已登录用户 |
| 培训问答 | 复用知识库教材问答，文档编码 `handbook.distributor.newcomer` | 任意已登录用户 |
| 操作手册 | 复用同一套问答，文档编码 `ops.manual`。正文前固定「以下内容来自系统操作手册：」。手册没写到时回答「操作手册未说明该问题。」 | 任意已登录用户 |
| 数据查询 | 把问句收成固定意图后，调用既有销售、出库、在库、应收看板。缺条件先追问，不猜。模型不写 SQL，也不编造数字。结果不缓存 | `biz.ai.data.query` |
| 粘贴文本创建 | 客户、供应商、需求。未选技能时出现操作卡，确认后走既有解析建单 | 对应 `biz.ai.entity.parse.*` |

**本期不做：**

- 在对话里直接改已有单据字段，也不在对话里提交审核、执行出库或做核销
- 数据查询不提供任意 SQL，也不覆盖销售分析以外的全部图表。客户、品牌、业务员、仓库筛选和「只看我的」留到后续
- 与顶栏「AI 助手」抽屉、菜单「培训问答」页共用会话
- 历史会话列表。Esc 关掉这一层，不保留上一轮
- 系统管理页面（员工、角色、权限、参数等）、控制台、每日行业新闻、草稿箱、入库运维检查、出库运维检查。业务菜单正文见 [系统操作手册](./操作手册/系统操作手册.md)

顶栏抽屉和培训问答页继续存在，各自开会话。

## 2. 功能需求

### 2.1 进入与退出

| 动作 | 行为 |
|------|------|
| 空格 | 新开一轮。输入框清空，不在按空格时创建反馈会话 |
| Esc | 退出本层 |
| 「退出AI模式」 | 与 Esc 相同。按钮在页面右上角，蓝底白字，带关闭图标。下方灰色说明：「按ESC也可退出」 |

空格在以下情况不打开本层：焦点在输入框、文本域、下拉、日期、可编辑区域；焦点在按钮、链接、勾选等可激活控件；正在输入法组字；按键重复或带修饰键；页面上已有正在显示的 Element Plus 弹层。已关闭的抽屉仍会留下 `display: none` 的遮罩，这种遮罩不算「正在显示」，不阻止空格。

解析确认框打开时，Esc 先关确认框，不关 AI 层。「退出AI模式」同样先不关 AI 层。

已登录用户即可按空格打开本层（反馈、培训教材、操作手册始终可用）。无数据查询权限时仍可使用前三项技能。

### 2.2 一轮里的布局

| 阶段 | 布局 |
|------|------|
| 刚打开、还没发送 | 输入框和技能按钮在屏幕正中。背后页面仍可见 |
| 发出第一条之后 | 输入框贴在底部。上方是本轮对话，可滚动 |

阅读栏与底部输入栏同宽，最大 800px，水平居中。

- 用户问题：气泡只包住文字，靠栏右侧，字号 14px。
- AI 回复：占满阅读栏宽度。左上角为蓝圆脸图标（两道白色眼睛）。正文 14px，行距 1.75。
- 蒙版：`rgba(15, 23, 42, 0.5)`，模糊 6px。层 `z-index` 4000。

未选技能时，输入框提示为：「输入问题，Enter 发送。可不选技能，由 AI 判断。」

选中技能后，提示改为：「当前技能：{技能名称}」。再点一次已选中的技能，取消选中，提示恢复未选时的文案。

技能按钮、反馈类别按钮（「反馈问题」「提改进建议」）、粘贴建档按钮、粘贴原文，字号均为 14px。

### 2.3 技能

按钮显示规则：

| 技能 | 显示条件 |
|------|----------|
| 反馈与建议 | 任意已登录用户（始终显示） |
| 培训教材 | 任意已登录用户（始终显示） |
| 操作手册 | 任意已登录用户（始终显示） |
| 数据查询 | 持有 `biz.ai.data.query` 时显示 |

菜单页标题「培训问答」不改。历史权限码 `biz.feedback.submit` / `biz.ai.kb.qa` / `biz.ai.ops.qa` 仍可存在于种子脚本与场景表，**运行时不再作为提问门控**。

| 规则 | 说明 |
|------|------|
| 已选定 | 这一句强制走该技能 |
| 未选定 | 由路由判断这一句，并显示「自动：{技能名称}」。不锁定后续句子 |
| 中途切换 | 对话保留，未发送草稿保留，插入一行「已切换到 {技能名称}」 |
| 再点已选中按钮 | 取消选中，下一句重新判断 |
| 上下文 | 模型能看到本轮已显示的对话，所以「上面这条不对」指得上前文 |

未选技能时的判断顺序：先看是不是粘贴建档；明确的报错、故障、缺陷、截图走反馈；「如何 / 什么是 / 怎么 / 步骤 / 公式」仍走操作手册或培训教材，不进数据查询。其余句子里出现业绩、趋势、库存金额、积压、待收款、应收、卖得最好、Top 时走数据查询。系统页面、步骤、公式、核销、提成、报关、装箱、拣货、审核、出库申请走操作手册；培训教材、新人和行业概念走培训教材。「怎么新建客户」走操作手册。「什么是客户的观四面」和「培训教材里怎么看库存」走培训教材。「本月业绩」走数据查询。「如何出库」走操作手册。

反馈只把**处在「反馈与建议」时发出的消息**写入反馈工单。切换到其他技能再切回来，仍续同一反馈会话，但其他技能的句子不写入工单正文。本轮对话作为背景上下文交给模型，不当作反馈正文存储。

图片只随反馈发送。培训问答和操作手册必须有文字，且不超过 500 字。

选中「反馈与建议」且本轮还没发出第一条反馈时，输入框上方出现「反馈问题」「提改进建议」。这是偏好，不是必填。

### 2.4 培训问答回复

正文前固定一句：**以下内容来自培训教材：**

检索到章节时，正文下方用一块操作面板与正文区分，标题为「查看相关文档」，下列出教材链接。面板为浅灰底，链接可新开教材阅读页。

检索、向量和缓存仍只用当前问题。本轮前文只附加在送给模型的问题后面，且有前文时不走问答缓存。缓存里若仍是旧固定语「以下内容来自新人培训教材，不是公司制度。」，返回时改写成新固定语。

教材问答的检索、切块和覆盖判定见 [AI知识库问答-设计与实现](./AI知识库问答-设计与实现.md)。提问按文档编码取该文档自己的启用版本。培训教材编码是 `handbook.distributor.newcomer`。不传编码时仍是培训教材，避免操作手册的启用版本抢走教材问答。

### 2.4.1 操作手册回复

正文前固定一句：**以下内容来自系统操作手册：**

出处面板与培训问答相同，标题仍是「查看相关文档」。链接打开阅读页时带上该版本。手册没覆盖时，回答是「操作手册未说明该问题。」，不补步骤和公式。

正文是 [系统操作手册](./操作手册/系统操作手册.md)，按业务菜单一章。上传接受该 Markdown（也仍接受教材 docx）。入库时去掉标题井号，再按「第N章」「N.N」切块。启用某一版只影响同一文档，不影响培训教材。已有启用版本时，新版本就绪后须再点启用。

本轮前文同样只附加给模型，有前文时不走问答缓存。第 15、16 章的合规提示只用于培训教材，不用于操作手册。

### 2.4.2 数据查询

按钮「数据查询」。未选技能时，业绩、趋势、库存金额、积压、待收款、应收和卖得最好会进这里。已选中的技能不被这句话改掉。

问句只映射到固定意图：业绩、销售趋势、订单趋势、今天的品牌排名、当前库存金额、积压、待收款、有应收的客户、本月新建订单的张数和金额。对不上时回答「这个数还不能查。」，不编数字。

必填条件缺一个就追问一个，给出可点的选项，也可以自己打字。已经说出的条件不再问。例如「本月业绩」只问出库金额、订单金额还是毛利；选了之后才查。毛利按期间合计还没有现成看板，选毛利时说明还不能查，并请改用另外两个。积压必须先定库龄天数（30 / 60 / 90 / 180，或自己输入），再问按金额还是数量。卖得最好先问金额还是数量，再问按出库还是按下单。

同一轮里「出库金额」补上还空着的口径；「换成近三个月」只改时间。换成另一类问题（业绩改问库存）时，丢掉上一问的条件。连续两句都没对上选项，就再列一次选项，仍然不查。

能直接查的口径：待收款是销售分析待办的待核销应收；当前库存金额是库存中心在库折算美金。这些不追问。「本月新建订单是多少条？金额是？」直接回答：张数是本期新建且未取消、未审核失败的销售订单；金额是其中已审核订单的折算美金。

回复先给一句结论，再给一个数字、折线或条形，表格最多 20 行。图下面有一句口径说明，并在新页面打开对应列表或看板。当前这一轮对话留在原页。数字每次现查，不缓存。没有销售金额权限或采购金额权限时，金额留空，和对应列表一致。排行沿用看板的前 10 名。

### 2.5 粘贴文本创建

未选技能，且没有待发送图片时，满足下面条件才出现建档卡，而不是直接当提问发出：

- 多行且不少于 8 字，或单行不少于 40 字
- 短问句不建档：不足 80 字，且像「怎么 / 如何 / 什么是 / 为什么 / 吗」或以问号结尾

已选技能时，粘贴内容留在该技能里，不出现建档卡。

建档卡上方是原文（14px），下方是操作面板：

- 标题：「用这段文字创建」
- 按钮：创建客户、创建供应商、创建需求。无权限的按钮不显示。三个都没有权限时不出现这张卡
- 不预选按钮，也不显示「更像」

点按钮后，标题和按钮隐藏，面板改为：「正在解析{按钮名称}，请稍后...」例如「正在解析创建客户，请稍后...」。

解析与确认复用既有实体解析：确认框在 AI 层之上（`z-index` 4600）。确认后跳到对应新建页并带上预填，同时关掉 AI 层。列表页原有的「粘贴文本」菜单不变。

客户、供应商、需求的字段解析与确认见 [AI实体解析建单-设计与实现](./AI实体解析建单-设计与实现.md)。本层只做入口，不在点按钮之前解析。

### 2.6 反馈落库

反馈的追问、精炼和工单规则不变，见 [AI用户反馈助手-设计与实现](./AI用户反馈助手-设计与实现.md)。本层在第一次真正发出反馈消息时才创建会话。

## 3. 设计实现

### 3.1 前端

宿主在 `AppLayout` 里挂载，Teleport 到 `body`，与顶栏 `AiAssistantDrawer` 并列，不替换抽屉。

| 文件 | 职责 |
|------|------|
| `CRM.Web/src/components/AiInteraction/AiInteractionLayer.vue` | 蒙版、对话、技能、建档卡、退出 |
| `CRM.Web/src/utils/aiInteractionHotkey.ts` | 空格是否开新一轮；是否已有可见弹层 |
| `CRM.Web/src/utils/aiInteractionTranscript.ts` | 技能启发式、是否粘贴建档、对话文本 |
| `CRM.Web/src/components/AiCreate/AiEntityCreateHost.vue` | 本层内复用。`openWithText` 跳过粘贴框，直接解析 |
| `CRM.Web/src/components/AiCreate/AiEntityParseConfirmDialog.vue` | 确认框 `z-index` 4600，`modal-class="ai-parse-confirm-overlay"` |

路由确认后跳转：客户 `CustomerCreate`，供应商 `VendorCreate`，需求 `RFQCreate`。监听路由变化后关闭本层。

前端路由失败（例如接口 404）时，用与后端相同的关键词启发式兜底。

### 3.2 接口

| 接口 | 用途 |
|------|------|
| `POST /api/v1/ai-assistant/route` | 未选技能时判断这一句是反馈、培训教材、操作手册还是数据查询。反馈/教材/手册对任意已登录用户始终可选；再按 `biz.ai.data.query` 决定是否含数据查询。可选技能多于一种时才可能调模型；仅一种时直接返回那一种 |
| `POST /api/v1/ai-assistant/data-query` | 数据查询。请求带当前问题和上一轮槽位。返回追问或结论、图、表。不写问答缓存。需 `biz.ai.data.query` |
| 既有反馈 `createSession` / `sendMessage` | 反馈。任意已登录即可（不再要求 `biz.feedback.submit`）。请求可带 `backgroundContext`，只进提示词，不写入工单正文 |
| 既有知识库 `ask` | 培训问答不传文档编码。操作手册传 `documentCode=ops.manual`。任意已登录即可。可带 `dialogueContext`。有上下文时问题向量和缓存仍用当前问题 |

路由实现：`AiAssistantService.RouteSkillAsync`。业绩、趋势、库存金额、积压、待收款、应收、卖得最好先按关键词进入数据查询，不交给模型。其余句子模型不可用时用 `AiInteractionSkillHeuristic`，规则与前端 `chooseAiSkill` 一致。

培训问答固定语在 `KbHandbookService` 拼到答案前面。读到缓存里的旧固定语时，先去掉再拼上「以下内容来自培训教材：」。

### 3.3 层级

| 层 | z-index |
|----|---------|
| AI 交互层 | 4000 |
| 解析确认遮罩 | 4600 |
| 消息条 | 5000 |

确认遮罩单独抬高。不要把所有 `.el-overlay` 都抬到 AI 层之上，否则业务页上残留的抽屉遮罩会盖住本层或挡住空格。

## 4. 验收要点

- 在列表页按空格出现居中输入框；焦点在表格外的空白处即可。焦点在输入框或按钮上时不出现。
- **无 `biz.feedback.submit` / `biz.ai.kb.qa` / `biz.ai.ops.qa` 的普通业务账号**：仍能看到并使用「反馈与建议」「培训教材」「操作手册」；顶栏「AI 助手」入口可见；提问不被「无权提问」拒绝。
- 无 `biz.ai.data.query` 时不显示「数据查询」技能，前三项仍可用。
- 右上角「退出AI模式」和 Esc 都能关掉本层。确认框开着时，两者都不关本层。
- 选中「培训教材」后，提示为「当前技能：培训教材」。再点一次，选中取消，提示恢复。
- 未选技能时问「什么是客户的观四面」，走培训问答。回答以「以下内容来自培训教材：」开头。有出处时，面板标题为「查看相关文档」。
- 未选技能时问「提成怎么算」或「怎么新建客户」，走操作手册。回答以「以下内容来自系统操作手册：」开头。手册未启用或没写到时，提示还没有启用版本，或回答「操作手册未说明该问题。」
- 「培训教材里怎么看库存」仍走培训问答。「报错了如何装箱」走反馈。
- 未选技能时粘贴一段客户资料，出现三个创建按钮，且没有预选。点「创建客户」后按钮隐藏，显示「正在解析创建客户，请稍后...」。
- 「怎么新建客户」这类短问句不出现建档卡。
- 顶栏 AI 助手抽屉仍可单独打开，会话不与本层混用。
