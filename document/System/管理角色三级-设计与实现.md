# 管理角色三级（SuperAdmin / Admin / Manager）— 设计与实现

**状态：** 一期已落地  
**关联：** [管理角色分级与权限体系PRD](../PRD/管理角色分级与权限体系PRD.md)

## 命名对照

| 产品称呼 | RoleCode | permission-summary |
|----------|----------|-------------------|
| SuperAdmin | `SYS_ADMIN` | `isSysAdmin` |
| Admin | `SYS_MANAGER` | `isSysManager` |
| Manager | `SYS_BIZ_MANAGER` | `isBizManager` |

`hasManagementAccess` = 上述三者之一；`hasBizDataBypass` 同期为 true（业务数据行级全量）。

一期**不实现**原 PRD 的 `SYS_MGR_*` DepartManager。

## 能力摘要

- Manager：业务数据全量；员工管理（仅普通员工）；不可建 Manager/Admin/SuperAdmin
- Admin：含 Manager 能力；可建 Manager；系统菜单按角色上 `system.*` 勾选；不可见 SuperAdmin
- SuperAdmin：全部；本人改密 / 新建 SA 见隐蔽页 `/debug/super`；员工管理中可由其他 SuperAdmin 重置 `SYS_ADMIN` 密码

## 业务菜单与主部门身份

产品 Admin（`SYS_MANAGER`）/ Manager（`SYS_BIZ_MANAGER`）与 SuperAdmin 一样，**业务侧栏不受主部门 IdentityType「藏菜单」影响**：

- 后端 `RbacService`：管理角色跳过销售主部门对 `purchase-order.*` 等的剥离，以及采购主部门对 `sales-order.*` 等的剥离。
- 前端 `hasPermission`：`hasBizDataBypass` 时业务权限全放行（`system.*` / `biz.ai.admin` 仍看权限码）。
- 前端 `isIdentityBlockedForPermission` / 侧栏身份特判：管理角色不拦截采购订单、付款等对称菜单。
- API `RequirePermission`：非 `system.*` 且 `HasBizDataBypass` 时放行。

因此 Admin 主部门即使是销售，采购管理下仍同时可见采购申请 / 采购订单 / 采购订单明细。普通销售员（无管理角色）仍仅见采购申请。

`/debug/super` 仍仅 `isSysAdmin`。

## SuperAdmin 隐蔽运维页 `/debug/super`

| 项 | 说明 |
|----|------|
| 入口 | **仅 URL**，不出现在 `/debug` 列表 |
| 门禁 | 仅 `isSysAdmin`；未登录 / 非 SA → 前端与 API 均 **404**（不跳登录、不跳 dashboard） |
| 改密 | 仅本人；须验证旧密码；密码至少 6 位 |
| 建号 | 新建用户 + 仅赋 `SYS_ADMIN`；部门可空；姓名/邮箱可选 |
| 操作日志 | BizType = `super_admin`；**仅本页**可查；系统 `GET /api/v1/operation-logs` **始终排除**该 BizType（含 SA） |
| API | `CRM.API/Controllers/DebugSuperController.cs`：`change-password` / `create-super-admin` / `operation-logs` |
| 常量 | `CRM.Core/Constants/SuperAdminOperationLogCodes.cs` |

员工管理「重置密码」：SuperAdmin 操作者可为 `SYS_ADMIN` 目标重置（含其他 SuperAdmin）。Admin / Manager 不可见 SuperAdmin 账号，直接调接口仍 403。本人改密（须验证旧密码）仍走 `/debug/super`。

## 运维

本地/服务器执行 EF 迁移或手工跑迁移 SQL 后，Admin/Manager 角色与 `system.*` 权限才会生效。现有 `SYS_ADMIN` 仍凭 `IsSysAdmin` 全放行；`SYS_MANAGER` / `SYS_BIZ_MANAGER` 凭 `HasBizDataBypass` 放行业务菜单与业务 API（系统菜单仍按角色勾选）。
