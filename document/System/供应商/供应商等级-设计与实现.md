## 1. 口径

供应商等级为 **S / A / B / C** 四档。**S 最高，C 最低**（未评级默认）。

| 库内 `vendorinfo.Level`（short） | 界面 / 字典名称 |
|------|------|
| 1 | S |
| 2 | A |
| 3 | B |
| 4 | C（默认） |

- 列类型仍为 `short`，**不**改成存字母（与客户等级码表独立：客户仍为 D/C/B/BPO/VIP/VPO）。
- 新建未选、导入空/无法识别、请求缺省或非法码（含 `0`、`5`～`13`），一律落 **C（4）**。
- 存量一次性全部刷成 C，**不**按旧 `1-`～`3+` / 旧 A/B/C/D 映射到新四档。
- 批量刷数 **不**写每条供应商字段变更日志。

---

## 2. 数据字典

`sys_dict_item.Category = VendorLevel`：

| 选项编码 | 中/英文名称 | 排序 | 有效 |
|------|------|------|------|
| 1 | S | 1 | 是 |
| 2 | A | 2 | 是 |
| 3 | B | 3 | 是 |
| 4 | C | 4 | 是 |

历史 `5`～`13`（原 `2`、`2+`、`3-`、`3`、`3+`、旧 A/B/C/D）**删除**。字典管理「状态=全部」也只剩四条；业务下拉仅活跃项。

前端列表/新建走 `useVendorDictStore`（接口只返回 `IsActive=true`）；导入与字典 API 不可用时回退 `VENDOR_LEVEL_OPTIONS`。

---

## 3. 影响范围

| 场景 | 调整 |
|------|------|
| 新建/编辑 | 下拉仅 S/A/B/C，默认 C，不可清空；等级旁问号点击弹出分档说明（含黑名单 D 的业务定义，D 不在下拉里） |
| 列表筛选 / 详情展示 | 选项与列文案为字母 |
| Excel 导入 | 空或无法识别 → C；认 `S/A/B/C` 与 `1`～`4` |
| AI 解析 | 认字母与 1～4；无法识别时保存仍落 C |
| 供应商列表看板、采购分析「供应商」、采购订单列表看板 | 等级饼图扇区为 S/A/B/C/未设置，不再是「等级 n」 |
| 系统字典 | 只维护四条；旧项删除 |
| 客户等级 | **不变** |

## 4. 存量与迁移

| 迁移 | 作用 |
|------|------|
| `20260909120000_VendorLevelSABC` | 全部 `vendorinfo.Level = 4`；字典 1～4 改为 S/A/B/C；删除非 1～4 的 VendorLevel |
| `20260910120000_VendorLevelDeleteLegacyDict` | 幂等再删一次历史字典项（给已执行「仅停用、未删除」的库补跑） |

**API 启动不自动迁移。** 开发库用 `CRM.DbMigrator --apply --force-dev`，或手工执行 §6 SQL。

等价脚本：`scripts/ensure_sys_dict_item_table.sql`（VendorLevel 段）、`scripts/customer_vendor_column_business_comments_postgresql.sql`（列注释）。

## 6. 上线 SQL（PostgreSQL，可重复执行）

本地开发库若已刷过，不必再跑。其它环境在维护窗口执行：

```sql
BEGIN;

UPDATE public.vendorinfo SET "Level" = 4;

COMMENT ON COLUMN public.vendorinfo."Level"
  IS '供应商等级 VendorLevelCode：1=S 2=A 3=B 4=C，默认 4=C';

UPDATE public.sys_dict_item
  SET "NameZh" = 'S', "NameEn" = 'S', "SortOrder" = 1, "IsActive" = true
  WHERE "Category" = 'VendorLevel' AND "ItemCode" = '1';
UPDATE public.sys_dict_item
  SET "NameZh" = 'A', "NameEn" = 'A', "SortOrder" = 2, "IsActive" = true
  WHERE "Category" = 'VendorLevel' AND "ItemCode" = '2';
UPDATE public.sys_dict_item
  SET "NameZh" = 'B', "NameEn" = 'B', "SortOrder" = 3, "IsActive" = true
  WHERE "Category" = 'VendorLevel' AND "ItemCode" = '3';
UPDATE public.sys_dict_item
  SET "NameZh" = 'C', "NameEn" = 'C', "SortOrder" = 4, "IsActive" = true
  WHERE "Category" = 'VendorLevel' AND "ItemCode" = '4';

INSERT INTO public.sys_dict_item ("Id","Category","ItemCode","NameZh","NameEn","SortOrder","IsActive","CreateTime")
SELECT gen_random_uuid()::text, 'VendorLevel', '1', 'S', 'S', 1, true, NOW() AT TIME ZONE 'utc'
WHERE NOT EXISTS (SELECT 1 FROM public.sys_dict_item d WHERE d."Category" = 'VendorLevel' AND d."ItemCode" = '1');
INSERT INTO public.sys_dict_item ("Id","Category","ItemCode","NameZh","NameEn","SortOrder","IsActive","CreateTime")
SELECT gen_random_uuid()::text, 'VendorLevel', '2', 'A', 'A', 2, true, NOW() AT TIME ZONE 'utc'
WHERE NOT EXISTS (SELECT 1 FROM public.sys_dict_item d WHERE d."Category" = 'VendorLevel' AND d."ItemCode" = '2');
INSERT INTO public.sys_dict_item ("Id","Category","ItemCode","NameZh","NameEn","SortOrder","IsActive","CreateTime")
SELECT gen_random_uuid()::text, 'VendorLevel', '3', 'B', 'B', 3, true, NOW() AT TIME ZONE 'utc'
WHERE NOT EXISTS (SELECT 1 FROM public.sys_dict_item d WHERE d."Category" = 'VendorLevel' AND d."ItemCode" = '3');
INSERT INTO public.sys_dict_item ("Id","Category","ItemCode","NameZh","NameEn","SortOrder","IsActive","CreateTime")
SELECT gen_random_uuid()::text, 'VendorLevel', '4', 'C', 'C', 4, true, NOW() AT TIME ZONE 'utc'
WHERE NOT EXISTS (SELECT 1 FROM public.sys_dict_item d WHERE d."Category" = 'VendorLevel' AND d."ItemCode" = '4');

DELETE FROM public.sys_dict_item
WHERE "Category" = 'VendorLevel' AND "ItemCode" NOT IN ('1','2','3','4');

INSERT INTO public."__EFMigrationsHistory" ("MigrationId", "ProductVersion")
SELECT '20260909120000_VendorLevelSABC', '9.0.11'
WHERE NOT EXISTS (
  SELECT 1 FROM public."__EFMigrationsHistory" h
  WHERE h."MigrationId" = '20260909120000_VendorLevelSABC'
);
INSERT INTO public."__EFMigrationsHistory" ("MigrationId", "ProductVersion")
SELECT '20260910120000_VendorLevelDeleteLegacyDict', '9.0.11'
WHERE NOT EXISTS (
  SELECT 1 FROM public."__EFMigrationsHistory" h
  WHERE h."MigrationId" = '20260910120000_VendorLevelDeleteLegacyDict'
);

COMMIT;
```

上线后重启 API，浏览器强刷前端。
