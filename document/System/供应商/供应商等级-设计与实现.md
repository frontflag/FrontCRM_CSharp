## 1. 口径

供应商等级为 **S / A / B / C** 四档。**S 最高，C 最低**（未评级默认）。

| 库内 `vendorinfo.Level`（short） | 界面 / 字典名称 |
|------|------|
| 1 | S |
| 2 | A |
| 3 | B |
| 4 | C（默认） |

列类型仍为 `short`，不改成存字母。客户等级（D/C/B/BPO/VIP/VPO）**不在本改动范围**。

新建未选、导入空等级、请求缺省或非法码，一律落 **C（4）**。

---

## 2. 数据字典

`sys_dict_item.Category = VendorLevel`：

- 启用：`ItemCode` `1`～`4`，名称 S/A/B/C
- 历史 `5`～`13`（原 `2`～`3+`、旧 A/B/C/D）**删除**，字典管理与下拉都不再出现

前端列表/新建走 `useVendorDictStore`（仅活跃项）；导入与 API 不可用时回退 `VENDOR_LEVEL_OPTIONS`。

---

## 3. 存量

迁移 `20260909120000_VendorLevelSABC`：

1. `UPDATE vendorinfo SET "Level" = 4`（含软删，一次刷齐）
2. 更新/补齐字典 1～4，删除其余 VendorLevel
3. 列注释改为 `1=S 2=A 3=B 4=C，默认 4=C`

**不**为每条供应商写字段变更日志。
