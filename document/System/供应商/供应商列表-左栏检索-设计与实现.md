## 1. 业务定位

左栏「检索」用于 **主栏不便直接表达的业务视角条件**（时间桶、关注、待办、报价活跃度、采购成单、在途业务），与主栏 keyword / 身份 / 类型 / 行业 / 采购员 / 结算币别 **共用 URL query**。

| 概念 | 说明 |
|------|------|
| **preset 单选** | 左栏全部选项全局仅一项激活；再点同一项或主栏 preset chip ✕ → **`router.replace` 清空全部 query（含 keyword）** |
| **keyword 叠加** | 选中 preset 时保留：`searchTerm`、`credit`、`ascriptionType`、`industry`、`purchaseUserId`、`currency`（可与 preset 同时生效） |
| **主栏隐藏** | 有 preset 时隐藏与之冲突的主栏控件：**状态**、**创建日期区间** |
| **筛选页签模式** | 结算币别页签/下拉与 preset 可并存（与客户列表一致） |
| **数据权限** | 与列表一致；采购侧 mask511 等对金额/名称的脱敏规则不变 |

左栏 **不提供** 底部「重置」按钮；取消条件仅通过 **再点同一 preset** 或 **主栏 chip ✕**。

**现状：** `VendorSearchPanel.vue` 已清空旧表单；本文档为重构目标。

## 2. preset 列表（定稿，分阶段交付）

共 **18** 项 preset（客户列表为 19 项，供应商关注分组 **无 VIP**）。

### 2.1 时间（供应商创建时间）

锚点：**`vendorinfo.CreateTime`**（与现有 `createdFrom` / `createdTo` 一致）。  
日期格式：**本地日历 `YYYY-MM-DD`**；区间 **含起止日**（与 `VendorListQuery` 后端 `[from, to+1day)` 一致）。

| preset ID | 左栏文案 | 日期区间（本地） |
|-----------|----------|------------------|
| `created_today` | 今日创建的供应商 | 今日～今日 |
| `created_last_7_days` | 近7日创建的供应商 | 今日往前 **6** 天～今日（共 7 个自然日） |
| `created_last_30_days` | 近30日创建的供应商 | 今日往前 **29** 天～今日（共 30 个自然日） |

时间类 **不写** `quickFilter`；由前端展开 `createdFrom` / `createdTo` 写入 URL（展示用保留 `preset`）。

### 2.2 关注

| preset ID | 左栏文案 | 展开 query / API |
|-----------|----------|-------------------|
| `favorite` | 收藏的供应商 | `favoriteOnly=1`（列表请求带当前用户收藏 ID 集合） |

**定稿：** 关注分组 **仅收藏**（不设等级/VIP 类 preset）。

### 2.3 待办

| preset ID | 左栏文案 | 展开 query / API |
|-----------|----------|-------------------|
| `pending_submit` | 待提交供应商 | `status=1`（新建，未提交审核） |
| `pending_audit` | 待审核供应商 | `status=2`（待审核） |

不含草稿 `status=0`。

### 2.4 需求（第二阶段，需后端 `quickFilter`）

左栏分组标题仍为 **「需求」**（与客户结构对称）；选项文案为 **报价** 视角。

**供应商 ↔ 报价行：** `quoteitem.vendor_id` → `vendorinfo`。  
**时间锚点（定稿）：** 主表 **`quote.quote_date`**（经 `quoteitem.quote_id` 关联）。  
**有效报价行（定稿，宽松）：** `quoteitem` 未删除（全局软删过滤）且 `vendor_id` 非空；**不**排除 `quote.status = Closed` 等主单状态。

| preset ID | 左栏文案 | 判定口径（定稿） |
|-----------|----------|------------------|
| `has_quote` | 有报价的供应商 | 存在至少一条有效报价行 |
| `quote_last_7_days` | 近7日发报价的供应商 | 存在 **任意一条** 报价行，其主单 `quote_date` 落在近 7 个自然日内 |
| `quote_last_30_days` | 近30日发报价的供应商 | 同上，近 30 日 |
| `quote_stale_6m` | 半年前发报价的供应商 | 曾有报价行，且近 **6** 个月无 `quote_date` 不早于 cutoff 的新报价 |
| `quote_stale_1y` | 1年前发报价的供应商 | 同上，锚点 **12** 个月 |

「近 N 日」= **窗口内至少有一条**（与客户 RFQ 口径一致，非「最近一条落在窗口内」）。

**quickFilter 切日：** 与客户 `CustomerListQueryQuickFilter` 一致，后端以 **UTC 日历日** 构造 `[startInclusive, endExclusive)`；与主栏手动 `createdFrom/To`（前端本地日展开）为两条路径。

### 2.5 成单（第二阶段，需后端 `quickFilter`）

左栏分组标题 **「成单」**；选项文案为 **采购** 视角。

锚点：**采购订单 `purchaseorder.CreateTime`**。  
**有效采购单（定稿）：** 与 `VendorsController.IsCommercialPurchaseOrder` 一致：

```csharp
Status >= 10 && Status != -1 && Status != -2
```

| preset ID | 左栏文案 | 判定口径（定稿） |
|-----------|----------|------------------|
| `has_purchase` | 有采购的供应商 | 存在至少一条有效采购单 |
| `purchase_last_7_days` | 近7日采购的供应商 | 存在 PO `CreateTime` 落在近 7 个自然日内 |
| `purchase_last_30_days` | 近30日采购的供应商 | 同上，近 30 日 |
| `purchase_stale_6m` | 半年前采购的供应商 | 曾有有效采购，近 6 个月无新 PO |
| `purchase_stale_1y` | 1年前采购的供应商 | 同上，12 个月 |

### 2.6 业务（第三阶段，需后端 `quickFilter`）

与 **`GET /api/v1/vendors/statistics`** 口径对齐（commercial PO 子集）：

| preset ID | 左栏文案 | 判定口径（定稿） |
|-----------|----------|------------------|
| `pending_inbound` | 待入库的供应商 | 存在有效 PO 且 **`StockStatus < 2`**（未全部入库） |
| `has_payable` | 应付款的供应商 | 存在有效 PO 且 **`FinanceStatus < 2`**（未全部付款） |

## 3. 交互与 UI（对齐客户列表）

### 3.1 左栏 `VendorSearchPanel`

| 项 | 规则 |
|----|------|
| 布局 | 标题「供应商检索」+ 分组（时间 / 关注 / 待办 / 需求 / 成单 / 业务）+ 纵向全宽按钮 |
| 样式 | 与 `CustomerSearchPanel.vue` / `SalesOrderItemSearchPanel.vue` 一致 |
| 点击未激活项 | `router.replace`：保留 keyword 区 query → 写入 `preset` + 展开字段或 `quickFilter` |
| 点击已激活项 | `router.replace({ query: {} })`，**清空全部 query** |
| 单选 | 任意时刻最多一个 preset |

### 3.2 主栏 `VendorList`

| 项 | 规则 |
|----|------|
| preset chip | 有 `preset` 时在筛选区顶部展示文案 + ✕ |
| 隐藏控件 | 有 preset 时隐藏：**状态下拉**、**创建日期区间** |
| 保留控件 | 关键词、等级、身份、类型、行业、采购员、结算币别（及结算币别页签模式） |
| 主栏「重置」 | 清空全部 query（含 preset、keyword） |
| 路由 | 左栏与 chip 使用 **`router.replace`** |

### 3.3 与筛选页签模式

- 有 preset 时：**不**隐藏结算币别页签条/下拉。
- preset 与 `crm.vendor-list.tab-mode` 独立；清空 query 不清 localStorage 页签偏好。

## 4. URL query 约定

| 键 | 说明 |
|----|------|
| `preset` | 当前左栏 preset ID |
| `quickFilter` | 第二、三阶段业务类 preset 对应后端码（时间/关注/待办类不写） |
| `createdFrom` / `createdTo` | 时间类 preset 展开，或主栏手动日期 |
| `status` / `favoriteOnly` | 待办/关注类 preset 展开 |
| keyword 区 | `searchTerm`、`credit`、`ascriptionType`、`industry`、`purchaseUserId`、`currency` |

**驱动链：** 左栏点击 / 主栏查询 / chip ✕ / 重置 → `router.replace` → `watch(route.query)` → 同步表单 → 列表请求。

## 6. 后端实现（第二、三阶段）

| 文件 | 职责 |
|------|------|
| `CRM.Core/Constants/VendorListQuickFilterCodes.cs` | 12 个业务码 + `IsKnown` |
| `CRM.Core/Interfaces/IVendorService.cs`（`VendorQueryRequest`） | `QuickFilter` |
| `CRM.Infrastructure/Vendors/VendorListQuery.cs` + `VendorListQueryQuickFilter.cs` | EF 子查询 |
| `CRM.API/Controllers/VendorsController.cs` | `GET vendors` 透传 `quickFilter` |

**互斥规则：** 已知 `quickFilter` 时，忽略手动 `status` / 创建日区间（与客户列表一致）。

**数据权限：** quickFilter 子查询 **不**单独套报价/PO 采购权限；筛选后在 `VendorListQuery` 末尾仍执行 **`ApplyVendorListDataScopeAsync`**（与客户 `CustomerListQuery` + RFQ/SO 子查询策略一致）。

### 6.1 EF 子查询要点（实现备忘）

**报价类：**

```text
EXISTS quoteitem qi
  JOIN quote q ON qi.quote_id = q.QuoteId
WHERE qi.vendor_id = vendor.Id
  AND qi 未删除 AND qi.vendor_id 非空
  AND q.quote_date 满足窗口 / stale 条件
```

**采购类：**

```text
EXISTS purchaseorder po
WHERE po.vendor_id = vendor.Id
  AND commercial 条件
  AND po.CreateTime 或 po.StockStatus / po.FinanceStatus 满足 preset
```
