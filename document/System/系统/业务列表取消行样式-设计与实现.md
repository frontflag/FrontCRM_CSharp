# 业务列表取消行样式 — 设计与实现

**状态：** 已上线  
**规范：** [业务列表规范 §3.5](../../PRD/规范/UI规范/业务列表规范.md)  
**测试对照：** [业务列表取消行样式-测试对照说明](../../QA/系统/业务列表取消行样式-测试对照说明.md)  
**帮助：** 销售订单、采购订单、销售订单明细、采购订单明细各帮助页「页面功能」

---

## 1. 目标

销售订单、采购订单及其明细列表：主单为 **取消** 时整行文字弱化（浅灰），便于扫读已作废单据。**审核失败不变灰。** 不是禁用行。

| 页面 | 判定字段 | 说明 |
|------|----------|------|
| 销售订单 `/sales-orders` | 主单 `status` | 仅 `-2` |
| 采购订单 `/purchase-orders` | `normalizePurchaseOrderMainStatus(row)` | 仅 `-2` |
| 销售订单明细 `/sales-order-items` | `orderStatus`（主单状态） | **不看**明细行状态 |
| 采购订单明细 `/purchase-order-items` | `orderStatus`（主单状态） | 主单已取消、明细仍为已确认等时 **同样变灰** |

看板模式、打印页、详情内嵌表明细表 **不在本范围**。其它业务列表（入库、付款等）本期不套用。

---

## 2. 视觉与交互

| 项 | 约定 |
|----|------|
| 弱化 | 数据格文字、单号 `el-link`、金额拆段、币别色 → `$text-muted` |
| 保持原色 | **状态等 `el-tag`**（须仍能认出「取消」）；**操作列**按钮 |
| 交互 | 单击、双击、操作列照常 |
| 选中优先 | `.crm-list-row--clicked`、`.current-row`、`.so-item-row--active` 时 **不**套灰字 |
| 悬停 | 沿用现有行悬停底，不做成禁用态 |

详情页标题取消时已有 `page-title--muted`，与列表行 class **不是**同一套，勿混用。

---

## 3. 实现

行 class：`list-row--cancelled`（`LIST_ROW_CANCELLED_CLASS`）。

`CrmDataTable` 的 `mergeCrmListRowClassName` 会再拼 `crm-list-row--clicked`，取消 class 须与之并存；选中时由 CSS `:not(.crm-list-row--clicked)` 去掉灰字。

| 层 | 位置 |
|----|------|
| 判定 helper | `CRM.Web/src/utils/listCancelledRow.ts` |
| 样式 | `CRM.Web/src/assets/styles/crm-unified-list.scss`（`.crm-items-table` 内） |
| 销售订单列表 | `SalesOrderList.vue` `salesOrderListRowClassName` |
| 采购订单列表 | `PurchaseOrderList.vue` `purchaseOrderListRowClassName` |
| 销售/采购明细列表 | 现有 `opsPanelRowClassName` **拼接**取消 class + `so-item-row--active`（`joinRowClassNames`） |
| 前端单测 | `CRM.Web/src/tests/list-cancelled-row.test.ts` |

无新 API、无新权限、无迁移。
