## 1. 目标与非目标

### 1.1 目标

1. SuperAdmin 在运维「消息通知管理」给指定启用员工发送一条通知（发送即落库）。  
2. 接收人在顶栏铃铛抽屉「系统消息」查看；点「查看」即记已读。  
3. 铃铛角标 = 未读系统通知 + 未读系统公告；超过 20 显示 `20+`。  
4. 仅当存在 **未读且重要** 的系统通知时铃铛摇动；仅有未读公告不摇。  
5. 打开抽屉时：有未读系统通知默认「系统消息」，否则「系统公告」。  
6. 模拟登录不摇、不记已读、角标按 0。

### 1.2 非目标（本期不做）

| 项 | 说明 |
|----|------|
| 改已发 / 撤回 | 发送后不可改、不可删 |
| 群发 / 全员 | 一次一人 |
| 附件 / Markdown | 纯文本，标题 100、正文 4000 |
| 强制弹窗挡登录 | 不做 |
| 草稿 | 无草稿状态 |

## 2. 数据

表 `sys_user_notice`：一对一行，不预插全员。

| 列 | 说明 |
|----|------|
| `id` | GUID |
| `recipient_user_id` | 接收人 |
| `is_urgent` | 重要（界面文案；库列名不变） |
| `title` / `body` | 标题 / 正文 |
| `sender_user_id` | 发送人 |
| `create_time` | 发送时间（UTC） |
| `read_at` | 可空；空=未读 |

接收人下拉：`IsActive` 且 `Status=1`（启用）。

---

## 3. API

**管理（SuperAdmin）**

- `GET /api/v1/ops/user-notices/recipients`
- `GET /api/v1/ops/user-notices`（重要、已读、接收人、标题/正文、发送日区间、分页）
- `GET /api/v1/ops/user-notices/{id}`（看正文，**不**改对方已读）
- `POST /api/v1/ops/user-notices`

**用户**

- `GET /api/v1/me/user-notices`
- `GET /api/v1/me/user-notices/unread-summary` → `{ unreadCount, hasUnreadUrgent }`（模拟登录返回 0）
- `GET /api/v1/me/user-notices/{id}`
- `POST /api/v1/me/user-notices/{id}/read`（模拟登录不写 `read_at`）

前端角标约 60 秒轮询一次摘要。
