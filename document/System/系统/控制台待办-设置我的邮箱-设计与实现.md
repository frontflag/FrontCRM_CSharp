## 1. 业务定位

控制台在统计卡下方增加 **待办** 面板。与顶部「待处理事项」数字（待审批条数）**分开**，不计入该数字。当前子任务：

1. **设置我的邮箱**（全体登录用户）
2. **用户反馈**（仅系统管理员）

无任何子任务时，整块「待办」隐藏。

---

## 2. 设置我的邮箱

| 项 | 口径 |
|----|------|
| 出现条件 | 当前用户没有任何 **验证成功** 的邮箱（平台或其他均可） |
| 消失条件 | 至少一条 `verifyStatus=ok` |
| 接口失败 | 仍显示引导（宁可多提示） |
| 加载中 | 不闪出该子任务 |
| 跳转 | `/profile/mailbox?from=/dashboard` |
| 权限 | 登录即可，无额外权限码 |

判断复用 `GET /api/v1/me/mails/summary` 的 `hasVerifiedMailbox`。

---

## 3. 用户反馈（系统管理员）

| 项 | 口径 |
|----|------|
| 可见角色 | **仅** `isSysAdmin`（系统管理员 / `SYS_ADMIN`）。仅有 `biz.feedback.admin` 的非 SA **不**显示 |
| 出现条件 | 存在 `needsHandling=true` 的用户反馈（与运维列表「需处理」一致） |
| 消失条件 | 需处理条数为 0；非系统管理员永不显示 |
| 展示 | 标题「用户反馈」+ 条数；说明「当前有 N 条需处理的反馈」 |
| 跳转 | `/ops/user-feedback?handling=need`（列表预选「需处理」） |
| 计数接口 | `GET /api/v1/feedback/admin?needsHandling=true&page=1&pageSize=1`，读 `total` |
| 接口失败 | **不**显示该子任务（不假装有待办） |
| 加载中 | 计数未返回前不闪出 |
| 回页刷新 | `onActivated` 重拉计数 |

不改 `user_feedback` 表；不新增权限码。
