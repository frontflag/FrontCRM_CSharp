## 1. 目标与非目标

### 1.1 目标

1. 用 **IMAP** 从已验证个人/平台邮箱拉取 **INBOX** 邮件，落库可检索元数据与正文。  
2. 全租户一份 **最早同步邮件日期**（公司邮箱设置 `MailSyncEarliestDate`）：不拉取该日 00:00 Asia/Shanghai 之前的邮件。  
3. **每日 08:30（Asia/Shanghai）** 自动同步所有有已验证 IMAP 邮箱的用户；支持「我的邮件」页手工「读取邮件」。  
4. 侧栏「我的」增加「我的邮件」：工作台布局、筛选、列表、查看（本地标已读）。  
5. **写新信 / 回复**占主区（`viewMode=compose`），经 `IEmailSender` 用登录用户**默认平台邮箱** SMTP 发出。  
6. **删除**只标本地 `user_mail_message.is_deleted`，**不写回 IMAP**。  
7. 右栏「内容提取」把当前邮件正文交给已有 `entity.parse.rfq` 流程，确认后进入新建需求。

### 1.2 非目标（本期不做）

| 项 | 说明 |
|----|------|
| 抄送落库 | 摘要抄送显示「—」 |
| 附件下载落盘 | 仅 `has_attachments` 标记；发信不带附件 |
| 已发送写回 IMAP | 发出的信只落本系统 `folder=SENT`，不写服务器已发送 |
| 草稿写回 IMAP | 草稿只落本系统 `folder=DRAFT`，不写服务器草稿箱 |
| 多文件夹 / 写回服务器已读 | 仅 INBOX；不改服务器 `\Seen`；不删服务器邮件 |
| Hangfire / 外部队列 | `BackgroundService` 对齐现有清理任务 |
| POP 收信 | 库列保留；UI/校验/同步均用 IMAP |

```text
CRM.Web
  我的/我的邮件 → MyMailsPage / useMyMailsWorkspace → /api/v1/me/mails/*
  右栏 MailFunctionPanel → AiEntityCreateHost（entity.parse.rfq）
  profile/mailbox → IMAP 配置与默认发信邮箱

  MeMailsController（列表/同步/本地已读/本地删/SMTP 发送）
  IEmailSender / SmtpEmailSender（默认平台邮箱）
  UserMailSyncService（手工 + 定时）
  MailSyncHostedService（每日 08:30 Asia/Shanghai）
  MailboxVerifyService（ImapClient）
DB
  user_mailbox（imap_*）
  user_mail_message（软删 IsDeleted）
  user_mailbox_sync_state
  mail_sync_daily_run
  Company.Profile.SmtpEmail JSON（smtp* + imap* + mailSyncEarliestDate）
```

权限：个人功能，`[Authorize]` + 按当前用户隔离（同 `MeMailboxesController`）。

## 3. 配置与凭证

### 3.1 公司邮箱设置（JSON `Company.Profile.SmtpEmail`）

| 字段 | 说明 |
|------|------|
| `imapHost` / `imapPort` / `imapUseSsl` | 租户 IMAP；平台邮箱收信用；端口默认 993 |
| `mailSyncEarliestDate` | 最早同步日（date）；缺省则同步服务拒绝并记错误 |
| `smtp*` / `enabled` / `platformEmailSuffix` | 发信与后缀，不变 |
| `pop*` | 兼容旧数据；加载时若无 IMAP 可从 POP 回填展示 |

公司信息「公司邮箱」页签：文案为 SMTP/IMAP；增加「最早同步邮件日期」。

### 3.2 个人邮箱 `user_mailbox`

| 列 | 说明 |
|----|------|
| `imap_host` / `imap_port` / `imap_use_ssl` | **personal** 自填；**platform** 用公司 IMAP |
| `pop_*` | 保留列，UI 不再使用 |

同步资格：`verify_status=ok` 且能解析到非空 IMAP 主机（平台取公司配置）。

改 IMAP 主机/端口/SSL/密码后：验证状态回退未验证，须重新验证才可同步。

### 3.3 校验

`MailboxVerifyService`：收信步骤 `ImapClient` 连接/认证/打开 `Inbox`；平台仍附 SMTP 测试信。旧 POP 字段可作 IMAP 回退。

## 4. 落库表

### 4.1 `user_mail_message`

| 要点 | |
|------|--|
| 归属 | `user_id` + `mailbox_id` |
| 去重 | 唯一 `(mailbox_id, folder, imap_uid)`（未删） |
| 内容 | `subject`、`from_*`、`to_addresses`、`received_at`、`is_unread`、`is_starred`、`remark`(≤2000)、`snippet`(≤500)、`body_text`/`body_html`、`has_attachments`、`size_bytes` |
| 文件夹 | IMAP 同步仅 `INBOX`；本系统另有 `SENT` / `DRAFT` |

### 4.2 `user_mailbox_sync_state`

每邮箱：`last_sync_at` / `last_success_at` / `last_error` / `last_uid_validity`。

### 4.3 `mail_sync_daily_run`

按 Asia/Shanghai 日期键 `run_date`（yyyy-MM-dd），多实例防重复全量扫。

## 5. 同步服务

`IUserMailSyncService` / `UserMailSyncService`：

- 输入：`userId` + 可选 `mailboxId`（空=该用户全部可同步邮箱）。  
- 仅 INBOX；日期下界 = 公司 `MailSyncEarliestDate`（上海日 00:00）。  
- IMAP Search：`Since` / DeliveredAfter + 优先未读（`UNSEEN`）。  
- Upsert 按 `(mailbox_id, folder, imap_uid)`；更新未读/摘要/正文；**不覆盖**本地 `is_starred` / `remark`。  
- **不**删服务器邮件；**不**改服务器已读 / 星标 / 备注。  
- 密码：`MailboxPasswordCipher` 解密。  
- 单邮箱失败不阻断其他；写 `sync_state.last_error`。

`MailSyncHostedService`：每分钟检查；本地日刚过 08:30 且当日 `mail_sync_daily_run` 未完成则扫用户逐个同步。

## 6. API（`/api/v1/me/mails`）

| 方法 | 用途 |
|------|------|
| `GET /summary` | 全部数、未读数；是否有已验证邮箱 |
| `GET /mailboxes` | 已验证邮箱下拉 |
| `GET /address-book` | 通讯录：客户/供应商联系人（有邮箱），`q` 姓名/邮箱/公司名；数据范围同列表 |
| `GET /` | 分页列表：邮箱、`q`（标题/发件人/正文/摘要/备注/收件人）、`isUnread`、`isStarred`、`hasRemark`、`folder=inbox\|sent\|draft\|deleted`、收件日区间 |
| `GET /{id}` | 详情（含已删除） |
| `POST /sync` | `{ mailboxId?: string \| null }` 手工同步；**跳过**本地已软删的同一 UID |
| `POST /{id}/read` | 本地标记已读（查看时调用） |
| `POST /read-all` | `{ mailboxId, folder? }` 将当前邮箱当前文件夹全部未读标为已读；不写回 IMAP |
| `POST /{id}/star` | `{ starred }` 本地星标；收件箱/已发送/已删除均可；不写回 IMAP |
| `POST /{id}/remark` | `{ remark }` 保存本地备注，空内容拒绝 |
| `POST /{id}/remark/clear` | 清除本地备注 |
| `DELETE /{id}` | 本地软删（`IsDeleted=true`），不写回 IMAP |
| `POST /{id}/restore` | 恢复到收件箱（清软删标记） |
| `POST /send` | `{ To, Cc?, Subject, Body, InReplyToMailId?, DraftId? }`：默认平台邮箱 SMTP 发出；带 `DraftId` 时发信后删除该本地草稿 |
| `POST /drafts` | `{ id?, mailboxId, to?, cc?, subject?, body?, inReplyToMailId? }` 本地保存/更新草稿，不写回 IMAP |

## 7. 前端

- 菜单：`AppLayout`「我的」→「我的邮件」→ `/my/mails`；i18n `layout.menu.myMails`。  
- 页面：`CRM.Web/src/views/My/MyMailsPage.vue`；共享状态 `useMyMailsWorkspace`。  
- API：`CRM.Web/src/api/myMails.ts`。  
- 无已验证邮箱：提示并跳转 `profileMailboxLocation('/my/mails')`。  
- 「收信 / 读取邮件」直接同步左栏下拉当前选中的邮箱（`POST /sync`，带 `mailboxId`），不再弹窗选择；并切到收件箱列表。  
- 主区 `viewMode`：`list` \| `body` \| `compose`。单击选中行；双击进正文并本地已读。返回回列表。  
- **写邮件**（列表工具栏）：进入 `compose` 空白稿；「发件人」只读纯文本，展示左栏当前选中邮箱地址。收件信息（发件人/收件人/抄送）与主题正文分属独立面板。可「保存草稿」落本系统 `folder=DRAFT`；再次保存更新同一封。  
- **草稿箱**：左栏可点；双击草稿回到写信页继续编辑；发出后删除该草稿。不写回 IMAP。  
- **回复**（正文工具栏）：收件人=原发件人，主题补 `Re:`，正文引用原文；`InReplyToMailId` 带原信 `Message-Id`。  
- **删除**（正文工具栏，收件箱）：确认后 `DELETE /{id}`，进本系统「已删除」。  
- **恢复到收件箱**（正文工具栏，已删除）：`POST /{id}/restore`。  
- 左栏邮箱下拉：有已验证邮箱时默认选第一项；记住当前用户最后选择（`localStorage` `crm-my-mails-mailbox:v1:{userId}`），下次进入 `/my/mails` 恢复；不可清空为「全部」。无已配置邮箱时该格显示「请设置个人邮箱」并跳转 `profileMailboxLocation('/my/mails')`，同时写信/收信/通讯录、文件夹、筛选全部禁用。  
- 左栏文件夹：`收件箱 （{未读}）`（0 也带括号）、草稿箱可点（本系统未发稿）、已发送可点（本系统发出的信）、已删除可点。未读数只统计收件箱。  
- 左栏「邮箱功能」：写信、收信、通讯录（主区列表：联系人名称 / 邮箱 / 客户/供应商；单击选中，双击写信并预填收件人）。主区「写邮件」「读取邮件」仍保留。  
- **内容提取**（右栏 `r-mail-fn`）：需权限 `biz.ai.entity.parse.rfq`，且已选中/打开一封邮件；取正文（无 `bodyText` 则剥 HTML）→ `AiEntityCreateHost.openWithText` → 确认弹窗 → `RFQCreate`。  
- 正文：邮件头（标题/发件人/时间/收件人/抄送）与邮件备注各自独立面板；中间为正文与签名档。正文 DOMPurify 后按 HTML 原样式渲染；无 HTML 则纯文本。签名档仍空态。抄送显示「—」。

### 7.1 工作台页签（`MyMails`）

| 侧 | Tab ID | 页签名 | 组件 |
|----|--------|--------|------|
| 左 | `l-mailbox` | 邮箱 | `MailMailboxMenuPanel`（邮箱选择 / 文件夹 / 筛选） |
| 左 | `l-mail-list` | 收件列表 | `MailInboxCardList`（与主区同源卡片） |
| 右 | `r-mail-fn` | 邮箱功能 | `MailFunctionPanel`（内容提取 → AI 解析 RFQ；当前信有备注时在下方显示只读「邮件备注」） |
| 右 | `r4` | 帮助 | `HelpManualPanel` |

进入页默认左 `l-mailbox`、右 `r-mail-fn`。不用 `l1`/`r-ops`，避免工作台规范把展开强制切到检索/操作。

主区列表列：未读/已读图标、星标（无表头，点击切换）、发件人、标题（后附浅灰 `snippet` 摘要）、备注、发送日期。列表底栏左侧「设置全部已读」将当前邮箱当前文件夹全部未读标为已读（不限当前页）。正文页邮件头、邮件备注各为独立面板：有内容才可「保存备注」；已有备注才可「清除备注」（确认后清空）。左栏筛选为纵向菜单：全部 / 未读 / 已读 / 星标 / 备注 + 日期。星标/备注筛选项只出当前文件夹下对应邮件。左侧收件卡片本期不显示星标、备注。

## 8. 验收要点

- 公司配 IMAP + 最早日期后，平台邮箱验证走 IMAP。  
- 个人其他邮箱填 IMAP 并验证成功后可同步。  
- 未配最早日期：同步失败并有明确错误。  
- 手工/定时均不拉取最早日之前邮件。  
- `/my/mails` 工作台可筛选、查看、本地已读；服务器邮件不变。  
- 写新信 / 回复占主区发出；无默认已验证平台邮箱时接口拒绝（`IEmailSender` 错误码）。  
- 删除后收件箱不再出现该信，可在「已删除」查看并恢复；IMAP INBOX 原信仍在。同步不会把本地已删的同一封再插回收件箱。  
- 有 `entity.parse.rfq` 权限时可从当前邮件抽出需求并进入新建 RFQ。  
- 当日 08:30 后仅跑一批（`mail_sync_daily_run`）。  
- 左「邮箱 / 收件列表」、右「邮箱功能 / 帮助」页签可用；双击进正文，返回回列表。  
- 有已验证邮箱时左栏下拉默认第一项并记住上次选择；无邮箱时显示「请设置个人邮箱」并禁用该面板其余功能。  
- 主区可给当前行加/取消星标；左栏「星标」只列出带星邮件；同步不丢星标。  
- 正文可保存/清除本地备注；列表显示备注；左栏「备注」只列出有备注的邮件；同步不丢备注。  
- 主区关键字搜索匹配标题、发件人、正文、摘要与本地备注；占位提示含「备注」。  
- 列表底栏「设置全部已读」可将当前邮箱当前文件夹全部未读标为已读；不写回 IMAP。  
- 写邮件可保存本地草稿；左栏草稿箱可打开续写；发出后草稿从本系统删除。
