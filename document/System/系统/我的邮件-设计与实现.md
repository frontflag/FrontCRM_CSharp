## 1. 目标与非目标

### 1.1 目标

1. 用 **IMAP** 从已验证个人/平台邮箱拉取 **INBOX**，落库可检索元数据与正文。  
2. 全租户一份 **最早同步邮件日期**（`MailSyncEarliestDate`）：不拉取该日 00:00 Asia/Shanghai 之前的邮件。  
3. **每日 08:30（Asia/Shanghai）** 自动同步；「收信 / 读取邮件」手工同步**当前选中邮箱**并切到收件箱列表。  
4. 工作台：筛选、列表、查看、本地已读 / 星标 / 备注 / 全部已读。  
5. **写新信 / 回复 / 本地草稿**占主区；SMTP 用登录用户**默认平台邮箱**发出。  
6. **删除**只标本地 `is_deleted`，不写回 IMAP。  
7. 右栏「内容提取」把当前正文交给 `entity.parse.rfq`，确认后进新建需求。

### 1.2 非目标（本期不做）

| 项 | 说明 |
|----|------|
| 正文页抄送展示 | 正文页抄送显示「—」；草稿的抄送存在本系统，写信页可续填 |
| 附件下载落盘 | 仅 `has_attachments`；发信不带附件 |
| 已发送 / 草稿写回 IMAP | 只落本系统 `SENT` / `DRAFT` |
| 写回服务器已读 / 星标 / 删除 | 不同步 `\Seen`、星标、删服务器邮件 |
| Hangfire / 外部队列 | `BackgroundService` 对齐现有清理任务 |
| POP 收信 | 库列保留；UI/校验/同步均用 IMAP |

侧栏菜单「草稿箱」（客户/供应商/RFQ）与邮件草稿箱无关。

## 3. 配置与凭证

见 [个人邮箱与公司邮箱设置-设计与实现](./个人邮箱与公司邮箱设置-设计与实现.md)。要点：

- 公司：IMAP 主机/端口/SSL + 最早同步日 + SMTP。  
- 个人：已验证才可同步；平台邮箱验 IMAP + SMTP；其他邮箱只收不发。  
- 改 IMAP/密码后验证状态回退，须重验。  
- 发信：`IEmailSender` 使用用户 **默认已验证平台邮箱**；展示「发件人」用左栏选中地址，二者可以不同。  
- SMTP 465 必须 `SslOnConnect`，其它端口 STARTTLS（`SmtpSecureOptions`）。

## 4. 落库

### 4.1 `user_mail_message`

| 要点 | |
|------|--|
| 归属 | `user_id` + `mailbox_id` |
| 去重 | 唯一 `(mailbox_id, folder, imap_uid)`（未删） |
| 内容 | `subject`、`from_*`、`to_addresses`、`received_at`、`is_unread`、`is_starred`、`remark`(≤2000)、`snippet`(≤500)、`body_text`/`body_html`、`has_attachments` |
| 文件夹 | IMAP 仅写 `INBOX`；本系统另有 `SENT`、`DRAFT`；软删用 `is_deleted`，不改 `folder` |

`SENT` / `DRAFT` 的 `imap_uid` 为本地随机值，不对应服务器 UID。

### 4.2 草稿收件人存储（例外）

写信页「收件人」「抄送」是两个字段，表上暂无独立抄送列。本期把二者打进 `to_addresses`：

`{收件人}\n--cc--\n{抄送}`

详情接口对 `folder=DRAFT` 拆回 `toAddresses` / `ccAddresses`。回复关系记在 `message_id`：`draft-in-reply:{原信Id}`。

此为 [系统设计规范](../系统设计规范.md)「禁止单字段拼接多语义」的**已立项例外**。后续应加 `cc_addresses`（及明确的 in-reply 列）再迁出拼接。已发送仍把 to+cc 用 `; ` 拼在 `to_addresses`（正文页抄送不展示）。

### 4.3 其它表

- `user_mailbox_sync_state`：每邮箱同步时间与错误、UIDVALIDITY。  
- `mail_sync_daily_run`：上海日历日 `yyyy-MM-dd`，多实例防重。

## 5. 同步

`IUserMailSyncService` / `UserMailSyncService`：

- 输入：`userId` + 可选 `mailboxId`（空=该用户全部可同步邮箱）。手工收信始终带当前下拉 `mailboxId`。  
- 仅 INBOX；日期下界 = 公司最早同步日（上海 00:00）。  
- Search：`Since` / DeliveredAfter + 优先 `UNSEEN`。  
- Upsert `(mailbox_id, folder, imap_uid)`；更新未读/摘要/正文；**不覆盖** `is_starred` / `remark`。  
- **跳过**本地已软删的同一 UID，避免再插回收件箱。  
- 不改服务器已读 / 星标 / 删除。  
- 单邮箱失败不阻断其它。

`MailSyncHostedService`：每分钟检查；本地日过 08:30 且当日 run 未完成则逐用户同步。

## 6. API（`/api/v1/me/mails`）

| 方法 | 用途 |
|------|------|
| `GET /summary` | 收件箱全部数、未读数；是否有已验证邮箱 |
| `GET /mailboxes` | 已验证邮箱下拉 |
| `GET /address-book` | 通讯录：有邮箱的客户/供应商联系人；`q` 姓名/邮箱/公司；数据范围同列表权限 |
| `GET /` | 分页：`mailboxId`、`q`（标题/发件人/正文/摘要/备注/收件人）、`isUnread`、`isStarred`、`hasRemark`、`folder=inbox\|sent\|draft\|deleted`、收件日区间 |
| `GET /{id}` | 详情（含已删除）；草稿拆分 to/cc |
| `POST /sync` | `{ mailboxId }` 手工同步当前邮箱 |
| `POST /{id}/read` | 本地已读 |
| `POST /read-all` | `{ mailboxId, folder? }` 当前邮箱当前文件夹全部未读 → 已读 |
| `POST /{id}/star` | `{ starred }` 本地星标 |
| `POST /{id}/remark` | `{ remark }` 非空，≤2000 |
| `POST /{id}/remark/clear` | 清除备注 |
| `DELETE /{id}` | 软删 |
| `POST /{id}/restore` | 清软删；`folder` 不变（草稿仍回草稿箱） |
| `POST /send` | `{ To, Cc?, Subject, Body, InReplyToMailId?, DraftId? }` SMTP 发出后落 `SENT`；有 `DraftId` 则删除该草稿 |
| `POST /drafts` | `{ id?, mailboxId, to?, cc?, subject?, body?, inReplyToMailId? }` 至少一项非空；无 `id` 新建，有则更新 |

## 7. 前端

### 7.1 入口与状态

- 菜单：`AppLayout`「我的」→「我的邮件」；路由名 `MyMails`。  
- 页面 `CRM.Web/src/views/My/MyMailsPage.vue`；共享状态 `useMyMailsWorkspace`；API `CRM.Web/src/api/myMails.ts`。  
- `viewMode`：`list` \| `body` \| `compose` \| `contacts`。  
- 邮箱记忆：`localStorage` `crm-my-mails-mailbox:v1:{userId}`。  
- 无邮箱：`profileMailboxLocation('/my/mails')`。

### 7.2 工作台页签

| 侧 | Tab ID | 页签名 | 组件 |
|----|--------|--------|------|
| 左 | `l-mailbox` | 邮箱 | `MailMailboxMenuPanel` |
| 左 | `l-mail-list` | 收件列表 | `MailInboxCardList`（同源卡片；本期无星标/备注/摘要） |
| 右 | `r-mail-fn` | 邮箱功能 | `MailFunctionPanel`（内容提取；有备注则下方只读） |
| 右 | `r4` | 帮助 | `HelpManualPanel` |

进入默认左 `l-mailbox`、右 `r-mail-fn`。不用 `l1`/`r-ops`。

### 7.3 左栏

- 邮箱下拉：已验证、默认第一项、记住上次、不可清空。  
- 功能：写信、收信、通讯录。收信同步当前邮箱并 `viewMode=list`、`folder=inbox`。  
- 文件夹：收件箱（未读括号）、草稿箱、已发送、已删除。选中项底色 `#e5fbff`。  
- 筛选：纵向 全部 / 未读 / 已读 / 星标 / 备注 + 日期。

### 7.4 主区列表

- 列：已读图标(40)、星标(40)、发件人(200)、标题（剩余宽度，后附浅灰 `snippet`）、备注(140)、日期(170)。  
- 未读只加粗标题/发件人/日期，摘要不加粗。无摘要不显示单独的 `-`。  
- 工具栏：左搜索+查询；右「读取邮件」「写邮件」。  
- 底栏左：「设置全部已读」（文字色 `#1a3a5c`，同左栏「写信」）。  
- 单击选中；双击正文（草稿双击写信）。

### 7.5 正文

- 工具栏左右分置：左返回；右删除（或恢复）+ 蓝色回复。已发送/草稿不显示回复。  
- 独立面板：邮件头（标题/发件人/时间/收件人/抄送—）；中间正文+签名档（无线框）；底部邮件备注。  
- 正文 DOMPurify 后按 HTML 渲染；无 HTML 则纯文本。签名档空态。  
- 备注：有草稿才可保存；有已存备注才可清除（确认）。输入框白底。

### 7.6 写信 / 回复 / 草稿

- 发件人只读 = 左栏选中地址。  
- 两块面板（底 `#F8F9FB`，输入框白）：收件信息；主题+正文（输入框拉满面板）。  
- 工具栏：左返回；右保存草稿、发送、（已有草稿时）删除。  
- 回复：To=原 From，主题 `Re:`，正文引用，`InReplyToMailId`。  
- 保存草稿至少 to/cc/subject/body 之一；再保存带 `id`。发送带 `draftId`，成功后删草稿并切已发送。

### 7.7 通讯录

主区表：联系人名称 / 邮箱 / 客户或供应商。单击选中，双击写信预填 To。范围走客户/供应商列表数据权限。

## 9. 验收要点

- 公司配 IMAP + 最早日期后，平台邮箱验证走 IMAP。  
- 未配最早日期：同步失败并有明确错误。  
- 手工/定时均不拉取最早日之前邮件。  
- 无已验证邮箱时引导「我的邮箱」，功能禁用。  
- 收信只同步当前邮箱并回到收件箱列表。  
- 打开未读 → 本地已读；「设置全部已读」清当前文件夹未读。  
- 星标/备注同步后仍在；搜索能命中备注。  
- 草稿可保存、续写；发出后草稿删除、已发送可见。  
- 删除后收件箱不再出现，已删除可恢复；IMAP 原信仍在；同步不回插已删 UID。  
- 有 `entity.parse.rfq` 时可从当前邮件进新建 RFQ。  
- 当日 08:30 后仅跑一批。  
- 无默认已验证平台邮箱时发信接口拒绝。
