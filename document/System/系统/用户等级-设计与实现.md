## 一、目标与非目标

### 1.1 目标

1. 每位员工独立维护 **1～20** 的用户等级，新建默认 **1**。
2. **当前等级**写在 `user`：`Level`、`LevelChangedAt`（从未改过级为空）、`LevelRemark`。
3. **变更履历**独立表 `user_level_history`（只追加），供回溯与以后按日取级算提成；**不**写入 `log_operation` / `log_change_fldval`。
4. 组织管理菜单、员工管理之下：路由 `/system/user-levels`（`UserLevelList`）。

### 1.2 非目标（一期不做）

| 项 | 说明 |
|----|------|
| 员工编辑页改等级 | `/system/users` 新增/编辑不出现等级字段；列表仅只读展示「等级」 |
| 提成计算 | 履历表已按「当时账号 + 旧/新级 + 时刻」落库，计算逻辑二期 |
| 新权限码 | 不新增；与员工管理同一套读写码 |
| 历史回填 1→1 | 上线不插默认履历行 |

## 二、已确认口径

| # | 项 | 决定 |
|---|-----|------|
| 1 | 取值 | 整数 1～20；每人单独改，互不影响 |
| 2 | 默认 | 新建员工 `Level = 1`；`LevelChangedAt` 为空 |
| 3 | 同级保存 | 只更新备注；**不**写履历、**不**改 `LevelChangedAt` |
| 4 | 改级 | 更新 `user.Level` / `LevelChangedAt` / `LevelRemark`，并追加履历一行 |
| 5 | 列表范围 | 与员工列表相同：`GET /api/v1/rbac/admin/users` + `ManagementAccountPolicy`；冻结账号仍出现 |
| 6 | 右栏 | 「变更日志」(`r-user-level-log`) + 帮助；门控同操作面板（收起不请求；在帮助页签单击只记行；切到变更日志才拉历史） |

## 三、数据模型

### 3.1 `user`（当前值）

| 列 | 说明 |
|----|------|
| `Level` | smallint，1～20，默认 1 |
| `LevelChangedAt` | timestamptz，当前等级开始时间；从未改过级为 NULL |
| `LevelRemark` | varchar(200)，当前备注 |

### 3.2 `user_level_history`（只追加）

| 列 | 说明 |
|----|------|
| `UserLevelHistoryId` | 主键 |
| `UserId` | 被改等级的员工 Id |
| `UserName` | **变更当时登录账号快照**（账号以后改名仍可读；不是实时 JOIN） |
| `OldLevel` / `NewLevel` | 旧级、新级 |
| `Remark` | 当次备注 |
| `ChangeTime` | 新等级开始时刻（UTC） |
| `OperatorUserId` / `OperatorUserName` | 操作人 Id；操作人姓名快照（无姓名则用其账号） |

索引：`(UserId, ChangeTime)`。

## 四、页面与 API

| 项 | 值 |
|----|-----|
| 菜单 | 组织管理 → 用户等级（员工管理之下） |
| 路由 | `/system/user-levels` · `UserLevelList` |
| 列表 | 复用 `GET /api/v1/rbac/admin/users`（`AdminUserDto` 含 `level` / `levelChangedAt` / `levelRemark`） |
| 员工列表 | `/system/users` 增加只读列「等级」；改级仍走用户等级页 |
| 改级 | `PUT /api/v1/user-levels/{userId}` body `{ level, remark }` |
| 履历 | `GET /api/v1/user-levels/{userId}/history` |

列表列：用户名称、用户账号、部门、等级、变更日期、备注、操作「设置等级」。

检索：用户名称、账号、部门、等级（前端过滤）。

编辑弹窗：名称/账号只读，等级 1～20，备注最长 200。

右栏「变更日志」：用户信息（当前账号与名称同一行、部门、等级）+ 历次履历（账号与名称同一行、日期与操作人同一行、`{旧} → {新}`；有备注时在变更等级下单独一行）。

列表页遵循 [业务列表规范](../../PRD/规范/UI规范/业务列表规范.md)、[列表搜索栏规范](../../PRD/规范/UI规范/列表搜索栏规范.md)、[列表操作列规范](../../PRD/规范/UI规范/列表操作列规范.md)。无独立详情路由：双击（有写权限）打开编辑弹窗；单击仍用于右栏变更日志。接口暂一次返回全量，前端按筛选结果分页（默认 20 条）。
