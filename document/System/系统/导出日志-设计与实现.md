## 一、功能定位

把导出审计从「操作日志」**独立成页**：

1. 菜单：系统日志 → **导出日志**（`/system/export-logs`）；
2. 数据仍写 `log_operation`（`ExtraInfo.exportKind`），不新建表；
3. 操作日志默认**排除**导出行；单据详情「导出记录」Tab 仍只看该单导出。

---

## 二、已确认口径

| # | 项 | 决定 |
|---|-----|------|
| 1 | 操作日志 | 按 `exportKind` 排除导出行 |
| 2 | 权限 | 新码 `system.logs.export.read`；已有操作日志权限的角色默认同开 |
| 3 | 系统备注 | 仅系统句：已截断、条件已按权限脱敏；「无筛选」只出现在导出条件 |
| 4 | 页面 / URL | 列表导出用目录；详情批次导出由前端传当前路径；旧数据用目录回填 |
| 5 | URL | 站内相对路径可点击，用路由跳到对应页；协议 / `//` 外链不跳 |

---

## 三、页面与 API

| 项 | 值 |
|----|-----|
| 路由 | `/system/export-logs` · `ExportLogList` |
| 列表 | `GET /api/v1/export-logs` |
| 业务类型下拉 | `GET /api/v1/export-logs/kinds` |
| 操作日志 | `GET /api/v1/operation-logs` 设 `ExcludeExportLogs=true` |

检索：导出业务类型、导出人、导出日期区间。

列表列：导出时间、导出人、导出业务类型、导出页面、导出页面 URL、导出条件、导出条目数、系统备注。

---

## 四、导出业务类型目录

每个导出按钮一个 `exportKind`（见 `ExportKindCatalog` / `ExportAuditKinds`）：

入库单列表、出库单列表、库存桶列表、库存明细列表、付款/进项/应收/预收/收款/销项/货代付款列表、销售/采购订单明细列表、批次核销入/出库批次、入库单批次、装箱单出库批次、采购订单入库批次、销售订单出库批次。
