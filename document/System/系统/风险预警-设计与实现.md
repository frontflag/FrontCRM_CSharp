## 1. 目标与非目标

### 1.1 目标（一期）

1. 全站一份门槛，在「预警参数」页维护。  
2. 控制台按当前用户的销售/采购/物流/财务 **数据范围** 现算，列出超标项。  
3. 点行跳到已有列表（库存明细、应收款、销售订单）。

### 1.2 非目标（一期不做）

| 项 | 说明 |
|----|------|
| 预警实例表 / 历史 | 不落库、不闭环 |
| 催收记录 / 立即联系 / 协同排产 | 不做 |
| 独立风险引擎 | 薄门槛 + 现算 |
| 解析销售订单付款条款文本 | 第 5 条只用挂账账龄 |

### 1.3 产品定稿（已冻结）

| 项 | 口径 |
|----|------|
| 第 1 条 | 在库占用资金（美金）合计超标 |
| 第 2 条 | 某条在库明细库龄超期；无入库日跳过；默认 90 天 |
| 第 3 条 | 待核销应收合计（美金）超标 |
| 第 4 条 | 按客户合计应收超标 |
| 第 5 条 | 销售订单挂账账龄：出库日（无则建账日）至今，**不是**承诺收款日 |
| 门槛 | 0 = 关闭该项；实际 **等于** 门槛不预警，**大于** 才预警 |
| 谁维护 | 仅 SYS_ADMIN、SYS_MANAGER |

## 2. 口径

时区：公司日历日 `Asia/Shanghai`。

### 2.1 库存占用与库龄

与物流分析在库快照同源：

```text
在库行：stock_item 未删、QtyRepertory > 0、非手工移库源行
数据范围：ApplyStockItemListDataScopeAsync
行美金：优先采购订单行 convert_price × 在库数，否则 PurchasePriceUsd × 在库数
库龄：上海今天 − stock_in.stock_in_date；无入库单或无入库日则跳过
```

### 2.2 应收与客户、挂账

与销售分析待办「待核销应收」同源：

```text
行：finance_receivable 未删、verified_to_be > 0
数据范围：ApplyFinanceReceivableListDataScopeAsync
行美金：优先销售订单行 convert_price/price 价比，否则查询日财务汇率
客户：按 customer_id 合计后再比门槛
挂账日：stock_out_date，缺省 create_time
订单：按 sell_order_id 取最大账龄，任一超期即计该单
```

### 2.3 脱敏

511 掩库存金额；521 掩应收金额与客户名。卡片仍加载，金额/名显示「—」。
