## 1. 目标与非目标

### 1.1 目标（一期）

1. 每天上海 **08:00** 生成一份简报。  
2. 日期窗口：**结束日 = 昨天**，**开始日 = 昨天往前 1 天**（两个自然日）。  
3. 登录用户即可看卡片（与消息通知相同）。  
4. 点一行或「查看全部」打开**当天全文**（Markdown）。  
5. 卡片用结构化 JSON（分类、标题、日期、一句话、重要性）；全文另存 Markdown。  
6. 提示词中的厂商名单是**优先关注样例**，不是封闭名单。

### 1.2 非目标（一期不做）

| 项 | 说明 |
|----|------|
| 独立历史列表 | 不做 |
| 关联机构外链 | 不做（模型未稳定返回 URL） |
| 打开桌面现搜 | 禁止；只读已落库简报 |
| 按人定制新闻 | 不做 |
| 评论 / 写入待办 | 不做 |
| 新侧栏菜单 | 不做 |

### 1.3 产品定稿（已冻结）

| 项 | 口径 |
|----|------|
| 窗口 | 结束日=昨天；开始日=昨天−1 天 |
| 谁可见 | 登录即可 |
| 点击 | 行 / 查看全部 → 当天全文 |
| 失败 | 保留上一份成功简报，卡片标「非今日简报」 |
| 文案 | 「今日简报」，不写实时资讯 / 15 分钟前 |

## 2. 口径

时区：公司日历日 `Asia/Shanghai`（`CommissionShanghai` / `IndustryNewsWindow`）。

```text
briefingDate = 上海今天
periodEnd    = briefingDate − 1 天
periodStart  = periodEnd − 1 天
作业可跑     ⇔ 上海本地时 Hour ≥ 8
```

示例：2026-09-14 早报覆盖 2026-09-12～2026-09-13。

关注维度固定 6 个：行业动态、关键厂商、行情价格、重组并购、公司治理、展会信息。Markdown 五个二级标题必须逐字为：

```text
## 本周要闻 Top 5
## 分类详述
## 行情速览
## 本周展望
## 内容总结
```

标题前不要写「一、二、三、四、五」；段落前不要序号。文中「本周」指上述两日窗口，不是自然周一到周日。

## 3. 实现

| 层 | 说明 |
|----|------|
| 场景 | `industry.news.briefing`，`enable_web_search=true`，缓存 TTL=0 |
| 作业 | `IndustryNewsHostedService`，每分钟检查；8 点后若今日无成功行则调用 `IAiOrchestrator.InvokeSystemAsync` |
| 落库 | `industry_news_briefing` 按 `briefing_date` 唯一 |
| 读 | `GET /api/v1/industry-news/latest` 取最近一份 **success** |
| 手跑 | `POST /api/v1/industry-news/run` **仅 SYS_ADMIN**；控制台「立即刷新」与 AI 配置「生成今日简报」 |
| UI | `IndustryNewsPanel.vue`，最多 5 条；全文弹层右侧按标题做楼层导航 |
| 模版维护 | `/system/ai-config` 模板 `industry.news.briefing`；保存时校验占位符与 JSON 契约 |

生产须把该场景 `provider_code` / `model` 改成已配置的 Moonshot（种子默认 `mock` 便于无 Key 联调）。

### 3.1 表与模版的关系

`industry_news_briefing` **不是**按提示词字段一列一列写死。表只存信封：`items_json` + `markdown` + 窗口日期 + 作业状态。

改 AI 配置里的关注重点、厂商样例、五节正文说法，**不用改表**。作业认的是解析契约：模型必须返回含 `items` / `markdown` 的 JSON；卡片读 `items`，弹层读整段 `markdown`。占位符必须仍是 `{{start_date}}` / `{{end_date}}`。
