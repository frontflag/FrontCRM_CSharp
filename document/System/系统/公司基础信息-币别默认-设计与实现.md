# 公司基础信息 · 人民币/外币抬头与报表选型 — 设计与实现

> **状态：** 配置 + 全量报表消费已实现（2026-08-09）  
> **页面：** `/system/company-info`（公司基础信息 / 公司印章）；各 `*ReportPage` 预览工具栏  

---

## 1. 目标

多组公司资料上标记 **人民币抬头 / 外币抬头**，报表按交易币别自动选用；工具栏可手动切换（不回写公司信息）。印章按抬头币别跟走，Logo 始终用全局默认。

---

## 2. 定稿规则

### 2.1 配置（公司基础信息）

| 项 | 规则 |
|----|------|
| 总默认 | 原「默认」勾选，字段仍为 `isDefault`（整站最多一组） |
| 默认含税 | 字段 `isDefaultRmb`；全列表最多 **1** 组；可不勾 |
| 默认外币 | 字段 `isDefaultForeign`；全列表最多 **1** 组；可不勾 |
| 配置控件 | 每组两个 checkbox（与「总默认」并列） |
| 同组互斥 | 同一组不可同时勾「默认含税」与「默认外币」 |
| 保存强制 | **不**要求各至少勾一个 |

### 2.2 配置（公司印章，支撑「印章跟抬头走」）

| 项 | 规则 |
|----|------|
| 总默认 | 原「默认」勾选，字段仍为 `isDefault`（整站最多一组） |
| 默认含税 / 默认外币 | 字段 `isDefaultRmb` / `isDefaultForeign`；各最多一组；同组互斥；可不勾（交互同基础信息） |
| 信息栏 | 浅黄面板展示「默认含税印章 / 默认外币印章」对应印章名称 |
| 与抬头 | 无 FK；按 **币别维度** 对齐（换抬头 → 按该抬头的含税/外币属性重选印章） |

### 2.3 报表消费

| 项 | 规则 |
|----|------|
| 范围 | Packing List、Commercial Invoice、SO/PO 报表、SO/客户/供应商质保书等全部公司抬头报表预览页 |
| 币别来源 | 明细 **第 1 条** 有值的交易币别；Packing/CI 取装箱行关联 SO 行 `priceCurrency`；无币别时走全局默认 |
| 自动选抬头 | RMB → 默认含税（`isDefaultRmb`）；外币 → 默认外币（`isDefaultForeign`）；否则 → 总默认 `isDefault` → 首组 |
| 工具栏下拉 | 「返回」后；选项 = 已配置含税抬头 + 外币抬头；二者皆无则仅总默认一项 |
| 「（默认）」后缀 | **仅**标在按币别自动选中的那一项 |
| 手动切换 | 立即刷新预览抬头；**不**持久化到公司信息 |
| Logo | **始终**全局默认 Logo（换抬头不变） |
| 印章 | **跟已选抬头币别**（人民币印章 / 外币印章 / 否则全局默认有文件印章） |

---

## 3. 数据

存于现有 sysparam JSON（无新表）：

| 参数 | 字段 |
|------|------|
| `Company.Profile.BasicInfos` | `isDefault` / `isDefaultRmb` / `isDefaultForeign` |
| `Company.Profile.Seals` | `isDefault` / `isDefaultRmb` / `isDefaultForeign` |

Packing 报表行增加 `priceCurrency`（short），供前端判币别。

## 5. 部署说明

- **无需 SQL**；保存公司信息页写入 JSON。
- 部署 API + Web；印章人民币/外币标记需在公司信息页按需勾选后，换抬头时印章才会区分。
