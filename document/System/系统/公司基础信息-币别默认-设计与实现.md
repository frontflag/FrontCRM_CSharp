# 公司基础信息 · 人民币/外币抬头 — 设计与实现

> **状态：** 配置页已实现（2026-08-09）；报表按币别选型 **未改**（仍用全局 `isDefault`）  
> **页面：** `/system/company-info`（`CompanyInfo`）→ 公司基础信息  

---

## 1. 目标

在多组「公司基础信息」上增加 **人民币抬头** / **外币抬头** 标记，供后续按交易币别选用公司抬头；本阶段仅配置与落库。

---

## 2. 定稿规则

| 项 | 规则 |
|----|------|
| 与原「默认」 | **并存**：全局 `isDefault` 不变（整站最多一组） |
| 人民币抬头 | 全列表最多勾 **1** 组；可不勾 |
| 外币抬头 | 全列表最多勾 **1** 组；可不勾 |
| 同组互斥 | 同一组 **不可** 同时勾「人民币抬头」与「外币抬头」 |
| 保存强制 | **不**要求各至少勾一个 |
| 报表/业务消费 | **本期不做**；打印仍 `pickDefault` → `isDefault` |

---

## 3. 数据

存于现有 sysparam JSON：`Company.Profile.BasicInfos`（无新表）。

| 字段 | 界面文案 |
|------|----------|
| `isDefault` | 默认 |
| `isDefaultRmb` | 人民币抬头 |
| `isDefaultForeign` | 外币抬头 |

旧数据无新字段时按 `false`；加载时前端会清洗「同组双勾 / 同维度多勾」脏数据。
