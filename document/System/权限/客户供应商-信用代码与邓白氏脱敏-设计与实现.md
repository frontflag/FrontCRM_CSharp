## 1. 规则（全站统一）

| 客商 | 触发（与现有掩码一致） | 须脱敏的身份编码 |
|------|------------------------|------------------|
| **客户** | `useSaleSensitiveFieldMask` / `SaleSensitiveFieldMask521.ShouldMask`（采购方向 + `SaleDataScope=4`，非管理员 bypass） | **统一社会信用代码**、**邓白氏编码** |
| **供应商** | `usePurchaseSensitiveFieldMask` / `PurchaseSensitiveFieldMask511.ShouldMask`（销售方向 + `PurchaseDataScope=4`，非管理员 bypass） | **统一社会信用代码**、**邓白氏编码** |

展示约定：

- **详情 / 编辑**：明文改为占位 `—`（编辑页只读；保存时不得因占位而清空库内原值）。
- **概况浮窗**（`CustomerSelect` / `VendorSelect`）：敏感时**整行隐藏**这两项（与名称类字段一致）。
- **情报对照条**：不展示信用代码（客户侧同步隐藏公司名/业务员明文）。

管理员 / `HasBizDataBypass`：**不脱敏**。

## 2. 前端落点（索引）

| 表面 | 客户 | 供应商 |
|------|------|--------|
| 详情 | `CustomerDetail.vue` | `VendorDetail.vue`（采购掩码下本已打码） |
| 编辑 | `CustomerEdit.vue`（只读 `—` + 保存回填/回取） | `VendorEdit` 写权限场景为主；详情已掩码 |
| 下拉概况 | `CustomerSelect.vue` | `VendorSelect.vue` |
| 情报条 | `CustomerIntelCrmContextBar.vue` + 列表/详情 `bindContext` | `VendorIntelCrmContextBar`（对称） |
| 业务回填 | `SalesOrderCreate.syncInvoiceFromCustomer`：脱敏时不写入「名称(信用代码)」 | — |

## 3. 例外

| 场景 | 口径 |
|------|------|
| **供应商查重提醒**（新建/编辑保存前、审批桌面查重面板） | 为防漏建重复，命中结果**仍可展示**名称与编码；与 [供应商查重-设计与实现](../供应商/供应商查重-设计与实现.md) 一致。详情页本身仍按采购脱敏打码。 |
| **导入 / Debug 录入** | 录入侧可填写；不是主档只读展示。 |

## 4. 后端对齐

| 方法 | 脱敏字段（mask=true） |
|------|------------------------|
| `SaleSensitiveFieldMask521.ApplyCustomerInfo` | 既有名称/编码/业务员等 + **`CreditCode`、`DUNS`** |
| `PurchaseSensitiveFieldMask511.ApplyVendorInfo`（含 `ApplyVendorInfos`） | 既有名称/编码等 + **`CreditCode`、`DUNS`** |

导出/打印须与上述同触发条件。
