## 1. 目标

客户详情 **跟进** 页签：看并处理 **当前客户** 上的工作任务（跟进计划），左右分栏。  
数据源只有 `work_task`（`object_type=CUSTOMER`，`object_id=当前客户`）。  
完成后仍按工作日程方案 A 写 **联系历史**；联系历史仍在「客户资料」，本页不另做一套跟进库。

---

## 2. 已拍板

| 项 | 约定 |
|----|------|
| 范围 | 该客户 **全部执行人** 的任务（能进该客户详情即可看全文） |
| 已取消 | 列表 **可以** 出现；「含已取消」**默认关**，打开后才混入 |
| 写操作 | 新建（客户已锁定）；开始 / 完成 / 取消；改标题/内容。须 `work-task.write` 且为创建人或执行人。别人的任务只读 |
| 日历与列表 | 一条列表。点日期 = 只看当天；顶栏 **全部** 与日期筛选互斥。翻月只换圆点，不改列表，除非点了某天 |
| 圆点 | 仅「有任务」一种点；不含需求/订单。圆点是否计入已取消，与「含已取消」开关一致 |
| 排序 / 分页 | `start_date` 降序，其次 `create_time` 降序；每页 50 |
| 软删 | 永不出现 |

## 3. 界面

```text
┌ 月历（上海日；有任务的日子打点）─────────┐  ┌ 跟进正文 ─────────────┐
│ 上月 / 年月 / 下月 / 今天                   │  │ 标题、状态、开始日     │
│ 点有点的日子 → 列表筛到该日                 │  │ 执行人、紧急程度、内容 │
│ [全部]  [含已取消]  [新建跟进]            │  │ 开始 / 完成 / 取消     │
│ 任务列表（日期、标题、状态、执行人、P）   │  │ 已完成可提示已记入联系历史 │
│ 分页                                       │  │                       │
└────────────────────────────────────────────┘  └───────────────────────┘
```

- 打开页：默认 **全部** + 不含已取消；若有行则选中第一条（有 `taskId` 查询则选中该条并必要时打开「含已取消」）。  
- 无任务：左空态 + 有写权限显示新建。  
- 无写权限：不显示新建与状态按钮；仍可看列表与正文。  
- 窄屏上下叠。月历用紧凑格，**不**嵌桌面 `WorkCalendarPanel`。

深链：`?tab=followUp&taskId=`；可选 `followDate=`（`yyyy-MM-dd`）、`followIncludeCancelled=1`。

## 4. 权限

| 动作 | 条件 |
|------|------|
| 看页签 / 列表 / 正文 | 能打开该客户详情（`customer.read` + 客户数据权限）。**不**要求 `work-task.read` |
| 新建 / 改状态 / 改标题内容 | `work-task.write` 且创建人或执行人 |
| 执行人下拉 | 与桌面相同 `GET /work-tasks/assignees` |

桌面 `GET /work-tasks/{id}` 仍仅创建人/执行人。本页正文走 **客户维度** 接口，同事可看。

## 5. 实现索引

| 层 | 路径 |
|----|------|
| API | `GET /api/v1/customers/{id}/work-tasks`、`GET .../work-tasks/month`、`GET .../work-tasks/{taskId}` |
| 服务 | `IWorkCalendarService.ListCustomerTasksAsync` / `GetCustomerMonthAsync` / `GetCustomerTaskAsync`；过滤 `WorkTaskCustomerScopeRules` |
| 写 | 现有 `POST /work-tasks`、`PATCH`、`start` / `complete` / `cancel` |
| 前端 | `CRM.Web/src/components/Customer/CustomerFollowUpPanel.vue`，挂在 `CustomerDetail` 的 `followUp` |
| 页签 | `followUp` 已移出 `CUSTOMER_DETAIL_PRIMARY_TAB_PLACEHOLDERS` |

无新表、无 DDL、无新权限码。
