# 客户列表 — 筛选页签模式 — 设计与实现

**页面：** `/customers`（`CustomerList`，搜索栏齿轮 →「页签模式」）  
**UI 规范：** [列表搜索栏规范 §10 筛选页签模式](../../PRD/规范/UI规范/列表搜索栏规范.md)  
**交互参考：** [需求明细列表-筛选页签模式-设计与实现](../需求/需求明细列表-筛选页签模式-设计与实现.md)

## 1. 业务定位

将搜索栏中适合做成单选桶的下拉，可选转为表格上方全宽页签条。**单维度**；关闭页签不清筛选值；点页签立即查询。

文本框、日期范围、状态/级别/类型/行业/业务员下拉不纳入页签模式。左栏 preset 见 [客户列表-左栏检索-设计与实现](./客户列表-左栏检索-设计与实现.md)。页签模式菜单仅提供「结算币别」一个维度。

---

## 2. 设计要求（定稿）

### 2.1 可纳入维度

| 维度 key | 搜索栏字段 | API query | 页签形态 |
|----------|------------|-----------|----------|
| `settlementCurrency` | `searchForm.currency` | `currency` | 全部 + USD/RMB/HKD/EUR（`SETTLEMENT_CURRENCY_OPTIONS`） |

结算币别：`1～4`（`TradeCurrency`；后端 RMB 默认含 `null`）。

### 2.2 交互与视觉

遵循 [列表搜索栏规范 §10](../../PRD/规范/UI规范/列表搜索栏规范.md)：

| 项 | 规则 |
|----|------|
| 默认 | `off`（下拉模式） |
| 入口 | 搜索 / 重置旁齿轮 →「关闭页签」+「页签模式 ▸」（结算币别） |
| 开启 | 隐藏结算币别下拉；页签条 `cu-filter-tabs` 在表格上方 |
| 关闭 | 恢复下拉；筛选值保留 |
| 点页签 | 写入 filter + `handleSearch()`（同步 URL query） |
| 偏好 | `localStorage`：`crm.customer-list.tab-mode` |

亮色未选中 `#E8EDF5`；暗色 `var(--crm-layer-1)`；5 格结算币别页签等分全宽。

### 2.3 不做的范围（本版）

- 类型 / 行业 / 业务员页签
- 多维度同时开多条页签条
- 后端 API 变更（仍用现有 query 参数）

## 3. 实现方法
