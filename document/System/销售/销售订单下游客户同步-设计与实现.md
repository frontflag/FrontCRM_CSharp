## 1. 目标

以销售订单 **`customer_id`**（或编辑时的**拟换客户**）为唯一准绳：

1. **刷新订单头 `customer_name` 快照**（从客户主数据 `OfficialName ?? CustomerName`）；销售订单明细列表读该快照，故一并纠正。
2. 将**未出库完成**链路上的下游 `customer_id` 同步为订单当前/目标客户；**已出库 / 已核销 / 已开票**单据阻断并提示。
3. **编辑换客户（方案 A）**：确认后一次保存（头客户 + 未完结下游），失败整单失败；取消确认则不保存。

与「刷新状态 / 刷新单价」分离，避免误操作。页头主按钮为「刷新状态」；下拉「刷新单价」覆盖下游销售价快照，见 [销售订单分面刷新](./销售订单分面刷新-设计与实现.md)。

详情刷新客户：销售参数「分面刷新 → 刷新客户」开启且将覆盖已完结出库链时，须 `confirmCompleted`。编辑换客户保存不套该标志。已核销应收不改**客户主键**（名称快照可对齐）；已开票销项仍不同步客户字段。

## 3. API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/sales-orders/{id}/sync-downstream-customer/preview` | 预检：同步计数 / 阻断列表；可选查询参数 `proposedCustomerId`（编辑拟换客户） |
| POST | `/api/v1/sales-orders/{id}/sync-downstream-customer` | 按已落库客户执行同步（详情「刷新客户」） |
| PUT | `/api/v1/sales-orders/{id}` | 请求体 `customerId` 与库中不同时：服务内一步 Apply（头+下游，同一次 SaveChanges） |

## 4. MVP 第一期：同步 vs 阻断

| 对象 | 同步条件 | 阻断条件 |
|------|----------|----------|
| 销售订单头 `sell_order.customer_name` | 与主数据名称不一致（按 `customer_id`） | —（随整体 `CanSync`；无有效 `customer_id` 则阻断） |
| 出库通知 `stockout_notify` | `status < 100` 且非取消，客户 ID 不一致 | `status = 100` 已出库 |
| 装箱单 `packing` | `status < 100`，客户 ID 不一致 | `status = 100` 已出库完成 |
| 装箱明细扩展 `packing_item_extend` | 随待同步装箱单明细批量 UPDATE | — |
| 出库单 `stock_out` | `status` 非已出库/取消，客户 ID 不一致 | `status = 2` 已出库 |
| 应收 `finance_receivable` | **未核销**且客户 ID 不一致；或客户 ID 已一致但**名称快照**与主数据不一致（含已核销，只改名称） | 已核销且客户 **ID** 不一致 |
| 销项发票 `financesellinvoice` | **不同步** | 已开票且客户不一致 |

**销售参数覆盖：** 当 [销售参数 · 分面刷新](./销售参数-设计与实现.md) 中「刷新客户」为开启时：出库通知 / 装箱 / 出库即使已完成也可进入同步列表，详情须 `confirmCompleted`；已核销应收与已开票销项不再写入阻断列表（仍不改已核销应收的**客户主键**、不改已开票销项）。默认关闭，保持上表阻断口径。详见 [分面刷新](./销售订单分面刷新-设计与实现.md) §8。

预检字段 `sellOrderCustomerNameToSync`（0/1）；明细项 `category=sellOrder`。仅名称过期、下游 ID 已一致时仍可同步（非 NoOp）。

装箱单**无单独 `customer_name` 落库列**。列表/详情头客户名展示口径：优先关联销售订单 `CustomerName` 快照（与出库通知一致），无关联订单时再按 `customer_id` 查主数据（`OfficialName ?? NickName`）。

## 5. 前端交互

### 5.1 详情页

- 主按钮：**刷新状态**。
- 下拉 ▾：**刷新客户** → 预检（已落库 ID，含订单名称快照）→ 若有将覆盖的已完结出库链则列出 → 确认 → 同步 → 结果摘要。

### 5.2 编辑页换客户（对齐 PO 换供应商，方案 A）

| 时机 | 行为 |
|------|------|
| 改客户（未保存） | 防抖调用 `preview?proposedCustomerId=`，页内 tip 栏仅提醒（不同步） |
| 保存且客户相对原单变更 | 再预检 → 阻断则停；可同步则确认「刷新并保存」/「取消」 |
| 确认刷新并保存 | `PUT` 换客户；后端一步写头+下游；失败整单失败 |
| 取消确认 | 留在编辑页，**不保存** |
