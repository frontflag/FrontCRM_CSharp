## 1. 业务定位

销售订单详情页底部 **「销售订单明细详情」** 面板下方，新增独立 **「绩效」** 面板，在选中某条销售明细后展示该行 **三层利润口径**（报价 / 预计销售 / 出库），并对「利润为 0、利润率显示 —」等易误解情形给出固定规则说明。

| 概念 | 说明 |
|------|------|
| **适用对象** | 单条 `sell_order_item` |
| **与概况关系** | 概况管执行进度矩阵；绩效管利润，不重复 |
| **开闭规则** | 与明细详情面板同开同关；面板内标题栏可折叠，默认折叠；**展开时才请求绩效数据** |

## 2. 功能要求

### 2.1 入口与交互

| 入口 | 操作 | 说明 |
|------|------|------|
| 销售订单详情 | `/sales-orders/:id` → 单击/双击订单明细行 | 展开明细详情面板后，其下方显示绩效面板 |

**显示条件：**

- `soItemLinePanel.visible === true`
- 未开启销售敏感脱敏（`!maskSaleSensitiveFields`）
- 具备金额查看权限（与订单明细金额列一致）

### 2.2 三层指标

每层展示：**利润（USD）** + **利润率（收入÷成本倍数）**；利润率旁 tooltip 补充 **毛利率 %** = `(利润 ÷ 收入) × 100`。

数值行下方展示 **计算公式（变量已代入）**：将 `qty`、`convertPrice`、成本与数量等变量替换为当前明细真实数据，并写出等号右侧计算结果（与扩展表同步口径一致）。

面板顶部 **公式变量对照** 区列出上述公式所用变量的当前值（销售/报价原币与折算 USD、下单汇率快照、PO 成本、出库数量等），便于与下方公式行逐项比对。

| 层 | 利润字段 | 利润率 |
|----|----------|--------|
| **报价** | `QuoteProfitExpected` / `ReQuoteProfitExpected`（有报价成本快照时用 ReQuote） | 扩展表对应 rate；成本为 0 → `—` |
| **预计销售** | `SalesProfitExpected` | `收入 USD ÷ PoCostUsdConfirmed`；已确认成本为 0 → `—` |
| **出库** | `ProfitOutBizUsd` | `ProfitOutRateBiz`；出库成本为 0 且利润 ≥ 0 → `—` |

中间层 **不** 单独展示「采购利润（全 PO）」；若存在已下单未确认成本，用说明文案提示。

### 2.3 异常说明

使用 `el-alert` + 固定 i18n 模板（`salesOrderDetailView.performance.hints.*`），不链接帮助文档。说明文案可带入 `purchaseProgressStatus` / `stockOutProgressStatus` 的展示标签（与列表 `extendTriLabel` 一致）。

| 规则 | 类型 | 判定要点 |
|------|------|----------|
| 无报价成本快照 | info | `quoteCostUsd <= 0` 且报价利润率不可算 |
| 报价层收支平衡 | info | 有报价成本、利润 ≈ 0、利润率 ≈ 1.00 |
| 无已确认采购成本 | info | `poCostUsdConfirmed <= 0`；文案含当前采购状态 |
| 预计销售收支平衡 | info | 已确认成本 > 0、利润 ≈ 0 |
| 预计销售平价（利润率 ≈ 1） | info | 同上且利润率 ≈ 1.00 |
| 已下单未确认 PO 成本 | info | `poCostUsdTotal > poCostUsdConfirmed` 且全 PO 利润更高；文案含采购状态 |
| 尚未出库 | info | `qtyStockOutActual <= 0` 且出库利润 ≈ 0；文案含出库状态 |
| 已出库但毛利为 0（平价） | info | 已出库、利润 ≈ 0、利润率 ≈ 1.00 |
| 已出库但毛利为 0（单价≈成本） | info | 已出库、利润 ≈ 0、利润率可算但非 1（舍入） |
| 出库利润为正但成本为 0 | warning | 利润率显示 —；文案含采购状态 |
| 销售收入无效 | warning | `revenueUsd <= 0` |

## 3. 数据口径

### 3.1 API

绩效数据独立接口（展开面板时按需加载）：

`GET /api/v1/sales-orders/{orderId}/sell-order-items/{itemId}/line-profit`

`mask521` 时响应 `data` 为 `null`。

`detail-tab-aggregates` **不再**返回 `lineProfit`，避免打开明细详情时预加载绩效。

### 3.2 后端实现

| 位置 | 说明 |
|------|------|
| `SalesOrdersController.GetSellOrderItemLineProfit` | 绩效独立接口 |
| `SalesOrdersController.BuildSellOrderLineProfitAsync` | 组装绩效 payload |
| `SellOrderItemProfitDisplay` | 报价/预计/出库利润率展示口径（成本为 0 → null） |

### 3.3 前端实现

| 位置 | 说明 |
|------|------|
| `SellOrderItemPerformancePanel.vue` | 绩效面板 UI；默认折叠，展开时调用 `line-profit` |
| `sellOrderLineProfitDisplay.ts` | 金额、倍数、毛利率格式化 |
| `sellOrderLineProfitFormulas.ts` | 三层利润公式文案（变量代入） |
| `sellOrderLineProfitVariables.ts` | 顶部公式变量对照表 |
| `sellOrderLineProfitHints.ts` | 异常说明规则 |
| `SalesOrderDetail.vue` | 挂载于明细详情面板下方 |
| `salesOrder.ts` → `SellOrderLineProfit` | TypeScript 类型 |

## 5. 自检清单

- [ ] 双击明细行后，绩效面板出现在明细详情面板正下方
- [ ] 点击明细详情「收起」后，绩效面板一并消失
- [ ] 绩效标题栏可折叠，默认折叠；折叠时不请求 `line-profit`
- [ ] 展开绩效面板后才加载并展示三层利润
- [ ] 三层利润与列表页 `SalesOrderItemList` 同口径
- [ ] 出库成本为 0 时利润率显示 `—`
- [ ] 无金额权限或脱敏时不显示绩效面板
