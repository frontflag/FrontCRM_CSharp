## 一、功能定位

为两张**订单明细**列表提供与财务/库存一致的**可审计 CSV 导出**：

1. 按**当前筛选**服务端导出（含左栏快捷检索、页签、进度多选），不含分页；上限 **50000** 行；
2. 固定全量列（不跟列表列显隐）；枚举写中文业务名；金额列后紧跟币别；
3. 导出 API **服务端**写入 `log_operation`（禁止仅前端二次记日志）；
4. 权限与各列表 **read** 相同；521/511 脱敏与列表一致（口径 B：文件与日志均脱敏）。
5. 查看入口：系统日志 → **导出日志**（操作日志不再列出导出行）。

本能力属于 **`log_operation` 操作审计**，不是 Telemetry 行为埋点。

**本版不做：** 销售/采购订单**主表**列表导出；「仅勾选行」导出。

## 二、已确认设计口径

| # | 项 | 决定 |
|---|-----|------|
| 1 | 范围 | 仅 `/sales-order-items`、`/purchase-order-items` 两张明细页 |
| 2 | 筛选 | 当前筛选全量（preset / 页签 / 进度多选）；**不**导出勾选篮子 |
| 3 | 销售利润三列 | **进导出**（销售利润、出库利润、出库利润率）；无金额权限或 521 时为空 |
| 4 | 格式 | CSV UTF-8 BOM；文件名 `{业务名}_yyMMddHHmm.csv` |
| 5 | 列 | 固定全量列，不跟列设置显隐；不含操作列 |
| 6 | 客商 | 中文 + 英文分列；无权限/脱敏为 `***`（客户订单号/客户料号为空） |
| 7 | 确认 | 导出前确认框；看板/列表视图按钮都可见，内容跟当前筛选 |

## 三、页面与 API

| 页面 | 路由 | API | ActionType | RecordCode | BizType |
|------|------|-----|------------|------------|---------|
| 销售订单明细 | `/sales-order-items` | `GET /api/v1/sales-orders/items/export` | `SalesOrderItemListExport` | `SALES_ORDER_ITEM_LIST` | `SellOrderItem` |
| 采购订单明细 | `/purchase-order-items` | `GET /api/v1/purchase-orders/items/export` | `PurchaseOrderItemListExport` | `PURCHASE_ORDER_ITEM_LIST` | `PurchaseOrderItem` |

- 权限：`sales-order.read` / `purchase-order.read`（与列表相同）。
- 按钮：页头右上角浅黄「导出」（`btn-export`）；看板/列表切换仍在搜索栏。
- 列表级导出：`RecordId=list`。
- 截断：描述含「已截断」，`ExtraInfo.truncated=true`。
- 进度多选：query 用重复 key（`buildQueryString`），不可把数组拼成 `"1,2"`。

## 四、CSV 列

**销售订单明细：** 销售订单明细、销售订单号、主状态、客户中文、客户英文、业务员、采购员、物料型号、品牌、客户订单号、客户料号、数量、单价、单价币别、行金额、行金额币别、折算美金单价、折算美金行金额、销售利润、出库利润、出库利润率、采购进度、入库进度、出库通知进度、出库进度、收款进度、开票进度、创建日期、创建人

- 创建人与列表一致：回退业务员；521 为 `***`。
- 出库利润率：对齐列表 `formatProfitOutRateBizDisplay`（rate=0 且利润≥0 导出空）。

**采购订单明细：** 采购订单明细、采购订单号、货代单号、明细状态、供应商中文、供应商英文、采购员、物料型号、品牌、数量、单价、单价币别、行金额、行金额币别、创建日期、创建人、请款进度、付款进度、采购进度、入库进度、发票进度

- 请款进度：`>=1` = 已申请，否则待申请。

## 五、脱敏

| 列表 | 规则 |
|------|------|
| 销售订单明细 | 521：客户中英文、业务员、创建人为 `***`；客户订单号/客户料号为空；金额、币别、利润三列为空 |
| 销售订单明细 | 无客户/金额权限：客商为 `***` 或空；金额与利润列为空（有金额权限才出数） |
| 采购订单明细 | 511：供应商中英文为 `***`；金额及对应币别为空 |
| 采购订单明细 | 无供应商权限但非 511：供应商中英文为 `***`；仅无金额权限时金额列为空（客商仍可出） |

无权限筛选项（如客户名、供应商名）不写入 `filters`。

## 七、已知限制

- 销售明细 DTO 无独立创建人字段，CSV「创建人」回退业务员（与列表展示一致）。
- 本版不导出主表列表、不支持仅勾选行。
