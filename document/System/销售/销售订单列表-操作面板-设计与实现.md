**交互参考：** [销售订单明细列表-操作面板-设计与实现](../销售订单明细列表-操作面板-设计与实现.md)（**§2.4** 门控、**§2.5** 布局）  
**测试对照：** [销售订单列表-操作面板-测试对照说明](../../QA/销售/销售订单列表-操作面板-测试对照说明.md)

---

## 1. 业务定位

销售订单**主表**列表右栏增加「操作」页签，只展示明细操作面板的前两张卡：**销售订单**、**文档**。一行一单，不含明细行级申请采购/出库。

| 概念 | 说明 |
|------|------|
| **页签** | `r-ops` / 客户 / 帮助；进入列表默认 **操作** |
| **单击门控** | 与明细列表 §2.4 相同（`useListRightOpsPanelInteraction`） |
| **详情页** | 不改；详情「操作」仍是点明细行后的行级面板 |

---

## 2. 卡片

| 卡片 | 口径 |
|------|------|
| 销售订单 | 编号（链到详情）+ 主单状态（取消/审核失败红色）；下一行客户中/英文名 |
| 文档 | 复用 `SalesOrderOpsDocumentsCard`，`bizType=SALES_ORDER`、`bizId` 为订单 Id；mask521 不显示 |

列表行字段：`id` / `sellOrderCode` / `status` / `customerName` / `customerEnglishName`。

---

## 3. 实现要点

| 层 | 路径 |
|----|------|
| 面板 | `CRM.Web/src/components/SalesOrder/SalesOrderOpsPanel.vue` |
| store | `CRM.Web/src/stores/salesOrderOpsPanel.ts` |
| 布局 | `AppLayout`：`SalesOrderList` 注册 `r-ops`，默认 `r-ops`；旧记忆「帮助」进页改为操作（客户记忆保留）；`v-if` 挂载以免在帮助页签下拉文档 |
| 列表 | `SalesOrderList.vue`：操作 + 客户各一套 §2.4；刷新 `clear` |

文档接口与明细同一套 `documentApi.getDocuments`，无新后端。
