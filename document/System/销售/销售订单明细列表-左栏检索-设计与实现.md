## 1. 业务定位

在销售订单明细列表页左栏提供 **preset 快捷检索**，与主栏 keyword 区、看板统计 **共用 URL query**，筛选口径与列表行内操作按钮（申请采购、申请出库等）保持一致。

| 概念 | 说明 |
|------|------|
| **preset 单选** | 左栏五组（下单时间 / 待办 / 业务进度 / 库存 / 收款）共 18 项；再点同一项或主栏 chip ✕ → **清空全部 query（含 keyword）** |
| **keyword 叠加** | 「销售订单/明细号」（主单号或明细号 OR 模糊）、客户、销售员、采购员、型号、客户单号/型号、币别可与 preset 同时生效；旧深链 `?sellOrderItemCode=` 合并进该输入框 |
| **进度/日期筛选互斥** | 有 preset 时主栏隐藏日期 + 六 progress；无 preset 时主栏直接展示这些筛选项 |
| **筛选页签模式** | 齿轮可将币别/进度下拉改为单维度页签；preset 时隐藏进度页签条与菜单项，币别可保留（见 [筛选页签模式](./销售订单明细列表-筛选页签模式-设计与实现.md)） |
| **看板一致** | 列表与看板共用 `boardFilters`，analytics API 同样传 `quickFilter` / 日期 / keyword |
| **数据权限** | 与列表一致；mask521 隐藏客户相关 keyword 与列 |

## 2. preset 列表

### 2.1 时间类（前端展开）

| preset ID | 含义 | API 参数 |
|-----------|------|----------|
| `order_today` | 今日下单 | `orderCreateStart/End` = 本地今日 |
| `order_today_yesterday` | 今昨下单 | 昨日～今日 |
| `order_last_7_days` | 近 7 日 | 今日往前 6 天～今日 |
| `order_last_30_days` | 近 30 日 | 今日往前 29 天～今日 |
| `order_this_week` | 本周订单 | 本周周一～今日（周一为一周起点） |
| `order_this_month` | 本月订单 | 本月 1 日～今日 |

日期格式：**本地日历 YYYY-MM-DD**，与现有列表 `orderCreateStart/End` 一致（`salesOrderItemListPreset.ts`）。

### 2.2 业务类（后端 `quickFilter`）

| preset ID | 含义 | 与按钮/进度口径 |
|-----------|------|-----------------|
| `pending_submit_audit` | 待提交审核 | 主单 status **1 或 -1**；`item.status=0` |
| `pending_submit_purchase_req` | 待申请采购 | 主单已审核+；`purchaseRemainingQty>0` |
| `pending_submit_stock_out_notify` | 待申请出库 | 与「申请出库」按钮完全一致（含备货放宽）；`QtyStockOutNotifyNot > 0`；排除出库完成(2)；主单已审核+ |
| `applied_pending_po` | 已申请待采购 | 未完结 PR(0/1) 且 PO 数量=0 |
| `purchased_pending_stock_in` | 已采购待入库 | PO 数量>0；`purchaseProgressStatus≥2` 且 `stockInProgressStatus<2`（与看板 `SalesAnalyticsPipelineClassifier` 待入库一致）；排除「通知已满且尚未入库」行 |
| `notify_pending_packing` | 已通知待装箱 | 任一关联出库通知 `status=10` |
| `packed_pending_stock_out` | 已装箱待出库 | 任一通知 `status=20` 且 `stockOutProgressStatus<2` |
| `in_stock_pending_out` | 在库待出 | 同一扩展行：`stockInProgressStatus∈{1,2}` 且 `stockOutProgressStatus∈{0,1}`；主单已审核+ |
| `used_stocking` | 使用备货 | 与操作面板「使用备货」同口径：存在 `pickingtaskitem.IsStockingSupplement=true` 且 `PickedQty>0`（经 packing_item / 出库通知关联本行） |
| `stock_out_pending_receipt` | 应收款 | `stockOutProgressStatus∈{1,2}` 且（`receiptProgressStatus=0` 或 `receiptAmountNot>0`） |
| `receipt_partial` | 部分收款 | `receiptProgressStatus=1` |
| `receipt_complete` | 收款完成 | `receiptProgressStatus=2` |

## 3. 前端实现

### 3.1 文件

| 文件 | 职责 |
|------|------|
| `CRM.Web/src/utils/salesOrderItemListPreset.ts` | preset ID、日期展开、URL query 构建 |
| `CRM.Web/src/components/RFQ/SalesOrderItemSearchPanel.vue` | 左栏五组 preset 按钮（下单时间 / 待办 / 业务进度 / 库存 / 收款） |
| `CRM.Web/src/layouts/AppLayout.vue` | 路由 `/sales-order-items` 时挂载左栏面板 |
| `CRM.Web/src/views/RFQ/SalesOrderItemList.vue` | keyword、preset chip、日期/进度筛选、路由同步、`loadList` |

### 3.2 URL query 约定

- `preset`：当前选中的 preset ID（展示用）
- `quickFilter`：业务类 preset 对应的后端码（时间类不写）
- `orderCreateStart/End`：时间类 preset 展开或主栏日期筛选
- keyword 键：`sellOrderCode`、`customerName`、`salesUserName`、`purchaseUserAccount`、`pn`、`customerSo`、`customerPn`、`transactionCurrency`

**驱动链：** 左栏点击 / 主栏查询 / 重置 → `router.replace` → `watch(route.query)` → `syncFiltersFromRoute` → `loadList`。

### 3.3 主栏 UI

- 有 preset 时顶部显示 **chip**（无角标），✕ 清空全部 query；日期与六 progress **隐藏**
- 无 preset 时，日期与六 progress 直接展示在主栏 keyword 区（无折叠「高级筛选」）

## 5. API

```
GET /api/v1/sales-orders/items?quickFilter=pending_submit_purchase_req&pn=ABC
GET /api/v1/sales-orders/items/analytics/dashboard?quickFilter=...
```

analytics 的 `dashboard` / `trends` / `breakdowns` / `rankings` 与列表共用同一套 query 参数。
