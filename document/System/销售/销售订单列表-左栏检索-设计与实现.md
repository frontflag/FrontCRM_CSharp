## 1. 业务定位

销售订单**主表**列表左栏改为与明细列表同款 **preset 快捷检索**（替换原订单号/客户/状态表单；这些字段仍在主栏）。

| 概念 | 说明 |
|------|------|
| **preset 单选** | 六组：下单时间 / 待办 / 文档 / 业务进度 / 库存 / 收款；分组标题不可点；再点同一项或主栏 chip ✕ → **清空全部 query** |
| **keyword 叠加** | 订单号、客户、业务员、备注可与 preset 同时生效 |
| **状态/日期互斥** | 有 preset 时主栏隐藏状态多选与创建日期；无 preset 时展示 |
| **看板一致** | 列表与看板共用筛选，analytics 传 `quickFilter` / 日期 / keyword |
| **粒度** | 列表一行一单。行级 preset 为 **EXISTS：该单至少有一行**满足明细列表同口径 |

---

## 2. preset 列表

分组、preset ID、文案与明细列表相同（`SellOrderItemListQuickFilterCodes`）。

| 类型 | 订单列表口径 |
|------|----------------|
| 时间 | 前端展开 `startDate`/`endDate`（主单 `CreateTime`） |
| `pending_submit_audit` | 主单 status **新建 / 审核失败** |
| `has/no_sales_order_docs` | 订单头 `SALES_ORDER` 未删除附件 |
| 其余业务项 | 明细 `ApplyQuickFilter` 命中的行 → `SellOrder.Id` EXISTS |
