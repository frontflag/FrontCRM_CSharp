## 1. 业务定位

与需求模块同一套右栏「客户」摘要：现读客户档案，按单据主键解析，不信任行上 `customerId`（521 会抹掉）。

| 页面 | 绑定 | 页签顺序 | 默认 |
|------|------|----------|------|
| `/sales-order-items` | 单击明细行 → 所属销售订单的客户 | 操作 → 流程 → 客户 → 帮助 | 操作 |
| `/sales-orders` | 单击订单行 | 客户 → 帮助 | 帮助 |
| `/sales-orders/:id` | 进页按单头绑定（不跟明细行、不跟操作面板选行） | 操作 → 流程 → 客户 → 帮助 | 操作 |

列表单击行 **不** 自动切到「客户」。详情进页即绑单头，与操作面板是否已选明细无关。521 脱敏下详情可能不自动选第一行做操作聚合，客户页签仍按单头绑定。

---

## 2. 权限

完整面板裁剪与需求模块相同（`customer.read` + `CanAccessCustomer` + 非 521）。

网关不要求 `customer.read`。`source=sellOrder` / `sellOrderItem` 须能读该销售订单（`sales-order.read` 或等价 bypass，且 `CanAccessSalesOrder`）。

---

## 3. 接口

`GET /api/v1/customer-workspace?source=&id=`

本批新增 `source`：

| source | id | 客户来源 |
|--------|----|----------|
| `sellOrder`（别名 `sell-order` / `sell_order`） | 销售订单主键 | `SellOrder.CustomerId` |
| `sellOrderItem`（别名 `sell-order-item` / `sell_order_item`） | 销售明细主键 | 明细 → 主表 `CustomerId` |

已删除单据 → 404；无权访问该销售订单 → 403。DTO 字段与需求模块相同。

---

## 4. 交互

- 明细列表：操作 / 流程仍走原 `dataTabIds`；客户用第二套交互，**不要**把 `r-customer` 并进操作聚合请求。
- 明细行主键优先 `sellOrderItemId`（列表行未必有 `id`）。
- 订单列表：只在 `@row-click` 绑定；`setCurrentRow` / `@current-change` 不拉客户。
- 列表搜索 / 重置 / 刷新：清空右栏客户选中。
- 看板点击不加载客户。
