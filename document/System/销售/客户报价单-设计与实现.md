## 1. 需求摘要

### 1.1 功能目的

业务员在 **采购报价**（内部 `quoteitem`）基础上加 **利润系数** 得到 **发送报价**，整理成 **客户报价单** 对外打印 / PDF / 邮件发给客户。客户还价后，业务员通过 **版本升版** 调整报价并再次发送；确认后可 **转销售订单**。

### 1.2 业务链路

```text
需求明细 (rfqitem)
  → 采购报价 (quote / quoteitem，内部)
  → 客户报价单草稿 (按创建人隔离)
  → 客户报价单 v1…vN (对外，编号+版本唯一)
  → 销售订单 (可选，可重复、不拦截)
```

### 1.3 与内部报价的区别

| 概念 | 数据 | 用途 |
|------|------|------|
| **采购报价 / 内部报价** | `quote` + `quoteitem` | 采购员维护成本价；已有 `/quotes`、`/rfq-items` 采购报价面板 |
| **客户报价单** | `customer_quote` + `customer_quote_item` | 对外展示 **发送报价**；不含供应商信息 |
| **客户报价单草稿** | `customer_quote_draft` | 选材篮子，非正式单据 |

### 1.4 定稿决策一览

| 议题 | 结论 |
|------|------|
| 草稿隔离 | 按 **创建人**；各业务员独立篮子 |
| 生成正式单校验 | 所选草稿须 **同一 `customer_id`** 且 **同一 RFQ 业务员 `sales_user_id`**（空 ID 不参与冲突）；主表写入首个非空值 |
| 同一 `quoteitem` 重复进草稿 | **不允许**；`source_quote_item_id` 在草稿表唯一 |
| 草稿展示编号 | 展示 **来源内部报价单** `quote.quote_code` 等，非客户报价单号 |
| 客户报价单号 | **独立生成**；v1 仅编码（如 `CQ00034`）；v2 起 `{code}-{version}`（如 `CQ00034-2`） |
| 列表作废行 | **继续出现**；状态显示「作废」 |
| 已发送正式单 | **只读**；改价须 **复制升版**，`version_no` 递增 |
| 版本唯一 | 同一逻辑对象：`customer_quote_code` + `version_no`（同组共用 `group_id`） |
| 升版改行 | **允许增删明细**；新增行来自 **草稿** 或 **采购报价行**，**禁止** 无来源手工行 |
| 每组未发送版本 | **同时最多 1 个** `unsent` |
| 列表粒度 | **`customer_quote` 主表**；**每个版本一行**（不展开 `customer_quote_item`） |
| `quoteitem` 占用 | 出现在任一 **未作废** 版本的客户报价明细中即占用；v1 已发送仍占用 |
| 利润系数 | 主单 **全局系数**；行级可手工改发送价；行级 **锁定** 不参与批量重算 |
| 编辑页字段 | 含 **交期 / Date Code / 备注**（自采购报价快照，未发送可改） |
| PDF 币别 | **允许多币别**；按币别 **分块小计**，不做跨币别汇率汇总 |
| 转销售订单 | **仅已发送** 版本显示入口；业务员 **任选版本**；**整单转**、**可重复转**、**系统不拦截** |
| 版本变动 UI | 详情展示 **版本时间线** + 相邻版本 **明细 diff**（增删行、改价高亮） |

### 3.3 客户报价单编辑页

**布局（自上而下）：**

1. **操作面板**  
   - **导出与发送**（保存修改左侧；跳转 `/customer-quotes/:id/preview`；未发送 / 已发送 / 作废均可进入预览）  
   - 说明：打印、导出 PDF、邮件发送在预览页操作  
   - 进入预览前若编辑页有未保存修改，提示「保存并继续」或「不保存继续」  
   - `unsent`：保存修改  
   - `sent`：**生成新版本**（复制升版）  
   - `sent`：**转销售订单**  
   - `void`：仅查看 / 版本历史；预览可打印/导出，邮件发送隐藏  

2. **客户面板**  
   - 客户名称、客户主联系人（下拉选择该客户联系人；变更后邮箱带出选中人邮箱，仍可手改）、业务员（登录账号）

3. **备注面板**（客户信息下方）  
   - 主表 `remark`；`unsent` 可输入并随「保存」写入；已发送 / 作废只读  

4. **报价列表面板**  

| 列 | 说明 |
|----|------|
| 物料型号 / 品牌 | 只读快照 |
| 客户物料型号 / 客户品牌 | 只读快照（来自 rfqitem）；紧挨「品牌」列之后 |
| 数量 | |
| 采购报价 + 币别 | 快照，只读 |
| 发送报价 + 币别 | 可编辑（`unsent`）；行内「锁定 / 解锁」。未锁定为输入框；锁定后变为只读标签，且「设置发送报价」跳过该行 |
| 利润率 | 只读计算列，不落库。公式：`send_price / purchase_price`，显示 2 位小数。采购价为 0 或无效时显示 `—`。改发送价或「设置发送报价」后即时刷新。仅编辑页，不出现在对外预览/PDF |
| 交期 / Date Code / 备注 | 可编辑（`unsent`） |
| 报价单编号 / 报价日期 / 报价采购员 | 来源内部报价，只读 |

**操作控件（`unsent`）：**

- **报价利润系数**：放在「报价明细」标题右侧；2 位小数；旁侧 **仅图标** 按钮，悬停 tip「设置发送报价」  
- **设置发送报价**：对未锁定行执行 `send_price = purchase_price × profit_factor`；`send_currency = purchase_currency`  
- **添加明细**：从草稿选择 / 从采购报价行选择（须通过 §6.3 占用校验）  
- **删除明细行**：允许  

5. **日志面板**（报价明细下方）  
   - 仅记录预览页 **打印 / 导出 / 发送邮件**（写入 `log_operation`，`BizType=CustomerQuote`）  
   - 列：操作日期、操作人（登录账号）、操作、备注  
   - 发送邮件时备注 = 收件人邮箱；打印/导出备注为空  
   - 「设置已发送」不记入本面板  

**版本历史区（折叠或 Tab）：** 同 `group_id` 版本列表；选中两版相邻对比 diff（新增行、删除行、字段变更）。

### 3.4 预览 / 报表页

**路径：** `/customer-quotes/:id/preview`

按业务样稿 PDF 渲染（见 §8）。工具栏：

- 打印（浏览器打印，隐藏壳层；点击后写日志「打印」）  
- 导出 PDF（前端 `renderElementToPdfBlob`，与 [采购订单报表](../../CRM.Web/src/views/RFQ/PurchaseOrderReportPage.vue) 同模式；成功后写日志「导出」）

## 5. 状态与版本规则

### 5.1 草稿

```text
draft ──生成正式 v1──► converted（列表默认隐藏）
  │
  └──删除──► soft delete
```

### 5.2 正式单

```text
unsent ──保存──► unsent
unsent ──预览发送/标记发送──► sent（只读）
sent ──生成新版本──► 新记录 unsent（version+1）
sent / unsent ──作废──► void
```

- 同一 `group_id` 下 **最多一个** `status=unsent`。  
- **已发送不可编辑**；仅 **生成新版本** 或 **转 SO**、**预览**。

### 5.3 升版复制

从版本 `vN`（通常 `sent`）复制 → `vN+1`（`unsent`）：

- 复制：客户、联系人、邮箱、利润系数、全部明细快照（含锁定状态）。  
- 新 `id`、`version_no+1`、`previous_version_id=vN.id`。  
- 业务员在 `vN+1` 可 **增删改** 明细（增删遵守 §6.3）。

### 5.4 版本 diff（前端）

对比 `vK` 与 `vK-1`：

| 变更类型 | 展示 |
|----------|------|
| 新增行 | 绿色「新增」 |
| 删除行 | 灰色删除线（对比上一版存在、当前版 `is_deleted` 或缺失） |
| 发送价/数量/交期等 | 旧值 → 新值 |

## 6. 业务规则

### 6.1 加入草稿

**触发：** `/rfq-items` 采购报价行菜单。

校验：

1. 当前用户有 `customer-quote.write`（或等价权限）。  
2. `quoteitem` 存在且未软删。  
3. **不存在** 未删草稿且 `source_quote_item_id` 相同。  
4. **不存在** 占用（§6.3）。  
5. 数据权限：与 RFQ / 报价列表一致（销售范围）。

### 6.2 草稿 → 生成客户报价单 v1

**触发：** 草稿列表复选 → **生成客户报价单**。

校验：

1. 选中 ≥1 行，**同一 `customer_id`** 且 **同一 `sales_user_id`（RFQ 业务员快照）**；空 ID 不参与冲突（口径同 `CRM.Web/src/utils/customerQuotePrefill.ts` 与 `CustomerQuoteGenerateRules`）。  
2. 均为当前用户、`status=draft`。  
3. 所选 `quoteitem` 均通过 §6.3。  

行为：

1. 分配新 `group_id`、`customer_quote_code`、`version_no=1`、`status=unsent`。  
2. 主表 `customer_id` / `sales_user_id` 取所选草稿中 **首个非空** 值。  
3. 写入明细（采购价快照、发送价初始可等于采购价或空，由用户点「设置发送报价」）。  
4. 草稿行 → `converted`；`customer_quote_id` 回填。  
5. 跳转 `/customer-quotes/{id}/edit`。

### 6.3 `quoteitem` 占用

某 `source_quote_item_id` **不可** 再次进入草稿或客户报价明细，若：

- 已存在于 **任一未作废**（`status != void`）的 `customer_quote_item`（任意版本、任意组）；或  
- 已存在于 **未删** 且 `status=draft` 的 `customer_quote_draft`。

**说明：** v1 已发送且未作废，即使 v2 删掉了该行，该 `quoteitem` **仍占用**（防止同一采购报价对同一客户重复对外报价）。

### 6.4 未发送版本直接加行

当某 `group_id` 存在 `unsent` 版本时，允许在 **编辑页** 或 **rfq-items** 将采购报价行 **直接追加** 到该版本（不经过草稿），校验同 §6.3，且新行的 **客户 ID、RFQ 业务员** 须与主表兼容（`CustomerQuoteGenerateRules.AssertLineMatchesHeader`：空值不冲突，非空必须一致）。

### 6.5 设置发送报价

- 公式：`send_price = round(purchase_price × profit_factor, 6)`（小数位与 `quoteitem.unit_price` 对齐）。  
- `send_currency = purchase_currency`。  
- `is_locked = true` 的行 **跳过**。  
- 用户可手工改 `send_price` / `send_currency`（`unsent`）。  
- 编辑页「利润率」列（只读、不落库）：`send_price / purchase_price`，显示 2 位小数；`purchase_price = 0` 或无效时显示 `—`。

### 6.6 转销售订单

**入口：** 已发送版本编辑页 / 列表行操作。

**规则（定稿）：**

| 项 | 行为 |
|----|------|
| 可转版本 | **仅 `sent`**（`unsent` 隐藏或禁用） |
| 版本选择 | 业务员 **任选** 已发送版本 |
| 重复转 | **允许**；每次 **整单** 生成 **新销售订单**；**不做** 重复拦截 |
| 售价 | 明细 **发送报价** → `sellorderitem` 销售价 |
| 溯源 | `sellorderitem.quote_id` ← `source_quote_id`；`sellorderitemextend.quote_item_id` ← `source_quote_item_id`；`rfq_item_id` 带入；建议扩展字段 `customer_quote_id` / `customer_quote_item_id` 写 `sellorder` / `sellorderitemextend` 便于回溯 |
| 客单类型 | 默认 **客单** `type=1`；明细须满足 [报价溯源约束](../../实现方案/销售订单明细-添加明细与报价溯源约束.md) |

**跳转：** `SalesOrderCreate?customerQuoteId={id}`（新 query，服务端按客户报价单预填；与现有 `quoteIds` 并存）。

## 8. 报表与 PDF

### 8.1 版式（对照装箱 Invoice V2）

与 `/inventory/packing/:packingId/invoice-report` 同一套 **Invoice V2 chrome**（藏青顶栏、青绿斜纹、导视条、深蓝表头）。字段仍来自客户报价单主从。

**页眉：** 左 Logo + YOUR RELIABLE SUPPLIER；右 **报价单 / QUOTATION**，单号 `{customer_quote_code}-{version_no}`。

**单据信息两格：** 单据日期、报价单号。预览工具栏可切中/英文（表头与区块标题随切换，页眉双语固定）。

**双栏：** 左 Bill To（客户名、联系人、电话、邮箱、地址）；右 Quoter（本公司、销售员、电话）。

**明细表：**

| 列 | 数据源 |
|----|--------|
| 序号 / No. | `line_no` |
| 型号/品牌（中文） / PN/Brand（英文） | 上行 `mpn`（沿用型号加粗），下行 `brand`（常规字重、不加粗） |
| 客户型号/品牌（中文） / Customer PN/Brand（英文） | **按需列：** 任一行 `customer_mpn` 或 `customer_brand` 非空时，紧挨上一列之后出现；上行客户物料型号、下行客户品牌，样式同上。全部为空则不出现该列；列出现时空单元格显示 `—` |
| 数量 / Qty | `quantity` |
| 单价 / UP | `send_price` + 币别 |
| 金额 / Amount | qty × send_price |
| 交期 / LT | `lead_time` |
| 生产日期（中文） / DC（英文） | `date_code` |
| 备注 / Remark | `remark`。全部明细备注为空时列宽收窄，但**不少于英文表头 Remark 单行**（含单元格内边距、不折行）；有内容时恢复较宽列 |

**合计：** 表内合计行；多币别分行，**不做** 跨币别单一 Total。明细表**不垫空白行**。

**抬头备注：** 主表 `remark` 去掉首尾空白后非空时，在 QUOTATION DETAILS 表格正下方显示一行 `{remark}`（无「备注：」前缀）；为空则不出现该行。与条款区固定「备注」文案、明细行 `remark` 列无关。

**收款银行：** 本公司银行主数据 + `Prices valid for 3 days`。

**签核：** 左报价方、右客户（对齐 Invoice 出口方/收货方签章框）。

**不展示：** 采购价、利润系数、利润率、供应商、采购员。
