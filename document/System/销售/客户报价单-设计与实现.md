## 1. 需求摘要

### 1.1 功能目的

业务员在 **采购报价**（内部 `quoteitem`）基础上加 **利润系数** 得到 **发送报价**，整理成 **客户报价单** 对外打印 / PDF / 邮件发给客户。客户还价后，业务员通过 **版本升版** 调整报价并再次发送；确认后可 **转销售订单**。

### 1.2 业务链路

```text
需求明细 (rfqitem)
  → 采购报价 (quote / quoteitem，内部)
  → 客户报价单草稿 (按创建人隔离)
  → 客户报价单 v1…vN (对外，编号+版本唯一)
  → 销售订单 (可选，可重复、不拦截)
```

### 1.3 与内部报价的区别

| 概念 | 数据 | 用途 |
|------|------|------|
| **采购报价 / 内部报价** | `quote` + `quoteitem` | 采购员维护成本价；已有 `/quotes`、`/rfq-items` 采购报价面板 |
| **客户报价单** | `customer_quote` + `customer_quote_item` | 对外展示 **发送报价**；不含供应商信息 |
| **客户报价单草稿** | `customer_quote_draft` | 选材篮子，非正式单据 |

### 1.4 定稿决策一览

| 议题 | 结论 |
|------|------|
| 草稿隔离 | 按 **创建人**；各业务员独立篮子 |
| 同一 `quoteitem` 重复进草稿 | **不允许**；`source_quote_item_id` 在草稿表唯一 |
| 草稿展示编号 | 展示 **来源内部报价单** `quote.quote_code` 等，非客户报价单号 |
| 客户报价单号 | **独立生成**；对外展示 **`{code}-{version}`**，如 `CQ20260001-2` |
| 已发送正式单 | **只读**；改价须 **复制升版**，`version_no` 递增 |
| 版本唯一 | 同一逻辑对象：`customer_quote_code` + `version_no`（同组共用 `group_id`） |
| 升版改行 | **允许增删明细**；新增行来自 **草稿** 或 **采购报价行**，**禁止** 无来源手工行 |
| 每组未发送版本 | **同时最多 1 个** `unsent` |
| 列表粒度 | **每个版本一行** |
| `quoteitem` 占用 | 出现在任一 **未作废** 版本的客户报价明细中即占用；v1 已发送仍占用 |
| 利润系数 | 主单 **全局系数**；行级可手工改发送价；行级 **锁定** 不参与批量重算 |
| 编辑页字段 | 含 **交期 / Date Code / 备注**（自采购报价快照，未发送可改） |
| PDF 币别 | **允许多币别**；按币别 **分块小计**，不做跨币别汇率汇总 |
| 转销售订单 | **仅已发送** 版本显示入口；业务员 **任选版本**；**整单转**、**可重复转**、**系统不拦截** |
| 版本变动 UI | 详情展示 **版本时间线** + 相邻版本 **明细 diff**（增删行、改价高亮） |

## 5. 状态与版本规则

### 5.1 草稿

```text
draft ──生成正式 v1──► converted（列表默认隐藏）
  │
  └──删除──► soft delete
```

### 5.2 正式单

```text
unsent ──保存──► unsent
unsent ──预览发送/标记发送──► sent（只读）
sent ──生成新版本──► 新记录 unsent（version+1）
sent / unsent ──作废──► void
```

- 同一 `group_id` 下 **最多一个** `status=unsent`。  
- **已发送不可编辑**；仅 **生成新版本** 或 **转 SO**、**预览**。

### 5.3 升版复制

从版本 `vN`（通常 `sent`）复制 → `vN+1`（`unsent`）：

- 复制：客户、联系人、邮箱、利润系数、全部明细快照（含锁定状态）。  
- 新 `id`、`version_no+1`、`previous_version_id=vN.id`。  
- 业务员在 `vN+1` 可 **增删改** 明细（增删遵守 §6.3）。

### 5.4 版本 diff（前端）

对比 `vK` 与 `vK-1`：

| 变更类型 | 展示 |
|----------|------|
| 新增行 | 绿色「新增」 |
| 删除行 | 灰色删除线（对比上一版存在、当前版 `is_deleted` 或缺失） |
| 发送价/数量/交期等 | 旧值 → 新值 |

## 6. 业务规则

### 6.1 加入草稿

**触发：** `/rfq-items` 采购报价行菜单。

校验：

1. 当前用户有 `customer-quote.write`（或等价权限）。  
2. `quoteitem` 存在且未软删。  
3. **不存在** 未删草稿且 `source_quote_item_id` 相同。  
4. **不存在** 占用（§6.3）。  
5. 数据权限：与 RFQ / 报价列表一致（销售范围）。

### 6.2 草稿 → 生成客户报价单 v1

**触发：** 草稿列表复选 → **生成客户报价单**。

校验：

1. 选中 ≥1 行，**同一 `customer_id`**（空客户 ID 不参与冲突判断）。  
2. 均为当前用户、`status=draft`。  
3. 所选 `quoteitem` 均通过 §6.3。  
4. 同一客户校验口径同 `CRM.Web/src/utils/quoteSalesOrderPrefill.ts`。

行为：

1. 分配新 `group_id`、`customer_quote_code`、`version_no=1`、`status=unsent`。  
2. 写入明细（采购价快照、发送价初始可等于采购价或空，由用户点「设置发送报价」）。  
3. 草稿行 → `converted`；`customer_quote_id` 回填。  
4. 跳转 `/customer-quotes/{id}/edit`。

### 6.3 `quoteitem` 占用

某 `source_quote_item_id` **不可** 再次进入草稿或客户报价明细，若：

- 已存在于 **任一未作废**（`status != void`）的 `customer_quote_item`（任意版本、任意组）；或  
- 已存在于 **未删** 且 `status=draft` 的 `customer_quote_draft`。

**说明：** v1 已发送且未作废，即使 v2 删掉了该行，该 `quoteitem` **仍占用**（防止同一采购报价对同一客户重复对外报价）。

### 6.4 未发送版本直接加行

当某 `group_id` 存在 `unsent` 版本时，允许在 **编辑页** 或 **rfq-items** 将采购报价行 **直接追加** 到该版本（不经过草稿），校验同 §6.3。

### 6.5 设置发送报价

- 公式：`send_price = round(purchase_price × profit_factor, 6)`（小数位与 `quoteitem.unit_price` 对齐）。  
- `send_currency = purchase_currency`。  
- `is_locked = true` 的行 **跳过**。  
- 用户可手工改 `send_price` / `send_currency`（`unsent`）。

### 6.6 转销售订单

**入口：** 已发送版本编辑页 / 列表行操作。

**规则（定稿）：**

| 项 | 行为 |
|----|------|
| 可转版本 | **仅 `sent`**（`unsent` 隐藏或禁用） |
| 版本选择 | 业务员 **任选** 已发送版本 |
| 重复转 | **允许**；每次 **整单** 生成 **新销售订单**；**不做** 重复拦截 |
| 售价 | 明细 **发送报价** → `sellorderitem` 销售价 |
| 溯源 | `sellorderitem.quote_id` ← `source_quote_id`；`sellorderitemextend.quote_item_id` ← `source_quote_item_id`；`rfq_item_id` 带入；建议扩展字段 `customer_quote_id` / `customer_quote_item_id` 写 `sellorder` / `sellorderitemextend` 便于回溯 |
| 客单类型 | 默认 **客单** `type=1`；明细须满足 [报价溯源约束](../../实现方案/销售订单明细-添加明细与报价溯源约束.md) |

**跳转：** `SalesOrderCreate?customerQuoteId={id}`（新 query，服务端按客户报价单预填；与现有 `quoteIds` 并存）。

## 8. 报表与 PDF

### 8.1 版式（对照样稿）

**页眉：** Logo、公司中英文名称、标题 **Quotation / 报价单**、Date、**Quotation No** = `{customer_quote_code}-{version_no}`。

**Bill To：** Company、Attn、Tel、Email、Add ← 客户 + 主联系人。

**明细表：**

| 列 | 数据源 |
|----|--------|
| No. | `line_no` |
| Part No. | `mpn` |
| MFG | `brand` |
| Qty | `quantity` |
| Unit Price | `send_price` + 币别代码 |
| Amount | qty × send_price（同币别） |
| Lead Time | `lead_time` |
| Date Code | `date_code` |
| Remark | `remark` |

**页脚：**

- **分币别合计**（如 `Total USD: …`、`Total HKD: …`）；**不做** 跨币别单一 Total。  
- 条款：`Prices valid for 3 days`（首期写死）。  
- Bank info：当前用户 **所属公司** 主数据。  
- Prepared by：业务员；Checked / Approved：首期留空。

**不展示：** 采购价、利润系数、供应商、采购员。

## 12. 与 EBS 差异（FrontCRM 定稿）

| 能力 | EBS | FrontCRM 本期 |
