---

## 1. 目标

按销售订单整单明细生成 **Certificate of Component / 质量保证书**（含货表），与客户主数据级质保书（无货表）区分。三租户皮肤映射与 Packing 一致。

---

## 2. 门控与数据

| 项 | 规则 |
|----|------|
| 状态 | `status >= 10`（审核通过/进行中/完成）；驳回/取消不可打；「打印销售订单」同口径 |
| 明细 | 整单全部明细行 |
| DC | 行 `dateCode`，空则 `—` |
| 客户订单号 | 行 `customerSo` |
| 文件编号语境 | 销售订单号（导出文件名等） |
| 甲方代表人 | 业务员中文名：详情 API 按 `salesUserId` 填充 `salesUserRealName`（User.RealName）；缺则回退 `salesUserName` |
| 甲方电话/地址 | 公司档案默认 `phone` / `address` |
| 乙方 | 关联客户主数据联系人/电话/地址，缺 `—` |
| 质保期条款 | constants 写死 6 个月质保 + 质量分析/修复退换/非甲方原因免责（中/英） |
