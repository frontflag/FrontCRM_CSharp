## 1. 目标

三租户打印销售订单报表时，**版式语言与配色**与同租户 Packing List / Commercial Invoice 一致，避免 SO 仍停留在旧橙表。

非目标：业务列表页皮肤。采购订单报表已按同一模式落地，见 [采购订单报表打印-三租户皮肤-设计与实现](../采购/采购订单报表打印-三租户皮肤-设计与实现.md)。

---

## 2. 架构

| 层 | 说明 |
|----|------|
| 租户来源 | `VITE_TENANT_ID` → `LOGIN_TENANT_ID` |
| 皮肤选择 | `resolveSalesOrderReportSkin(tenantId)`（与 Packing/Invoice 映射相同） |
| 数据 | 既有 `docBind`（卖方/买方/交付、含税明细、附加信息与条款） |
| 版式 | 三套皮肤 + 共用 `SalesOrderReportBody` |

```
SalesOrderReportPage
  → resolveSalesOrderReportSkin(LOGIN_TENANT_ID)
  → SalesOrderReportSkin{Semicore|Idesemi|Ecoinf}
```

## 4. 皮肤差异摘要

| 租户 | 皮肤组件 | 主题色 | 页眉 | 三栏 / 表头 |
|------|----------|--------|------|-------------|
| semicore | Idesemi | `#0D1F35` / `#020612` | 深色顶栏 + Meta 卡片 | 三列地址块；深色表头 |
| idesemi | Ecoinf | `#6DC5F6` / `#11161F` | 大标题左、Logo 右 | 三列区块 + 青竖条；斑马纹 |
| ecoinf | Semicore | `#A8D070` / `#101010` | Logo 左、公司/标题居中 | 绿表头三栏表；绿附加条 |

区块顺序：页眉 → 卖方/买方/交付 → 明细 → 金额汇总 → 附加信息/条款 → 签字。

明细表只打印实际行；**不补空白行、不显示「以下空白」**。无明细时显示「暂无明细」。

- 金额权限掩码、印章开关、PDF 导出三皮肤均可用。
