## 2. 左栏：刷新客户

| 字段 | 说明 |
|------|------|
| 允许刷新已完成业务节点 | `el-switch`：允许 / 不允许（默认不允许） |
| 存储 | `sysparam.ParamCode = System.Sales.AllowRefreshCompletedBizNodes`（Boolean） |
| API | `GET` 需 `refresh-customer.read`；`PUT` 需 `refresh-customer.write` → `/api/v1/sales-params/allow-refresh-completed-biz-nodes` |

### 行为口径

- **不允许（默认）**：已出库出库通知、已出库完成装箱、已出库出库单、已核销应收、已开票销项 → 阻断「刷新客户」  
- **允许**：出库通知 / 装箱 / 出库即使已完成也可同步客户；应收核销与销项开票不再阻断，但本版不改写其客户字段
