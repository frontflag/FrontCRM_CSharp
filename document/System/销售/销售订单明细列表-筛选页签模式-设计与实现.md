## 1. 业务定位

将主栏搜索区中**适合做成单选桶**的下拉筛选项，可选地转为表格/看板上方的**全宽页签条**，便于在「全部 / 各状态」之间快速切换并立即查询。

| 概念 | 说明 |
|------|------|
| **页签模式** | 用户偏好：把某一个筛选项从 `el-select` 换成页签条 |
| **单维度** | 同一时间只允许一个维度处于页签模式（互斥） |
| **关闭页签** | 退出页签模式，恢复对应下拉；**不清空**当前筛选值 |
| **与 preset** | 左栏快捷检索激活时：进度类页签条隐藏，菜单中进度项也隐藏；**币别**页签与菜单项仍可用 |

文本框、日期范围**不**纳入页签模式。

## 2. 设计要求（定稿）

### 2.1 可纳入的下拉维度

| 维度 key | 搜索栏字段 | 页签形态 |
|----------|------------|----------|
| `currency` | `transactionCurrency` | 全部 / 人民币 / 外币 |
| `purchase` | `purchaseProgressStatus` | 全部 / 待采购 / 采购中 / 采购完成 |
| `stockIn` | `stockInProgressStatus` | 全部 / 待入库 / 部分入库 / 入库完成 |
| `stockOutNotify` | `stockOutNotifyProgressStatus` | 全部 / 未通知 / 部分通知 / 通知完成 |
| `stockOut` | `stockOutProgressStatus` | 全部 / 待出库 / 部分出库 / 出库完成 |
| `receipt` | `receiptProgressStatus` | 全部 / 待收款 / 部分收款 / 收款完成 |
| `invoice` | `invoiceProgressStatus` | 全部 / 待开票 / 部分开票 / 开票完成 |

- 币别为业务桶（`rmb` / `foreign`），**不是** ISO 币种列表。
- 进度类选项值与现有下拉一致：`0 | 1 | 2`；「全部」对应清空该字段（`undefined` / `''`）。

### 2.2 交互

| 项 | 规则 |
|----|------|
| 入口 | 看板按钮旁齿轮 →「关闭页签」+「页签模式 ▸」子菜单 |
| 开启 | 子菜单点某一维度 → 该维度进入页签模式，对应下拉隐藏，页签条出现在表格/看板上方 |
| 切换维度 | 再点另一维度 → 仅切换当前页签维度（单维度）；各字段筛选值各自保留 |
| 关闭 | 「关闭页签」→ 维度变为 `off`，下拉恢复；筛选值保留 |
| 点页签 | 写入对应 filter 后**立即** `runSearch()`（与下拉需点「查询」不同） |
| 列表 / 看板 | 共用同一套 filter / URL query |

### 2.3 与左栏 preset 的互斥

| 场景 | 行为 |
|------|------|
| preset **未**激活 | 子菜单展示全部 7 个维度；进度类页签条可显示 |
| preset **已**激活 | 主栏日期 + 六 progress 下拉本就隐藏；**进度类页签条隐藏**；子菜单**只保留「交易币别」**（进度项隐藏而非禁用） |
| 币别 + preset | 币别页签条仍可显示；币别下拉仍隐藏（若当前维度为币别） |
| 曾选进度维度后开 preset | 偏好可仍记为进度维度，但页签条与菜单项不展示进度；清除 preset 后进度页签条按偏好恢复 |

### 2.4 明暗主题

| 主题 | 未选中页签背景 |
|------|----------------|
| 亮色 | `#E8EDF5` |
| 暗色 | `var(--crm-layer-1)` |

选中态：青色顶边 + `color-mix` 与 `layer-2` 混合，与现有列表视觉一致。

### 2.5 不做的范围（本版）

- 多维度同时开多条页签条
- 采购订单明细列表等其它页面（可复用同一模式，另开文档）
- 将日期、文本框做成页签

## 3. 实现方法

### 3.1 文件

| 文件 | 职责 |
|------|------|
| `CRM.Web/src/utils/salesOrderItemListTabMode.ts` | 维度枚举、localStorage 读写、币别/进度 tab↔filter、是否进度维度 |
| `CRM.Web/src/views/RFQ/SalesOrderItemList.vue` | 齿轮菜单、页签条、按维度隐藏下拉、preset 时隐藏进度页签/菜单项 |
| `CRM.Web/src/locales/zh-CN.ts` / `en-US.ts` | `salesOrderItemList.settingsMenu.*`、`currencyTabs.*`；维度文案复用 `filters.*` / `extendProgress.*` |

**无需改后端**：页签只是前端把同一 query 字段写进 URL/API（`transactionCurrency`、各 `*ProgressStatus`）。

### 3.2 偏好存储

| Key | 值 |
|-----|-----|
| `crm.so-item-list.tab-mode` | `off` \| `currency` \| `purchase` \| `stockIn` \| `stockOutNotify` \| `stockOut` \| `receipt` \| `invoice` |
| `crm.so-item-list.tab-mode.currency`（遗留） | 读：若新 key 无值且旧 key=`1` → 视为 `currency`；写：与新 key 同步，便于旧逻辑兼容 |

浏览器本地存储，**非**按用户账号服务端偏好。

### 3.3 前端关键逻辑

```
tabModeDimension = readSoItemTabMode()   // 'off' | 某维度

开启维度 D:
  tabModeDimension = D
  writeSoItemTabMode(D)
  隐藏 filters 对应 el-select
  若 D 为进度且 presetActive → 不显示页签条；否则显示 so-filter-tabs

关闭:
  tabModeDimension = 'off'
  writeSoItemTabMode('off')
  恢复下拉（筛选值不变）

点页签:
  币别 → filters.transactionCurrency = '' | 'rmb' | 'foreign'
  进度 → filters[progressKey] = undefined | 0 | 1 | 2
  runSearch()
```

| 计算属性 | 含义 |
|----------|------|
| `filterTabStripVisible` | `dimension≠off` 且（非进度 **或** 无 preset） |
| `visibleTabModeMenuOptions` | 有 preset 时仅 `['currency']`，否则全部 `SO_ITEM_TAB_MODE_OPTIONS` |
| `filterTabOptions` | 按当前维度生成「全部 + 选项」 |
| `activeFilterTabId` | 由当前 filter 值映射 |

### 3.4 UI 结构（摘要）

```
搜索栏: [keywords…] [币别下拉?] [日期?] [进度下拉×6?] [查询][重置][看板][⚙]
主内容:
  [页签条?]          ← so-filter-tabs，与表格顶边贴合
  列表 CrmDataTable | 看板 SalesOrderItemListBoard
```

样式类：`so-filter-tabs` / `so-filter-tabs__item`；容器 `so-main-panel--with-filter-tabs` 去掉表格顶圆角以便页签与表头衔接。

### 3.5 扩展新下拉为页签（清单）

若后续要把新的单选下拉纳入页签模式：

1. 在 `SoItemTabModeDimension` / `SO_ITEM_TAB_MODE_OPTIONS` 增加维度  
2. 若属进度类：扩展 `isProgressTabDimension`、`progressDimensionToFilterKey`  
3. 列表页：`TAB_MODE_FILTER_I18N`、对应 `el-select` 的 `v-if="tabModeDimension !== '…'"`、`filterTabOptions` 分支  
4. 与 preset 互斥：进度类走现有「隐藏页签 + 隐藏菜单项」；非进度类需单独约定  
5. 更新本文档与 QA 对照表
