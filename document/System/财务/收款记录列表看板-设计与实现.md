## 1. 业务定位

在收款记录列表内切换统计看板。统计范围 = **当前搜索栏筛选结果全量**（含新建 / 确认 / 取消，不硬过滤确认），不是当前页，也不是财务分析透镜。

金额为单头 **收款金额原币**，按币别分开展示，**不折算美金**，禁止跨币别相加。计数为 **收款单数**（单头）。

## 2. 交互

| 项 | 行为 |
| --- | --- |
| 入口 | 搜索栏「查询」之后、「设置」齿轮之前 |
| 默认 | 列表 |
| 看板态 | 隐藏顶部当前页统计卡、表格、分页；筛选与页签仍可用 |
| 帮助 | 看板态覆盖为收款记录看板说明 |
| 页签 | 保留齿轮；看板跟当前页签筛选 |

---

## 3. 口径摘要

| 指标 | 口径 |
| --- | --- |
| 收款金额 | 单头 `ReceiptAmount` + `ReceiptCurrency`；KPI / 趋势 / 业务员饼 / Top10 按原币分面 |
| 收款客户数 | 头表 `CustomerId` 去重；空不计 |
| 收款单数 | 单头数，与列表总条数同一集合 |
| 趋势 | 收款日 `ReceiptDate`；收款单数 + 各原币金额；天/周/月。无收款日不进趋势 |
| 核销状态饼 | 整单汇总核销状态，按**单数** |
| 业务员 | 头表 `SalesUserId`；空归「未分配业务员」；按原币分面 |
| 排名 | 各原币独立 Top10 客户、Top10 业务员 |

521 时金额脱敏，饼图/排名改按**单数**，客户名不展示。

---

## 4. API

`GET /api/v1/finance/receipts/analytics/{dashboard,trends,breakdowns,rankings}`  
参数与 `GET /api/v1/finance/receipts` 相同。须注册在 `[HttpGet("{id}")]` **之前**。

列表与看板共用 `FinanceReceiptListFilter`。用途筛选按明细 `receipt_purpose`（头表用途字段不落库）。
