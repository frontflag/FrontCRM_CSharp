## 一、功能定位

为财务 7 个列表提供与入库/出库一致的**可审计 CSV 导出**：

1. 按**当前筛选**服务端导出，上限 **50000** 行；
2. 枚举写业务名称；金额列后紧跟币别（ISO：`CNY`/`USD`/`EUR`）；客商拆成中文/英文两列；
3. 导出 API **服务端**写入 `log_operation`（禁止仅前端二次记日志）；
4. 权限与列表 **read** 相同；511/521 脱敏与列表一致（口径 B：文件与日志均脱敏）。

本能力属于 **`log_operation` 操作审计**，不是 Telemetry 行为埋点。

## 二、已确认设计口径

| # | 项 | 决定 |
|---|-----|------|
| 1 | 格式 | CSV UTF-8 BOM，Excel 可直接打开；**不**引入新的 xlsx 库 |
| 2 | 文件名 | `{业务名}_yyMMddHHmm.csv`（如 `付款记录_2608140709.csv`） |
| 3 | 筛选 | 与列表当前 query 一致（不含分页） |
| 4 | 币别 | 同行每个金额列后各跟一列币别，即使币别相同也不合并 |
| 5 | 客商 | 中文名称 + 英文名称分列，不导出 extend-col 单列 |
| 6 | 不含 | 操作列；不发明单价列（这些列表只有金额） |
| 7 | 预收款/货代 | 页面上独立「币别」列不进导出，币别跟在各金额后 |
| 8 | 币别来源 | 付款 `PaymentCurrency`；收款/货代 `ReceiptCurrency`；发票/应收/预收 `Currency` |

## 五、脱敏

| 列表 | 规则 |
|------|------|
| 付款 / 进项发票 | 511：供应商中英文、银行为 `***`；进项金额列为空 |
| 收款 / 销项 / 应收 / 预收 | 521：客户中英文（应收另含业务员）为 `***`；金额列为空 |
| 货代付款 | 521：仅客户中英文为 `***`，金额仍导出（与列表 API 只掩客户名一致） |

无权限筛选项（如供应商名、客户 Id）不写入 `filters`。

## 六、实现索引

- CSV / 标签：`CRM.API/Utilities/FinanceExportHttp.cs`（复用 `InventoryExportHttp.CsvFile`、`CollectForExportAsync`）
- 审计 kind：`ExportAuditKinds`、`FinanceExportActionTypes`、`ExportOperationAudit` 条件摘要
- 客商英文：列表查询补全 `OfficialName` / `EnglishOfficialName`（销项、预收、货代）
- 前端：各列表 `exportList` + `downloadCsvBlob` / `withExportTimestamp`

---

## 七、已知限制

- 货代付款列表查询为先筛后内存分页，导出走同一路径；业务量通常较小。
- 进项发票实体无独立发票类型字段，CSV 固定「增值税专用发票」（与列表默认一致）。
- 进项/销项发票实体无创建人姓名，CSV「创建人」为空（与列表 `-` 一致）。
