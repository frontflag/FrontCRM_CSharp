## 1. 业务定位

将搜索栏中适合做成单选桶的下拉，可选转为表格上方全宽页签条。**单维度**；关闭页签不清筛选值；点页签立即查询。

文本、备注、日期不纳入。首版**只做页签模式**；本页既有下拉/日期 `@change` 即查行为**保持不变**。无需改后端（`status`、`paymentMode` 已支持）。

---

## 2. 设计要求（定稿）

### 2.1 可纳入维度

| 维度 key | 搜索栏字段 | 页签形态 |
|----------|------------|----------|
| `status` | `status` | 全部 + 新建 / 待审核 / 审核通过 / 付款完成 / **审核失败** / **取消**（7 格，与下拉一致） |
| `paymentMode` | `paymentMode` | 全部 + 银行转账 / 现金 / 支票 / 承兑汇票 |

### 2.2 交互与视觉

遵循 UI 规范 §10：齿轮在查询旁；类名 `fp-filter-tabs`。

## 3. 实现方法

| 文件 | 职责 |
|------|------|
