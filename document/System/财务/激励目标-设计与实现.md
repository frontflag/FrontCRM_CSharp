## 1. 目标与非目标

### 1.1 目标（一期）

1. 每人按当前身份保存 **本期计划提成**、**年度计划提成**（业务 USD）。  
2. 桌面展示实际、目标、完成度。  
3. 实际值从现成 `commission_dynamic` / `commission_locked` 汇总，**不重算提成**。

### 1.2 非目标（一期不做）

| 项 | 说明 |
|----|------|
| 经理下达 / 团队目标 | 别人不可见、不可写 |
| OKR、评分、评语 | 独立考核以后再做 |
| 销售额 / GP / 单量定额 | 只做提成金额 |
| 历史窗编辑、趋势图 | 只维护「当前开放窗」和「当前年」 |
| 独立菜单 | 只放控制台 |
| 扩展 `work_task` | 跟进任务与定额分开 |
| 改提成引擎 | 不写动态表 / 锁定表 |

### 1.3 产品定稿（已冻结）

与 [实施方案 §0](../../实现方案/激励目标实施方案.md) 同一张表，实现时不再分叉。

| 项 | 口径 |
|----|------|
| 指标 | 计划提成金额（USD，2 位） |
| 本期 | `CommissionTerm.GetOpenWindow`，`period_key = Term` |
| 年度 | 上海日历年 |
| 谁设 | 仅本人 |
| 实际 | 本期 = 当前开放窗动态表合计；年度 = 当年锁定 + 当年动态 |
| 完成度 | 实际 ÷ 目标；未设或目标 ≤ 0 →「未设置」 |
| 身份 | 采购主部门看采购提成，销售主部门看业务提成 |
| 控制台卡片 | 仅销售部（`identityType=1`）、采购部（`2/3` 或 `belongsToPurchaseDept`）、**SYS_ADMIN** 显示；财务/物流/商务等即使有 read 也不出卡片 |
| 超额 | 实际 > 目标允许，完成度可超过 100% |

## 2. 口径

### 2.1 日切

公司日历日：`Asia/Shanghai`。开放窗、年度、`calc_month` 都按上海日。

### 2.2 「自己」与角色

| 数据 | 取值 |
|------|------|
| 目标行 | `incentive_target.user_id` = 当前用户 Id |
| 提成行 | `commission_*.user_id` = 当前用户 Id |
| `role_type` | 采购主部门（`identityType` 2/3）→ `2`；否则 `1` |

不跟销售/采购分析的 `SaleDataScope` / `PurchaseDataScope`。经理也只看自己的定额。

### 2.3 实际值公式

```text
open = CommissionTerm.GetOpenWindow(上海今天)

本期实际 = Σ commission_dynamic.commission_usd
           （本人、当前 role_type、calc_month ∈ 开放窗两个 yyyy-MM）

年度实际 = Σ commission_locked.commission_usd
           （本人、当前 role_type、calc_month 年 = 今年）
         + Σ commission_dynamic.commission_usd
           （本人、当前 role_type、calc_month 年 = 今年）
```

锁定行已不在动态表，相加不重复。跨年双月（如 12–1 月）按 **`calc_month` 自然年** 切开，不用 `term` 的年份。

### 2.4 完成度

```text
hasTarget ⇔ 存在未删行且 target_amount_usd > 0
completionPct = hasTarget ? Round(actual / target × 100, 1) : null
```

界面超过 `999.9` 时显示 `999.9%+`。实际为 0 且已设目标 → `0.0%`。

### 2.5 窗切换

偶数月 2 日（及 `GetOpenWindow` 回退规则）之后，`period_key` 变成新 Term。桌面按新 key 找目标；找不到即「未设置」。旧行保留，一期不提供改历史。

## 4. API 与服务

| 方法 | 路径 | 权限 |
|------|------|------|
| `GET` | `/api/v1/incentive-targets/me` | `incentive-target.read` |
| `PUT` | `/api/v1/incentive-targets/me` | `incentive-target.write`（一次写本期+年度） |

服务建议：`IIncentiveTargetService` / `IncentiveTargetService`。

- 汇总提成用 LINQ，**不要**调提成重算。  
- `period_key` 只由服务端按今天生成。  
- 冒充：写接口 403。  
- 请求体若带 `userId` / `roleType`：**忽略**。  
- 511 / 521：实际与完成度置空，目标仍返回。

DTO 与校验细则见实施方案 §4。
