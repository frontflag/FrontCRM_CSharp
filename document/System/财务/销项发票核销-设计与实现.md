## 1. 业务定位

将 **已开具的销项发票** 与 **销售出库产生的应收款** 做金额匹配，形成可追溯的匹配流水。  
**现金冲账**仍走既有 **收款核销**（`finance_receivable_write_off`）；本功能 **不**替代收款核销。

| 概念 | 说明 |
|------|------|
| **应收款** | 出库完成后按「出库单 + 销售明细」生成；`Amount` 为匹配基数 |
| **销项发票** | 客户侧开票；匹配进度用 `Match*`；收款进度用 `Receive*`（派生缓存） |
| **匹配流水** | `finance_sell_invoice_write_off`：账本真相 = **发票头 + 应收** |
| **收款核销** | 来款 ↔ 同一 `finance_receivable_id`；与匹配流水并列、互不替代 |

```text
销项发票 ──匹配流水──► finance_receivable ◄──收款核销流水── 收款明细/预收
                              │
                              └─ stock_out_id（展示出库，不当匹配键）
```

**允许顺序：** 未开票可先收款核销；开票匹配后仍允许「先收款后开票/后匹配」。未匹配前发票 `Receive* = 0`，匹配后按公式从已匹配应收的 `verified_*` 汇总。

## 2. 冻结口径

| 项 | 口径 |
|---|---|
| 账本匹配键 | **发票头 ↔ `finance_receivable_id`** |
| 应收两套余额 | 收款：`verified_done / verified_to_be / verification_status`（已有）；开票匹配：新建 `invoice_match_*` |
| 发票两套字段 | 匹配：新建 `MatchDone / MatchToBe / MatchStatus`；收款：既有 `ReceiveDone / ReceiveToBe / ReceiveStatus`（**仅派生缓存**） |
| 匹配基数 | 应收：`Amount`；发票：`InvoiceTotal − Σ(有效匹配流水)` |
| 队列入列 | 同客户 + 币别，须同时有 **待匹配发票** 且 **待匹配应收** |
| 候选发票 | 未作废、蓝字、可匹配状态（默认已开票）、`MatchToBe > 0` |
| MVP | **仅正向**；无反核销、无匹配流水页 |
| 废弃 | **收款明细直改发票 `Receive*`**（旧 `FinanceReceiptService` 路径） |

**勿混用：**

- 右栏「待核销开票金额」= 应收 `invoice_match_to_be`，**不是** `verified_to_be`
- 左栏/发票列表「已核销/待核销」= 发票 `Match*`，**不是** `Receive*`
- 发票列表「收款状态」= `ReceiveStatus`（派生）

## 3. 数据模型

### 3.1 新建 `finance_sell_invoice_write_off`

| 字段 | 必填 | 说明 |
|---|---|---|
| `FinanceSellInvoiceWriteOffId` | 是 | PK |
| `finance_sell_invoice_id` | 是 | 销项发票主表 |
| `finance_sell_invoice_item_id` | 否 | 预留，MVP 恒 NULL |
| `finance_receivable_id` | 是 | **匹配键** |
| `stock_out_id` | 否 | 冗余（自应收带出，便于展示） |
| `Amount` | 是 | 本次匹配金额 |
| `Currency` | 是 | 币别 |
| `operator_user_id` / `CreateTime` / `is_deleted` | | 审计；软删列预留反核销 |

### 3.2 `financesellinvoice` 补字段

| 字段 | 说明 |
|------|------|
| `MatchDone` | 已匹配金额（票↔应收） |
| `MatchToBe` | 待匹配金额 |
| `MatchStatus` | 0 未匹配 / 1 部分 / 2 完成 |

既有 `ReceiveDone` / `ReceiveToBe` / `ReceiveStatus`：**保留**，改为按 §4.2 派生回写，禁止收款明细直接加减。

### 3.3 `finance_receivable` 补字段

| 字段 | 说明 |
|------|------|
| `invoice_match_done` | 已匹配开票金额 |
| `invoice_match_to_be` | 待匹配开票金额（右栏「待核销开票金额」） |
| `invoice_match_status` | 0/1/2 |

初始化（出库生成应收时 / 迁移回填）：`invoice_match_to_be = Amount`，`invoice_match_done = 0`，`invoice_match_status = 0`。

### 3.4 关联图

```text
financesellinvoice（Match* / Receive*）
        │  finance_sell_invoice_write_off（账本）
        ▼
finance_receivable（verified_* 收款｜invoice_match_* 开票）
        │
        ├─◄── finance_receivable_write_off（收款核销账本）
        │
        └─ stock_out_id → 出库单（右扩展展示）
```

## 4. 余额与收款派生公式

### 4.1 匹配（票 ↔ 应收）

```text
发票 MatchDone   = Σ(有效匹配流水 where finance_sell_invoice_id)
发票 MatchToBe   = InvoiceTotal - MatchDone
发票 MatchStatus = 0/1/2（相对 InvoiceTotal）

应收 InvoiceMatchDone = Σ(有效匹配流水 where finance_receivable_id)
应收 InvoiceMatchToBe = Amount - InvoiceMatchDone
应收 InvoiceMatchStatus = 0/1/2（相对 Amount）

提交：Σ allocations ≤ 发票 MatchToBe
      每行 amount ≤ 该应收 InvoiceMatchToBe
      同客户、同币别
```

### 4.2 发票收款进度（Receive*，派生）

对发票 I，仅统计**已匹配到的**应收：

```text
对每个已匹配应收 R：
  linkAmount(I,R) = Σ(匹配流水 I→R)
  cashFrom(R)     = min(linkAmount(I,R), R.VerifiedDone)

ReceiveDone   = Σ cashFrom(R)
ReceiveToBe   = MatchDone - ReceiveDone
ReceiveStatus = 0/1/2（相对 MatchDone；MatchDone = 0 时为未收款）
```

**回写时机：**

1. 票↔应收匹配提交成功后：重算该发票 `Match*` 与 `Receive*`；重算相关应收 `invoice_match_*`
2. 收款核销（应收 `verified_*` 变化）后：找出匹配到该应收的所有销项发票，逐张重算 `Receive*`

## 5. API（建议）

| 方法 | 路径 | 权限 |
|---|---|---|
| GET | `/api/v1/finance/sell-invoice-write-offs/customer-summaries` | read |
| GET | `/api/v1/finance/sell-invoice-write-offs/candidates?customerId=&currency=` | read |
| POST | `/api/v1/finance/sell-invoice-write-offs` | write |

**提交体：** `{ financeSellInvoiceId, allocations: [{ financeReceivableId, amount }] }`

**候选：** 待匹配销项发票列表 + 待匹配应收列表（字段对齐收款核销桌面应收侧：应收单号、出库单号/日期、销售订单号、业务员、货代单号、入库单号、待核销开票金额、本次核销）。

提交后：写匹配流水 → 重算发票 Match* → 重算应收 invoice_match_* → 重算发票 Receive*。

## 6. 与收款核销 / 进项核销对照

| | 收款核销 | 销项发票核销（本功能） | 进项发票核销 |
|--|----------|------------------------|--------------|
| 账本表 | `finance_receivable_write_off` | `finance_sell_invoice_write_off` | `finance_purchase_invoice_write_off` |
| 匹配键 | 收款明细/预收 ↔ **应收** | **发票头** ↔ **应收** | 发票头 ↔ **入库明细** |
| 应收字段 | `verified_*` | `invoice_match_*` | （无） |
| 桌面右栏 | 待核销应收 | 待核销应收（开票匹配） | 待核销入库 |
