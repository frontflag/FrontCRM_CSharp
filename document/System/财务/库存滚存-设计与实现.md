## 一、功能定位

库存滚存是财务模块中的**只读报表**功能，按月滚动统计采购入库与销售出库的数量与金额（USD），展示：

- **上期结余**：期初或上月结转
- **本期入库 / 本期出库**：当月发生额
- **期末结余**：上期 + 入库 − 出库

用于财务对**采购库存价值**的持续追踪，不参与过账、不写库。

### 1.1 本期范围（MVP）

| 功能 | 状态 | 说明 |
|------|------|------|
| 库存滚存（按年 12 月汇总） | ✅ 已实现 | 选年份，固定返回 12 行 |
| 库存明细滚存（按月分页） | ✅ 已实现 | 按 `stock_in_item` 展开，支持下钻 |
| 供应商滚存 / 供应商明细 | ✅ 已实现 | 见 § 十三 |
| 客户滚存 / 客户明细 | ✅ 已实现 | 见 § 十四 |
| Excel 导出 | ⏳ 二期 | 未做 |

### 1.2 与 EBS 的差异摘要

| 维度 | EBS（原文档） | FrontCRM（本实现） |
|------|---------------|-------------------|
| 入库实体 | `StockInV2` 单行 | `stock_in` + `stock_in_item` + `stock_item` |
| 折算单价 | `ConvertCost` | `stock_item.PurchasePriceUsd` |
| 出库时间 | `PackingItem` / 装箱时间 | `stock_out.StockOutDate`（空则 `CreateTime`） |
| 出库数据源 | `PackingItem` | `stock_out` → `stock_out_item` → `stock_out_item_extend` |
| 出库关联入库 | `StockInId` | `stock_out_item_extend.StockInItemId` |
| API 前缀 | `BaseFinance/Accumulated/*` | `api/v1/finance/accumulated/*` |

## 二、已确认的设计口径

以下口径在需求讨论中已拍板，作为实现与测试的唯一依据。

### 2.1 时间与粒度

| # | 项 | 决定 |
|---|-----|------|
| 1 | 出库时间 | `stock_out.StockOutDate`；为空回退 `stock_out.CreateTime` |
| 2 | 入库时间 | `stock_in.StockInDate` |
| 3 | 统计粒度 | `stock_in_item`（入库明细行） |
| 4 | 月份边界 | 业务自然月，默认 `Asia/Shanghai`（可回退 `UTC+8` 固定偏移） |

### 2.2 数据过滤

| # | 项 | 决定 |
|---|-----|------|
| 5 | 入库类型 | 仅采购入库 `stock_in.StockInType = 10` |
| 6 | 排除类型 | 移库/报关/退货/报废入库均不统计 |
| 7 | 入库状态 | 仅已过账 `stock_in.Status = 2` |
| 8 | 出库状态 | `stock_out.Status IN (2, 4)`（已出库 / 已完成） |
| 9 | 出库类型 | 仅销售出库 `StockOutType = 10`，排除移库虚拟出库 `3`（查询代码仍 `OR` 历史 `1`，**库中已刷净**） |
| 10 | 软删除 | `is_deleted = true` 的记录排除 |

### 2.3 金额与数量

| # | 项 | 决定 |
|---|-----|------|
| 11 | 入库金额 | `stock_in_item.Quantity × stock_item.PurchasePriceUsd` |
| 12 | 出库数量 | 优先 `stock_out_item_extend.QtyStockOut`，否则 `ActualQty` / `Quantity` |
| 13 | 出库单价 | 优先 `stock_out_item_extend.PurchasePriceUsd`；为 0 时回查 `stock_item` |
| 14 | 出库金额 | 出库数量 × 出库单价（USD） |
| 15 | 金额展示 | 统一 USD，保留 2 位小数；数量为整数 |
| 15a | USD 折算时点 | 入库过账时按**财务基准汇率**将原币采购价写入 `stock_item.PurchasePriceUsd`；报表读取该快照，**查询时不重新换汇**；出库优先用 `stock_out_item_extend.PurchasePriceUsd`，为 0 时回查库存层 |

### 2.4 权限、菜单与范围

| # | 项 | 决定 |
|---|-----|------|
| 16 | 数据范围 | 公司全量（不按部门/个人过滤） |
| 17 | 权限码 | `finance-accumulated.read`（API 兼容 `finance-receipt.read`） |
| 18 | 金额脱敏 | 与财务分析一致（`maskAmounts`） |
| 19 | 菜单位置 | 财务 → **库存报表** → **库存滚存 → 客户滚存 → 供应商滚存**（在「收款管理」之后） |
| 20 | 数据分析区「财务分析」 | 保持不动（`/reports/finance`） |

## 三、业务公式

### 3.1 库存滚存汇总（按年 12 行）

对每一年，循环 `month = 1..12`：

```
本期入库金额 = Σ(当月入库明细数量 × PurchasePriceUsd)
本期出库金额 = Σ(当月出库数量 × 出库 USD 单价)
本期入库数量 = 当月入库数量合计
本期出库数量 = 当月出库数量合计

若 month = 1：
  上期金额 = 当年 1 月 1 日（显示时区）之前累计入库金额 − 累计出库金额
  上期数量 = 同上（数量）
否则：
  上期金额 = 上月结余金额
  上期数量 = 上月结余数量

结余金额 = 上期金额 + 本期入库金额 − 本期出库金额
结余数量 = 上期数量 + 本期入库数量 − 本期出库数量
```

- 固定返回 **12 行**（不分页）
- 当年尚未到来的月份：指标为 **0**（仍占一行）

### 3.2 库存明细滚存（按月分页）

**数据范围：** 所选自然月内过账的采购入库明细（`stock_in_item`）。

对每条明细行：

```
本期入库数量 = stock_in_item.Quantity
本期入库金额 = 本期入库数量 × PurchasePriceUsd

本期出库数量 = 本月内、关联本 StockInItemId 的出库数量合计
本期出库金额 = Σ(本月出库数量 × 出库 USD 单价)

上期出库数量 = 本月之前、关联本 StockInItemId 的出库数量合计
上期出库金额 = Σ(上期出库数量 × 出库 USD 单价)

上期数量 = 0 − 上期出库数量        （本月新入库行，期初入库为 0）
上期金额 = 0 − 上期出库金额

结余数量 = 上期数量 + 本期入库数量 − 本期出库数量
结余金额 = 上期金额 + 本期入库金额 − 本期出库金额
```

**筛选参数：** `month`（必填）、`queryKeywords`、`pn`、`stockInCode`、`stockInTimeStart`、`stockInTimeEnd`、`page`、`pageSize`（默认 20，最大 100）。

**明细行字段（`/stock-items`、`/vendor-items`、`/customer-items` 共用）：**

| 字段 | 说明 |
|------|------|
| `stockInItemId` | 入库明细行主键 |
| `stockInId` | 入库单主键（`stock_in.Id`），供前端跳转入库单详情 |
| `billCode` | 入库单号（`stock_in.StockInCode`） |
| `pn` | 物料型号 |
| `stockInTime` | 入库时间 |
| `stockInQty` / `stockOutQty` / `prvQty` / `balanceQty` | 数量 |
| `prvAmountTotal` 等 | USD 金额（脱敏时为 `null`） |

```
┌─────────────────────────────────────────────────────────────┐
│  CRM.Web                                                     │
│  FinanceStockAccumulatedList.vue      （年份 + 12 月表）      │

┌──────────────────────────▼──────────────────────────────────┐
│  CRM.API                                                     │
│  FinanceStockAccumulatedController                           │
│    · 权限 / 财务数据范围 / 金额脱敏                           │
└──────────────────────────┬──────────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────────┐
│  CRM.Infrastructure                                          │
│  FinanceStockAccumulatedQuery                                  │
│    · EF 加载入库/出库流水 → 内存按自然月聚合                    │
└──────────────────────────┬──────────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────────┐
│  PostgreSQL                                                  │
│  stock_in / stock_in_item / stock_item                       │
│  stock_out / stock_out_item / stock_out_item_extend          │
└─────────────────────────────────────────────────────────────┘

辅助：CRM.Core/Utilities/FinanceAccumulatedMonthBoundary.cs
      （自然月 UTC 边界，含 12 月跨年处理）
```

### 4.1 计算策略说明

- **汇总接口**：一次性加载全部符合条件的入库/出库流水，在内存中按 `FinanceAccumulatedMonthBoundary` 切月聚合，再滚动计算 12 个月。数据量为财务汇总级别，MVP 可接受。
- **明细接口**：先按月份与筛选条件对 `stock_in_item` 分页，再按页内 `StockInItemId` 批量加载关联出库流水计算行指标。

## 五、API 设计

**Controller：** `FinanceStockAccumulatedController`  
**路由前缀：** `api/v1/finance/accumulated`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/search-options` | 年份下拉（来自已过账采购入库的 `StockInDate.Year`） |
| GET | `/stock?year=2026` | 库存滚存汇总（12 行） |
| GET | `/stock-items?month=2026-01&...` | 库存明细滚存（分页） |
| GET | `/vendors?month=2026-01&...` | 供应商滚存汇总（分页） |
| GET | `/vendor-items?month=2026-01&vendorId=&...` | 供应商明细滚存（分页） |
| GET | `/customers?month=2026-01&...` | 客户滚存汇总（分页） |
| GET | `/customer-items?month=2026-01&customerId=&...` | 客户明细滚存（分页） |

**鉴权：**

- `[RequireAnyPermission("finance-accumulated.read", "finance-receipt.read")]`
- `FinanceDataScope = 4` 时拒绝访问（与财务菜单一致）

**响应：**

- 统一 `ApiResponse<T>` 信封，JSON camelCase
- 汇总/明细均带 `maskAmounts`；脱敏时金额字段为 `null`

### 15.2 公共约定

| 项 | 要求 |

### 15.3 汇总页 — 表头期间切换（`header-period-nav`）

两页汇总均在标题栏右侧放置 **`[<]` 选择器 `[>]`**：

| 元素 | 说明 |
|------|------|
| `<` / `>` 按钮 | 类名 `period-step-btn`；图标为字面量 `<`、`>`；`title` / `aria-label` 为「上一月」「下一月」（i18n：`actions.prevMonth` / `nextMonth`） |
| 库存滚存 | 中间为**年份**下拉（`GET /search-options`）；维护 `selectedMonth`（yyyy-MM）与 `selectedYear` 同步 |
| 供应商滚存 | 中间为**月份**选择器（`el-date-picker type="month"`，`value-format="YYYY-MM"`） |
| 客户滚存 | 同供应商滚存（月份选择器 + `[<]` / `[>]`） |

**上一月 / 下一月逻辑：**

- 按自然月 ±1；跨年时月份与年份一并更新。
- **库存滚存**：仅当 `selectedYear` 变化时重新请求 `GET /stock?year=`；同一年内切换月份只更新高亮行，不重复请求。
- **供应商 / 客户滚存**：每次切换月份均重新请求 `GET /vendors?month=` 或 `GET /customers?month=`（重置到第 1 页）。

**年份手动切换（仅库存滚存）：** 保留当前月份数字（如原为 3 月，改选 2025 年 → `2025-03`），并重新拉取该年 12 行。

### 15.4 汇总页 — 列顺序与列宽

**列顺序（强制）：**

```
维度列（年月 / 供应商 / 客户） → 4 列数量 → 4 列金额(USD) → 操作
```

数量列：`上期数量`、`入库数量`、`出库数量`、`结余数量`  
金额列：`上期金额(USD)`、`本期入库(USD)`、`本期出库(USD)`、`结余金额(USD)`

**8 个指标列等宽：**

- 不设固定 `width`，共用同一 `minWidth`（由 `resolveAccumulatedSummaryMetricMinWidth` 取 8 列表头估算最大值，通常 ≥130）。
- 汇总页容器启用 `table-layout: fixed`，表格 `width: 100%` 撑满父容器；维度列与操作列保持固定宽度，剩余空间由 8 列均分。
- `column-layout-key`：库存 `finance-stock-accumulated-summary-v5`；供应商 `finance-vendor-accumulated-summary-v5`；客户 `finance-customer-accumulated-summary-v1`。

**供应商 / 客户滚存检索条：** 汇总表上方使用 `panel-search`（《业务详情页面规范》§7.4）：对方关键词输入、查询、重置。

### 15.5 汇总页 — 行级交互（《列表交互规范》）

本功能**无编辑页**，仅实现「双击 → 明细」；不实现 Ctrl + 双击进编辑。

| 操作 | 库存滚存汇总 | 供应商滚存汇总 | 客户滚存汇总 |
|------|--------------|----------------|--------------|
| **单击行** | 选中该月（`selectedMonth`），行高亮（`accumulated-month-row--active`）；**不跳转** | 选中行高亮；**不跳转** | 同供应商 |
| **双击行** | 跳转库存明细滚存，`query.month = yearMonth` | 跳转供应商明细滚存，携带 `month`、`vendorId`、`vendorName` | 跳转客户明细滚存，携带 `month`、`customerId`、`customerName` |
| **操作列「明细」** | 单击跳转（单元格 `@click.stop` / `@dblclick.stop`） | 同上 | 同上 |
| **对方名称列** | — | 有 `vendorId` 且具备 `vendor.read`、身份未屏蔽、供应商模块未隐藏：**单击**名称跳转 `/vendors/:id`；否则纯文本 | 有 `customerId` 且具备 `customer.read`、身份未屏蔽、客户模块未隐藏：**单击**名称跳转 `/customers/:id`；否则纯文本 |
| **入库单号（明细页）** | 见 §15.8 | 见 §15.8 | 见 §15.8 |
| 行样式 | `table-row-pointer` + `highlight-current-row` | 同上 | 同上 |

### 15.6 汇总页 — 单元格样式

| 字段组 | 类名 | 视觉 |
|--------|------|------|
| 上期 / 本期入库 / 本期出库 **金额** | `accumulated-amount-neutral` | 正文色，常规字重，不加粗、不着色 |
| 上期 / 入库 / 出库 **数量** | `inv-list-qty` | 默认列表数量样式 |
| **结余数量** | `accumulated-qty-balance` | **橙色 + 加粗** |
| **结余金额** | `amount-text amount-text--balance` | **青色 + 加粗** |
| 结余数量 / 金额为**负数** | 追加 `accumulated-balance-negative` | **纷红色**（CSS 变量 `--crm-accumulated-balance-negative-color`） |

### 15.7 明细页 — 页头与检索

| 项 | 库存明细滚存 | 供应商明细滚存 | 客户明细滚存 |
|----|--------------|----------------|--------------|
| 返回 | 标题**左侧** `btn-back`「返回汇总」，跳转对应汇总页 | 同上；返回时保留 `month` query | 同供应商 |
| 标题 | `库存明细滚存 · {month}` | `供应商明细滚存 · {month} · {vendor}`；**供应商名**琥珀色 | `客户明细滚存 · {month} · {customer}`；**客户名**琥珀色 |
| 检索条 | `panel-search`：物料型号、PN、入库单号、入库日期范围、查询、重置 | 同左 |
| 分页 | 默认 `pageSize=20`，可选 10/20/50/100 | 同左 |

### 15.8 明细页 — 列顺序

**列顺序（强制）：**

```
入库单号 → 物料型号 → 入库时间 → 4 列数量 → 4 列金额(USD)
```

数量列：`入库数量`、`出库数量`、`上期数量`、`结余数量`  
金额列：与汇总页相同的 4 个 USD 列。

单元格样式规则与 §15.6 一致。明细表**不绑定**行级双击跳转（只读下钻列表）。

**明细页列内链接（强制）：**

遵循 [《列表跳单号链接样式规范》](../../PRD/规范/UI规范/列表跳单号链接样式规范PRD.md)（类名 `link-text`）；列内链接为**单击**跳转，明细表无行级双击，一般无需 `stop` 冒泡。

| 页面 | 列 | 条件 | 行为 |
|------|-----|------|------|
| 供应商滚存汇总 | 供应商 | 有 `vendorId` + `vendor.read` + 身份未屏蔽 + 供应商模块可见 | 单击 → `/vendors/:id`（`VendorDetail`） |
| 客户滚存汇总 | 客户 | 有 `customerId` + `customer.read` + 身份未屏蔽 + 客户模块可见 | 单击 → `/customers/:id`（`CustomerDetail`） |
| 三处明细滚存 | 入库单号 | 有 `stockInId` 且 `billCode` 非空 + `inventory.read` + 身份未屏蔽 | 单击 → `/inventory/stock-in/:id`（`StockInDetail`） |
| 上述任一 | — | 无 ID / 无权限 /「未指定」 | 普通文本，不可点 |

**实现：** `useFinanceAccumulatedPartyAccess.ts`；供应商/客户/库存三处明细 `#col-billCode` 槽；`stockInId` 由 `GET /vendor-items`、`/customer-items`、`/stock-items` 返回，见 §3.2。

`column-layout-key`：库存 `finance-stock-accumulated-items-v2`；供应商 `finance-vendor-accumulated-items-v2`；客户 `finance-customer-accumulated-items-v1`。
