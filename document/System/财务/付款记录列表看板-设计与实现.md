## 1. 业务定位

在付款记录列表内切换统计看板。统计范围 = **当前搜索栏筛选结果全量**（含新建 / 待审 / 已付 / 取消，不硬过滤付款完成），不是当前页，也不是财务分析透镜。

金额为明细 **已付货款**（`FinancePaymentItem.PaymentAmount` 合计），**不含** 单头费用（手续费、运费等）。按付款单头原币分面，**不折算美金**，禁止跨币别相加。计数为 **付款单数**（单头）。

## 2. 交互

| 项 | 行为 |
| --- | --- |
| 入口 | 搜索栏「查询」之后、「设置」齿轮之前 |
| 默认 | 列表 |
| 看板态 | 隐藏顶部当前页统计卡、表格、分页；筛选与页签仍可用 |
| 帮助 | 看板态覆盖为付款记录看板说明 |
| 页签 | 保留齿轮；看板跟当前页签筛选 |

---

## 3. 口径摘要

| 指标 | 口径 |
| --- | --- |
| 付款金额 | `Σ(明细.PaymentAmount)` + 单头 `PaymentCurrency`；KPI / 趋势 / 采购员饼 / Top10 按原币分面。不用单头 `PaymentAmount` / `PaymentTotalAmount`（完成态已含费用） |
| 付款供应商数 | 头表 `VendorId` 去重；空不计 |
| 付款单数 | 单头数，与列表总条数同一集合 |
| 趋势 | 付款日 `PaymentDate`；付款单数 + 各原币货款；天/周/月。无付款日不进趋势 |
| 核销状态饼 | 整单汇总核销状态，按**单数** |
| 采购员 | 明细 → 采购订单 `PurchaseUserId`；空归「未分配采购员」；一张单可拆到多名采购员；按原币分面 |
| 排名 | 各原币独立 Top10 供应商、Top10 采购员 |

511 时金额脱敏，饼图/排名改按**单数**，供应商名不展示。

## 4. API

`GET /api/v1/finance/payments/analytics/{dashboard,trends,breakdowns,rankings}`  
参数与 `GET /api/v1/finance/payments` 相同。须注册在 `[HttpGet("{id}")]` **之前**。

列表与看板共用 `FinancePaymentListFilter`。
