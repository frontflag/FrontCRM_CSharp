## 1. 业务口径

| 项 | 口径 |
|---|---|
| 核销匹配 | **进项发票主表 ↔ 入库明细**（账本真相） |
| UI 展示 | **先按入库单**；单明细不展开；多明细展开行各自「本次核销」 |
| 汇总关联 | 票 → 入库明细 → PO 明细 ↔ 付款（付款不参与核销匹配） |
| 队列 | 同供应商+币别下，须同时有待核销发票 **且** 待核销入库明细 |
| MVP | **仅正向核销**；反核销 / 流水页二期 |
| 发票明细 ID | 流水中 `finance_purchase_invoice_item_id` **空着预留** |
| 入库过滤 | 仅 `stock_in.Status = 2`（已入库） |
| 明细基数 | `stock_in_item.Amount`（**不用** `stock_in.TotalAmount` 作核销基数） |
| 头汇总缓存 | `stock_in_extend.InvoiceMatch*` = Σ 明细（与明细同步维护） |

**勿混用：** `financepaymentitem.Verification*` 表示付款完成对 PO 应付，**不是**进项发票核销。

## 2. 数据模型

### 2.1 新建 `finance_purchase_invoice_write_off`

| 字段 | 必填 | 说明 |
|---|---|---|
| `FinancePurchaseInvoiceWriteOffId` | 是 | PK |
| `finance_purchase_invoice_id` | 是 | 发票主表 |
| `finance_purchase_invoice_item_id` | 否 | 预留，MVP 恒 NULL |
| `stock_in_item_id` | 是 | **核销键**（列名对应实体明细 PK `ItemId`） |
| `stock_in_id` | 是 | 冗余，按单聚合 |
| `purchase_order_item_id` | 否 | 写流水时自 `stock_in_item_extend` 带出 |
| `Amount` | 是 | 本次金额 |
| `Currency` | 是 | 币别 |
| `operator_user_id` / `CreateTime` / `is_deleted` | | 审计；软删列预留反核销 |

### 2.2 `financepurchaseinvoice` 补字段

`Currency`，`VerifiedDone`，`VerifiedToBe`，`VerificationStatus`（0/1/2）

### 2.3 `stock_in_item_extend` 补字段（明细匹配真相）

`InvoiceMatchDone`，`InvoiceMatchToBe`，`InvoiceMatchStatus`，`InvoiceMatchCurrency`（可选）

### 2.4 `stock_in_extend` 补字段（头缓存）

同上 `InvoiceMatch*` 四套（或三套+币别），由明细汇总写入；**不改** `stock_in` 核心列。

### 2.5 关联图

```text
financepurchaseinvoice
        │  write_off（账本）
        ▼
stock_in_item ──1:1── stock_in_item_extend（InvoiceMatch*）
        │                    │
        │                    └── purchase_order_item_id ──► PO明细 ◄── financepaymentitem
        ▼
   stock_in ──1:1── stock_in_extend（InvoiceMatch* 汇总缓存）
```

## 3. 余额公式

```text
明细 InvoiceMatchToBe = Amount - Σ(有效流水 where stock_in_item_id)
发票 VerifiedToBe     = InvoiceAmount - Σ(有效流水 where invoice_id)
头 InvoiceMatchToBe   = Σ 明细 InvoiceMatchToBe
提交：Σ allocations ≤ 发票 VerifiedToBe
      每行 amount ≤ 该明细 InvoiceMatchToBe
      同供应商、同币别
```

## 4. API（建议）

| 方法 | 路径 | 权限 |
|---|---|---|
| GET | `/api/v1/finance/purchase-invoice-write-offs/vendor-summaries` | read |
| GET | `/api/v1/finance/purchase-invoice-write-offs/candidates?vendorId=&currency=` | read |
| POST | `/api/v1/finance/purchase-invoice-write-offs` | write |

**提交体：** `{ financePurchaseInvoiceId, allocations: [{ stockInItemId, amount }] }`

**候选：** 发票主表列表 + 按入库单聚合的待核销入库（内含 `items[]` 供多明细展开）。

货代单号：经明细 → PO 的 `freight_forwarder_order_no`，复用 `FreightForwarderOrderNoLookup`。  
采购员：来自 **PO 头**（无则空）。

提交后：写流水 → 重算发票 → 重算明细 extend → 刷新头 extend → 按 PO 行重算 `purchaseorderitemextend` 票进度。
