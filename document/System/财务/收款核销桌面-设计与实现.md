# 收款核销桌面 — 设计与实现

**状态：** MVP  
**路由：** `/finance/receipt-write-off-desktop`（`ReceiptWriteOffDesktop`）  
**关联：** 原核销页 `/finance/receipt-write-off`（并存）；入口收款记录 `/finance/receipts`  
**范式：** [审批桌面-设计与实现](../审批/审批桌面-设计与实现.md)、[报价桌面-设计与实现](../报价/报价桌面-设计与实现.md)  
**业务口径：** [收款核销-设计与实现](./收款核销-设计与实现.md)、[收款单状态-设计与实现](./收款单状态-设计与实现.md)（仅 **确认** 后的来款可核销）

---

## 1. 产品目标

将「待核销客户」队列、上一条/下一条、待核销收款与待核销应收合并为桌面，支持连续核销作业。

- 与原「收款核销」三栏页并存；侧栏「收款管理 → 收款核销」与收款记录页入口均进入桌面。
- 左栏仅展示 **有待核销应收** 的 **客户 + 币别**；无应收客户永不展示。
- 核销成功后 **留在当前客户+币别**，刷新队列与候选。

## 2. 页面结构

```text
┌─ 左扩展「待核销客户」─┬─────────── 收款核销桌面 ────────────┬─ 右扩展 ─┐
│ 搜索 + 客户卡片列表   │ 顶：‹ › | 统计 | 核销流水             │ 出库单   │
│ （客户+币别，有应收） │ 中：待核销收款 | 待核销应收（嵌入旧页）│ 帮助     │
└──────────────────────┴────────────────────────────────────┴──────────┘
```

| 区域 | 行为 |
|------|------|
| 左扩展 | `ReceiptWriteOffDesktopQueuePanel`；Pinia `receiptWriteOffDesktopQueue`；可按最早/最近收款日期排序（`crm.receipt-write-off.queue-sort`）；列表默认每页 20 条 |
| 顶栏 | 按客户+币别翻页；`共 {N} 条待核销客户，{M} 条待核销记录`（N/M 为有应收全量，不受左栏搜索过滤） |
| 中区 | `FinanceReceiptWriteOffPage` `embedded`（隐藏左栏客户表与页头）；点击待核销应收行驱动右栏 |
| 中区排列 | 待核销收款 / 待核销应收支持 **左右** 或 **上下**；偏好存 `localStorage`（`crm.receipt-write-off.panels-layout`），下次进入桌面按上次模式恢复 |
| 右扩展 | 进入桌面默认关闭；展开后默认「出库单」页签（另有帮助） |

### 2.1 右栏「出库单」

展示当前聚焦应收行（默认首行；可点击切换）对应字段：

| 字段 | 来源 |
|------|------|
| 出库单号 / 出库日期 | 应收候选 `stockOutCode` / `stockOutDate`（单号可链到出库详情） |
| 客户中文 / 英文名称 | 候选行；英文空则不显示该行（可回落左栏客户摘要） |
| 业务员 | `salesUserName` |
| 出库数量 / 出库金额+币别 | `outboundQty` / `amount` + `currency` |
| 已核销金额 / 待核销金额 | `verifiedDone` / `verifiedToBe` |
