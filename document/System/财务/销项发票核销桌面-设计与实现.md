## 1. 产品目标

将「待核销客户」队列、上一条/下一条、待核销销项发票与待核销应收合并为桌面，支持连续做 **票↔应收匹配**。

- 左栏仅展示 **有待匹配发票且有待匹配应收** 的 **客户 + 币别**。
- 账本落 **`finance_receivable_id`**；中右 UI 为「待核销应收」（对齐收款核销桌面应收面板样式）。
- 核销成功后 **留在当前客户+币别**，刷新队列与候选。
- MVP **无**反核销、无匹配流水页。

## 2. 页面结构

```text
┌─ 左扩展「待核销客户」─┬──────── 销项发票核销桌面 ────────┬─ 右扩展 ─┐
│ 搜索 + 客户卡片       │ 顶：‹ › | 统计                    │ 出库单   │
│ （客户+币别，双边）   │ 中：待核销销项发票 | 待核销应收   │ 帮助     │
└──────────────────────┴──────────────────────────────────┴──────────┘
```

| 区域 | 行为 |
|------|------|
| 左扩展 | 搜索；卡片：客户中/英名、业务员、待核销发票总额+币别（**MatchToBe 合计**）、待核销发票条数、最早开票日期；分页默认 20 |
| 顶栏 | 上一/下一客户+币别；`共 {N} 条待核销客户，{M} 条待核销发票记录`（全量，不受左栏搜索缩小） |
| 中左 | 待核销销项发票（见 §2.1） |
| 中右 | 待核销应收（见 §2.2）；样式/交互对齐收款核销桌面「待核销应收」 |
| 中区排列 | 支持左右/上下，偏好 `localStorage`（建议键 `crm.sell-invoice-write-off.panels-layout`） |
| 右扩展 | **进入默认关闭**；展开后默认「出库单」页签 |

### 2.1 「待核销销项发票」面板

对齐进项桌面「待核销进项发票」。

**信息栏：**

```text
当前核销客户：{客户中文名} / {客户英文名}（{币别}）
```

（无英文名时不显示 `/ 英文名`。）数据来自左栏选中客户+币别。

**列表字段：**

| 列 | 说明 |
|----|------|
| 发票单号 | 可链详情 |
| 开票日期 | |
| 发票类型 | |
| 发票金额 + 币别 | |
| 已核销金额 | **MatchDone** |
| 待核销金额 | **MatchToBe** |

行选中后驱动中右信息栏与「本次核销」预算。

### 2.2 「待核销应收」面板

对齐收款核销桌面「待核销应收」。

**信息栏：**

```text
发票单号：{发票单号}，待核销发票金额：{MatchToBe + 币别}
```

数据来自中左选中销项发票。

**列表字段：**

| 列 | 说明 |
|----|------|
| 应收单号 | |
| 出库单号 | 可链出库详情 |
| 出库日期 | |
| 销售订单号 | |
| 业务员 | |
| 货代单号 | |
| 入库单号 | |
| 待核销开票金额 + 币别 | **`invoice_match_to_be`**（非收款 `verified_to_be`） |
| 本次核销 | 输入框；支持自动填写 |

底部：**提交核销**（需 write）。

### 2.3 右扩展「出库单」

聚焦中右当前应收行对应出库（`stock_out_id`）：

- 出库单号、出库日期  
- 客户中文名称（无则整行不显示）  
- 客户英文名称（无则整行不显示）  
- 业务员、出库数量、出库金额 + 币别  
- 已核销发票金额 / 待核销发票金额（该出库下应收 `invoice_match_*` 汇总，或当前聚焦应收——实现时与进项右栏口径对齐写清）
