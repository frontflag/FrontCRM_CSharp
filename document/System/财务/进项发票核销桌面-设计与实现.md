## 1. 产品目标

将「待核销供应商」队列、上一条/下一条、待核销进项发票与待核销入库合并为桌面，支持连续核销。

- 左栏仅展示 **有待核销发票且有待核销入库** 的 **供应商 + 币别**。
- 账本落 **入库明细**；UI **按入库单** 展示（单明细不展开；多明细展开行输入）。
- 核销成功后 **留在当前供应商+币别**，刷新队列与候选。
- MVP **无**核销流水页；反核销在 **进项发票列表/详情**，本桌面不加按钮。

## 2. 页面结构

```text
┌─ 左扩展「待核销供应商」─┬──────── 进项发票核销桌面 ────────┬─ 右扩展 ─┐
│ 搜索 + 供应商卡片       │ 顶：‹ › | 统计                    │ 入库单   │
│ （供应商+币别，双边）   │ 中：待核销进项发票 | 待核销入库   │ 帮助     │
└────────────────────────┴──────────────────────────────────┴──────────┘
```

| 区域 | 行为 |
|------|------|
| 左扩展 | 搜索；卡片：中/英名、待核销发票总额+币别、待核销发票条数、最早开票日期；**不显示采购员**；分页默认 20 |
| 顶栏 | 上一/下一供应商+币别；`共 {N} 条待核销供应商，{M} 条待核销发票记录`（全量，不受左栏搜索缩小） |
| 中左 | 待核销进项发票：发票单号、开票日期、发票类型、发票金额+币别、已核销、待核销 |
| 中右 | 待核销入库（按单）；信息栏：当前供应商/币别或选中发票语境；列表含货代单号、采购订单号、采购员(PO)、金额、待核销、本次核销 |
| 中区排列 | 支持左右/上下，偏好 localStorage（对齐收款桌面） |
| 右扩展 | 进入默认关闭；展开默认「入库单」页签 |

### 2.1 按单 / 明细 UI（方案 B）

| 入库 | UI |
|------|-----|
| 仅 1 条待核明细 | 一行入库单 + 一个「本次核销」→ 提交映射该 `stockInItemId` |
| 多条待核明细 | 展开明细行，每行各自「本次核销」 |

### 2.2 右栏「入库单」

聚焦中右当前行（单或明细所属单）：入库单号/日期、供应商中/英（无则隐藏对应行）、采购员(PO)、入库数量/金额+币别、已核销发票金额、待核销发票金额、货代单号（有则显示）。
