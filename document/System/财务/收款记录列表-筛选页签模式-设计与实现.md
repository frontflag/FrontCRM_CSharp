## 1. 业务定位

将搜索栏中适合做成单选桶的下拉，可选转为表格上方全宽页签条。**单维度**；关闭页签不清筛选值；点页签立即查询。

关键词、收款日期不纳入。首版**只做页签模式**；本页既有状态下拉/日期 `@change` 即查行为**保持不变**。为支持「收款用途」页签，同步增加搜索栏用途下拉与列表 API 查询参数。后续增加「核销状态」维度（整单汇总，见核销状态筛选文档）。

---

## 2. 设计要求（定稿）

### 2.1 可纳入维度

| 维度 key | 搜索栏字段 | 页签形态 |
|----------|------------|----------|
| `status` | `status` | 全部 + 新建 / 确认 / **取消**（4 格，与下拉一致） |
| `receiptPurpose` | `receiptPurpose` | 全部 + 普通(10) / 预收(20) |
| `verificationStatus` | `verificationStatus` | 全部 + 未核销(0) / 部分核销(1) / 核销完成(2) |

### 2.2 交互与视觉

遵循 UI 规范 §10。齿轮放在查询按钮旁；标题行右上角为「收款核销桌面」，搜索栏右侧保留「新建」。

## 3. 实现方法

| 文件 | 职责 |
|------|------|
| `FinanceReceiptQueryRequest` / `FinanceReceiptsController` / `FinanceReceiptListQuery` | `receiptPurpose`、`verificationStatus` 查询 |
| `CRM.Web/src/utils/financeReceiptListTabMode.ts` | 维度、localStorage、`tab↔filter` |
| `CRM.Web/src/views/Finance/FinanceReceiptList.vue` | 用途/核销状态下拉、菜单、页签条、核销状态列 |
| `zh-CN.ts` / `en-US.ts` | `filters.*`、`settingsMenu.*`、`filterTabs.all`、`columns.verificationStatus` |

**localStorage：** `crm.finance-receipt-list.tab-mode` = `off` \| `status` \| `receiptPurpose` \| `verificationStatus`。

**API：**  
- `GET /api/v1/finance/receipts?receiptPurpose=10|20`（可选）  
- `GET /api/v1/finance/receipts?verificationStatus=0|1|2`（可选）
