## 1. 业务定位

财务在付款记录列表直接看到该单关联的 **采购订单号**、**采购员**，并可用采购订单号、采购员、采购币种筛选。数据来自付款明细已关联的采购订单，**不新增表字段**。

---

## 2. 定稿口径

| 项 | 口径 |
|----|------|
| 采购订单号列 | 明细关联 PO 去重后拼接；有采购订单查看权限时可点跳详情，无权限仅文字 |
| 采购员列 | 关联 PO 的采购员姓名去重拼接 |
| 一单多 PO | 与货代单号相同：去重拼接；订单号各自可点 |
| 无关联 PO | 两列显示「—」；三项筛选均筛不中 |
| 采购币种筛选 | 精确匹配 **采购订单币种**，不是付款单付款币种。金额列仍显示付款币种。不做列表列、不进页签模式 |
| 采购订单号 / 采购员筛选 | 文本模糊（Contains） |

任一关联 PO 命中该筛选项即保留付款单；多项筛选之间为 AND。

## 3. 实现方法

| 文件 | 职责 |
|------|------|
| `FinancePaymentQueryRequest` | `purchaseOrderCode` / `purchaseUserName` / `purchaseCurrency` |
| `FinancePaymentListQuery` | 先找命中的 PO，再按付款明细 Any 关联（复用货代单号模式） |
| `FinancePayment`（NotMapped） | `PurchaseOrderCodes`、`PurchaseOrderRefs`、`PurchaseUserName` |
| `FinancePaymentService.EnrichFreightForwarderOrderNosAsync` | 同批加载 PO，一并填展示字段 |
| `FinancePaymentsController` | 列表与导出 query |
| `FinanceExportHttp.BuildPaymentCsv` | CSV 增加采购订单号、采购员列 |
| `ExportOperationAudit.FinancePaymentListLabels` | 导出条件中文名 |
| `FinancePaymentList.vue` | 搜索栏、列（`column-layout-key` v5）、权限链接 |
