# 客户 / 供应商质保书打印 — 三租户皮肤

**状态：** 已上线  
**入口：** `/customers` → 打印质保书；`/vendors` → 打印质保书  
**页面：** `/customers/:id/warranty`、`/vendors/:id/warranty`（报表页工具栏切换中/英，默认中文）  
**V2 规范：** [报表规范-客户供应商质保书-V2](../../PRD/规范/业务规范/报表规范-客户供应商质保书-V2.md)（`semicore` + `System.Report.StyleVersion = V2`）  
**色板：** [租户主题色规范](../../PRD/规范/UI规范/租户主题色规范.md)  
**对照：** 与 Packing List、销售订单质保书同一租户↔皮肤映射

---

## 1. 目标

客户 / 供应商主数据级质保书（无货表明细）由单一黑白信笺改为三租户皮肤，色系与布局对齐 Packing。

---

## 2. 皮肤映射

| 租户 | 组件文件 | 视觉要点 |
|------|----------|----------|
| `semicore` | `WarrantyLetterReportSkinIdesemi` | 深色顶栏 `#0D1F35`，强调 `#020612` |
| `idesemi` | `WarrantyLetterReportSkinEcoinf` | 工业极简，青点缀 `#6DC5F6` |
| `ecoinf` | `WarrantyLetterReportSkinSemicore` | 绿分隔/侧条 `#A8D070`，字色 `#101010` |

---

## 3. 关键文件

| 路径 | 职责 |
|------|------|
| `components/warrantyLetterReport/*` | Body / V2 Body / types / resolve / 三皮肤 + V2 皮肤 |
| `views/Customer/CustomerWarrantyReportPage.vue` | 客户预览打印（读 `getEffectiveStyleVersion()`） |
| `views/Vendor/VendorWarrantyReportPage.vue` | 供应商预览打印（读 `getEffectiveStyleVersion()`） |
| `components/Vendor/VendorWarrantyReportDocument.vue` | 兼容旧引用，转发 resolve（默认 V1） |

文案仍用 `constants/vendorWarrantyReportZh.ts` / `En.ts`（客户页共用）。

---

## 4. V2（semicore）

当全局参数 `System.Report.StyleVersion = V2` 且租户为 **semicore** 时，客户 / 供应商质保书改用 PO V2 chrome（与销售订单质保书 V2 同系），详见 [报表规范-客户供应商质保书-V2](../../PRD/规范/业务规范/报表规范-客户供应商质保书-V2.md)。`idesemi` / `ecoinf` 在 V2 参数下仍走 §2 三租户 V1 皮肤。
