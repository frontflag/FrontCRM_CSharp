## 1. 业务定位

在库存明细列表内切换统计看板。统计范围 = **当前搜索栏与页签筛选的全量明细**（含数据范围），不是当前页。库存明细已是库存中心看板的下钻目标；本看板继续用同一套 `stagnantOnly` / `rankDimension` 回到列表。

不做报表「公司/部门/个人」透镜。

## 3. 口径摘要

| 模块 | 口径 |
| --- | --- |
| 在库数量 | `Σ qty_repertory`，与列表卡 `qtyRepertoryTotal` 一致 |
| 库存金额 | 原币分列 `Σ(qty_repertory × purchase_price)`，不折算 |
| 周转天数 | `在库数量 / 近30天出库数量 × 30`；出库或在库为 0 则「—」 |
| 呆滞料数量 | 入库日 ≤ 今天−90 **或无入库日** 的在库 `Σ qty_repertory`（数量，非层数） |
| 趋势 | 时点存量 `qty_inbound − 累计出库`；尊重 `groupBy=day\|week\|month`；默认日 30 / 周 12 / 月 12；入库日起止与趋势窗相交裁剪 |
| 分布 | 库存类型 / 仓库 / 业务员 / 库龄（物流分析桶）；无入库日不进饼 |
| 排名 | Top10 客户、业务员、物料（型号+品牌）、品牌；空客户「无客户 / 备货」 |

出库事件：`stock_out_item` + 头 `status∈{2,4}`，数量 `ActualQty` 优先。

511 / 无采购金额权：金额「—」，饼图与排行回退数量；周转天数仍显示。521：排行客户/业务员名按列表同样脱敏。

## 4. API

挂在 `InventoryCenterController`，写在 `stock-items/{id}` 之前：

| GET | 说明 |
| --- | --- |
| `/api/v1/inventory-center/stock-items/analytics/dashboard` | KPI |
| `.../trends?groupBy=` | 趋势 |
| `.../breakdowns` | 饼图 |
| `.../rankings` | Top10 |

Query 与 `GET .../stock-items` 相同。
