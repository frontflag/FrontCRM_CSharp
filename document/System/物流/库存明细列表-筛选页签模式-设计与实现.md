## 1. 业务定位

将搜索栏中适合做成单选桶的下拉，可选转为表格上方全宽页签条。**单维度**；关闭页签不清筛选值；点页签立即查询。

**可纳入维度：** 出库状态、是否有库存、仓库（>10 回退下拉）、入库类型。  
**本版不纳入：** 业务员、采购员。文本、日期不纳入。

---

## 2. 设计要求（定稿）

### 2.1 可纳入维度

| 维度 key | 搜索栏字段 | 页签形态 |
|----------|------------|----------|
| `outboundStatus` | `outboundStatus` | 全部 + 未出库 / 部分出库 / 出库完成 |
| `stockPresence` | `stockPresence` | **全部**（对应下拉空串/「空白」语义）+ 有库存 / 无库存 |
| `warehouse` | `warehouseId` | 全部 + 仓库列表；**>10 回退下拉**（阈值与库存中心共用 `INVENTORY_WAREHOUSE_TAB_MAX`） |
| `stockInType` | `stockInType` | 全部 + 采购 / 报关 / 退货 / 报废（与下拉一致；历史采购 `1` 归一为 `10`；不含移库） |

### 2.2 禁止维度

业务员 `salespersonUserId`、采购员 `purchaserUserId`：**子菜单不出现**，始终为下拉。

### 2.3 交互与视觉

遵循 UI 规范 §10；类名 `isi-filter-tabs`。开启对应维度后隐藏该下拉。

---

## 3. 实现方法

| 文件 | 职责 |
|------|------|
| `CRM.Web/src/utils/inventoryStockItemListTabMode.ts` | 维度、localStorage、`tab↔filter`；复用仓库阈值与入库类型归一 |
| `CRM.Web/src/views/Inventory/InventoryStockItemList.vue` | 菜单、页签条、仓库 >10 回退、按维度隐藏下拉 |
| `zh-CN.ts` / `en-US.ts` | `settingsMenu.*`、`filterTabs.all` |

**localStorage：** `crm.inventory-stock-item-list.tab-mode` = `off` \| `outboundStatus` \| `stockPresence` \| `warehouse` \| `stockInType`。

**无需改后端**：同一套列表 query；点页签走现有 `fetchList()`。
