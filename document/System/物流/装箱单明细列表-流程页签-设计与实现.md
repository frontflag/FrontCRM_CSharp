## 1. 业务定位

| 概念 | 说明 |
|------|------|
| **目标** | 在明细列表右栏查看**当前单击的那一条装箱明细**的出库侧流程 |
| **页签** | 默认 `r-flow`；并列「客户」、帮助 |
| **列表绑定** | **单击**明细行即绑定该行（无 chip） |
| **流程内容** | 与装箱详情/装箱单列表共用：销售订单明细 → 出库通知 → 装箱 → 拣货 → 出库 |
| **与装箱单列表差异** | 列表行已是装箱明细，不再用顶部明细单号条切换；换行 = 再点另一行 |

---

## 2. 交互

| # | 条件 | 结果 |
|---|------|------|
| A | 未单击行 | 提示「请单击列表中的装箱明细，查看流程」 |
| B | 单击行 | 按 `packingId` + 装箱行 `id` 拉装箱详情 + 拣货页，选中该行并渲染流程 |
| C | 同箱再点另一行 | 只切换明细，不重拉整箱 |
| D | 换箱的另一行 | 重拉新箱详情后选中该行 |
| E | 离开 `PackingItemList` | `clear()` store |
| F | 无「操作」页签 | 与装箱单列表一致 |

选中行高亮（`so-item-row--active`）。脱敏不拦截加载。

---

## 3. 数据

| 步骤 | 来源 |
|------|------|
| 绑定 | `bindPackingItemFromList(packingId, packingItemId)` |
| 箱头 / 拣货 | 与装箱单列表相同（`GET packing/{id}` + `PickPageByPacking`） |
| 销售 aggregates | 有 `sellOrderItemId` 时与详情相同 |
| 出库站（目标） | 按装箱行查出来的出库明细，见 [出库明细单号与装箱流程出库站](./出库明细单号与装箱流程出库站-设计与实现.md) |
| UI | 复用 `PackingItemFlowPanel`（**不用**带 chip 的 `PackingListFlowPanel`） |
