## 1. 业务定位

将搜索栏中适合做成单选桶的下拉，可选转为表格上方全宽页签条。**单维度**；关闭页签不清筛选值；点页签立即查询。

文本筛选不纳入。首版**只做页签模式**；本页既有下拉 `@change` 即查行为**保持不变**。

---

## 2. 设计要求（定稿）

### 2.1 可纳入维度

| 维度 key | 搜索栏字段 | 页签形态 |
|----------|------------|----------|
| `stockType` | `stockType` | 全部 + 客单库存 / 备货库存 / 样品库存 |
| `warehouse` | `warehouseId` | 全部 + 当前启用仓库列表（标签与下拉一致：编码 · 名称） |

### 2.2 仓库页签上限（定稿）

| 规则 | 说明 |
|------|------|
| 阈值 | 仓库下拉选项数 **≤ 10** 才允许仓库页签 |
| **> 10** | 子菜单「仓库」禁用；若偏好已是仓库，**自动回退下拉**（显示仓库下拉、隐藏页签条；偏好可保留，仓数回落到 ≤10 时页签自动恢复） |
| 常量 | `INVENTORY_WAREHOUSE_TAB_MAX = 10`（`inventoryListTabMode.ts`） |

### 2.3 交互与视觉

遵循 UI 规范 §10；类名 `inv-filter-tabs`。仓库页签文案过长时省略号 + `title` 完整名。

---

## 3. 实现方法

| 文件 | 职责 |
|------|------|
| `CRM.Web/src/utils/inventoryListTabMode.ts` | 维度、阈值、localStorage、`tab↔filter` |
| `CRM.Web/src/views/Inventory/InventoryList.vue` | 菜单、页签条、仓库 >10 回退 |
| `zh-CN.ts` / `en-US.ts` | `settingsMenu.*`、`warehouseTabDisabled`、`filterTabs.all` |

**localStorage：** `crm.inventory-list.tab-mode` = `off` \| `stockType` \| `warehouse`。

**无需改后端**：同一套 overview 查询参数。
