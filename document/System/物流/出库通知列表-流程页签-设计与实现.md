## 1. 业务定位

| 概念 | 说明 |
|------|------|
| **目标** | 以地铁竖轴展示 **一条出库通知** 的销售行、本通知绑定库存、装箱与出库 |
| **页签** | 默认 **流程** `r-flow`；并列「客户」、帮助；报关出库时另加「报关单」 |
| **数据粒度** | 一条 `stockout_notify`（`stockOutNotifyId`） |
| **只读** | 无动作按钮；单号可跳转 |

视觉克隆库存明细流程（`so-item-flow-panel.scss` + `StockBizTypeTag`）。当前站为 **出库通知**。

---

## 2. 站序

```
销售明细 → 出库通知 ☜ → 库存明细 →（有卡才插入）备货库存 → 装箱 → 出库
```

不含采购、质检、入库、拣货、收款、开票。备货库存仅当 `stockingStockItems` 有卡时插入，空则整站不画。库存明细含已出完（qty=0）的绑定层。装箱/出库只收口本通知，不按销售行全量。

字段见 [流程页签规范 §3.1](../../PRD/规范/UI规范/流程页签规范.md)。出库通知/装箱/出库走客户与出库类型；库存明细额外走供应商、采购价、入库数量、出库数量。

---

## 3. 交互

`dataTabIds: ['r-flow']`。单击行同时绑流程 store 与客户面板。报关出库时「报关单」页签逻辑仍见 [报关单页签设计](../报关/出库通知列表-报关单页签-设计与实现.md)（该文页签组合以本文为准：流程始终在）。

| 条件 | 行为 |
|------|------|
| 右栏收起单击 | 忽略 |
| 展开且非「流程」单击 | 仅高亮 |
| 展开且在「流程」单击 | `GET /api/v1/stock-out/request/{id}/flow-aggregates` |
| 离开路由 | `stockOutNotifyFlowStore.clear()` |
