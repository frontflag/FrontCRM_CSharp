## 1. 业务定位

左栏提供 **preset 快捷检索**，表达主栏下拉/单日控件不便覆盖的 **业务视角**（逾期、排期、实到、待办等）；与主栏 keyword **共用 URL query**。

| 概念 | 说明 |
|------|------|
| **preset 单选** | 六组共 **20 项**；再点同一项 / 主栏 preset chip ✕ / 主栏「重置」→ **清空全部 query**（含 keyword） |
| **keyword 叠加** | `purchaseOrderCode`、`freightForwarderOrderNo` 可与 preset 同时生效 |
| **日期互斥** | 有 preset 时主栏隐藏「预计到货日期」单日控件（由 preset 或后端区间表达） |
| **筛选页签模式** | preset 激活时：隐藏与 preset 冲突的维度页签及齿轮子项（见 §5、[筛选页签模式](./到货通知列表-筛选页签模式-设计与实现.md) §10.3） |
| **列表驱动** | 左栏点击 / 主栏查询 / 重置 → `router.replace` → 列表 `watch(route.query)` → `GET /api/v1/logistics/arrival-notices` |

**不含左栏 keyword 表单**（与质检/入库单左栏不同）：精确单号仍在主栏输入。

## 2. 数据字段

### 2.1 已有

| 字段 | 用途 |
|------|------|
| `ExpectedArrivalDate` | 预计到货日；逾期组 / 预计组 |
| `Status` | 1/10/20/30/100；未到货、待办、状态 preset |
| `StockInType` | 10 采购 / 20 报关 / …；类型 preset |

### 2.2 新增 `ActualArrivalDate`（实到日）

| 项 | 定稿 |
|----|------|
| 列 | `stockin_notify.ActualArrivalDate`（`timestamptz`，可空） |
| **写入** | 任意路径使通知 **首次** 进入 `status ≥ 20` 且实到日为空时，写入 **当前 UTC 时刻**（展示按本地日历日） |
| **清空** | 状态回滚至 `status = 10`（含强制删除质检后的回滚）时 **清空** 实到日 |
| **主路径** | 用户「确认到货」：`UpdateArrivalNoticeStatusAsync` 10→20 |
| **历史回填** | 上线脚本：对已 `status ≥ 20` 且实到日为空的行，用 **`ModifyTime` 转业务本地日历日** 回填（近似） |

到货组「今日到货」等 5 项 **必须** 依赖本字段，禁止用 `ExpectedArrivalDate` 或 `ModifyTime` 降级替代。

### 2.3 空预计日

`ExpectedArrivalDate` **为空** 的通知：**不参与** 逾期组、预计组任一 preset；仍可通过 **到货·未到货**、主栏状态、keyword 查到。

## 3. preset 列表（20 项）

日历边界均为 **用户本地日历日**（与前端 `YYYY-MM-DD`、列表展示一致）。  
下文「今天」= 本地当日 0 点起算。

### 3.1 逾期（`status = 10` 且预计日有值）

| preset ID | 文案 | 条件 |
|-----------|------|------|
| `overdue_all` | 所有逾期 | 预计日 **< 今天** |
| `overdue_1_day` | 逾期1天 | 预计日 **= 昨天** |
| `overdue_3_days` | 逾期3天 | 预计日 ∈ **[今天-3, 昨天]** |
| `overdue_1_week` | 逾期1周 | 预计日 ∈ **[今天-7, 昨天]** |

包含关系：`overdue_1_day` ⊂ `overdue_3_days` ⊂ `overdue_1_week` ⊂ `overdue_all`。

### 3.2 预计（不限 status；不含逾期）

| preset ID | 文案 | 条件 |
|-----------|------|------|
| `expected_today` | 预计今日 | 预计日 = **今天** |
| `expected_tomorrow` | 预计明天 | 预计日 = **明天** |
| `expected_within_3_days` | 预计3天内 | **今天 ≤ 预计日 ≤ 今天+3** |
| `expected_within_7_days` | 预计1周内 | **今天 ≤ 预计日 ≤ 今天+7** |

### 3.3 到货

| preset ID | 文案 | 条件 |
|-----------|------|------|
| `not_arrived` | 未到货 | `status = 10`（不限预计日） |
| `arrived_today` | 今日到货 | `status ≥ 20` 且实到日 = **今天** |
| `arrived_today_yesterday` | 今昨到货 | 实到日 ∈ **[昨天, 今天]** |
| `arrived_within_3_days` | 3日内到货 | 实到日 ∈ **[今天-2, 今天]** |
| `arrived_within_7_days` | 1周内到货 | 实到日 ∈ **[今天-6, 今天]** |
| `arrived_within_30_days` | 1月内到货 | 实到日 ∈ **[今天-29, 今天]** |

后 5 项要求实到日有值；`status ≥ 20` 为冗余校验（与实到日写入规则一致）。

### 3.4 类型

| preset ID | 文案 | 条件 |
|-----------|------|------|
| `type_purchase` | 采购入库 | `stockInType = 10` |
| `type_customs` | 报关入库 | `stockInType = 20` |

### 3.5 待办

| preset ID | 文案 | 条件 |
|-----------|------|------|
| `todo_pending_qc` | 待质检 | `status = 20` |
| `todo_pending_stock_in` | 待入库 | `status = 30` 且 **无已过账入库单** 关联本通知（见 §3.7） |

### 3.6 状态

| preset ID | 文案 | 条件 |
|-----------|------|------|
| `status_qc_done` | 已质检 | `status = 30`（含已绑定未过账入库单） |
| `status_stocked_in` | 已入库 | `status = 100` |

**待入库 ⊂ 已质检**（分层口径）：同一 `status=30` 行，待入库为真子集。

### 3.7 「无已过账入库单」（待入库）

与 `PurchaseOrderItemExtendSyncService.RecalculateArrivalNoticeStatusesForPoLineAsync` 一致，满足任一即视为 **已有已过账入库**（排除在待入库外）：

- 存在 `stock_in.status = 2`（已过账）且 `stock_in.stock_in_type = 采购(10)`，且  
  `stock_in.source_id = 本通知 Id`，**或**
- 存在上述已过账入库单，且关联质检 `qcinfo.stock_in_id = stock_in.id` 或 `stock_in.qc_id = qcinfo.id`，且 `qcinfo.stock_in_notify_id = 本通知 Id`

## 4. API 与 query

### 4.1 URL query（前端）

| 键 | 说明 |
|----|------|
| `preset` | 上表 preset ID；单选 |
| `purchaseOrderCode` | 可叠加 |
| `freightForwarderOrderNo` | 可叠加 |
| `noticeId` | 深链保留（与 preset 互斥时 preset 优先或进入页清 preset，实现时以列表现有 `noticeId` 行为为准） |

有 preset 时 **不写** 主栏 `status` / `stockInType` / `expectedArrivalDate` 到 query（由 preset 解析）。

### 4.2 后端 `GET /api/v1/logistics/arrival-notices`

扩展参数（与现有 `status`、`stockInType`、`expectedArrivalDate` 并存；**preset 路径优先**）：

| 参数 | 说明 |
|------|------|
| `preset` | 枚举，对应 §3 各 ID；服务端解析为 SQL |
| `expectedArrivalDateFrom` / `To` | 可选；preset 为预计/逾期类时由服务端填入 |
| `actualArrivalDateFrom` / `To` | 可选；preset 为实到类时由服务端填入 |

实现：`ArrivalNoticeListQuery.GetPagedAsync` + `ArrivalNoticeListQuickFilter`（新）。

## 5. 与主栏、页签模式互斥

| preset 类型 | preset 激活时 |
|-------------|----------------|
| 逾期 / 预计 | 隐藏主栏「预计到货日期」 |
| 到货（实到 5 项） | 同上 |
| 类型 | 隐藏到货类型下拉 + **页签「到货类型」** + 齿轮该项 |
| 待办 / 状态 / 未到货 | 隐藏状态下拉 + **页签「状态」** + 齿轮该项 |
| keyword | **保留** |

清除 preset 后，按 `localStorage` `crm.arrival-notice-list.tab-mode` 恢复页签模式。

主栏展示 **preset chip**（文案 + ✕），与采购明细一致。
