## 1. 业务定位

| 概念 | 说明 |
|------|------|
| **筛什么** | 入库单头 `stock_in.StockInType`，**不是** 库存层 `stock_item.Type`（客单/备货/样品，参数名仍为 `stockType`） |
| **控件** | 搜索栏 `el-select`，占位「入库类型」，`clearable`，变更即查 |
| **位置** | 搜索栏：「是否有库存」之后、「入库单号」之前 |
| **页签模式** | **纳入**（齿轮「页签模式」可选本字段；开启后下拉隐藏，页签：全部 + 四档，口径与下拉相同）。详见 [筛选页签模式](./库存明细列表-筛选页签模式-设计与实现.md) |
| **表格列** | 「入库类型」，`StockBizTypeTag`，在入库日期与仓库之间 |

---

## 2. 选项与匹配

| 界面 | 请求 `stockInType` | 库内匹配 |
|------|-------------------|---------|
| 清空 / 不传 | 不传 | 不过滤 |
| 采购入库 | `10` | `10` **或** 历史 `1` |
| 报关入库 | `20` | `20` |
| 退货入库 | `30` | `30` |
| 报废入库 | `40` | `40` |

**不含移库 `3`。** 非法值（含 3）后端忽略，不过滤。无入库单头的行（join 不到 `stock_in`）选任何类型都不进入结果。

导出走同一套 query；CSV 在「入库日期」后增加「入库类型」列（文案与入库单导出一致）。
