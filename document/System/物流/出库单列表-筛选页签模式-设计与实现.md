## 1. 业务定位

将搜索栏中适合做成单选桶的下拉，可选转为表格上方全宽页签条。**单维度**；关闭页签不清筛选值；点页签立即查询。

文本、出货方式（字典动态）、日期不纳入。首版**只做页签模式**，不改日期控件形态、不下拉变更即查。

---

## 2. 设计要求（定稿）

### 2.1 可纳入维度

| 维度 key | 搜索栏字段 | 页签形态 |
|----------|------------|----------|
| `status` | `status` | 全部 + 草稿 / 待出库 / 准备出库 / 已取消 / 出库完成（**6 格，含已取消**；与下拉一致） |
| `stockOutType` | `stockOutType` | 全部 + 销售 / 报关 / 退货 / 报废 |

### 2.2 交互与视觉

遵循 UI 规范 §10：齿轮菜单、单维度、贴合表顶、亮色未选中 `#E8EDF5`、暗色 `var(--crm-layer-1)`。

---

## 3. 实现方法

| 文件 | 职责 |
|------|------|
| `CRM.Web/src/utils/stockOutListTabMode.ts` | 维度、localStorage、`tab↔filter` |
| `CRM.Web/src/views/Inventory/StockOutList.vue` | 菜单、页签条、按维度隐藏下拉 |
| `zh-CN.ts` / `en-US.ts` | `settingsMenu.*`、`filterTabs.all` |

**localStorage：** `crm.stock-out-list.tab-mode` = `off` \| `status` \| `stockOutType`。

**无需改后端**：同一套列表 query（`status`、`stockOutType`）；点页签走现有 `handleSearch` → 路由 query → 拉列表。
