## 1. 业务定位

将搜索栏中适合做成单选桶的下拉，可选转为表格上方全宽页签条。**单维度**；关闭页签不清筛选值；点页签立即查询。

文本、日期不纳入。偏好与出库单列表**分开记忆**。

---

## 2. 设计要求（定稿）

### 2.1 可纳入维度

| 维度 key | 搜索栏字段 | 页签形态 |
|----------|------------|----------|
| `status` | `status` | 全部 + 草稿 / 待出库 / 准备出库 / 出库完成 / **已取消**（**6 格**；已取消置底，与下拉一致） |
| `stockOutType` | `stockOutType` | 全部 + 销售 / 报关 / 退货 / 报废（销售筛仍含历史类型 1） |

### 2.2 交互与视觉

遵循 UI 规范 §10：齿轮菜单、单维度、贴合表顶、亮色未选中 `#E8EDF5`、暗色 `var(--crm-layer-1)`。勿与底栏「列设置」齿轮混淆。

---

## 3. 实现方法

| 文件 | 职责 |
|------|------|
| `CRM.Web/src/utils/stockOutItemListTabMode.ts` | 维度、localStorage |
| `CRM.Web/src/utils/stockOutListTabMode.ts` | 复用 `tab↔filter` 映射 |
| `CRM.Web/src/views/Inventory/StockOutItemList.vue` | 菜单、页签条、按维度隐藏下拉 |
| `zh-CN.ts` / `en-US.ts` | `stockOutItemList.settingsMenu.*`、`filterTabs.all` |

**localStorage：** `crm.stock-out-item-list.tab-mode` = `off` \| `status` \| `stockOutType`。

**无需改后端**：同一套 `StockOutItemListQuery`；点页签走现有 `fetchList`。
