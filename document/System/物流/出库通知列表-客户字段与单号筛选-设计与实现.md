## 1. 业务定位

出库通知列表补齐销售侧对照字段与下游单号检索：

- **列：** 客户型号、客户订单号、出库单号（装箱单号原已有列）。
- **筛：** 销售单号、客户订单号、客户型号、装箱单号、出库单号、品牌（均为文本模糊包含）。

页签模式仍只覆盖状态 / 地域 / 出库类型；上述文本筛不进页签。

---

## 2. 字段口径

| 展示/筛选 | 来源 | 说明 |
|-----------|------|------|
| 物料型号 | 出库通知快照 `MaterialCode` | 创建时写入，不随后续改单刷新 |
| 品牌 | 出库通知快照 `MaterialName` | 同上；筛品牌即筛该快照 |
| 客户订单号 | 销售明细当前 `customer_so` | **读当前值**，不是通知快照 |
| 客户型号 | 销售明细当前 `customer_pn` | **读当前值**，不是通知快照 |
| 销售单号 | 销售订单头 `sell_order_code` | 列原已有，本版补筛选 |
| 装箱单号 | `packing_item.stockout_notify_id` → `packing.code` | 多单顿号拼接；筛子串 |
| 出库单号 | 经装箱明细关联出库单 | 见 §3；未装箱/未出库为空 |

销售敏感掩码（采购方向且销售数据范围禁止）下：客户订单号、客户型号列显示 `—`，对应筛选项隐藏；与客户名、业务员一致。

---

## 3. 出库单号解析

一条出库通知经装箱明细关联装箱单，再关联出库单（排除移库虚拟出库）：

1. `stock_out_item.packing_id` = 该通知装箱单；或
2. `pickingtaskitem.packing_item_id` = 该通知装箱明细，再经 `stock_out_item.picking_task_item_id`。

多出库单时列值顿号拼接，链接落到排序后的首条。无关联则空；筛「出库单号」时无出库的通知不命中。
