## 1. 业务定位

| 概念 | 说明 |
|------|------|
| **目标** | 以时间节点推进方式展示 **单条装箱明细** 的出库侧链路（纵向轴） |
| **展示位置** | `AppLayout` 右侧辅助栏 **「流程」**，与「客户」、帮助并列 |
| **页签 ID** | `r-flow`（`layout.auxTabs.flow`） |
| **数据粒度** | 一条装箱明细（`packingItemId`）；必须点中明细行 |
| **主节点** | 「装箱」站：当前装箱单 + 当前明细 |
| **节点** | 销售订单明细 → 出库通知 → 装箱 → 拣货 → 出库（共 5 站） |
| **上游** | 销售明细由 `sellOrderItemId` **单线**确定 |
| **只读** | 无业务动作；单号可跳转详情 |

**列表补充：** 列表侧先单击装箱单，再在流程顶用明细单号切换，解决「一箱多明细」选中问题；流程内容与详情共用适配器。

## 2. 布局与交互

### 2.1 结构

与销售明细流程相同：竖轴自上而下；同站多卡按创建时间升序；未发生节点空心站 +「未开始」。

### 2.2 选中门控

| # | 条件 | 结果 |
|---|------|------|
| A | 未选中装箱明细 | 流程页提示「请选择一条装箱明细」；不请求销售 aggregates |
| B | 选中明细且含 `sellOrderId` + `sellOrderItemId` | 拉取销售明细 `detail-tab-aggregates` 并渲染全链路 |
| C | 选中明细但无关联销售行 | 提示无法构建上游；装箱站仍展示当前箱/行 |
| D | 切换明细行 | 重新加载 aggregates |
| E | 离开 `PackingDetail` | `clear()` store |

详情页已有 `selectedPackingItemId`（默认首行）；流程复用该选中态。

### 2.3 小卡字段

列表、明细列表与详情共用 `PackingItemFlowPanel`。客户名称独占一行，**不**展示客户编号。描述 MVP 固定空/`—`。出入库类型用 `StockBizTypeTag`；报关图标仅当类型为报关且有报关单 ID（见 [流程页签规范 §2.2](../../PRD/规范/UI规范/流程页签规范.md)）。

| 站 | 相对旧口径的字段 |
|----|------------------|
| 销售明细 | 单号、状态、创建日期、业务员、客户、销售价、数量 |
| 出库通知 | 用 **出库类型** 替换申请人；另有「地域」（`RegionTypeChip`，10=大陆 / 20=海外，位于数量右侧） |
| 装箱 | 用 **出库类型** 替换创建人 |
| 拣货 | 仍展示创建人 |
| 出库 | 出库单号 + 出库明细单号；**状态后**给出库类型；下一行创建日期 + 创建人。类型缺失时回退箱头 `stockOutType` |

出库站对齐细则见 [出库明细单号与装箱流程出库站](./出库明细单号与装箱流程出库站-设计与实现.md)。

## 3. 节点顺序（定稿）

```
1. 销售订单明细     ← 上游（由 packing_item.sell_order_item_id 单线确定）
2. 出库通知         ← 优先本箱明细关联通知
3. 装箱             ← 主节点（当前装箱）
4. 拣货             ← 本箱拣货任务（PickPage）
5. 出库             ← 按本装箱行对齐出库明细（出库单号 + 出库明细单号 + 本行数量）；对不上则空站
```

出库站**禁止**再用销售行聚合 `stockOuts` + `packingCodes` 展示整单数量。细则见 [出库明细单号与装箱流程出库站](./出库明细单号与装箱流程出库站-设计与实现.md)。

## 4. 数据

### 4.1 MVP 数据来源

| 数据 | 来源 |
|------|------|
| 装箱头 / 当前明细 | 详情已加载的 `PackingDetail` + 选中行 |
| 出库通知 | 详情内嵌 `stockOutNotifies`（按明细关联）；不足时回退销售 aggregates |
| 拣货 | 详情页已加载的 `PickPageByPacking`（`pickingTask` + 当前行） |
| 出库等补充 | 销售行 aggregates **不再**作为出库站数据源 |
| 出库站 | 按 `packingItemId` → 拣货行 → `stock_out_item.picking_task_item_id` 查询（见出库明细单号设计） |
| 适配器 | `buildPackingItemFlowStations`：仅产出上述 5 站；出库站只读 extras |

## 6. 权限与脱敏

- 进入详情：沿用装箱详情既有权限（`sales-order.read` 或 `purchase-order.read`）。  
- 拉取销售 aggregates：需可访问对应销售订单；失败时流程页展示错误文案。  
- 521 销售敏感脱敏：客户/金额等同销售流程面板处理。
