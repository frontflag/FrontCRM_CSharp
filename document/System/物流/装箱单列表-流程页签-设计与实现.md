## 1. 业务定位

| 概念 | 说明 |
|------|------|
| **目标** | 在列表右栏查看某张装箱单下 **单条装箱明细** 的出库侧流程 |
| **页签** | 默认 `r-flow`；并列「客户」、帮助 |
| **列表绑定** | **单击**装箱单行即绑定该箱（口径 A） |
| **明细切换** | 流程页顶部始终展示本箱全部明细单号（`itemCode`，如 `PAK0020Z-1`）；**始终显示**（仅 1 条也可点/高亮，口径 A） |
| **流程内容** | 与详情页「流程」**一致**：销售订单明细 → 出库通知 → 装箱 → 拣货 → 出库。字段见详情 §2.3 与 [流程页签规范 §3.1](../../PRD/规范/UI规范/流程页签规范.md)。**出库站**按装箱行对齐出库明细（出库单号 + 出库明细单号 + 本行数量），见 [出库明细单号与装箱流程出库站](./出库明细单号与装箱流程出库站-设计与实现.md) |

## 2. 交互

| # | 条件 | 结果 |
|---|------|------|
| A | 未单击装箱单 | 提示「请选择一张装箱单」 |
| B | 单击装箱单 | 拉取详情 + 拣货页；默认选中第一条明细；渲染流程 |
| C | 顶部切换明细单号 | 切换当前明细，重载该行 aggregates（拣货 extras 同步） |
| D | 切换另一张装箱单 | 重置为新箱首条明细 |
| E | 离开 `PackingList` | `clear()` store |

列表行高亮当前已绑定的装箱单。
