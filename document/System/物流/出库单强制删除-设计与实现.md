## 1. 目的

强制删除出库单会回滚库存、软删未核销应收。确认前须展示本单应收与核销状态及后果，避免只输入单号就删。

## 2. 权限与入口

| 项 | 规则 |
|---|---|
| 按钮 | 出库单列表操作列「强制删除」；仅系统管理员、平台管理员 |
| 预览 | `GET /api/v1/stock-out/{id}/force-delete-preview`，同上权限，否则 403 |
| 执行 | `POST /api/v1/stock-out/{id}/force-delete`，`confirmBillCode` 须与出库单号一致 |

## 3. 弹窗规则

先拉预览，再决定能否输入单号。

| 预览 | 界面 |
|---|---|
| `CanForceDelete = false`（已核销等） | 红字拦截原因 + 应收表（单号、核销状态、金额、已核销、收款单号）；无确认输入；仅「关闭」 |
| 无有效应收 | 文案「本单没有有效应收」；可输入单号删除 |
| 有未核销应收 | 列出应收；后果含「一并作废未核销应收」；输入出库单号后可删 |

**删除后将会（允许删除时）：**

- 有未核销应收：一并作废，应收列表不再显示  
- 状态为已出库/出库完成（2/4）：回滚库存  
- 不会自动再生成应收；要再出库须重新出库后「标记完成」  
- 关联装箱状态按剩余有效出库校正  

已核销不得与「确认删除」共用一套文案。

| 模块 | 路径 |
