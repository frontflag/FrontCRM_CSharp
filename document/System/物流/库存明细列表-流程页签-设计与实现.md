## 1. 业务定位

| 概念 | 说明 |
|------|------|
| **目标** | 以地铁竖轴展示 **单条库存明细层** 从采购到出库的链路 |
| **展示位置** | `AppLayout` 右侧辅助栏 **「流程」**，与「帮助」并列（本版 **无「操作」**） |
| **页签 ID** | `r-flow`（默认）；帮助 `r4` |
| **数据粒度** | 一条 `stock_item`（`stockItemId`） |
| **只读** | 无动作按钮；单号可跳转详情 |

进入本页默认右栏为「流程」。帮助页仍用既有手册（库存明细暂无独立 help 页）。卡片视觉与客商跳转见 [流程页签规范 §2.5～§2.9](../../PRD/规范/UI规范/流程页签规范.md)：创建日期 `yy-MM-dd`；供应商/客户通栏名称在有权限且有 ID 时可点（新开页）。

## 2. 布局与交互

### 2.1 站点顺序（定稿，仅 7 站）

```
采购明细 → 质检 → 入库 → 库存明细 ☜ → 出库通知 → 装箱 → 出库
```

不含销售明细、收款、开票、采购申请、到货、使用备货。空站仍画空心「未开始」。同站多卡按创建时间升序。描述 MVP 固定不展示（空/`—`）。

当前业务站为 **库存明细**，标题旁挂 `FlowYouAreHereMark`，站容器加 `is-main`。

### 2.2 交互门控

对齐销售/待报关：`dataTabIds: ['r-flow']`。

| 条件 | 行为 |
|------|------|
| 右栏收起单击 | 忽略，不请求 |
| 展开且在「帮助」单击 | 仅高亮选中行，不请求 |
| 展开且在「流程」单击 | `GET .../stock-items/{id}/flow-aggregates` |
| 切到「流程」或展开右栏且已在「流程」 | 有选中行则加载 |
| 双击行 | 仍进分桶详情（现网），与单击互不冲突 |
| 511 / 521 脱敏 | **仍加载**；供应商/采购价或客户/业务员/销售价为 `—` |

无 `r-ops` 时展开右栏回落到 `r-flow`（`preferRightOpsTabOnExpand`）。

## 3. 按站字段

| 站 | 单号/状态/日期 | 供应商 | 采购员+采购价+数量 | 入库数量 | 客户 | 业务员+销售价 | 装箱/出库数量 |
|----|----------------|--------|---------------------|----------|------|-----------------|----------------|
| 采购明细 | 有（创建日） | 有（名称通栏，无编号） | 有（采购行数量） | 无 | 无 | 无 | 无 |
| 质检 | 有 | 无 | 无 | 无（通过/拒收） | 无 | 无 | 无 |
| 入库 | 有；第一行右入库类型（报关入库旁挂报关图标） | 无 | 无 | 有（本层入库量） | 无 | 无 | 无 |
| **库存明细** | 库存明细编号 / 出库状态 / **入库日** / 入库类型（报关入库旁挂报关图标） | 有（名称通栏，无编号） | 层采购价+币别 | 层入库量 | 有则显（名称通栏，无编号） | 有则显销售价（本站不展示业务员） | 层已出库 |
| 出库通知 | 有（创建日）；右侧出库类型（报关出库旁挂报关图标） | 无 | 无 | 无 | 有（名称通栏，无编号） | 本站不展示业务员 | 本层装箱量 |
| 装箱 | 有（创建日）；右侧出库类型（报关出库旁挂报关图标） | 无 | 无 | 无 | 有（名称通栏，无编号） | 本站不展示业务员 | 本层装箱量 |
| 出库 | 有（创建日）；右侧出库类型（报关出库旁挂报关图标） | 无 | 无 | 无 | 有（名称通栏，无编号） | 本站不展示业务员 | 本层出库量 |

入库站第一行左单号、右入库类型；类型为报关入库时在文案旁显示报关图标（示意，不要求可点进报关单）。下一行左状态、右创建日期。

库存明细站第二行左入库日、右入库类型（报关入库时类型旁显示报关图标；本站不展示业务员）。其下红框顺序：供应商名称通栏 → 采购价·币别 | 入库数量 → 客户名称通栏（有客单才显）→ 销售价·币别 | 出库数量。供应商名称、客户名称各自单独一行（`grid-column: 1 / -1`），**不**展示供应商编号 / 客户编号。

出库通知、装箱、出库三站第二行左创建日期、右出库类型（报关出库时类型旁显示报关图标；本站不展示业务员）。

## 4. 数据口径（只挂本层）

| 站 | 来源 |
|----|------|
| 采购明细 | `stock_item.purchase_order_item_id` → 采购行（无则空站） |
| 质检 | 本层入库单 `stock_in.QCID`（无则空站） |
| 入库 | 本层 `stock_item.StockInId` |
| 库存明细 | 列表行 + 聚合回显 |
| 出库通知 / 装箱 | **仅** `packing_item.stock_item_id`（及拣货行 `pickingtaskitem.stock_item_id` 反查装箱明细）指向本层的单据；**不**用销售行全量 `detail-tab-aggregates` |
| 出库 | **仅** `stock_out_item_extend.StockItemId` = 本层 |

同销售行其它库存层的出库通知/装箱/出库 **不出现** 在本层流程上。
