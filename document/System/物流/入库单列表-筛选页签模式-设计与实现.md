## 1. 业务定位

将搜索栏中适合做成单选桶的下拉，可选转为表格/看板上方全宽页签条。**单维度**；关闭页签不清筛选值；点页签立即查询。

文本、日期不纳入。本版维度仅 **仓库**、**入库类型**。

---

## 2. 设计要求（定稿）

### 2.1 可纳入维度

| 维度 key | 搜索栏字段 | 页签形态 |
|----------|------------|----------|
| `warehouse` | `warehouseId` | 全部 + 启用仓库（名称；选项 **>10** 时强制回退下拉，菜单项禁用） |
| `stockInType` | `stockInType` | 全部 + 采购 / 报关 / 退货 / 报废（与下拉一致；历史采购 `1` 归一为 `10`） |

### 2.2 交互与视觉

遵循 UI 规范 §10：齿轮菜单、单维度、贴合表顶、亮色未选中 `#E8EDF5`、暗色 `var(--crm-layer-1)`。开启对应维度后隐藏该下拉。看板视图同样显示页签条，点页签同步 `boardFilters`。

---

## 3. 实现方法

| 文件 | 职责 |
|------|------|
| `CRM.Web/src/utils/stockInListTabMode.ts` | 维度、localStorage、`tab↔filter` |
| `CRM.Web/src/views/Inventory/StockInList.vue` | 菜单、页签条、按维度隐藏下拉 |
| `zh-CN.ts` / `en-US.ts` | `stockInList.settingsMenu.*`、`filterTabs.all` |

**localStorage：** `crm.stock-in-list.tab-mode` = `off` \| `warehouse` \| `stockInType`。

**无需改后端**：同一套列表 query（`warehouseId`、`stockInType`）；点页签走现有 `handleSearch` → 路由 query → 拉列表 / 看板。
