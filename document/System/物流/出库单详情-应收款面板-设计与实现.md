# 出库单详情 — 应收款面板

> **状态：** 已实现（2026-08-19）  
> **适用页面：** 出库单详情 `/inventory/stock-out/:id`  
> **关联：** [出库单详情-销售行与装箱号展示](./出库单详情-销售行与装箱号展示-设计与实现.md)、[出库单强制删除](./出库单强制删除-设计与实现.md)  
> **用户帮助：** [出库单](../../../help/pages/出库单_MENU_STOCK_OUT.md)

---

## 1. 口径

销售出库标记完成后，按本单扩展表销售行生成应收（一头多行销售行 → 多张应收）。详情在「销售订单明细」**之下**展示本单有效应收，只读对照。

| 项 | 规则 |
|---|---|
| 谁看得到面板 | **销售出库**（`StockOutType = 10`）才显示；报关/退货/报废不显示。代码仍兼容历史 `1`（库中已刷净） |
| 读权限 | 与出库单详情相同；`GET /api/v1/stock-out/{id}/receivables`，**不**要求 `finance-receipt.read` |
| 点进应收详情 | 仍要 `finance-receipt.read`；无权限只显示单号文本 |
| 粒度 | 一张应收对应一条销售行，不是一条出库明细 |
| 不做 | 作废、核销、补生成 |

空态：尚未标记完成（状态 ≠ 4）→「尚未标记完成，暂无应收」；已完成仍无行 →「暂无应收款」。

---

## 2. 列

应收单号、销售订单明细编号、出库数量、应收金额（含币别）、收款核销状态、收款已核销、收款待核销、发票核销状态。

单头已有客户/出库单号/日期，不再重复。金额列跟随出库详情的销售金额可见性（`sales.amount.read` + 敏感字段脱敏）。

---

## 3. 实现

| 位置 | 行为 |
|------|------|
| `FinanceReceivableService.ListForStockOutDetailAsync` | 按 `stock_out_id` 取未删除应收，补销售明细编号 |
| `StockOutService.GetDetailReceivablesAsync` | 出库不存在 404；非销售返回空 |
| `StockOutController` `GET {id}/receivables` | 与出库详情同一授权 |
| `StockOutDetail.vue` | 销售出库时渲染面板 |
