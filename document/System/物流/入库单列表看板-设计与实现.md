## 1. 业务定位

在入库单列表内切换统计看板。统计范围 = **当前搜索栏筛选结果全量**（含草稿 / 待入库 / 已取消），不是当前页，也不是物流分析透镜。

金额统一为 **全部入库金额**（入库采购单价 × 入库数量），不用成单 / 订单额。计数为 **入库单数**（单头）。

---

## 2. 交互

| 项 | 行为 |
| --- | --- |
| 入口 | 搜索栏「查询 / 重置」后 |
| 默认 | 列表 |
| 看板态 | 隐藏表格、分页、标题「共 N 条」；筛选仍可用 |
| 帮助 | 看板态覆盖为入库单看板说明 |
| 页签模式 | **无**（入库单列表没有筛选页签齿轮，不抄出库明细） |

---

## 3. 口径摘要

| 指标 | 口径 |
| --- | --- |
| 入库金额 | `入库数量 × 入库采购单价`；美金：过账快照 → `convert_price × 数量` → 查询日汇率 |
| 入库单数 | 单头数，与列表「共 N 条」对齐 |
| 入库供应商数 | 头表供应商去重；空供应商不计 |
| 趋势 | 入库日；入库单数 + 折算美金；天/周/月 |
| 分布 | 入库类型（1 与 10 合并采购）、采购员 |
| 排名 | Top10 供应商、Top10 采购员（折算美金） |

无采购金额权限或 511 时金额脱敏，饼图/排名改按**单数**。511 时请求去掉 `vendorName`。

参数与 `GET /api/v1/stock-in` 相同。须注册在 `[HttpGet("{id}")]` **之前**。
