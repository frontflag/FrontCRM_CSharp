## 1. 业务定位

左栏提供 **preset 快捷检索**，表达主栏 keyword 不便一键覆盖的 **时间窗口、质检结果、图片有无** 等业务视角；与主栏精确筛选 **共用 URL query**。

| 概念 | 说明 |
|------|------|
| **适用页面** | 质检列表（路由名 `QcList`）；左栏在 `QcCreate` 路由仍显示页签，但 **preset 仅在 `QcList` 生效** |
| **preset 单选** | 两组共 **10 项**；再点同一项 → 清除 preset、**保留** keyword；主栏 preset chip ✕ → 清除 preset、保留 keyword；主栏「重置」→ **清空全部 query** |
| **keyword 叠加** | `qcCode`、`model`、`vendorName`、`purchaseOrderCode`、`freightForwarderOrderNo`、`salesOrderCode`、`stockInType` 可与 preset **同时生效**（与到货通知不同：主栏到货类型 **不与 preset 互斥**） |
| **不含左栏文本输入** | 型号/供应商/单号等仍在主栏 search-bar；左栏 **仅 preset 按钮** |
| **列表驱动** | 左栏点击 / 主栏搜索 / 重置 → `router.replace` → 列表 `watch(route.query)` → `GET /api/v1/logistics/qcs` |
| **右栏操作面板** | 搜索/重置/preset 切换触发 `resetListRightPanelOnReload(qcOpsStore)`，与操作面板 §2.4 一致 |

## 2. 数据字段

### 2.1 时间 preset：`CreateTime`

| 项 | 定稿 |
|----|------|
| 字段 | `qcinfo.CreateTime`（列表列「创建时间」） |
| 含义 | **质检单创建时刻**，非 `ModifyTime`（保存判定结果时间） |
| 日历边界 | 服务端 `DateTime.UtcNow.Date` 起算，窗口为 **UTC 日历日**（与 [到货通知左栏检索](./到货通知列表-左栏检索-设计与实现.md) 后端 preset 一致；后续若统一业务时区可整体调整） |

### 2.2 状态 preset：`Status` / `ModifyTime`

`QCInfo.Status` 口径（实体注释）：

| 值 | 列表列文案 | 说明 |
|----|------------|------|
| `100` | 已通过 | 详情页保存结果为 pass |
| `10` | 部分通过 | 见 §3.2 **部分通过** 严格口径 |
| `-1` | 未通过 | 详情页保存结果为 reject |

创建质检单时默认 `Status = 10`、`ModifyTime = null`（尚未保存判定）。

### 2.3 图片 preset：`upload_document`

| 项 | 定稿 |
|----|------|
| 关联 | `BizType = 'QC'`，`BizId = qcinfo.UserId`（主键） |
| 图片判定 | 与前端 `qcImageDocument.ts` / 销售·采购明细「质检图片」一致：`mime` 以 `image/` 开头，或扩展名 / 原始文件名为 `.jpg/.jpeg/.png/.gif/.webp/.bmp` |
| 软删 | `UploadDocument` 全局 query filter 已排除 `IsDeleted` |

## 3. preset 列表（10 项）

窗口算法与到货通知「X 日内到货」对齐：**含当天**，向前共 N 个 UTC 日历日。

### 3.1 时间（5 项）

| preset ID | 左栏文案 | 条件（`CreateTime`） |
|-----------|----------|----------------------|
| `qc_today` | 今日质检 | = **今天**（UTC 日） |
| `qc_today_yesterday` | 今昨质检 | ∈ **[昨天, 今天]** |
| `qc_within_3_days` | 近3日质检 | ∈ **[今天-2, 今天]**（共 3 日） |
| `qc_within_7_days` | 近7日质检 | ∈ **[今天-6, 今天]** |
| `qc_within_30_days` | 近30日质检 | ∈ **[今天-29, 今天]** |

### 3.2 状态（5 项）

| preset ID | 左栏文案 | 条件 |
|-----------|----------|------|
| `status_passed` | 已通过 | `Status = 100` |
| `status_partial` | 部分通过 | `Status = 10` **且** `ModifyTime != null`（**不含** 刚创建未保存的单据） |
| `status_rejected` | 拒绝 | `Status = -1`（左栏文案「拒绝」；列表状态列仍显示「未通过」） |
| `has_qc_images` | 有质检图片 | 存在 §2.3 口径的图片附件 |
| `no_qc_images` | 无质检图片 | 不存在上述图片附件 |

## 4. API 与 query

### 4.1 URL query（前端）

| 键 | 说明 |
|----|------|
| `preset` | §3 preset ID；单选 |
| `qcCode` / `model` / `vendorName` / `purchaseOrderCode` / `freightForwarderOrderNo` / `salesOrderCode` | 可与 preset 叠加 |
| `stockInType` | 到货类型（10/20/30/40）；可与 preset 叠加 |

### 4.2 后端 `GET /api/v1/logistics/qcs`

`QcQueryRequest` 扩展：

| 参数 | 说明 |
|------|------|
| `preset` | 绑定 `Preset`；`QcListQuickFilterCodes.IsKnown` 时由 `QcListQuickFilter.Apply` 解析 |

preset 与既有 keyword、`StockInType` 等条件 **AND** 组合（在 `QcListQuery.GetPagedQcIdsAsync` 内先 Apply preset，再应用其余筛选）。

## 5. 与主栏关系

| 项 | 行为 |
|----|------|
| 主栏 search-bar | 保留全部控件；**不**因 preset 隐藏到货类型或单号输入 |
| preset chip | 有 preset 时在 search-bar 上方展示（文案 + ✕） |
| 左栏再点同一 preset | 仅清除 `preset`，keyword 保留 |
| chip ✕ | 同上 |
| 主栏「重置」 | 清空 preset + 全部 keyword |

### 7.1 图片筛选 EF 实现注意

**禁止** 在 `IQueryable` 的 `Any` 内调用不可翻译的静态方法（如 `IsQcImageDocument(d)`），否则 PostgreSQL 提供程序报错。

正确做法：

1. `QcImageDocumentBizIds`：对 `UploadDocuments` 用 **内联** `mime` / `FileExtension` / `OriginalFileName` 条件，`.Select(d => d.BizId).Distinct()`；
2. 主查询 `q.Where(x => imageQcIds.Contains(x.Id))`（或取反）。
