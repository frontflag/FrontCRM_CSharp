## 1. 目的

只读全量核对：装箱单、装箱明细、出库单、出库明细、应收款。查出链条中断、状态不一致、金额/币别偏差、客户不一致、重复出库。不自动改数。

## 2. 权限与入口

| 项 | 规则 |
|---|---|
| 菜单 | 出库管理最后一项；系统/平台管理员，或财务部门总监 |
| 路由 | `StockOutOpsCheck`，`meta.inventoryOpsCheckAccess` |
| API | `POST /api/v1/stock-out/ops-check`，`InventoryOpsCheckAccessRules.CanAccess` |
| 范围 | 全量；结果最多 2000 条 |

物流操作员、普通出库菜单用户、财务部非总监不可见。

## 3. 检查项

排除 `StockOutType = 3`（调拨虚拟出库）。有效出库 = 未删除且状态 ∈ {2, 4}。

| 类别 | 条件 | 级别 | 运维操作建议 |
|---|---|---|---|
| 链条 | 装箱状态 100 且无有效出库 | 错误 | ① 本行装箱单详情点「刷新」 |
| 链条 | 装箱 100 但装箱行对不上出库明细 | 错误 | ① 打开装箱单详情核对本行；② 打开对应出库详情核对拣货；③ 对该出库「强制删除」后按流程重出。已核销的出库先写收款单号「反核销」 |
| 链条 | 销售出库状态 4 无应收 | 错误 | ① 打开该出库详情确认；② 「强制删除」该出库单号；③ 重出后对新单「标记完成」 |
| 链条 | 应收存在、出库单缺失或已删 | 错误 | 未核销：① 应收款详情对该应收单号「作废应收」。已核销：① 打开核销对应的收款单号「反核销」；② 再「作废应收」。不出现「去列表里找」 |
| 状态 | 有有效出库但装箱不是 100 | 错误 | ① 本行装箱单详情点「刷新」 |
| 状态 | 已有有效出库，通知不是已出库/已取消 | 警告 | 出库未完成：对该出库单号「标记完成」。出库已完成（无「标记完成」）：打开出库通知核对（无单独改状态按钮） |
| 重复 | 一装箱单 ≥ 2 张有效出库 | 错误 | **保留出库单号最小的一张**，其余按单号逐步「强制删除」（输入该出库单号确认）；最后本行装箱单详情「刷新」。仅当**被删的那张**已核销才插入收款单号「反核销」 |
| 重复 | 一装箱行对应 ≥ 2 张出库单 | 错误 | 同上（刷新写装箱单号，因本行是装箱明细） |
| 金额 | 应收数量 ≠ 出库明细数量合计 | 错误 | 出库仍有效时**不作废应收**。已核销先收款单号「反核销」；再对该出库「强制删除」（同步软删未核销应收）；重出后「标记完成」 |
| 金额 | 应收金额 ≠ Σ(出库数量 × 销售行单价)，容差 0.01 | 错误 | 同上 |
| 金额 | 应收币别 ≠ 销售订单币别 | 错误 | 同上 |
| 客户 | 装箱 / 出库 / 应收 / 销售订单 `customer_id` 不一致 | 错误 | 打开该销售订单号，「刷新 ▾ → 刷新客户」。本行已核销则先收款单号「反核销」 |
| 客户 | 主键一致但应收名称 ≠ 客户主数据 | 警告 | 打开该销售订单号，「刷新 ▾ → 刷新客户」 |

建议由服务端按**本行单据**生成：一步一行、①②③ 编号；每步含页面 + 单号 + 按钮。未核销行不得出现反核销步骤。出库单仍有效时不得建议「作废应收」（作废仅用于出库已删的孤儿应收）。前端建议列 `white-space: pre-line` 保留换行。

销售出库不查供应商（本类型不适用）。出库明细单价常为 0，金额以销售行为准。

装箱行对齐：`packing_item` → `pickingtaskitem.packing_item_id` → `stock_out_item.picking_task_item_id`，或 `packing_id` + 扩展表销售行。

## 4. 结果过滤（前端切片）

检查仍是全量扫描，过滤不传 API、不缩小扫描范围。下拉即时生效；单号回车或点「搜索」。重置只清过滤，不清已跑出的报告。

| 条件 | 字段 | 规则 |
|---|---|---|
| 单号 | `DocCode` 或 `RelatedDocCode` | 去空格、忽略大小写、**右模糊**（`StartsWith`） |
| 级别 | `Severity` | `error` / `warning`；清空 = 全部 |
| 检查类型 | `Category` | `chain` 链条 / `status` 状态 / `duplicate` 重复 / `amount` 金额 / `customer` 客户 |
| 单据类型 | `DocType`（主单） | `packing` 装箱单 / `packingItem` 装箱明细 / `stockOut` 出库单 / `receivable` 应收款 |

标题与筛选之间为数据面板：「错误」（红）、「警告」（橙）、「合计」（青，全量条数）。有过滤时第三张改为「显示 x / y」。无匹配时文案为「当前过滤无匹配」，与「未发现异常」区分。过滤只作用于已返回的最多 2000 条。
