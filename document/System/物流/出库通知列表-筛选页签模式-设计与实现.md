## 1. 业务定位

将搜索栏中适合做成单选桶的下拉，可选转为表格上方全宽页签条。**单维度**；关闭页签不清筛选值；点页签立即查询。

文本、日期不纳入。本列表无左栏 shortcut preset。首版**只做页签模式**，不改日期控件形态、不下拉变更即查。

---

## 2. 设计要求（定稿）

### 2.1 可纳入维度

| 维度 key | 搜索栏字段 | 页签形态 |
|----------|------------|----------|
| `status` | `status` | 全部 + 待报关 / 待装箱 / 已装箱 / 已出库 / **已取消**（与下拉一一对应） |
| `regionType` | `regionType` | 全部 + 境内 / 境外 |
| `stockOutType` | `stockOutType` | 全部 + 销售 / 报关 / 退货 / 报废（筛选项仅 10/20/30/40，不含移库、未知） |

### 2.2 交互与视觉

遵循 UI 规范 §10：齿轮菜单、单维度、贴合表顶、亮色未选中 `#E8EDF5`、暗色 `var(--crm-layer-1)`。两路由共用偏好键。

### 2.3 出库类型文案与筛选（禁止兜底）

| 口径 | 规则 |
|------|------|
| 列表/页签/下拉**展示** | 与出库单同一套映射：`10` → 销售出库；`20` 报关；`30` 退货；`40` 报废；`3` 移库；`0`/空/其它 → **未知**。禁止未识别值写成销售出库。代码仍把历史 `1` 显示为销售出库（**库中已刷净**）。 |
| **筛选查询** | 点「销售出库」只传 `stockOutType=10`，后端按该值**精确匹配**。存量销售出库均为 `10`。 |
| 筛选项集合 | 仍为 10/20/30/40，不增加「移库」「未知」筛选项。 |
| 写入归一 | 新建出库通知未传类型仍由 `NormalizeForNotify` 写成 `10`，本页筛选不改写入。 |

实现：`resolveStockOutTypeLabelKey`；`StockOutRequestListQuery` 不再对筛选项做 `NormalizeForNotify`。
