## 1. 业务定位

库存中心回答 **「当前仓里还有哪些货」**：

- 数据源：库存明细 `stock_item`
- 仅 **在库数量 &gt; 0**
- 排除手工移库源行
- **不按销售明细拆开**；默认一行 = 物料型号 + 品牌
- 可选再按库存类型、仓库拆分（可复选）
- 金额按采购 **原币分列合计**，不折算、不混加

库存桶仍是 `stock` 分桶结余（含在库数量 = 0），供对账与下钻。

## 2. 拆分与筛选

| 区域 | 行为 |
|------|------|
| 拆分维度栏 | 复选：库存类型、仓库。记住上次勾选（localStorage `crm.inventory-on-hand.split`）。首次进入均不勾。 |
| 搜索栏始终 | 物料型号、品牌（包含匹配，忽略大小写） |
| 搜索栏绑定拆分 | 勾选库存类型后出现类型下拉；勾选仓库后出现仓库下拉。取消勾选时清空对应筛选值。 |
| 重置 | 只清搜索栏，不清拆分勾选 |

分组键：型号、品牌去空白后忽略大小写。

---

## 3. 列表列

固定：物料型号、品牌、在库数量。

勾选拆分后追加：库存类型列、仓库列。

金额列：按 **当前筛选全量结果** 中出现过的采购原币出列，顺序 RMB → USD → EUR → HKD → JPY → GBP。未出现的币别不出列。同一行数量按 PCS 加总，金额按该层原币分到对应列（没有的币别为 0）。

```text
在库金额{币别} = Σ(该组内采购原币=该币别 的 在库数量 × 采购单价)
在库数量 = Σ(组内在库数量)
```

无导出、无点行下钻、不拆境内/境外。

标题下统计卡片（当前筛选全量，与分页无关）：

- **在库数量**：Σ 在库数量（PCS）
- **各币别库存金额**：与列表同口径、同币别顺序；未出现的币别不出卡片。采购敏感角色金额显示「—」。

## 4. API 与实现

| 项目 | 约定 |
|------|------|
| **GET** | `/api/v1/inventory-center/on-hand/paged` |
| **实现** | `CRM.Infrastructure/InventoryCenter/InventoryOnHandSummaryQuery.cs` |
| **数据范围** | `ApplyStockItemListDataScopeAsync`（与库存明细列表相同） |
| **Query** | `materialModel`、`purchaseBrand`、`stockType`、`warehouseId`、`groupByStockType`、`groupByWarehouse`、`page`、`pageSize` |
| **响应** | `items`、`total`、`page`、`pageSize`、`currencies`、`onHandQtyTotal`、`totalAmounts`（全量结果出现过的币别及合计） |
| **脱敏** | 采购敏感角色（511）行金额与 `totalAmounts` 置 0；前端金额列与金额卡片显示「—」 |
