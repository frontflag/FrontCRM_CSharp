## 1. 入口

搜索栏「看板」进入；再点「列表」返回表格。看板态右侧帮助切换为看板说明。

拆分维度栏仍可见；勾选只影响列表列，看板统计集合不变。

---

## 2. 筛选

与列表搜索栏一致：

| 条件 | 说明 |
| --- | --- |
| 型号 / 品牌 | 始终可用，包含匹配 |
| 库存类型 / 仓库 | 仅勾选对应拆分后出现；未勾选时不参与筛选 |

重置只清搜索值，不清拆分勾选。

## 3. 指标

### 3.1 KPI（今天）

| 指标 | 公式 |
| --- | --- |
| 在库数量 | Σ `qty_repertory` |
| 库存金额 | 各原币 Σ(`qty_repertory × purchase_price`) |
| 加权平均库龄 | `ROUND(Σ(库龄天×qty)/Σ(qty),1)`；与 [物流统计](../../IMP/数据看板/物流统计.md) §4.3 一致 |
| 呆滞层数 | 入库日 ≤ 今天−90 或无入库日，按层计数 |

### 3.2 趋势（最近 12 个月，按月，时点存量）

固定 **12 个月度点**（当月往前共 12 个自然月）；金额趋势固定 **RMB、USD** 两图（无该原币在库时为 0）。

每个周期末：

```text
层在库数量(asOf) = max(0, qty_inbound − Σ出库数量(出库日 ≤ asOf))
```

金额 = 各原币 `在库数量 × 采购单价` 分列。

### 3.3 分布 / 排行

饼图与 Top10 可在 **数量 / 各原币金额** 间切换。库龄分桶与 [物流统计](../../IMP/数据看板/物流统计.md) §4.3 一致。

## 4. API

| GET | 说明 |
| --- | --- |
| `/api/v1/inventory-center/on-hand/analytics/dashboard` | KPI |
| `.../trends` | 趋势（固定按月 12 点） |
| `.../breakdowns` | 饼图 |
| `.../rankings` | Top10 |

数据范围：`ApplyStockItemListDataScopeAsync`；排除移库源行；`qty_repertory > 0`。

511：行金额脱敏；**加权平均库龄不脱敏**；分布/排行金额模式回退数量。
