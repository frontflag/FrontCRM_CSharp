**状态：** 已上线  
**测试对照：** [出库单关联文档-测试对照说明](../../QA/物流/出库单关联文档-测试对照说明.md)  
**关联：** [出库单列表-操作面板-设计与实现](./出库单列表-操作面板-设计与实现.md)、[上传文档管理系统IMP](../../IMP/上传文档管理系统IMP.md)、UI [文档上传组件规范](../../PRD/规范/UI规范/文档上传组件规范.md)（§2.6 类型下拉、§3.5 分类平铺）、用户帮助 [出库单](../../../help/pages/出库单_MENU_STOCK_OUT.md)

本文描述 **FrontCRM** 出库单头挂载附件、按类型区分「出货照片 / 出货签收单 / 其他」，并在 **出库单列表操作面板** 与 **出库详情** 上传、预览、删除。

---

## 1. 业务定位

| 概念 | 说明 |
|------|------|
| **挂载对象** | 出库单头 `stock_out.Id`，`BizType=STOCK_OUT`（复用 `upload_document`，不新表） |
| **不是** | 出库明细行、出库通知、装箱单 |
| **类型** | `SHIP_PHOTO` 出货照片；`POD` 出货签收单；`OTHER` 其他 |
| **入口** | ① 出库单列表右侧「操作」面板「文档」卡；② 出库详情「关联文档」页签 |
| **状态** | 不限出库状态；草稿到出库完成均可上传 |

---

## 2. 数据

表 `upload_document` 增加 `DocCategory`（`varchar(32)` NOT NULL，默认 `OTHER`）。

| 码 | 含义 | 典型文件 |
|----|------|----------|
| `SHIP_PHOTO` | 出货照片 | jpg / png，可多张 |
| `POD` | 出货签收单 | pdf 或照片 |
| `OTHER` | 其他 | 沿用文档模块白名单 |

未知码、空值、历史未分类记录：`UploadDocumentCategory.Normalize` → `OTHER`。  
其它业务（销售订单、质检等）不传分类时同样落 `OTHER`，列表默认不显示类型标签，行为与改前一致。

迁移：`CRM.Infrastructure/Migrations/20260918150000_UploadDocumentDocCategory.cs`。

---

## 3. API

`POST /api/v1/documents/upload` 增加表单字段 `docCategory`（可选）。  
响应 DTO 增加 `docCategory`。未登录用户标识时，`UploadUserId` 取当前 JWT。  
单次非通知附件最多 **20** 个文件（对齐出库详情既有上限）。

查询仍按 `bizType` + `bizId`，按 `CreateTime` 降序；分类由前端在出库列表每行左侧用标签展示（`showCategoryTag`）。

## 4. 界面

### 4.1 列表操作面板

卡片插在「出库摘要」与「出货方式」之间，**可折叠**：标题「文档」+ 份数（或「（无上传）」）常显，右侧上下箭头（收起 ↓ / 展开 ↑）。本机第一次为**收起**；之后用 `localStorage`（`frontcrm.stock-out-ops.docs-expanded`）记住上次展开/收起，换行、刷新仍沿用。收起时仍请求文档列表以刷新标题份数，上传区与文件列表不占高度。

展开后视觉（间距、左缘对齐、紧凑下拉、悬停工具条）以 [扩展窗口页签-操作规范 §3.2b](../../PRD/规范/UI规范/扩展窗口页签-操作规范.md) 为准。

展开后：物流可写显示类型下拉（默认出货照片）+ 上传；只读仅列表。  
下方为**一条平铺列表**（不按类型分三组），按上传时间新到旧；每行左侧类型标签（出货照片 / 出货签收单 / 其他），其后文件名。文件行**无单独边框**，操作面板列表**无统一外框**。点文件名可预览。**预览 / 下载 / 删除（可写）默认隐藏**；鼠标移到该行后，右侧浮现浅黄底工具条（预览、下载、删除）。无文件时单条「暂无」。

### 4.2 出库详情

「关联文档」页签：有文件时文案为 `关联文档 ({n})`（`n` 为未删除附件份数，与列表一致）；`n=0` 不显示括号。先选类型再上传；类型下拉与文件名字号/字体一致（13px / Noto Sans SC）；列表平铺、行首类型标签；文件行**无单独边框**，整份列表共用一圈边框。**预览 / 下载 / 删除常显**（不随操作面板悬停隐藏）。物流只读隐藏上传、不可删除。

### 4.3 权限

无新权限码。上传/删除跟 `canWriteLogisticsData`（物流数据可写）。列表可见范围与出库单数据权限一致。
