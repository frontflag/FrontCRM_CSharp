# 通用图片浏览 — 设计与实现

**状态：** MVP（Phase 1）  
**关联：** 质检图片只读画廊 `QcImagesReadonlyGallery`、质检编辑 `QcCreate.vue`、文档 API `documentApi`

---

## 1. 业务定位

在应用内提供 **全屏多图浏览器**，替代「每张图新开浏览器标签」的预览方式，支持顺序浏览、文件名列表点选、缩放与适应窗口/宽度。

### 1.1 Phase 1 接入场景

| 场景 | 入口 |
|------|------|
| 销售订单明细详情 · 质检图片 | `QcImagesReadonlyGallery`（`SalesOrderDetail.vue`） |
| 采购订单明细详情 · 质检图片 | `QcImagesReadonlyGallery`（`PurchaseOrderDetail.vue`） |
| 质检新建/编辑 · 质检图片 | `QcCreate.vue` `el-upload` 预览 |

### 1.2 Phase 1 不做

- 底栏缩略图条
- 独立路由页 `/tools/image-viewer`
- 浏览时删除当前图
- 下载按钮

## 2. 交互规格（已定稿）

| 项 | 规则 |
|----|------|
| 形态 | 全屏遮罩；`z-index: 10050`；`Teleport` 至 `body` |
| 挂载 | `AppLayout` 根级单例 `CrmImageBrowser` |
| 打开方式 | `useImageBrowser().openImageBrowser({ items, initialIndex, title })` |
| 默认显示 | **适应窗口**；切换图片时重置为适应窗口 |
| 100% | 真实像素 1:1（`scale = 1`） |
| 适应宽度 | 宽铺满主图区，高超屏纵向滚动 |
| 缩放 | 25%～400%，步进 25%；`scale` 模式下可拖拽平移 |
| 左侧列表 | 多图时平铺 **仅文件名**（截断 + `title` tooltip）；单图时 **隐藏侧栏** |
| 顶栏 | 标题 \| 缩小 \| 放大 \| 100% \| 适应窗口 \| 适应宽度 \| 关闭 |
| 底栏 | 上一张 \| 下一张 \| `n / total` |
| 导航边界 | 首尾禁用上一张/下一张 |
| 关闭 | `Esc`、顶栏关闭；**点击背景不关闭** |
| 路由切换 | **自动关闭**浏览器 |
| 权限 | 沿用 `GET /api/v1/documents/{id}/preview`，不新增后端 |

### 2.1 键盘

- `←` / `→`：上一张 / 下一张  
- `+` / `-`：放大 / 缩小  
- `0`：100%  
- `Esc`：关闭

## 3. 数据模型

```ts
interface ImageBrowserItem {
  id: string
  name: string
  documentId?: string
  previewUrl?: string  // 质检编辑未上传的 blob:
}
```

映射工具：

- `qcReadonlyRowsToBrowserItems` — 订单明细 aggregates `qcImages`
- `qcUploadFilesToBrowserItems` — 质检编辑 `el-upload` 文件列表

## 5. 测试要点

1. 销售/采购明细质检图片：多图时左侧文件名、底栏计数、上一张/下一张正确。  
2. 单图：无左侧栏，主图区占满。  
3. 缩放至 400% 后切换图片：重置为适应窗口。  
4. 适应宽度：长图可纵向滚动。  
5. 质检编辑：已上传（`documentId`）与未上传（`blob:`）均可浏览。  
6. 路由 Tab 切换：全屏层自动关闭。  
7. `Esc` 关闭；点击暗色背景不关闭。
