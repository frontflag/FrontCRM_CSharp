## 1. 业务定位

将搜索栏中适合做成单选桶的下拉，可选转为表格上方全宽页签条。**单维度**；关闭页签不清筛选值；点页签立即查询。

文本、日期不纳入页签。首版**只做页签模式**，不改日期控件形态；状态下拉 / 到货类型下拉在页签模式下隐藏，文本与日期仍须点「搜索」。

---

## 2. 设计要求（定稿）

### 2.1 可纳入维度

| 维度 key | 搜索栏字段 | 页签形态 |
|----------|------------|----------|
| `status` | `status` | 全部 + 新建 / 未到货 / 到货待检 / 已质检 / 已入库（**6 格**；与下拉一致） |
| `stockInType` | `stockInType` | 全部 + 采购 / 报关 / 退货 / 报废 |

**不含**「地域 domestic/overseas」；若后续需要须先加搜索下拉再谈页签。

### 2.2 交互与视觉

遵循 UI 规范 §10：齿轮菜单、单维度、贴合表顶、亮色未选中 `#E8EDF5`、暗色 `var(--crm-layer-1)`。

默认 **off**（仅下拉）；偏好写入 localStorage。

### 2.3 与左栏 preset 并存

遵循 [列表搜索栏规范 §10.3](../../PRD/规范/UI规范/列表搜索栏规范.md)：`preset` 激活且带 `status` / `stockInType` 时，隐藏对应页签条与齿轮子项；清除 preset 后恢复 localStorage 页签偏好。详见 [左栏检索 §5](./到货通知列表-左栏检索-设计与实现.md#5-与主栏页签模式互斥)。

## 3. 实现方法

| 文件 | 职责 |
|------|------|
| `CRM.Web/src/utils/arrivalNoticeListTabMode.ts` | 维度、localStorage、`tab↔filter` |
| `CRM.Web/src/views/Logistics/ArrivalNoticeList.vue` | 菜单、页签条、按维度隐藏下拉 |
| `zh-CN.ts` / `en-US.ts` | `settingsMenu.*`、`filterTabs.all` |

**localStorage：** `crm.arrival-notice-list.tab-mode` = `off` \| `status` \| `stockInType`。

**无需改后端**：同一套列表 query（`status`、`stockInType`）；点页签走现有 `loadData` → 拉列表。
