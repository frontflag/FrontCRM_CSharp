## 1. 业务定位

| 概念 | 说明 |
|------|------|
| **目标** | 以本条出库明细为当前节点，展示上下游 **七站**（v1 不含发票） |
| **页签** | 默认 **流程** `r-flow`；并列「客户」、帮助（无「操作」） |
| **数据粒度** | 一条 `stock_out_item`（`stockOutItemId`） |
| **只读** | 无动作按钮；单号可跳转 |

视觉对齐出库通知 / 库存明细流程。当前站为 **出库**。

---

## 2. 站序与绑定

```
销售明细 → 出库通知 → 库存明细 → 装箱 → 出库 ☜ → 应收款 → 收款核销
```

### 2.1 物流五站（原有）

以 `stock_out_item` 为锚向上游收口，**不**扩到整张销售明细（见 2026-09-01 版 §2）。

### 2.2 应收款站

| 项 | 规则 |
|----|------|
| **绑定键** | 本行解析出的 `stock_out_id` + `sell_order_item_id` → `finance_receivable` |
| **粒度** | **出库单 + 销售行**（非出库明细 ID）；同一出库单、同一销售行下多条出库明细 **共享一条应收** |
| **展示** | 应收单号、核销状态、应收金额·币别、**待核销金额·币别**（`verified_to_be`）、出库日期、客户 |
| **多明细说明** | 当关联出库明细条数 **> 1** 时，卡片展示「本次应收包含 {N} 条出库明细」 |
| **明细单号列表** | 列出该应收对应的 **全部** `stock_out_item_code`（可跳转出库明细列表 `?highlight=`） |
| **跳转** | 应收单号 → `FinanceReceivableDetail` |
| **空站** | 无销售行、非销售出库、无应收（含零价未生成） |

### 2.3 收款核销站

| 项 | 规则 |
|----|------|
| **绑定** | 上述应收在本出库单下的 `finance_receivable_write_off` 流水（按销售行查台账后按 `stock_out_id` 过滤） |
| **站名** | **收款核销**（与全系统菜单、销售明细流程一致） |
| **卡片** | 收款单号（优先）、状态「已核销」、核销金额·币别、创建日期、操作人、客户 |
| **跳转** | 收款单号 → `FinanceReceiptDetail` |
| **v1 不含** | 销项发票 / 票↔应收匹配站 |

## 3. 交互与权限

同 2026-09-01 版 §3。511/521 仍加载聚合；财务金额与客户字段按 521 显示 `—`。应收数据另经 `CanAccessFinanceReceivableAsync` 过滤；无权限则不返回财务两站数据。
