## 1. 业务定位

| 概念 | 说明 |
|------|------|
| **筛什么** | 库存层 `stock_item."Type"`（参数名 `stockType`）：1=客单库存、2=备货库存、3=样品库存 |
| **不是** | 入库单头 `stock_in.StockInType`（采购入库 / 报关入库等，参数名 `stockInType`，见 [入库类型筛选](./库存明细列表-入库类型筛选-设计与实现.md)） |
| **控件** | 搜索栏 `el-select`，占位「库存类型」，`clearable`，变更即查 |
| **位置** | 搜索栏：「是否有库存」之后、「入库类型」之前 |
| **页签模式** | **纳入**（齿轮「页签模式」可选本字段；开启后下拉隐藏，页签：全部 + 三档）。详见 [筛选页签模式](./库存明细列表-筛选页签模式-设计与实现.md) |
| **表格列** | **本版不加列。** 备货行仍在库存明细编号旁显示箱子图标（tooltip「备货库存」） |

备货采购入库过账后，层类型为备货（`StockInventoryTypeCodes.Stocking = 2`），与采购订单头类型一致。

---

## 2. 选项与匹配

| 界面 | 请求 `stockType` | 库内匹配 |
|------|------------------|---------|
| 清空 / 不传 | 不传 | 不过滤 |
| 客单库存 | `1` | `stock_item."Type" = 1` |
| 备货库存 | `2` | `= 2` |
| 样品库存 | `3` | `= 3` |

非法值后端忽略，不过滤。与「入库类型」「是否有库存」等条件 **AND**。

URL `?stockType=2`（看板下钻、手工打开）进入本页时，下拉选中对应项。导出走同一套 query。

文案复用 `inventoryList.stockTypes`（客单库存 / 备货库存 / 样品库存），与库存中心、库存桶一致。
