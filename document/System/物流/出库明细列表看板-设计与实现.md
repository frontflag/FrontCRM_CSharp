## 1. 业务定位

在出库明细列表内切换统计看板。统计范围 = **当前搜索栏筛选结果全量**（含页签模式），不是当前页，也不是物流分析透镜。

金额统一为 **出库金额**（销售单价 × 出库数量），不用成单/订单额。

---

## 2. 交互

| 项 | 行为 |
| --- | --- |
| 入口 | 搜索栏「查询 / 重置」后、「列表筛选设置」齿轮前 |
| 默认 | 列表 |
| 看板态 | 隐藏表格、分页、标题「共 N 条」；筛选与页签仍可用 |
| 帮助 | 看板态覆盖为出库明细看板说明 |

---

## 3. 口径摘要

| 指标 | 口径 |
| --- | --- |
| 出库金额 | `出库数量 × 销售单价`；美金：`SalesPriceUsd` → `convert_price × 数量` → 查询日汇率 |
| 出库数量 | `ActualQty > 0 ? ActualQty : Quantity` |
| 出库客户数 | 头表客户去重；空客户不计 |
| 趋势 | 出库日；条目数 + 折算美金；天/周/月 |
| 分布 | 出库类型（1 与 10 合并销售）、业务员 |
| 排名 | Top10 客户、Top10 业务员（折算美金） |

无销售金额权限或 521 时金额脱敏，饼图/排名改按行数。
