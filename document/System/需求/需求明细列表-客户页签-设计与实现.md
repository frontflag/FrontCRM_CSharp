## 1. 业务定位

在需求相关页面右栏查看 **当前单据所属客户档案**（现读主数据），便于对照客户概况而不离开当前页。

| 要做 | 不做 |
|------|------|
| 页签 `r-customer`，插在帮助前 | 进来默认停在客户 |
| 三块卡片：客户概况（编号橙色主标题）；基本信息 / 财务信息（标签：值） | 编辑客户、调查报告 |
| 有权限：编号与名称链到客户详情 | 无权限时链到详情（避免绕过） |
| 服务端按单据主键解析客户 | 信任前端传入的 `customerId`（521 会抹掉行上 id） |

| 页面 | 绑定 | 页签顺序 | 默认 |
|------|------|----------|------|
| `/rfq-items` | 单击明细行 → 所属需求的客户 | 物料 → 客户 → 帮助 | 物料 |
| `/rfqlist` | 单击需求行 | 客户 → 帮助 | 帮助 |
| `/rfqs/:id` | 进页按单头绑定（不跟明细行） | 客户 → 帮助 | 帮助 |

列表单击行 **不** 自动切到「客户」。详情进页即绑单头；回收站只读详情不绑。

## 2. 权限

完整面板 = **能打开该客户详情** 且 **非 521 采购脱敏**：

- 具备 `customer.read`（系统管理员视为具备）
- `CanAccessCustomer` 对该客户为真
- `SaleSensitiveFieldMask521` 为假（采购方向 + SaleDataScope=4 **永远受限**）

否则只展示 **客户编号、业务员**（业务员取 **客户档案** `SalesUserId`，不是需求单业务员）。编号为纯文本。基本信息、财务信息整块不渲染，接口也不下发这些字段与 `customerId`。

网关不要求 `customer.read`。`source=rfq` / `rfqItem` 须能读该需求（`rfq.read` 或等价 bypass，且 `CanAccessRFQ`）。

## 3. 字段口径

现读 `customerinfo`（及档案业务员登录名）。

| 面板 | 字段 | 来源 |
|------|------|------|
| 客户概况 | 客户编号 | `CustomerCode` |
| | 中文名称 | `OfficialName`，空则 `StandardOfficialName` |
| | 英文名称 | `EnglishOfficialName` |
| | 业务员 | 档案 `SalesUserId` → 登录名 |
| 基本信息 | 类型 / 等级 / 行业 | `Type` / `CustomerLevel` / `Industry` + 客户字典 |
| | 地区 | 主表 `Province` + `City`（`Region`） |
| 财务信息 | 信用额度 | `CreditLine`，金额格式与客户详情相同 |
| | 账期 | `Payment`（天） |
| | 结算币别 | `TradeCurrency`（ISO） |
| | 税率 / 发票类型 | 与客户编辑同源；主表未落库时展示 — |

无关联客户或档案已删：空态「该单据未关联客户档案」。

## 4. 交互

- 右栏展开且当前为「客户」才请求（在「帮助」「物料」下单击不拉客户）。
- 切到「客户」或收起后再展开且已在该页签：有选中单据则加载。
- 列表搜索 / 重置 / 刷新：清空右栏选中。
- 有完整权限时 **三块** 卡片：概况（编号橙色主标题、无字段标签）+ 基本信息 + 财务信息（标签：值）。卡片背景用工作台 embedded 层（`$layer-3`）。

---

## 5. 接口

`GET /api/v1/customer-workspace?source=&id=`

本批 `source`：`rfq`（需求主键）、`rfqItem`（需求明细主键）。服务端从需求主表取 `CustomerId`，再按 §2 裁剪 DTO。销售来源见销售设计文档。

单据不存在 → 404；无权访问单据 → 403；未知 source → 400。

已删除 `GET /api/v1/rfqs/items/{itemId}/customer-workspace`。
