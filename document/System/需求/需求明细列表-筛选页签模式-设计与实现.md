## 1. 业务定位

将搜索栏中适合做成单选桶的下拉，可选转为表格/看板上方全宽页签条。**单维度**；关闭页签不清筛选值；点页签立即查询。

文本框、日期范围、业务员/采购员动态下拉、「有报价」复选框不纳入。

左栏 shortcut preset 见 [左栏检索-设计与实现](./需求明细列表-左栏检索-设计与实现.md)：preset 激活时隐藏明细状态下拉与本页签条（及「页签模式」菜单中的明细状态项）。

---

## 2. 设计要求（定稿）

### 2.1 可纳入维度

| 维度 key | 搜索栏字段 | 页签形态 |
|----------|------------|----------|
| `itemStatus` | `itemStatus`（API/看板侧为 `status`） | 全部 + 待报价 / 已报价 / 查无报价 / 已接受 / 已拒绝 / 已关闭（共 **7** 格，与下拉一一对应） |

选项值：`0 | 1 | 2 | 3 | 4 | 5`；「全部」清空该字段（`undefined`）。

> 页签数多于 UI 规范 §10.1「约 2～4 档」建议值；产品已确认等分 7 格可接受，且仍满足「与下拉选项一一对应」。

### 2.2 交互与视觉

遵循 [列表搜索栏规范 §10](../../PRD/规范/UI规范/列表搜索栏规范.md)：

| 项 | 规则 |
|----|------|
| 入口 | 看板按钮旁齿轮 →「关闭页签」+「页签模式 ▸」（仅「明细状态」一项） |
| 开启 | 隐藏明细状态下拉；页签条出现在表格/看板上方 |
| 关闭 | 恢复下拉；筛选值保留 |
| 点页签 | 写入 `searchForm.itemStatus` 后立即 `handleSearch()` |
| 菜单范围 | 与销售一致，**只**放「页签模式」，不预留其它列表偏好 |

亮色未选中 `#E8EDF5`；暗色 `var(--crm-layer-1)`。

### 2.3 不做的范围（本版）

- 业务员 / 采购员 / 「有报价」做成页签
- 多维度同时开多条页签条

## 3. 实现方法

| 文件 | 职责 |
|------|------|
| `CRM.Web/src/utils/rfqItemListTabMode.ts` | 维度枚举、localStorage、`tab↔filter` |
| `CRM.Web/src/views/RFQ/RFQItemList.vue` | 齿轮菜单、页签条、按维度隐藏下拉 |
| `zh-CN.ts` / `en-US.ts` | `rfqItemList.settingsMenu.*`、`filterTabs.all`、`filters.itemStatus` |

**localStorage：** `crm.rfq-item-list.tab-mode` = `off` \| `itemStatus`。

**无需改后端**：同一套 query（`itemStatus`）与看板 `status` 映射。
