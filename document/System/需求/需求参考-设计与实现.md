# 需求参考 — 设计与实现

**状态：** MVP  
**页面：** `/rfq-item-reference`（路由名 `RFQItemReference`），菜单名「需求参考」  
**不改作业行为：** `/rfq-items`、`/rfq`、`/quotes`、`/quote-desktop` 默认接口与权限口径不变  
**无 DDL、无新权限码：** 入口复用 `rfq.read` + 销售/采购身份（见 §2.1）  
**测试对照：** [需求参考-测试对照说明](../../QA/需求/需求参考-测试对照说明.md)  
**用户帮助：** `help/pages/需求参考_MENU_RFQ_ITEM_REFERENCE.md`  
**关联：** [数据权限-业务员客户与采购员供应商](../权限/数据权限-业务员客户与采购员供应商.md)、[需求保护时长](../需求保护时长-设计与实现.md)、PRD §5.1.1（511 采购脱敏）/ §5.2.1（521 销售脱敏）

废弃方案（在作业页放宽行集合）见 [需求明细列表-业务员全局可见](./需求明细列表-业务员全局可见-设计与实现.md)，勿按该稿实现。

## 1. 产品目标

销售/采购要对着**全公司需求明细**对照别人已经问到的**采购报价单价**，同时：

- 不能在本页做作业（报价、查无报价、生成销售订单、进详情等）；
- 销售不能随意看到他人客户名称；
- 本页一律不展示供应商名称（等级、交易次数、单价仍显示）。

---

## 2. 功能要求（定稿）

### 2.1 入口与身份

**所有销售、所有采购（含采购运营）**可见本页；财务、物流、客服等其它身份不出现菜单（系统/平台管理员、业务经理因 bypass 仍可进，便于运维对照）。

| 判定 | 值 |
|------|-----|
| 销售 | 主部门身份类型 = 销售 |
| 采购 | 主部门身份类型 = 采购 |
| 采购运营 | 主部门身份类型 = 采购运营 |
| 兼任兜底 | 属于采购部门（与报价保护池采购侧判定一致） |
| 另需 | 具备需求模块读权限 |
| bypass | 系统管理员 / 平台管理员 / 业务经理 / 业务数据 bypass：可进 |

含一线、经理、总监，**不按组织职级再裁入口**。无需求读权限仍不可进。

**菜单位置：** 侧栏「需求管理」分组最后一项：

1. 需求列表  
2. 需求明细  
3. **需求参考**

当前路由为参考页时，需求管理分组保持展开。面包屑为「需求参考」。

**作业页页头入口（仅 `/rfq-items`）：** 在「进入报价桌面」左侧，同款按钮「需求参考」；有入口身份才显示；点击在**新窗口**打开本页。参考页页头不出现「进入报价桌面」或「需求参考」。

直链无身份：前端回控制台；接口 `reference=true` 返回 403。

### 2.2 行集合（与作业页隔离）

| 规则 | 需求参考 | 需求明细作业页 |
|------|----------|----------------|
| 销售数据范围 | **不裁行**（全公司明细） | 按销售/采购数据范围 |
| 需求保护时长 | **不生效**（保护期内分配给他人的行也出现） | 按现网保护规则 |
| 「仅我可报」 | 强制关闭 | 报价桌面等可开 |

默认 `GET /api/v1/rfqs/items`、`GET /api/v1/quotes` **不加**参考开关时，行为与上线前一致。

### 2.3 客户脱敏（主表）

行全可见。有客户信息读权限时：**仅客户名称 / 客户 Id** 按业务员匹配集合明文；**客户料号、客户品牌不脱敏**（空则显示 `—`）。无客户信息读权限或 521 时：整页无客户名/料号/品牌（与作业页 521 一致）。

| 角色 | 客户名 / 客户 Id |
|------|------------------|
| 一线业务员 | 仅该行业务员 = 自己 |
| 销售部门经理 / 总监 | 组织子树明文集合（`GetAllowedUserIds(includeChildren: true)`，与现网组织数据范围一致：经理不含同级经理；总监含子树经理和员工） |
| 采购 / 采购运营 / 兼任采购 | 521 则整页无客户；否则**不**按业务员再打码 |
| 系统管理员 / 业务数据 bypass | 不按业务员打码 |

空业务员 → 客户名打码。接口抹掉不可见行的客户 Id/名称，不要只藏 DOM。

**客户名称搜索**只命中可明文客户，不能靠关键字把打码行翻出来。  
**物料关键字**可按本司型号或客户料号命中全部可见行（在可见客户信息的前提下）。

本页无客户页签、无客户跳转。

### 2.4 供应商脱敏（报价码头）

列与作业页采购报价面板**完全一致**。唯一差异：

| 字段 | 作业页 | 需求参考 |
|------|--------|----------|
| 供应商名称 | 销售 511 时隐藏；采购可见 | **一律 `—`**（销售、采购都如此；接口抹名称/编码/ID，列仍在） |
| 供应商等级、交易次数、询价单价及其它列 | 现网规则 | **仍显示**；无供应商 ID 时交易次数仍按次数字段展示 |

已删报价里的供应商列同样打码。复制到剪贴板不得带出供应商名称。

### 2.5 只读、允许复制、禁止跳转

操作列**仅「复制」**（主表与报价码头相同语义：把当前行摘要写入剪贴板，不新建单据、不跳转）。脱敏字段按已抹掉的 DTO 复制，不会把他人客户名或供应商名拷出去。单元格纯文本仍可用浏览器选中复制。

本页所有编号、名称均为**纯文本**，不可点进其它页。包括但不限于：需求编号、客户、报价编号、供应商、物料型号；双击 / Ctrl+双击不进详情或编辑。

禁止的作业入口：报价、查无报价、编辑/删除报价、生成销售订单、复选篮子、看板、左栏检索、右栏客户/物料、进入报价桌面。

### 2.6 页面结构与搜索

- 上：需求明细只读表；下：采购报价码头（点一行看该明细报价）。未选行时码头提示先点一行。
- 筛选可保留：日期、需求编号、型号、品牌、状态、业务员、采购员、有报价等。
- 搜索栏**无**看板切换、**无**「列表筛选设置」（齿轮）、**无**表格上方筛选页签；状态等筛选始终用下拉（即使本机作业页开过页签模式）。
- 查询 / 重置后仍停在本页（不得误跳需求明细）。
- 上下分栏比例、列宽可调；列设置与作业页**分 key 存储**，互不覆盖。
- 右栏仅「帮助」；无左栏。

### 2.7 明确不做

- 不改作业页行集合、保护规则、511/521 作业口径。
- 不把参考开关做成默认列表行为（必须显式 `reference=true`）。
- 本页不做页签模式、篮子、看板、右栏客户/物料。

## 3. 实现方法

### 3.1 总体策略

独立路由，**与作业页共用** `RFQItemList.vue`，以 `route.name === 'RFQItemReference'`（`isRfqItemReference`）切换只读模式。后端用查询参数 `reference=true`（请求标志 `ForRfqItemReference`）跳过作业页数据范围并做脱敏；无该参数则走原逻辑。

### 3.2 入口与守卫

| 层 | 做法 |
|----|------|
| 规则 | `CRM.Core/Utilities/RfqItemReferenceAccessRules.cs`：`CanEnterPage` / `NeedsSalespersonCustomerMask` / `CanRevealCustomerOnRow` |
| 前端镜像 | `CRM.Web/src/utils/rfqItemReferenceAccess.ts` → `canAccessRfqItemReference`（另需 `rfq.read`） |
| 路由 | `routes.ts`：`path: rfq-item-reference`，`meta.permission = rfq.read`，`meta.rfqItemReferenceAccess = true` |
| 守卫 | `router/index.ts`：无身份则 `/dashboard` |
| 菜单 | `AppLayout.vue`：`showRfqItemReferenceMenu`；参考页展开 `openGroups.rfqs`；右栏仅帮助 |
| 埋点页名 | `TelemetryCatalog`：`/rfq-item-reference` → 「需求参考」 |

### 3.3 API 开关 `reference=true`

仅下列接口认该参数；其它 RFQ/报价接口不变。

| 接口 | 参考开关效果 |
|------|----------------|
| `GET /api/v1/rfqs/items?reference=true` | 须能进页，否则 403；跳过销售/采购裁行与需求保护；强制关闭「仅我可报」；销售按 §2.3 抹客户身份 |
| `GET /api/v1/quotes?rfqItemId=…&reference=true` | 须能进页；**必须带** `rfqItemId` 否则 400；跳过报价列表数据范围；响应抹供应商身份（`ApplyQuotesVendorIdentityOnly`）；521 仍按销售脱敏 |
| `GET /api/v1/quotes/aggregate/quote-counts-by-rfq-item-ids?reference=true` | 跳过报价列表数据范围，他人明细条数与实有报价一致 |
| `GET /api/v1/rfqs/items/{itemId}/deleted-quotes?reference=true` | `GetItemByIdAsync(..., skipRfqDataScope: true)`；抹已删报价 `VendorName` |

控制器入口校验：`ForbidRfqItemReferenceIfNeededAsync`（`RFQsController` / `QuotesController`）。

前端：`rfqApi.searchRFQItems({ reference: true })`、`quoteApi.getList` / `getQuoteCountsByRfqItemIds`、`getDeletedQuotesForItem` 仅在参考页传该标志。

### 3.4 列表筛选与客户搜索

`RfqItemListFilter`：`ForRfqItemReference` 时若不能进页则空结果；能进则**不走**作业页 `SaleDataScope` / `PurchaseDataScope` / 需求保护。销售需打码时：客户关键字额外限制在明文业务员集合内。

`RFQService.GetPagedItemsAsync`：521 / 无客户信息读权限 → `MaskRfqItemListRowCustomerFields`（含料号/品牌）；参考页且销售打码 → 仅 `MaskRfqItemListRowCustomerIdentityFields`（保留料号/品牌）。

### 3.5 报价码头展示

- 列定义与作业页同一套；`maskPurchaseSensitiveFields` 在参考页恒为真（供应商名称走 `quoteVendorNamesDisplay(..., masked)`）。
- `quoteVendorTradeCountsDisplay`：无供应商 ID 时仍显示 `vendorTradeCount`（避免打码后次数变成 `—`）。
- 参考页不拉作业页联动详情（避免无范围的明细详情 403），码头摘要用当前行字段拼。
- 不绑定物料情报 / 操作面板行点击。

### 3.6 前端只读开关（`RFQItemList.vue`）

| 项 | 参考页 |
|----|--------|
| 标题 | 「需求参考」，页标「参」 |
| 页头 | 无报价桌面 / 需求参考按钮 |
| 搜索栏 | 无看板、无齿轮、无页签条；状态下拉始终显示 |
| 主表 | 无复选列、无篮子；操作仅复制；单元格不跳转 |
| 列布局 key | `rfq-item-list-reference-main` / `rfq-item-list-reference-dock-quotes` |
| 查询路由名 | `RFQItemReference`（查询/重置不跳到 `RFQItemList`） |
| 右栏 | 仅帮助（`AppLayout`） |
