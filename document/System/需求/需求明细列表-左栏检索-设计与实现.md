## 1. 业务定位

左栏提供 **preset 快捷检索**，用于主栏不适合直接表达的业务视角条件；与主栏 keyword、看板 **共用 URL query**。

| 概念 | 说明 |
|------|------|
| **preset 单选** | 四组共 18 项；再点同一项或主栏 chip ✕ → **清空全部 query（含 keyword）** |
| **keyword 叠加** | 需求编号、客户、型号、业务员、采购员可与 preset 同时生效 |
| **主栏隐藏** | 有 preset 时隐藏：创建日期、明细状态下拉、「有报价」；明细状态页签条一并隐藏 |
| **看板一致** | 列表与看板共用同一套 filter / `quickFilter` / 时间窗参数 |

## 2. preset 列表（定稿）

### 2.1 需求（明细创建时间）

锚点：**需求明细行 `RFQItem.CreateTime`**（非主单创建时间）。

| preset ID | 含义 | API |
|-----------|------|-----|
| `item_last_10m` | 10 分钟内需求 | `itemCreateStart` / `itemCreateEndExclusive`（前端展开为绝对 UTC ISO） |
| `item_last_30m` | 30 分钟内需求 | 同上 |
| `item_last_1h` | 1 小时内需求 | 同上 |
| `item_today` | 今日需求 | 本地今日 0 点～次日 0 点（UTC 瞬刻） |
| `item_today_yesterday` | 今昨需求 | 昨日 0 点～明日 0 点 |
| `item_last_3_days` | 3 天内需求 | 含今日共 3 个本地日历日 |
| `item_last_7_days` | 1 周内需求 | 含今日共 7 个本地日历日 |

时间类 **不写** `quickFilter`；亦不写主栏用的 `startDate`/`endDate`（主栏日期仍表示 **主单** 创建日，与本组互斥隐藏）。

### 2.2 需求状态（`quickFilter`）

| preset ID | 含义 | 判定 |
|-----------|------|------|
| `important` | 重要需求 | 主表 `Importance == 3`（界面三星选中时的存盘值） |
| `converted` | 成单需求 | **等同看板成单明细**：存在未删除 SO 明细 `status=0`，经 `quote` 回挂本 `rfqitem`，且 `sellorder.status >= 10` |

### 2.3 报价（报价创建时间）

锚点：存在至少一条关联报价，其 `Quote.CreateTime` 落在窗口内（软删报价由全局过滤排除）。

| preset ID | 含义 | API |
|-----------|------|-----|
| `quote_last_10m` … `quote_last_7_days` | 与需求组对称的 7 档 | `quoteCreateStart` / `quoteCreateEndExclusive` |

### 2.4 报价状态（`quickFilter`）

| preset ID | 含义 | 判定 |
|-----------|------|------|
| `no_quote` | 查无报价 | `rfqitem.status == 5`（左栏保留；preset 时隐藏状态下拉与页签） |
| `multi_quote` | 多条报价 | 关联报价条数 **≥ 2** |

## 3. 实现方法

### 3.1 文件

| 文件 | 职责 |
|------|------|
| `CRM.Core/Constants/RfqItemListQuickFilterCodes.cs` | 业务码 + `IsKnown` |
| `CRM.Core/Interfaces/IRFQService.cs`（`RFQItemQueryRequest`） | 时间窗 + `QuickFilter` |
| `CRM.Infrastructure/RFQ/RfqItemListFilter.cs` + `.QuickFilter.cs` | 筛选 |
| `CRM.API/Controllers/RFQsController.cs` | 列表与 analytics 绑定 |
| `CRM.Web/src/utils/rfqItemListPreset.ts` | preset ID、时间展开、URL |
| `CRM.Web/src/components/RFQ/RFQItemSearchPanel.vue` | 左栏四组按钮 |
| `CRM.Web/src/views/RFQ/RFQItemList.vue` | chip、隐藏项、query 同步 |

### 3.2 URL query

- `preset`：当前选中 ID  
- 时间类：`itemCreateStart`/`itemCreateEndExclusive` 或 `quoteCreate*`  
- 业务类：`quickFilter`（与 preset ID 相同）  
- keyword：`rfqCode`、`customerKeyword`、`materialModel`、`salesUserId`、`purchaserUserId`

**已知 `quickFilter` 时**：后端忽略手动 `status` / `hasQuotesOnly`（与 SO 进度互斥同理）。

### 3.3 与页签模式

preset 激活 → **隐藏**明细状态页签条；「页签模式」子菜单中「明细状态」项亦可隐藏。清除 preset 后按偏好恢复。
