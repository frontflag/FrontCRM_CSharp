## 1. 业务定位

业务岗在 **需求详情**、**需求明细** 按行查看「本行曾有报价被删除」：报价单号、物料型号、品牌、生产日期、交期、供应商、供应商等级、报价数量、报价价格、币别、报价员、创建日期、删除人、删除时间。

| 要做 | 不做 |
|------|------|
| 记录贴在**那一行**上，点开只看该行 | 整单「已删报价」总表（本版不做） |
| 身份用稳定 **行号 + 物料型号 + 品牌** | 用详情表 `#` 当前序号当历史定位 |
| 系统操作日志仍可筛业务类型「报价」、动作「报价单删除」 | 混入需求「更改日志」页签 |

权限与查看该需求相同（读需求 + 数据范围）。

## 2. 数据口径

- **来源：** 软删报价（`quote.is_deleted`）按 `rfq_item_id` 挂到需求明细；删除人/时间优先取 `log_operation`（`BizType=报价`，`ActionType=报价单删除`），否则回退报价 `ModifyTime`。供应商/单价/币别/生产日期/交期/数量来自该报价下 `quoteitem`（含已随单软删的行，阶梯多行换行对齐）；物料型号与品牌优先报价明细去重，缺省回退需求明细/报价头；供应商等级按 `quoteitem.vendor_id` 现读 `vendorinfo.Level`，展示 S/A/B/C（无 ID 则空）；创建日期取报价 `CreateTime`；报价员取采购员登录名，缺省回退创建人。
- **需求明细底部：** 无已删记录时不展示该块；有记录时默认折叠，标题为「已删报价 {n} 条」，点击标题展开/折叠。本面板删除报价成功后自动展开。换选明细行回到折叠。
- **列表左栏：** `/rfq-items` 检索 → 报价状态 → **有删报价**（`has_deleted_quote`）按同一命中筛主列表与看板，见 [需求明细列表-左栏检索](./需求明细列表-左栏检索-设计与实现.md) §2.4。
- **删除写入：** `QuoteService.DeleteAsync` 记操作日志，`ExtraInfo` 含 `rfqItemId` / `lineNo` / `mpn` / `brand`。历史删除即使无 ExtraInfo，只要报价仍挂着明细 ID 也能对上。
- **成单报价不可删**（与报价列表一致）；已删记录只读展示。

## 3. API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/rfqs/{id}/deleted-quotes` | 本需求全部现行明细上的已删报价 |
| GET | `/api/v1/rfqs/items/{itemId}/deleted-quotes` | 指定明细行 |

实现：`RFQsController` → `IQuoteService.GetDeletedQuotesByRfqItemIdsAsync`。

## 4. 前端

| 页面 | 展示 |
|------|------|
| 需求详情明细列表 / 卡片 | 操作列前（卡片挂在「明细 n」旁）「已删报价 n」；无记录显示 —；弹窗标题带行号、型号、品牌 |
| 需求明细底部采购报价 | 无已删记录时不展示；有记录时标题「已删报价 {n} 条」默认折叠，展开后见表（含供应商等级及物料/交期/数量/创建日期）；删除报价成功后自动展开并刷新 |

## 5. 不在本版
