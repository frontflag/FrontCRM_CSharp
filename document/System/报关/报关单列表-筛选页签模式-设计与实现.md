## 1. 业务定位

将搜索栏中适合做成单选桶的下拉，可选转为表格上方全宽页签条。**单维度**；关闭页签不清筛选值；点页签立即查询。

文本、申报日期不纳入。首版**只做页签模式**；本页既有下拉/日期 `@change` 即查行为**保持不变**，不另改正日期控件形态。

---

## 2. 设计要求（定稿）

### 2.1 可纳入维度

| 维度 key | 搜索栏字段 | 页签形态 |
|----------|------------|----------|
| `internalStatus` | `internalStatus` | 全部 + 待处理 / 报关中 / 已完成 / **作废**（5 格，与下拉一致） |
| `declarationType` | `declarationType` | 全部 + 进口 / 出口 |
| `customsClearanceStatus` | `customsClearanceStatus` | 全部 + 未维护 / 放行 / 已结关（含 `0`） |

### 2.2 交互与视觉

遵循 UI 规范 §10：齿轮菜单、单维度、贴合表顶、亮色未选中 `#E8EDF5`、暗色 `var(--crm-layer-1)`。

## 3. 实现方法

| 文件 | 职责 |
|------|------|
| `CRM.Web/src/utils/customsDeclarationListTabMode.ts` | 维度、localStorage、`tab↔filter` |
| `CRM.Web/src/views/Customs/CustomsDeclarationList.vue` | 菜单、页签条、按维度隐藏下拉 |

**localStorage：** `crm.customs-declaration-list.tab-mode` = `off` \| `internalStatus` \| `declarationType` \| `customsClearanceStatus`。

**无需改后端**：同一套 `fetchCustomsDeclarations` 查询参数。
