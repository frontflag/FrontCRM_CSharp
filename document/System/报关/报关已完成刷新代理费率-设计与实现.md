## 1. 目标

已结关锁定或内部已完成的报关单，历史代理费率快照可能与报关公司主数据不一致。管理员可将本单费率刷新为报关公司当前 `agency_rate`，全单重算，并回写到货通知、报关入库与在库采购价（P1）。动作与新旧费率写入变更日志。

---

## 2. 规则

| 项 | 约定 |
|----|------|
| 入口 | 费用头「代理费率」旁 **刷新自报关公司** |
| 权限 | 仅 SYS_ADMIN / SYS_MANAGER（`CanForceDelete` / `canCorrectLockedCostUsd`） |
| 单据状态 | 费用已锁定或内部已完成；作废不可 |
| 费率来源 | 本单绑定报关公司主数据 `agency_rate`（须 ≥ 1） |
| 下游 | 强制 `CascadeDeclarationItemAsync`（与采购美金价更正相同） |
| 与普通保存 | 锁定/已完成下改价或补杂费再保存仍 **保留** 代理费率快照；仅本按钮刷新费率 |
| 未保存草稿 | 有未保存费用/备注草稿时先提示保存或放弃，不直接刷新 |
| 日志 | 必写 `refreshAgencyRateFromBroker`（旧/新费率，即使相同也写）；清除手工标记时另写 `agencyRateManual` |

---

## 3. 实现要点

- `RecalculateDeclarationFeesAsync(..., refreshAgencyRateFromBroker: true)`：关闭 `preserveAgency`，强制 `cascadeInbound`。
- `POST /api/v1/customs-declarations/{id}/recalculate-fees` body：`refreshAgencyRateFromBroker`。
- 前端确认框展示本单当前费率 → 公司当前费率。

---

## 4. 操作提示

打开已完成或已结关报关单详情 → 报关费用 → 管理员点 **刷新自报关公司** → 确认 → 查看价税变化、下游回写提示与 **变更日志**。
