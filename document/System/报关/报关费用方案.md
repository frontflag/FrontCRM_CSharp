## 1. 目标与边界

### 1.1 目标

| 目标 | 说明 |
|------|------|
| 公式与 EBS 一致 | 货款 → 关税 → 增值税 → 代理费 → 价税总额 → 含税单价 |
| 报关汇率关务手工 | 报关单头 `exchange_rate` 手工填写、可修改（不对财务汇率自动锁定） |
| 采购系数全局配置 | `purchase_cost_param` 按生效时间取数；未配置不可试算 |
| 入库前校验 | 明细未维护关税税率 / 未完成费用试算 → 不可进入报关入库链 |
| 境内成本正确 | 报关入库 `PurchasePrice` = P1，经系数与价税链形成到岸含税单价 |
| Hub 在报关详情 | 「报关费用」面板：编辑汇率、税率、杂费，试算与汇总 |

### 1.2 与 EBS 的差异（仅此几项）

| 项 | EBS | FrontCRM V2 |
|----|-----|-------------|
| 报关公司 | `CustomsDef` = 客户/供应商 | 独立表 `customs_broker` |
| 代理费率 | 客户主数据上的报关费率 | `customs_broker.agency_rate`（存 **1+费率**，如 1.03） |
| 境内入账 | 移库一步过账 + 虚拟出/入 | 到货通知 → 质检 → 报关入库（`StockInType=20`） |
| 汇率初始值 | 纯手工 | 可 **建议** 填财务当前 USD/CNY，但不锁定 |

其余（费用名目、公式、采购系数、价税总额不含商检、货款基数等）**与 EBS 对齐**。

## 2. 业务流程与费用节点

```text
装箱确认 → 生成报关单（头：汇率待填/可预填；行：费用=0）
    ↓
拣货回写 → 写入 P0、采购币别、源在库行
    ↓
关务维护「报关费用」面板 → 汇率、HS、关税税率、杂费/商检 → 【试算/保存】
    ↓
海关状态 → 已结关
    ↓
【校验费用完整】→ 生成报关到货通知
    ↓
确认到货 → 质检 → 报关入库过账
    ↓
OnCustomsStockInCompleted → stock_item.PurchasePrice = P1
```

**费用试算触发点**（对齐 EBS `GetData` / `Save` / 拉明细）：

1. 关务点击「试算费用」或「保存费用」
2. 修改头汇率、报关公司（代理费率变化）后重算
3. 修改行关税税率 / 杂费 / 商检费后重算（杂费/商检不参与代理费基数，仅汇总）
4. **不在**装箱确认时强制试算（此时尚无 P0）

## 3. 主数据

### 3.1 采购系数 `purchase_cost_param`（EBS §3.2）

| 列 | 类型 | 说明 |
|----|------|------|
| `id` | varchar(36) | PK |
| `ratio` | numeric(10,4) | 乘数，>0；1.0000 = 不变 |
| `start_time` | timestamptz | 生效开始时间 |
| `remark` | varchar(500) | 变更说明 |
| `is_deleted` | bool | 软删 |

**取数**：`start_time <= asOf`，按 `start_time DESC, create_time DESC` 取第一条；**无记录 → 报错「未配置采购系数！」**

**管理**：系统设置 / 财务参数区；推荐 `purchase_cost_param_change_log` 变更日志。

### 3.2 报关公司 `customs_broker`（扩展）

| 列 | 类型 | 说明 |
|----|------|------|
| `agency_rate` | numeric(10,6) NOT NULL DEFAULT 1 | **1+纯费率**，如 1.030000；代理费 = 基数 × `(agency_rate - 1)` |

选报关公司时带入试算；保存时在报关单头快照 `broker_agency_rate`。

### 3.3 增值税率

| 方案 | 说明 |
|------|------|
| 一期 | 明细 `vat_rate` 默认 **0.13**，可手工改 |
| 二期 | 可选接系统参数 / 税率主数据（对标 EBS `VATRateId`） |

### 3.4 财务汇率（仅作建议值）

- 编辑报关汇率时，UI 提供「采用当前财务 USD/CNY」快捷按钮
- 不参与自动锁定；以 `customs_declaration.exchange_rate` 为准

## 4. 数据模型

### 4.1 报关单头 `customs_declaration`

| 列 | 变更 | 说明 |
|----|------|------|
| `exchange_rate` | 语义变更 | 关务手工；生成时可预填建议值，**始终可 PATCH** |
| `broker_agency_rate` | 新增 | 试算/保存时快照 `customs_broker.agency_rate` |
| `total_tax_amount` | 保留 | Σ `item.total_value_tax` |
| `fees_calculated_at` | 新增 nullable | 最后一次成功试算时间 |
| `fees_locked` | 新增 bool default false | 可选：结关后锁定自动项 |

**移除行为**：装箱确认时 **不再**写死 `ExchangeRate = 财务 UsdToCny`。

### 4.2 报关明细 `customs_declaration_item`

**已有**：`original_purchase_price`（P0）、各费用金额、`declare_unit_price`、`tax_included_unit_price`

**新增**：

| 列 | 类型 | 说明 | EBS 对应 |
|----|------|------|----------|
| `purchase_cost_param_id` | varchar(36) | 试算时系数配置 Id | `PurchaseCostParamId` |
| `purchase_ratio` | numeric(10,4) | 系数快照 | `Ratio` |
| `purchase_currency` | smallint | 采购币别快照 | `Currency` |
| `cost_usd` | numeric(18,6) | 采购美金价（含系数） | `CostUSD` |
| `duty_rate` | numeric(18,6) | 关税税率 | `CustomsDutyRate` |
| `vat_rate` | numeric(18,6) | 增值税率，默认 0.13 | `VATRateId` 简化 |
| `customs_usd_price` | numeric(18,6) optional | 报关美金价 | `CustomsUSDPrice`（一期可与 `cost_usd` 相同） |

**P0 / P1 语义**：

| 字段 | 含义 |
|------|------|
| `original_purchase_price` | **P0**：原采购单价（原币，**不含**系数） |
| `cost_usd` | 原币→USD × `purchase_ratio` |
| `tax_included_unit_price` | **P1**：`total_value_tax / declare_qty`（**不含商检**） |
| `declare_unit_price` | 关务申报单价（**不参与**货款公式） |

DDL 增量见《报关 V2 — DDL 与表结构》§16（待 F1 迁移脚本落地）。

## 5. 计算公式（EBS §3.3）

### 5.1 符号

| 符号 | 来源 |
|------|------|
| `cost` | `original_purchase_price`（P0，原币） |
| `costCur` | `purchase_currency` |
| `purchaseRatio` | 当前生效系数 → 快照 `purchase_ratio` |
| `systemFx` | 财务 `GetCurrentAsync()`（**仅** P0→USD，非报关汇率） |
| `exchangeRate` | 报关单头 `exchange_rate`（关务手工） |
| `qty` | `declare_qty` |
| `tariffRate` | `duty_rate` |
| `vatRate` | `vat_rate`（默认 0.13） |
| `customsRate` | 头快照 `broker_agency_rate`（**1+费率**） |

### 5.2 递进公式

```text
① 采购美金价
   cost_usd = UnitLocalToUsd(cost, costCur, systemFx) × purchaseRatio

② 报关公司货款（CNY）
   customs_payment_goods = cost_usd × exchangeRate × qty

③ 关税
   duty_amount = customs_payment_goods × tariffRate

④ 增值税
   vat_amount = (customs_payment_goods + duty_amount) × vatRate

⑤ 报关代理费
   customs_agency_fee = (customs_payment_goods + duty_amount + vat_amount) × (customsRate − 1)

⑥ 杂费 / 商检费
   other_fee、inspection_fee → 关务手工（不参与⑤基数）

⑦ 价税总额（行）— 不含商检
   total_value_tax = customs_payment_goods + duty_amount + vat_amount
                     + customs_agency_fee + other_fee

⑧ 含税单价 P1
   tax_included_unit_price = total_value_tax / qty

⑨ 报关单头
   total_tax_amount = Σ total_value_tax
```

### 5.3 手工 vs 自动

| 字段 | 方式 |
|------|------|
| 货款、关税、增值税、代理费、价税总额、含税单价 | 系统计算 |
| 汇率 | 关务手工（头） |
| 关税税率 | 关务手工（行；入库链必填） |
| 增值税率 | 默认 0.13，可改 |
| 杂费、商检费 | 手工 |
| 采购系数 | 主数据自动；缺失则试算失败 |

**Override**：关务 **不可**直接 PATCH 自动计算项；须改输入项后 **重算**。杂费/商检 PATCH 后仅重算⑦⑧⑨。

## 6. 服务设计

### 6.1 核心服务

| 服务 | 职责 |
|------|------|
| `IPurchaseCostParamService` | 按时间取生效系数；无配置抛「未配置采购系数！」 |
| `ICustomsFeeCalculator` | 实现 §5.2 公式链 |
| `CustomsV2FlowService.RecalculateDeclarationFeesAsync` | 全单试算 + 快照系数/费率 |
| `CustomsV2FlowService.UpdateDeclarationHeaderAsync` | 扩展 PATCH `exchangeRate`、`customsBrokerId` |
| `CustomsV2FlowService.UpdateDeclarationItemAsync` | 收窄：仅输入项 + 触发重算 |

### 6.2 与 EBS 调用时机对照

| EBS | V2 |
|-----|-----|
| `GetData` / `GetItemById` / `Save` 前取系数 | 试算/保存费用前取系数 |
| 保存写 `PurchaseCostParamId` | 保存写 `purchase_cost_param_id` + `purchase_ratio` |

## 7. 入库链校验

### 7.1 生成报关到货通知前

除现有条件（已结关、目标仓、报关出库已完成）外，**每行**须满足：

| 校验 | 失败文案 |
|------|----------|
| 头 `exchange_rate > 0` | 请填写报关汇率 |
| `purchase_ratio > 0` 且 `purchase_cost_param_id` 非空 | 未配置或未试算采购系数 |
| `duty_rate` 已维护（零关税须 HS + 税率=0） | 请填写报关税率 |
| `tax_included_unit_price > 0` | 请先完成报关费用试算 |
| `original_purchase_price > 0` | 请先完成拣货回写采购价 |

### 7.2 报关入库过账前

`ValidateCustomsStockInFeesAsync`：与 §7.1 相同校验，防止通知生成后改单。

## 8. 报关入库与采购单价

```text
P1 = tax_included_unit_price   // 含系数→货款→关税→增值税→代理费→杂费；不含商检

报关入库完成（OnCustomsStockInCompletedAsync）：
  stock_item.purchase_price = P1
```

**系数进入采购单价的路径**：P0 × 系数 → `cost_usd` → 价税链 → P1，**不**在 P0 上直接乘系数展示为最终采购价。

**到货通知 Cost**：`tax_included_unit_price > 0 ? P1 : declare_unit_price`

**销售出库 extend**（已定稿）：报关出库用 P0；销售出库用 P1。

## 9. 财务对接（EBS 对齐）

| 时机 | 行为 |
|------|------|
| 保存/试算成功 | 事件 `CustomsDeclarationFeesSaved`（对标 `DeclareCustomsSavedMessage`） |
| 费用场景 | `DeclareTariff` ← 关税；`Extra` ← 杂费；`InspectionFee` ← 商检 |
| 价税总额 | **不含**商检；商检单独入账 |

货款 / 增值税 / 代理费应付拆分：**二期**。

## 13. 验收要点

1. 公式与 EBS §3.3 用例一致（含 `agency_rate=1.03`、系数 1.05）。
2. 改头汇率 → 货款及以下全部变化；改系数主数据不影响已试算旧单。
3. 未填 `duty_rate` → 不能生成到货通知。
4. 报关入库后 `stock_item.purchase_price` = P1。
5. `total_value_tax` **不含**商检。
6. 移库 API 不可再创建报关移库。

---

**定稿摘要**：报关费用 = EBS 公式 + 全局采购系数 + 关务手工报关汇率 + 行级关税税率 + 独立报关公司代理费率；试算结果快照到明细，价税总额（不含商检）形成 P1 作为报关入库采购单价；未完成费用维护不得进入到货/入库；Hub 在报关详情「报关费用」面板。
