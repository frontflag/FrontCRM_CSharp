## 1. 背景与目标

开单、换报关公司、每次费用试算，原先都把 `customs_broker.agency_rate` 写入报关单头 `broker_agency_rate`。面板上代理费率只读，关务无法为本单单独改费率（例如本票与报关公司资料不一致）。

本需求在费用面板提供 **「系统 / 手工」** 切换：默认仍跟报关公司资料；手工时本单可输入费率，试算不再被主数据覆盖。

公式不变（见 [报关费用方案](./报关费用方案.md) §5.2 ⑤）：

```text
customs_agency_fee = (货款 + 关税 + 增值税) × (customsRate − 1)
customsRate = 头快照 broker_agency_rate（1+纯费率，如 1.025000 = 2.5%）
```

## 2. 功能需求

### 2.1 入口与权限

| 项 | 约定 |
|----|------|
| 位置 | 「报关费用」头区「代理费率」数值右侧 |
| 控件 | 分段按钮，文案 **系统** / **手工**（i18n：`customsPages.fees.agencyRateModeSystem` / `agencyRateModeManual`） |
| 显示条件 | 物流数据可写，且费用面板为可维护态（可编辑或未拣货 P0=0）；采购 511 脱敏时不显示切换 |
| 隐藏 | 只读、已作废、内部已完成、费用已锁定（结关锁定） |

默认 **系统**。存量报关单 `agency_rate_manual = false`，行为与上线前一致。

### 2.2 系统模式

- 绿框为只读数字（6 位小数）+ 「等价 n%」。
- 展示并试算 **当前报关公司资料** 的 `agency_rate`（详情 DTO `brokerMasterAgencyRate`）。
- 试算成功后把该值写回头快照 `broker_agency_rate`。
- **切回系统时立刻**用报关公司资料覆盖输入框（不必等试算才改显示）。表格里的代理费金额仍须点「试算费用」或「保存」才重算。

### 2.3 手工模式

- 绿框改为 `el-input-number`（6 位小数，步进 0.001）。
- 关务输入写入头快照 `broker_agency_rate`；试算 **不再**用报关公司资料覆盖。
- 「等价 n%」两种模式都显示。

### 2.4 校验（手工，前后端一致）

| 规则 | 说明 |
|------|------|
| 类型 | 须为有限数字 |
| 下限 | **≥ 1**（`1.000000` = 0% 代理费） |
| 上限 | **不设** |
| 格式 | **1+纯费率**，与报关公司资料相同（例 `1.025000`） |

非法时拦截试算/保存，不写库。文案：`customsPages.fees.validateAgencyRate`。

与报关公司主数据校验共用 `CustomsAgencyRateRules`（主数据路径仍抛 `ArgumentException`）。

### 2.5 更换报关公司

PATCH 报关单头 `customsBrokerId`（或等价换公司）时：

1. `agency_rate_manual` 强制 `false`
2. `broker_agency_rate` 取新公司资料费率
3. 同一请求里的手工费率字段忽略

开单（装箱确认生成报关单）固定系统模式。

### 2.6 生效时机

与报关汇率相同：切换或改数只改本地草稿；点 **试算费用** 或 **保存** 后 PATCH 再试算。不在每次按键时重算费用表。

### 2.7 非目标

- 不改报关公司主数据上的费率（那是「报关公司」页）。
- 不改代理费公式、不改杂费/商检是否进代理费基数。
- 费用锁定后不可改来源或费率（仅杂费/商检可改，既有规则）。

## 3. 数据模型

### 3.1 `customs_declaration`

| 列 | 类型 | 说明 |
|----|------|------|
| `broker_agency_rate` | numeric(10,6) NOT NULL DEFAULT 1 | 本单试算用的费率快照（1+纯费率） |
| `agency_rate_manual` | boolean NOT NULL DEFAULT false | `false` = 系统（跟报关公司）；`true` = 本单手工。换公司强制 false |

`customs_broker.agency_rate` 不变。无独立费率变更日志。

### 3.2 详情 DTO（`CustomsDeclarationDetailViewDto`）

| 字段 | 含义 |
|------|------|
| `brokerAgencyRate` | 头快照 |
| `agencyRateManual` | 是否手工 |
| `brokerMasterAgencyRate` | 报关公司资料当前费率（系统模式对照 / 切回覆盖） |

采购 511 脱敏时 `brokerAgencyRate`、`brokerMasterAgencyRate` 置 0，前端不提供切换。

## 4. 实现方案

### 4.1 试算取数

`CustomsV2FlowService.RecalculateDeclarationFeesAsync`：

```text
brokerRate = CustomsAgencyRateRules.ResolveForCalculation(
    dec.AgencyRateManual,
    dec.BrokerAgencyRate,
    broker.AgencyRate)
```

- 手工：快照 &lt; 1 → `InvalidOperationException`
- 系统：`broker.AgencyRate > 0` 则用主数据，否则 `1`；写回头快照

行计算器仍只接收一个 `brokerAgencyRate`，公式不变。

### 4.2 PATCH 报关单头

`PATCH /api/v1/customs-declarations/{id}` 增加：

| 字段 | 行为 |
|------|------|
| `agencyRateManual` | 写入来源标记 |
| `brokerAgencyRate` | 仅手工模式采纳并校验 ≥ 1 |

`UpdateDeclarationHeaderAsync`：换公司优先（强制系统）；否则按上表。费用已锁定且改汇率/公司/代理费率 → 拒绝。头字段变化且汇率 &gt; 0 时仍触发一次试算（与改汇率相同；随后前端 `recalculate-fees` 可能再跑一次）。

### 4.3 前端

`CRM.Web/src/components/Customs/CustomsDeclarationFeesPanel.vue`：

- 草稿：`agencyRateManual`、`headerBrokerAgencyRate`
- 切到系统：立刻 `headerBrokerAgencyRate = brokerMasterAgencyRate`
- 试算/保存前 `persistDirtyFields`：手工则 PATCH `agencyRateManual: true` + `brokerAgencyRate`；从手工切回系统则 PATCH `agencyRateManual: false`（服务端用主数据覆盖快照）

校验工具：`CRM.Web/src/utils/customsAgencyRate.ts`（`isValidCustomsAgencyRate`）。

## 5. 上线

1. 执行脚本或 EF 迁移（列 `IF NOT EXISTS`，存量默认系统模式）。
2. 重启 API 后打开报关单详情费用面板，确认「系统 / 手工」出现。
3. 手工改费率 → 试算 → 代理费按新 `(rate − 1)` 变化；切回系统 → 数字立刻变回公司资料，再试算费用对齐。
