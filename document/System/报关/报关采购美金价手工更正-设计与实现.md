# 报关采购美金价手工更正 — 设计与实现

**状态：** 已实现  
**页面：** 报关单详情 `/customs/declarations/:id` → 「报关费用」  
**关联：** [报关费用方案](./报关费用方案.md)、[业务字段变更日志](../业务字段变更日志-设计与实现.md)

---

## 1. 目标

已试算（含结关锁定）的历史单，采购美金价可能是系统公式结果且不准。关务/管理员可改为手工价，重跑费用链，并回写已生成的到货通知、报关入库与在库采购价（P1）。更改写入字段变更日志。

---

## 2. 规则

| 项 | 约定 |
|----|------|
| 入口 | 费用面板采购美金价 **系统 / 手工**；改价后点试算或保存 |
| 未锁定 | 物流可写即可切手工改价（与上线前一致），保存后重算并级联下游 |
| 结关锁定 | **仅 SYS_ADMIN / SYS_MANAGER** 可改采购美金价模式与行价并试算；其他人仍只能改杂费/商检 |
| 已完成 | 与结关锁定相同：仅 SYS_ADMIN / SYS_MANAGER 可改采购美金价并刷新下游 |
| 已作废 | 仍不可改 |
| 公式 | 手工行：`CalculateLineFromManualCostUsd`；系统行仍走 P0×系数 |
| 锁定下试算 | 保留本单已快照的代理费率，不强制改回报关公司资料 |
| 下游 | 新 P1 → 到货通知 `Cost`/`ExpectTotal`、报关入库明细单价/金额、`stock_item.purchase_price` / 金额 / 采购美金 |
| Invoice | 读报关明细现 `cost_usd`，不另回写 |
| 财务应付 | 不自动冲 |
| 日志 | `log_change_fldval`：头 `costUsdManual`；行 `costUsd` / `costUsdManual`（`{单号}-L{n}`）。人手保存记登录账号；仅后台自动回写或解析不到用户时记「系统」 |

---

## 3. 实现要点

- `CustomsLockedCostUsdCorrection`：锁定或已完成且非管理员拒绝改价/试算。
- 已完成时头 PATCH 仅允许 `costUsdManual`；明细 PATCH 仅允许 `costUsd` / `costUsdManual`。试算保留本单已快照的代理费率。
- API 以 `ManagementAccountPolicy.CanForceDelete`（SYS_ADMIN / SYS_MANAGER）传入 `canCorrectLockedCostUsd`。
- `RecalculateDeclarationFeesAsync` 成功后调用 `CascadeDeclarationItemAsync`（与代理费率下游刷新同一套回写）。
- `GET /api/v1/customs-declarations/{id}/change-logs` 聚合主表 + 明细变更，详情页展示。

---

## 4. 操作提示

结关锁定或已完成后，管理员将采购美金价切到 **手工**，改行价（如 1073.44 → 877），再 **保存**。成功提示会列出回写的到货通知、入库明细、库存层数。
