## 1. 目标

以 **当前报关单头** 为锚，在列表与详情右栏「流程」页签画地铁竖轴：上游收到销售明细，下游收到报关入库。详情页内「业务记录」表格仍是 Hub 全量列表，**不**当作流程轴。

右栏页签：**操作 + 流程 + 帮助**；有 `r-ops` 时默认仍是 **操作**。

---

## 2. 基数与生成时机

| 关系 | 基数 | 说明 |
|------|------|------|
| 报关单 : 装箱 | 1:1 | `customs_declaration.packing_id` |
| 报关单 : 报关明细 | 1:N | 装箱确认时按装箱行逐行生成 |
| 装箱明细 : 报关出库通知 | 1:1 | Type=20 |

**1:N 出现条件：** 新建报关装箱时勾选多条报关出库通知（同一境外仓、同一送达地域），确认装箱后一张报关单带多行明细。

流程按 **整张报关单** 画轴，不做装箱那种「明细条切换当前行」。

---

## 3. 站序（10 站，不含拣货）

```
1. 销售订单明细          同站多卡（按创建时间升序）
2. 销售出库通知 Type=10  同站多卡
3. 待报关                同站多卡
4. 报关出库通知 Type=20  同站多卡
5. 报关装箱              1 卡
6. 报关                  ★ 当前站（FlowYouAreHereMark）；1 卡；不出客户
7. 报关出库              按实际出库单（通常 1 卡）
8. 报关到货通知          按本单明细绑定，同站多卡
9. 报关质检              同站多卡
10. 报关入库             同站多卡
```

空站仍画空心「未开始」。待报关流程仍含拣货；本页签 **不单独出拣货站**。装箱在报关之上、报关出库在报关之下，对齐「装箱确认生成报关单」。

---

## 4. 字段裁剪

套用流程页签规范 §2.5～§2.8。描述不展示。

- 每站：单号（可跳转）、状态、创建日期 `yy-MM-dd`。
- 客户：销售明细站通栏 `{名称} ({编号})`；其它出客户站名称 + 编号两格。有 `customer.read` 且有 `customerId` 时新开页进客户详情。
- **报关当前站不出客户**（并单可能多客户）；**报关公司**只出现在报关当前站（报关单头，非 `vendorId`）。
- 单价·币别：仅销售明细。
- 数量标签：销售明细 / 销售出库通知 / 待报关 → 销售出库数量；报关出库通知 / 装箱 / 报关出库 → 报关出库数量；到货 / 质检用本站数量；报关入库 → 报关入库数量。
- 报关出库通知 / 装箱 / 报关出库 / 报关入库：`StockBizTypeTag`；海关图标仅类型为报关且已关联本报关单 ID。

511/521 **仍加载**，敏感字段显示 `—`。报关公司不按供应商脱敏。
