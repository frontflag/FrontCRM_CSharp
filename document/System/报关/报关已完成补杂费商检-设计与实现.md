## 1. 目标

历史单在 **已结关、已完成、已生成到货通知** 之后才发现漏填杂费或商检费。不回退海关状态、不改流程状态，由 **SYS_ADMIN / SYS_MANAGER** 在费用面板补录，重算本单尾部金额，并把新的含税单价 **P1** 回写到货通知、报关入库、库存。

---

## 2. 规则

| 项 | 约定 |
|----|------|
| 海关状态 / 已完成 | **不改**。禁止用回退「未维护」当编辑开关 |
| 已作废 | 仍不可改 |
| 已结关、未完成（`fees_locked`） | 物流可写即可改杂费/商检；杂费导致 P1 变化时 **回写下游** |
| 已完成 | **仅 SYS_ADMIN / SYS_MANAGER** 可改杂费/商检并试算回写；其他人仍整表只读（采购美金价更正规则不变） |
| 权限判定 | 与采购美金价相同：`ManagementAccountPolicy.CanForceDelete` |
| 公式 | 杂费进价税总额与 P1；商检费 **不进** 价税总额。其余货款/关税/增值税/代理费公式不变 |
| 试算 | 已锁定或已完成且管理员操作时，保留本单已快照代理费率（同采购美金价） |
| 下游 | 新 P1 → 到货 `Cost`/`ExpectTotal`、报关入库明细单价/金额、`stock_item.purchase_price` / 金额 / 采购美金 |
| 仅改商检 | 本单保存商检费；P1 不变则下游计数为 0 |
| Invoice / 应付 | 不自动冲、不另回写 |
| 日志 | 行 `otherFee` / `inspectionFee`（`{单号}-L{n}`），记登录账号 |
| 负数 | 杂费、商检费不能为负 |

## 3. 与采购美金价更正的关系

同一面板、同一套 `RecalculateDeclarationFeesAsync` + `CascadeDeclarationItemAsync`。
