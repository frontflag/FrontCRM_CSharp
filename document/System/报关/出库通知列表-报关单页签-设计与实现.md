# 出库通知列表 · 右侧「报关单」页签 — 功能要求与实现说明

**状态：** 已上线  
**关联：** [报关业务溯源与供应商口径](./报关业务溯源与供应商口径-设计与实现.md)（Hub + Spoke 模型 · P2 出库侧列表）、[报关单列表-操作面板-设计与实现](./报关单列表-操作面板-设计与实现.md)（报关单列表关务操作参考）、[销售订单明细列表-操作面板-设计与实现](../销售订单明细列表-操作面板-设计与实现.md)（右栏页签 + Store 模式参考）、EBS 对照 [报关业务逻辑](../../EBS/物流/报关.md)（只读）

本文描述 **FrontCRM（CRM.Web / CRM.API / CRM.Core）** 中 **出库通知列表页**（`StockOutNotifyList` / `InventoryStockOutNotifyList`）右侧工作区辅助栏 **「报关单」** 页签的设计要求与实现方法。

---

## 1. 业务定位

| 概念 | 说明 |
|------|------|
| **适用页面** | 出库通知列表（`CRM.Web/src/views/RFQ/StockOutNotifyList.vue`） |
| **展示位置** | `AppLayout` 右侧辅助栏（`aux-right`） |
| **页签 ID** | `r-stock-out-customs`（文案 i18n：`stockOutNotifyList.auxTabs.customsDeclaration` → 中文「报关单」） |
| **与「帮助」关系** | 选中 **报关出库** 行时页签为 **报关单 + 帮助**；否则仅 **帮助** |
| **目标** | 单击报关出库通知后，在不离开列表的前提下 **只读查看** 关联报关单摘要，并可跳转报关单详情 |
| **与报关单列表操作面板区别** | 报关单列表右栏为 **「操作」** 页签，含设置海关状态、生成到货通知等写操作；本页签 **无写操作**，仅摘要 +「查看报关单」链接 |
| **与出库通知详情区别** | 详情页内嵌 `StockOutCustomsSummaryPanel`（页内区块）；本功能为 **列表右栏独立页签** |

定稿遵循 [报关业务溯源与供应商口径](./报关业务溯源与供应商口径-设计与实现.md) §3：**报关单详情为 Hub**；出库通知列表为 **Spoke**，提供最少摘要 + 跳转入口。

## 2. 页签显示条件

用户 **单击** 列表行后，按 **出库类型**（`stockOutType` / `StockOutTypeCode`）控制：

| 条件 | 右栏页签 | 面板行为 |
|------|----------|----------|
| `stockOutType === 20`（**报关出库**） | 显示「报关单」+「帮助」 | 展开右栏，激活「报关单」页签，加载报关单详情 |
| `stockOutType !== 20`（销售/退货/报废等） | 仅「帮助」 | **不展开**右栏；`clear()` 报关上下文 |
| 未选中行 | 仅「帮助」 | 页签内提示「单击报关出库通知查看报关单信息」 |

**判定函数（前端）：** `resolveNotifyStockOutType(row.stockOutType) === StockOutTypeCode.Customs`（常量 `20`，见 `CRM.Web/src/constants/stockOutType.ts`）。

**注意：** 不使用出库通知自身的 `customsStatus`（待报关/报关中等）作为本页签显示条件——该字段描述 **销售出库** 走报关流程的进度；本页签仅服务 **报关出库通知**（Type=20）上的报关单溯源。

## 3. 布局与交互要求

### 3.1 整体结构

```
┌─ 右侧辅助栏 ─────────────────────────────┐
│ [报关单] [帮助]                [全屏][✕] │  ← 仅报关出库选中时出现「报关单」
├──────────────────────────────────────────┤
│  ┌ 报关单（卡片标题）──────────────────┐  │
│  │ 报关单号：CDS00000    [查看报关单]  │  │
│  │ 报关公司：××报关行                  │  │
│  │ 申报日期：2026-07-05                │  │
│  │ 香港美信仓 → 深圳仓                 │  │
│  └────────────────────────────────────┘  │
│  ┌ 状态标签 ──────────────────────────┐  │
│  │ [报关中]  [已结关]                  │  │
│  └────────────────────────────────────┘  │
└──────────────────────────────────────────┘
```

- 嵌入模式复用右栏样式体系：`so-item-ops-root--embedded`、`ops-card`、`ops-kv` 等（与报关单列表操作面板同源）。
- 宽度 `100%` 自适应父面板，禁止横向滚动。

### 3.2 列表交互

| 操作 | 行为 |
|------|------|
| **单击报关出库行** | `selectNotifyRow` → `toggleRightPanel(true)` → `setRightActiveTab('r-stock-out-customs')` |
| **单击非报关出库行** | `stockOutNotifyCustomsPanelStore.clear()`；不打开右栏 |
| **双击行** | 跳转出库通知详情 `StockOutNotifyDetail`（与改造前一致） |
| **勾选复选篮子** | `selection-change` 逻辑不变，与单击开面板互不干扰 |
| **选中行高亮** | `:row-class-name="customsPanelRowClassName"` → `so-item-row--active` |
| **列表刷新** | `refreshCustomsPanelIfOpen`：若仍有选中行则 `refreshFromListRows` |
| **离开列表路由** | `stockOutNotifyCustomsPanelStore.clear()`；右栏恢复仅「帮助」 |

与报关单列表的 **deferred 加载**（先记行、展开后再请求）不同：本页签定稿为 **单击报关出库行即展开并请求详情**。

### 3.3 「报关单」卡片 — 字段与样式

**卡片标题：**「报关单」（i18n：`stockOutNotifyList.customsTab.overviewTitle`），字号 **20px**、加粗。

| 顺序 | 展示 | 样式与规则 |
|------|------|------------|
| 1 | `报关单号：{declarationCode}` | 标签 + 值 KV 行；值 **琥珀色** `$color-amber`（`--crm-color-amber`），字号 **13px**、加粗；**纯文本，不可点击** |
| 1 同行右侧 | 链接「查看报关单」 | `router-link` → `CustomsDeclarationDetail`；需报关模块访问权限（见 §6） |
| 2 | `报关公司：{customsBrokerName}` | 13px KV |
| 3 | `申报日期：{declareDate}` | 日期取 `YYYY-MM-DD` |
| 4 | `{源仓} → {目标仓}` | 无标签前缀；`fromWarehouseName → toWarehouseName`（名称优先，回退 code/id） |

**空态：**

| 场景 | 文案（i18n） |
|------|----------------|
| 报关出库但 `customsDeclarationId` 为空 | `stockOutNotifyList.customsTab.noDeclaration` →「报关单尚未生成」 |
| 接口失败 | `stockOutNotifyList.customsTab.loadFailed` + 错误信息 |

空态 **仅提示**，不引导跳转装箱单/待报关列表。

### 3.4 状态标签卡片

详情加载成功后展示第二卡片（无独立标题）：

| 标签 | 字段 | 取值 |
|------|------|------|
| 报关流程状态 | `internalStatus` | 待处理(1) / 报关中(2) / 已完成(3) / 作废(-1) |
| 海关状态 | `customsClearanceStatus` | 未维护(0) / 放行(10) / 已结关(100) |

文案与配色复用 `customsPages.declarations.*`（与报关单列表操作面板一致）。

## 4. 数据与 API

### 4.1 列表行已有字段（Type=20 批量 enrichment）

出库通知列表 API `GET /api/v1/stock-out/request` 返回 `StockOutRequestListItemDto`，对 `stockOutType=20` 行由 `CustomsTraceQuery.EnrichStockOutRequestListItemsAsync` 回填：

| 字段 | 说明 |
|------|------|
| `customsDeclarationId` | 关联报关单主键 |
| `customsDeclarationCode` | 报关单号 |
| `customsBrokerName` | 报关公司名称（展示用） |

### 4.2 页签懒加载详情

选中行后，若存在 `customsDeclarationId`，前端请求：

```http
GET /api/v1/customs-declarations/{id}
```

响应 `CustomsDeclarationDetailDto`，页签主要使用：

| 字段 | 用途 |
|------|------|
| `declarationCode` | 报关单号 |
| `customsBrokerName` / `customsBrokerCode` | 报关公司 |
| `declareDate` | 申报日期 |
| `fromWarehouseName` / `toWarehouseName` | 源仓 → 目标仓 |
| `internalStatus` | 报关流程状态标签 |
| `customsClearanceStatus` | 海关状态标签 |

**后端：** 本功能 **无需新增 API**；列表 enrichment + 既有报关单详情接口即可。

**备选（未接入前端）：** `GET /api/v1/customs-declarations/by-stock-out-request/{stockOutRequestId}` 可在无 `customsDeclarationId` 时用于反查，当前定稿仅依赖列表行 ID。

### 4.3 数据链路（报关出库 → 报关单）

```text
stockout_notify (StockOutType = 20)
  → customs_declaration_item.customs_stockout_notify_id
  → customs_declaration (+ customs_broker_id)
```

详见 [报关业务溯源与供应商口径](./报关业务溯源与供应商口径-设计与实现.md) §4.1。

## 5. 前端实现

### 5.1 文件清单

| 角色 | 路径 |
|------|------|
| 列表页 | `CRM.Web/src/views/RFQ/StockOutNotifyList.vue` |
| 页签面板 | `CRM.Web/src/components/Inventory/StockOutNotifyCustomsTabPanel.vue` |
| Pinia Store | `CRM.Web/src/stores/stockOutNotifyCustomsPanel.ts` |
| 布局注册 | `CRM.Web/src/layouts/AppLayout.vue` |
| 出库类型常量 | `CRM.Web/src/constants/stockOutType.ts`（`StockOutTypeCode.Customs = 20`） |
| 报关 API | `CRM.Web/src/api/customs.ts` → `fetchCustomsDeclarationById` |
| i18n | `CRM.Web/src/locales/zh-CN.ts` / `en-US.ts` → `stockOutNotifyList.auxTabs` / `customsTab` |

### 5.2 Store：`useStockOutNotifyCustomsPanelStore`

| 状态 / 方法 | 说明 |
|-------------|------|
| `notifyRow` | 当前选中的出库通知行 |
| `detail` | 报关单详情 DTO |
| `loading` / `loadError` / `noDeclaration` | 加载与空态 |
| `isCustomsSelection` | 是否报关出库选中（驱动动态页签） |
| `selectNotifyRow(row)` | 写入行；有 `customsDeclarationId` 则 `fetchCustomsDeclarationById` |
| `refreshFromListRows(rows)` | 列表刷新后同步选中行 |
| `clear()` | 离开页或单击非报关行时清空 |

并发：`loadSeq` 序号防止快速切换行时旧请求覆盖新选中。

### 5.3 AppLayout 注册

1. **路由判断：** `isStockOutNotifyListRoute` → `InventoryStockOutNotifyList` \| `StockOutNotifyList`。
2. **动态页签：** `syncStockOutNotifyListRightTabs()` — `isCustomsSelection` 为真时 `rightTabs = [r-stock-out-customs, r4]`，否则仅 `r4`。
3. **watch：** `stockOutNotifyCustomsPanelStore.isCustomsSelection` 在列表路由下触发 `syncStockOutNotifyListRightTabs`。
4. **面板显示：** `showStockOutNotifyCustomsPanel` = 当前 tab 为 `r-stock-out-customs` 且在列表路由。
5. **权限：** `:can-access-customs="showCustomsMenus"`（`canAccessCustomsModule`）控制「查看报关单」链接是否渲染。

### 5.4 列表页接线

```typescript
// StockOutNotifyList.vue — 单击报关出库行
async function onRowClick(row: StockOutRequestDto) {
  if (!isCustomsNotify(row)) {
    stockOutNotifyCustomsPanelStore.clear()
    return
  }
  await stockOutNotifyCustomsPanelStore.selectNotifyRow(row, t('stockOutNotifyList.customsTab.loadFailed'))
  workspaceLayout?.toggleRightPanel(true)
  await nextTick()
  workspaceLayout?.setRightActiveTab('r-stock-out-customs')
}
```

`CrmDataTable` 使用 `@row-click`；`inject(WorkspaceLayoutKey)` 获取 `toggleRightPanel` / `setRightActiveTab`。

## 6. 权限

| 场景 | 规则 |
|------|------|
| 查看页签摘要 | 随出库通知列表可读（物流读权限） |
| 「查看报关单」链接 | 需 **报关模块访问**（`canAccessCustomsModule`：系统管理员 / 财务部 / 物流部）；无权限时不渲染链接 |
| 报关单号展示 | 琥珀色纯文本，**不依赖**报关权限即可见 |

与 [报关业务溯源与供应商口径](./报关业务溯源与供应商口径-设计与实现.md) §6 一致。

## 8. 测试核对要点

1. 筛选「报关出库」类型，单击一行 → 右栏出现「报关单」页签并展示字段与双状态标签。
2. 单击销售出库行 → 右栏不展开；若此前在报关单页签，页签收回仅「帮助」。
3. 报关出库但无 `customsDeclarationId` → 显示「报关单尚未生成」。
4. 双击行 → 进入出库通知详情，与单击行为不冲突。
5. 列表刷新后选中行字段与状态仍正确（`refreshFromListRows`）。
6. 无报关模块权限账号：可见报关单号（琥珀色文本），无「查看报关单」链接。
7. 离开出库通知列表路由 → store 清空，其他页面右栏无残留「报关单」页签。
