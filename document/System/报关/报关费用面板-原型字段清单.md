## 1. 面板位置与结构

| 项 | 约定 |
|----|------|
| 位置 | 报关单详情页，**基础信息**区块之下、**明细表**区块之上 |
| 区块类名 | `info-section`（与现有详情页一致） |
| 区块标题 | `customsPages.declarations.sectionFees` → 中文「报关费用」 |
| 布局 | 上：**头区**（单头输入 + 汇总 + 操作）；下：**行区**（费用明细表） |
| Hub 原则 | 完整费用维护 **仅在此面板**；明细表保留摘要列，不重复全套编辑控件 |

```text
┌─ 报关费用 ───────────────────────────── [试算费用] [保存] ─┐
│ 头区：汇率 | 代理费率 | 采购系数 | 税费总额 | 状态提示      │
├────────────────────────────────────────────────────────────┤
│ 行区：CrmDataTable / el-table（每报关明细一行）              │
├────────────────────────────────────────────────────────────┤
│ 可选：公式说明折叠区                                         │
└────────────────────────────────────────────────────────────┘
```

## 2. 面板状态机

| 状态 | 条件 | 头区 | 行区可编辑 | 试算/保存 |
|------|------|------|------------|-----------|
| `readonly_void` | 报关单已作废 | 只读 | 只读 | 隐藏 |
| `readonly_completed` | 内部状态已完成 | 只读 | 只读 | 隐藏 |
| `readonly_locked` | `fees_locked=true`（已结关锁定） | 只读 | 仅杂费/商检可改 | 仅保存（部分重算） |
| `editable` | 默认可编辑 | 可编辑 | 可编辑输入项 | 显示 |
| `blocked_no_p0` | 存在行 P0=0（未拣货） | 可编辑汇率等 | 关税税率等禁用 | 试算 disabled + Alert |

## 3. 头区字段清单

| # | 字段标签（zh） | i18n key（建议） | 绑定/API 字段 | 控件 | 可编辑 | 必填 | 权限 | 说明 |

| H1 | 报关汇率 | `customsPages.fees.exchangeRate` | `detail.exchangeRate` | `el-input-number`（6 位小数） | editable 态 | 试算前 | 511 脱敏时显示 0/— | USD→CNY；旁侧按钮「采用财务汇率」调用 `GET finance/exchange-rate` 填入 **不自动保存** |
| H2 | 报关公司 | （复用 `colBroker`） | `detail.customsBrokerId` | 只读文本 + 链接主数据 | 否（在基础信息或装箱改） | — | — | 面板只 **展示**；换公司后须重算；展示 `customsBrokerName` |
| H3 | 代理费率 | `customsPages.fees.agencyRate` | `detail.brokerAgencyRate` | 只读 | 否 | — | — | 展示 `1.030000` + 辅助文案「等价 3%」；来自头快照 |
| H4 | 采购系数 | `customsPages.fees.purchaseRatio` | `detail.effectivePurchaseRatio` 或首行 `purchaseRatio` | 只读 | 否 | — | 511 | 展示当前试算快照；副文案：系统生效系数（`GET purchase-cost-params/effective`）不一致时 Warning |
| H5 | 税费总额 | `customsPages.declarations.colTotal` | `detail.totalTaxAmount` | 只读 | 否 | — | 511 | Σ 行 `totalValueTax`；CNY 2 位 |
| H6 | 试算时间 | `customsPages.fees.calculatedAt` | `detail.feesCalculatedAt` | 只读 | 否 | — | — | 最后一次成功试算 UTC→本地 |
| H7 | 费用状态 | `customsPages.fees.status` | 计算属性 | Tag | 否 | — | — | `未试算` / `已试算` / `可生成到货` / `阻塞：{reason}` |

### 3.1 头区 Alert

| 条件 | 类型 | 文案 key |
|------|------|----------|
| `exchangeRate <= 0` | warning | `customsPages.fees.alertNoExchangeRate` |
| 未配置采购系数 | error | `customsPages.fees.alertNoPurchaseRatio` |
| 存在行 `dutyRate` 未填且需入库 | warning | `customsPages.fees.alertNoDutyRate` |
| 快照系数 ≠ 系统当前系数 | info | `customsPages.fees.alertRatioStale` |

### 3.2 头区操作按钮

| 按钮 | i18n key | 方法 | disabled 条件 |
|------|----------|------|-----------------|
| 试算费用 | `customsPages.fees.btnRecalculate` | `POST .../recalculate-fees` | void/completed/locked；或无 P0；或无系数 |
| 保存 | `customsPages.fees.btnSave` | 同试算或 PATCH 头+行脏数据 | 同左 |
| 采用财务汇率 | `customsPages.fees.btnApplyFinanceRate` | 本地填 H1 | editable 态 |

### 4.1 行区不放入面板、留在原明细表的字段

| 字段 | 原因 |
|------|------|
| `declareUnitPrice` | 申报价，非费用链输入；留明细表只读 |
| 客户 / 业务员 / 供应商 / 到货通知号 | 溯源信息，非费用 |

### 4.2 行级校验（前端即时）

| 规则 | 提示 |
|------|------|
| `dutyRate < 0` | 关税税率不能为负 |
| `dutyRate === 0` 且 `hsCode` 空 | 零关税请填写 HS 编码 |
| `vatRate <= 0` | 增值税率须大于 0 |
| `originalPurchasePrice <= 0` | 该行尚未拣货回写，无法试算（行背景高亮） |

### 5.3 PATCH 请求体（editable 态）

**头** `PatchCustomsDeclarationHeader` 扩展：

```json
{
  "exchangeRate": 7.2500,
  "toWarehouseId": "...",
  "remark": "..."
}
```

**行** `CustomsDeclarationItemPatch` 收窄为：

```json
{
  "hsCode": "8542310000",
  "dutyRate": 0.05,
  "vatRate": 0.13,
  "otherFee": 100.00,
  "inspectionFee": 50.00
}
```

**禁止 PATCH**：`customsPaymentGoods`、`dutyAmount`、`vatAmount`、`customsAgencyFee`、`totalValueTax`、`taxIncludedUnitPrice`、`costUsd`（须试算重算）。

## 6. 交互流程（原型）

```text
1. 进入详情 → 加载 detail（含 fees 字段）
2. 若 exchangeRate=0 → Alert + 引导填写或「采用财务汇率」
3. 关务填写 H1、行 L8–L10、L15–L16
4. 点击「试算费用」→ POST recalculate-fees → 刷新 L7、L11–L18、H5、H6
5. 点击「保存」→ 同试算（或 PATCH 脏字段后试算）
6. 「生成报关到货通知」按钮：沿用 `canCreateArrivalNotifies`；阻塞时展示 `feesBlockReason`
```

## 9. 与现有明细表的关系

| 策略 | 说明 |
|------|------|
| 面板 | 费用 **输入 + 试算 + 完整输出** |
| 原明细表 | 保留 PN/客户/到货通知等；费用列可 **精简** 为 P1 + 价税总额两列，避免横向过宽 |
| 基础信息 | **移除**汇率只读展示（改在费用面板）；或保留只读副本 + 面板可编辑（二选一，**推荐仅面板**） |
