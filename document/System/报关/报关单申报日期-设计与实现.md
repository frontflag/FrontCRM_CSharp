## 1. 口径

界面「申报日期」**不是**拣货生成报关单当天，也**不是**装箱点「出库」那天。

```text
报关装箱对应的报关出库单（类型=报关出库）状态 = 出库完成
  → 申报日期 = 该出库单「出库日期」（实际出库日期 StockOutDate）
此前（无出库单、准备出库、已取消等）
  → 申报日期 = 空（—）
```

与出库单列表同一字段、同一天。装箱批量出库只生成 **准备出库**，须再在出库单上 **标记完成** 后才有申报日期。离开「出库完成」（强制删除后退回等）后重新变空。多条有效完成出库时取最晚出库日期。

查询时实时关联，不把出库日期写回报关单头展示列。头表 `DeclareDate` 仍在生成时写入占位日期（库列非空），**界面与筛选不读该列**。

---

## 2. 关联路径

报关单 `packing_id`（或装箱单 `customs_declaration_id` 兜底）→ 报关出库单：`SourceId` = 装箱单 Id，或出库明细 `packing_id`。仅 `StockOutType = 20` 且 `Status = 4` 且 `StockOutDate` 有值。

---

## 3. 展示与筛选

| 表面 | 行为 |
|------|------|
| 报关单列表 / 详情 / 操作面板概况 | 完成则显示日期，否则 — |
| 报关明细列表 | 同行头日期 |
| 出库通知「报关单」页签 | 同详情 |
| 报关入库详情摘要 | 同左；时间线「报关单」步骤时刻用该日期，未完成则无时刻 |
| 列表「申报日期」筛选 | 按上述出库日期；未完成的单筛不出来 |
| 物流控制台近 30 天「报关」条数 | 按该日期落入区间的报关明细行计 |
