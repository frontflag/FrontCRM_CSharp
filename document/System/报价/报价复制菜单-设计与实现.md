## 1. 需求

1. 列表操作中「复制」支持**两种**剪贴板格式：
   - **复制**：仅值（多行字段值，无标题前缀）。
   - **带标题复制**：多行「标题: 值」。
2. 一级「复制」入口：悬停后展开二级项「带标题复制」（不必先点一级才能看到二级）。
3. 二级浮层默认在右侧展开；**右侧空间不足**时自动改到左侧（`fallback-placements`）。

---

## 2. 交互方案

| 项 | 约定 |
|----|------|
| 触发 | 操作列下拉内嵌 `el-popover` / flyout：`trigger="hover"`，`placement="right-start"` |
| 回退 | `OP_COPY_FLYOUT_FALLBACK_PLACEMENTS`（含 `left-start` 等） |
| 样式 | `op-copy-flyout`（`crm-biz-list-page.scss` / `crm-unified-list.scss`） |
| 成功/失败 | `ElMessage` i18n：`quoteList.actions.copySuccess` / `copyWithTitleSuccess` / `copyFailed` |
