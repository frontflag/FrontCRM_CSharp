## 1. 目标

报价头一行：供应商占 **1/3**，**供应商等级 / 联系人 / 失效日期** 均分剩余 **2/3**。

保存报价时若等级相对供应商主数据有变化，回写 `vendorinfo.Level`（与供应商编辑页改等级相同）。**有报价保存权限即可**，不要求供应商写入权限。报价仍不存等级快照，列表继续现读主数据。

---

## 2. 交互

| 项 | 约定 |
|----|------|
| 未选供应商 | 等级下拉禁用 |
| 选中供应商 | 带出当前 S/A/B/C（缺省按 C） |
| 换供应商 | 等级换成新供应商当前档 |
| 选项 | 与供应商编辑相同，不可清空 |
| 采购脱敏 | 供应商、等级、联系人显示「—」，不可改；失效日期仍可填 |
| 未改等级 | 不写主数据、不记供应商字段日志 |

---

## 3. 保存

明细请求带 `vendorLevel`。`QuoteService` 创建/更新在 `SaveChanges` 前调用 `IVendorService.ApplyLevelIfChangedAsync`。同一供应商取首次出现的等级。供应商不存在则整单失败。等级变更记供应商字段变更日志（字段 `level`）。

---

## 4. 实现索引

| 层 | 位置 |
|----|------|
| DTO | `CreateQuoteItemRequest.VendorLevel` |
| 回写 | `VendorService.ApplyLevelIfChangedAsync`（不单独 SaveChanges） |
| 报价 | `QuoteService.ApplyVendorLevelsFromQuoteItemsAsync` |
| 前端 | `QuoteCreate.vue`、`quote.ts` `buildItemsFromQuoteCreateForm` |
| 单测 | `QuoteServiceTests` 创建时调用 / 未传不调用 / 供应商缺失不提交 |

无新权限码、无迁移。
