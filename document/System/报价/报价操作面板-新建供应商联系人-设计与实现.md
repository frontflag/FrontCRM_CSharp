## 1. 需求

1. 新建/编辑报价右侧扩展栏增加 **「操作」** 页签（与历史报价、物料、帮助并列）。
2. 默认仍停在「历史报价」；「操作」为辅助入口。
3. 未选供应商：按钮禁用，并提示先选供应商。
4. 已选供应商：可 **新建供应商联系人** → 打开既有 `VendorContactDialog`。
5. 保存成功后：关闭弹窗、刷新该供应商联系人列表，并**自动选中**新建联系人。

表单区供应商旁也可提供「+」快捷入口（无供应商时 tooltip 提示），与操作面板同一套弹窗/回填逻辑。

---

## 2. 方案

### 2.1 页签与面板

| 项 | 约定 |
|----|------|
| 布局 | `AppLayout`：`QuoteCreate` / `QuoteEdit` 的 `rightTabs` 含 `r-ops` |
| 面板 | `QuoteOpsPanel.vue`；`v-show` 当 `rightActiveTabId === 'r-ops'` |
| 默认页签 | `r-quote-history`（历史报价） |

### 2.2 状态桥接

报价页为表单态，不依赖「选中列表行」的 ops 体系。用 Pinia：

- Store：`quoteOpsPanel.ts`
- `bind({ vendorId, vendorName })`：由 `QuoteCreate` watch / 挂载驱动
- 弹窗 `success` 携带新建联系人（至少 `id`，及展示名）→ `createdContact` → 报价页 `consumeCreatedContact` 后写入 `vendorContactId` / 联系人下拉

`VendorContactDialog`：`success` payload 带回新建实体；仅打开时再挂载，避免无谓订阅。

### 2.3 实现索引

| 层 | 位置 |
|----|------|
| Store | `CRM.Web/src/stores/quoteOpsPanel.ts` |
| 面板 | `CRM.Web/src/components/RFQ/QuoteOpsPanel.vue` |
| 布局 | `AppLayout.vue`（`showQuoteOpsPanel`） |
| 表单 | `QuoteCreate.vue`（绑定、自动选中、表单区「+」） |
| 弹窗 | `VendorContactDialog.vue` |
| 桌面清理 | `QuoteDesktop.vue` 离开时 `clear()` |
