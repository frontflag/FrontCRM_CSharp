# 报价桌面 — 设计与实现

**状态：** MVP  
**路由：** `/quote-desktop`（标题：报价桌面）  
**关联：** 需求明细列表 `/rfq-items`、新建报价 `/quotes/create`（并存入口）

---

## 1. 产品目标

将待报价需求明细队列、上一条/下一条导航、报价表单、右侧历史报价合并为单页，支持连续报价作业。

- 与独立「新建报价」页、需求明细行内「报价」**并存**；行内报价功能不变。
- 入口：`QuoteCreate` 右上角 + 需求明细列表右上角「报价桌面」。
- 顶栏统计：`全部待报价需求明细 {N}条`，**N 随左栏日期筛选变化**。
- 保存报价成功或「查无报价」成功后刷新队列并**自动选中下一条**（跨页；无下一条则空态）。

---

## 2. 页面结构

左右栏使用 **AppLayout 扩展面板页签**（与审核桌面同一工作台模式）。

```text
┌─ 左扩展 ─┬──────────────────────────┬─ 右扩展 ──────────┐
│ 待报价队列│ 顶：上一条 | 统计 | 下一条 │ 历史报价（默认） │
│ +日期筛选 │ 中：嵌入报价表单         │ + 帮助            │
│ +翻页     │                          │                    │
└──────────┴──────────────────────────┴────────────────────┘
```

| 区域 | 行为 |
|------|------|
| 左扩展「待报价」 | 仅路由 `QuoteDesktop`；`status=0` 且当前用户可报价；页大小 20；日期筛；翻页 |
| 顶栏 + 中栏 | 筛选后总数；上/下一条（跨页）；嵌入 `QuoteCreate`（`embedded`） |
| 右扩展 | 默认「历史报价」+「帮助」 |

---

## 3. 左栏筛选与列表

日期筛（按**需求明细创建时间**本地日历日）：

| 选项 | 含义 |
|------|------|
| 全部 | 不限创建日 |
| 今日 | `[今日 0:00, 明日 0:00)` |
| 昨日 | `[昨日 0:00, 今日 0:00)` |
| 前天 | `[前天 0:00, 昨日 0:00)` |
| 3日前 | `创建日 ≤ 今天−3`（`CreateTime < 前天 0:00`） |

列表字段：需求编号、创建日期、物料型号、品牌、业务员、采购员。

权限：仅可报价明细（后端 `quotableByMe=true`，对齐 `canQuoteRfqItem`）。

---

## 4. 右侧「历史报价」

- **物料**：当前明细型号、品牌。
- **历史报价**：按物料型号精确匹配，报价日期降序最近 10 条；展开多档阶梯；主状态 `status===1` 显示「成单」。

---

## 5. 导航与深链

- 上/下一条跨筛选全集；页末/页首自动翻页。
- 从 `QuoteCreate?rfqItemId=` 进入：定位该条；失败则提示并选第一条。
- 保存报价、查无报价成功后均跳下一条。

## 6. 前端实现要点

| 文件 | 职责 |
|------|------|
| `views/RFQ/QuoteDesktop.vue` | 顶栏 + 嵌入报价表单 |

| `components/RFQ/QuoteHistoryPanel.vue` | 右扩展报价历史 |
| `stores/quoteDesktopQueue.ts` | 分页队列、筛选、选中、跨页导航 |

| `views/RFQ/QuoteCreate.vue` | `embedded` 模式 + 入口按钮 |
| `views/RFQ/RFQItemList.vue` | 入口按钮 |

---

## 7. API

- `GET /api/v1/rfqs/items?status=0&quotableByMe=true&pageSize=20&itemCreateStart&itemCreateEndExclusive&preferItemId=`
- `GET /api/v1/quotes?exactMpn=&pageSize=10`
- `POST /api/v1/rfqs/items/{id}/mark-no-quote`
- 报价创建/更新：既有 quotes API
