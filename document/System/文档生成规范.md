# 文档生成规范

本文档约定仓库内 **Markdown 技术文档** 的目录职责、命名与生成/更新规则。AI 辅助生成、人工编写、以及从 EBS 对照摘录时均须遵守。

**关联：** [系统设计规范](./系统设计规范.md)

---

## 一、`document/` 目录职责

| 目录 | 用途 | 是否可新建/修改 |
|------|------|-----------------|
| `document/EBS/` | **旧系统（EBS）** 设计与业务逻辑文档，仅供 FrontCRM 对照阅读 | **否（只读）** |
| `document/System/` | FrontCRM **系统级**设计与实现（`xxx-设计与实现.md`、业务规则、架构说明） | 是 |
| `document/PRD/` | 产品需求、UI/业务规范 | 是 |
| `document/IMP/` | 数据看板、统计方案等实现级说明 | 是 |
| `document/实现方案/` | 分阶段实施方案、DDL、迁移与上线步骤 | 是 |
| `document/QA/` | 测试人员用的**测试对照说明**（口径、公式、核对步骤） | 是 |
| `help/` | 右侧帮助面板，**面向业务用户**（见 `help/README.md`） | 是 |

---

## 二、`document/EBS/` 只读（强制）

`document/EBS` 存放的是 **EBS 原系统** 的设计与业务文档，在 FrontCRM 项目中 **仅作只读参考**，用于理解历史口径、字段含义与对照验收。

### 2.1 禁止事项

- **禁止修改** `document/EBS/` 下任意已有文件（含增删改段落、补链接、改标题、纠错、同步 FrontCRM 实现说明等）。
- **禁止在** `document/EBS/` **下新建** FrontCRM 的设计、实现、测试或 PRD 类文档。
- **禁止将** EBS 文档 **移动或复制后改写** 为 FrontCRM 实现文档并仍留在 `EBS/` 目录。

### 2.2 允许事项

- **阅读与引用**：在 `document/System/`、`document/QA/`、`document/IMP/` 等文档中 **链接** 到 EBS 文档作为对照来源。
- **摘录对照**：在 FrontCRM 文档中用文字说明「EBS 原规则」与「FrontCRM 差异」，**不要回写进 EBS 文件**。

### 2.3 FrontCRM 文档应写到哪里

| 文档类型 | 推荐路径 | 命名示例 |
|----------|----------|----------|
| 设计需求 + 实现说明 | `document/System/{业务域}/` | `库存滚存-设计与实现.md` |
| 测试对照说明 | `document/QA/数据分析/` 或对应子目录 | `库存滚存-测试对照说明.md` |
| 统计/看板方案 | `document/IMP/数据看板/` | `销售统计.md` |
| 产品需求 | `document/PRD/` | 按现有 PRD 结构 |
| 用户帮助 | `help/pages/` | 按 `help/README.md` 与菜单注册表 |

**错误示例（禁止）：** 在 `document/EBS/物流/` 下新建 `库存滚存-设计与实现.md` 描述 FrontCRM 实现。  
**正确做法：** 新建 `document/System/财务/库存滚存-设计与实现.md`（或 `document/System/物流/`），文内链接到 `document/EBS/物流/库存滚存业务逻辑文档.md` 作对照。

---

## 三、新建文档时的通用要求

1. **文首元信息**：状态（草案/MVP/已上线）、关联 EBS 对照链接（如有）、权限脚本路径（如有）。
2. **交叉引用**：FrontCRM 实现文档 ↔ QA 测试文档 ↔ EBS 只读对照，链接写在 **FrontCRM 侧文档** 中。
3. **不重复污染 EBS**：EBS 目录保持「原系统快照」，FrontCRM 迭代只更新 `System` / `QA` / `IMP` 等目录。
4. **帮助文档**：从 `document/System/` 摘录到 `help/pages/` 时须改写为业务用户语言，规则见 [扩展面板.帮助规范](../PRD/规范/UI规范/扩展面板.帮助规范.md)。

---

## 四、生成文档自检清单

生成或更新文档后，确认：

- [ ] 未改动 `document/EBS/` 下任何文件
- [ ] FrontCRM 设计与实现写在 `document/System/`（或 `IMP/` / `实现方案/`），而非 `EBS/`
- [ ] 需要测试核对时，在 `document/QA/` 单独维护测试对照说明
- [ ] 引用 EBS 处使用 Markdown 链接，不在 EBS 文件中反向补 FrontCRM 链接
- [ ] `help/pages/` 无权限码、路由、表名字段等开发术语（帮助规范另有要求）

---

*本规范适用于所有由人工或 AI 生成的仓库文档；与具体模块 PRD、实现方案配合使用。*
