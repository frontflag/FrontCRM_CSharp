**状态：** 已上线  
**页面：** `/reports/sales`（概况 → 分解 →「出库进度（明细行）」柱状图）  
**测试对照：** [销售分析-测试对照说明 §5.4](../../QA/数据分析/销售分析-测试对照说明.md)  
**帮助（业务用户）：** [销售分析](../../../help/pages/销售分析_MENU_SALES_ANALYTICS.md)「分解」表  
**关联 IMP：** [销售统计.md](../../IMP/数据看板/销售统计.md)  
**展示总规：** [数据看板总要求 §3.7](../../IMP/数据看板/数据看板总要求.md) — 占比类面板须同时显示绝对量与百分比（纯比率如转化率除外）；出库进度条图已按行数 + `%` 展示。

## 1. 需求设计

### 1.1 目标

在销售分析概况页的数据面板（分解柱状图）上，为「出库进度（明细行）」增加两类操作入口，降低「图上数字」与「业务列表 / 帮助口径」之间的认知成本：

| 按钮 | 作用 |
|------|------|
| **口径** | 弹出 Tip，展示该图在帮助「分解」表中的图名、数据源、口径说明 |
| **详情** | 打开明细弹窗，按同口径分页列出销售订单明细行，并可下钻列表 |

### 1.2 产品定稿

| 项 | 说明 |
|----|------|
| 作用图 | 仅概况分解中的 **出库进度（明细行）**（`groupKey = stockOutProgress`）；其它分解图暂不开放 |
| 口径 Tip 内容来源 | **产品文案（i18n）**，与帮助页「分解 → 出库进度」行保持一致；**不**运行时解析 `help/*.md` |
| Tip 左侧标签来源 | 对齐帮助「分解」表**列标题**：**图** / **数据源** / **口径说明**（KPI 卡勿用本表「图」，见总要求 [§3.9](../../IMP/数据看板/数据看板总要求.md)） |
| Tip 展示字段 | 图、数据源、口径说明（三行）；首行标签 i18n = `definitionTip.chart` |
| 详情数据口径 | 与分解柱图一致：区间内有效销售明细，按 `stock_out_progress_status` 0/1/2 计行；不限主单是否已审核 |
| 详情信息栏 | 展示当前 **视角**（公司 / 部门 / 个人）与 **统计区间**（`dateFrom`～`dateTo`），并提示「按销售订单创建日期；与页面顶部筛选一致」 |
| 详情交互 | 弹窗可 **拖动**、可 **缩放**；表格区内滚；Tab 筛进度档只影响列表分页，不改变顶部三档 summary |
| 客户列 | 受 `customer.info.read` 与销售 5.2.1 脱敏约束；无权限时不返回客户名且前端不展示该列 |

### 1.3 口径 Tip 文案（与帮助绿框对齐）

| Tip 行 | 左侧标签（= 帮助列标题） | 右侧内容（= 帮助「出库进度」行） | i18n |
|--------|--------------------------|----------------------------------|------|
| 1 | **图** | 出库进度 | 标签 `definitionTip.chart`；值 `stockOutProgressDefinition.chart` |
| 2 | **数据源** | 销售订单明细 | `definitionTip.dataSource` / `stockOutProgressDefinition.dataSource` |
| 3 | **口径说明** | 区间内有效明细按「待出库 / 部分出库 / 出库完成」计行数（不限是否已审核）。 | `definitionTip.definition` / `stockOutProgressDefinition.text` |

帮助页路径：`help/pages/销售分析_MENU_SALES_ANALYTICS.md` →「概况 → 分解」表。修改口径时须 **同时** 更新：帮助 md、i18n（`salesAnalytics.stockOutProgressDefinition.*`）、本文与 QA §5.4。

## 2. 实现方法

### 2.1 前端结构

| 组件 / 位置 | 职责 |
|-------------|------|
| `AnalyticsBreakdownChart.vue` | 柱状分解图；每行同时展示 **行数（value）+ 百分比（ratio）**（对齐全链路饼图图例）；标题行右侧：`口径` + `详情` |
| `SalesAnalyticsPage.vue` | 对 `stockOutProgress` 传入 `showDefinition` / `showDetail` 与 i18n 文案；打开详情弹窗 |
| `StockOutProgressDetailDialog.vue` | 详情弹窗：信息栏 + 三档 summary + Tab + 表格 + 分页 |
| `useResizableDialog.ts` | 自研拖拽（改 `left`/`top`）与缩放；**不**使用 Element Plus `draggable`（与 resize 后 transform 冲突） |

### 2.2 口径按钮

- 样式：与「详情」同为 `el-button` link / primary / small；顺序为 **口径 → 详情**。
- 交互：`el-popover`，`trigger="click"`，`placement="bottom-end"`。
- Props：`showDefinition`、`definitionLabel`、`definitionChart`、`definitionDataSource`、`definitionText`。
- i18n 键：
  - 按钮与列标签：`salesAnalytics.definitionTip.*`
  - 出库进度正文：`salesAnalytics.stockOutProgressDefinition.{chart,dataSource,text}`

### 2.3 详情弹窗

**打开参数：** 继承页面 `buildQuery()`（`viewLevel`、`departmentId`、`salesUserId`、`dateFrom`、`dateTo`）。

**信息栏（顶部）：**

| 展示项 | 来源 |
|--------|------|
| 视角 | `query.viewLevel` → `salesAnalytics.tabs.company/department/personal` |
| 统计区间 | `dateFrom`～`dateTo`；缺省显示「起不限 / 止不限」 |
| 提示 | 「按销售订单创建日期；与页面顶部筛选一致」 |

**列表字段顺序：** 销售订单明细（编号，可新标签打开 `/sales-order-items?sellOrderItemCode=`）→ 订单创建日期 → 客户（权限门控）→ 业务员 → 物料型号 → 品牌 → 订单数量 → 订单明细出库状态。

**拖拽 / 缩放：**

| 能力 | 实现要点 |
|------|----------|
| 拖拽 | 标题栏拖动；写对话框 `left`/`top`，避免与 EP `draggable` 的 transform 叠用 |
| 缩放 | 右 / 下 / 右下角手柄；`minWidth`≈960、`minHeight`≈420；body 内 flex，表格 `height:100%` 内滚 |
| 打开时 | `fitDialogToContentWithRetry` 钉住初始高度与位置，避免缩放后再拖错位 |

### 2.4 后端 API

| 方法 | 路径 |
|------|------|
| GET | `/api/v1/analytics/sales/breakdowns/stock-out-progress/detail` |

查询参数：与销售分析公共筛选一致，另加 `stockOutProgressStatus?`、`page`、`pageSize`。

响应要点：

- `summary`：始终三档（0/1/2），缺档 `count=0`，带 `ratio`
- `items`：当前页明细行（含客户名等字段）
- `canViewCustomer`：前端是否展示客户列
- Tab 传 `stockOutProgressStatus` 时只过滤 `items`，不改写 `summary`

实现入口：`SalesAnalyticsController` → `SalesAnalyticsService` / `SalesAnalyticsQuery.GetStockOutProgressDetailAsync`。

### 2.5 扩展约定

后续其它分解图若增加「口径」：

1. 在帮助「分解」表维护图 / 数据源 / 口径说明；
2. 增加对应 i18n 段（勿读 help 文件）；
3. 在页面按 `groupKey` 打开 `showDefinition` 并传入三段文案。

「详情」弹窗按图独立组件或通用明细抽屉扩展，保持信息栏展示视角 + 统计区间。
