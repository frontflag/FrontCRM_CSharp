## 1. 需求

在物流分析增加 **出入库概况** 两张金额卡：

| 卡 | 语义 |
|----|------|
| 入库金额 | 趋势区间内、已过账的**采购入库**行金额 |
| 出库金额 | 趋势区间内、**出库完成**的**销售出库**行金额 |

与「在库概览」正交：在库是截至日时点存量；本板块是趋势区间内的仓库单据流量。

折算美金采用 **方案 B（过账快照）**：入库 `PurchasePriceUsd × 入库数量`；出库 `SalesPriceUsd × 出库数量`。不用查询日财务汇率回算。

---

## 2. 口径

### 2.1 日期

| 筛选项 | 参数 | 本板块 |
|--------|------|--------|
| 趋势开始 | `dateFrom` | 含当日 |
| 趋势结束 | `trendDateTo`（未传回落 `dateTo`） | 含当日；查询用 `< 次日 UTC 零点` |
| 截至日期 | `dateTo` | **不**用于本板块（仍用于在库/库龄） |

入库日期字段：`stock_in.StockInDate`。  
出库日期字段：`stock_out.StockOutDate`（标记完成时必填；空日期不计入）。

入库数量趋势与本板块共用 `dateFrom`～`trendDateTo`。

### 2.2 入库金额

| 项 | 规则 |
|----|------|
| 单据 | `stock_in` 未删除；`Status = 2`（已过账）；类型采购 `10` 或历史 `1` |
| 行 | `stock_in_item` 未删除；数量取行 `Quantity`（不是在库剩余） |
| 原币 | `Quantity × (行 Price，为 0 时回落 stock_item.PurchasePrice)`，按行币别分档 |
| USD | `Quantity × stock_item.PurchasePriceUsd` |
| 库存类型 | 经 `stock_item.StockType`（与页面全部/客单/备货一致；样品仅「全部」） |
| 权限 | 入库单列表数据范围 + 与在库相同的视角透镜 |

不含报关/退货/报废/调拨入库。

### 2.3 出库金额

| 项 | 规则 |
|----|------|
| 单据 | `stock_out` 未删除；`Status = 4`（出库完成）；类型销售 `10` 或历史 `1` |
| 行 | `stock_out_item` + `stock_out_item_extend` 未删除；数量取 `stock_out_item.Quantity` |
| 原币 | `Quantity × (extend.SalesPrice>0 ? SalesPrice : 行 Price)`，按销售币别分档 |
| USD | `Quantity × (extend.SalesPriceUsd ?? 0)`；快照为空则该行美金为 0 |
| 库存类型 | 经关联 `stock_item.StockType` |
| 权限 | 出库单列表数据范围 + 与在库相同的视角透镜 |

**不含**状态 2「准备出库」。因此本卡 **不等于** 销售分析「已出库金额」（后者按销售订单创建日、数量含 2\|4、美金为 `qty × convert_price`）。

不含报关/退货/报废/调拨出库。

### 2.4 脱敏

| 卡 | 条件 | 结果 |
|----|------|------|
| 入库金额 | `PurchaseSensitiveFieldMask511` 或无 `purchase.amount.read` | `maskAmounts`，金额 `—` |
| 出库金额 | `SaleSensitiveFieldMask521` 或无 `sales.amount.read` | `maskSalesAmounts`，金额 `—` |

两卡独立脱敏。

## 3. 实现索引

| 层 | 路径 |
|----|------|
| DTO | `LogisticsAnalyticsFlowDto`（`dashboard.flow`） |
| Scope | `TrendDateTo`、`MaskSalesAmounts` |
| Query | `LogisticsAnalyticsQuery.BuildFlowAsync` |
| 页面 | `LogisticsAnalyticsPage.vue` 板块「出入库概况」 |
| 下钻 | `logisticsAnalyticsDrill.ts` → 入库单列表 / 出库明细列表 |

下钻带趋势日期；入库带 `stockInType=10`（列表将历史类型 1 一并视为采购）；出库带 `status=4` 与 `stockOutType=10`（出库明细列表将历史类型 1 一并视为销售）。列表无库存类型筛时，结果可能比 KPI 略宽（见 QA 已知差异）。
