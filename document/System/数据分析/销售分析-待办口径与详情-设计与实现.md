## 1. 需求设计

| 按钮 | 行为 |
|------|------|
| **口径** | Tip 三行标签对齐帮助「待办」表头：**指标** / **数据源** / **口径说明**（首行值为指标名，勿用分解图的「图」）；文案 i18n，不读 help md |
| **详情** | **新标签**打开对应业务列表（复用既有下钻路由）；**不**新建详情 API / 弹窗 |

### 1.1 「口径」Tip 标签来源（对齐帮助表头）

帮助页：`help/pages/销售分析_MENU_SALES_ANALYTICS.md` →「概况 → 待办」表。总规见 [数据看板总要求 §3.9](../../IMP/数据看板/数据看板总要求.md)。

| Tip 左侧标签 | 来源 | i18n |
|--------------|------|------|
| **指标** | 帮助待办表 **第一列标题**（非分解表「图」） | `salesAnalytics.definitionTip.metric` |
| **数据源** | 帮助待办表第二列标题 | `salesAnalytics.definitionTip.dataSource` |
| **口径说明** | 帮助待办表第三列标题 | `salesAnalytics.definitionTip.definition` |

| Tip 右侧内容 | 来源 | i18n（示例） |
|--------------|------|----------------|
| 首行值 | 该卡对应「指标」列单元格 | `todoReceivableDefinition.chart` 等（字段名历史为 chart，语义为指标名） |
| 数据源值 | 「数据源」列单元格 | `*.dataSource` |
| 口径说明值 | 「口径说明」列单元格 | `*.text` |

| 待办项 | 详情目标 |
|--------|----------|
| 待核销应收款 | 应收款列表，`onlyOpen=1`（`finance_receivable` Σ `verified_to_be`，与列表看板「待核销应收款」同源） |
| 待出库明细数 | 销售订单明细，`stockOutPending=1` |
| 待开票金额 | 销售订单明细，`invoicePending=1` |

整卡点击下钻取消，仅「详情」触发，避免与「口径」冲突。详情显示受权限与金额脱敏约束（与原 `isTodoDrillable` 一致）。

**金额展示（对齐应收款列表看板）：** 应收款 / 待开票返回 `SalesAnalyticsMoneyDto`（`totalUsd` + `byCurrency[]`）；前端 `layout=split`：左侧折算美金，右侧原币分档（RMB / USD …）。折算优先明细 `convert_price/price`，否则用查询日财务汇率。

**样式（与概况已出库/已收款、应收款看板共用 `AnalyticsKpiGrid`）：**

| 项 | 约定 |
|----|------|
| 左侧主金额 | 「折算美金」小标题 + 主数字 **18px**（`.kpi-value--split-money`） |
| 右侧列顶标签 | 币别字母灰色次要文案（不上币别色） |
| 右侧金额尾缀 | 三位币别字母用系统标准色（`listAmountCurrencyDockClass` / `.dock-tier-ccy*`） |
| 总规 | [数据看板总要求 §3.8](../../IMP/数据看板/数据看板总要求.md)；[金额与币别范式 §5.2](../../PRD/规范/UI规范/金额与币别代码显示范式.md) |

概况「已出库金额 / 已收款金额」：主数字同成单（折算美金 + 可选后缀）；原币进标签行 **查看本币** Tip（左侧标签灰、行尾币别上色）。
