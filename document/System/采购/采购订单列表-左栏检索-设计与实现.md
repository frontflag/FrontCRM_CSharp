## 1. 业务定位

采购订单**主表**列表左栏「检索」页签填入与明细列表同款 **preset 快捷检索**（原先该页签为空）。主栏仍保留订单号 / 供应商 / 采购员 / 货代单号 / 备注 / 订单类型。

| 概念 | 说明 |
|------|------|
| **preset 单选** | 五组：时间 / 待办 / 文档 / 付款 / 入库；分组标题不可点；再点同一项或主栏 chip ✕ → **清空全部 query** |
| **keyword 叠加** | 订单号、供应商、采购员、货代单号、备注、**订单类型**可与 preset 同时生效 |
| **状态/日期互斥** | 有 preset 时主栏隐藏状态多选与创建日期；无 preset 时展示 |
| **看板一致** | 列表与看板共用筛选，analytics 传 `quickFilter` / 日期 / keyword / `orderType` |
| **粒度** | 列表一行一单。行级 preset 为 **EXISTS：该单至少有一行**满足明细列表同口径 |

---

## 2. preset 列表

分组、preset ID、文案与明细列表相同（`PurchaseOrderItemListQuickFilterCodes`）。

| 类型 | 订单列表口径 |
|------|----------------|
| 时间 | 前端展开 `startDate`/`endDate`（主单 `CreateTime`） |
| `pending_submit_audit` | 主单 status **新建 / 待审核 / 审核失败**（1 / 2 / -1） |
| `pending_vendor_confirm` | 主单 status **待确认**（20） |
| `pay_later` | 主单 `IsPayLater` |
| `has/no_purchase_order_docs` | 订单头 `PURCHASE_ORDER` 未删除附件 |
| 其余业务项 | 明细 `ApplyQuickFilter` 命中的行 → `PurchaseOrder.Id` EXISTS |
