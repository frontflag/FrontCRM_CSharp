## 1. 业务定位

采购订单**主表**列表右栏增加「操作」页签，只展示明细操作面板的前两张卡：**采购订单**、**文档**。一行一单，不含明细行级申请付款 / 到货通知。

| 概念 | 说明 |
|------|------|
| **页签** | `r-ops` / 帮助；进入列表默认 **操作** |
| **单击门控** | 与明细列表 §2.4 相同（`useListRightOpsPanelInteraction`） |
| **详情页** | 不改；详情「操作」仍是点明细行后的行级面板 |

---

## 2. 卡片

| 卡片 | 口径 |
|------|------|
| 采购订单 | 编号（链到详情）+ 主单状态；审核通过 / 待确认时状态后浅灰斜体「（等待供应商确认）」；下一行供应商中/英文名 |
| 文档 | 复用 `SalesOrderOpsDocumentsCard`，`bizType=PURCHASE_ORDER`、`bizId` 为订单 Id；mask511 不显示 |

列表行字段：`id` / `purchaseOrderCode` / `status` / `vendorName` / `vendorEnglishName`。

---

## 3. 实现要点

| 层 | 路径 |
|----|------|
| 面板 | `CRM.Web/src/components/purchaseOrder/PurchaseOrderOpsPanel.vue` |
| store | `CRM.Web/src/stores/purchaseOrderOpsPanel.ts` |
| 布局 | `AppLayout`：`PurchaseOrderList` 注册 `r-ops`，默认 `r-ops`；旧记忆「帮助」进页改为操作；`v-if` 挂载以免在帮助页签下拉文档 |
| 列表 | `PurchaseOrderList.vue`：§2.4；刷新 `clear` |

文档接口与明细同一套 `documentApi.getDocuments`，无新后端。
