## 1. 目标

三租户打印采购订单报表时，**版式语言与配色**与同租户 Packing / Invoice / 销售订单报表一致。

非目标：列表页皮肤；外贸 PURCHASE CONTRACT 列结构改版（另议）。

---

## 2. 架构

| 层 | 说明 |
|----|------|
| 租户来源 | `VITE_TENANT_ID` → `LOGIN_TENANT_ID` |
| 皮肤选择 | `resolvePurchaseOrderReportSkin`（与 Packing 映射相同） |
| 数据 | 既有 `docBind`（卖方=供应商、买方=我方、印章在买方侧） |
| 版式 | 三套皮肤 + 共用 `PurchaseOrderReportBody` |

```
PurchaseOrderReportPage
  → resolvePurchaseOrderReportSkin(LOGIN_TENANT_ID)
  → PurchaseOrderReportSkin{Semicore|Idesemi|Ecoinf}
```

---

## 3. 关键文件

| 路径 | 职责 |

| `.../purchaseOrderReport/types.ts` | props |

---

## 4. 皮肤差异摘要

| 租户 | 皮肤 | 主题要点 |
|------|------|----------|
| semicore | Idesemi | 深色顶栏 `#0D1F35`、强调 `#020612` |
| idesemi | Ecoinf | 大标题左、青竖条 `#6DC5F6` |
| ecoinf | Semicore | 绿表 `#A8D070`、公司名 `#101010` |

与 SO 差异：三栏文案为「卖方 / 买方 / 交付」；印章在 **Buyer** 侧；确认语为 24 小时合同确认。

明细表只打印实际行；**不补空白行、不显示「以下空白」**。无明细时显示「暂无明细」。

---

## 5. 验证要点

- 同租户 PO 与 Packing 页眉色系一致；打印/PDF/邮件三皮肤可用。
