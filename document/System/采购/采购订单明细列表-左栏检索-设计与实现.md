## 1. 业务定位

左栏提供 **preset 快捷检索**，覆盖主栏不便表达的业务视角条件；与主栏 keyword、看板 **共用 URL query**。

| 概念 | 说明 |
|------|------|
| **preset 单选** | 四组：时间 / 待办 / 付款 / 入库；再点同一项或主栏 chip ✕ → **清空全部 query** |
| **keyword 叠加** | 「采购订单/明细号」（主单号或明细号 OR 模糊）、货代单号、供应商、采购员、型号、币别、订单类型可与 preset 同时生效；列表已去掉「销售订单明细单号」筛选项 |
| **进度/日期互斥** | 有 preset 时主栏隐藏日期 + 四维进度；无 preset 时展示 |
| **筛选页签模式** | 齿轮可将币别/订单类型/进度下拉改为单维度页签；preset 时隐藏进度页签与菜单项，币别与订单类型可保留（见 [筛选页签模式](./采购订单明细列表-筛选页签模式-设计与实现.md)） |
| **看板一致** | 列表与看板共用筛选，analytics 传 `quickFilter` / 日期 / keyword |
| **时间 preset** | 仅展开 `startDate/endDate`（主单创建日），**不过滤状态** |
| **业务 preset** | 排除主单或明细 `status = -2`（取消） |

## 2. preset 列表

### 2.1 时间（前端展开）

| preset ID | 含义 | API |
|-----------|------|-----|
| `order_today` | 今日订单 | `startDate/endDate` = 今日 |
| `order_today_yesterday` | 今昨订单 | 昨日～今日 |
| `order_last_7_days` | 近 7 日 | 往前 6 天～今日 |
| `order_last_30_days` | 近 30 日 | 往前 29 天～今日 |
| `order_this_week` | 本周订单 | 周一～今日 |
| `order_this_month` | 本月订单 | 1 日～今日 |

### 2.2 业务（后端 `quickFilter`）

| preset ID | 文案 | 口径摘要 |
|-----------|------|----------|
| `pending_submit_audit` | 待提交审核 | 主单 `status ∈ {1,2,-1}` |
| `pending_vendor_confirm` | 待供应商确认 | 主单 `status = 20` |
| `pending_submit_payment_request` | 待提交付款申请 | 主单 `=30`；对齐申请付款可申请条件（忽略权限） |
| `pending_submit_arrival_notify` | 待提交到货通知 | 主单 `=30`；`QtyStockInNotifyNot > 0` |
| `pay_later` | 后付款订单 | 主单 `is_pay_later`；只排除取消 |
| `confirmed_unpaid` | 已确认，未付款 | 主单 `=30` + `paymentProgressStatus=0` |
| `stocked_in_unpaid` | 已入库，未付款 | `stockIn≥1` + `payment=0`；只排除取消 |
| `payment_partial` / `payment_complete` | 部分/付款完成 | `payment=1` / `=2`；只排除取消 |
| `confirmed_pending_stock_in` | 已确认，未入库 | 主单 `=30` + `stockIn=0` |
| `paid_pending_stock_in` | 已付款，待入库 | `payment=2` + `stockIn<2`；只排除取消 |
| `stocked_in` | 已入库 | `stockIn∈{1,2}`；只排除取消 |

「已确认」= 主单状态字面 **已确认**（`status = 30`）。
