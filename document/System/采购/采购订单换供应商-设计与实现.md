# 采购订单换供应商 / 刷新供应商 — 设计与实现

**状态：** 已上线（对齐销售订单「刷新客户」口径）  
**页面：** 采购订单编辑 `/purchase-orders/:id/edit`  
**对照：** [销售订单下游客户同步-设计与实现](../销售/销售订单下游客户同步-设计与实现.md)

---

## 1. 目标

以采购订单 **`vendor_id`**（或编辑时的拟换供应商）为准：

1. **刷新订单头 `vendor_name` / `vendor_code` 快照**（供应商主数据 `OfficialName ?? NickName` / `Code`）；明细列表读头快照，故一并纠正。
2. 将**未完结**下游供应商 ID/名称同步为订单目标供应商；**已完结且供应商不一致**的单据阻断。
3. **编辑换供应商（方案 A）**：确认后一次保存（头 + 明细 + 未完结下游），失败整单失败；取消确认则不保存。

---

## 2. 权限

| 方式 | 说明 |
|------|------|
| RBAC | `purchase-order.change-vendor`（见 `scripts/ensure_purchase_order_change_vendor_permission_postgresql.sql`） |
| 角色 | 系统管理员；或采购侧总监同等判定 |
| 数据范围 | 须通过 `CanAccessPurchaseOrderAsync` |

后端：`PurchaseOrderVendorChangeAccessRules`；前端：`canChangePurchaseOrderVendor()`。

「刷新」供应商名称与换供应商使用同一权限门控（不再仅限 sysadmin）。

---

## 3. API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/purchase-orders/{id}/change-vendor/preview?newVendorId=` | 预检（换 ID 或同 ID 刷名称） |
| PUT | `/api/v1/purchase-orders/{id}` body 含 `vendorId` | 换供应商一步 Apply（与编辑保存同一入口） |
| POST | `/api/v1/purchase-orders/{id}/refresh-vendor-name` | 按已落库 `vendor_id` 刷头名称 + 未完结下游 |

预检字段：`poVendorNameToSync`（0/1）、`sameVendorId`、下游同步计数、`blockingDocuments`。

---

## 4. 下游分界

| 下游 | 同步 | 阻断（仅当供应商 ID 与目标不一致） |
|------|------|--------------------------------------|
| 到货通知 | 未入库；ID 不一致或名称快照过期 | `status = 100` 已入库且 ID 不一致 |
| 入库单 | 未过账且 ID 不一致 | 已过账且 ID 不一致 |
| 付款单 | 未完成；ID 不一致或名称过期 | 已付款且 ID 不一致 |
| 进项发票 | 未认证/未冲红；ID 不一致或名称过期 | 已认证/已冲红且 ID 不一致 |

同供应商 ID、仅名称过期：已完结下游**不阻断**头名称刷新；已完结单据上的名称快照本版不回写（与 SO 不改正完结下游 ID 一致）。

---

## 5. 前端交互

### 5.1 编辑页换供应商

| 时机 | 行为 |
|------|------|
| 改供应商（未保存） | 防抖预检，页顶 tip 仅提醒（不同步） |
| 保存且供应商相对原单变更 | 再预检 → 阻断则停并提示「当前无法保存供应商资料」；可同步则确认「刷新并保存」/「取消」 |
| 确认刷新并保存 | `PUT` 带 `vendorId`；后端一步写头+下游 |
| 取消确认 | 留在编辑页，**不保存** |

### 5.2 详情页刷新供应商（同 ID，对齐销售「刷新客户」）

详情页：`刷新 ▾` → **刷新供应商** → 预检 → 确认 → `refresh-vendor-name`（头名称 + 未完结下游）。  
编辑页不再提供字段旁「刷新」入口（与销售编辑页对称）。

## 7. 业务规则

- 换供应商后**主状态不回退**。
- 新供应商不得为黑名单 / 禁用 / 已删 / `PENDING` / 手工占位 ID。
- 换 ID 时原 `vendor_contact_id` 不属于新供应商则**清空**；仅刷名称不清空联系人。
- 明细 `vendor_id` 与主表不一致时纳入同步。
