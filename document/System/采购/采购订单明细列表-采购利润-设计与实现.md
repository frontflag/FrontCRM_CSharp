# 采购订单明细列表 — 采购利润 — 设计与实现

**状态：** 已上线  
**页面：** 采购订单明细列表（含备货采购清单共用列、导出 CSV）  
**EBS 对照：** [PurchaseOrderItemExtend 统计字段](../../EBS/采购/PurchaseOrderItemExtend统计字段文档.md) §7.1（EBS 为销售总额 − 采购总额；本列不沿用）  
**关联：** 销售订单明细上的 `PurchaseProfitExpected` 为销售行粒度，与本列不同

---

## 1. 业务口径

列表在 **明细总额** 之后增加 **采购利润**（USD）：

```
采购利润 = (销售折算美金单价 − 采购折算美金单价) × 采购明细数量
```

| 项 | 取值 |
| --- | --- |
| 销售折算美金单价 | 关联 `sellorderitem.convert_price` |
| 采购折算美金单价 | 本行 `purchaseorderitem.convert_price` |
| 采购明细数量 | 本行 `qty`（与列表「数量」列相同） |

结果四舍五入到 **2 位**（`AwayFromZero`）。采购价高于销售价时为负数。

无法计算时显示 **—**（不要写成 0）：

- 无 `sell_order_item_id`（备货/样品/手工行）
- 任一侧折算美金单价缺失或 ≤ 0

**不做：** 看板 KPI / 分解 / 排行；不写入 `purchaseorderitemextend`。

## 2. 权限

仅跟 **采购金额** 权限（与单价、明细总额相同：`purchase.amount.read`，511 脱敏时隐藏）。不要求销售金额权限。
