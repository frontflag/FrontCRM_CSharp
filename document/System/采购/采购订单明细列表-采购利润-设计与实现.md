## 1. 业务口径

列表在 **明细总额** 之后增加 **采购利润**（USD）：

```text
采购利润 = (销售折算美金单价 − 采购折算美金单价) × 本行采购数量
```

| 项 | 取值 |
| --- | --- |
| 销售折算美金单价 | 本行 `sell_order_item_id` 对应 `sellorderitem.convert_price` |
| 采购折算美金单价 | 本行 `purchaseorderitem.convert_price` |
| 采购数量 | 本行 `qty`（与列表「数量」列相同） |

结果四舍五入到 **2 位**（`AwayFromZero`）。采购价高于销售价时为**负数**。

无法计算时显示 **—**（不要写成 0）：

- 无 `sell_order_item_id`（备货 / 样品 / 手工行）
- 任一侧折算美金单价缺失或 ≤ 0

关联方向：一条采购明细最多一条销售明细；一条销售明细可对应多条采购。本列按**本条采购**现算，不把兄弟采购行算进来。

**不做：** 看板 KPI / 分解 / 排行；不写入 `purchaseorderitemextend`；不改销售行 `PurchaseProfitExpected`。

---

## 2. 权限

仅跟 **采购金额** 权限（与单价、明细总额相同）。511 脱敏或无金额查看权限时隐藏本列（导出对应单元格为空）。**不要求**销售金额权限。无新权限码、无迁移。

## 3. 出现位置

| 表面 | 行为 |
|------|------|
| 采购订单明细列表 | 金额权限下，在「明细总额」后显示；看板不含此列 |
| 备货采购清单 | 同一列定义；备货行通常无销售关联，多为 **—** |

| 采购订单审核 | 同一公式；有 tip。见审批桌面 §3.2（tip 文案用「销售单价折算USD / 采购单价折算USD」） |

## 5. 已知口径差异

| 对象 | 差异 |
|------|------|
| EBS 采购明细扩展 `ProfitExpected` | 销售总额 − 采购总额 |
| 销售明细 `PurchaseProfitExpected` | 销售数量 × 销售折算美金单价 − Σ（各关联采购数量 × 采购折算美金单价） |
| 审核 tip 文案 | 界面写「销售单价折算USD − 采购单价折算USD」，取值仍是两侧 `convert_price` |
