## 1. 入口

| 项 | 说明 |
|----|------|
| 主菜单 | 参数管理 → **报表参数**（位于「财务参数」之后、组内最后一项） |
| 路径 | `/system/report-params` → 默认 `/system/report-params/global` |
| 布局 | 左栏参数分类 + 右栏内容（对齐销售/采购/财务参数） |

左栏本期仅一项：**报表全局参数**。

---

## 2. 报表全局参数

| 字段 | 说明 |
|------|------|
| 报表样式版本 | `el-select`：`V1` / `V2` |
| 存储 | `sysparam.ParamCode = System.Report.StyleVersion`（String） |
| 默认 | 无行或非法值视为 **V1** |
| PUT 非法值 | 400，文案「报表样式版本仅允许 V1 或 V2」 |
| API（管理） | `GET` 需 `report.global.read`；`PUT` 需 `report.global.write` → `/api/v1/report-params/style-version` |
| API（打印） | `GET /api/v1/report-params/effective-style-version`：任意登录可读，返回规范化 V1/V2 |

### 消费范围

- **采购订单打印**已读生效版本：V2 **仅 semicore 租户**换新版式；idesemi / ecoinf 仍为各自 V1。版式见 [报表规范-采购订单-V2](../../PRD/规范/业务规范/报表规范-采购订单-V2.md)。
- **装箱单打印**已读生效版本：V2 **仅 semicore** 换新版式（竖版 9 列中英、横版 14 列英文）；idesemi / ecoinf 仍为各自 V1。版式见 [报表规范-装箱单-V2](../../PRD/规范/业务规范/报表规范-装箱单-V2.md)。
- 销售订单、发票、`report-bundle`、抬头选择 **仍不读** 该值。
- 与公司信息中的报表备注、抬头、印章 **互不影响**。
- 打印账号通常无参数管理权限，故不得要求 `report.global.read` 才能出单。
