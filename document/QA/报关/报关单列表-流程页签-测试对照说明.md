## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有报关模块访问（财务 / 物流 / 管理员）打开报关单列表 | 右栏为 **操作 + 流程 + 帮助**，默认 **操作** |
| 打开报关单详情 | 同一套右栏，默认 **操作**；页内「业务记录」仍在 |
| 无报关模块访问 | 不能进入列表/详情；`GET .../flow-aggregates` 403 |
| 无 `customer.read` | 客户名称不可点，纯文本 |

本功能不适用：无独立 write 权限码控制流程页签只读；操作按钮仍走物流写权限（见操作面板对照说明）。

---

## 二、工作台门控（列表）

| 步骤 | 预期 |
|------|------|
| **A** 收起右栏后单击行 | 不展开、不请求 `flow-aggregates`、不请求报关详情 |
| **B** 展开 →「帮助」→ 单击行 | 高亮；不切页签；无流程/详情请求 |
| **D** 再点「流程」 | 请求 `GET /api/v1/customs-declarations/{id}/flow-aggregates` |
| **C** 已在「流程」下单击另一行 | 立即请求并刷新地铁轴 |
| 已在「操作」下单击行 | 请求报关详情，不打 flow-aggregates |
| **F** 列表刷新 | 操作/流程面板清空，需重新选行 |
| 双击行 | 进入报关单详情 |

详情：进入页同步当前报关单到操作 store；切到「流程」才拉聚合。刷新后右栏默认页签按工作台记忆，非法则回落 `r-ops`。

---

## 三、站序与当前站

| 步骤 | 预期 |
|------|------|
| 选中一张报关单并打开「流程」 | 10 站：销售订单明细 → 销售出库通知 → 待报关 → 报关出库通知 → 报关装箱 → **报关** → 报关出库 → 报关到货通知 → 报关质检 → 报关入库 |
| 当前站 | 「报关」标题旁橙色左指手势；轨道为状态色圆点；无「我在此」文字胶囊 |
| 拣货 | **不出现**拣货站 |
| 下游未发生 | 空心「未开始」 |
| 一张报关单多行明细 | 销售明细 / 销售出库通知 / 待报关 / 报关出库通知 **同站多卡**，按创建时间升序；装箱、报关各 1 卡 |
| 仅一行装箱 | 上游各站 1 卡（1:1 合法） |

## 四、字段与视觉

| 步骤 | 预期 |
|------|------|
| KV | 值不折行，过长省略号 |
| 单号 | 默认同正文色、无下划线；悬停橙色；点击跳转（521 时不可点） |
| 创建日期 | `yy-MM-dd`（如 `26-08-01`） |
| 销售明细客户 | 通栏 `{名称} ({编号})`；有权限可点新开客户详情 |
| 报关当前站 | **无客户**；有报关公司名称 |
| 数量标签 | 销售侧「销售出库数量」；报关出库通知/装箱/报关出库「报关出库数量」；到货/质检用本站名；入库「报关入库数量」 |
| 出入库类型 | 报关出库/装箱/报关出库通知、报关入库出 `StockBizTypeTag`；类型为报关且有报关单 ID 才出海关图标 |
| 描述 | 不展示或始终空 |

---

## 五、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 521 | 流程仍加载；客户名/编号、销售单价为 `—`；报关公司仍显示 |
| 511 | 流程仍加载；到货成本单价不展示 |
| 下游 | 到货/质检/入库只出现 **本报关单** 明细绑定的单据，不串其它报关单 |

## 九、回归 / 交叉

| 步骤 | 预期 |
|------|------|
