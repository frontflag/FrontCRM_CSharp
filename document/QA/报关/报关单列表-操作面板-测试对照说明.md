# 报关单列表 — 右侧操作面板 — 测试对照说明

> **页面：** `/customs-declarations`（以实际路由名为准）  
> **设计文档：** [报关单列表-操作面板-设计与实现](../../System/报关/报关单列表-操作面板-设计与实现.md)  
> **门控规范（权威）：** [销售操作面板 §2.4](../../System/销售订单明细列表-操作面板-设计与实现.md)

交互门控与销售订单明细列表相同（A～F）；加载接口为报关单详情（`loadDetail`）。

| 步骤 | 预期 |
|------|------|
| **A** 收起右栏后单击行 | 不展开、不请求报关详情 |
| **B** 展开 →「帮助」→ 单击行 | 高亮；不切页签；无详情请求 |
| **D** 再点「操作」 | 加载该单概况 / 海关状态 / 到货通知卡片 |
| **C** 已在「操作」下单击另一行 | 立即请求并刷新面板 |
| **F** 列表刷新 | 面板清空，需重新选行 |
| 双击行 | 进入报关单详情 |
