# 报关明细列表 · 流程页签 — 测试对照说明

> **页面 / 路由：** `/customs/declaration-items`（`CustomsDeclarationItemList`）  
> **设计文档：** [报关明细列表-流程页签-设计与实现](../../System/报关/报关明细列表-流程页签-设计与实现.md)  
> **UI 规范：** [流程页签规范](../../PRD/规范/UI规范/流程页签规范.md)、[流程页签.当前业务指示规范](../../PRD/规范/UI规范/流程页签.当前业务指示规范.md)  
> **上线：** 须重启 API 后 `GET /api/v1/customs-declaration-items/{id}/flow-aggregates` 才可用。无新增 SQL、无权限脚本。

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 打开报关明细列表 | 右栏为「流程」「帮助」，默认停在「流程」 |
| 无报关模块访问权 | 流程聚合 403，与报关单流程相同 |
| 本页 | 无操作页签，不能在右栏设置海关状态或生成到货通知 |

本功能不适用：无独立 write 权限码控制流程页签。页签只读。

## 二、单击门控

| 步骤 | 预期 |
|------|------|
| 右栏收起时单击一行 | 不请求 `flow-aggregates` |
| 右栏展开且停在「帮助」时单击一行 | 行高亮，仍停在帮助，不请求聚合 |
| 切到「流程」 | 再请求当前行聚合 |
| 右栏展开且已在「流程」时单击一行 | 请求该行聚合；当前站为「报关」，旁有当前业务指示 |
| 刷新页面 | 右栏默认页签按工作台记忆；重新查询列表后已选流程行清空 |
| 双击一行 | 仍进入该行报关单详情 |

## 三、本行收口

同一张报关单至少两行明细。在「流程」页签分别单击这两行。

| 步骤 | 预期 |
|------|------|
| 站序 | 销售订单明细 → 销售出库通知 → 待报关 → 报关出库通知 → 报关装箱 → 报关 → 报关出库 → 报关到货 → 报关质检 → 报关入库 |
| 销售明细、销售出库通知、待报关、报关出库通知 | 只有本行那一张；另一行的单号不出现 |
| 装箱、报关 | 两行看到同一张装箱单、同一张报关单。报关站数量是整单申报数量合计 |
| 报关出库 | 只挂本行拣货明细对应的出库单。本行没有拣货明细时该站为未开始 |
| 到货、质检、入库 | 只挂本行下游；另一行的到货 / 质检 / 入库不出现 |
| 空站 | 仍画出，文案为「未开始」 |

卡片状态是业务文案，不显示状态码。报关站卡片作废仍写「作废」。

## 四、站点章

本功能不适用：金额提交的足额成功与超额拒绝。站点章只读，口径同 [报关单列表-流程页签-测试对照说明](./报关单列表-流程页签-测试对照说明.md) 第十节，但只按本行未删除单据判断。

| 步骤 | 预期 |
|------|------|
| 本行出库单为准备出库 | 报关出库站为进行中；卡片为「准备出库」 |
| 本行出库单为出库完成 | 该站为已完成 |
| 本行销售明细未取消，且收款、开票都完成 | 销售订单明细站为已完成；卡片仍为「正常」 |
| 报关单流程已完成 | 报关站为已完成 |
| 报关单作废 | 报关站为已取消；卡片为「作废」 |

## 五、脱敏

| 步骤 | 预期 |
|------|------|
| 账号带 521 | 聚合仍加载；客户、销售单价显示 `—` |
| 账号带 511 | 聚合仍加载；到货成本单价显示 `—` |
| 报关公司 | 不因 511 被遮住 |

## 六、多租户 / 打印

本功能不适用：无打印、无租户报表皮肤。
