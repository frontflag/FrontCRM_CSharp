> **设计文档：** [报关已完成补杂费商检-设计与实现](../../System/报关/报关已完成补杂费商检-设计与实现.md)  
> **实施方案：** [报关已完成补杂费商检-实施方案](../../实现方案/报关已完成补杂费商检-实施方案.md)

> **权限 / DDL：** 无新权限码、无迁移。管理员判定与采购美金价更正相同（系统管理员 / 平台管理员）。须部署含本改动的 API + Web 并刷新前端。

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有物流写权限、报关单未完成且未结关 | 费用面板可维护汇率、税率、杂费、商检 |
| 已结关锁定、未完成、关务（非管理员） | 杂费、商检可改；汇率/税率/采购美金价只读 |
| 已完成、关务（非管理员） | 整表只读（含杂费、商检）；保存/试算不可用 |
| 已完成、系统管理员或平台管理员 | 杂费、商检、采购美金价可改并保存；汇率、税率、HS 仍只读 |
| 已作废 | 仍不可改 |
| 511 采购脱敏 | 金额列为 `—`；面板仍能打开；管理员补费入口按脱敏规则隐藏采购美金价 |

本功能不适用：无独立菜单；不新增权限码。本功能不适用工作台左栏队列、列表页签模式、操作面板 §2.4 门控（费用在详情页内）。

## 二、不要回退海关状态

| 步骤 | 预期 |
|------|------|
| 已完成 + 已结关单，任何人改海关状态为「未维护」 | 拒绝（如「报关单已完成，不能修改海关状态」） |
| 管理员补杂费后 | 海关状态仍为 **已结关**；流程状态仍为 **已完成** |

---

## 三、已完成补杂费 / 商检（管理员）

前置：报关单已完成、已结关、已有到货通知（可用 `CDS00009` 类）；杂费当前为 0。

| 步骤 | 预期 |
|------|------|
| 管理员改行杂费（如 0 → 100）并保存 | 成功；价税总额增加 100；成功提示列出回写到货/入库/库存条数（有下游则 >0） |
| 到货通知成本单价、报关入库明细单价、库存采购价 | 等于新含税单价 P1 |
| 仅补商检费（如 0 → 80）并保存 | 成功；价税总额与 P1 **不变**；下游条数为 0 或等值跳过 |
| 变更日志 | 出现行「杂费」或「商检费」，对象 `{单号}-L{行号}`，原值/新值正确，操作人为登录账号 |
| 管理员同时改采购美金价与杂费 | 一次保存后费用链与下游均按新值 |
| 非管理员改杂费（抓包 PATCH `otherFee`） | 拒绝，文案含系统管理员或平台管理员 |
| 任何人改关税率 / HS | 仍拒绝「已完成报关单不能修改明细」 |

---

## 四、已结关锁定、未完成（关务可改）

| 步骤 | 预期 |
|------|------|
| 关务改杂费并保存 | 本单价税含杂费；已生成到货/入库/库存的含税单价同步为新 P1 |
| 仅改商检 | 本单商检更新；P1 与下游不变 |
| 改关税率 | 仍拒绝锁定文案 |

---

## 五、口径 / 公式核对

```text
价税总额 = 货款 + 关税 + 增值税 + 代理费 + 杂费
含税单价 P1 = 价税总额 / 申报数量
商检费不进入价税总额，不进入 P1
```

| 步骤 | 预期 |
|------|------|
| **足额：** 杂费从 0 改为 100.00 保存 | **成功**；价税新值 = 旧价税 + 100.00（2 位） |
| **足额：** 杂费从 100.00 改回 0 | **成功**；价税回落；下游 P1 同步 |
| 杂费为负（界面或 PATCH） | **拒绝**（「杂费不能为负数」）；价税与下游不变 |
| 商检费为负 | **拒绝**；价税不变 |
| 商检 80 与杂费 0 | 价税与 P1 相对补前不变 |

本功能不适用：核销/匹配提交的「略超一个最小货币单位拒绝」「分次核销至清零」。无待核销余额。
