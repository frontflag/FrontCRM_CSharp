## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 已完成或已结关锁定 + 系统管理员/平台管理员 | 代理费率旁可见 **刷新自报关公司** |
| 同上 + 关务（非管理员） | **无**该按钮；抓包 `refreshAgencyRateFromBroker=true` → 拒绝（无权） |
| 处理中、未锁定、费用可维护 | **无**该按钮（普通保存即可带入主数据费率） |
| 已作废 | 无按钮；API 刷新 → 拒绝「报关单已作废」 |
| 无物流写 / 无报关模块访问 | 不可维护费用；无刷新入口 |
| 511 采购脱敏 | 代理费率显示 `—`；刷新按钮不展示（与脱敏一致） |

本功能不适用：无独立菜单；不新增权限码。本功能不适用工作台左栏队列、列表页签模式、操作面板 §2.4 门控（费用在详情页内）。

## 二、刷新成功路径（管理员）

前置：如 `CDS00002` — 已完成 + 已结关；单头历史代理费率 `1.025000`；绑定报关公司主数据 `1.003000`；已有到货/入库下游更佳。

| 步骤 | 预期 |
|------|------|
| 页头代理费率 | 显示 `1.025000`，旁注 **(历史参数)**；可提示公司当前 `1.003000` |
| 点 **刷新自报关公司** | 确认框展示从 `1.025000` → `1.003000`，并说明将重算且回写到货/入库/库存 |
| 确认 | 成功；页头代理费率 → `1.003000`，仍旁注 **(历史参数)**；明细代理费、价税、P1 按新费率重算 |
| 成功提示 | 含到货通知 / 入库明细 / 库存层回写条数（有下游则合计 > 0） |
| 到货通知成本、报关入库单价、库存采购价 | 等于新含税单价 P1 |
| **变更日志** | 必有一条「刷新代理费率自报关公司」，旧值 `1.025000`、新值 `1.003000`，操作人为登录账号 |
| 海关状态 / 流程状态 | 仍为已结关 / 已完成（不回退） |

## 三、草稿门控与「费率已相同」

| 步骤 | 预期 |
|------|------|
| 已改杂费或手工采购美金价未保存，再点刷新 | **不调用**刷新；提示先保存或放弃其它修改 |
| 单头费率已与主数据同为 `1.003000`，再点刷新并确认 | **允许**；仍重算并可回写；变更日志仍写一条动作（旧值=新值均为 `1.003000`） |

---

## 四、与普通「保存」的交叉

| 步骤 | 预期 |
|------|------|
| 刷新成功后，管理员再改杂费并保存 | 代理费率仍为已刷新的主数据值（**不**被改回旧历史）；杂费进价税并回写下游 |
| 刷新成功后，管理员改采购美金价并保存 | 代理费率快照仍保留（`preserveAgency`）；仅采购美金价/费用链变化 |
| 未刷新前：管理员仅改采购美金价保存 | 代理费率保持原历史快照（如 `1.025000`），与刷新前行为一致 |

## 五、口径 / 公式核对

```text
代理费 = (报关货款 + 关税 + 增值税) × (代理费率 − 1)
价税总额 = 货款 + 关税 + 增值税 + 代理费 + 杂费
含税单价 P1 = 价税总额 / 申报数量
```

刷新后代理费率取报关公司主数据（如 `1.003` → 纯费率 `0.003`）。

| 步骤 | 预期 |
|------|------|
| **足额成功：** 历史 `1.025` 刷新为公司 `1.003` 并确认 | **成功**；代理费 = Round2((货款+关税+增值税)×0.003)；价税与 P1 同步；下游含税单价 = 新 P1 |
| **足额成功：** 刷新后公式演示⑤代入页头费率 | 与表格代理费一致（无「与报关费用列表不一致」） |
| **拒绝：** 非管理员 `refreshAgencyRateFromBroker=true` | 失败；单头费率与明细、下游均不变 |
| **拒绝：** 已作废单刷新 | 失败；无变更日志新动作 |
| **拒绝：** 报关公司主数据代理费率 &lt; 1 | 失败（「报关公司代理费率无效」）；单头不变 |

本功能不适用：核销/匹配「略超一个最小货币单位拒绝」「分次核销至清零」。无待核销余额。金额类「足额」对应「按合法主数据费率刷新成功」；「超额/非法」对应无权、作废、主数据费率无效等拒绝。
