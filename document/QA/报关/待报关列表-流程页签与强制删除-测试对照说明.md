# 待报关列表 · 流程页签与强制删除 — 测试对照说明

**关联设计：** [待报关列表-流程页签与强制删除-设计与实现](../../System/报关/待报关列表-流程页签与强制删除-设计与实现.md)

## 流程页签

- [ ] `/customs/pendlists` 右侧有「流程」「帮助」；默认可落到「流程」
- [ ] 右栏收起时单击行：不请求 flow-aggregates
- [ ] 右栏展开且在「流程」：单击行加载地铁轴；主节点为「待报关列表」，轨道为状态色圆点，标题旁为醒目橙色、指向左的手势图标（无「我在此」文字胶囊）
- [ ] 上游顺序：销售订单明细 → 出库通知(销售) → 待报关；上游无分支
- [ ] 销售出库通知已删的孤儿行：出库通知站显示「已删除」；待报关主节点仍可展示
- [ ] 下游可空心「未开始」；有单据时出现小卡（报关出库/装箱/拣货/出库/报关/到货/质检/报关入库）
- [ ] 「报关出库通知」小卡有 pendlist Id；「待报关」主卡与列表列无 Id
- [ ] 列表主区不出现 pendlist Id 列

## 强制删除

- [ ] 非管理员看不到「强制删除」
- [ ] 管理员点强制删除：弹窗展示完整 Id，须原样输入才成功
- [ ] Open 且无下游：删除成功，列表消失
- [ ] 已有报关出库通知 / 装箱 / 报关明细：拒绝并提示下游
- [ ] 强制删除销售出库通知后，关联待报关不再以 Open 残留（同步取消+软删）
