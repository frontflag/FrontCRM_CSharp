# 报关单列表 — 筛选页签模式 — 测试对照说明

> **页面：** `/customs/declarations`  
> **设计文档：** [报关单列表-筛选页签模式-设计与实现](../../System/报关/报关单列表-筛选页签模式-设计与实现.md)

---

## 一、入口

| 步骤 | 预期 |
|------|------|
| 进入页面（未开过页签） | 无页签条；搜索栏显示报关类型 / 流程状态 / 海关状态下拉 |
| 点搜索栏齿轮（非底栏列设置） | 「关闭页签」禁用；「页签模式 ▸」含三项：报关流程状态、报关类型、海关状态 |

---

## 二、开启与切换

| 步骤 | 预期 |
|------|------|
| 页签模式 → 报关流程状态 | 流程状态下拉隐藏；页签 5 格：全部 / 待处理 / 报关中 / 已完成 / **作废** |
| 点「作废」 | 立即查询；列表仅作废 |
| 再开「报关类型」 | 流程状态下拉恢复（值可保留）；类型下拉隐藏；页签：全部 / 进口 / 出口 |
| 再开「海关状态」 | 类型下拉恢复；海关状态下拉隐藏；页签：全部 / 未维护 / 放行 / 已结关 |
| 点「未维护」 | 能筛到 clearance=0（勿与「全部」混淆） |
| 关闭页签 | 页签消失；对应下拉恢复且值保留 |

---

## 三、与「查询」按钮 / 即查

| 步骤 | 预期 |
|------|------|
| 未开页签时改下拉或日期 | 仍立即查询（现网行为保留） |
| 点页签 | **立即**请求 |
| 本版不改日期控件形态 | 日期仍为原 daterange |

---

## 四、持久化与主题

| 步骤 | 预期 |
|------|------|
| 开启某维度后 F5 | 仍为该维度页签 |
| 亮色未选中页签 | 约 `#E8EDF5` |
| 暗色未选中页签 | 深色层，不发白 |

---

*文本筛选与日期控件改造不在本版范围。*
