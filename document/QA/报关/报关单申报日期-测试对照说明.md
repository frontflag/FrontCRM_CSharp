# 报关单申报日期 — 测试对照说明

> **页面 / 路由：** 报关管理 → 报关单 `/customs/declarations`；报关单详情；报关明细 `/customs/declaration-items`；出库通知列表右栏「报关单」；报关入库详情  
> **设计文档：** [报关单申报日期-设计与实现](../../System/报关/报关单申报日期-设计与实现.md)  
> **帮助：** [报关单](../../../help/pages/报关单_MENU_CUSTOMS_DECLARATIONS.md)  
> **权限：** 沿用报关模块访问 + 物流数据范围；**无新权限码。**

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有报关模块权限进入报关单列表 | 可见「申报日期」列与日期筛选 |
| 无报关模块权限 | 不能进入报关单 / 报关明细 |
| 物流数据范围为「仅本人」 | 只出现范围内的报关单；本口径不扩大可见行集 |

---

## 二、展示口径

对照同一张 **报关出库装箱** 及其 **报关出库单**（出库类型=报关出库）。

| 步骤 | 预期 |
|------|------|
| 仅拣货生成报关单，装箱尚未点出库 | 列表 / 详情 / 操作面板概况 / 报关明细该行申报日期均为 **—** |
| 装箱已点「出库」，出库单状态为「准备出库」 | 申报日期仍为 **—**（不要出现生成日或预计出库日期） |
| 出库单「标记完成」，状态为「出库完成」 | 申报日期 = 该出库单列表上的 **出库日期**（实际出库日期），同一天 |
| 标记完成弹窗里把实际出库日期填成非当天 | 申报日期跟所填那天，不是点按钮的系统当天 |
| 完成后在出库单头改出库日期 | 报关单界面申报日期跟着变 |
| 强制删除该出库单或状态离开「出库完成」 | 申报日期回到 **—** |

Network：`GET /api/v1/customs-declarations`、`GET /api/v1/customs-declarations/{id}`、`GET /api/v1/customs-declaration-items` 的 `declareDate`；未完成时为 `null`，界面 **—**。

出库通知右栏「报关单」页签、报关入库详情摘要与上表同一口径。

---

## 三、筛选

| 步骤 | 预期 |
|------|------|
| 不填申报日期区间 | 未完成与已完成的报关单都可出现（受其它条件约束） |
| 填申报日期从～至 | 只出现出库完成且出库日期落在区间内的报关单；未完成的 **筛不出来** |
| 区间与出库单列表按出库日期筛选同一天 | 能对上同一张报关出库单 |

---

## 四、口径 / 公式核对

```text
申报日期 = 报关装箱对应报关出库单（类型 20）状态=出库完成(4) 时的 StockOutDate
否则空
```

手工复算：打开出库单列表，筛该装箱 / 报关出库，看状态与「出库日期」。不要用报关单生成日、装箱预计出库日期。

---

## 五、数据范围与回归

| 步骤 | 预期 |
|------|------|
| 报关单列表单击行 → 操作面板概况 | 申报日期与列表该行一致 |
| 双击进详情 | 与列表一致 |
| 报关明细列表同行 | 与报关单头一致 |
| 物流控制台近 30 天「报关」条数 | 按本口径日期落入近 30 天的 **报关明细行**；仅生成、未出库完成的不计 |
| 历史已有报关单 | 改版后未标记完成的从「生成日」变为 —；已标记完成的变为出库日期 |

---

## 六、本功能不适用

- **本功能不适用：§4.5 核销金额足额成功 / 超额拒绝**（本功能只改日期展示与筛选，不提交核销/匹配）。
- **本功能不适用：工作台 / 桌面左栏队列（§4.3）**。
- **本功能不适用：操作面板门控（§4.4）**（单击拉面板的门控见操作面板对照；本功能只改概况里的日期值）。
- **本功能不适用：页签模式持久化**（申报日期不是页签维度；页签见筛选页签对照）。
- **本功能不适用：多租户打印皮肤（§4.6）**。
- **本功能不适用：金额脱敏 / 511**（日期不跟金额权限）。
