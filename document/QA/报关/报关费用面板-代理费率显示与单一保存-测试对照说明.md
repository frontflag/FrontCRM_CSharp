# 报关费用面板 — 代理费率显示与单一保存 — 测试对照说明

> **页面 / 路由：** `/customs/declarations/:id`（报关单详情 → 「报关费用」）  
> **设计文档：** [报关费用方案](../../System/报关/报关费用方案.md)  
> **实施方案：** [报关费用面板-代理费率显示与单一保存-实施方案](../../实现方案/报关费用面板-代理费率显示与单一保存-实施方案.md)  
> **权限 / DDL：** 无新权限码、无迁移。须部署含本改动的 Web 并刷新详情页。后端试算与结关锁定不在本版改动范围。

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有物流写权限、处理中、费用可维护 | 费用区只有 **保存**，没有「试算费用」。缺汇率、缺采购系数、或缺 P0 且未填合法手工采购美金价时，保存禁用 |
| 已结关锁定、内部状态未完成、非管理员 | 只有 **保存**。不因缺 P0 / 缺汇率禁用。保存只提交杂费、商检费 |
| 已结关锁定、管理员且采购字段未脱敏 | 只有 **保存**。保存提交改动并整单重算，代理费率快照不被报关公司当前费率覆盖 |
| 内部状态已完成、非管理员 | 费用区无保存按钮 |
| 内部状态已完成、管理员且采购字段未脱敏 | 只有 **保存**。保存后整单重算，保留原代理费率快照 |
| 已作废 | 无保存按钮 |
| 无物流写入权限 | 无保存按钮 |

本功能不适用：无独立菜单；不新增权限码。本功能不适用工作台左栏队列、列表页签模式、操作面板 §2.4 门控（费用在详情页内）。

## 二、代理费率显示

页头「代理费率」只读，6 位小数，右侧「等价 n%」，再后接来源说明 **(当前参数)** 或 **(历史参数)**。

| 步骤 | 预期 |
|------|------|
| 尚未保存过费用（试算时间为空） | 显示该报关公司**当前**费率，旁注 **(当前参数)**。公司主数据改费率后重新打开，页头变为新费率，仍为 **(当前参数)** |
| 已保存过费用 | 显示这张单保存时写入的费率，旁注 **(历史参数)**。不跟后来改过的报关公司主数据。与当前费率数字相同仍标 **(历史参数)** |
| `CDS00001` | 页头 **1.025000**（等价 2.50%）**(历史参数)**。报关公司当前若为 1.003000，页头仍为 1.025000 |
| 费率为 1.000000 | 正常显示 1.000000，等价为「—」（费率为 1 时百分比提示为 —）。来源说明仍按上两行 |
| 采购敏感字段脱敏 | 代理费率显示「—」，不显示数字，也不显示 (当前参数) / (历史参数) |

## 三、保存按钮

| 步骤 | 预期 |
|------|------|
| 处理中可维护的单，改汇率或税率后点保存 | 成功提示「费用试算成功」（有下游回写时带条数）。试算时间出现。页头代理费率变为本次保存写入的费率，旁注由 **(当前参数)** 改为 **(历史参数)**。明细货款、关税、增值税、代理费、价税总额更新 |
| 已结关、未完成、非管理员，只改杂费后保存 | 提示「费用已保存」。价税总额与含税单价含新杂费；已有到货、入库、库存按新含税单价更新。代理费率与代理费金额不变 |
| 已结关、未完成、非管理员，只改商检费后保存 | 提示「费用已保存」。价税总额与含税单价含新商检；代理费金额不变。已有到货、入库、库存按新含税单价更新 |
| 已完成或已锁定、管理员点保存 | 整单重算成功。单头代理费率仍是保存前的快照，不改成报关公司当前费率。报关汇率不变。锁图标见下一节 |
| 已作废 | 无保存按钮。三项都有锁，见下一节 |
| 处理中可维护 | 三项都不加锁，见下一节 |

「采用财务汇率」仍在报关汇率旁边。点后只填入数字，提示未保存、请点保存。

## 四、头区锁图标

锁表示这次保存**不会改**数据库里的这一列。不加锁表示这一列**会被更新**。页头数字可以不是最终写入的值。价税合计不加锁。

鼠标悬停锁图标：报关汇率为「保存不会修改报关汇率」，代理费率为「保存不会修改代理费率」，采购系数为「保存不会修改采购系数」。

| 步骤 | 报关汇率 | 代理费率 | 采购系数 |
|------|----------|----------|----------|
| 处理中、有写入权限、可整单重算（含缺 P0、保存暂时禁用） | 无锁。汇率改过再保存，库中汇率变为页面上的数 | 无锁。保存后单头费率变为报关公司当前费率，旁注改为 **(历史参数)** | 无锁。若旁注「当前参数…，保存后覆盖历史」，保存后明细采购系数变为该当前系数，不再是页头原先显示的旧数 |
| 已完成、能整单重算、单头费率大于 0。用 `CDS00001`（费率 1.025000） | 有锁。保存后汇率仍为保存前的数 | 有锁。保存后仍为 1.025000，不是报关公司当前 1.003000 | 无锁。保存后明细采购系数变为当前生效采购系数 |
| 已结关、未完成、不能整单重算，只保存杂费或商检费 | 有锁。汇率不变 | 有锁。代理费率与代理费金额不变 | 有锁。采购系数不变 |
| 已结关、未完成、能整单重算、单头费率大于 0 | 有锁 | 有锁。快照不被当前费率覆盖 | 无锁。采购系数变为当前生效系数 |
| 已作废 | 有锁 | 有锁 | 有锁。无保存按钮 |
| 无写入权限，单据仍在处理中 | 有锁 | 有锁 | 有锁。无保存按钮 |
| 已完成、不能整单重算 | 有锁 | 有锁 | 有锁。无保存按钮 |
| 已完成或已锁定、能整单重算，但单头代理费率不是大于 0 的数 | 有锁 | 无锁。保存后单头费率变为报关公司当前费率 | 无锁 |
| 代理费率为 1.000000 的已完成单，能整单重算 | 有锁 | 有锁。1 表示 0% 代理费，仍算已有费率 | 无锁 |

本功能不适用：工作台左栏队列（§4.3）。锁图标在报关单详情费用区，不是审批桌面。

## 五、口径 / 公式核对

```text
代理费 = (报关货款 + 关税 + 增值税) × (页头代理费率 − 1)
价税总额 = 报关货款 + 关税 + 增值税 + 代理费 + 杂费 + 商检费
含税单价 = 价税总额 ÷ 数量
杂费、商检费都不进入代理费基数
```

已保存单据的页头费率必须等于算出表格代理费的那个费率。

| 步骤 | 预期 |
|------|------|
| **足额：** `CDS00001` 展开「计算公式说明」并点「演示」 | 页头 1.025000。⑤ 代理费 = (12,441.34 + 0.00 + 1,617.37) × (1.025000 − 1) = **351.47**，与表格一致，不标「与报关费用列表不一致」。汇率、数量、杂费与表格一致时，⑥ 价税总额 **14,410.18**、⑦ 含税单价 **46.484452** 同样不标色 |
| 尚未保存费用的新单点「演示」 | 页头为报关公司当前费率。表格金额可能仍为空或 0，允许标「与报关费用列表不一致，列表数值=…」 |
| 已保存的单改了汇率但还没点保存，再点「演示」 | 货款等步骤可标「与报关费用列表不一致，列表数值=…」。这是未保存草稿和已保存结果的差异 |

本功能不适用：核销/匹配提交的「略超一个最小货币单位拒绝」「分次核销至清零」。本页不提交核销，没有待核销余额。代理费按已保存费率足额算出即成功。

## 六、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 打开报关单详情 | 只显示本单费率与费用，不串其它报关单 |
| 采购字段脱敏 | 代理费率、金额列为「—」，不显示 (当前参数) / (历史参数)；面板仍能打开 |

本功能不适用：部门数据权限额外裁剪（报关单详情已按模块访问进入）。

## 七、回归 / 交叉

| 步骤 | 预期 |
|------|------|
| 结关后非管理员补杂费 | 仍只改杂费/商检并回写下游，与 [报关已完成补杂费商检](./报关已完成补杂费商检-测试对照说明.md) 一致 |
| 管理员更正采购美金价 | 原路径仍可用，保存后重算 |
| 列表操作页签「下一步」 | 待完成费用时引导去详情 **保存** 报关费用，不再写「试算费用」按钮 |
| 多租户打印皮肤 | 本功能不适用（无打印改动） |

已知口径差异：报关公司主数据费率可以晚于本单已保存费率。页头以本单已保存费率为准，不自动改成主数据。这是本版要保留的差异，不是缺陷。
