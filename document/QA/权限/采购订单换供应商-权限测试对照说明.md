# 采购订单换供应商 — 权限测试对照说明

> **业务文档：** [采购/采购订单换供应商-测试对照说明.md](../采购/采购订单换供应商-测试对照说明.md) §一
> **页面 / 路由：** `/purchase-orders/:id/edit`；详情 `/purchase-orders/:id`
> **所需权限：** `purchase-order.write`、换供应商特权（审核后）、本单数据范围、非采购脱敏身份

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 采购员（有采购订单写权限、无换供应商特权）打开 **新建 / 待审核 / 审核失败** 单的编辑页 | 可搜索更换供应商 |
| 同上账号打开 **审核通过及之后** 的编辑页 | **不能**换供应商（只读展示） |
| 系统管理员 / 采购总监 / 持有换供应商特权的账号，审核通过后的编辑页 | 仍可换（下游完结规则见业务文档第二节） |
| 采购脱敏账号（销售方向且主部门采购数据禁止） | 编辑页无供应商搜索；改供应商接口 403 |
| 无采购订单写权限 | 不可保存；预检/刷新接口 403 |
| 待审核单上采购员换供应商后，审批桌面打开该单 | **按最新供应商**展示与调查，不是提交当时的旧供应商 |

**数据范围：** 只能改本人数据范围内的采购订单。
