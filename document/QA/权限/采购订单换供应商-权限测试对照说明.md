## 一、入口与权限

供应商与**供应商联系人**同一门控（编辑页搜索框是否可点）。预检接口 `GET /api/v1/purchase-orders/{id}/change-vendor/preview` 失败文案为「当前无权更换供应商」；前端可能包成标题「下游供应商预检失败」。

| 步骤 | 预期 |
|------|------|
| 采购员（有采购订单写权限、无换供应商特权）打开 **新建 / 待审核 / 审核失败** 单的编辑页 | 可搜索更换供应商与联系人 |
| 同上账号打开 **审核通过及之后** 的编辑页 | **不能**换供应商/联系人（只读展示）；预检 403 |
| **SYS_ADMIN** 打开任意状态编辑页（含主部门为销售部） | 可换供应商与联系人；预检 200 |
| **SYS_MANAGER**（产品 Admin，如账号 Admin、主部门销售部、部门角色可为销售总监）打开任意状态编辑页 | 可换供应商与联系人；预检 **不**再 403「当前无权更换供应商」 |
| **采购部总监**（主部门 IdentityType=2 + DEPT_DIRECTOR）审核通过后的编辑页 | 可换供应商与联系人 |
| **采购运营部总监**（主部门 IdentityType=3 + DEPT_DIRECTOR）审核通过后的编辑页 | 可换供应商与联系人 |
| 仅销售部总监（DEPT_DIRECTOR + 主部门销售，无 SYS_ADMIN / SYS_MANAGER） | **不能**换 |
| 仅 **SYS_BIZ_MANAGER**（产品 Manager，非上述四类）审核通过后 | **不能**换；预检 403 |
| 持有显式 `purchase-order.change-vendor` 的账号，审核通过后 | 可换 |
| 采购脱敏账号（销售方向且主部门采购数据禁止；非 SYS_ADMIN / SYS_MANAGER） | 编辑页无供应商搜索；改供应商接口 403 |
| 无采购订单写权限 | 不可保存；预检/刷新接口 403 |
| 待审核单上采购员换供应商后，审批桌面打开该单 | **按最新供应商**展示与调查，不是提交当时的旧供应商 |
| 详情页审核通过后：SYS_MANAGER / SYS_ADMIN / 两总监 | 「刷新 ▾」含「刷新供应商」且可执行 |
| 详情页审核通过后：普通采购员 | 无「刷新供应商」或接口 403 |

**数据范围：** 只能改本人数据范围内的采购订单。

**本功能不适用：** 金额核销/匹配足额与超额（§4.5）；看板公式；工作台左右栏队列；列表页签模式 / 左栏检索 / 操作面板门控；多租户打印皮肤。
