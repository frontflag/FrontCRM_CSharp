## 一、导出日志

**所需权限：** `system.logs.export.read`

| 步骤 | 预期 |
|------|------|
| 有导出日志查看权限 | 系统日志下可见「导出日志」，可进入列表 |
| 无该权限、有操作日志权限 | 可见操作日志，**无**导出日志菜单；直接打开 `/system/export-logs` 被拒 |
| 无操作日志权限、有导出日志权限 | 可进导出日志；操作日志菜单不可见 |
| 无 write | 本页无写操作，有 read 即可查看 |

## 二、报表参数

**所需权限：**
- 侧栏：`system.params.report.read`
- 页内：`system.params.report.global.read` / `.write`

| 步骤 | 预期 |
|------|------|
| 有报表参数查看权限（SYS_ADMIN / SYS_MANAGER 默认有） | 参数管理组内可见「报表参数」，排在「财务参数」之后、组内最后 |
| 进入报表参数 | 左栏有「报表全局参数」；右栏为样式版本下拉 |
| 无侧栏/页内 read | 参数管理中无「报表参数」；直接打开 `/system/report-params/global` 被拒 |
| 有 read、无 write | 可看当前版本；下拉禁用；无「保存」按钮；「刷新」仍可用 |
| 有 write | 可改 V1/V2 并保存 |

## 三、申请公司邮箱

**权限说明：** 登录即可申请；**不**新增权限码、**不**改表。复用 `user_feedback` / `ai_assistant_session`。

| 步骤 | 预期 |
|------|------|
| 任意已登录用户打开「我的邮箱」 | 能看本人邮箱列表；无额外邮箱权限 |
| 无「反馈问题」权限的普通员工 | 仍能看到「申请公司邮箱」并提交成功（不要求反馈助手权限） |
| 未登录直打申请接口 | 401 |

## 四、控制台待办 — 设置我的邮箱

**所需权限：** 登录即可；按个人邮箱设置实现。

| 步骤 | 预期 |
|------|------|
| 已登录用户打开控制台「设置我的邮箱」待办 | 可进入并完成邮箱设置 |
| 未登录用户直打接口 | 401 |
