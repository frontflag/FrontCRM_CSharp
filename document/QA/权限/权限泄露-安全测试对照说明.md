# 权限泄露 — 安全测试对照说明

> **目标**：验证 RBAC 与数据范围在边界、绕过、组合、缓存、直接 API 访问等场景下不会导致越权或数据泄露。
> **关联文档**：
> - [RBAC权限体系-权限测试对照说明.md](./RBAC权限体系-权限测试对照说明.md)
> - [PRD/RBAC权限系统PRD.md](../../PRD/RBAC权限系统PRD.md)
> - [System/管理角色三级-设计与实现.md](../../System/管理角色三级-设计与实现.md)

## 一、测试策略

| 维度 | 关注点 | 主要风险 |
|------|--------|----------|
| 水平越权 | 同角色用户访问他人数据 | 数据范围未生效、ID 遍历 |
| 垂直越权 | 低权限用户访问高权限功能 | 前端隐藏但 API 未鉴权 |
| 数据范围绕过 | 范围=1/2/3 的用户看到范围外数据 | 过滤条件缺失、缓存未清 |
| 跨租户隔离 | 多租户间数据/配置/菜单串用 | TenantId 缺失 |
| 敏感字段泄露 | API 返回被脱敏字段、列表返回全量字段 | 返回 DTO 未裁剪 |
| 附件泄露 | 通过对侧附件 ID 直接下载 | 未校验业务类型与范围 |
| 路由/菜单泄露 | 隐藏菜单仍可通过 URL 访问 | 前端隐藏但路由未拦截 |
| 权限缓存/生效时间 | 修改权限后旧权限仍可用 | 会话未刷新 |
| 参数篡改 | 通过改 userId/deptId/orderId 越权 | 未做资源归属校验 |
| 批量操作越权 | 批量选择他人数据执行删除/编辑/导出 | 未逐条校验 |

## 十五、自动化测试建议

## 十六、测试 checklist

- [ ] 每个业务实体均测试「自己 / 同部门 / 子部门 / 其他部门 / 禁止」五种范围
- [ ] 每个敏感操作均测试「有 read 无 write / 有 write 无 read / 完全无权限」三种状态
- [ ] 每个隐藏菜单均测试直接访问 URL
- [ ] 每个列表/详情/导出/附件接口均测试数据范围
- [ ] 每个管理角色均测试业务 bypass 与系统权限的边界
- [ ] 权限变更后均测试重新登录前后的差异
- [ ] 测试结束后清理测试数据，避免污染其他用例
