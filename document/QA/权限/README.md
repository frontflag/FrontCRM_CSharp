## 维护规则

1. 业务测试文档中「入口与权限」章节的详细用例，应逐步迁移到本目录对应文件中。
2. 业务文档保留核心结论和编号引用，不再重复展开权限用例表格。
3. 新增跨域权限功能时，在本目录新增独立文档，并同步更新 [测试文档目录.md](../测试文档目录.md)。
