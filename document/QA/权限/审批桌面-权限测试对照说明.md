# 审批桌面 — 权限测试对照说明

> **业务文档：** [审批/审批桌面-测试对照说明.md](../审批/审批桌面-测试对照说明.md) §一
> **页面 / 路由：** `/approval-desktop`；入口页 `/pending-approvals`
> **权限说明：** 登录即可进待审批与审批桌面；通过/拒绝仍受各业务 `canDecide` / 后端 decide 校验

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 待审批页右上角「进入审批桌面」 | 进入 `/approval-desktop`；左栏待审队列、中栏表单、右栏参考页签 |
| 待处理列表操作「审核」 | 进入桌面并选中该条；左栏「待审核」滚到该记录 |
| 待处理列表操作「仅查看」 | 进入桌面并选中该条；表单只读，不能通过/拒绝 |
| **待处理分段双击一行** | 与「审核 / 仅查看」相同：进入桌面并开始审该条（有权限可决定，无权限只读） |
| 已通过 / 已拒绝分段双击一行 | **不**进审批桌面，打开对应业务详情 |
| 仅登录、无对应业务写权限 | 可进桌面看队列；对该条只能「仅查看」，decide 被后端拒绝 |
| 销售总监（销售部 + 部门总监）提交自己的客户或销售订单 | 待处理显示「审核」；可在桌面通过/拒绝；接口不返回「不能审批本人…」 |
| 销售经理或销售员工提交自己的客户或销售订单 | 待处理为「仅查看」；decide 返回不能审批本人提交的客户/销售订单 |
| 采购总监（采购或采购运营部 + 部门总监）提交自己的供应商或采购订单 | 待处理显示「审核」；可在桌面通过/拒绝；接口不返回「不能审批本人…」 |
| 采购经理或采购员工提交自己的供应商或采购订单 | 待处理为「仅查看」；decide 返回不能审批本人提交的供应商/采购订单 |
| 销售总监提交自己的供应商或采购订单 | **仍不能**自审（例外只覆盖客户与销售订单） |
| 采购总监提交自己的客户或销售订单 | **仍不能**自审（例外只覆盖供应商与采购订单） |
| 非系统管理员提交自己的付款 | 待处理为「仅查看」；不能通过/拒绝 |
| 系统管理员提交自己的任意待审类型 | 待处理为「审核」；可在桌面通过/拒绝 |
| 收款 | 待审批业务类型与桌面队列中 **无收款**；历史收款待审不再出现 |

### 1.1 本人提交与总监例外（口径）

身份以 **主部门** `IdentityType` + 组织角色为准（须重新登录后测）：

| 角色 | 主部门身份 | 可自审 |
|------|------------|--------|
| 部门总监 | 销售（1） | 客户、销售订单（业务员 = 本人） |
| 部门总监 | 采购 / 采购运营（2/3） | 供应商、采购订单 |
| 系统管理员 | - | 全部类型 |
| 普通员工 / 经理 | 任何 | 均不可自审 |
