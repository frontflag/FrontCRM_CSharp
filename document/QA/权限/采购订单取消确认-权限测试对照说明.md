# 采购订单取消确认 — 权限测试对照说明

> **业务文档：** [采购/采购订单取消确认-测试对照说明.md](../采购/采购订单取消确认-测试对照说明.md) §一
> **页面 / 路由：** 采购订单列表 `/purchase-orders` 操作列；采购订单详情 `/purchase-orders/:id` 顶栏
> **所需权限：** `purchase-order.write`、本单数据范围

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有采购订单写权限，主状态 **已确认** | 列表操作列与详情顶栏显示「取消确认」 |
| 主状态为待确认 / 审核通过 / 进行中 / 采购完成 / 取消 | **不显示**「取消确认」 |
| 无采购订单写权限 | 不显示；直接 PATCH `status=20` 应 403 |
| 详情「取消订单」 | 仅新建 / 待审核 / 审核失败显示；已确认、待确认均 **不** 显示 |

**数据范围：** 只能操作本人数据范围内的采购订单。脱敏账号仍可操作本按钮（状态字段非金额/客商）。
