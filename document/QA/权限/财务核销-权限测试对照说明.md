## 一、进项发票核销桌面

**所需权限：** `finance-purchase-invoice.read` / `.write`

| 步骤 | 预期 |
|------|------|
| `/finance/purchase-invoices` 右上角 | 「进项发票核销桌面」按钮（样式对齐收款核销桌面） |
| 侧栏「付款管理 → 进项发票核销」 | 进入桌面 |
| 无 `finance-purchase-invoice.read` | 不可进 |
| 无 `.write` | 可看不可提交 |

---

## 二、销项发票核销桌面

**所需权限：** `finance-sell-invoice.read` / `.write`

| 步骤 | 预期 |
|------|------|
| `/finance/sell-invoices` 右上角 | 「销项发票核销桌面」按钮 |
| 侧栏「收款管理 → 销项发票核销」 | 进入桌面 |
| 无 `finance-sell-invoice.read` | 不可进入 |
| 仅 read、无 write | 可看队列与候选；提交按钮禁用或提交被拒 |

---

## 三、收款核销桌面

**所需权限：** 收款管理相关 read / write 权限（按收款核销桌面实现）

| 步骤 | 预期 |
|------|------|
| `/finance/receipts` 标题行右上角 | 有「收款核销桌面」（浅蓝底+箭头，对齐待审「进入审批桌面」）；无「收款核销」旧入口 |
| 点「收款核销桌面」 | 进入桌面；左栏为「待核销客户」 |
| 侧栏「收款管理 → 收款核销」 | 进入 `/finance/receipt-write-off-desktop`（非旧三栏页） |
| 无收款核销权限 | 不可进入或提交被拒 |
