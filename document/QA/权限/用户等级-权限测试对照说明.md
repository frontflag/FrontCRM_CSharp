# 用户等级 — 权限测试对照说明

> **业务文档：** [系统/用户等级-测试对照说明.md](../系统/用户等级-测试对照说明.md) §一
> **页面 / 路由：** 组织管理 → 用户等级 `/system/user-levels`
> **所需权限：** `system.org.users.read` / `system.org.users.write`

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有员工查看权限 | 组织管理下、**员工管理之下**可见「用户等级」，可进入列表 |
| 无员工查看权限 | 无该菜单；直接打开 `/system/user-levels` 被拒 |
| 有 read、无 write | 可看列表与右栏变更日志；**无**「设置等级」按钮/下拉，不能改级 |
| 有 write | 操作列「设置等级」可用；弹窗可改等级与备注 |
| 管理账号策略 | 与员工列表相同：无权维护的管理账号**不出现**在本列表；改级/履历接口对无权对象返回「用户不存在」 |
