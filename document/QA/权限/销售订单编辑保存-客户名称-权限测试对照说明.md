# 销售订单编辑保存 — 客户名称 — 权限测试对照说明

> **业务文档：** [销售/销售订单编辑保存-客户名称-测试对照说明.md](../销售/销售订单编辑保存-客户名称-测试对照说明.md)
> **页面：** `/sales-orders/:id/edit`、`/sales-orders`、`/sales-order-items`
> **所需权限：** 销售订单编辑权限、客户读权限（非 mask521）

---

## 一、前置

- 测试账号具备销售订单编辑与客户读权限（非 mask521）
- 准备至少两个不同客户（A、B），名称在客户档案中可区分
- 浏览器 Network 可查看 `PUT /api/v1/sales-orders/{id}` 请求体

---

## 二、入口与权限

| 步骤 | 预期 |
|------|------|
| 有销售订单编辑权限 | 可打开编辑页并修改客户 |
| 无销售订单编辑权限 | 编辑入口不可见；直接调用 PUT 接口返回 403 |
| 客户读权限被脱敏（mask521） | 客户下拉可能不显示或显示受限；按产品设计验证 |
| 保存时无本单数据范围 | 保存接口 403；本单客户不变 |
