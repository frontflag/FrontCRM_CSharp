# 权限泄露 — 安全测试报告

> **测试依据**：`document/QA/权限/权限泄露-安全测试对照说明.md`（共 106 条用例）

> **测试执行人**：AI 辅助代码审查 + 既有单测执行
> **报告状态**：初版

---

## 一、测试目标

验证 RBAC 与数据范围在以下场景不存在权限泄露：

- 水平越权（同角色用户访问他人数据）
- 垂直越权（低权限用户访问高权限功能）
- 数据范围绕过（Scope 限制被参数/导出/统计等绕过）
- 跨租户隔离
- 敏感字段泄露
- 附件跨业务线泄露
- 路由/菜单/API 泄露
- 权限缓存与生效时间
- 参数篡改
- 批量操作越权
- 管理角色 bypass 边界
- 组合权限边缘场景
- 审批与付款敏感操作

## 七、主要发现与风险

### 7.1 已确认无风险（代码 + 单测支撑）

1. **DataPermissionService 核心过滤逻辑正确**
   - SYS_ADMIN / HasBizDataBypass / 财务身份可 bypass 范围限制
   - Scope=4 时返回空集合
   - Scope=1/2/3 时正确按用户/部门/子部门过滤

2. **RequirePermissionAttribute 基本鉴权正确**
   - 未登录 401、无权限 403、SYS_ADMIN 放行、`rfq.create` 独立校验

3. **附件跨业务线有统一策略**
   - `CrossSideDocumentAttachmentPolicy` 已接入 `DocumentsController`

### 7.2 中高风险（需进一步验证或补充）

| 风险编号 | 风险描述 | 涉及用例 | 建议 |
|----------|----------|----------|------|
| R-01 | **查询参数 userId/deptId 可能被服务层直接读取**，导致范围绕过 | BYP-005、TAMP-001~005 | 统一在 Query/Service 层使用当前用户 ID，禁止读取 DTO/参数中的归属字段；增加集成测试 |
| R-02 | **导出/统计接口可能未复用同一权限过滤**，导致批量泄露 | BYP-006~007、BULK-001~005 | 所有导出/统计入口必须调用 DataPermissionService 或统一 WHERE 条件 |
| R-03 | **搜索建议接口可能未过滤**，返回无权限数据 | BYP-008 | 搜索建议需接入权限范围 |
| R-04 | **敏感字段脱敏调用点不明确**，列表/导出/详情可能遗漏 | FLD-001~006 | 建立统一的响应 DTO 脱敏拦截器或 AOP，确保所有出口调用 FieldMask |
| R-05 | **附件资源归属校验缺失**，同业务线仍可能通过 ID 遍历访问他人附件 | ATT-LEAK-005 | DocumentsController 下载时应校验附件所属单据是否在用户数据范围内 |
| R-06 | **批量接口逐条校验缺失** | BULK-001~005 | 批量操作前必须过滤输入 ID 列表 |
| R-07 | **审批自审规则调用点不明确** | APP-001~006 | 需确认每个审批 decide 入口是否调用 `SalesDirectorSelfApprovalRules` / `PurchaseDirectorSelfApprovalRules` |
| R-08 | **跨租户隔离未评审** | TEN-001~005 | 建议单独进行跨租户安全专项测试 |
| R-09 | **禁用用户后旧 Token 仍可能有效** | CACHE-005、EDGE-008 | 在 JWT 验证中间件中增加用户状态校验，或缩短 Token 有效期 |

## 九、后续建议

1. **补齐集成测试环境**，将 106 条用例中的 P0 项全部端到端执行一遍。
2. **对所有 Controller Action 做权限扫描**：确认每个需要鉴权的接口都已配置 `[RequirePermission]` / `[RequireAnyPermission]` 或 `[Authorize]`。
3. **统一 Query 层权限过滤**：禁止从请求参数读取 `userId`、`departmentId`、`purchaseUserId`、`salesUserId` 等归属字段。
4. **统一响应脱敏**：在 DTO 映射或序列化层接入 `SaleSensitiveFieldMask521` / `PurchaseSensitiveFieldMask511`。
5. **附件下载增加资源归属校验**：`DocumentsController` 下载前校验附件所属业务单据是否在用户数据范围内。
6. **批量操作统一过滤 ID 列表**：所有 `[FromBody] List<string> ids` 接口在执行前调用 DataPermissionService。
7. **审批 Decide 入口接入自审规则**：确认 `SalesDirectorSelfApprovalRules` / `PurchaseDirectorSelfApprovalRules` 被调用。
8. **补充跨租户安全测试**：单独输出测试报告。
9. **JWT 验证增加用户状态校验**：禁用用户后旧 Token 应立即失效。
