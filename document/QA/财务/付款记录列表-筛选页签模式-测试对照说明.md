# 付款记录列表 — 筛选页签模式 — 测试对照说明

> **页面：** `/finance/payments`  
> **设计文档：** [付款记录列表-筛选页签模式-设计与实现](../../System/财务/付款记录列表-筛选页签模式-设计与实现.md)

---

## 一、入口

| 步骤 | 预期 |
|------|------|
| 进入页面（未开过页签） | 无页签条；搜索栏显示状态、付款方式下拉 |
| 点搜索栏齿轮（非底栏列设置） | 「关闭页签」禁用；「页签模式 ▸」含：状态、付款方式 |

---

## 二、开启与切换

| 步骤 | 预期 |
|------|------|
| 页签模式 → 状态 | 状态下拉隐藏；页签 7 格：全部 / 新建 / 待审核 / 审核通过 / 付款完成 / **审核失败** / **取消** |
| 点「取消」 | 立即查询；列表仅取消态（status=-2） |
| 点「审核失败」 | 列表仅审核失败（status=-1） |
| 再开「付款方式」 | 状态下拉恢复；方式下拉隐藏；页签：全部 + 四类方式 |
| 关闭页签 | 页签消失；对应下拉恢复且值保留 |

---

## 三、与「查询」按钮 / 即查

| 步骤 | 预期 |
|------|------|
| 未开页签时改下拉或日期 | 仍立即查询（现网行为保留） |
| 点页签 | **立即**请求 |

---

## 四、持久化与主题

| 步骤 | 预期 |
|------|------|
| 开启某维度后 F5 | 仍为该维度页签 |
| 亮色未选中页签 | 约 `#E8EDF5` |
| 暗色未选中页签 | 深色层，不发白 |

---

*文本筛选与日期控件改造不在本版范围。*
