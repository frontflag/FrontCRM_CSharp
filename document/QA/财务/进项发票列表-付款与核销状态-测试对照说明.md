## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有 read 打开列表 | 可见列：开票状态、发票单号、开票日期、供应商、发票号码、发票金额、核销状态、核销金额、付款状态、付款金额、发票备注、发票类型、创建日期、创建人 |

| 步骤 | 预期 |
|------|------|
| 核销状态 = 未核销 / 部分核销 / 核销完成 | 请求带 `verificationStatus=0/1/2`，结果仅该状态 |

| 清空下拉 | 不再带该参数，列表恢复 |

## 三、口径 / 公式核对

```text
核销金额 = VerifiedDone
核销状态：0 未核销（已核销≤0）；2 核销完成（已核销≥发票金额）；否则 1 部分核销

付款金额 = Σ min(本票核销到该 PO 明细的金额, 该 PO 明细已付)
付款待付 = max(0, 核销金额 - 付款金额)
付款状态相对核销金额：未核销则未付款；付款金额≥核销金额且核销金额>0 → 付款完成
```

| 用例 | 预期 |
|------|------|
| **足额（核销金额 = 发票金额）** | 核销状态 = 核销完成 |
| **足额（付款金额 = 核销金额，且核销金额>0）** | 付款状态 = 付款完成 |
| 略超（核销桌面本次金额 > 待核销） | **拒绝，余额不变**（本页不提交；在 [进项发票核销桌面-测试对照说明](./进项发票核销桌面-测试对照说明.md) 测） |
| 分次核销至清零 | 列表核销状态从部分 → 完成，核销金额累加 |
| 已核销后对应 PO 付清 | 列表付款状态 → 付款完成；付款金额不超过核销金额 |

本页不提交核销/付款金额。超额拒绝以核销桌面为准；本页校验付款金额被钳制为不超过核销金额。
