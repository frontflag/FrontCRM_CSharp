## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 无收款读权限 | 不可进入上述页面 |
| 打开收款记录列表 / 详情，展开右栏 | 页签 **客户 → 帮助**；默认 **帮助**（若无本页记忆） |
| 点「客户」且列表未选行 | 提示单击列表行查看客户 |
| 详情打开后点「客户」 | 无需再点列表行即可出摘要 |
| 能打开该客户详情的账号 | 三块卡片（概况橙色编号 + 基本信息/财务信息标签：值） |
| 无客户模块权限，或客户不在数据范围，或 521 | 仅编号 + 档案业务员；编号不可点 |

刷新后右栏页签记忆与其它扩展页签相同。

---

## 二、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 列表看不到的收款单 | 客户页签 403 或 404，与列表一致 |
| 521 仍能打开的收款单 | 仍可出编号 + 档案业务员；名称/额度不下发 |
| Network | `GET /api/v1/customer-workspace?source=financeReceipt&id=`，**不**带 `customerId` |

---

## 三、门控与空态

| 步骤 | 预期 |
|------|------|
| 停在「帮助」时单击行 | **不**请求客户摘要、**不**自动切到「客户」 |
| 再点「客户」 | 才请求并展示 |
| 右栏收起时单击行 | 不请求客户 |
| 列表搜索 / 重置 / 翻页 / 筛选页签 | 右栏客户回到未选行 |
| 无客户的收款单 | 「该单据未关联客户档案」 |
| 收款核销桌面 | 本批无「客户」页签 |

---

## 四、字段核对（有完整权限时）

与 **客户详情** 对照同一客户：编号、中英文名称、类型/等级/行业、账期、结算币别、信用额度一致。业务员取客户档案，不是收款单上的业务员。

---

## 五、回归 / 交叉

| 步骤 | 预期 |
|------|------|
| 收款列表页签模式（状态 / 用途 / 核销状态） | 筛选与本改动前一致；与右栏客户页签互不影响 |
| 双击行进详情 | 仍进详情；右栏默认帮助 |
| 需求 / 销售 / 履约客户页签 | 不受本批影响 |

---

## 六、本功能不适用

- **本功能不适用：§4.5 核销金额足额成功 / 超额拒绝**（只读展示信用额度，不提交核销）。
- **本功能不适用：多租户打印皮肤**。
- **本功能不适用：工作台左栏队列 / 顶栏 N/M**。
- **本功能不适用：列表页签模式本身**（本页签不改筛选；页签模式回归见上一节）。
- **本功能不适用：收款核销桌面 / 应收台账右栏**（应收列表见 [销项发票与应收款-客户页签-测试对照说明](销项发票与应收款-客户页签-测试对照说明.md)；核销桌面本批不做）。
- **本功能不适用：需求 / 销售 / 履约右栏**（已另有对照说明）。
