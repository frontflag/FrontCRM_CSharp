## 一、入口与权限

权限用例已集中维护于：[权限/财务核销-权限测试对照说明.md](../权限/财务核销-权限测试对照说明.md) §一。

## 二、左栏队列

| 步骤 | 预期 |
|------|------|
| 打开桌面 | 仅「有待核销发票且有待核销入库」的供应商+币别 |
| 卡片字段 | 中文名、英文名、待核销发票总额+币别、条数、最早开票日期；**无采购员** |
| 点击卡片 | 中区加载该桶候选 |
| 搜索 | 过滤左栏；顶栏 N/M 不变 |

---

## 三、核销与明细

| 步骤 | 预期 |
|------|------|
| 单明细入库 | 一行入库单；提交流水含该 `stock_in_item_id` |
| 多明细入库 | 展开多行，各自本次核销；流水按明细落库 |
| 超额 | 拒绝，余额不变 |
| 成功后 | 留在当前供应商+币别；余额与队列刷新 |
| 货代单号 | 有 PO 货代单号时中右/右栏可显示 |
| 采购员 | 中右、右栏显示（来自 PO）；左栏不显示 |

---

## 四、公式核对

```text
明细待匹配 = Amount - Σ流水(stock_in_item_id)
发票待核销 = InvoiceAmount - Σ流水(invoice_id)
头缓存待匹配 = Σ明细待匹配
```
