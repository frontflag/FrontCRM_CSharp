# 收款记录列表 — 筛选页签模式 — 测试对照说明

> **页面：** `/finance/receipts`  
> **设计文档：** [收款记录列表-筛选页签模式-设计与实现](../../System/财务/收款记录列表-筛选页签模式-设计与实现.md)

---

## 一、入口

| 步骤 | 预期 |
|------|------|
| 进入页面（未开过页签） | 无页签条；搜索栏显示状态、**收款用途**下拉 |
| 点搜索栏齿轮（非底栏列设置；非右侧核销/新建） | 「关闭页签」禁用；「页签模式 ▸」含：状态、收款用途 |

---

## 二、开启与切换

| 步骤 | 预期 |
|------|------|
| 页签模式 → 状态 | 状态下拉隐藏；页签 6 格：全部 / 草稿 / 待审核 / 已审核 / 已收款 / **已取消** |
| 点「草稿」 | 立即查询；能筛到 status=0 |
| 再开「收款用途」 | 状态下拉恢复；用途下拉隐藏；页签：全部 / 普通 / 预收 |
| 点「预收」 | 列表仅预收用途 |
| 关闭页签 | 页签消失；对应下拉恢复且值保留 |

---

## 三、与「查询」按钮 / 即查

| 步骤 | 预期 |
|------|------|
| 未开页签时改状态/用途/日期 | 仍立即查询（现网行为保留） |
| 点页签 | **立即**请求 |

---

## 四、持久化与主题

| 步骤 | 预期 |
|------|------|
| 开启某维度后 F5 | 仍为该维度页签 |
| 亮色未选中页签 | 约 `#E8EDF5` |
| 暗色未选中页签 | 深色层，不发白 |

---

*需部署含 `receiptPurpose` 查询参数的 API 后验收用途筛选。*
