## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有 `finance-receipt.read` 进入页面 | 列表可开；无 write 时无新建/确认/取消 |
| 无 read | 菜单不可进或接口 403 |
| 销售敏感掩码账号 | 客户名/金额为 `—`，页签仍可切换并出结果 |
| 进入页面（未开过页签） | 无页签条；搜索栏显示状态、收款用途、**核销状态**下拉；列表有 **核销状态** 列 |
| 点搜索栏齿轮（非底栏列设置；非右侧核销/新建） | 「关闭页签」禁用；「页签模式 ▸」含：状态、收款用途、**核销状态** |

---

## 二、开启与切换

| 步骤 | 预期 |
|------|------|
| 页签模式 → 状态 | 状态下拉隐藏；页签 **4 格**：全部 / 新建 / 确认 / **取消** |
| 点「新建」 | 立即查询；能筛到 status=0（历史 1 迁库后亦为 0） |
| 点「确认」 | 能筛到 status=3 |
| 点「取消」 | 能筛到 status=4 |
| 再开「收款用途」 | 状态下拉恢复；用途下拉隐藏；页签：全部 / 普通 / 预收 |
| 点「预收」 | 列表仅预收用途 |
| 再开「核销状态」 | 用途下拉恢复；核销状态下拉隐藏；页签：全部 / 未核销 / 部分核销 / 核销完成 |
| 点「核销完成」 | 仅整单全部明细为核销完成的收款单；无明细单不出现 |
| 点「未核销」 | 含无明细单，及全部明细未核销的单 |
| 关闭页签 | 页签消失；对应下拉恢复且值保留 |

---

## 三、与「查询」按钮 / 即查

| 步骤 | 预期 |
|------|------|
| 未开页签时改状态/用途/核销状态/日期 | 仍立即查询（现网行为保留） |
| 点页签 | **立即**请求 |

---

## 四、整单汇总口径（抽测）

| 明细情况 | 列表「核销状态」 | 筛「部分核销」 | 筛「核销完成」 |
|----------|------------------|----------------|----------------|
| 无明细 | 未核销 | 否 | 否 |
| 全部 0 | 未核销 | 否 | 否 |
| 全部 2 | 核销完成 | 否 | 是 |
| 一行 0 + 一行 2 | 部分核销 | 是 | 否 |
| 全部 1 | 部分核销 | 是 | 否 |

---

## 五、持久化与主题

| 步骤 | 预期 |
|------|------|
| 开启某维度后 F5 | 仍为该维度页签 |
| 亮色未选中页签 | 约 `#E8EDF5` |
| 暗色未选中页签 | 深色层，不发白 |

---

## 六、本功能不适用

- **本功能不适用：§4.5 核销金额足额成功 / 超额拒绝**（页签只改列表筛选，不提交核销金额；核销见 [收款核销桌面-测试对照说明](./收款核销桌面-测试对照说明.md)）。
- **本功能不适用：审批工作台左栏队列**（收款单已退出待审批）。
- **本功能不适用：多租户打印皮肤**（本页无打印壳层）。
