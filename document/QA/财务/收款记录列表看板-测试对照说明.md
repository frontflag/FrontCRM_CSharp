## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有收款记录列表权限 | 可进入 `/finance/receipts`；搜索栏「查询」后、「设置」齿轮前有 **看板** 按钮 |
| 无对应菜单权限 | 不可进入，与现网一致 |
| 默认 | 列表；顶部四张当前页统计卡可见 |
| 点「看板」 | 按钮文案变为「列表」；顶部统计卡、表格、分页隐藏；出现看板（Tag「筛选」+ KPI + 趋势 + 饼图 + Top10） |
| 再点「列表」 | 回到表格与当前页统计卡 |
| 看板态右侧帮助 | 为收款记录看板说明（非收款记录列表帮助） |
| 列表态右侧帮助 | 恢复收款记录列表帮助 |
| 无 write | 仍可看列表与看板；新建等写入按钮按现网禁用 |

**本功能不适用：** 工作台左栏队列（总纲 §4.3）、多租户打印皮肤（§4.6）、看板写入/提交。

## 二、筛选联动与页签

| 步骤 | 预期 |
|------|------|
| 列表筛状态=确认，再切看板 | 看板只统计确认；Network `finance/receipts/analytics/*` 带 `status=3` |
| 状态不限（全部） | 看板含新建、确认、取消等当前能列出的单（**不**强制只统计确认） |
| 看板下改日期后点查询 | 看板自动刷新；四个 analytics 请求带同一 `startDate/endDate`（筛的是创建时间） |
| 开启页签模式（状态 / 用途 / 核销） | 对应下拉隐藏；点页签即查；F5 后页签模式保持；看板跟当前页签 |
| 用途页签=预收 | 列表与看板都能筛出预收单（用途按明细，不是单头空字段） |
| 521 用户 | 客户名与金额为「—」；看板仍能加载 |

列表与看板必须共用同一 WHERE（含数据权限）。抽 1 个筛选组合：列表总条数 = 看板「收款单数」口径下的头表数（看板 KPI 不单独展示单数时，用趋势各桶之和 + 无收款日单数，或对照 dashboard `headerCount` / 列表 total）。

页签模式持久化与现网收款列表一致（总纲 §4.4）。

## 三、口径 / 公式核对

计数：收款**单头**数（不是明细行数）。  
金额：单头 `ReceiptAmount`，按 `ReceiptCurrency` 分档。  
**不要**用明细 `ReceiptConvertAmount` 当美金或当合计核对。  
**不要**把人民币与美元原币相加。

```text
某币别收款金额 = Σ 该币别收款单头 ReceiptAmount
收款客户数 = 头表 CustomerId 非空去重
收款单数 = 筛选结果头表条数
趋势日期 = ReceiptDate（空则不进趋势，仍进 KPI / 饼图 / 排名）
核销状态 = 无明细或全部 0 → 未核销；全部 2 → 核销完成；否则部分核销
业务员 = 头表 SalesUserId；空 → 未分配业务员
```

| 核对 | 预期 |
|------|------|
| **足额（筛选结果逐单加总 = 看板）** | 抽当前筛选（建议含确认 + 有收款日 + 至少两种币别）：列表总条数 = 筛选全量头表数；有金额权限时，各原币 KPI = 该币别单头金额之和（允许四舍五入到分的尾差） |
| 原币分档 | 禁止把不同原币直接相加当主数字；人民币 / 美元混存时 KPI 至少两行 |
| 收款客户数 | = 列表结果里头表有客户 ID 的去重数；无客户单不计入 |
| 趋势（按月） | 只含有收款日的单；无收款日单进 KPI 但不进趋势桶；金额趋势每种原币一张图 |
| 核销状态饼 | 扇区为**单数** + 百分比（总要求 §3.7） |
| 业务员饼 | 按原币分面；面内为该币原币金额（或脱敏下单数）+ 百分比 |
| Top10 客户 / 业务员 | 每个原币各自独立排序；无客户可出现「未关联客户」；无业务员归「未分配业务员」 |
| **超额拒绝** | **本功能不适用：** 看板只读，无核销/匹配/金额提交 |

本功能不适用折算美金主口径（总纲 §3.2 看板美金项）：产品已锁定不折美金。

## 四、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 数据权限收窄用户 | 看板可见集合 ≤ 该用户列表可见全量，不得大于 |
| 521 采购向敏感掩码 | 收款金额显示「—」；客户名不展示；饼图/排行按单数；看板仍能加载 |
| 非 521 | 各原币金额与客户名可见 |

## 六、回归 / 已知差异

| 项 | 说明 |
| --- | --- |
| 财务分析「已收款」 | 常只统计确认，且金额可能走明细折算 / `ReceiptConvertAmount` 当美金覆盖。本页跟筛选、只用单头原币，数字不必相等 |
| 列表顶部四张统计卡 | 仅当前页、且「本月收款总额」会把不同币别加在「¥」下；看板按全量筛选、分币别，不要用顶卡对数 |
| 列表日期筛 | 筛的是创建时间；趋势按收款日。同一批单的趋势桶可以和创建日筛区间不完全重合 |
| 应收款看板 | 在 `/finance/receivables`，金额是应收/待核销折美金；不要在收款记录找「待核销应收」 |

**上线前：** 部署含本看板的版本后 **重启 CRM.API**；已登录用户刷新前端即可。无需新权限脚本、无 DDL。
