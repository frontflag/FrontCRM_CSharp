## 二、锁定（金额边界）

正式提成 = 从预计表 **原样复制**，不再取档。锁定当天先按该锁定日重算预计，再把 **当时动态表全部行** 写入锁定表（`CommissionLockService` **不**再按入池日过滤）。`term` 只是上一完整双月结束月标签。

| 用例 | 预期 |
|------|------|
| **足额锁定**：锁定时已在预计表中的行 | 进入该 `term`；预计表删除该业务键；金额与锁定前一致 |
| **尚未进预计**（该出库应收未核销完成，或未落入 Base/Other） | 不进入本次正式；仍只在提成池 |
| 同一 `(角色, 出库行)` 再跑锁定 | 跳过，行数与金额不变 |
| 销售已锁、采购未锁 | 采购仍可入预计并在下次锁定时冻采购侧 |
| 锁定后再改档 / 再重算预计 | 正式金额不变；该键不再回预计 |
| 3 月出库、4 月 10 日才核销完 | 4 月 2 日不锁该行；6 月 2 日才锁（Other） |

本功能不适用：核销超额拆锁定、反核销回滚已锁行、手工改正式金额。
本功能不适用：按入池日再筛一遍锁定窗口（已取消）。

## 三、账期与列表

| 步骤 | 预期 |
|------|------|
| 顶栏账期 | 默认最近已锁账期；展示如 `2026-01（12–1月）` |
| 2 月 2 日账期 | `term=本年01`（Base 出库日窗为上年 12/1～本年 1/31；Other 核销窗另计，只要当时在预计表就会进本期） |
| 默认列表 | 按人汇总；双击下钻出库行，多一列「账期」 |
| 单号链接 | 第 3 层为出库/销售/采购**明细单号**；无对应读权限则纯文本 |

## 五、回归 / 交叉

| 步骤 | 预期 |
|------|------|
| 锁定后预计页刷新 | 刚才锁定的行消失；锁定时尚不在预计的行，核销完成后仍可进预计 |
| 反核销已锁行对应出库应收 | 正式行仍在；次日预计不会把该键加回来 |
| 再点锁定 | `inserted=0` 或仅补新键；已锁金额不变 |

## 六、本功能不适用

- 本功能不适用：工作台左栏队列、列表页签模式、操作面板门控。
- 本功能不适用：多租户打印皮肤。
- 本功能不适用：EBS Formal 扣补、转正审批、方案版本。
- 本功能不适用：核销超额拆锁定（无拆分金额提交）。
- 本功能不适用：按入池日二次过滤、收款核销延期天数。
- 看板类公式仅本页快照金额，无数据分析筛选视角。

## 七、口径 / 公式核对

```text
锁定日 = 偶数月 2 日（手工补跑收成最近一次应锁日）
锁哪些行 = 该日重算后动态表里的全部行（不按入池日再筛）
term = 上一完整双月结束月 yyyyMM（标签）
正式行金额 = 动态行快照（不重算）
已正式 ⇔ EXISTS commission_locked (role_type, stock_out_item_id)
```
