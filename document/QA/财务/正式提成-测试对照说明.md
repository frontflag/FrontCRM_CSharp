## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 持有 `commission-official-sales.read` | 可进业务正式提成 |
| 无对应 `.read` | 菜单不出现；直链 403 |
| SuperAdmin / 平台 Admin / 旁路 | 看全部人 |
| 其余 `.read` | 只看本人 |
| 非管理员 | 无「锁定上一双月」 |
| 管理员锁定 | 二次确认；只补窗口内尚未锁定的键 |

---

## 二、锁定窗口（金额边界）

正式提成 = 从预计表 **原样复制**，不再取档。窗口按 **入池日**。

| 用例 | 预期 |
|------|------|
| **足额锁定**：入池日落在上一完整双月的预计行 | 进入该 `term`；预计表删除该业务键；金额与锁定前一致 |
| **窗口外 / 尚未入池** | 不进入本次 `term`；仍留在预计（若已入池） |
| 同一 `(角色, 出库行)` 再跑锁定 | 跳过，行数与金额不变 |
| 销售已锁、采购未锁 | 采购仍可入预计并在其窗口锁定 |
| 锁定后再改档 / 再重算预计 | 正式金额不变；该键不再回预计 |

本功能不适用：核销超额拆锁定、反核销回滚已锁行、手工改正式金额。

---

## 三、账期与列表

| 步骤 | 预期 |
|------|------|
| 顶栏账期 | 默认最近已锁账期；展示如 `2026-01（12–1月）` |
| 2 月 2 日窗口 | 入池日上年 12/1～本年 1/31 → `term=本年01` |
| 默认列表 | 按人汇总；双击下钻出库行，多一列「账期」 |
| 单号链接 | 与预计提成相同：无库存/销售/采购权限则纯文本 |

---

## 四、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 非旁路改查别人 | 后端仍只返回本人 |
| 无客户列 | 不套销售敏感客户名掩码 |

---

## 五、回归 / 交叉

| 步骤 | 预期 |
|------|------|
| 锁定后预计页刷新 | 窗口内行消失，窗口外仍在 |
| 反核销已锁行对应销售明细 | 正式行仍在；次日预计不会把该键加回来 |
| 再点锁定 | `inserted=0` 或仅补新键；已锁金额不变 |

---

## 六、本功能不适用

- 本功能不适用：工作台左栏队列、列表页签模式、操作面板门控。
- 本功能不适用：多租户打印皮肤。
- 本功能不适用：EBS Formal 扣补、转正审批、方案版本。
- 本功能不适用：核销超额拆锁定（无拆分金额提交）。

---

## 七、口径 / 公式核对

```text
锁定日 = 偶数月 2 日（手工补跑收成最近一次应锁日）
窗口 = 锁定日前两个自然月（入池日闭区间）
term = 窗口结束月 yyyyMM
正式行金额 = 动态行快照（不重算）
已正式 ⇔ EXISTS commission_locked (role_type, stock_out_item_id)
```
