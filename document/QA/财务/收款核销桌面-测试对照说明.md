# 收款核销桌面 — 测试对照说明

> **设计文档：** [收款核销桌面-设计与实现](../../System/财务/收款核销桌面-设计与实现.md)

## 一、入口与权限

权限用例已集中维护于：[权限/财务核销-权限测试对照说明.md](../权限/财务核销-权限测试对照说明.md) §三。

本节保留核心结论：收款核销桌面入口在 `/finance/receipts` 标题行右上角及侧栏「收款管理 → 收款核销」；无权限不可进入或提交被拒。

| 步骤 | 预期 |
|------|------|
| `/finance/receipts` 标题行右上角 | 有「收款核销桌面」（浅蓝底+箭头，对齐待审「进入审批桌面」）；无「收款核销」旧入口 |
| 点「收款核销桌面」 | 进入桌面；左栏为「待核销客户」；右栏默认关闭；展开后默认「出库单」页签（另有帮助） |
| 点待核销收款的收款单号 | 打开收款记录列表，搜索框为该单号，能查到该单；不误选中该行做核销 |
| 点待核销应收的应收单号 | 打开应收款列表，关键字为该单号，能查到该单；不误选中该行做核销 |
| 点待核销应收的销售订单号 | 打开销售订单列表，订单号筛选为该单，能查到该单；不误选中该行做核销 |
| 点待核销应收的入库单号 | 打开入库单列表，入库单号筛选为该单，能查到该单；不误选中该行做核销 |
| 点待核销应收的出库单号 | 仍打开出库详情（本版不改为列表） |
| 侧栏「收款管理 → 收款核销」 | 进入 `/finance/receipt-write-off-desktop`（非旧三栏页） |

---

## 二、左栏队列

| 步骤 | 预期 |
|------|------|
| 打开桌面 | 仅显示有待核销应收的客户+币别卡片 |
| 卡片字段 | 中文名、英文名、业务员、待核销总额+币别、待核销收款条数、收款日期（随排序切换标签） |
| 点击卡片 | 中区加载该客户该币别的待核销收款 / 应收 |
| 搜索 | 过滤左栏列表；顶栏 N/M **不变**（仍为有应收全量） |
| 搜索右侧排序 | 可选「最早收款日期」「最近收款日期」；列表按对应字段排序；卡片日期标签与取值同步切换；偏好记忆 |
| 列表翻页 | 默认每页 20 条；底部分页；上一客户/下一客户跨页时自动切页 |

---

## 三、顶栏与核销后

| 步骤 | 预期 |
|------|------|
| 顶栏文案 | `共 {N} 条待核销客户，{M} 条待核销记录` |
| 上一客户 / 下一客户 | 按当前左栏可见列表中的客户+币别切换 |
| 提交核销成功 | 仍停留当前客户+币别；候选与左栏数据刷新 |

---

## 四、右栏「出库单」

| 步骤 | 预期 |
|------|------|
| 进入桌面并选中客户后展开右栏 | 默认「出库单」；随待核销应收首行展示字段 |
| 点击另一应收行 | 右栏切换为该行出库信息 |
| 字段 | 出库单号、出库日期、客户中文名、客户英文名（无则隐藏）、业务员、出库数量、出库金额+币别、已核销金额、待核销金额 |
| 客户无英文名 | 不显示「客户英文名称」行 |

---

## 五、中区排列（左右 / 上下）

| 步骤 | 预期 |
|------|------|
| 待核销收款标题栏右侧图标 | 可切换「左右排列」「上下排列」 |
| 切换后刷新 / 再次进入桌面 | 仍为上次选择的排列 |
| 左右模式 | 分割条可左右拖；上下模式分割条可上下拖 |

---

## 六、旧页

| 步骤 | 预期 |
|------|------|
| 旧页「去除无待核销应收客户」勾选 | 仍存在且行为不变 |

---

## 七、核销金额边界（§4.5）

| 步骤 | 预期 |
|------|------|
| 本次核销金额 = 待核销余额（足额） | 提交成功，该收款/应收待核销变为 0 或按设计出列 |
| 本次略大于待核销余额 | 拒绝，余额不变 |
| 无 `finance-receipt.write` | 可看桌面，不能提交核销 |

---

## 八、本功能不适用

- **本功能不适用：列表页签模式 / 操作面板门控**（桌面非普通列表页签）。  
- **本功能不适用：多租户打印皮肤**。  
- **本功能不适用：看板统计公式**。  
- **本功能不适用：销售/采购敏感掩码下的独立操作面板**（金额掩码随财务列表既有规则）。
