# 付款记录列表 — 采购订单与采购员 — 测试对照说明

> **页面 / 路由：** 财务 → 付款记录（`/finance/payments`）  
> **设计文档：** [付款记录列表-采购订单与采购员-设计与实现](../../System/财务/付款记录列表-采购订单与采购员-设计与实现.md)

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有付款记录或采购订单查看权限的用户打开菜单「付款记录」 | 进入列表；搜索栏含采购订单号、采购员、采购币种；表在供应商后有采购订单号、采购员两列 |
| 无付款记录且无采购订单查看权限 | 不可进入本页 |
| 有采购订单查看权限 | 采购订单号为可点链接，进入对应采购订单详情 |
| 仅有付款记录查看、无采购订单查看权限 | 采购订单号显示文字，不可点 |

---

## 二、列表展示

| 步骤 | 预期 |
|------|------|
| 付款单只关联一张采购订单 | 采购订单号、采购员各显示该订单的单号与采购员姓名 |
| 付款单关联两张不同采购订单（采购员可不同） | 订单号去重拼接，各自可点；采购员姓名去重拼接 |
| 付款单无采购明细 / 明细未挂采购订单 | 两列均为「—」 |
| 刷新页面 | 列布局按本页新版记忆（旧列宽偏好不强制沿用） |

---

## 三、筛选（命中 / 不命中）

| 步骤 | 预期 |
|------|------|
| 采购订单号输入完整或连续片段后回车 / 查询 | 仅保留明细关联单号包含该片段的付款单 |
| 输入不存在的采购订单号 | 列表为空 |
| 采购员输入姓名片段 | 仅保留关联采购订单采购员姓名包含该片段的付款单 |
| 采购员输入不存在姓名 | 列表为空 |
| 采购币种选 USD | 仅保留关联采购订单币种为美元的付款单；付款金额列币种仍以付款单为准 |
| 采购币种清空 | 不再按币种限制 |
| 同时填采购订单号 + 采购员 + 采购币种 | 须同时满足三项（AND） |
| 无关联采购订单的付款单 | 上述任一筛选项有值时都不会出现 |
| 清空文本框 | 立即重新查询（与本页其它文本筛一致） |
| **付款单号**填已软删除的单号（如 `PAY0022N`） | 命中该行；状态列旁显示「已删除」；不填付款单号时默认列表**不含**已删除行 |

---

## 四、导出

| 步骤 | 预期 |
|------|------|
| 带上述筛选点「导出」 | CSV 含「采购订单号」「采购员」列；导出日志「导出条件」含采购订单号 / 采购员 / 采购币种（币种显示为 ISO 代码） |

---

## 五、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 列表仍受财务付款数据权限约束 | 只能看到权限范围内的付款单 |
| 采购敏感掩码开启 | 供应商等既有掩码字段仍为「—」；采购订单号、采购员按关联采购单原文展示（本功能不把这两项纳入客商/金额掩码） |

---

## 六、回归

| 步骤 | 预期 |
|------|------|
| 齿轮 → 页签模式（状态 / 付款方式） | 行为与 [筛选页签模式对照](./付款记录列表-筛选页签模式-测试对照说明.md) 一致；采购币种不出现在页签维度里 |
| 既有货代单号、付款单号、供应商筛选 | 仍可用，可与新筛选项叠加 |

---

## 七、本功能不适用（总纲强制声明）

- **本功能不适用：金额 / 核销 / 匹配的足额成功与超额拒绝**（§4.5）。本页只做列表展示与筛选，不提交核销或匹配金额。
- **本功能不适用：工作台 / 桌面左右栏队列**（§4.3）。
- **本功能不适用：操作面板门控**（§4.4 操作面板类）。
- **本功能不适用：多租户皮肤 / 打印**（§4.6）。本页无新皮肤、无打印。
- **本功能不适用：看板统计公式**。
- **本功能不适用：数据库迁移 / 新权限脚本**（§4.7）。不改表；沿用既有付款记录查看与采购订单查看权限。
