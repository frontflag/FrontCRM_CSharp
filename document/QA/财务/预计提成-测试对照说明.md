## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 持有 `commission-estimated-sales.read` | 可进业务预计提成 |
| 无对应 `.read` | 菜单不出现；直链 403 |

| SuperAdmin / 平台 Admin | 有「立即重算」，二次确认后覆盖动态结果 |

## 二、入池（金额边界）

公式：`提成 = Round(计算用GP × 点数 / 100, 2)`。出库 GP = 出库行 `profit_out_biz_usd`；计算用 GP = `max(出库GP, 0)`。点数按该人该计算月计算用 GP 合计对照生效版本档位（须先达梯度1）。

门槛（预计提成）：出库完成 **且** 该出库行对应应收核销完成（`verification_status = 2`），并落入当期 Base/Other。**不**等同一销售明细其它出库批次收齐，**不**看销售明细「收款状态」。

| 用例 | 预期 |
|------|------|
| **足额入预计**：出库完成 + 该出库应收核销完成 + Base/Other 满足 | 次日（或管理员立即重算后）该角色出现一行；提成按公式 |
| **部分核销**（该出库应收未核销完成） | 不入预计；提成池仍可看到该出库行，收款核销为部分核销 |
| **待核销** | 不入预计 |
| 同一销售明细分两批出库：仅第一批应收核销完成 | 仅第一批入预计；第二批不入。销售明细收款状态可以仍是部分收款 |
| 无归属人 | 该侧不生成行；另一侧仍可 |
| 采购侧无采购订单 | 采购页不出现该出库行 |
| 已在正式提成锁定的 `(角色, 出库行)` | 不再出现在该角色预计提成 |
| 一侧已锁定、另一侧未锁 | 未锁一侧仍可入预计 |

本功能不适用：核销超额拆提成、手工改金额、进项发票/付款门槛。
本功能不适用：收款核销延期天数（已取消，改 Base/Other）。

## 三、取档与列表

| 步骤 | 预期 |
|------|------|
| 同一人同一计算月多行 | 各行点数相同；本月 GP = 这些行计算用 GP 合计 |
| 档位为空或本月 GP 不到第 1 档 | 点数 0，行仍在列表 |
| 改生效档位后不重算 | 列表仍是旧点数；次日或点「立即重算」后变 |
| 默认列表 | 按人汇总：人员、等级、出库行数、各月 GP/提成合计 |
| 在职业务员/采购员无人池行 | 仍有一行，预计提成 0 |
| 离职人员提成 = 0 | 不出现 |
| 离职人员提成 > 0 | 出现 |
| 双击人员 | 进入该人各月 |
| 双击月份 | 出库行列出示出库明细单号、销售明细单号（采购页另有采购明细单号）；有库存/销售/采购读权限可点进单头，否则纯文本 |
| 日期默认 | 当前开放双月；清空后可看全部未锁定 |

## 七、口径 / 公式核对

```text
入预计 ⇔ 已出库 ∧ 该出库行对应应收核销完成 ∧ 落入当期 Base/Other ∧ 该侧未正式锁定
核销日 = 回放该条应收核销流水首次累计 ≥ 该应收额的那一笔（有收款单用收款日，否则用核销落库日）
计算月 = Base 用出库月 / Other 用核销月
本月 GP = Σ 同角色同人同计算月未锁定行的计算用GP
提成 = Round(行计算用GP × 本月点数 / 100, 2)
```

## 八、已知口径差异

- 与 EBS / Mogul 不一致：无扣点、无延期、不按销售额。对照文档只读，不验收。
- 与销售明细「收款状态」不一致：提成跟该出库对应应收核销，不等整行收齐。
- 不要用旧预计实施方案正文里的延期天数、入池日取档、开放双月一个点数。
