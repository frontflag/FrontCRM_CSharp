## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 持有 `commission-estimated-sales.read` | 可进业务预计提成 |
| 无对应 `.read` | 菜单不出现；直链 403 |
| 仅采购 `.read` | 不能进业务页 |
| SuperAdmin / 平台 Admin / 业务数据旁路 | 看到全部归属人 |
| 其余持有 `.read` 的账号 | 只看到归属人 = 自己的行 |
| 非管理员 | 无「立即重算」 |
| SuperAdmin / 平台 Admin | 有「立即重算」，二次确认后覆盖动态结果 |

---

## 二、入池（金额边界）

公式：`提成 = Round(出库GP × 点数 / 100, 2)`。出库 GP = 出库行 `profit_out_biz_usd`。点数按该人当期入池 GP 取生效版本档位。

延期：`计算日 − 收款核销日 > 延期天数`（严格大于）。填 0 时核销当天不入池。

| 用例 | 预期 |
|------|------|
| **足额入池**：出库完成 + 销售明细收款进度=完成 + 延期已满足 | 次日（或管理员立即重算后）该角色出现一行；提成按公式 |
| **未完成收款**（进度不是完成） | 不入池 |
| **延期未到**（含 delay=0 的核销当天） | 不入池 |
| 无归属人 | 该侧不生成行；另一侧仍可 |
| 采购侧无采购订单 | 采购页不出现该出库行 |
| 已在正式提成锁定的 `(角色, 出库行)` | 不再出现在该角色预计提成 |
| 一侧已锁定、另一侧未锁 | 未锁一侧仍可入预计 |

本功能不适用：核销超额拆提成、手工改金额、进项发票/付款门槛。

---

## 三、取档与列表

| 步骤 | 预期 |
|------|------|
| 同一人同一开放双月多行 | 各行点数相同；当期入池 GP = 这些行出库 GP 合计 |
| 档位为空或当期 GP 不到第 1 档 | 点数 0，行仍在列表 |
| 改生效档位后不重算 | 列表仍是旧点数；次日或点「立即重算」后变 |
| 默认列表 | 按人汇总：人员、等级、出库行数、当期 GP、预计提成 |
| 在职业务员/采购员无人池行 | 仍有一行，预计提成 0 |
| 离职人员提成 = 0 | 不出现 |
| 离职人员提成 > 0 | 出现 |
| 双击人员 | 下钻出库行；有库存/销售权限则单号可点，否则纯文本 |
| 日期默认 | 当前开放双月；清空后可看全部未锁定 |

## 四、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 非旁路用户改查询别人 `userId` | 后端仍只返回本人 |
| 销售敏感掩码 | 本页金额为提成 USD，不套客户名掩码；无客户列 |

## 五、回归 / 交叉

| 步骤 | 预期 |
|------|------|
| 提成参数改延期天数后重算 | 未满延期的行从预计消失 |
| 反核销使收款进度不再完成 | 次日/重算后该行从预计消失；已锁定正式行不受影响 |
| 业务预计与采购预计 | 同一出库行可同时存在，金额独立 |

## 七、口径 / 公式核对

```text
入池 ⇔ 已出库 ∧ 销售明细收款完成 ∧ (计算日 − 核销日 > 延期天数)
核销日 = 回放核销流水首次累计 ≥ 应收额的那一笔（有收款单用收款日，否则用核销落库日）
入池日 = 核销日 + 延期天数 + 1
当期 GP = Σ 同角色同人、入池日落在该行所属开放双月 的出库 GP
提成 = Round(行出库GP × 取档点数 / 100, 2)
```
