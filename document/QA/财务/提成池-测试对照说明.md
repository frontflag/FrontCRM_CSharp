# 提成池 — 测试对照说明

> **页面 / 路由：** `/commission/pool`（菜单：提成 → 提成池，位于预计提成之上）  
> **设计文档：** [业务员与采购员提成-设计与实现](../../System/财务/业务员与采购员提成-设计与实现.md) §11  
> **现行口径：** [业务员与采购员提成方案](../../实现方案/业务员与采购员提成方案.md)  
> **权限 / DDL：** 无独立权限码。`SYS_ADMIN` / `SYS_MANAGER` 看全部；销售身份业务员、采购身份采购员可进且只看本人行。池表脚本 `scripts/commission_pool_schema.sql`  
> **上线前：** 池表已存在即可；部署本版本后管理员重新登录

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| `SYS_ADMIN` 登录 | 侧栏「提成」最上方出现「提成池」，可点开 `/commission/pool`；`GET /api/v1/commission/pool` 200；列表为全量 |
| `SYS_MANAGER` 登录 | 同上，可看全量 |
| 主部门销售（业务员） | 有「提成池」菜单，可进页面；列表仅业务员字段为自己的行；搜索栏无业务员/采购员下拉 |
| 主部门采购或采购运营（采购员） | 有菜单可进；列表仅采购员字段为自己的行；无人员下拉 |
| 业务员改查询参数冒充他人 `salesUserId` | 仍只返回自己的行 |
| 财务 / 物流 / 商务职员 | 无「提成池」菜单；直打 `/commission/pool` 回控制台；直打 API 403 |
| 仅有预计/正式提成 `.read`、非管理员且非销/采身份 | 无菜单；直打页面回控制台；API 403 |
| `SYS_BIZ_MANAGER`（非销/采身份） | 同上，不可进 |
| 角色管理里 | 不出现可勾选的「提成池」权限码 |

## 二、列表与筛选

数据来自提成入池事实，一行一个已完成出库明细。只读，无保存、无重算。

| 步骤 | 预期 |
|------|------|
| 打开页面 | 服务端分页，默认每页 20，可改 10/50/100；底栏有翻页器；列含出库明细单号、销售明细单号、采购明细单号；采购明细单号之后、出库GP之前依次为物料型号、品牌、采购单价、销售单价、采购单价(折算美金)、销售单价(折算美金)、出库数量；列顺序末尾为「销售提成状态」「采购提成状态」 |
| 对照出库明细 | 物料型号/品牌与出库明细采购 PN/品牌一致（明细空时与销售明细一致）；空显示「—」 |
| 对照出库扩展 | 采购单价为扩展原币+币别；采购单价(折算美金)为扩展 USD；销售单价/销售单价(折算美金)优先扩展，空则销售明细单价/`convert_price`；出库数量优先扩展出库量 |
| 单价展示 | 与系统列表通用金额单元格一致：数字分段 + 尾部彩色 ISO 币别（RMB/USD/EUR/HKD）；缺值「—」 |
| 有库存/销售/采购读权限 | 出库/销售/采购**明细单号**单击新开浏览器页打开对应单头详情，提成池页仍留着；默认与表格正文同色、无下划线；悬停变蓝、出现下划线、手型光标 |
| 无对应读权限 | 明细单号显示为文字，不可点 |
| 有销售单且订单上有业务员 | 「业务员」列显示登录账号（不是中文姓名） |
| 有采购单且订单上有采购员 | 「采购员」列显示登录账号（不是中文姓名） |
| 该行无业务员/采购员归属 | 对应列显示「—」，不是空白格子 |
| 关键词匹配出库明细单号（如 `STO00221-2`） | 仅该出库行出现；搜出库单号 `STO00221` 仍命中该单全部入池行 |
| 关键词匹配销售/采购明细单号 | 命中对应行；搜销售/采购单号仍命中该单下入池行 |
| 物料型号 | 包含匹配出库明细采购 PN；明细为空时也能命中销售明细型号；不区分大小写；与单号条件同时生效 |
| 搜索栏选择业务员 | 仅管理员可见该下拉；选项显示登录账号；可清空；仅该业务员入池行 |
| 搜索栏选择采购员 | 仅管理员可见该下拉；选项显示登录账号；可清空；仅该采购员入池行 |
| 池行人员 ID 为空、销售单/采购单上是所选人 | 仍命中 |
| 重置 | 关键词、物料型号、业务员、采购员、销售/采购提成状态、收款核销、出库日期全部清空 |
| 销售提成状态=已提成 | 仅该侧已正式锁定的行 |
| 采购提成状态=不适用 | 仅无采购归属的行 |
| 收款核销=核销完成 | 仅该出库行对应应收为核销完成的入池行；`GET .../pool?receiptStatus=2` |
| 收款核销=部分核销 / 待核销 | 仅对应应收核销状态；非法 `receiptStatus=3` 接口 400 |
| 「收款核销」列 | 核销完成绿色标签、部分核销黄色标签、待核销灰色信息标签（与应收核销状态一致，**不是**销售明细收款状态） |
| 出库日起止 | 含起含止；起晚于止时接口 400 |
| 空结果 | 「暂无提成池数据」，不报错 |
| 双击行 | 不跳转、不打开详情；打开单据只靠单击明细单号（新开页） |

## 三、口径核对

列表 **出库GP** 直接展示池中出库 GP，不在本页重算提成。物料/单价/数量为当前页回填，便于手工验算，不写回池表。

```text
一行 = commission_pool 一条出库明细
出库GP（池表，两位小数）≈ (销售单价折算美金 − 采购单价折算美金) × 出库数量
销售提成状态 0 未提成 / 1 已提成
采购提成状态 0 未提成 / 1 已提成 / 2 不适用
收款核销 0 待核销 / 1 部分核销 / 2 核销完成（该出库行对应应收，不是销售明细收款状态）
```

| 步骤 | 预期 |
|------|------|
| 对照库中该 `stock_out_item_id` | 出库明细单号、出库GP、两侧状态、收款日与列表一致 |
| 同一销售明细分两批出库，仅第一批应收核销完成 | 第一批收款核销=核销完成且有核销日；第二批为待核销或部分核销。销售明细「收款状态」可以仍是部分收款 |
| 用列表折算美金单价 × 出库数量 | 与该行出库GP一致（两位小数、AwayFromZero）；若池表入池后扩展价已变，以池表 GP 为准，记下差异 |
| 采购侧无采购订单 | 采购提成状态为「不适用」 |
| 已锁定正式提成的一侧 | 对应状态为「已提成」；另一侧可仍为「未提成」 |
| 改预计提成金额或定额 | 本页出库GP与状态不变（本页不读动态表/定额） |

**本功能不适用：核销/匹配的「足额成功 + 超额拒绝」。** 本页不提交金额、不核销、不改池。金额类核对见上表「折算美金单价 × 数量」。

## 四、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| SYS_ADMIN / SYS_MANAGER | 看到全部入池行，不按销售/采购数据范围裁行 |
| 业务员 | 只看到业务员=自己的行（含池行 ID 空、销售单上回填为自己） |
| 采购员 | 只看到采购员=自己的行（含池行 ID 空、采购单上回填为自己） |
| 销售 511 / 采购 521 | 本人可见行仍展示出库GP、销售单价与销售单价(折算美金)（本页不按 511/521 掩码） |
| 非销/采身份持有提成 `.read` | 不能用本页绕过看池行 |

## 五、回归 / 交叉

| 步骤 | 预期 |
|------|------|
| 预计提成 / 正式提成 | 仍仅管理员菜单可见，位置在「提成池」下方；列表金额不因打开本页而变 |
| 提成参数 | 不受影响 |
| 控制台个人提成 | 不受影响 |
| 无写操作 | 刷新后池行数量与库一致 |

## 六、本功能不适用

- 本功能不适用：核销/匹配的「足额成功 + 超额拒绝」（见 §三）。  
- 本功能不适用：工作台左栏队列、列表页签模式、操作面板门控。  
- 本功能不适用：多租户打印皮肤。  
- 本功能不适用：看板公司/部门/个人透镜。  
- 本功能不适用：手工入池、删行、改状态。

---

## 七、已知口径差异

- 「收款核销」列是该出库对应应收（待核销/部分核销/核销完成），不是销售明细收款状态。
- 池里有行不等于进了预计提成。
