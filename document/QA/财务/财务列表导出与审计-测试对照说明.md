## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有对应列表查看权限 | 页头或搜索栏右侧浅黄「导出」可见，可下载 CSV |
| 无列表查看权限 | 无法进入列表，亦无导出 |
| 无 write 仅有 read | 仍可导出（导出不是写操作） |
| 应收款看板/列表切换 | 「导出」始终可见；导出内容跟当前筛选，与是否处于看板视图无关 |

## 三、CSV 列与口径

### 3.1 通用

| # | 步骤 | 期望 |
|---|------|------|
| A | 对照客商主档 | 中文=官方中文名（空则回退列表所用名称）；英文=英文全称；**无**原「客户/供应商」单列 |
| B | 金额与币别 | 每个金额列后紧跟一列币别，ISO 文案 `CNY`/`USD`/`EUR`；同行多个金额即使币别相同也不合并 |
| C | 枚举单元格 | 状态/用途/核销/付款方式等为中文业务名，不得仍为 `1`/`2`/`100` |

本导出**不提交**核销/匹配金额，故总纲 §4.5「足额成功 / 超额拒绝」**本功能不适用**（无写入待核销余额的操作）。

### 3.2 付款记录

状态、供应商中文、供应商英文、收款银行、付款银行、请款金额、请款金额币别、付款金额、付款金额币别、付款方式、付款日期、水单号、备注、货代单号、付款单号、创建日期、创建人

币别取付款单 `PaymentCurrency`。511 下金额仍导出（与列表掩码一致，不把付款金额置空）。

### 3.3 进项发票

开票状态、发票单号、开票日期、供应商中文、供应商英文、发票号码、发票金额、发票金额币别、核销状态、核销金额、核销金额币别、付款状态、付款金额、付款金额币别、发票备注、发票类型、创建日期、创建人

| # | 步骤 | 期望 |
|---|------|------|
| 2a | 冲红（红字）发票 | **开票状态=已作废** |
| 2b | 已认证、未冲红 | **开票状态=已开票** |
| 2c | 未认证且未冲红 | **开票状态=未申请** |
| 2d | 发票类型 | 导出「增值税专用发票」（与列表默认一致；实体无独立发票类型字段） |
| 2e | 创建人 | 单元格为空（列表本身显示 `-`） |

### 3.4 销项发票

开票状态、发票单号、开票日期、客户中文、客户英文、发票号码、发票金额、发票金额币别、核销状态、核销金额、核销金额币别、收款状态、收款金额、收款金额币别、发票备注、发票类型、创建日期、创建人

开票状态按销项状态码：未申请 / 申请中 / 已开票 / 开票失败 / 已作废。创建人单元格为空。

### 3.5 收款记录

状态、核销状态、用途、客户中文、客户英文、收款金额、收款金额币别、收款方式、收款日期、水单号、备注、收款单号、创建日期、创建人

用途：预收 / 普通。币别取 `ReceiptCurrency`。

### 3.6 应收款

核销状态、出库日期、应收单号、出库单号、客户中文、客户英文、业务员、型号、品牌、数量、金额、金额币别、已核销、已核销币别、待核销、待核销币别

默认筛选「仅待核销」与列表勾选一致；取消勾选后导出应含已核销完成行。

### 3.7 预收款

客户中文、客户英文、余额、余额币别、累计入账、累计入账币别、累计核销、累计核销币别

页面独立「币别」列不进导出。

### 3.8 货代付款

状态、收款单号、客户中文、客户英文、货代公司、收款金额、收款金额币别、已付、已付币别、待付、待付币别、收款日期

状态：待付款 / 部分付款 / 付款完成。页面独立「币别」列不进导出。

## 五、回归注意

| # | 说明 |
|---|------|
| A | 列表页筛选下拉仍可显示码值；仅 **CSV 单元格** 与操作日志条件摘要为业务名称 |
| B | 付款/收款页签模式只改变筛选交互；导出仍跟当前生效筛选 |
| C | 货代付款列表实现为先筛后内存分页；导出走同一查询，数据量大时可能较慢（业务量通常较小） |
| D | 预收款无独立菜单帮助页；导出验收以本对照说明 + 页面按钮为准 |

## 六、本功能不适用（总纲裁剪）

| 维度 | 说明 |
|------|------|
| 工作台 / 桌面（§4.3） | 本功能不适用：导出不是左栏队列桌面 |
| 页签模式 / 操作面板（§4.4） | 本功能不适用：付款/收款页签见既有列表对照说明；导出只跟当前筛选 |
| 金额核销足额/超额（§4.5） | 本功能不适用：导出不提交核销或匹配 |
| 看板公式（§3.2 / 数据分析） | 本功能不适用：应收看板统计见既有应收看板帮助；导出只出列表行 |
| 多租户皮肤 / 打印（§4.6） | 本功能不适用：CSV 无租户皮肤 |
