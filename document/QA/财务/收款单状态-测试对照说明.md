# 收款单状态 — 测试对照说明

> **页面 / 路由：** `/finance/receipts`、`/finance/receipts/:id`（菜单：收款管理 → 收款记录）  
> **设计文档：** [收款单状态-设计与实现](../../System/财务/收款单状态-设计与实现.md)  
> **页签筛选：** [收款记录列表-筛选页签模式-测试对照说明](./收款记录列表-筛选页签模式-测试对照说明.md)  
> **权限：** 确认 / 取消仅 `finance-receipt.write`（不是四个 `finance-*.write` 任一，也不是仅 read）

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 仅 read | 可看列表/详情；无确认、取消、编辑、新建 |
| 有 `finance-receipt.write` | 新建单显示 **确认**、**取消** |
| 无 write 的其它财务写权限（如仅付款 write） | 不能确认收款单 |
| 待审批桌面 | 业务类型中 **无收款**；历史待审收款不会再出现 |

---

## 二、状态文案与筛选

| 步骤 | 预期 |
|------|------|
| 列表/详情/导出 CSV | 状态为 **新建 / 确认 / 取消**（不再出现草稿、待审核、已审核、已收款） |
| 状态下拉与页签 | 仅 新建、确认、取消（加「全部」） |
| 顶部统计 | 新建 / 确认 / 取消 计数与当前页数据一致 |

---

## 三、编辑收款金额与默认明细

列表编辑只改单头金额；核销桌面读明细。新建保存金额须把默认明细写成一样。

| 步骤 | 预期 |
|------|------|
| 新建保存 100，再编辑为 200 保存 | 列表金额 200；打开详情，明细收款金额与折算金额均为 200 |
| 上一步确认后打开收款核销桌面 | 待核销收款「收款金额」与「待核销余额」为 200（同币别），不是旧的 100 |
| 确认后再编辑保存 | 拒绝（仅新建可编辑） |
| 一张单有多条明细时改单头金额 | 明细金额不自动改（拆分单不覆盖） |

历史已确认单若列表与核销桌面金额不一致：不能靠再编辑修复，须改库后再验收。

---

## 四、确认

| 步骤 | 预期 |
|------|------|
| 新建单点确认 | 状态变为确认；可核销；操作日志有「收款确认」 |
| 确认后再点确认 | 拒绝（不可重复确认） |
| 确认后编辑保存 | 拒绝 |
| 预收款确认 | 金额进入客户预收池 |
| 货代付款确认 | 出现在货代付款台账 |

---

## 五、取消

| 步骤 | 预期 |
|------|------|
| 新建单取消 | 状态为取消 |
| 确认且整单未核销、无货代付款、预收可冲回 | 取消成功；预收冲回 |
| 已部分/全部核销后直接取消 | 拒绝，提示先反核销；状态仍为确认 |
| 反核销后再取消 | 成功 |
| 预收已被核到应收、池余额不够冲回 | 拒绝取消 |
| 货代已登记付款 | 拒绝取消 |

---

## 六、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 部门数据权限 | 只能确认/取消本人可见范围内的收款单 |
| 销售敏感掩码 | 金额/客户名为 `—`，确认/取消按钮仍按权限显示 |

---

## 七、本功能不适用

- **本功能不适用：§4.5 核销金额足额成功 / 超额拒绝**（本状态机与编辑金额同步不提交核销；核销见 [收款核销桌面-测试对照说明](./收款核销桌面-测试对照说明.md)）。
- **本功能不适用：审批工作台左栏队列 / 上一条下一条**（收款已退出待审批）。
- **本功能不适用：列表页签模式 / 操作面板门控**（页签见 [收款记录列表-筛选页签模式-测试对照说明](./收款记录列表-筛选页签模式-测试对照说明.md)）。
- **本功能不适用：多租户打印皮肤**。
- **本功能不适用：看板统计公式**。
- **本功能不适用：销售/采购敏感掩码的面板加载细节**（§4.2 已测金额掩码为 `—`；无独立操作面板）。
