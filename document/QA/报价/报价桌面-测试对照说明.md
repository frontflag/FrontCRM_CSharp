# 报价桌面 — 测试对照说明

**关联设计：** [报价桌面-设计与实现](../../System/报价/报价桌面-设计与实现.md)

## 入口

- [ ] 新建报价页右上角有「报价桌面」，进入 `/quote-desktop`
- [ ] 若 URL 带 `rfqItemId`，进入桌面后选中该条（可跨页）；失败则提示并选第一条
- [ ] 需求明细列表右上角有「报价桌面」
- [ ] 需求明细行内「报价」仍进入 `/quotes/create?...`，行为不变

## 左栏 / 顶栏

- [ ] 左扩展「待报价」仅在报价桌面出现；列表为可报价的待报价明细
- [ ] 日期筛：全部 / 今日 / 昨日 / 前天 / 3日前（创建日 ≤ 今天−3）；顶栏 N 随筛选变
- [ ] 页大小 20，支持翻页
- [ ] 上一条/下一条跨页；到本页最后一条再下一条会翻到下一页首条
- [ ] 字段：需求编号、创建日期、物料型号、品牌、业务员、采购员

## 中间报价

- [ ] 选中行后嵌入新建报价表单（同 QuoteCreate 内容）
- [ ] 保存成功后自动选中下一条；当前条离开待报价队列
- [ ] 「查无报价」成功后同样跳下一条
- [ ] 无待报价时中间/右栏为空态（暂无…）

## 右侧历史报价

- [ ] 默认激活「历史报价」
- [ ] 物料展示当前明细型号、品牌
- [ ] 同型号+同品牌精确匹配最近 10 条，日期降序；阶梯价展开多档；仅型号或仅品牌时列表为空
- [ ] 仅 `status===1` 显示成单标签
