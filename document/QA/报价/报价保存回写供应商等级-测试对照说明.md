# 报价保存回写供应商等级 — 测试对照说明

> **页面 / 路由：** 新建报价 `/quotes/create`（可带 `rfqId`）；编辑报价 `/quotes/:id/edit`；报价桌面嵌入同一表单  
> **设计文档：** [报价保存回写供应商等级-设计与实现](../../System/报价/报价保存回写供应商等级-设计与实现.md)、[供应商等级-设计与实现](../../System/供应商/供应商等级-设计与实现.md)  
> **自动化：** `tests/CRM.Core.Tests/Services/QuoteServiceTests.cs`（创建回写 / 编辑回写 / 未传不写 / 供应商缺失不提交）  
> **权限 / DDL：** 无新权限码、无迁移。有报价保存权限即可改等级并回写供应商资料；不要求供应商维护权限。  
> **帮助：** `help/pages/报价列表_MENU_QUOTE_LIST.md`、`help/pages/需求明细_MENU_RFQ_ITEMS.md`  
> **总纲：** [测试规范总纲.md](../测试规范总纲.md)

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有报价保存权限，打开新建/编辑报价 | 可见「供应商等级」下拉（须先选供应商） |
| 仅有报价保存、**无**供应商维护 | 仍可改等级并保存；打开供应商详情/列表可见新等级 |
| 无报价保存 | 不能保存本页；本功能无单独权限码 |
| 采购脱敏账号 | 供应商、等级、联系人为「—」且不可改；失效日期仍可填 |

---

## 二、布局与下拉（必测）

| 步骤 | 预期 |
|------|------|
| 看第一行 | 供应商约占整行 1/3；等级、联系人、失效日期均分剩余 2/3 |
| 未选供应商 | 等级下拉禁用 |
| 选一个当前为 C 的供应商 | 等级显示 **C** |
| 下拉选项 | 仅 **S / A / B / C**，不可清空 |
| 换成另一个供应商 | 等级变为该供应商当前档，不保留上一档未保存改动 |
| 编辑已有报价 | 带出该报价供应商当前主数据等级 |

---

## 三、保存回写主数据（必测）

准备：供应商甲当前等级 **C**。

| 步骤 | 预期 |
|------|------|
| 选甲，等级保持 C，保存报价 | 甲仍为 C；供应商字段变更日志 **无** 新的等级记录 |
| 选甲，改成 **S**，保存报价 | 甲变为 S；报价列表/需求明细采购报价该供应商显示 S；供应商变更日志有「等级」 |
| 保存失败（如校验拦下） | 甲仍为 C |
| 供应商后来在供应商编辑页再改成 A | 历史报价列表等级显示 A（现读，不是报价快照） |

编辑报价：打开后改等级再保存，同样回写。

---

## 四、口径 / 公式核对

本功能不适用：金额核销 / 匹配的足额成功与超额拒绝（总纲 §4.5）。不提交核销金额。

等级码：1=S 2=A 3=B 4=C；非法或缺省按 C。报价表不落等级列。

---

## 五、回归 / 交叉

| 步骤 | 预期 |
|------|------|
| 供应商编辑页改等级 | 行为不变；与报价回写共用主数据 |
| 报价列表 / 需求明细采购报价 / 已删报价 | 仍现读主数据；改档后列跟着变 |
| 报价桌面嵌入新建 | 同一行布局与回写 |

---

## 六、本功能不适用

- **本功能不适用：工作台 / 桌面左栏队列（总纲 §4.3）。** 报价桌面仅嵌入同一表单。
- **本功能不适用：列表页签模式 / 左栏检索 / 操作面板单击门控（总纲 §4.4）。**
- **本功能不适用：金额提交 / 核销 / 匹配足额与超额（总纲 §4.5）。**
- **本功能不适用：数据分析看板公式。**
- **本功能不适用：多租户皮肤 / 打印（总纲 §4.6）。** 三租户报价表单行为相同。
