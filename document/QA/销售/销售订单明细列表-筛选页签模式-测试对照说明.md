# 销售订单明细列表 — 筛选页签模式 — 测试对照说明

> **页面：** `/sales-order-items`  
> **设计文档：** [销售订单明细列表-筛选页签模式-设计与实现](../../System/销售/销售订单明细列表-筛选页签模式-设计与实现.md)

---

## 一、入口与默认

### 1.1 前置

- 账号可打开销售订单明细列表
- 左栏**无**快捷检索 preset（除非测 §四）

### 1.2 预期

| 步骤 | 预期 |
|------|------|
| 进入页面（未开过页签模式） | 无页签条；搜索栏显示币别下拉 + 日期 + 六进度下拉 |
| 点击看板旁齿轮 | 弹出「关闭页签」（禁用）、「页签模式 ▸」 |
| 悬停「页签模式」 | 子菜单 7 项：交易币别、采购/入库/出库通知/出库/收款/开票状态 |

---

## 二、开启与切换（单维度）

| 步骤 | 预期 |
|------|------|
| 页签模式 → 交易币别 | 币别下拉隐藏；表格上方出现「全部 / 人民币 / 外币」；「关闭页签」可点；子菜单该项高亮 |
| 点「人民币」 | 立即查询；URL/`transactionCurrency=rmb`；列表与看板一致 |
| 再开「出库状态」 | 币别下拉恢复（值仍可保留）；出库下拉隐藏；页签变为「全部 / 待出库 / 部分出库 / 出库完成」 |
| 点「部分出库」 | 立即查询；带 `stockOutProgressStatus=1` |
| 关闭页签 | 页签条消失；出库下拉恢复且仍为「部分出库」；不自动清筛选 |

---

## 三、与「查询」按钮差异

| 步骤 | 预期 |
|------|------|
| 仅改其它下拉（未开页签的维度）不点查询 | 不请求（与现网一致） |
| 点击页签 | **立即**请求，无需再点查询 |

---

## 四、与左栏 preset 互斥

| 步骤 | 预期 |
|------|------|
| 无页签时选任意 preset | 日期与六进度下拉隐藏；币别下拉仍在 |
| 先开「采购状态」页签，再选 preset | 进度页签条**消失**；齿轮 → 页签模式子菜单**仅「交易币别」**（进度项隐藏） |
| preset 下开「交易币别」 | 币别页签条**仍显示**；点「外币」可查询 |
| 清除 preset（chip ✕ 或再点同一 preset） | 若偏好仍是进度维度：进度页签条恢复；子菜单恢复 7 项 |

---

## 五、明暗主题（抽查）

| 步骤 | 预期 |
|------|------|
| 亮色 + 未选中页签 | 背景约 `#E8EDF5`，文字可读 |
| 暗色 + 未选中页签 | 深色层（非浅灰白块），文字可读 |
| 选中页签 | 顶边青色高亮，与未选中区分明显 |

---

## 六、刷新持久化

| 步骤 | 预期 |
|------|------|
| 开启某维度后 F5 | 仍为该维度页签模式（localStorage） |
| 关闭页签后 F5 | 无页签条 |
