## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 无销售订单读权限 | 不可进入上述页面 |
| 打开销售订单明细，展开右栏 | 页签顺序 **操作 → 流程 → 客户 → 帮助**；默认 **操作**（若无本页记忆） |
| 打开销售订单列表，展开右栏 | 页签顺序 **客户 → 帮助**；默认 **帮助**（若无本页记忆） |
| 打开销售订单详情，展开右栏 | 页签顺序 **操作 → 流程 → 客户 → 帮助**；默认 **操作**（若无本页记忆） |
| 点「客户」且列表未选行 | 提示单击列表行查看客户 |
| 销售订单详情打开后点「客户」 | 无需再点明细行即可出摘要（按单头客户） |
| 能打开该客户详情的账号 | **三块**卡片：概况（编号橙色主标题、中英文名、档案业务员）；基本信息、财务信息为独立卡片，**标签：值**（13px，非两列大号指标） |
| 上述账号下客户编号、中文名、英文名 | **可点**进入客户详情（当前页） |
| 无客户模块查看权限，或该客户不在数据范围内 | 仅概况中的 **客户编号、业务员**；无基本信息/财务信息卡片；编号 **不可点** |
| 521 采购脱敏账号 | **永远**与上一行相同（即使有客户模块权限） |

刷新后右栏页签记忆与其它扩展页签相同（有本页记忆则恢复；无则用上表默认）。

## 二、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 销售订单数据范围外的单据 | 客户页签失败或看不到该行（与列表一致） |
| 列表已打码客户名的 521 账号 | 仍可出编号 + 档案业务员；名称/额度不下发 |
| 521 详情页可能不自动选第一行做操作聚合 | 点「客户」仍出单头客户（不依赖明细选中） |
| 客户档案业务员与订单业务员不同 | 页签显示 **档案业务员** |
| Network | `GET /api/v1/customer-workspace?source=sellOrderItem\|sellOrder&id=`，**不**带 `customerId` |

---

## 三、门控与空态

| 步骤 | 预期 |
|------|------|
| 明细列表：右栏在「帮助」「操作」或「流程」时单击行 | **不**请求客户摘要（Network 无 `customer-workspace`）；操作/流程按原规则请求 |
| 订单列表：默认停在帮助时单击行 | **不**请求；也不自动切到「客户」 |
| 再点「客户」 | 才请求并展示 |
| 右栏收起时单击行 | 不请求；展开且当前是「客户」后再加载 |
| 列表搜索 / 重置 / 刷新 | 右栏客户回到未选行 |
| 分页后表格高亮第一行（程序 `setCurrentRow`） | **不**当作单击，不拉客户 |
| 无客户的订单 | 「该单据未关联客户档案」 |
| 销售订单 / 明细看板 | 不因看板点击加载客户 |
| 新建 / 编辑销售订单 | 右栏无「客户」页签 |

---

## 四、字段核对（有完整权限时）

与 **客户详情** 对照同一客户：编号、中英文名称、类型/等级/行业、账期、结算币别、信用额度一致。地区取客户主表省市，可能与详情默认地址不完全相同。税率为空则 —。

---

## 五、回归 / 交叉

| 步骤 | 预期 |
|------|------|
| 明细列表「操作」「流程」 | 默认页签、单击门控、申请采购/出库与本改动前一致 |
| 详情底部明细选中 / 操作面板 | 仍要点明细行；客户页签不跟该选中 |
| 需求模块三页客户页签 | 不受本批影响 |

---

## 六、本功能不适用

- **本功能不适用：§4.5 核销金额足额成功 / 超额拒绝**（只读展示信用额度，不提交核销）。
- **本功能不适用：多租户打印皮肤**。
- **本功能不适用：工作台左栏队列 / 顶栏 N/M**。
- **本功能不适用：需求 / 履约 / 收款右栏**（需求见 [需求模块-客户页签-测试对照说明](../需求/需求明细列表-客户页签-测试对照说明.md)；履约见 [履约单据-客户页签-测试对照说明](../物流/履约单据-客户页签-测试对照说明.md)；收款见 [收款记录-客户页签-测试对照说明](../财务/收款记录-客户页签-测试对照说明.md)）。
- **本功能不适用：列表页签模式 / 左栏检索 preset**（本页签不改筛选）。
