## 1. 范围

分别在 **semicore / idesemi / ecoinf** 构建包中打开 `/sales-orders/:id/report`，并与同租户 Packing List / Invoice 对照。

---

## 2. 通过标准

| 检查项 | 期望 |
|--------|------|
| 租户差异 | 三套观感明显不同 |
| 与 Packing 对齐 | 同租户页眉结构、主色一致 |
| semicore | 深色顶栏（约 `#0D1F35`） |
| idesemi | 左大标题「销售订单」、右 Logo；青竖条 |
| ecoinf | 绿表头/附加条（约 `#A8D070`） |
| 字段 | 卖方/买方/交付、含税明细、附加信息与条款、双签章区 |
| 打印 / PDF | 壳层隐藏；色块保留；导出可用 |

同租户 SO 若仍为旧橙色而 Packing 已为新色系 → 不通过。
