# 销售订单报表打印 — 三租户皮肤 — 测试对照说明

> **页面 / 路由：** 销售订单详情 → 打印/报表 `/sales-orders/:id/report`  
> **设计文档：** [销售订单报表打印-三租户皮肤-设计与实现](../../System/销售/销售订单报表打印-三租户皮肤-设计与实现.md)  
> **色板：** [租户主题色规范](../../PRD/规范/UI规范/租户主题色规范.md)  
> **权限 / DDL：** 无新权限码、无新迁移。须有销售订单查看权限；金额列受销售掩码。

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有销售订单查看权限，从详情进报表 | 打开 `/sales-orders/:id/report`，三栏与明细可见 |
| 无销售订单权限 | 进不了详情/报表，或回控制台 |
| 销售金额脱敏 | 单价、合计等金额为 `—`；版式仍加载 |
| 本页无提交按钮 | 无核销/匹配/保存 |

## 二、范围与皮肤

分别在 **semicore / idesemi / ecoinf** 构建包中打开 `/sales-orders/:id/report`，并与同租户 Packing List / Invoice 对照。

| 检查项 | 期望 |
|--------|------|
| 租户差异 | 三套观感明显不同 |
| 与 Packing 对齐 | 同租户页眉结构、主色一致 |
| semicore | 深色顶栏（约 `#0D1F35`） |
| idesemi | 左大标题「销售订单」、右 Logo；青竖条 |
| ecoinf | 绿表头/附加条（约 `#A8D070`） |
| 字段 | 卖方/买方/交付、含税明细、附加信息与条款、双签章区 |
| 打印 / PDF | 壳层隐藏；色块保留；导出可用 |

同租户 SO 若仍为旧橙色而 Packing 已为新色系 → 不通过。

## 三、明细行（空白行）

| 步骤 | 预期 |
|------|------|
| 仅 1 行明细（如 `SO00259`） | 明细表只有这一行，紧接下方是「总计」；**无**补齐空行，**无**「以下空白」 |
| 多行明细（≥6） | 只打印实际行，行间无空行垫高 |
| 无明细 | 显示「暂无明细」，无空行、无「以下空白」 |

## 四、口径 / 公式核对

本页**只展示**订单已落库金额，不提交核销或匹配。

```text
行含税合计 = 数量 × 含税单价
价税合计 = Σ行含税合计
不含税金额、增值税由订单税率拆分展示
```

| 用例 | 预期 |
|------|------|
| **足额（展示金额 = 订单行合计）** | 总计含税与订单一致（如 1600 × 63.00 = 100,800.00） |
| 超额 / 核销提交 | **本功能不适用：无核销、匹配、付款提交** |

## 五、通用维度（不适用项）

| 维度 | 说明 |
|------|------|
| 数据范围与脱敏 | 见一；本页无操作面板 |
| 工作台 / 桌面 | 本功能不适用 |
| 页签模式 / 左栏检索 / 操作面板 | 本功能不适用 |
| 多租户皮肤 / 打印 | 见二；三租户分别验收 |
| 上线前置 | 无 DDL。须部署含本改动的前端 |

## 六、回归

| 步骤 | 预期 |
|------|------|
| 采购订单报表 | 同样不补空白行（已对齐） |
| 销售订单详情 | 不受影响 |
