## 一、前置

- 账号可打开销售订单明细列表（脱敏账号另测敏感字段为 `—`，仍应能加载面板）
- 浏览器 Network 可过滤 `detail-tab-aggregates`（或同类聚合接口路径）

---

## 二、交互门控（§2.4）

| 步骤 | 预期 |
|------|------|
| **A** 收起右侧辅助栏后单击某行 | 右栏**不**自动展开；行**不**高亮为操作选中；Network **无**聚合请求 |
| **B** 展开右栏 → 切到「帮助」→ 单击某行 | 该行高亮；仍停在「帮助」；Network **无**聚合请求 |
| **D** 在 B 之后再点「操作」页签 | 出现聚合请求；面板**最上方**为「销售订单」卡片，其下为订单明细 / 进度等卡片 |
| **C** 已在「操作」页签下单击另一行 | 立即请求新行聚合；高亮切换；面板内容更新 |
| **E** 在「操作」页签下先选中一行 → 收起右栏 → 再展开 | 默认切到 **「操作」** 页签（[工作台规范 §2](../../PRD/规范/UI规范/扩展面板.工作台规范.md)）；若选中仍在 store 则加载/沿用面板数据 |
| **F** 选中行后点「查询」刷新列表 | 操作面板清空为「请先选择记录」；需重新单击行 |

## 二点一、销售订单卡片

| 步骤 | 预期 |
|------|------|
| 选中一行 | 操作页签**最上方**卡片标题为「销售订单」 |
| 销售订单编号与状态 | **同一行**，各占行宽 **50%**；编号与订单明细里 PN 同为常规 13px，**不是**明细编号那种橙色大字；编号**无下划线**（含悬停） |
| 状态 | 销售**主单**状态文案（如审核通过、进行中），与列表销售订单状态一致，不是行上部分采购等标签。状态为 **取消** 或 **审核失败** 时，状态文字为**红色** |
| 客户 | 该卡片**最下一行**（整行）**加粗**；中英名称合并显示；英文空则只显示中文；脱敏为 `—`。**订单明细卡片不再展示客户** |
| 点击编号 | 进入该销售订单详情（无单号或无 id 时为纯文本「—」） |

## 三、功能抽查（非门控）

| 步骤 | 预期 |
|------|------|
| 「操作」下选中有备货库存的行 | 出现「备货库存」卡片 |
| 无备货库存 | 不显示该卡片 |
| 有使用备货记录 | 出现「使用备货」卡片 |
| 布局 §2.5 / 操作规范 §7.6 | 状态区 3 列网格；单标签仅占第一列。「使用备货」等为双列 Key:Value。采购申请 / 出库通知「已完成」时指标下展示可点击单号（采购申请单号 / 出库通知单号），无进度条、无主按钮 |
| 订单明细卡片 | 首行为琥珀色明细编号，其后为 PN / 品牌 / 单价 / 数量；**不含客户** |
| 采购申请已完成 | 标题「已完成」；列出未取消的采购申请单号；单击进入采购申请详情 |
| 出库通知已完成 | 标题「已完成」；列出未取消的出库通知单号；单击进入出库通知详情 |
| 已完成但单据均已取消 | 不出现空的「单号：」行 |
| 双击行 | 进入销售订单详情（不被单击逻辑挡住） |
| 脱敏账号 | 「操作」页签下单击仍加载；敏感字段为 `—`；完成态单号不可点 |

## 五、本功能不适用

- **本功能不适用：工作台 / 桌面左栏队列（总纲 §4.3）。** 非审批/报价/核销桌面。
- **本功能不适用：金额提交 / 核销 / 匹配的足额成功与超额拒绝（总纲 §4.5）。** 本面板不提交核销或匹配金额。
- **本功能不适用：数据分析看板公式。** 看板口径见销售订单明细看板帮助 / IMP。
- **本功能不适用：多租户皮肤 / 打印（总纲 §4.6）。** 本面板无打印、无租户报表皮肤。
- **本功能不适用：上线前置 SQL / 迁移 / 重新登录（总纲 §4.7）。** 本改动无新权限码、无新迁移。
