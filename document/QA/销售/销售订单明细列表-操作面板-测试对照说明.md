# 销售订单明细列表 — 右侧操作面板 — 测试对照说明

> **页面：** `/sales-order-items`  
> **设计文档：** [销售订单明细列表-操作面板-设计与实现](../../System/销售订单明细列表-操作面板-设计与实现.md)（**§2.4** 决策表全站共用；**§2.5** 状态 3 列 / 信息双列布局）  
> **帮助：** `help/pages/销售订单明细_MENU_SALES_ORDER_ITEMS.md`  
> **同门控列表：** 采购订单明细、报关单列表、到货通知列表（`useListRightOpsPanelInteraction`）

---

## 一、前置

- 账号可打开销售订单明细列表（脱敏账号另测敏感字段为 `—`，仍应能加载面板）
- 浏览器 Network 可过滤 `detail-tab-aggregates`（或同类聚合接口路径）

---

## 二、交互门控（§2.4）

| 步骤 | 预期 |
|------|------|
| **A** 收起右侧辅助栏后单击某行 | 右栏**不**自动展开；行**不**高亮为操作选中；Network **无**聚合请求 |
| **B** 展开右栏 → 切到「帮助」→ 单击某行 | 该行高亮；仍停在「帮助」；Network **无**聚合请求 |
| **D** 在 B 之后再点「操作」页签 | 出现聚合请求；面板展示该行订单明细 / 进度等卡片 |
| **C** 已在「操作」页签下单击另一行 | 立即请求新行聚合；高亮切换；面板内容更新 |
| **E** 在「操作」页签下先选中一行 → 收起右栏 → 再展开 | 默认切到 **「操作」** 页签（[工作台规范 §2](../../PRD/规范/UI规范/扩展面板.工作台规范.md)）；若选中仍在 store 则加载/沿用面板数据 |
| **F** 选中行后点「查询」刷新列表 | 操作面板清空为「请先选择记录」；需重新单击行 |

---

## 三、功能抽查（非门控）

| 步骤 | 预期 |
|------|------|
| 「操作」下选中有备货库存的行 | 出现「备货库存」卡片 |
| 无备货库存 | 不显示该卡片 |
| 有使用备货记录 | 出现「使用备货」卡片 |
| 布局 §2.5 | 状态区 3 列网格；单标签仅占第一列。「使用备货」等为双列 Key:Value |
| 双击行 | 进入销售订单详情（不被单击逻辑挡住） |
| 脱敏账号 | 「操作」页签下单击仍加载；敏感字段为 `—` |

---

## 四、与左栏检索交叉

preset「使用备货」等口径抽查仍见 [左栏检索-测试对照说明](./销售订单明细列表-左栏检索-测试对照说明.md)；打开操作面板查看「使用备货」卡片时，须先满足本节 **C** 或 **D**（右栏展开且在「操作」页签）。
