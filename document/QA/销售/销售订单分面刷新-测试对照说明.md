## 一、入口与权限

权限用例已集中维护于：[权限/销售订单分面刷新-权限测试对照说明.md](../权限/销售订单分面刷新-权限测试对照说明.md)。

本节保留核心结论：全部六分面需销售订单写权限 + 本单数据范围；无新权限码、无新迁移。

**本功能不适用：** 工作台/桌面左栏队列（§4.3）、列表页签模式 / 左栏检索 / 操作面板门控（§4.4）、多租户皮肤 / 打印（§4.6）。无需新 SQL / 迁移 / 重新登录（§4.7）。

**本版不测：** 「刷新全部」（无入口）。列表页右上角「刷新」是重查列表，不是本功能。库存换堆 / 删除空汇总（销售分面不做）。

**本轮核对：** 已完结须预检列出、确认后才覆盖（§九）；编辑换客户不套详情 `confirmCompleted`（§九步骤 6）。客户默认不允许已完结，见参数页对照。装箱主表型号/品牌销售分面会覆盖；若之后采购订单也刷新型号，后执行者生效（§四步骤 12）。

## 二、刷新状态

前置：明细扩展出库进度与头表主状态曾脱节。

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 点「刷新状态」并确认 | `POST …/refresh` body `facet=status` |
| 2 | 确认文案 | 说明不改客户、型号、品牌、数量、单价 |
| 3 | 扩展进度 / 主状态 | 按出库、收款、开票事实对齐；可下调 |
| 4 | 出库通知 | **状态**可按出库事实重算；`MaterialCode` / `MaterialName` / `Quantity` **不变** |
| 5 | 装箱 / 库存 / 出库 / 应收 | 单价、数量、型号、品牌快照不变 |
| 6 | 操作日志 | 有「刷新状态」（若确实有字段变化） |

## 三、刷新客户

口径与 [销售订单编辑保存-客户名称-测试对照说明](./销售订单编辑保存-客户名称-测试对照说明.md) 详情刷新相同。本页只核对：下拉「刷新客户」仍走预检。参数关：已完结且客户不一致 → 无法刷新。参数开：预检列出**将覆盖**的已完结出库通知/装箱/出库单，确认后 `confirmCompleted=true`；取消则不刷新。已核销应收**客户主键**不改、不进将覆盖列表；主键已一致时**名称快照**可对齐主数据。已开票销项仍不改客户。不改销售价 / 品牌 / 数量。

---

## 四、刷新物料型号 / 刷新品牌

前置：销售明细已改型号或品牌（及客户料号/客户品牌）并保存；出库通知、装箱、装箱扩展、应收仍是旧快照。库存中心分堆仍按**采购**型号/品牌。

**本功能不适用：足额成功 / 超额拒绝的核销或发票匹配提交。** 本分面不改销售价、应收金额、收款流水。

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 「刷新品牌」确认 | `facet=brand`；确认框为警告样式；文案写明改出库通知/装箱/应收品牌快照，**不改库存分堆** |
| 2 | 出库通知 | `MaterialName` = 销售行当前品牌；`MaterialCode` 不变 |
| 3 | 装箱明细 | `Brand` 更新；`Pn` 不变 |
| 4 | 装箱扩展 | `customer_brand` = 销售行客户品牌；`customer_pn` 不变 |
| 5 | 应收 | `Brand` 更新；`PN` 不变；金额不变 |
| 6 | 库存明细 | `purchase_brand` / `purchase_pn` **不变**；**库存明细编号不变**；不换堆 |
| 7 | 采购订单 / 报关采购型号品牌 | **不变** |
| 8 | 「刷新物料型号」对称 | 只改型号类（含客户料号），品牌不变 |
| 9 | 已出库通知；参数「刷新物料型号」允许 | 预检列出已出库等单据；确认后仍覆盖快照 |
| 9b | 同上；参数改为不允许 | **整面拦住**，快照不变 |
| 10 | 已核销应收；参数允许 | 列出该应收；确认后覆盖 PN/Brand 展示列，核销金额不变 |
| 11 | 结果弹窗 | 含出库通知 / 装箱 / 装箱扩展 / 应收计数；**无**换堆 / 新建汇总 / 删除空汇总 |
| 12 | 交叉：采购订单对该库存也「刷新物料型号」 | 装箱主表型号可能被采购覆盖；销售再刷则改回销售行。后执行者生效 |

## 五、刷新数量

**本功能不适用：足额成功 / 超额拒绝的核销或发票匹配提交。** 刷新数量不发起收款核销、开票匹配，也不改已有流水或实出数量。

刷新后行总额仍为：

```text
行总额 = 销售行数量 × 当前单价
出库通知不改单价
```

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 一行仅 1 条**未出库**通知，数量 1000，销售行 800，点「刷新数量」 | 通知数量变为 800；型号、品牌、单价不变 |
| 2 | 一行 2 条分批通知（300+200），销售行 1000 | 各批次数量**不变**（不扩成整单） |
| 3 | 一行仅 1 条**已出库**通知，数量大于销售行 | 预检按参数列出该已出库通知；确认后通知数量**仍不变** |
| 4 | 实出 / 库存 / 装箱数量 | **不变** |
| 5 | 销售数量小于已实出，或小于有效通知合计 | 失败，提示不能小于已实出或已通知 |
| 6 | 扩展待通知量、出库进度 | 按新计划量与现有出库事实重算 |
| 7 | 关联：刷新数量后去收款核销桌面 | 待核销仍按应收金额（实出未改）；**足额成功**，略超**拒绝**（验收见收款核销对照） |
| 8 | 行上有已出库通知；参数不允许 | 拦住，未出库通知也不改 |

## 六、刷新单价

入口改为「刷新 ▾ → 刷新单价」。金额、超额警告、幂等见 [下游销售价刷新对照](./销售订单下游销售价刷新-测试对照说明.md) §二～§五。

额外：刷新单价后出库通知 **品牌、型号、计划数量不变**。有已完结下游时须确认；参数关闭则拦住（相对现网「无状态门控点了就改」的补加）。

**足额 / 超额（关联回归，强制）：** 刷新不提交核销。刷新后用新待核销 / 新待匹配去收款核销或开票匹配：**足额成功**；略超**拒绝**。公式见单价对照 §四。

## 七、分面互不污染

| 操作 | 不得发生 |
|------|----------|
| 刷新状态 | 出库通知 `MaterialCode` / `MaterialName` / `Quantity`、装箱型号/品牌、下游销售价被改写 |
| 刷新品牌 | 销售价、数量、型号被改写；库存明细编号被改写 |
| 刷新物料型号 | 品牌、销售价、数量被改写；库存明细编号被改写 |
| 刷新数量 | 实出/库存/装箱实绩数量、品牌、单价被改写；已出库通知数量被改写 |
| 刷新单价 | 品牌、型号、出库通知分批数量被改写 |
| 刷新客户 | 销售价、品牌、数量被改写；已核销应收 / 已开票销项客户被改写 |

|------|------|
| 销售金额脱敏 | 面板仍能刷新状态/单价；金额列可为「—」，结果弹窗仍可出现计数/警告 |
| 无本单范围 | 任一 facet 均 403 |

## 九、已完结预检与确认

页面：销售订单详情；参数页见 [销售参数 · 分面刷新](./销售参数-刷新客户-测试对照说明.md)。

**本功能不适用：足额成功 / 超额拒绝的核销提交**（本门控不改金额流水）。刷新单价之后的核销边界仍见 §六。

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 无已完结下游，刷新型号 | 预检 `hasCompleted=false`；确认后 `confirmCompleted` 可为 false；快照按分面覆盖 |
| 2 | 有已出库通知；参数型号允许 | 警告列出「出库通知…已出库」；取消不刷新；确定后 `confirmCompleted=true` 且覆盖型号快照 |
| 3 | 有已出库通知；参数型号不允许 | 提示无法刷新已完结节点；不发 refresh（或 refresh 400）；快照不变 |
| 4 | 刷新状态，即使行已完结 | **不**走已完结门控；只重算状态 |
| 5 | 直接调 refresh 且 `confirmCompleted=false`（有已完结、参数开） | 后端拒绝「须确认后再刷新」 |
| 6 | 编辑页换客户保存（参数开、有已完结出库链） | 仍可保存同步（不套详情确认标志）；确认框应能看到已完结清单 |
| 7 | 已核销应收；刷新客户；参数允许 | 不阻断；应收客户**主键**不改；不进将覆盖列表。主键已一致、名称过期时预检非 NoOp，确认后只改名称 |
| 8 | 已核销应收；刷新单价；参数允许 | 列出该应收；确认后覆盖单价/总额（超额警告口径见单价对照） |

## 十、回归 / 交叉

| 项 | 预期 |
|----|------|
| 兼容路径 `POST …/refresh-item-extends` | 仍只做刷新单价 |
| Debug「刷新销售订单状态」 | 只重算状态，不覆盖全库销售价 |
| 保存销售明细（改数量后保存，不点刷新状态） | 仍按 Default Recalculate 收缩超量单条**未出库**通知（业务事件） |
| 保存销售明细（改型号后保存，不点刷新型号） | 出库通知/装箱型号快照**不**自动改 |
| 采购订单分面刷新型号 | 库存分堆按采购身份变；销售分面不抢采购分堆 |
| 出库运维检查「刷新客户」指引 | 入口仍是详情「刷新 ▾ → 刷新客户」 |

## 十一、与自动化对应

| 用例 | 覆盖点 |
|------|--------|
| Recalculate StatusOnly 不改出库通知数量/型号/品牌 | 刷新状态不写快照 |
| QtyPlanOnly 只收缩未出库单条超量通知 | 刷新数量 |
| 分批通知不扩成整单 | 与现网 `AlignStockOutRequestsWithSoLineQtyAsync` 一致 |
| 已出库通知数量不被收缩 | 与采购可收缩已入库到货的差异 |
| Identity Apply 型号不改品牌、不改库存 purchase_pn、不换堆 | 分面隔离 |
| Identity 更新装箱主表 + 装箱扩展客户料号 | 创建口径 |
| Preview 参数关 + 已出库 → 整面阻断 | 第二期门控 |
| EnsureAllowed 参数开未确认 → 拒绝；确认后放行 | `confirmCompleted` |
| 单价套件 | 见下游销售价刷新对照 §七 |
| 客户套件 | 见编辑保存客户名称对照 §五；补详情 `confirmCompleted` |
