# 销售订单下游销售价刷新 — 测试对照说明

> **页面 / 路由：** `/sales-orders/:id`（销售订单详情 → 页头「刷新」）  
> **设计文档：** [销售订单下游销售价刷新-设计与实现](../../System/销售/销售订单下游销售价刷新-设计与实现.md)

> **自动化：** `tests/CRM.Core.Tests/Services/SalesOrderSalesPriceDownstreamSyncServiceTests.cs`

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 1 | 打开销售订单详情 | 页头主按钮为「刷新」（下拉「刷新客户」是另一能力，本对照不测客户同步） |
| 2 | 无销售订单写权限 | 「刷新」不可提交（按钮禁用或 403） |
| 3 | 有写权限、无本单数据范围 | 403，下游单价不变 |
| 4 | 点「刷新」 | 确认框说明：按当前销售单价覆盖装箱 / 库存 / 出库 / 应收快照（含已出库、已核销、已开票）；收款流水与发票票面不改 |
| 5 | 取消确认 | 不请求 `POST /api/v1/sales-orders/{id}/refresh-item-extends` |

**本功能不适用：** 工作台/桌面左栏队列（§4.3）、列表页签模式 / 左栏检索 / 操作面板门控（§4.4）、多租户皮肤 / 打印（§4.6）。无需新 SQL / 迁移 / 重新登录（§4.7）。

## 二、黄金路径（改价后刷新）

前置：客单已出库，装箱、库存层、出库明细、应收均已按**旧单价**落快照。编辑销售订单把该行单价改为新值并保存（折算美金随保存重算）。

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 详情点「刷新」并确认 | `POST …/refresh-item-extends` 成功 |
| 2 | 结果弹窗 | 列出该行旧单价 → 新单价；装箱 / 库存 / 出库明细 / 出库单头 / 应收计数 ≥ 1 |
| 3 | 装箱明细 | 销售价 / 币别 / 折算美金 = 销售行当前值 |
| 4 | 库存明细 | 销售价快照与入库毛利快照按新折算美金 × 入库数量重算 |
| 5 | 出库列表 / 出库明细 | 销售单价读扩展快照，为新单价（不从旧库存层抄回） |
| 6 | 出库单头金额 | `Σ(该出库单各行出库数量 × 该行扩展销售单价)`；一箱多销售行时，其它行仍用各自扩展价 |
| 7 | 应收 | `UnitPrice` = 新单价；`Amount = 出库数量 × 新单价` |
| 8 | 销售明细扩展 | 出库利润等随 Recalculate 更新，与出库扩展合计一致 |
| 9 | 操作日志 | 本单有「刷新销售价」，含操作人、行号、旧→新、条数 |

## 三、无状态门控

| 步骤 | 预期 |
|------|------|
| 下游已出库完成 | **仍覆盖**销售价，不提示阻断 |
| 应收已核销完成 | **仍改**应收总额与待核销；核销流水金额不变 |
| 应收已开票匹配完成 | **仍改**应收总额与待匹配；销项发票票面不变 |
| 报关已申报 | 申报单价**不变** |
| 采购价 / 入库成本 | **不变** |

## 四、金额与核销 / 匹配口径

**本功能不适用：足额成功 / 超额拒绝的核销或发票匹配提交。** 刷新不发起核销、不发起开票匹配，也不改已有流水。

刷新后应收公式（须手工核对）：

```text
Amount = OutboundQty × 销售行当前单价（四舍五入到 2 位）
VerifiedDone、InvoiceMatchDone 保持原值
VerifiedToBe = Amount − VerifiedDone   （可为负，不拦截）
InvoiceMatchToBe = Amount − InvoiceMatchDone   （可为负，不拦截）
核销/开票匹配状态按新总额与已完成额重标
```

| 用例 | 操作 | 预期 |
|------|------|------|
| 未核销改价 | 出库数量 2、旧单价 10→20 后刷新 | 应收总额 40，待核销 40，状态未核销 |
| 已核销超额（降价） | 已核销 20，新总额 16 后刷新 | **不拒绝**；总额 16，已核销仍 20，待核销 -4；结果弹窗警告应收编号、已核销、新总额 |
| 已开票匹配超额 | 已匹配 20，新总额 16 | 同口径警告「已开票匹配大于新总额」；发票票面不变 |
| 升价后待核销变大 | 已核销 10，新总额 40 | 待核销 30，状态部分核销；**无**超额警告 |
| 刷新后足额核销（关联回归） | 用新待核销金额去收款核销桌面提交 | 按核销功能原规则：**足额成功**；略超新待核销则**拒绝**（验收见收款核销对照，本页只确认余额已是新值） |

## 五、结果提示与幂等

| 步骤 | 预期 |
|------|------|
| 单价与下游已一致 | 「无更新数据」（扩展进度也无变更时） |
| 扩展进度无变更，但下游单价有覆盖 | **不**显示「无更新数据」，展示下游计数 |
| 连续点两次刷新 | 第二次下游计数为 0（或无单价变化行） |
| 销售金额脱敏 | 面板仍能刷新；金额列可为「—」，结果弹窗仍可出现计数/警告 |

## 六、回归 / 交叉

| 项 | 预期 |
|----|------|
| 「刷新 ▾ → 刷新客户」 | 仍只同步客户，不改销售价 |
| 出库列表导出销售价 | 优先扩展快照，刷新后导出为新单价 |
| 明细绩效出库利润 | 展开绩效后与出库扩展 `ProfitOutBizUsd` 合计一致 |
