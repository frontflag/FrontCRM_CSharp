## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 1 | 参数管理 → 销售参数 | 左栏可见「分面刷新」（原「刷新客户」位置） |
| 2 | 无 read | 左栏无此项、不可进入 |
| 3 | 有 read 无 write | 可看五个开关，保存 403 或按钮不可用 |
| 4 | 有 write | 可保存 |

**本功能不适用：** 工作台/桌面（§4.3）、列表页签/操作面板（§4.4）、多租户皮肤/打印（§4.6）、金额核销提交（§4.5，本页只开关，不提交核销）。无需新 SQL / 迁移；改完不必重新登录（§4.7）。

---

## 二、页面与默认

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 进入分面刷新 | 五个开关：刷新客户 / 物料型号 / 品牌 / 数量 / 单价 |
| 2 | 未配置过 | 客户 = 不允许（沿用现网：改已完结客商身份风险高）；型号、品牌、数量、单价 = 允许（避免上线后单价行为倒退） |
| 3 | 改若干项并保存，刷新页面 | 保持刚保存的组合 |
| 4 | 只改客户开关并保存 | 旧「允许刷新已完成业务节点」接口读到的值与客户开关一致 |

---

## 三、业务联动

| 场景 | 开关 | 预期 |
|------|------|------|
| SO 下游有已出库完成装箱，客户不一致 | 客户不允许 | 刷新客户被阻断 |
| 同上 | 客户允许 | 预检列出已完结出库链；详情须确认才同步；已核销应收 / 已开票仍不改客户 |
| 有已出库通知 | 型号不允许 | 刷新物料型号拦住 |
| 同上 | 型号允许 | 列出已出库等，确认后覆盖销售身份快照（不换库存堆） |
| 行上有已出库通知 | 数量不允许 | 刷新数量拦住 |
| 应收已核销 / 已开票匹配 | 单价不允许 | 刷新单价拦住 |
| 行已完结 | （任意） | **刷新状态**仍可进行，不看本页开关 |

编辑销售订单换客户保存：不要求详情页的确认标志；参数关时仍按原换客户阻断。

---

## 四、回归

- 采购参数「分面刷新」不受影响  
- 开关为不允许时，原刷新客户阻断口径不变
