# 销售订单明细列表 — 左栏检索 — 测试对照说明

> **页面：** `/sales-order-items`  
> **设计文档：** [销售订单明细列表-左栏检索-设计与实现](../../System/销售/销售订单明细列表-左栏检索-设计与实现.md)

---

## 一、入口与布局

### 1.1 前置条件

- 测试账号具备销售订单明细列表读权限（非 mask521 时可测客户 keyword）
- 左栏切换到 **「检索」** 页签

### 1.2 预期

| 步骤 | 预期 |
|------|------|
| 进入 `/sales-order-items` | 左栏显示五组 preset：下单时间 / 待办 / 业务进度 / 库存 / 收款 |
| 主栏 | keyword 输入区 + 「高级筛选」+ 查询/重置/看板切换 |
| 无 preset | URL 无 `preset`/`quickFilter`；高级筛选可用 |

---

## 二、preset 切换与 URL

| 步骤 | 预期 |
|------|------|
| 点击「待申请采购」 | URL 含 `preset=pending_submit_purchase_req`、`quickFilter=pending_submit_purchase_req`；左栏高亮；主栏 chip 显示同名文案 |
| 再点同一项 | **清空全部 query**（含 keyword），恢复默认列表 |
| 点击 chip ✕ | 同上，全部清空 |
| 选 preset 后在 keyword 填「型号」点查询 | URL 保留 preset + keyword；列表与看板均带 `pn` |
| 选「近 7 日订单」 | URL 含 `preset=order_last_7_days`、`orderCreateStart/End`（本地 YYYY-MM-DD）；**无** `quickFilter` |
| 选「本周订单」 | `orderCreateStart` = 本周周一，`orderCreateEnd` = 今日；周一为一周起点 |
| 选「本月订单」 | `orderCreateStart` = 本月 1 日，`orderCreateEnd` = 今日 |

---

## 三、高级筛选互斥

| 步骤 | 预期 |
|------|------|
| 任意业务 preset 激活 | 「高级筛选」按钮 disabled；展开区日期与六 progress disabled；底部提示文案出现 |
| 清除 preset | 高级筛选恢复可用；progress 字段为空 |

---

## 四、列表与看板口径一致

1. 选 preset「待申请出库」，记录列表 **total** 与看板 KPI（成单明细数等）。
2. 切换看板 ↔ 列表，不修改 query。
3. **预期：** 看板请求 params 含相同 `quickFilter`；统计范围与列表筛选一致。

对时间 preset：看板与列表均应带相同 `orderCreateStart/End`。

---

## 五、业务 preset 抽样核对

以下每条：选 preset 后，抽 1～2 行与按钮/进度列对照。

| preset | 核对要点 |
|--------|----------|
| `pending_submit_audit` | 主单 status 为新建(1)或审核失败(-1)；明细未取消 |
| `pending_submit_purchase_req` | 主单已审核+；「申请采购」按钮可点（剩余可申请 >0） |
| `pending_submit_stock_out_notify` | 与「申请出库」按钮 enabled 行集合一致（含备货放宽）；`QtyStockOutNotifyNot > 0` |
| `applied_pending_po` | 有未完结 PR、无有效 PO 行 |
| `purchased_pending_stock_in` | 采购完成、入库待/部分；列表「入库状态」为待入库或部分入库；出库通知已满且入库仍为待入库的行应排除 |
| `notify_pending_packing` | 存在 status=10 的出库通知 |
| `packed_pending_stock_out` | 存在 status=20 通知且出库进度 <2 |
| `in_stock_pending_out` | 同行列：入库状态为部分/完成，且出库状态为待/部分（非出库完成） |
| `used_stocking` | 打开操作面板应出现「使用备货」卡片；无备货补充拣货的行不应出现 |
| `stock_out_pending_receipt` | 应收款（已出库且收款未完成或有未收金额） |
| `receipt_partial` / `receipt_complete` | 收款进度列 = 部分 / 完成 |
