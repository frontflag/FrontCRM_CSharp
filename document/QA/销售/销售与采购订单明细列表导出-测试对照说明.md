## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有对应列表查看权限 | 搜索栏「看板/列表」后浅黄「导出」可见，可下载 CSV |
| 无列表查看权限 | 无法进入列表，亦无导出 |
| 无 write 仅有 read | 仍可导出（导出不是写操作） |
| 看板 / 列表切换 | 「导出」始终可见；导出内容跟当前筛选，与是否处于看板视图无关 |
| 销售/采购订单**主表**列表 | 本版无导出按钮（主表以后再套） |

## 二、列表导出

| # | 步骤 | 期望 |
|---|------|------|
| 1 | 销售订单明细设筛选 → 「导出」→ 确认 | 下载 `销售订单明细_yyMMddHHmm.csv`；**导出日志**业务类型=销售订单明细列表（底层 `BizType=SellOrderItem`、`ActionType=SalesOrderItemListExport`、`RecordCode=SALES_ORDER_ITEM_LIST`）；「导出条件」与筛选一致（业务名称） |
| 2 | 采购订单明细同上 | `采购订单明细_*.csv` + `PurchaseOrderItemListExport` / `PURCHASE_ORDER_ITEM_LIST` / `BizType=PurchaseOrderItem` |
| 3 | 无筛选导出 | 条件摘要「全部（无筛选）」 |
| 4 | 左栏快捷检索（preset）生效时导出 | 条件含快捷检索中文名；**不含**被互斥掉的进度多选 |
| 5 | 页签模式点页签后导出 | 导出跟当前生效筛选（币别/进度/订单类型页签），不是仅当前页 |
| 6 | 进度多选（如采购中+采购完成） | 导出行与列表同一查询；日志摘要为中文业务名，不是 `1,2` |
| 7 | 勾选若干行后再导出 | 仍导出**当前筛选全量**，不是仅勾选篮子 |
| 8 | 列表隐藏部分列后再导出 | CSV 仍为固定全量列（不跟列显隐） |
| 9 | Excel 打开 CSV | 可直接打开；中文不乱码（UTF-8 BOM） |
| 10 | CSV 不含 | 无「操作」列；无分页残留 |

## 三、数据范围与脱敏

| # | 步骤 | 期望 |
|---|------|------|
| 11 | 521 账号导出销售明细 | 客户中英文、业务员、创建人为 `***`；客户订单号/客户料号为空；单价/行金额/折算美金/利润三列及对应币别为空；客户名等无权限筛选项不出现在 filters |
| 12 | 有销售金额权限、非 521 | 销售利润、出库利润、出库利润率有数（利润率在 rate=0 且利润≥0 时为空，与列表一致） |
| 13 | 无销售金额权限、非 521 | 利润三列与金额/币别为空；客户列按客户权限出明文或 `***` |
| 14 | 511 账号导出采购明细 | 供应商中英文为 `***`；单价/行金额及币别为空 |
| 15 | 有供应商权限、无采购金额权限 | 供应商中英文仍导出；金额及币别为空 |
| 16 | 部门/业务数据权限账号 | 导出行集合与列表同一数据范围（不能比列表多看到行） |

本导出**不提交**核销/匹配金额，故总纲 §4.5「足额成功 / 超额拒绝」**本功能不适用**（无写入待核销余额的操作）。

## 四、CSV 列与口径

### 4.1 销售订单明细

销售订单明细、销售订单号、主状态、客户中文、客户英文、业务员、采购员、物料型号、品牌、客户订单号、客户料号、数量、单价、单价币别、行金额、行金额币别、折算美金单价、折算美金行金额、销售利润、出库利润、出库利润率、采购进度、入库进度、出库通知进度、出库进度、收款进度、开票进度、创建日期、创建人

| # | 步骤 | 期望 |
|---|------|------|
| A | 主状态 / 各进度 | 中文业务名（如「审核通过」「待采购」），不得仍为数字码 |
| B | 创建人 | 与列表一致：回退业务员；521 为 `***` |
| C | 出库利润率 | 与列表同一口径；成本为 0 或 rate=0 且利润≥0 时为空 |

### 4.2 采购订单明细

采购订单明细、采购订单号、货代单号、明细状态、供应商中文、供应商英文、采购员、物料型号、品牌、数量、单价、单价币别、行金额、行金额币别、创建日期、创建人、请款进度、付款进度、采购进度、入库进度、发票进度

| # | 步骤 | 期望 |
|---|------|------|
| D | 明细状态 / 各进度 | 中文业务名 |
| E | 请款进度 | 已有有效请款为「已申请」，否则「待申请」 |
| F | 订单类型 / 交易币别筛选 | 日志摘要为「客单采购 / 备货采购 / 样品采购」「人民币 / 外币」，不是数字码 |

## 六、回归注意

| # | 说明 |
|---|------|
| A | 列表页筛选下拉仍可显示码值；仅 **CSV 单元格** 与导出日志条件摘要为业务名称 |
| B | 左栏 preset 与进度筛选互斥：导出必须与列表同一套互斥，不能把 preset 与进度一起传 |
| C | 进度数组必须用重复 query key，不能变成逗号拼接字符串 |
| D | 销售/采购订单主表列表本版不测导出 |

## 七、本功能不适用（总纲裁剪）

| 维度 | 说明 |
|------|------|
| 工作台 / 桌面（§4.3） | 本功能不适用：导出不是左栏队列桌面 |
| 操作面板门控（§4.4 操作面板） | 本功能不适用：导出不经过右侧操作/流程页签 |
| 金额核销足额/超额（§4.5） | 本功能不适用：导出不提交核销或匹配 |
| 看板公式（§3.2 / 数据分析） | 本功能不适用：看板统计见既有明细看板对照/帮助；导出只出列表行 |
| 多租户皮肤 / 打印（§4.6） | 本功能不适用：CSV 无租户皮肤、无打印 |

页签模式 / 左栏检索的**筛选互斥**对导出适用，见上文 §二 #4、#5 与 §五 #21；操作面板门控本身不适用。
