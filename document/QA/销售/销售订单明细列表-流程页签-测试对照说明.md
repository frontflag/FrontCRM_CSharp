# 销售订单明细列表 — 右侧「流程」页签 — 测试对照说明

> **页面：** `/sales-order-items`  
> **设计文档：** [销售订单明细列表-流程页签-设计与实现](../../System/销售订单明细列表-流程页签-设计与实现.md)  
> **UI 规范：** [流程页签.当前业务指示规范](../../PRD/规范/UI规范/流程页签.当前业务指示规范.md)  
> **关联门控：** 与操作面板共用选中行 / aggregates；见 [操作面板-测试对照说明](./销售订单明细列表-操作面板-测试对照说明.md)

---

## 一、前置

- 账号可打开销售订单明细列表（非脱敏账号便于看客户与金额）
- 右栏可见页签：**操作 / 流程 / 帮助**
- 销售订单详情 `/sales-orders/:id` 右栏同样有 **操作 / 流程 / 帮助**；流程与列表同面板，由详情内选中（或默认首条）明细驱动；「销售订单明细」站标题旁有当前业务指示
- Network 可过滤 `detail-tab-aggregates`

---

## 二、交互门控

| 步骤 | 预期 |
|------|------|
| **A** 收起右栏后单击行 | 不展开、不选中、无 aggregates 请求 |
| **B** 展开 →「帮助」→ 单击行 | 行高亮；仍停在帮助；无请求 |
| **D** 在 B 之后点「流程」 | 出现（或复用）aggregates；展示纵向流程轴；「销售订单明细」站标题旁有橙色左指手势（当前业务指示），轨道仍为状态色圆点 |
| **C** 已在「流程」下单击另一行 | 请求/切换到新行；轴内容更新 |
| 在「操作」已加载后切「流程」 | **不再强制重复请求**（可复用 store）；内容与同行一致 |
| 脱敏账号 | 单击不选中、不请求 |

---

## 三、节点与展示抽查

| 步骤 | 预期 |
|------|------|
| 无下游单据的新明细 | 仅「销售订单明细」为实心/有卡；其余为空心「未开始」 |
| 有多张采购申请 | 「采购申请」同站多卡，创建时间 **早→晚** |
| 采购申请 / 采购明细 / 质检 / 入库 / 使用备货 | **无**「客户名称/客户编号」行 |
| 销售明细、出库通知、装箱、出库、收款、发票 | **有**客户相关行（有数据时） |
| 使用备货有记录 | 站在「出库通知」之后；单号为 **采购单号**，可跳转采购详情 |
| 收款核销 / 发票 | 显示 **金额·币别**，不显示数量 |
| 采购申请采购员 | 当前接口无字段时人员为 **—** |
| 发票创建人 | 当前接口无字段时人员为 **—** |
| 描述 | 为空或 — |
| 窄右栏 | 无横向滚动；长单号可换行 |

## 四、报关图标（入库 / 出库通知 / 装箱 / 出库）

本功能不适用：金额核销/匹配（无提交金额，无足额/超额场景）；桌面左栏队列；多租户打印皮肤；无新 SQL/权限脚本。

| 步骤 | 预期 |
|------|------|
| 采购入库 / 销售出库等同站非报关卡 | 单号右侧 **无** 报关图标 |
| 报关类型且已有报关单 | 单号右侧彩色报关图标；悬停两行：**报关单号**、**报关公司**（缺值为 —） |
| 点击已有报关单的图标 | **新开页** 打开该报关单详情（当前页流程不关） |
| 报关类型但尚未生成报关单（如刚生成的报关出库通知） | 单号右侧 **灰色** 图标；悬停「暂未生成报关单」；点击不跳转 |
| 销售订单详情 `/sales-orders/:id` 切「流程」 | 与明细列表同面板、同样规则 |
| 脱敏账号能加载流程时 | 报关图标仍按类型显示；不因 511/521 隐藏 |

图标展示不按报关模块权限隐藏；无报关权限点进详情时按报关模块既有拦截。

---

## 五、站态

| 步骤 | 预期 |
|------|------|
| 某站无任何单据 | 空心 +「未开始」 |
| 出库单为准备出库 | 出库站为进行中，不标已完成 |
| 出库单、出库通知、入库、采购申请为已取消 | 对应站为已取消 |
| 质检未通过 | 质检站为未通过 |
| 采购明细审核失败、销项发票开票失败 | 对应站为审核失败、开票失败 |
| 销项发票已作废 | 发票站为已取消 |
| 销售订单审核失败 | 销售订单站为审核失败 |
| 销售明细未取消，且收款完成、开票完成 | 销售订单明细站为已完成；卡片仍为「正常」 |
| 做完与已取消混在一起，没有进行中、也没有失败类 | 已完成 |
| 有失败类且没有进行中 | 失败优先 |

本功能不适用：金额提交的足额成功与超额拒绝。上表为 [流程页签规范 §0.4](../../PRD/规范/UI规范/流程页签规范.md) 的预期。已落地，按本节验收。

## 六、回归交叉

- 操作面板行为不被破坏（申请采购/出库、备货库存卡片仍在「操作」）。
- 双击行仍进入销售订单详情。
- 物流列表流程页签的报关图标仍挂在类型标签旁；无报关单时不出图标（不套用销售明细「灰色待生成」）。
