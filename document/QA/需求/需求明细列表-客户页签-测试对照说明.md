# 需求模块 — 客户页签 — 测试对照说明

> **设计文档：** [需求模块-客户页签-设计与实现](../../System/需求/需求明细列表-客户页签-设计与实现.md)

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 无需求读权限 | 不可进入上述页面 |
| 打开需求明细，展开右栏 | 页签顺序 **物料 → 客户 → 帮助**；默认 **物料**（若无本页记忆） |
| 打开需求列表 / 需求详情，展开右栏 | 页签顺序 **客户 → 帮助**；默认 **帮助**（若无本页记忆） |
| 点「客户」且列表未选行 | 提示单击列表行查看客户 |
| 需求详情（非回收站）打开后点「客户」 | 无需再点明细行即可出摘要（按单头客户） |
| 能打开该客户详情的账号 | **三块**卡片：概况（编号橙色主标题、中英文名、档案业务员）；基本信息、财务信息为独立卡片，**标签：值**（13px，非两列大号指标） |
| 上述账号下客户编号、中文名、英文名 | **可点**进入客户详情（当前页） |
| 无客户模块查看权限，或该客户不在数据范围内 | 仅概况中的 **客户编号、业务员**；无基本信息/财务信息卡片；编号 **不可点** |
| 521 采购脱敏账号 | **永远**与上一行相同（即使有客户模块权限） |

---

## 二、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 需求数据范围外的单据 | 客户页签失败或看不到该行（与列表一致） |
| 列表已打码客户名的 521 账号 | 仍可出编号 + 档案业务员；名称/额度不下发 |
| 客户档案业务员与需求单业务员不同 | 页签显示 **档案业务员** |
| Network | `GET /api/v1/customer-workspace?source=rfqItem|rfq&id=`，**不**带 `customerId` |

---

## 三、门控与空态

| 步骤 | 预期 |
|------|------|
| 需求明细：右栏在「帮助」或「物料」时单击行 | **不**请求客户摘要（Network 无 `customer-workspace`） |
| 需求列表：默认停在帮助时单击行 | **不**请求；也不自动切到「客户」 |
| 再点「客户」 | 才请求并展示 |
| 右栏收起时单击行 | 不请求；展开且当前是「客户」后再加载 |
| 列表搜索 / 重置 | 右栏回到未选行 |
| 无客户的需求 | 「该单据未关联客户档案」 |
| 需求明细看板 | 不因看板点击加载客户 |
| 回收站只读详情 | 不绑定客户摘要 |

---

## 四、字段核对（有完整权限时）

与 **客户详情** 对照同一客户：编号、中英文名称、类型/等级/行业、账期、结算币别、信用额度一致。地区取客户主表省市，可能与详情默认地址不完全相同。税率为空则 —。

---

## 五、本功能不适用

- **本功能不适用：§4.5 核销金额足额成功 / 超额拒绝**（只读展示信用额度，不提交核销）。
- **本功能不适用：多租户打印皮肤**。
- **本功能不适用：工作台左栏队列 / 顶栏 N/M**。
- **本功能不适用：销售订单 / 履约 / 收款右栏**（销售见 [销售订单-客户页签-测试对照说明](../销售/销售订单-客户页签-测试对照说明.md)；履约见 [履约单据-客户页签-测试对照说明](../物流/履约单据-客户页签-测试对照说明.md)；收款见 [收款记录-客户页签-测试对照说明](../财务/收款记录-客户页签-测试对照说明.md)）。
