# 需求明细列表 — 筛选页签模式 — 测试对照说明

> **页面：** `/rfq-items`（需求明细）  
> **设计文档：** [需求明细列表-筛选页签模式-设计与实现](../../System/需求/需求明细列表-筛选页签模式-设计与实现.md)

---

## 一、入口与默认

| 步骤 | 预期 |
|------|------|
| 进入页面（未开过页签模式） | 无页签条；搜索栏显示「全部明细状态」下拉 |
| 点击看板旁齿轮 | 弹出「关闭页签」（禁用）、「页签模式 ▸」 |
| 悬停「页签模式」 | 子菜单仅 **明细状态** 一项 |

---

## 二、开启、切换与关闭

| 步骤 | 预期 |
|------|------|
| 页签模式 → 明细状态 | 明细状态下拉隐藏；表格/看板上方出现 7 格：全部 / 待报价 / 已报价 / 查无报价 / 已接受 / 已拒绝 / 已关闭；「关闭页签」可点；子菜单该项高亮 |
| 点「查无报价」 | **立即**查询；URL 带 `itemStatus=5`；列表与看板一致 |
| 点「全部」 | 清除 `itemStatus`；立即查询 |
| 关闭页签 | 页签条消失；下拉恢复且仍为关闭前选中值（如查无报价）；不自动清筛选 |

---

## 三、与「查询」按钮差异

| 步骤 | 预期 |
|------|------|
| 仅改其它筛选项（未开页签）不点查询 | 不请求（与现网一致） |
| 点击页签 | **立即**请求，无需再点查询 |

---

## 四、明暗主题（抽查）

| 步骤 | 预期 |
|------|------|
| 亮色 + 未选中页签 | 背景约 `#E8EDF5`，文字可读 |
| 暗色 + 未选中页签 | 深色层（非浅灰白块），文字可读 |
| 选中页签 | 顶边青色高亮，与未选中区分明显 |

---

## 五、刷新持久化

| 步骤 | 预期 |
|------|------|
| 开启「明细状态」后 F5 | 仍为该维度页签模式（localStorage `crm.rfq-item-list.tab-mode`） |
| 关闭页签后 F5 | 无页签条 |
