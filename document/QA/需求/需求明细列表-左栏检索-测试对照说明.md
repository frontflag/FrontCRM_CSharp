# 需求明细列表 — 左栏检索 — 测试对照说明

> **页面：** `/rfq-items`  
> **设计文档：** [需求明细列表-左栏检索-设计与实现](../../System/需求/需求明细列表-左栏检索-设计与实现.md)

---

## 一、入口与清空

| 步骤 | 预期 |
|------|------|
| 无 `rfq.read` | 不可进入 `/rfq-items` |
| 打开左栏「检索」 | 四组共 **19** 项：需求 / 需求状态 / 报价 / 报价状态；报价状态末项为「有删报价」；无日期表单 |
| 点某一 preset | 主栏出现 chip；日期、明细状态下拉、「有报价」隐藏；若开着状态页签则页签条隐藏 |
| 再点同一 preset 或 chip ✕ | query 清空；隐藏项恢复 |

---

## 二、需求时间（明细创建）

| 步骤 | 预期 |
|------|------|
| 点「10 分钟内需求」 | URL 含 `preset=item_last_10m` 与 `itemCreate*`；列表仅明细 `CreateTime` 落在近 10 分钟的行 |
| 点「今日需求」 | 按**本地日历今日**筛明细创建时间（非主单创建日） |
| 点「3 天内需求」 | 含今日共 3 个本地日历日 |

可用新建不久的明细 vs 旧明细对照。

---

## 三、需求状态

| 步骤 | 预期 |
|------|------|
| 「重要需求」 | 仅主表重要程度存盘值为 **3**（三星）的明细 |
| 「成单需求」 | 与看板「成单明细数」同一链路；在相同其它筛选下，列表行与 KPI 可对账 |

---

## 四、报价时间与报价状态

| 步骤 | 预期 |
|------|------|
| 「今日报价」 | 明细下存在今日创建的报价即命中 |
| 「待报价」 | 报价状态组第一行；等同明细 status=0；状态下拉/页签隐藏 |
| 「查无报价」 | 等同明细 status=5；状态下拉/页签隐藏 |
| 「多条报价」 | 至少 2 条**未软删**关联报价 |
| 「有删报价」 | 报价状态组最后一行；URL `preset=has_deleted_quote` 且 `quickFilter=has_deleted_quote`；chip 中文「有删报价」、英文 Has deleted quotes |
| 选一行底部已展开/可展开「已删报价 n 条」的明细，再点「有删报价」 | 该行必须出现在列表（及看板统计范围内） |
| 选一行底部**无**「已删报价」块的明细，再点「有删报价」 | 该行**不**出现；全库无已删报价时列表为空 |
| 某行当前仍有有效报价，但曾经删过报价 | **仍命中**（不看当前有效报价） |
| 某行明细为待报价 / 已报价 / 查无报价，只要有软删报价 | **均命中**（不看明细状态） |

---

## 五、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 部门/业务数据权限外的明细即使有已删报价 | **不出现**（与无 preset 时同一数据范围） |
| 客户名脱敏（521）/ 供应商名脱敏（511） | 左栏命中不受影响；主栏名称仍按既有掩码 |

---

## 六、keyword 叠加与看板

| 步骤 | 预期 |
|------|------|
| preset + 需求编号/型号/品牌 | 两者同时生效；品牌按主键精确匹配 |
| 物料型号之后选择品牌并查询 | URL 含 `brandId`；列表与看板仅该品牌；控件无「新建品牌」 |
| 重置 | 品牌清空 |
| 切换看板 | 统计范围与列表筛选一致 |

---

## 七、与页签模式交叉

| 步骤 | 预期 |
|------|------|
| 先开「明细状态」页签，再点左栏任意 preset | 状态页签条消失 |
| 清除 preset | 若偏好仍为明细状态页签，页签条恢复 |

---

## 八、本功能不适用

- **本功能不适用：§4.5 核销金额足额成功 / 超额拒绝**（检索不是金额核销/匹配）。
- **本功能不适用：多租户打印皮肤**。
- **本功能不适用：操作面板门控**（本页左栏为快捷检索，不是列表操作面板）。
- **本功能不适用：工作台左栏队列 / 顶栏 N/M**（本页不是审批/核销桌面）。

**上线前置：** 部署含 `has_deleted_quote` 的版本后须**重启 CRM.API**，列表与看板才能识别新 `quickFilter`。

*成单口径对照看板文档 §2.1。*
