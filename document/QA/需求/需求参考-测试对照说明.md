# 需求参考 — 测试对照说明

> **页面 / 路由：** `/rfq-item-reference`（侧栏「需求管理」最后一项「需求参考」）  
> **设计文档：** [需求参考-设计与实现](../../System/需求/需求参考-设计与实现.md)  
> **权限 / DDL：** 无新权限码、无 DDL；须需求读权限 + 销售/采购/采购运营身份（或系统 bypass）

**本功能不适用：** §4.5 金额核销/匹配（足额成功 + 超额拒绝）— 本页只读对照报价单价，不提交核销或匹配。  
**本功能不适用：** §4.3 工作台/桌面左栏队列。  
**本功能不适用：** §4.4 页签模式 / 左栏检索 preset / 操作面板门控 — 本页无左栏、无右栏客户/物料；搜索栏无「列表筛选设置」，不提供页签模式（作业页页签偏好不带到本页）。  
**本功能不适用：** §4.6 多租户皮肤 / 打印。  
**本功能不适用：** §4.7 上线前置 SQL/迁移 — 无新表、无权限脚本。

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 主部门销售 / 采购 / 采购运营，且有需求读权限 | 需求管理组最后一项出现「需求参考」；可打开 `/rfq-item-reference` |
| 兼任采购部门（主部门非采购/采购运营但属于采购侧） | 同样出现菜单 |
| 财务 / 物流 / 客服等其它身份（无 bypass） | **无**该菜单；直链 `/rfq-item-reference` 回控制台；接口带 `reference=true` 返回 403 |
| 销售身份但无需求读权限 | 无菜单、不可进 |
| 系统管理员 / 平台管理员 / 业务经理（bypass） | 可进，便于运维对照 |
| 打开本页 | 需求管理分组保持展开；面包屑为「需求参考」；右栏仅「帮助」，无左栏检索 |
| 需求明细页头「需求参考」 | 在「进入报价桌面」左侧，同款浅蓝按钮；有入口身份才显示；点击在**新窗口**打开 `/rfq-item-reference` |
| 参考页页头 | 无「进入报价桌面」、无「需求参考」按钮 |

---

## 二、作业页不得被带偏

| 步骤 | 预期 |
|------|------|
| 一线业务员打开 `/rfq-items` | 行集合仍按销售数据范围；需求保护规则**不变** |
| 同一账号打开 `/rfq-item-reference` | 可见全公司明细（含保护期内他人行） |
| 报价列表 `/quotes`、报价桌面 | 默认接口**不**因本页放宽数据范围 |
| Network：作业页拉明细 | `GET /api/v1/rfqs/items` **不含** `reference=true` |
| Network：参考页拉明细 | **含** `reference=true` |
| 作业页已开启页签模式 | 参考页仍无齿轮、无页签条；状态下拉可用；作业页页签偏好刷新后仍在 |
| 参考页调整列宽后回作业页 | 作业页列宽/篮子不被覆盖（列设置 key 不同） |

## 三、只读与禁止跳转

| 步骤 | 预期 |
|------|------|
| 主表操作列 | **仅「复制」**；无详情 / 报价 / 查无报价；无复选列 |
| 搜索栏 | 无看板切换；无复选篮子；无「列表筛选设置」齿轮；无表格上方筛选页签；查询/重置后 URL 仍是 `/rfq-item-reference` |
| 双击主表行 / Ctrl+双击 | 不跳转、不打开编辑 |
| 需求编号、客户名、物料型号 | 纯文本，不可点进详情或其它页 |
| 底部报价操作列 | **仅「复制」**；无编辑 / 删除 / 生成销售订单 |
| 双击报价行 | 不进报价详情/编辑 |
| 主表复制 | 剪贴板有型号等摘要；脱敏行不含他人客户名 |
| 报价复制 | 剪贴板**不含**供应商名称 |

## 四、报价码头

| 步骤 | 预期 |
|------|------|
| 未选行 | 提示先点一行 |
| 点一行 | 拉该明细报价；列与需求明细作业页报价面板一致（报价号、型号、品牌、DC、交期、供应商、等级、交易次数、数量、单价、币别、报价员、时间、状态、操作等） |
| 供应商名称 | **一律「—」**（销售、采购都如此；采购在作业页仍可见供应商） |
| 供应商等级、交易次数、单价 | **仍显示**；供应商名为「—」时交易次数仍为数字，不为「—」（仅无次数时才是「—」） |
| Network：报价列表 | `GET /api/v1/quotes?...&rfqItemId=...&reference=true`；作业页同接口无 `reference` |
| Network：无 `rfqItemId` 却带 `reference=true` | 400（须指定需求明细） |
| 报价条数 | 他人明细的条数与实际报价数一致（不为 0） |
| 已删报价 | 可展开只读看价格；供应商列为「—」；无恢复 |
| 布局切换（上下分栏） | 可切换；刷新后本页列设置保持，与作业页独立 |

## 五、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 一线业务员 | 全公司行可见；仅「业务员=自己」的行显示客户名；其它行客户名为「—」；**客户料号、客户品牌仍明文**；空业务员只打码客户名；客户名空值显示「—」 |
| 销售经理 | 自己 + 本部门及子部门**员工**的客户名明文；同级经理的客户名打码；料号/品牌不打码 |
| 销售总监 | 自己 + 部门树经理和员工的客户名明文；料号/品牌不打码 |
| 用客户关键字搜他人客户 | **搜不到**（不因关键字把打码行翻出来） |
| 用物料型号搜：命中他人客户料号、未命中本司型号 | **命中**该行（客户料号可搜） |
| 采购 521（销售数据范围无权限） | 整页无客户名；客户料号/品牌随 521 仍不展示 |
| 采购可见客户 | 本页**不**按业务员再打码客户（可能看到全公司客户名） |
| 保护期内分配给他人的明细 | **出现**在参考页；作业页仍按保护规则隐藏 |
| 511 销售在作业页报价码头 | 仍按原规则隐藏供应商身份；采购在作业页可见供应商 |

## 六、回归 / 交叉

| 步骤 | 预期 |
|------|------|
| 参考页与作业页来回切换 | 作业页篮子、列宽、页签模式不被参考页覆盖 |
| 帮助右栏 | 打开参考页可看到「需求参考」业务说明；无权限码/表名/路由 |

**已知口径差异：** 本页相对作业页刻意放宽行集合、关闭需求保护、一律打码供应商名称；不要按作业页数据范围报缺陷。

**本版不测：** 作业页页签模式/左栏检索本身（见对应对照说明）；核销/匹配金额边界。

*部署含需求参考页的版本后验收。*
