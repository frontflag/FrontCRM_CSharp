# 审批桌面 — 测试对照说明

> **页面 / 路由：** `/approval-desktop`（菜单：待办 → 待审批 → 进入审批桌面）；入口页 `/pending-approvals`  
> **设计文档：** [审批桌面-设计与实现](../../System/审批/审批桌面-设计与实现.md)  
> **权限：** 登录即可进待审批与审批桌面；通过/拒绝仍受各业务 `canDecide` / 后端 decide 校验（客户、供应商、销售订单、采购订单、付款各自写权限）

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 待审批页右上角「进入审批桌面」 | 进入 `/approval-desktop`；左栏待审队列、中栏表单、右栏参考页签 |
| 待处理列表操作「审核」 | 进入桌面并选中该条；左栏「待审核」滚到该记录 |
| 待处理列表操作「仅查看」 | 进入桌面并选中该条；表单只读，不能通过/拒绝 |
| **待处理分段双击一行** | 与「审核 / 仅查看」相同：进入桌面并开始审该条（有权限可决定，无权限只读） |
| 已通过 / 已拒绝分段双击一行 | **不**进审批桌面，打开对应业务详情（客户/供应商/销售订单/采购订单/付款） |
| 仅登录、无对应业务写权限 | 可进桌面看队列；对该条只能「仅查看」，decide 被后端拒绝 |
| 收款 | 待审批业务类型与桌面队列中 **无收款**；历史收款待审不再出现 |

---

## 二、工作台（左栏队列 + 中区）

- [ ] 审核桌面：待审列表在 **左侧扩展面板「待审核」页签**内；单据编号与业务类型标签同一行
- [ ] `/pending-approvals`：**无**待审队列左栏；左扩展为默认检索/收藏/历史占位
- [ ] 类型过滤后左栏列表变化；顶栏「全部待审 / 各类型」为**全局**计数，不随左栏过滤变少
- [ ] 上一条/下一条在过滤列表边界置灰；点击切换中间表单
- [ ] 刷新 `/approval-desktop` 后左栏过滤不要求持久化（当前无本地记忆）
- [ ] **性能 A+B1**：进入桌面时 Network 仅见队列 `items` + **一次** `summary?pendingOnly=true`（无 7×summary）；左栏先出列表，顶栏计数随后校正
- [ ] 进入 `/approval-desktop` 时右扩展**展开**；审核销售订单或客户时默认页签为 **客户调查**（不是「销售订单」）；切换待审条时仍回到该默认；可手点「销售订单」页签

## 三、审批与自动下一条

- [ ] 中间表单含业务信息、附件/订单文件、意见、历史
- [ ] 通过/拒绝后当前条离开队列，自动选中下一条（无则空态）
- [ ] 无「全部通过」按钮
- [ ] 从待审批双击进入后，中栏即该行单据，不是队列第一条（除非双击的就是第一条）

## 四、销售订单审核展示

| 步骤 | 预期 |
|------|------|
| 中栏区块顺序 | 业务相关信息 → **客户信息**（浅黄底）→ **订单概况**（淡青）→ **订单明细**（淡青）→ 订单文件 / 意见 / 历史 |
| 业务相关信息 · 金额 | `27.00 RMB` 这类 **数字 + 币别**，不加粗；不是 `¥27`；销售掩码为 — |
| 订单概况 · 订单金额 | 同样数字 + 币别，**数字加粗** |
| 订单概况字段 | 销售订单编号、订单类型（客单采购/备货采购/样品采购）、客户名称、订单金额、创建日期、销售员 |
| 订单明细标题 | 「订单明细」加粗；后接 `（ n条 ）` 不加粗；右侧可折叠；默认展开；刷新后恢复展开（不持久化）；中栏与右栏折叠互不影响 |
| 订单明细字段顺序 | 订单明细编号 → 客户订单号 → 物料型号 → 品牌 → 生产日期 → 交期 → 销售单价 → 数量 → 报价利润 → 报价利润率 |
| 报价利润率 | 在报价利润之后；保留 **2 位小数**；无报价成本或掩码为 —；点问号可见公式 |
| 右栏 | 进入时展开；默认 **客户调查**；可手点「销售订单」页签（与中栏概况/明细同内容） |

### 口径 / 公式核对（销售订单明细）

```text
报价利润(USD) = (销售单价 − 报价) × 销售数量
报价利润率     = 销售单价 ÷ 报价
```

| 步骤 | 预期 |
|------|------|
| 有报价成本 | 界面数值与问号公式代入结果一致；利润 USD 2 位；利润率 2 位小数 |
| 无报价成本 | 利润/利润率显示 —；点问号说明无法按上式计算 |
| 销售敏感掩码 | 客户名、订单金额、客户订单号、报价利润、报价利润率为 —；订单类型、生产日期、交期仍显示 |

## 五、右侧参考（其它类型）

| 类型 | 期望 |
|------|------|
| 客户 | 右栏「客户调查」+ 帮助 |
| 供应商 | 右栏「供应商调查」+ 帮助 |
| 销售订单 | 见第四节。右栏客户调查 +「销售订单」页签 + 帮助 |
| 采购订单 | 供应商调查 +「采购订单」页签（订单概况/订单明细）+ 帮助；采购利润与关联销售明细一致（无关联 —）。明细卡片另含行 **交期**（仅日期，空为 —）。中栏仍为供应商信息 + 订单金额等，**尚未**按销售订单中栏结构对齐 |
| 付款 | 供应商调查 + 帮助 |

### 无调查记录自动调查

- [ ] 提交客户/供应商审核时，若该主体无调查报告，后台异步生成；打开审批桌面右栏可看到调查中或结果
- [ ] 提交销售订单审核且关联客户无报告 → 自动客户调查
- [ ] 提交采购订单 / 付款审核且关联供应商无报告 → 自动供应商调查
- [ ] 已有可用报告时不重复强制刷新
- [ ] 调查失败不导致提交审核失败

## 六、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 部门/业务数据范围 | 队列只出现当前账号可见范围内的待审单 |
| 销售敏感掩码 | 金额/客户名/客户订单号/订单金额/报价利润/报价利润率为 `—`；订单类型、生产日期与交期仍显示；面板仍加载 |
| 采购敏感掩码 | 供应商/金额按现有规则打码；面板仍加载 |

---

## 七、本功能不适用

- **本功能不适用：§4.5 核销金额足额成功 / 超额拒绝**（审批桌面不提交核销/匹配金额）。
- **本功能不适用：列表页签模式 / 操作面板门控**（待审批列表无页签模式；桌面用左右扩展页签，见第二节）。订单明细折叠不写本地记忆，刷新后恢复展开（见第四节）。
- **本功能不适用：多租户打印皮肤**。
