# 审批桌面 — 测试对照说明

**关联设计：** [审批桌面-设计与实现](../../System/审批/审批桌面-设计与实现.md)

## 入口与并存

- [ ] 待审批页右上角有「进入审批桌面」，进入 `/approval-desktop`
- [ ] 待审批列表操作「审核 / 仅查看」跳转 `/approval-desktop`，并选中该条；左栏「待审核」自动滚到该记录

## 左栏 / 顶栏

- [ ] 审核桌面：待审列表在 **左侧扩展面板「待审核」页签**内；单据编号与业务类型标签同一行
- [ ] `/pending-approvals`：**无**待审队列左栏；左扩展为默认检索/收藏/历史占位（与图2一致）
- [ ] 类型过滤后左栏列表变化
- [ ] 顶栏「全部待审 / 各类型」为**全局**计数，不随左栏过滤变少
- [ ] 上一条/下一条在过滤列表边界置灰；点击切换中间表单

## 审批与自动下一条

- [ ] 中间表单与原弹窗信息一致（业务信息、附件/订单文件、意见、历史）
- [ ] 通过/拒绝后当前条离开队列，自动选中下一条（无则空态）
- [ ] 无「全部通过」按钮

## 右侧参考（右扩展面板页签，非主区内红框列）

| 类型 | 期望 |
|------|------|
| 客户 | 右栏「客户调查」+ 帮助 |
| 供应商 | 右栏「供应商调查」+ 帮助 |
| 销售订单 | 客户调查 +「销售订单」页签（订单概况/订单明细）+ 帮助；报价利润与详情绩效报价层一致 |
| 采购订单 | 供应商调查 +「采购订单」页签（订单概况/订单明细）+ 帮助；采购利润与关联销售明细一致（无关联 —） |
| 付款 | 供应商调查 + 帮助 |
| 收款 | 客户调查 + 帮助 |

## 掩码

- [ ] 销售敏感掩码下金额/客户信息按现有规则打码
- [ ] 采购敏感掩码下供应商/金额按现有规则打码
