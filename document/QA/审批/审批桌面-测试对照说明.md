# 审批桌面 — 测试对照说明

> **页面 / 路由：** `/approval-desktop`（菜单：待办 → 待审批 → 进入审批桌面）；入口页 `/pending-approvals`  
> **设计文档：** [审批桌面-设计与实现](../../System/审批/审批桌面-设计与实现.md)  
> **权限：** 登录即可进待审批与审批桌面；通过/拒绝仍受各业务 `canDecide` / 后端 decide 校验（客户、供应商、销售订单、采购订单、付款各自写权限）。**无新权限码。** 销售总监 / 采购总监本人提交例外见 [设计 §4.1](../../System/审批/审批桌面-设计与实现.md#41-本人提交与总监例外)。

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 待审批页右上角「进入审批桌面」 | 进入 `/approval-desktop`；左栏待审队列、中栏表单、右栏参考页签 |
| 待处理列表操作「审核」 | 进入桌面并选中该条；左栏「待审核」滚到该记录 |
| 待处理列表操作「仅查看」 | 进入桌面并选中该条；表单只读，不能通过/拒绝 |
| **待处理分段双击一行** | 与「审核 / 仅查看」相同：进入桌面并开始审该条（有权限可决定，无权限只读） |
| 已通过 / 已拒绝分段双击一行 | **不**进审批桌面，打开对应业务详情（客户/供应商/销售订单/采购订单/付款） |
| 仅登录、无对应业务写权限 | 可进桌面看队列；对该条只能「仅查看」，decide 被后端拒绝 |
| 销售总监（销售部 + 部门总监）提交自己的客户或销售订单 | 待处理显示「审核」；可在桌面通过/拒绝；接口不返回「不能审批本人…」 |
| 销售经理或销售员工提交自己的客户或销售订单 | 待处理为「仅查看」；decide 返回不能审批本人提交的客户/销售订单 |
| 采购总监（采购或采购运营部 + 部门总监）提交自己的供应商或采购订单 | 待处理显示「审核」；可在桌面通过/拒绝；接口不返回「不能审批本人…」 |
| 采购经理或采购员工提交自己的供应商或采购订单 | 待处理为「仅查看」；decide 返回不能审批本人提交的供应商/采购订单 |
| 销售总监提交自己的供应商或采购订单 | **仍不能**自审（例外只覆盖客户与销售订单） |
| 采购总监提交自己的客户或销售订单 | **仍不能**自审（例外只覆盖供应商与采购订单） |
| 非系统管理员提交自己的付款 | 待处理为「仅查看」；不能通过/拒绝 |
| 系统管理员提交自己的任意待审类型 | 待处理为「审核」；可在桌面通过/拒绝 |
| 收款 | 待审批业务类型与桌面队列中 **无收款**；历史收款待审不再出现 |

### 1.1 本人提交与总监例外（口径）

身份以 **主部门** `IdentityType` + 组织角色为准（须重新登录后测）：

| 角色 | 主部门身份 | 可自审 |
|------|------------|--------|
| 部门总监 | 销售（1） | 客户、销售订单（业务员 = 本人） |
| 部门总监 | 采购（2）或采购运营（3） | 供应商、采购订单（采购员 = 本人） |
| 部门经理 / 部门员工 | 任意 | 不可自审 |
| 系统管理员 | — | 全部类型可自审 |

- 列表「本人」：客户/销售订单看业务员 **或** 创建人；供应商/采购订单看采购员 **或** 创建人。decide 拦截只看业务员 / 采购员。
- 无对应业务写权限时，即使是总监也只能「仅查看」，decide 被后端拒绝。
- **本功能不适用：** 不新增权限码；不测核销金额足额/超额（见第九节）。

## 二、工作台（左栏队列 + 中区）

- [ ] 审核桌面：待审列表在 **左侧扩展面板「待审核」页签**内；单据编号与业务类型标签同一行
- [ ] `/pending-approvals`：**无**待审队列左栏；左扩展为默认检索/收藏/历史占位
- [ ] 类型过滤后左栏列表变化；顶栏「全部待审 / 各类型」为**全局**计数，不随左栏过滤变少
- [ ] 上一条/下一条在过滤列表边界置灰；点击切换中间表单
- [ ] 刷新 `/approval-desktop` 后左栏过滤不要求持久化（当前无本地记忆）
- [ ] **性能 A+B1**：进入桌面时 Network 仅见队列 `items` + **一次** `summary?pendingOnly=true`（无 7×summary）；左栏先出列表，顶栏计数随后校正
- [ ] 进入 `/approval-desktop` 时右扩展**展开**；审核销售订单或客户时默认页签为 **客户调查**（不是「销售订单」）；审核采购订单、供应商或付款时默认页签为 **供应商调查**（不是「采购订单」）；切换待审条时仍回到该默认；可手点「销售订单 / 采购订单」页签

## 三、审批与自动下一条

- [ ] 中间表单含业务信息、附件/订单文件、意见、历史
- [ ] 通过/拒绝后当前条离开队列，自动选中下一条（无则空态）
- [ ] 无「全部通过」按钮
- [ ] 从待审批双击进入后，中栏即该行单据，不是队列第一条（除非双击的就是第一条）

## 四、销售订单审核展示

| 步骤 | 预期 |
|------|------|
| 中栏区块顺序 | 业务相关信息 → **客户信息**（浅黄底）→ **订单概况**（淡青）→ **订单明细**（淡青）→ 订单文件 / 意见 / 历史 |
| 业务相关信息 · 金额 | `27.00 RMB` 这类 **数字 + 币别**，不加粗；不是 `¥27`；销售掩码为 — |
| 订单概况 · 订单金额 | 同样数字 + 币别，**数字加粗** |
| 订单概况字段 | 销售订单编号、订单类型（客单采购/备货采购/样品采购）、客户名称、订单金额、创建日期、销售员 |
| 订单明细标题 | 「订单明细」加粗；后接 `（ n条 ）` 不加粗；右侧可折叠；默认展开；刷新后恢复展开（不持久化）；中栏与右栏折叠互不影响 |
| 订单明细字段顺序 | 订单明细编号 → 客户订单号 → 物料型号 → 品牌 → 生产日期 → 交期 → 销售单价 → 数量 → 报价利润 → 报价利润率 |
| 报价利润率 | 在报价利润之后；保留 **2 位小数**；无报价成本或掩码为 —；点问号可见公式 |
| 右栏 | 进入时展开；默认 **客户调查**；可手点「销售订单」页签（与中栏概况/明细同内容） |

### 口径 / 公式核对（销售订单明细）

```text
报价利润(USD) = (销售单价 − 报价) × 销售数量
报价利润率     = 销售单价 ÷ 报价
```

| 步骤 | 预期 |
|------|------|
| 有报价成本 | 界面数值与问号公式代入结果一致；利润 USD 2 位；利润率 2 位小数 |
| 无报价成本 | 利润/利润率显示 —；点问号说明无法按上式计算 |
| 销售敏感掩码 | 客户名、订单金额、客户订单号、报价利润、报价利润率为 —；订单类型、生产日期、交期仍显示 |

## 五、采购订单审核展示

| 步骤 | 预期 |
|------|------|
| 中栏区块顺序 | 业务相关信息 → **供应商信息**（浅黄底）→ **订单概况**（淡青）→ **订单明细**（淡青）→ 订单文件 / 意见 / 历史 |
| 业务相关信息 · 金额 | 与销售相同：`27.00 RMB` 这类 **数字 + 币别**，不加粗；采购掩码为 — |
| 供应商信息字段 | 供应商名称、供应商身份、**交易次数**、付款方式、账期类型、账期天数。**无**整单交期、采购单号（单号已在业务相关信息）。次数公式见 [供应商交易次数对照](../供应商/供应商交易次数-测试对照说明.md) |
| 订单概况 · 订单金额 | 同样数字 + 币别，**数字加粗** |
| 订单概况字段 | 采购订单编号 → 创建日期 → 供应商名称 → 订单类型（客单采购/备货采购/样品采购）→ 订单金额 → 采购员 |
| 订单概况 · 两列配对 | 编号 \| 创建日期；供应商名称 \| 订单类型；订单金额 \| 采购员 |
| 订单明细标题 | 与销售相同：条数 `（ n条 ）`、可折叠、默认展开、刷新不持久化；中栏与右栏折叠互不影响 |
| 订单明细字段顺序 | **订单明细编号单独占一行**（两列时跨整行）→ 物料型号 → 品牌 → 生产日期 → 交期 → 采购单价 → 数量 → 采购利润 → 采购利润率。**无**客户订单号 |
| 订单明细 · 两列配对 | 编号独占一行；型号 \| 品牌；生产日期 \| 交期；采购单价 \| 数量；采购利润 \| 采购利润率 |
| 采购利润率 | 在采购利润之后；保留 **2 位小数**；无关联销售/采购单价或掩码为 —；点问号可见公式 |
| 右栏 | 进入时展开；默认 **供应商调查**；可手点「采购订单」页签（与中栏概况/明细同内容） |

### 口径 / 公式核对（采购订单明细）

```text
采购利润(USD) = (销售单价 − 采购单价) × 采购数量
采购利润率     = 销售单价 ÷ 采购单价
```

单价取折算美金。本桌面按单价比，**不是** EBS「销售总额 ÷ 采购总额」。

| 步骤 | 预期 |
|------|------|
| 有关联销售且有采购单价 | 界面数值与问号公式代入结果一致；利润 USD 2 位；利润率 2 位小数 |
| 无关联销售 | 利润/利润率为 —；不出现无法计算的问号（未拉到 line-profit） |
| 有关联但无采购单价 | 利润/利润率显示 —；点问号说明无法按上式计算 |
| 采购敏感掩码 | 供应商名、订单金额、采购员、采购单价、采购利润、采购利润率为 —；订单类型、型号、品牌、生产日期、交期、**交易次数**仍显示 |

### 无调查记录自动调查

- [ ] 提交客户/供应商审核时，若该主体无调查报告，后台异步生成；打开审批桌面右栏可看到调查中或结果
- [ ] 提交销售订单审核且关联客户无报告 → 自动客户调查
- [ ] 提交采购订单 / 付款审核且关联供应商无报告 → 自动供应商调查
- [ ] 已有可用报告时不重复强制刷新
- [ ] 调查失败不导致提交审核失败

## 九、本功能不适用

- **本功能不适用：§4.5 核销金额足额成功 / 超额拒绝**（审批桌面不提交核销/匹配金额）。
- **本功能不适用：列表页签模式 / 操作面板门控**（待审批列表无页签模式；桌面用左右扩展页签，见第二节）。订单明细折叠不写本地记忆，刷新后恢复展开（见第四、五节）。
- **本功能不适用：多租户打印皮肤**。

### 已知口径差异

- 审批桌面「报价利润率」展示 **2 位小数**；销售订单明细绩效页同一倍数为 6 位小数。核对时以审批桌面问号公式与 2 位展示为准。
- 审批桌面「采购利润率」目前仅本桌面展示，同样 **2 位小数**；公式为 **销售单价 ÷ 采购单价**（折算美金），与 EBS 采购明细扩展字段「销售总额 / 采购总额」不同。
