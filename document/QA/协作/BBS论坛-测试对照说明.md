# BBS 论坛 — 测试对照说明

> **页面 / 路由：** 侧栏「我的」→「论坛」`/bbs`；发帖 `/bbs/create`；发起投票 `/bbs/create?kind=poll`；详情 `/bbs/:id`；编辑 `/bbs/:id/edit`  
> **设计文档：** [BBS论坛-设计与实现](../../System/协作/BBS论坛-设计与实现.md)  
> **实施方案：** [BBS论坛-实施方案](../../实现方案/BBS论坛-实施方案.md)  
> **EBS 对照（只读）：** [document/EBS/辅助功能/BBS.md](../../EBS/辅助功能/BBS.md)  
> **权限 / DDL：** 读/写 = 登录即可；板块版主 = `bbs_board_moderator`；全局版主 = SYS_ADMIN / SYS_MANAGER / `bbs.moderate`；**仅 SYS_ADMIN / SYS_MANAGER 可设版主、新建板块、排序**。须执行 `scripts/ensure_bbs_postgresql.sql`（或 SchemaEnsure）后重启 API  
> **总纲：** [测试规范总纲.md](../测试规范总纲.md)

| 总纲条款 | 说明 |
|----------|------|
| §4.2 数据范围与脱敏 | 论坛全员可见，无部门数据范围；无销售/采购金额脱敏 |

| §4.6 多租户皮肤 / 打印 | 本版无打印皮肤 |

## 一、入口与权限

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 未登录访问 `/bbs` | 跳登录 |
| 2 | 未登录调 `GET /api/v1/bbs/subjects` | 401 |
| 3 | 普通业务员登录 | 侧栏「我的」下可见「论坛」；可进列表 |
| 4 | 普通业务员发帖、回复 | 成功 |
| 5 | 普通业务员对他人帖点置顶 | 403 / 前端无置顶按钮（`canSetTop=false`） |
| 6 | SYS_ADMIN 或 SYS_MANAGER 打开他人帖 | 可见置顶/删帖等版主操作 |
| 7 | 赋权 `bbs.moderate` 的非管理员 | 与**全局**版主能力一致（全板块） |
| 7a | 超管在侧栏某板块点「设置」，选任意启用账号保存 | `PUT /board-moderators/{type}` 成功；侧栏显示该账号 |
| 7b | 普通用户 / 非超管 | 侧栏无分类「设置」；调 PUT 返回 403 |
| 7c | 板块版主 A 对**本板块**他人帖 | 可置顶/关闭/删帖/删回复；`canEdit` 对他人帖为 false |
| 7d | 板块版主 A 对**其他板块**他人帖 | 无版主按钮 / 403 |
| 7e | 超管清除版主 | 侧栏显示「未设置」；原版主失去本板块管理权 |

## 七、投票帖

| # | 步骤 | 预期 |
|---|------|------|
| 30 | 点「发起投票」，选项少于 2 | 前端拦截 / API 400 |
| 31 | 合法投票帖（单选，≥2 选项）发布 | 列表有「投票」角标；详情可投 |
| 32 | 用户 A 投票成功后再投 | 失败（已投票不可改） |
| 33 | 用户 B（未投）看详情 | **看不到**各选项票数/占比；提示投票后可见 |
| 34 | 用户 B 投票后 | 可见统计；作者/版主未投也可看统计 |
| 35 | 设置截止时间并过期后，未投票用户 C | **可看**统计；不可再投 |
| 36 | 多选：超过上限勾选 | 前端/API 拒绝 |
| 37 | 投票帖下发表回复 | 成功（与投票分离） |
| 38 | 关帖后投票 | 失败 |
| 39 | 截止日期选今天之前 | 日期灰显不可选；提交提示不能早于当天 |

## 九、上线前

1. 执行 `scripts/ensure_bbs_postgresql.sql`（或确认 SchemaEnsure）  
2. 重启 API / 刷新前端  
3. 普通账号：发帖、回复、投票  
4. 超管：板块新建/排序、「系统更新」发帖  

## 十、范围外（本版不测）

- 改票、公示选民、@提及、IsNotify 铃铛、微信端、EBS 历史迁移  

## 十一、已知口径差异（相对 EBS）

| 点 | EBS | FrontCRM |
|----|-----|----------|
| 投票防重 | 用户+投票项（可多投项） | 用户+主题唯一；选项独立表 |
| 类型 | 四类+系统参数 | 内置六类 + 自定义 type≥100 |
| 通知 | IsNotify 角标 | 不做 |
