## 一、用户侧 · AI 助手

| 步骤 | 预期 |
|------|------|
| 顶栏有「AI 助手」入口 | 可打开聊天抽屉；与「消息通知」铃铛分离 |
| 欢迎语 | 可反馈问题或提建议；可选 chip「反馈问题」「提改进建议」 |
| 直接打字描述故障 | AI 追问补全；可识别为「问题」 |
| 无业务 Id 的列表页反馈 | AI **主动问**相关单据号 |
| 详情页已有路由 Id | **不必**再问单号（除非用户指另一张单） |
| 用户说没有单号 | 可继续并最终落库；摘要可注明无单号 |
| 信息齐套后 | 结束语含「已记录并通知开发团队」；**不**念精炼摘要；**不**问确认 |
| 结束语 | **不含**具体解决日期/工作日承诺 |
| 多轮仍说不清（约 6 轮） | 礼貌结束；运维列表**无**对应正式工单 |
| Ctrl+V 粘贴截图 | 可作为附件进入会话/工单 |
| 改进建议表述 | 类型为「建议」；复现/单号可不强求 |
| 闲聊（天气/笑话等） | AI **拒答并引导**反馈/建议；**不**创建工单 |
| 连续跑题 ≥ 3 次 | 礼貌结束会话；提示可重新打开专门反馈问题；中间若转入有效反馈则计数重置 |
| 先闲聊后改口反馈系统问题 | 可转回正常追问流程 |

## 二、运维 · 用户反馈

| 步骤 | 预期 |
|------|------|
| 菜单「运维」→「用户反馈」 | 打开 `/ops/user-feedback` |
| 无 `biz.feedback.admin` | 看不到菜单 |
| 列表 | 见 AI 精炼标题/类型/摘要等，**不是**整段聊天 |
| 详情 | 可改：是否需处理、是否完成、完成日期、备注；可改类型 |
| 勾选完成处理 | 完成日期可默认当天；建议必填 |
| 展开原始对话 | 可见多轮记录与截图 |
| 「已通知开发团队」含义 | 工单出现在本列表（无邮件亦可） |
| 「我的邮箱」点「申请公司邮箱」 | 列表多一条类型「建议」、标题「申请公司邮箱」、摘要含「申请公司邮箱，申请人{登录账号}」；**无**多轮 AI 对话。对照见 [申请公司邮箱](./申请公司邮箱-测试对照说明.md) |
| 系统管理员打开控制台且有需处理反馈 | 待办出现「用户反馈」及条数；非 SA 不出现。对照见 [控制台待办](./控制台待办-设置我的邮箱-测试对照说明.md) |
