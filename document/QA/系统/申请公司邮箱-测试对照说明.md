# 申请公司邮箱 — 测试对照说明

> **页面 / 路由：** 个人设置 → 我的邮箱 `/profile/mailbox`  
> **设计文档：** [个人邮箱与公司邮箱设置-设计与实现](../../System/系统/个人邮箱与公司邮箱设置-设计与实现.md) §2.10  
> **关联：** [AI用户反馈助手-测试对照说明](./AI用户反馈助手-测试对照说明.md)（运维「用户反馈」列表）  
> **权限 / DDL：** 登录即可申请；**不**新增权限码、**不**改表。复用 `user_feedback` / `ai_assistant_session`

---

## 一、入口与权限

权限用例已集中维护于：[权限/系统功能-权限测试对照说明.md](../权限/系统功能-权限测试对照说明.md) §三。

本节保留核心结论：登录即可申请；不新增权限码、不改表；未登录直打接口返回 401。

---

## 二、提示栏显隐

| 步骤 | 预期 |
|------|------|
| 没有任何验证成功的**平台**邮箱（未添加 / 仅未验证草稿 / 仅验证失败 / 只有其他邮箱如 QQ 且已验证） | 标题说明与邮箱卡片之间出现提示栏 |
| 提示栏文案（已配平台后缀，如 `@semicoregroup.com`） | `我目前尚未有@semicoregroup.com公司邮箱`，其后有按钮「申请公司邮箱」 |
| 管理员尚未配置平台后缀、列表也无平台行 | 文案为 `我目前尚未有公司邮箱`；申请按钮仍在 |
| 至少一条平台邮箱为「验证成功」 | **整栏不出现**（含按钮） |
| 仅验证成功「其他邮箱」、平台仍未验证 | 提示栏**仍出现**（与控制台「设置我的邮箱」待办口径不同） |
| 加载列表过程中 | 不先闪出提示栏再因已验证而消失（等列表返回后再决定） |

---

## 三、申请提交

| 步骤 | 预期 |
|------|------|
| 点「申请公司邮箱」 | 按钮进入 loading，不可连点；Network 出现 `POST /api/v1/me/mailboxes/apply-company` |
| 接口成功 | 弹窗「申请已发送，敬请等候处理」；点确定关闭 |
| 成功后仍无已验证平台邮箱 | 提示栏**仍在**，可再次申请 |
| 接口失败（网络/500） | **不**弹成功窗；页面错误提示（如「申请发送失败」） |
| 已有已验证平台时强打接口 | 400，提示已有验证成功的平台邮箱 |

---

## 四、运维可见（用户反馈）

| 步骤 | 预期 |
|------|------|
| 申请成功后，有反馈管理权限的账号打开「运维」→「用户反馈」 | 新增一条待处理工单 |
| 标题 | `申请公司邮箱` |
| 类型 | 「建议」（`suggestion`） |
| 摘要 | `申请公司邮箱，申请人{该员工登录账号}`（账号与个人设置「员工账号」一致，不是显示名） |
| 页面 | 我的邮箱 / `/profile/mailbox` |
| 详情展开原始对话 | 可见一条用户消息，内容与摘要相同；**无** AI 多轮追问 |
| 处理勾选完成 | 与普通用户反馈相同（完成日期、备注） |

---

## 五、回归 / 交叉

| 步骤 | 预期 |
|------|------|
| 已验证平台邮箱的用户打开本页 | 无提示栏；添加/验证/默认发信原流程不变 |
| 控制台「设置我的邮箱」待办 | 口径仍是「任意邮箱未验证」；不因本栏显隐而改 |
| 顶栏 AI 助手「反馈问题」 | 仍走多轮对话；本功能不打开助手抽屉 |
| 公司邮箱页签 / 后缀配置 | 无改动 |

---

## 六、本功能不适用（总纲强制声明）

- **本功能不适用：金额 / 核销 / 匹配的足额成功与超额拒绝**（§4.5）。申请不涉及金额。
- **本功能不适用：工作台左右栏队列**（§4.3）。
- **本功能不适用：列表页签模式 / 操作面板门控**（§4.4）。
- **本功能不适用：多租户皮肤 / 打印**（§4.6）。无新皮肤、无打印。
- **本功能不适用：看板统计公式**。
- **本功能不适用：数据库迁移 / 新权限脚本**（§4.7）。不改表；复用用户反馈表。
- **本功能不适用：销售/采购敏感掩码**（§4.2）。工单不含客商名与金额。
