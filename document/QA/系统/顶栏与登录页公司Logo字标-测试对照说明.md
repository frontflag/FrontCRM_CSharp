# 顶栏与登录页公司 Logo 字标 — 测试对照说明

> **页面 / 路由：** 登录 `/login`；登录后任意页全局顶栏左侧品牌图（标题右侧不变）  
> **配置入口：** 系统 → 公司信息 `/system/company-info`（公司 Logo）  
> **设计文档：** [顶栏与登录页公司Logo字标-设计与实现](../../System/系统/顶栏与登录页公司Logo字标-设计与实现.md)  
> **自动化：** `CRM.Web/src/tests/company-profile-wordmark.test.ts`（租户门控；观感以本对照手工验）  
> **权限 / DDL：** 无独立权限码、无迁移。登录页匿名可看 Logo。改上传须公司信息写入权限。  
> **帮助：** `help/pages/公司信息_MENU_COMPANY_INFO.md`  
> **总纲：** [测试规范总纲.md](../测试规范总纲.md)

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 未登录打开 `/login`（semicore 构建） | 左侧品牌区显示公司 Logo 字标（或未上传时的内置回退图），无需登录 |
| 已登录任意业务页（semicore） | 顶栏左侧为较宽字标（高 24px、宽随图）；右侧标题为 `AI Intelligent System`（无「Semicore」前缀） |
| 无公司信息查看/写入权限 | 不影响顶栏/登录页已上传 Logo 的展示；不能改上传 |
| 有公司信息写入 | 可在公司信息中替换 Logo；保存后登录页/顶栏应能看到新图（浏览器缓存约 10 分钟，必要时硬刷新） |

---

## 二、semicore：字标比例（必测）

准备：公司信息已上传**横版透明 PNG**（宽明显大于高）。

| 步骤 | 预期 |
|------|------|
| 看顶栏左侧品牌图 | **不是** 36×36 方块；高度 **24px**，宽度随图变宽；图不拉伸变形（横纵比与原文件一致） |
| 看顶栏标题 | 文案为 **AI Intelligent System**（无「Semicore」），常规字重不加粗，仍在 Logo **右侧**，可点回工作台 |
| 看登录页左侧品牌图 | 与公司信息同一张 Logo（不是另一套内置 SEMICORE 小标优先）；无白底圆角小卡裁切；横纵比不变 |
| 浏览器开发者工具看 `<img>` 渲染宽高 | `width / height` 约等于原图像素比（允许 1px 级误差） |

未上传或接口失败：顶栏/登录页回退内置字标图，布局仍是横版字标（semicore），不是方块小标。

## 三、多租户（总纲 §4.6）

须分别用 **semicore / idesemi / ecoinf** 构建（或对应环境）看登录页与顶栏。

| 租户 | 预期 |
|------|------|
| **semicore** | 顶栏较宽字标（高 24px）+ 标题 `AI Intelligent System` + 登录页公司 Logo 字标（本节二） |
| **idesemi** | 顶栏仍为约 36×36 小标；标题仍含租户名（如 IDESemi …）；登录页仍为白底小标卡 |
| **ecoinf** | 顶栏小标与完整标题不改为 semicore 字标/去前缀；登录页为 ecoinf 独立页，本版不改 |

通过标准：三套观感差异明显；semicore 与另两套在品牌图布局上可一眼区分。

## 四、口径 / 公式核对

本功能不适用：金额核销 / 匹配的足额成功与超额拒绝（总纲 §4.5）。不提交金额。

Logo 选取（与装箱单抬头一致）：优先「默认且已有文件」的公司 Logo；否则取任一已有文件的行。接口 `GET /api/v1/company-profile/login-logo` 返回原文件，不是缩略图。

## 五、回归 / 交叉

| 步骤 | 预期 |
|------|------|
| 装箱单 / 采购订单等报表抬头 Logo | 仍走原报表下载逻辑，不因顶栏字标布局而改选取规则 |
| 公司信息页缩略图 | 列表仍可用缩略图；登录/顶栏用原文件流 |
| 亮暗主题顶栏 | 字标透明底叠在顶栏上；不要被圆角裁成方块 |

## 六、本功能不适用

- **本功能不适用：工作台 / 桌面左栏队列（总纲 §4.3）。**
- **本功能不适用：列表页签模式 / 左栏检索 / 操作面板单击门控（总纲 §4.4）。**
- **本功能不适用：金额提交 / 核销 / 匹配足额与超额（总纲 §4.5）。**
- **本功能不适用：数据分析看板公式。**
- **本功能不适用：打印报表皮肤换色（总纲 §4.6 打印项）。** 多租户验收仅登录页与顶栏品牌图；打印页 Logo 另见各报表对照。
