# 系统通知 — 测试对照说明

> **页面 / 路由：**  
> - 管理：运维管理 → 消息通知管理 `/ops/user-notices`  
> - 用户：任意已登录页顶栏铃铛 → 抽屉「系统消息」  
> **设计文档：** [系统通知-设计与实现](../../System/系统/系统通知-设计与实现.md)  
> **权限 / DDL：** 管理端仅系统管理员（无独立权限码）；须执行 `scripts/ensure_sys_user_notice_postgresql.sql` 或迁移 `20260924120000_AddSysUserNotice`  
> **关联：** [系统公告-设计与实现](../../System/系统/系统公告-设计与实现.md)（对照：公告会强制弹窗，本功能不会）

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 系统管理员看侧栏运维管理 | 「用户反馈」之后有「消息通知管理」 |
| 点「消息通知管理」 | 进入 `/ops/user-notices`，右上角有「发送消息」 |
| 非系统管理员（含仅有用户反馈权限） | 侧栏无此项；直链 `/ops/user-notices` 被拦，进不了页 |
| 普通员工打开发送接口 `POST /api/v1/ops/user-notices` | 403 |
| 任意已登录用户 | 顶栏铃铛可用；抽屉有「系统消息」 |

---

## 二、发送

| 步骤 | 预期 |
|------|------|
| 选启用员工、不勾重要、标题与正文都填，点发送 | 成功；列表立刻有这一行；重要=普通；已读=未读 |
| 标题填了、正文空、加 1～9 张合法图片后发送 | 成功；列表摘要为「N 张图片」；详情能看图 |
| 标题填了、正文空、不选图 | 前端提示「请填写正文或添加图片」，不落库 |
| 第 10 张图 | 前端拒绝；后端亦拒绝 |
| 单张超过 8MB 或非 jpg/png/webp/gif | 前端拒绝；后端亦拒绝 |
| 勾选重要后发送 | 列表重要=重要；接收人未读时铃铛摇动（见第四节） |
| 不选接收人 / 标题空 | 前端提示，不落库 |
| 标题超过 100 字、正文超过 4000 字 | 输入框限制；后端亦拒绝 |
| 接收人下拉 | 仅启用员工（账号 / 姓名）；停用、冻结不出现 |
| 发送后想改或撤回 | 本期无入口，列表无编辑/删除 |

---

## 三、搜索与管理列表

| 步骤 | 预期 |
|------|------|
| 按重要 / 已读 / 接收人 / 标题或正文关键字 / 发送日期区间查询 | 列表只出符合条件的行；条数与筛选一致 |
| 点重置 | 条件清空，列表回到默认 |
| 列 | 重要、是否已读、接收人、标题、发送时间 |
| 点某一行 | 弹出完整标题+正文（若有）+附图；**接收人仍是未读**（管理端查看不改 `read_at`）；点缩略图可全屏看图 |
| 刷新列表 | 该行已读列仍是未读，直到接收人自己点「查看」 |

---

## 四、用户铃铛与已读

| 步骤 | 预期 |
|------|------|
| 接收人登录，有未读系统通知 | 角标 = 未读通知数 + 未读公告数；大于 20 显示 `20+`（不是 `99+`） |
| 仅有未读公告、没有未读通知 | 角标仍显示公告未读数；铃铛**不摇** |
| 有至少一条未读且重要的系统通知 | 铃铛摇动 |
| 只有未读普通通知（无重要） | 角标有数，**不摇** |
| 点铃铛，当前有未读系统通知 | 抽屉默认停在「系统消息」 |
| 点铃铛，没有未读系统通知（可有未读公告） | 抽屉默认「系统公告」 |
| 「系统消息」卡片 | 重要时有纸飞机图标；显示发送日期、标题、摘要（无正文则「N 张图片」） |
| 点卡片 | 弹出完整标题+正文（若有）+附图；该条变为已读；角标减 1；若再无未读重要，停止摇动 |
| 非接收人用文档预览接口打开该图 | 403 / 无法显示 |
| 不点卡片、只开抽屉看列表 | 仍是未读 |
| 模拟登录到该接收人 | 角标为 0、不摇；可浏览列表与正文/图；点卡片后真实账号仍未读 |
| 登录后 | **不会**被系统通知挡住，无强制弹窗 |

---

## 五、与系统公告交叉

| 步骤 | 预期 |
|------|------|
| 同时有未读公告 + 未读通知 | 角标为两者之和；打开抽屉默认「系统消息」 |
| 发布一条系统公告 | 仍走强制弹窗；系统通知列表不出现该公告 |
| 发一条系统通知 | 不出现公告强制窗 |

## 六、上线前置（§4.7）

1. 执行 `scripts/ensure_sys_user_notice_postgresql.sql` 或已含 `20260924120000_AddSysUserNotice` 的迁移。  
2. 重启 / 发布 API 与 Web（`AllowedExtensions` 含 `.gif`）。  
3. 系统管理员重新登录后看运维菜单。无需新表。

未部署对应版本则本对照无效。

## 八、本功能不适用（总纲强制声明）

- **本功能不适用：金额 / 核销 / 匹配的足额成功与超额拒绝**（§4.5）。本功能不提交金额。  
- **本功能不适用：工作台左右栏队列**（§4.3）。  
- **本功能不适用：列表页签模式 / 操作面板门控**（§4.4）。管理页是普通筛选列表。  
- **本功能不适用：多租户皮肤 / 打印**（§4.6）。无新皮肤、无打印。  
- **本功能不适用：看板统计公式**。角标为未读条数相加，无折算。  
- **本功能不适用：销售/采购敏感掩码**（§4.2）。通知不含客商名与金额；管理列表不受部门数据权限裁剪（仅 SuperAdmin）。
