## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 任意已登录用户打开 `/dashboard` | 右侧出现「工作日程」月历（无独立菜单） |
| 无 `work-task.read` | 橙点全无；点日期任务列表为空；无「新建客户跟进」（无 write 时按钮也不出） |
| 无 `rfq.read`、有 `sales-order.read` | 蓝点无；绿点按自己的已通过订单出现 |
| 无 `sales-order.read`、有 `rfq.read` | 绿点无；蓝点按自己的已分配需求出现 |
| 无 `work-task.write`、有 read | 能看自己的任务，无新建/开始/完成/取消 |
| 模拟登录点完成/新建 | 接口 403「模拟登录不能改任务」，库中无新行 |

## 二、圆点口径

日切：`Asia/Shanghai`。一天最多蓝/绿/橙各 1 点。

| 颜色 | 计入 | 不计入 |
|------|------|--------|
| 蓝 | 自己 `sales_user_id` 的需求，状态 ∈ 已分配及之后（不含取消），`assigned_at` 落在该日 | 待分配、已取消、软删、`assigned_at` 空、他人业务员 |
| 绿 | 自己业务员的销售订单，状态 ∈ 审核通过/进行中/完成，`approved_at` 落在该日 | 新建、待审核、审核失败、取消、软删、`approved_at` 空、他人业务员 |
| 橙 | 自己是执行人、未删除、未取消（**含已完成**），`start_date` = 该日 | 取消、软删、自己只是创建人但执行人是别人 |

| 步骤 | 预期 |
|------|------|
| 需求从待分配变为已分配 | 分配当天出现蓝点；之后改报价中/关闭仍用原 `assigned_at` |
| 订单审核通过 | 通过当天绿点；再改为进行中/完成不改日期 |
| 通过后又取消订单 | 绿点消失（状态不再 ≥ 审核通过） |
| 新建跟进开始日=今天 | 今天橙点；完成后橙点仍在 |
| 取消任务 | 橙点消失 |
| 派给同事 | 自己日历无此橙点，同事日历有 |
| UTC 16:30 审核通过 | 上海已是次日，绿点打在次日 |

悬停或点日期摘要：需求 N / 订单 N / 任务 N 与当天列表条数一致。

## 三、只看自己

| 步骤 | 预期 |
|------|------|
| 经理账号（有部门数据范围）看桌面 | 仍只统计 **自己当业务员** 的需求/订单，**不是**下属全量 |
| 同日下属有已分配需求、自己没有 | 自己无蓝点 |

本功能不适用：按销售数据范围看团队（二期）。

## 四、客户跟进任务

| 步骤 | 预期 |
|------|------|
| 点日期 → 新建客户跟进，填客户/标题/开始日 | 任务待开始；执行人默认自己 |
| 开始 | 状态进行中 |
| 完成 | 状态完成；客户详情联系历史多一条：主题=标题，内容=任务内容，下次跟进空，结果「任务完成」 |
| 再点完成 | 幂等，不写第二条联系历史 |
| 取消 | 不写联系历史 |
| 选自己不可见的客户 | 拒绝 |
| 完成/取消后再改开始日 | 拒绝 |

## 五、通用维度（裁剪）

| 维度 | 说明 |
|------|------|
| §4.1 入口与权限 | 见第一节 |
| §4.2 数据范围与脱敏 | 只看自己；**本功能不适用：511/521 金额脱敏**（日历无金额） |
| §4.3 工作台桌面 | 月历在桌面右侧；点日期出当天三块列表；刷新后仍在当前月（不要求记住点开的日） |
| §4.4 页签 / 操作面板 | **本功能不适用：列表页签模式、左栏检索、操作面板** |
| §4.5 金额与核销 | **本功能不适用：无金额提交/核销/匹配** |
| §4.6 多租户皮肤 | **本功能不适用：无打印/皮肤** |
| §4.7 上线前置 | 执行迁移或 `scripts/ensure_work_task_postgresql.sql`；重启 API；业务角色重新登录以拿到 `work-task.*` |

## 六、回归

| 步骤 | 预期 |
|------|------|
| 桌面业务总览、右侧月历下方的邮箱待办与反馈待办 | 仍可用 |
| 需求分配、订单审核通过 | 业务状态机不变，仅多写 `assigned_at` / `approved_at`（只写首次） |

## 七、范围外（本版不测）

考核、协作人、附件、截止日期/逾期红点、周期任务、独立日程菜单、团队日历。
