# 导出日志 — 测试对照说明

> **页面 / 路由：** 系统日志 → 导出日志 `/system/export-logs`  
> **设计文档：** [导出日志-设计与实现.md](../../System/系统/导出日志-设计与实现.md)  
> **权限 / 迁移：** `system.logs.export.read`；须执行迁移 `20260902120000_SeedExportLogPermission`（或等价种子 SQL）  
> **总纲：** [测试规范总纲.md](../测试规范总纲.md)

| 项 | 内容 |
|----|------|
| 状态 | 随 MVP 已实现同步 |

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有导出日志查看权限 | 系统日志下可见「导出日志」，可进入列表 |
| 无该权限、有操作日志权限 | 可见操作日志，**无**导出日志菜单；直接打开 `/system/export-logs` 被拒 |
| 无操作日志权限、有导出日志权限 | 可进导出日志；操作日志菜单不可见 |
| 无 write | 本页无写操作，有 read 即可查看 |

## 二、列表与检索

| # | 步骤 | 期望 |
|---|------|------|
| 1 | 进入页面 | 检索栏：导出业务类型、导出人、导出日期区间；列表含导出时间、导出人、导出业务类型、导出页面、导出页面 URL、导出条件、导出条目数、系统备注 |
| 2 | 业务类型下拉 | 中文名（如「销售订单明细列表」），不是 camelCase 码 |
| 3 | 选一种类型查询 | 仅该按钮产生的行 |
| 4 | 按导出人模糊查 | 命中操作人名称 |
| 5 | 按日期区间查 | 含起日 0 点至止日 23:59:59；列表「导出时间」仍到时分 |
| 6 | 无筛选查询 | 全部导出行，按时间倒序 |
| 7 | 点击「导出页面 URL」 | 跳到该站内路径（如 `/sales-order-items`、`/sales-orders/{id}`）；空值显示「—」不跳；`http://` / `//` 外链不跳 |

## 三、数据范围与脱敏

| # | 步骤 | 期望 |
|---|------|------|
| 8 | 本页 | **本功能不适用部门数据范围**：导出日志是系统审计，有权限即看全部导出行（与操作日志相同） |
| 9 | 521/511 账号当时导出 | 「导出条件」无其无权筛选项；系统备注含「条件已按权限脱敏」（新写入）；金额明文不出现在条件摘要 |

## 四、与操作日志 / 详情 Tab 交叉

| # | 步骤 | 期望 |
|---|------|------|
| 10 | 任意列表点导出后看导出日志 | 新增一行；业务类型、页面标题、条件、条目数正确 |
| 11 | 同一账号打开操作日志 | **没有**该导出行；也无「导出条件」列 |
| 12 | 销售订单 / 入库单等详情「导出记录」Tab | 仍能看到**该单**的批次导出（不因操作日志排除而消失） |
| 13 | 详情批次导出 | 导出页面为单据页标题（如「销售订单」）；URL 含该单路径（如 `/sales-orders/{id}`） |
| 14 | 历史导出行（无 pageTitle） | 页面标题/URL 由目录回填；条目数、条件仍可读 |

## 五、系统备注与条目数

| # | 步骤 | 期望 |
|---|------|------|
| 15 | 未截断、未脱敏 | 系统备注为空 |
| 16 | 结果达到上限 | 条目数=上限；备注含「已截断（上限 50000）」；**条目数不写进备注** |
| 17 | 无筛选导出 | 导出条件=「全部（无筛选）」；备注**不**重复写「无筛选」 |

## 六、本功能不适用（总纲裁剪）

| 维度 | 说明 |
|------|------|
| 工作台 / 桌面（§4.3） | 本功能不适用：不是左栏队列桌面 |
| 页签模式 / 操作面板（§4.4） | 本功能不适用：本页无页签模式、无操作面板 |
| 金额核销足额/超额（§4.5） | 本功能不适用：只读审计，不提交核销/匹配 |
| 看板公式（§3.2） | 本功能不适用：无统计看板 |
| 多租户皮肤 / 打印（§4.6） | 本功能不适用：无打印、无租户皮肤 |

## 七、上线前置

1. 部署含本改动的 API 与 Web；**须重启 CRM.API**。  
2. **须执行**迁移 `20260902120000_SeedExportLogPermission`（或跑更新后的 `seed_management_roles_system_permissions.sql`）。  
3. 已有操作日志权限的账号须**重新登录**后才出现「导出日志」菜单。

*部署含导出日志独立页的版本后验收。*
