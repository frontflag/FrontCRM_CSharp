## 一、入口与权限

| # | 步骤 | 预期 |
|---|------|------|
| 1 | SYS_ADMIN 或 SYS_MANAGER 重新登录 | 参数管理可见「预警参数」；可打开 `/system/risk-alert-params` |
| 2 | 有 read、无 write（若单独摘权） | 能看五项门槛；输入框禁用；无「保存」；「刷新」可用 |
| 3 | SYS_BIZ_MANAGER（默认无本权限） | 参数管理无「预警参数」；直打路由被拒 |
| 4 | 普通业务员 | 无菜单；直打门槛页被拒；控制台卡片仍可见（现算自己数据范围） |
| 5 | 未登录打 `GET /api/v1/risk-alerts/dashboard` | 401 |
| 6 | SYS_BIZ_MANAGER 即使被误授 write，PUT 门槛 | HTTP 403（须 SYS_ADMIN / SYS_MANAGER） |

## 二、门槛默认与持久化

| # | 步骤 | 预期 |
|---|------|------|
| 7 | 首次进入（种子行） | 金额三项为 **0**；库龄、挂账天数为 **90** |
| 8 | 改任一值保存后刷新 | 仍为刚保存的值 |
| 9 | 金额填负数 / 超过上限 / 三位小数后 PUT | HTTP 400；库中原值不变 |
| 10 | 天数填负数或大于 9999 | HTTP 400；原值不变 |
| 11 | 保存成功后再点「刷新」 | 与已保存值一致 |

## 三、金额门槛边界（总纲 §4.5 对照）

本功能不提交核销，但「实际 vs 门槛」必须覆盖相等与超过。核对公式：

```text
金额超标 ⇔ 门槛 > 0 且 实际USD > 门槛
天数超标 ⇔ 门槛 > 0 且 账龄天数 > 门槛
门槛 = 0 → 该项关闭，不出现在控制台列表
```

| # | 步骤 | 预期 |
|---|------|------|
| 12 | **足额：实际 = 门槛**（金额或天数） | **不预警**；控制台不出现该项（成功/不触发） |
| 13 | **超额：实际比门槛大一个最小单位**（0.01 USD 或 1 天） | **预警**；出现对应行 |
| 14 | 门槛改为 0 后刷新控制台 | 该项消失（关闭） |
| 15 | 前端提示与后端判定 | 文案可不同，是否出卡以 API `triggered` 为准 |

## 四、五条口径 / 公式核对

在库与应收均受当前用户数据范围。可用库存明细、应收款列表手工复算。

| # | 规则 | 核对 |
|---|------|------|
| 16 | 库存占用 | 在库行 `QtyRepertory>0`、非移库源；美金优先 PO 行 `convert_price×数量`，否则 `PurchasePriceUsd×数量`。合计 > 门槛则预警 |
| 17 | 库龄 | `上海今天 − stock_in.stock_in_date`；无入库单/无入库日 **跳过**。超期条数与最长天数与列表一致 |
| 18 | 应收总额 | `verified_to_be>0`；美金优先 SO 行价比，否则查询日财务汇率。合计 > 门槛则预警 |
| 19 | 客户应收 | 按客户合计后再比；展示金额最大的一家及超标家数 |
| 20 | 订单挂账 | 挂账日 = `stock_out_date`，缺省建账日；**不**读付款条款文本。按销售订单取最大账龄，> 门槛则预警 |

## 八、本功能不适用（总纲裁剪）

| 维度 | 说明 |
|------|------|
| 工作台 / 桌面（§4.3） | 本功能不适用：不是左栏队列桌面 |
| 页签模式 / 操作面板（§4.4） | 本功能不适用：无业务列表页签、无操作面板 |
| 核销提交足额/超额（§4.5 核销义） | 本功能不适用核销/匹配提交；金额比较边界见 §三（相等不预警 + 超过预警） |
| 多租户皮肤 / 打印（§4.6） | 本功能不适用：无打印、无租户换肤 |
