# 业务列表取消行样式 — 测试对照说明

> **页面 / 路由：** 销售订单 `/sales-orders`；采购订单 `/purchase-orders`；销售订单明细 `/sales-order-items`；采购订单明细 `/purchase-order-items`（均为 **列表** 视图，非看板）  
> **设计文档：** [业务列表取消行样式-设计与实现](../../System/系统/业务列表取消行样式-设计与实现.md)  
> **规范：** [业务列表规范 §3.5](../../PRD/规范/UI规范/业务列表规范.md)  
> **自动化：** `CRM.Web/src/tests/list-cancelled-row.test.ts`（判定 helper；观感以本对照手工验）  
> **权限 / DDL：** 无独立权限码、无迁移。须各列表原有查看权限。  
> **帮助：** `help/pages/销售订单_MENU_SALES_ORDERS.md`、`采购订单_MENU_PURCHASE_ORDERS.md`、`销售订单明细_MENU_SALES_ORDER_ITEMS.md`、`采购订单明细_MENU_PURCHASE_ORDER_ITEMS.md`  
> **总纲：** [测试规范总纲.md](../测试规范总纲.md)

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有对应列表查看权限 | 可进列表；取消行样式随列表数据出现，无单独开关 |
| 无对应列表权限 | 进不了该页；本功能无单独权限码 |
| 销售/采购脱敏账号 | 金额/客商仍为 `—`；主单取消行仍整行浅灰（状态标签除外） |

---

## 二、主单取消：整行浅灰（必测）

筛选或翻页找到主状态为 **取消** 的行（与同页 **审核失败**、**已确认/审核通过** 对照）。

| 页面 | 准备 | 预期 |
|------|------|------|
| 销售订单列表 | 主单取消 | 整行文字、单号链接、金额/币别为浅灰；「取消」标签仍是原来的深色标签 |
| 采购订单列表 | 主单取消 | 同上 |
| 销售订单明细 | 所属销售订单取消 | 整行浅灰（只看主单，不看明细状态） |
| 采购订单明细 | 所属采购订单取消 | 整行浅灰；**主单已取消、明细状态仍显示已确认** 时同样浅灰 |
| 上述任一页 | 主单 **审核失败** | **不变灰**，与正常行字色一致 |
| 上述任一页 | 主单非取消 | 不变灰 |

操作列按钮（详情 / 取消确认等）保持原色，不是灰字禁用。

---

## 三、交互：不是禁用行

| 步骤 | 预期 |
|------|------|
| 单击取消行 | 可选中；明细列表可打开右侧操作（门控规则不变） |
| 双击取消行 | 仍进入详情（与列表交互规范一致） |
| 点中该行后 | 字色恢复正常（选中优先于灰色）；点其它行后该取消行再次浅灰 |
| 悬停取消行 | 有行悬停底，光标不是禁用 |

---

## 四、口径 / 公式核对

本功能不适用：金额核销 / 匹配的足额成功与超额拒绝（总纲 §4.5）。不提交金额。

判定：主单状态码 **取消 = `-2`**。审核失败 `-1` 不得套用。明细列表读主单状态字段 `orderStatus`，不读明细 `itemStatus`。

---

## 五、回归 / 交叉

| 步骤 | 预期 |
|------|------|
| 切到 **看板** | 看板卡片 **不** 套用本列表浅灰行（本版范围外） |
| 销售/采购详情标题 | 取消单标题弱化若已有，与列表行是两套样式，列表页回归以表体行为准 |
| 其它列表（入库、付款等） | 本期 **不** 因取消主单而整行浅灰 |

---

## 六、本功能不适用

- **本功能不适用：工作台 / 桌面左栏队列（总纲 §4.3）。**
- **本功能不适用：列表页签模式 / 左栏检索 / 操作面板单击门控（总纲 §4.4）。** 仅改行 class 与字色；门控仍按原操作面板对照。
- **本功能不适用：金额提交 / 核销 / 匹配足额与超额（总纲 §4.5）。**
- **本功能不适用：数据分析看板公式。**
- **本功能不适用：多租户皮肤 / 打印（总纲 §4.6）。** 三租户列表行为相同；打印页不在范围。

---

## 七、上线前

1. 部署含本改动的 **Web** 即可；不必改库、不必重启 API。  
2. 用户无需重新登录。  
3. 前端 helper 单测：`npx vitest run src/tests/list-cancelled-row.test.ts`（在 `CRM.Web`）。
