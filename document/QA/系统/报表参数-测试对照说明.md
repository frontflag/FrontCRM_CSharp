## 一、入口与权限

权限用例已集中维护于：[权限/系统功能-权限测试对照说明.md](../权限/系统功能-权限测试对照说明.md) §二。

本节保留核心结论：侧栏需 `system.params.report.read`；页内需 `system.params.report.global.read` / `.write`；无 read 被拒，无 write 可看不可改。

## 二、默认与持久化

| # | 步骤 | 期望 |
|---|------|------|
| 1 | 从未保存过（无 sysparam 行） | 下拉显示 **V1** |
| 2 | 选 V2 并保存，刷新页面 | 仍为 V2 |
| 3 | 再改回 V1 并保存，刷新 | 仍为 V1 |
| 4 | `PUT` 非法值（如 `V3`、`v1`） | HTTP 400；库中原值不变 |
| 5 | 保存成功后点「刷新」 | 与已保存值一致 |

## 三、数据范围与脱敏

| # | 步骤 | 期望 |
|---|------|------|
| 6 | 本页 | **本功能不适用部门数据范围**：系统参数全站一份，有权限即读写该参数 |
| 7 | 521/511 金额掩码账号 | **本功能不适用脱敏**：本页无金额、无客商名 |

## 四、与现有打印 / 公司信息交叉

| # | 步骤 | 期望 |
|---|------|------|
| 8 | 改为 V2 并保存后，在 **semicore** 打开采购订单打印并刷新 | 使用 V2 图1版式（详见 [采购订单报表打印对照](../采购/采购订单报表打印-三租户皮肤-测试对照说明.md)） |
| 8a | 改为 V2 并保存后，在 **idesemi / ecoinf** 打开采购订单打印并刷新 | **仍为该租户 V1**，与参数为 V1 时相同 |
| 8b | 改为 V2 并保存后，在 **semicore** 打开装箱单打印并刷新 | 竖版为 V2 双语 9 列；横版为 V2 14 列英文表头（详见 [装箱单对照](../物流/装箱单PackingList打印-三租户皮肤-测试对照说明.md)） |
| 8b1 | 改为 V2 并保存后，在 **idesemi / ecoinf** 打开装箱单打印 | **仍为该租户 V1**（竖/横均不变） |
| 8b2 | 改为 V2 并保存后打开销售订单/出库发票打印 | **版式不变**（仍走现有抬头与租户皮肤；本期不消费该参数） |
| 8c | 无参数管理权限的采购员打开采购订单打印 | 能打印；不要求进入「报表参数」页 |
| 9 | 公司信息里改报表备注或抬头 | 报表参数页的版本选择不变；反之亦然 |
| 10 | 销售参数 / 采购参数 / 财务参数菜单与页 | 不受影响 |

## 五、本功能不适用（总纲裁剪）

| 维度 | 说明 |
|------|------|
| 工作台 / 桌面（§4.3） | 本功能不适用：不是左栏队列桌面 |
| 页签模式 / 操作面板（§4.4） | 本功能不适用：本页无业务列表页签模式、无操作面板 |
| 金额核销足额/超额（§4.5） | 本功能不适用：不提交金额、不核销、不匹配 |
| 看板公式（§3.2） | 本功能不适用：无统计看板 |
| 多租户皮肤 / 打印（§4.6） | 配置页本身无打印预览。采购订单：V2 仅 semicore 换版。装箱单：V2 仅 semicore（竖+横）。idesemi/ecoinf 仍 V1。销售/发票打印不随本参数变 |

3. 已有管理账号须**重新登录**后才出现「报表参数」菜单。
