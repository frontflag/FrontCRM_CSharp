# 控制台待办 — 测试对照说明

> **页面 / 路由：** 控制台 `/dashboard`  
> **设计文档：** [控制台待办-设计与实现](../../System/系统/控制台待办-设置我的邮箱-设计与实现.md)  
> **关联：** [申请公司邮箱-测试对照说明](./申请公司邮箱-测试对照说明.md)、[AI用户反馈助手-测试对照说明](./AI用户反馈助手-测试对照说明.md)

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 任意已登录用户打开控制台 | 能看到欢迎区与统计卡；待办面板仅在有未完成子任务时出现 |
| 无额外邮箱权限的普通员工 | 仍可看到「设置我的邮箱」（个人设置，不另授权） |
| 非系统管理员（含仅有反馈管理权限的运维账号） | **不**出现「用户反馈」子任务 |
| 系统管理员（`SYS_ADMIN`） | 有需处理反馈时出现「用户反馈」 |

---

## 二、设置我的邮箱

| 步骤 | 预期 |
|------|------|
| 用户没有任何验证成功的邮箱（未添加 / 仅未验证 / 仅验证失败） | 统计卡下方出现「待办」；内有子任务「设置我的邮箱」；说明含收信引导；按钮「去设置」 |
| 点「去设置」 | 进入「我的邮箱」；返回后回到控制台 |
| 在「我的邮箱」添加任意一条（平台或其他）并验证成功，再回控制台 | 「设置我的邮箱」消失；若无其它待办项，整块「待办」消失 |
| 仅有未验证草稿平台邮箱 | 该子任务仍在（草稿不算完成） |
| 统计卡「待处理事项」数字 | 仍只表示待审批条数，不因邮箱待办 +1 |

---

## 三、用户反馈（系统管理员）

| 步骤 | 预期 |
|------|------|
| 系统管理员、库中有 `需处理=是` 的反馈 N 条 | 待办中出现「用户反馈」；标题旁数字为 N；说明为「当前有 N 条需处理的反馈。」 |
| 点「去处理」 | 进入运维「用户反馈」；处理筛选项预选「需处理」；列表条数与控制台 N 一致 |
| 把全部需处理勾成不需处理或已完成，再回控制台 | 「用户反馈」消失；若邮箱也已验证，整块「待办」消失 |
| 需处理条数为 0 | 不出现「用户反馈」 |
| 系统管理员同时未验证邮箱且有需处理反馈 | 待办内同时有「设置我的邮箱」与「用户反馈」两张卡片 |
| 统计卡「待处理事项」 | **不**因反馈条数变化 |

---

## 四、异常与加载

| 步骤 | 预期 |
|------|------|
| 邮件摘要接口失败 | 仍显示「设置我的邮箱」（按未完成处理） |
| 反馈列表接口失败 | **不**显示「用户反馈」 |
| 页面加载瞬间 | 各子任务等对应接口返回后再出现，不先闪后消失 |

---

## 五、回归 / 交叉

| 步骤 | 预期 |
|------|------|
| 采购主部门 / 客户主部门 / 仅待处理事项统计 | 原统计卡布局不变，待办在其下方 |
| 控制台帮助 | 提到待办、邮箱引导，以及系统管理员的用户反馈待办（业务说法） |
| 运维「用户反馈」原筛选 / 详情处理 | 不受 `?handling=need` 以外的回归破坏；无该参数时仍默认不筛 |

---

## 六、本功能不适用（总纲强制声明）

- **本功能不适用：金额 / 核销 / 匹配的足额成功与超额拒绝**（§4.5）。本页只做引导显隐与条数展示，不提交金额。
- **本功能不适用：工作台左右栏队列**（§4.3）。控制台待办不是审批桌面。
- **本功能不适用：列表页签模式 / 操作面板门控**（§4.4）。
- **本功能不适用：多租户皮肤 / 打印**（§4.6）。无新皮肤、无打印。
- **本功能不适用：看板统计公式**。条数直接取反馈列表 `total`，无折算。
- **本功能不适用：数据库迁移 / 新权限脚本**（§4.7）。不改表；复用邮件摘要与反馈管理接口。
- **本功能不适用：销售/采购敏感掩码**（§4.2）。待办不含客商名与金额。
