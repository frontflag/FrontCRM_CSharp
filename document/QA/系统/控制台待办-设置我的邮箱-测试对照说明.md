# 控制台待办 — 设置我的邮箱 — 测试对照说明

> **页面 / 路由：** 控制台 `/dashboard`  
> **设计文档：** [控制台待办-设置我的邮箱-设计与实现](../../System/系统/控制台待办-设置我的邮箱-设计与实现.md)

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 任意已登录用户打开控制台 | 能看到欢迎区与统计卡；待办面板仅在有未完成引导任务时出现 |
| 无额外邮箱权限的普通员工 | 仍可看到「设置我的邮箱」（个人设置，不另授权） |

---

## 二、出现与消失

| 步骤 | 预期 |
|------|------|
| 用户没有任何验证成功的邮箱（未添加 / 仅未验证 / 仅验证失败） | 统计卡下方出现「待办」；内有子任务「设置我的邮箱」；说明含收信引导；按钮「去设置」 |
| 点「去设置」 | 进入「我的邮箱」；返回后回到控制台 |
| 在「我的邮箱」添加任意一条（平台或其他）并验证成功，再回控制台 | 「设置我的邮箱」消失；若无其它待办项，整块「待办」消失 |
| 仅有未验证草稿平台邮箱 | 待办仍在（草稿不算完成） |
| 统计卡「待处理事项」数字 | 仍只表示待审批条数，不因邮箱待办 +1 |

---

## 三、异常

| 步骤 | 预期 |
|------|------|
| 摘要接口失败 | 仍显示「设置我的邮箱」（按未完成处理） |
| 页面加载瞬间 | 不先闪出再消失（等摘要返回后再决定显隐） |

---

## 四、回归

| 步骤 | 预期 |
|------|------|
| 采购主部门 / 客户主部门 / 仅待处理事项统计 | 原统计卡布局不变，待办在其下方 |
| 控制台帮助 | 提到待办与邮箱引导（业务说法） |

---

## 五、本功能不适用（总纲强制声明）

- **本功能不适用：金额 / 核销 / 匹配的足额成功与超额拒绝**（§4.5）。本页只做引导显隐，不提交金额。
- **本功能不适用：工作台左右栏队列**（§4.3）。控制台待办不是审批桌面。
- **本功能不适用：列表页签模式 / 操作面板门控**（§4.4）。
- **本功能不适用：多租户皮肤 / 打印**（§4.6）。无新皮肤、无打印。
- **本功能不适用：看板统计公式**。
- **本功能不适用：数据库迁移 / 新权限脚本**（§4.7）。不改表；复用邮件摘要接口。
- **本功能不适用：销售/采购敏感掩码**（§4.2）。待办不含客商名与金额。
