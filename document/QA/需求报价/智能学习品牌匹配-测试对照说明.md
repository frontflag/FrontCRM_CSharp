## 一、环境与前置

| # | 检查项 | 预期 |
|---|--------|------|
| 1 | 已执行 `ensure_biz_brand_learned_mapping_postgresql.sql` | 表与唯一索引 `ux_biz_brand_learned_mapping_source_key` 存在 |
| 2 | `biz_brand` 有测试品牌 A、B（标准名互不混淆） | options 接口可搜到 |
| 3 | 测试账号已登录 | 可调用 `biz-brands` API |

---

## 二、归一化键（source_key）

在 DB 或 API 层验证下列原文 **命中同一条** 学习记录：

| 写入 source_text | 再次导入/resolve 用原文 | 预期 |
|------------------|-------------------------|------|
| `TI(德州仪器)` | `ti(德州仪器)` | resolve 命中 |
| `TI(德州仪器)` | `ＴＩ（德州仪器）`（全角） | resolve 命中 |
| `  ST  ` | `st` | resolve 命中 |
| `TI(德州仪器)` | `TI(德州市仪器)` | **不**命中（不同 key） |

---

## 三、学习写入（Remember）

| # | 操作 | 预期 |
|---|------|------|
| 1 | Excel 导入一行品牌 pending，进入 RFQCreate | 行显示「导入「xxx」待选择」 |
| 2 | 为该选手标准品牌 A | Toast「已记住该品牌映射…」；`_importBrandText` 清除 |
| 3 | 查 DB | 一行：`source_key` 归一化、`brand_id`=A、`hit_count`=1 |
| 4 | 同一行再次改选品牌 B | `brand_id` 更新为 B，`hit_count` 递增 |
| 5 | RFQCreate 普通手选（无 `_importBrandText`） | **不**调用 remember |
| 6 | remember 非法 `brandId` | API 404 |

---

## 四、学习读取（Resolve）

| # | 操作 | 预期 |
|---|------|------|
| 1 | DB 已有 `TI(德州仪器)` → 品牌 A | `resolve { sourceTexts: ["TI(德州仪器)"] }` 返回 A |
| 2 | Excel 再次导入含 `TI(德州仪器)` | 统计「规则/学习」+1，`mappingSource=learned`，无需手选 |
| 3 | resolve 空数组 | 返回 `[]` |
| 4 | 学习映射指向已软删品牌 | resolve **不**返回该条（或跳过无效 brand） |

---

## 五、规则层（与学习的关系）

| # | 场景 | 预期 |
|---|------|------|
| 1 | 无学习记录，导入「STMicroelectronics」与标准名一致 | `mappingSource=rule`，不写学习表 |
| 2 | 有学习记录 `TI(德州仪器)`→A，导入同文案 | **走 learned**，即使规则也能匹配到其他品牌 |
| 3 | 导入「ST」且标准库多品牌含 ST 歧义 | `pending`，不自动绑定 |
| 4 | 括号拆词：`XXX(YYY)` 仅 `XXX` 能唯一匹配 | 可通过拆词 rule 命中 |

---

## 六、AI 层（补漏）

| # | 操作 | 预期 |
|---|------|------|
| 1 | pending 行点击「AI 智能匹配品牌」 | 仅 pending 文本进入 `source_texts` |
| 2 | AI 返回 standard_brand 且规则唯一命中 | `mappingSource=ai` |
| 3 | 已 learned 行 | **不**被 AI 覆盖 |

（场景配置与权限见 RFQ Excel 导入测试文档 §4.3。）

---

## 七、匹配链优先级（集成）

| 顺序 | 来源 | 验证方法 |
|------|------|----------|
| 1 | learned | 先 remember，再导入同文案 |
| 2 | rule | 删除学习记录后，用与 standardBrand 一致文案导入 |
| 3 | ai | 非常规写法 + AI 按钮 |
| 4 | pending | 歧义或生僻写法 |
| 5 | 手选+学习 | pending → RFQCreate 手选 → 下次变 learned |

---

## 八、API 请求/响应样例

**Remember**

```http
POST /api/v1/biz-brands/learned-mappings/remember
{ "sourceText": "TI(德州仪器)", "brandId": 123 }
```

**Resolve**

```http
POST /api/v1/biz-brands/learned-mappings/resolve
{ "sourceTexts": ["TI(德州仪器)", "ST"] }
```

响应项含：`sourceText`、`sourceKey`、`brandId`、`standardBrand`。

## 九、回归清单

- [ ] source_key 归一化（半角、小写、括号）
- [ ] remember 写入与覆盖、`hit_count` 递增
- [ ] resolve 批量命中
- [ ] learned 优先于 rule
- [ ] 手选学习后二次导入自动匹配
- [ ] 无 `_importBrandText` 不写入学习表
- [ ] RFQ 保存仍要求每行 `brandId > 0`
