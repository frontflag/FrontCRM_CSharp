# 客户首页 KPI — 测试对照说明

**对应设计：** [客户首页KPI-设计与实现](../../System/客户/客户首页KPI-设计与实现.md)  
**页面：** 客户首页；客户列表左栏「有在库的客户」「应收款的客户」

---

## 1. 应收

| 步骤 | 预期 |
|------|------|
| 选一客户，有出库完成生成的应收且 `VerifiedToBe > 0`（原币） | 首页「应收货款」含该笔按关联销售订单行 `convert_price/price` 折 USD；「应收客户」计入该客户 |
| 点「应收货款」或「应收客户」 | 进入客户列表，`preset=has_receivable`，列表含该客户 |
| 将该台账核销至 `VerifiedToBe = 0` | 金额与客户数不再计入；快筛也不再命中 |
| 对比财务应收看板同一客户未结金额折 USD | 与首页口径一致（SO 行 `convert_price` / `FromExtend`） |

## 2. 在库

| 步骤 | 预期 |
|------|------|
| 客单库存 `QtyRepertory > 0`，行上有 `CustomerId` 或关联销售明细客户 | 金额 ≈ Σ Qty×SalesPriceUsd；客户计入「在库客户」 |
| 仅备货（StockType=2）或样品（3）有在库 | **不计入** |
| 无销售明细但 `CustomerId` 有值 | **计入** |
| 点「在库金额」或「在库客户」 | `preset=pending_shipment`，列表含该客户 |
| 左栏文案 | 显示「有在库的客户」，非「待发货」 |

## 3. 权限与脱敏

| 步骤 | 预期 |
|------|------|
| 无该客户数据权限的账号 | 首页金额/客户数不含该客户；列表快筛也不出 |
| 触发 mask521 的角色 | 金额显示为 0，客户数仍可有值（与既有行为一致） |
