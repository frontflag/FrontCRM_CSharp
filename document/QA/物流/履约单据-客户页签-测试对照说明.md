## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 无销售订单读 **且** 无采购订单读 | 不可进入上述页面 |
| 出库通知列表（非报关筛选），展开右栏 | 页签 **客户 → 帮助**；默认 **帮助**（若无本页记忆） |
| 出库通知列表处于报关筛选 | 页签 **报关 → 客户 → 帮助**；默认仍为 **报关** |
| 出库通知详情 / 出库单详情 / 出库明细 | 页签 **客户 → 帮助**；默认 **帮助** |
| 装箱单列表 / 详情 / 装箱明细 | 页签 **流程 → 客户 → 帮助**；默认 **流程** |
| 出库单列表 | 页签 **操作 → 客户 → 帮助**；默认 **操作** |
| 点「客户」且列表未选行 | 提示单击列表行查看客户 |
| 详情打开后点「客户」 | 无需再点明细行即可出摘要 |
| 能打开该客户详情的账号 | 三块卡片（概况橙色编号 + 基本信息/财务信息标签：值） |
| 无客户模块权限，或客户不在数据范围，或 521 | 仅编号 + 档案业务员；编号不可点 |

刷新后右栏页签记忆与其它扩展页签相同。

---

## 二、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 列表看不到的单据 | 客户页签 403 或 404，与列表一致 |
| 521 仍能打开的物流范围「全部」单据 | 仍可出编号 + 档案业务员；名称/额度不下发 |
| Network | `GET /api/v1/customer-workspace?source=stockOutRequest\|packing\|packingItem\|stockOut\|stockOutItem&id=`，**不**带 `customerId` |

---

## 三、门控与空态

| 步骤 | 预期 |
|------|------|
| 停在「帮助 / 操作 / 流程 / 报关」时单击行 | **不**请求客户摘要 |
| 列表默认页签下单击行 | **不**自动切到「客户」（报关通知单击仍自动切「报关」） |
| 再点「客户」 | 才请求并展示 |
| 右栏收起时单击行 | 不请求客户 |
| 列表搜索 / 重置 | 右栏客户回到未选行 |
| 无客户的单据 | 「该单据未关联客户档案」 |
| 装箱明细单击行 | **不**自动切到「客户」；在「流程」下仍加载流程（原行为） |
| 看板 | 不因看板点击加载客户 |

---

## 四、字段核对（有完整权限时）

与 **客户详情** 对照同一客户：编号、中英文名称、类型/等级/行业、账期、结算币别、信用额度一致。

---

## 五、回归 / 交叉

| 步骤 | 预期 |
|------|------|
| 出库单「操作」、装箱「流程」、出库通知「报关」 | 默认页签与单击门控与本改动前一致 |
| 需求 / 销售三页客户页签 | 不受本批影响 |

---

## 六、本功能不适用

- **本功能不适用：§4.5 核销金额足额成功 / 超额拒绝**（只读展示信用额度）。
- **本功能不适用：多租户打印皮肤**。
- **本功能不适用：工作台左栏队列 / 顶栏 N/M**。
- **本功能不适用：列表页签模式 / 左栏检索 preset**（本页签不改筛选）。
- **本功能不适用：需求 / 销售 / 收款 / 销项发票 / 应收右栏**（已另有对照说明）。

**上线前置：** 部署后须 **重启 CRM.API**。
