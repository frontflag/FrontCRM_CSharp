# 出库单强制删除 — 测试对照说明

> **页面 / 路由：** 仓储管理 → 出库单列表 `/stock-outs`（`StockOutList`）  
> **设计文档：** [出库单强制删除-设计与实现](../../System/物流/出库单强制删除-设计与实现.md)  
> **权限 / DDL：** 无新权限码、无新迁移。预览与强制删除：系统管理员、平台管理员。  
> **关联：** [出库运维检查-测试对照说明](./出库运维检查-测试对照说明.md)、[收款核销](../../System/财务/收款核销-设计与实现.md)

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 系统管理员或平台管理员打开出库单列表 | 操作列可见「强制删除」；点开弹出确认框（不是浏览器 `prompt`） |
| 非上述角色（有出库列表权限） | 无「强制删除」按钮；直调 `GET …/force-delete-preview` 与 `POST …/force-delete` 均为 403 |
| 未登录 | 进登录页 |

## 二、确认框内容

先打开列表，再点「强制删除」。弹窗须先加载预览。

| 数据 | 预期 |
|------|------|
| 销售出库完成、无有效应收 | 文案「本单没有有效应收。」无应收表。列出后果（不含「一并作废应收」）。可输入出库单号；单号一致才能点「强制删除」 |
| 销售出库完成、未核销应收 `ARV…` 金额 100、已核销 0 | 表中有该应收单号、核销状态「未核销」、应收金额 100.00、已核销 0.00、收款单「—」。后果含「一并作废未核销应收」。输入正确出库单号后删除成功；应收列表不再有该 `ARV…` |
| 同一出库、应收已核销（已核销金额 > 0，有收款单 `FRC…`） | 红字「不能强制删除」+ 守卫原文（含已核销金额）。表中核销状态非「未核销」，收款单列为该 `FRC…`。有「请先…反核销」说明。无出库单号输入、无「强制删除」按钮；仅「关闭」。出库单与应收均仍在 |
| 输入单号与出库单号不一致 | 「强制删除」按钮保持不可用；强行提交则提示单号不匹配，单据未删 |
| 输入正确单号后成功 | 提示成功；列表刷新后该出库单消失 |
| 预览接口失败 | 提示加载失败；不出现空白确认框可删 |

## 三、口径 / 公式核对

本功能**不提交核销金额**。弹窗金额来自有效应收行：

```text
应收金额 = finance_receivable.amount
已核销   = finance_receivable.verified_done
核销状态 = 0 未核销 / 1 部分核销 / 2 核销完成
```

| 用例 | 预期 |
|------|------|
| **足额（已核销 = 应收金额）** | 拦截，不能强制删除（与核销完成一致） |
| 超额核销提交 | **本功能不适用：无核销、匹配、付款提交** |
| 未核销（已核销 = 0） | 允许删除且预览「将作废应收」 |
| 前端提示与后端拒绝 | 已核销时弹窗先拦截；即使调 `POST force-delete` 仍 400，单据不变 |

库存回滚：仅出库状态为已出库(2)或出库完成(4)时预览出现「回滚库存」。

## 四、通用维度（不适用项）

| 维度 | 说明 |
|------|------|
| 数据范围与脱敏 | 强制删除仅管理员。预览按该出库下全部有效应收，不分销售员数据范围。本弹窗不展示客户名，无销售掩码字段 |
| 工作台 / 桌面 | 本功能不适用 |
| 页签模式 / 左栏检索 / 操作面板 | 本功能不适用：页签见 [出库单列表-筛选页签模式-测试对照说明](./出库单列表-筛选页签模式-测试对照说明.md) |
| 多租户皮肤 / 打印 | 本功能不适用 |
| 上线前置 | 无 DDL。须部署含本弹窗的前后端并重启 API |

## 五、回归

| 步骤 | 预期 |
|------|------|
| 普通删除 | 已出库/出库完成仍不可普通删除 |
| 标记完成 | 对话框与强制删除互不影响 |
| 出库运维检查 | 强制删除未核销应收的出库后，不再报「出库已删、应收仍有效」 |
| 帮助页签 | 业务说明，无权限码/表名 |

*部署含本功能的版本后验收。*
