# 库存明细列表 · 库存类型筛选 — 测试对照说明

> **页面 / 路由：** `/inventory/stock-items`（库存明细）  
> **设计文档：** [库存明细列表-库存类型筛选-设计与实现](../../System/物流/库存明细列表-库存类型筛选-设计与实现.md)  
> **页签模式（交叉）：** [库存明细列表-筛选页签模式-测试对照说明](./库存明细列表-筛选页签模式-测试对照说明.md)  
> **权限 / DDL：** 无新权限码、无新迁移；刷新前端即可验收

---

## 1. 入口与权限

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 有库存读权限进入 `/inventory/stock-items` | 搜索栏「库存类型」在「是否有库存」之后、「入库类型」之前；表格 **无**「库存类型」列；备货行编号旁仍有箱子图标 |
| 2 | 无库存读权限 | 不可进入本页（与列表既有门控一致） |
| 3 | 采购 511 / 销售 521 脱敏 | 下拉仍可用；供应商/客户等仍为 `—` |

**本功能不适用：** 无 write 提交按钮（只改筛选）。

---

## 2. 搜索栏

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 未选（占位「库存类型」） | 请求 **不带** `stockType` |
| 2 | 选备货库存 | `GET .../stock-items?stockType=2`；结果仅备货层；备货行编号旁有箱子图标 |
| 3 | 选客单库存 / 样品库存 | 分别为 `1` / `3`；结果与层类型一致 |
| 4 | 清空 | 恢复不过滤 |
| 5 | 改选项 | **立即**刷新列表与顶部数量合计 |
| 6 | 重置 | 下拉清空；请求不带 `stockType` |
| 7 | 下拉选项 | 仅三档：客单库存 / 备货库存 / 样品库存 |
| 8 | 打开 `/inventory/stock-items?stockType=2` | 下拉已选「备货库存」；请求带 `stockType=2` |
| 9 | 齿轮 → 页签模式 | **有**「库存类型」项；选中后本下拉隐藏，页签为全部 / 客单库存 / 备货库存 / 样品库存；点页签立即查询（详见 [筛选页签模式对照](./库存明细列表-筛选页签模式-测试对照说明.md)） |

---

## 3. 口径交叉

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 选「备货库存」且该层来自采购入库 | **出现**（入库类型与库存类型独立） |
| 2 | 同时选「入库类型 = 采购入库」与「库存类型 = 备货库存」 | 两条件 **AND** |
| 3 | 同时选「是否有库存 = 有库存」 | 两条件 **AND** |
| 4 | 勿与「入库类型」混淆 | 本下拉 **不**改变 `stockInType`；「入库类型」下拉 **不**改变 `stockType` |
| 5 | 导出 | 当前筛选含类型时 CSV 仅含该类型（沿用既有导出 query） |

---

## 4. 本功能不适用

- **本功能不适用：金额 / 核销 / 匹配足额与超额。**
- **本功能不适用：数据分析看板公式。**
- **本功能不适用：多租户打印皮肤。**
- **本功能不适用：审批/核销工作台左栏队列。**
- **本功能不适用：数据库迁移**（沿用 `stock_item."Type"`）。
- **本功能不适用：新增表格列**（首版仅搜索栏；备货仍靠编号旁图标）。
- 页签形态与持久化的细项见 [筛选页签模式对照](./库存明细列表-筛选页签模式-测试对照说明.md)（本字段已注册为页签维度）。
