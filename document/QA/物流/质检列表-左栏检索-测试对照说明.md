# 质检列表 — 左栏检索 — 测试对照说明

> **页面：** `/logistics/qc`  
> **设计文档：** [质检列表-左栏检索-设计与实现](../../System/物流/质检列表-左栏检索-设计与实现.md)

---

## 一、入口与布局

| 步骤 | 预期 |
|------|------|
| 进入质检列表，展开左栏「检索」 | 两组：**时间**（5 项）、**状态**（5 项） |
| 左栏 | **无** 型号/供应商等文本输入框 |
| 主栏 | 到货类型、单号、型号等 search-bar 始终可见 |

---

## 二、交互

| 步骤 | 预期 |
|------|------|
| 点击「近7日质检」 | URL 含 `preset=qc_within_7_days`；主栏上方出现 preset chip |
| 再点同一项 | 清除 `preset`；**保留** 主栏 keyword（若有） |
| chip ✕ | 同上 |
| 主栏「重置」 | 清空 preset + 全部 keyword |
| 选 preset 后填型号点「搜索」 | URL 同时含 `preset` + `model` |
| 选 preset 后选「报关入库」点「搜索」 | URL 含 `preset` + `stockInType=20`；列表为交集 |
| F5 | preset 仍生效 |

---

## 三、时间组

前置：以 **`CreateTime`（创建时间）** 为准，UTC 日历日窗口（与到货 preset 后端一致）。

| preset | 构造数据要点 | 预期 |
|--------|----------------|------|
| 今日质检 | 今天创建的质检单 | ✅ |
| 今昨质检 | 昨天或今天创建 | ✅；更早日期 ❌ |
| 近3日质检 | 创建日在 [今天-2, 今天] | 共 3 个日历日 |
| 近7日质检 | 创建日在 [今天-6, 今天] | 同上 |
| 近30日质检 | 创建日在 [今天-29, 今天] | 同上 |

---

## 四、状态组

| preset | 构造数据要点 | 预期 |
|--------|----------------|------|
| 已通过 | 详情保存结果为 pass（`Status=100`） | ✅ |
| 部分通过 | 保存为 partial（`Status=10` 且已保存，`ModifyTime` 有值） | ✅ |
| 部分通过 | **仅创建、未保存**（`Status=10`，`ModifyTime` 空） | ❌ **不应出现** |
| 拒绝 | 保存为 reject（`Status=-1`） | ✅；左栏文案「拒绝」，列表列可为「未通过」 |
| 有质检图片 | 已上传 QC 图片附件（`BizType=QC`） | ✅；接口无 EF 翻译错误 |
| 无质检图片 | 无图片附件 | ✅；与「有质检图片」互斥 |

---

## 五、与右栏操作面板

| 步骤 | 预期 |
|------|------|
| 选中行后切换 preset / 搜索 / 重置 | 右侧操作面板选中清空（与高亮行一致） |
| 分页 | 若选中行仍在当前页，操作面板同步刷新 |
