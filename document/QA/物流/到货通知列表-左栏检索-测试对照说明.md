# 到货通知列表 — 左栏检索 — 测试对照说明

> **页面：** `/logistics/arrival-notices`  
> **设计文档：** [到货通知列表-左栏检索-设计与实现](../../System/物流/到货通知列表-左栏检索-设计与实现.md)

---

## 一、入口与布局

| 步骤 | 预期 |
|------|------|
| 进入页面，展开左栏「检索」 | 六组：逾期 / 预计 / 到货 / 类型 / 待办 / 状态（共 20 项） |
| 无 preset | 主栏可见状态、到货类型、预计到货单日、查询/重置 |
| 选任一 preset | 主栏出现 preset chip；与 preset 冲突的主栏控件隐藏（见设计 §5） |

交叉：页签模式与 preset 见 [筛选页签模式-测试对照说明](./到货通知列表-筛选页签模式-测试对照说明.md) §10.3。

---

## 二、交互

| 步骤 | 预期 |
|------|------|
| 点击「所有逾期」 | URL 含 `preset=overdue_all`；列表仅 `status=10` 且预计日 &lt; 今天 |
| 再点同一项 | **清空全部 query**（含采购单号等 keyword） |
| chip ✕ / 主栏「重置」 | 同上，清空 preset |
| 选 preset 后填采购单号点「搜索」 | URL 保留 `preset` + `purchaseOrderCode` |
| F5 | preset 仍生效 |

---

## 三、逾期组

前置：行需有 **预计到货日**；无预计日 **不进** 逾期 preset。

| preset | 构造数据要点 | 预期 |
|--------|----------------|------|
| 所有逾期 | 预计日=昨天，`status=10` | ✅ |
| 逾期1天 | 预计日=昨天 | ✅；预计日=前天 → 仅「所有逾期/逾期3天/逾期1周」 |
| 逾期3天 | 预计日 ∈ [今天-3, 昨天] | 与包含关系一致 |
| 逾期1周 | 预计日 ∈ [今天-7, 昨天] | 同上 |
| 预计日在未来 | `status=10` | **不进** 任何逾期项；可用 **未到货** |

---

## 四、预计组

| preset | 预期 |
|--------|------|
| 预计今日 | 预计日=今天（**可含** `status=20+`） |
| 预计明天 | 预计日=明天 |
| 预计3天内 | 今天 ≤ 预计日 ≤ 今天+3；**不含** 昨天（逾期） |
| 预计1周内 | 今天 ≤ 预计日 ≤ 今天+7 |

无预计日行：**不出现** 于预计组结果。

---

## 五、到货组与实到日

| preset | 预期 |
|--------|------|
| 未到货 | 全部 `status=10`（含未来预计日） |
| 今日到货 | 确认到货后实到日=今天；`status≥20` |
| 今昨到货 / 3日内 / 1周内 / 1月内 | 实到日落对应区间 |

| 步骤 | 预期 |
|------|------|
| 确认到货 | 写入 `ActualArrivalDate`；列表「实到日」列有值 |
| 回滚至未到货（若业务允许） | 实到日清空；「今日到货」筛不到 |

历史数据：执行回填脚本后，旧单「1月内到货」可查到近似实到日。

---

## 六、类型 / 待办 / 状态

| preset | 预期 |
|--------|------|
| 采购入库 / 报关入库 | `stockInType` 10 / 20 |
| 待质检 | `status=20` |
| 待入库 | `status=30` 且无 **已过账** 采购入库单关联 |
| 已质检 | 全部 `status=30`（含已建未过账入库单） |
| 已入库 | `status=100` |

| 构造 | 待入库 | 已质检 |
|------|--------|--------|
| 质检完成，未生成入库单 | ✅ | ✅ |
| 已生成入库单未点「标记已入库」 | ✅ | ✅ |
| 入库单已过账 | ❌ | ✅ |

---

## 七、与页签模式

| 步骤 | 预期 |
|------|------|
| 已开「状态」页签 + 选「待质检」preset | 页签条隐藏；状态下拉隐藏 |
| 清除 preset | 恢复 localStorage 页签偏好 |
| 已开「到货类型」页签 + 选「采购入库」preset | 类型页签隐藏 |

---

*keyword 仅采购单号/货代单号；左栏无型号/供应商表单。*
