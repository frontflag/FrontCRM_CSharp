# 出库通知列表 — 客户字段与单号筛选 — 测试对照说明

> **页面 / 路由：** `/stock-out-notifies`、`/inventory/stock-out-notifies`（同一组件）  
> **设计文档：** [出库通知列表-客户字段与单号筛选-设计与实现](../../System/物流/出库通知列表-客户字段与单号筛选-设计与实现.md)  
> **权限：** 路由 `sales-order.read` 或 `purchase-order.read`（OR）  
> **总纲：** [测试规范总纲](../测试规范总纲.md)

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有 `sales-order.read` 或 `purchase-order.read` 之一 | 可进入列表，见新列与新筛选项 |
| 两码皆无 | 不可进入该页 |

---

## 二、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 普通业务账号打开列表 | 仅本数据权限范围内的出库通知 |
| 销售敏感掩码开启 | 客户名、业务员、**客户订单号、客户型号** 列为 `—`；搜索栏不出现客户订单号 / 客户型号输入；列表仍可加载 |
| 掩码账号筛销售单号 / 装箱单号 / 出库单号 / 品牌 | 仍可筛；结果行客户侧字段仍为 `—` |

---

## 三、列展示

| 步骤 | 预期 |
|------|------|
| 打开列表（未改过列设置，或重置列后） | 可见「客户型号」（在物料型号旁）、「客户订单号」（在销售单号旁）、「出库单号」（在装箱单号旁） |
| 对照同一条销售明细 | 客户订单号 / 客户型号与销售明细列表当前值一致（不是出库通知创建时的旧值） |
| 物料型号 / 品牌 | 仍为出库通知上的型号、品牌（快照）；与「客户型号」不同 |
| 未装箱 | 装箱单号、出库单号均为 `—` |
| 已装箱未出库 | 有装箱单号；出库单号为 `—` |
| 已出库 | 出库单号有值；单击进入该出库单详情（多单号时点进排序后的第一张） |
| 装箱单号单击 | 进入对应装箱单详情（原行为保持） |

---

## 四、筛选（点「搜索」后生效）

均为占位符文本框，**模糊包含**（大小写不敏感）。改完不点搜索不请求。

| 步骤 | 预期 |
|------|------|
| 筛销售单号（部分字符） | 仅销售单号包含该字串的通知；请求带 `salesOrderCode` |
| 筛客户订单号 | 仅销售明细当前客户订单号包含该字串；请求 `customerSo` |
| 筛客户型号 | 仅销售明细当前客户型号包含该字串；请求 `customerPn` |
| 筛装箱单号 | 仅已关联装箱且装箱单号包含该字串；未装箱的通知不出现；请求 `packingCode` |
| 筛出库单号 | 仅已关联出库且出库单号包含该字串；未出库的通知不出现；请求 `stockOutCode` |
| 筛品牌 | 仅通知上的品牌快照包含该字串；请求 `brand`（不是客户品牌） |
| 与原有物料型号、公司、业务员、日期组合 | 条件同时成立（AND） |
| 点「重置」 | 上述新筛与原有筛一并清空并重新查询 |

筛选项顺序（公司、业务员之后）：销售单号 → 客户订单号 → 客户型号 → 物料型号 → 装箱单号 → 出库单号 → 品牌 → 预计出库日期。

## 五、页签模式回归

| 步骤 | 预期 |
|------|------|
| 开启页签模式（状态 / 地域 / 出库类型任一） | 页签仍只有该维度；**不会**出现销售单号等文本页签 |
| 页签筛选 + 文本筛销售单号 | 两者同时生效 |

完整页签验收见 [出库通知列表-筛选页签模式-测试对照说明](./出库通知列表-筛选页签模式-测试对照说明.md)。

## 六、本功能不适用（总纲强制项）

| 维度 | 说明 |
|------|------|
| 金额 / 核销 / 匹配（总纲 §4.5） | 本功能不适用：列表展示与文本筛选，无金额提交、核销或匹配进度 |
| 工作台 / 桌面（总纲 §4.3） | 本功能不适用：无左栏队列 |
| 多租户打印皮肤（总纲 §4.6） | 本功能不适用：无打印、无租户报表皮肤 |
| 左栏 shortcut preset | 本功能不适用：本列表无左栏检索 preset |
| 操作面板门控 | 本功能不适用：本对照不覆盖报关单右栏 |
| 上线 SQL / 迁移 | 本功能不适用：无新权限码、无 DDL；改后端后须**重启 API** |

---

## 七、已知口径差异

| 项 | 说明 |
|----|------|
| 客户订单号 / 客户型号 | 读销售明细**当前**值；物料型号 / 品牌仍是通知快照。改销售明细后刷新列表，前两项会变，后两项不变 |
| 多装箱 / 多出库 | 单号顿号拼接；链接只进第一条 |
| 报关单「业务记录」嵌入表 | 与主列表共用列定义，同样出现新列 |
