> **关联设计：** [入库单列表-操作面板-设计与实现](../../System/物流/入库单列表-操作面板-设计与实现.md)  
> **布局规范（权威）：** [销售操作面板 §2.5 / §2.5.4](../../System/销售订单明细列表-操作面板-设计与实现.md)、[扩展窗口页签-操作规范](../../PRD/规范/UI规范/扩展窗口页签-操作规范.md)

## 1. 页签与门控

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 进入 `/inventory/stock-in`（列表模式） | 右栏显示 **操作 + 帮助**，默认 **操作** |
| 2 | 右栏收起，单击任意行 | 不展开右栏、不高亮、不请求 `ops-aggregates` |
| 3 | 展开右栏，切到 **帮助**，单击行 | 行高亮 `so-item-row--active`，不切回操作、不请求 |
| 4 | 在 **操作** 页签单击行 | 请求 `GET /api/v1/stock-in/{id}/ops-aggregates`，面板展示卡片 |
| 5 | 双击行 | 进入入库详情，与单击选中不冲突 |
| 6 | 搜索 / 重置 | 面板清空为「请先选择行」 |
| 7 | 切到 **看板** | 右栏 **不注册**「操作」（仅「帮助」）；清空选中；不请求 aggregates；无列表行可点 |
| 7b | 切回 **列表** | 右栏恢复 **操作 + 帮助**，默认 **操作** |
| 8 | 采购 511 脱敏账号 | 「操作」页签下单击仍加载面板；供应商/单价/采购员/采购明细单号为 `—` |

## 2. 入库概况与状态

| # | 数据 | 预期 |
|---|------|------|
| 1 | 任意入库单 | 概况含：单号、供应商、型号、品牌、「入库日期」、**同一行**「采购单价」+ 币别与「入库数量」pcs、入库类型；**无仓库** |
| 2 | 单号 | 琥珀 hero，可跳转 `StockInDetail` |
| 3 | 入库日期 | 标题「入库日期」，值为 `YYYY-MM-DD`；无日期为 `—` |
| 4 | 采购单价 / 入库数量 | 同一行双列，标题分别为「采购单价」「入库数量」 |
| 5 | 入库数量 | `{qty} pcs`，不加粗、不用强调色 |
| 6 | 单价 + 币别 | 数字 + 空格 + 三位字母（如 `1.50 USD`）；511 为 `—` |
| 7 | 报关入库且报关单有报关公司 | 类型标签与报关单图标 **同一行右侧** 显示公司中文名；无独立「报关公司：」标签 |
| 8 | 报关入库但公司名为空 | 不显示占位 `—` |
| 9 | 采购/退货/报废 | 类型行不出现报关公司名 |
| 10 | 状态草稿/待入库/已入库/已取消 | 独立状态卡；单标签只占 3 列网格 **第一列**，不拉满 |

## 3. 备注

| # | 条件 | 预期 |
|---|------|------|
| 1 | 有备注 | 卡片展示原文 |
| 2 | 无备注 | 展示 `—`，卡片仍在 |
| 3 | 物流可写 | 卡底通栏「修改备注」，打开与行内同源对话框 |
| 4 | 物流只读 | 无按钮，正文仍可见 |
| 5 | 保存成功 | 列表备注列与面板同步 |

行内「修改备注」仍可用。本版右栏 **无**「标记已入库」。

## 4. 采购订单

**布局（§2.5.2）：** 双列 Key:Value。

| 字段 | 核对口径 |
|------|----------|
| 采购明细单号 | 与采购行 `purchase_order_item_code` 一致；可跳转 PO 详情并定位明细；511 为 `—` 且不链 |
| 采购订单类型 | 客单采购 / 备货采购 / 样品采购（主单 `Type` 1/2/3） |
| 采购日期 | 采购主单创建日 |
| 采购员 | 与主单/通知口径一致；511 为 `—` |
| 采购明细数量 | 采购行 `qty` |
| 采购单价 + 币别 | 采购行 `cost` + `currency`；511 为 `—` |

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 无关联采购 | 「暂无关联采购明细」 |
| 2 | 报关入库 | 采购四项+类型+单价按 **原始采购** 溯源有值（非一律空白） |

## 5. 到货通知

| # | 场景 | 预期 |
|---|------|------|
| 1 | 无到货通知 | 「暂无关联到货通知」 |
| 2 | 有通知 | 单号可跳转 `ArrivalNoticeList?noticeId=`；到货类型标签 |
| 3 | 实到日期 | 仅 `actualArrivalDate`；没有则为 `—`，**不**改成预计到货日 |
| 4 | 到货数量 | **实收** `receiveQty`，不是预计 `expectQty` |
| 5 | 质检通过 | 有质检为 `passQty`；无质检为 `—` |

## 7. 本功能不适用

- **本功能不适用：金额 / 核销 / 匹配足额与超额。**
- **本功能不适用：数据分析看板公式**（入库列表「看板」模式另有看板对照，本面板不测 KPI）。
- **本功能不适用：多租户打印皮肤。**
- **本功能不适用：审批/核销工作台左栏队列。**
- **本功能不适用：数据库迁移**（报关公司名与操作聚合均为展示字段）。
- **本功能不适用：右栏「标记已入库」**（本版仅备注；过账仍走行内按钮）。
