## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有装箱详情权限 | 可进 `/inventory/packing/:id`；右栏有「流程」「帮助」 |
| 能访问关联销售订单 | 上游销售站可加载；否则流程区错误提示，不白屏 |

准备：一箱多明细（不同销售行）、一箱单明细已出库链路各一张。

---

## 二、黄金路径

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 打开装箱详情 | 默认选中第一条装箱明细；右栏有「流程」「帮助」 |
| 2 | 切到「流程」 | 时间轴仅 5 站：销售订单明细 → 出库通知 → 装箱 → 拣货 → 出库；「装箱」含当前箱号；「装箱」站标题旁橙色左指手势（当前业务指示） |
| 2a | 看销售订单明细 / 出库通知 / 装箱小卡 | **无「客户编号」**；「客户名称」独占一行（不与其它字段并排）；脱敏时客户名为 `—` |
| 2b | 看出库通知小卡 | 数量右侧有「地域」；值为大陆/海外系统胶囊标签（与库存列表地域列同款）；缺省显示 `—` |
| 3 | 上游 | 销售明细单线；出库通知优先本箱明细关联 |
| 4 | 拣货 / 出库 | 有拣货任务则显示拣货单号；出库按**本装箱行**对齐出库明细（单号 + 出库明细单号 + 本行数量），不是整箱单头 |
| 5 | 切换另一条装箱明细 | 流程刷新为对应销售行 / 通知 / 拣货行 |
| 6 | 点击单号 | 跳转对应详情（脱敏时不可点） |

---

## 三、边界

| 场景 | 预期 |
|------|------|
| 明细无 `sellOrderItemId` | 提示销售明细站为空；出库通知/装箱/拣货仍可按本箱展示 |
| 无销售订单访问权限 | 流程区错误提示，不白屏 |
| 离开详情再进入 | 流程 store 清空后按新选中行重载 |
| 出库通知送达地域 10 | 「地域」为黄色胶囊「大陆」 |
| 出库通知送达地域 20 | 「地域」为蓝色胶囊「海外」 |

---

## 四、金额 / 页签 / 桌面 / 打印

**本功能不适用：核销/匹配金额足额与超额；看板公式；列表页签模式；核销桌面；打印皮肤。**

---

## 五、回归

- 改动装箱详情右栏或销售明细 aggregates 时跑本节二 + 三  
- 销售/出库通知/装箱小卡无「客户编号」，客户名称独占一行  
- 出库通知小卡数量右侧为「地域」胶囊（大陆黄 / 海外蓝）  
- 对照销售明细列表「流程」页签视觉与字段一致性（销售明细出库站仍为销售行口径，与装箱出库站不同，见已知差异）
- 出库站与装箱明细列表单击同一行一致
