## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有入库单列表权限 | 可进入 `/inventory/stock-in`；搜索栏「查询 / 重置」后有 **看板** 按钮 |
| 无对应菜单权限 | 不可进入，与现网一致 |
| 默认 | 列表；标题旁「共 N 条」可见 |
| 点「看板」 | 按钮文案变为「列表」；表格与分页隐藏；「共 N 条」隐藏；出现看板（Tag「筛选」+ KPI + 趋势 + 饼图 + Top10） |
| 再点「列表」 | 回到表格；标题旁条数恢复 |
| 看板态右侧帮助 | 为入库单看板说明（非入库单列表帮助） |
| 列表态右侧帮助 | 恢复入库列表帮助 |

**本功能不适用：** 工作台左栏队列（总纲 §4.3）、多租户打印皮肤（§4.6）、看板写入/提交、筛选页签模式齿轮（入库单列表无页签模式，§4.4）。

## 二、筛选联动

| 步骤 | 预期 |
|------|------|
| 列表筛入库类型=采购入库，再切看板 | 看板只统计类型 10 与历史 1；Network `stock-in/analytics/*` 带 `stockInType=10` |
| 看板下改入库日区间后点查询 | 看板自动刷新；四个 analytics 请求带同一 `stockInDateStart/End` |
| 不选类型（默认全部） | 看板含草稿、待入库、已取消等当前能列出的单（**不**强制已过账采购）；仍排除移库 3 |
| 点「重置」 | 筛选清空；看板按空条件重算 |
| 511 用户 | 供应商名称筛不出现；analytics 请求无 `vendorName` |

列表与看板必须共用同一 WHERE（含数据权限）。抽 1 个筛选组合：列表「共 N 条」= 看板「入库单数」。

## 三、口径 / 公式核对

计数：入库**单头**数（不是明细行数）。  
原币行金额：`入库数量 × 入库采购单价`（明细 `Quantity × Price`），按这些单下明细加总。  
**不要**用头表 `TotalAmount`（仍为 0 时回落 PO Cost）核对看板。  
折算美金（逐行后再按单加总）：

```text
若该行已有在库明细：入库数量 × PurchasePriceUsd（有在库行即用快照，含 0）
否则若采购订单行 convert_price>0：入库数量 × convert_price
否则：入库数量 × 采购单价 按查询日财务汇率折 USD
```

| 核对 | 预期 |
|------|------|
| **足额（筛选结果逐单加总 = 看板）** | 抽当前筛选（建议含已入库 + 明确入库日）：看板入库单数 = 列表总条数；有金额权限时，看板折算美金 ≈ 各单明细按上式加总（允许四舍五入到分的尾差） |
| 原币分档 | 各币别原币合计 = 该币别行 `数量 × 单价` 之和；禁止把不同原币直接相加当主数字 |
| 入库供应商数 | = 列表结果里头表有供应商 ID 的去重数；无供应商单不计入 |
| 趋势（按月） | 只含有入库日的单；无入库日单进 KPI 但不进趋势桶 |
| 入库类型饼 | 类型 1 与 10 合并为「采购入库」；扇区为金额（或脱敏下单数）+ 百分比 |
| Top10 供应商 | 按折算美金降序；无供应商单可出现「未关联供应商」 |
| Top10 采购员 | 按单头主采购员（明细挂 PO 的首个非空采购员）整单金额归该人；挂不上归「未分配采购员」 |
| **超额拒绝** | **本功能不适用：** 看板只读，无核销/匹配/金额提交 |

饼图须同时显示 **数值 + 百分比**（总要求 §3.7）。金额主数字为折算美金（§3.8）。

## 四、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 数据权限收窄用户 | 看板入库单数 ≤ 该用户列表可见全量，不得大于 |
| 511 采购向 / 无 `purchase.amount.read` | 入库金额显示「—」；饼图/排行按单数；看板仍能加载 |
| 有金额权限且非 511 | 金额与原币分档可见 |

## 六、回归 / 已知差异

| 项 | 说明 |
| --- | --- |
| 出库明细看板 | 在 `/inventory/stock-out/items`，计数是条目数、金额是出库金额；不要在入库单列表找「出库条目数」 |
| 物流分析「已入库」 | 常强制已过账采购；无快照时美金可能记 0。同筛「已入库+采购+同一入库日」时，本页美金 **≥** 物流卡（本页会回落 convert_price） |
| 采购分析「已入库」 | 仍按订单成单口径（本需求未改） |
| 列表金额列 | 列表头表金额在未过账时可能为 0 或回落 PO；看板按行 `Quantity × Price`，二者可不一致 |

**上线前：** 部署含本看板的版本后 **重启 CRM.API**；已登录用户刷新前端即可。无需新权限脚本、无 DDL。
