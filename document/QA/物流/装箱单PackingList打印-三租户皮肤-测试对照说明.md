## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有装箱单列表权限，列表行「打印 Packing」 | 打开 `packing-report`；工具栏默认不含出货检验，可切换含检/不含检并记忆 |
| 无装箱单列表权限 | 进不了列表，或直接打开打印路由回控制台 |
| 物流员**无**报表参数管理权限 | 仍能打开打印；Network 可见 `effective-style-version` 返回 200（非 403）；版式按生效版本 |
| 销售敏感字段脱敏 | 客户名为 `—`；V1 Bill/Ship 名称与 V2 收货人名称均为 `—`；版式仍加载 |
| 本页无提交按钮 | 无核销/匹配/保存 |

## 二、V1 / V2 切换

全局参数在「参数管理 → 报表参数」维护。打印页加载时读一次；改参数后须**重新打开/刷新报表页**才变。

| 步骤 | 预期 |
|------|------|
| 从未配置或非法值 | 打印为 **V1**（现网三租户皮肤 / 14 列横版） |
| 参数为 V1，打开打印 | 现网版式：Bill To / Ship To 双客户；竖版 6 列或横版 14 列 |
| 改为 V2 并保存，在 **semicore** 构建包刷新打印页 | 藏青顶栏，「装箱单」白字 **16pt**，「PACKING LIST」青色 **6.5pt**，「装箱单号码 / Packing List No.」白字 **7pt**（竖/横相同）；左发货人（我方）/ 右收货人（客户）；无中/英切换。默认方向仍为记忆值（首次多为横版） |
| 同上，点工具栏「横版」 | **V2 横版**：包装明细 14 列英文表头与图1一致（S/No. … Remark）；表头藏青+浅白竖线；不是 V1 深紫/橙表 |
| 改为 V2 并保存，在 **idesemi / ecoinf** 构建包刷新打印页 | **与该租户 V1 相同**（不换 PDF 版式）；中/英切换仍在 |
| 再改回 V1，刷新打印页 | 回到现网版式 |
| 改参数后不刷新已打开的打印页 | 仍显示打开时的版本 |
| 销售订单 / 发票打印 | **本功能不适用其消费该参数**：版式不变 |

## 三、范围与皮肤

在 **semicore / idesemi / ecoinf** 构建包打开同一装箱单打印。V1 三租户都要看；V2 只验收 **semicore 竖/横换版、另外两租户不变**。

| 检查项 | 期望 |
|--------|------|
| 租户差异（V1） | 三套观感明显不同（不只换 Logo） |
| 与采购订单对齐 | 同租户 V1 主色一致。semicore 在 V2 竖版时为 PDF 藏青/青，不再要求与 V1 Packing 深紫顶栏同构 |
| semicore | V1：深紫顶栏 + 琥珀。V2 竖版：藏青顶栏 + 青色「PACKING LIST」 |
| idesemi | V1：大标题字距 + 青竖条。参数 V2 时**仍为此版式** |
| ecoinf | V1：橙色表头/分区条。参数 V2 时**仍为此版式** |
| 签章 | V1 随皮肤；V2 印章在发货人（左） |
| 打印 / PDF | 壳层隐藏；色块保留；截取 `.po-doc` |

任一套 V1 皮肤若与另两套「只差 Logo」→ 不通过。

## 四、方向、语言、检验

| 步骤 | 预期 |
|------|------|
| 参数 V1，首次进入（无记忆） | **横版**；刷新后若点过竖/横则保持 |
| 参数 V2 + semicore | 竖版 = V2 9 列中英；横版 = V2 14 列英文（图1）；方向记忆刷新后保持 |
| 参数 V2 + semicore，看顶栏左侧 | 「YOUR RELIABLE SUPPLIER」与 Logo（无 Logo 时为公司名）水平居中对齐，整组仍靠左；竖/横相同 |
| V1：中文 / 英文切换 | 标签语言切换，明细数据不变 |
| V2 竖版 | **无**中/英切换；栏名中英对照；公司档案装箱备注中英都有则都印 |
| 印章开/关 | 发货方区印章显示/隐藏（V1/V2 均适用） |
| 含出货检验 | V1 与 V2 均有出库检验五项；V2 在明细之后、运输/汇总之前 |
| `without-inspection` | **无**检验区（V1/V2 均适用） |
| 明细空 | 显示「无明细 / No items」类提示，无补齐空行 |

## 五、V2 字段不丢

仅在 **semicore** 用同一张装箱单，先看 V1 再切参数 V2（竖/横都对）。idesemi / ecoinf 不做本节。

| V1 已出现 | V2 期望 |
|-----------|---------|
| Logo、我方公司名 | 顶栏 Logo；发货人公司名 |
| 装箱单号、出库日期 | 顶栏 Packing List No. + 元数据单据日期 |
| 出货方式 | 运输方式 |
| Bill To / Ship To（双客户） | **不要**再出双客户；左我方、右客户 Ship To |
| 竖版 No / PN / Brand / Qty / Carton / Remark | 箱号（第一列）/ MPN / 厂牌 / 批号(DC) / 描述(备注+客户型号) / 数量 / N.W. / G.W. / 尺寸；**表头最多 2 行**（中英各一行，不按字竖折） |
| V1 横版 14 列 | V2 横版同序英文表头：S/No.、CUSTOMER PO、PART NUMBER、CUSTOMER PN、Brand、QTY (PCS)、DC、CO、COD、SIZE、NW (KG)、GW (KG)、CARTON、Remark |
| 空箱号 | 显示 **01、02…**（按行序），不另开序号列、不显示 — |
| 有箱号 | 原样显示（如 `A-1`） |
| Outbound Inspection 五项 | 仍显示（含检路由）；中英配对 |
| 公司档案装箱备注 | 运输资料备注；空则默认双语包装句 |
| 快递公司 + 快递单号 | 承运人/快递单号（有则填） |
| 贸易术语 / 起运地 / 目的地 / 体积 | **—**（无字段，不编造） |
| 合计数量 | 包装汇总总数量 = Σ 行数量 |
| 总箱数 | = 明细行数（含补序箱号的行） |
| 发货人签章日期 | V1 可印出库日期；**V2 竖/横**发货人、收货人「日期 / Date」均为下划线，不印 `2026-08-19` 这类日期 |

抬头切换、含印章开关：V1/V2 行为与改版前一致。

## 六、口径 / 公式核对

本页**只展示**已落库装箱/出库数据，不提交核销或匹配。

```text
总数量 = Σ 行 qty
总箱数 = 明细行数
总净重 = 若任一行 nw 有值则 Σ nw，否则 —
总毛重 = 若任一行 gw 有值则 Σ gw，否则 —
```

| 用例 | 预期 |
|------|------|
| **足额（展示数量 = 行数量合计）** | 汇总总数量与各行数量手工加总一致（如 10 + 20 = 30） |
| 超额 / 核销提交 | **本功能不适用：无核销、匹配、付款提交** |
