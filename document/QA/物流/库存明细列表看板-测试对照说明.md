## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有库存明细列表权限 | 可进入 `/inventory/stock-items`；搜索栏「查询 / 重置」后有 **看板** 按钮，再右侧是筛选设置齿轮 |
| 无对应菜单权限 | 不可进入，与现网一致 |
| 默认 | 列表；标题旁「共 N 条」与标题下三张数量卡可见 |
| 点「看板」 | 按钮文案变为「列表」；标题条数、三张数量卡、表格、分页隐藏；筛选与页签仍可见；出现看板 |
| 再点「列表」 | 回到表格与数量卡；标题旁条数恢复 |
| 看板态右侧帮助 | 为库存明细看板说明 |
| 列表态右侧帮助 | 恢复库存明细列表帮助 |

**本功能不适用：** 工作台左栏队列（总纲 §4.3）、多租户打印皮肤（§4.6）、看板写入/提交。

## 二、筛选联动

| 步骤 | 预期 |
|------|------|
| 列表筛「有库存」后切看板 | 看板在库数量 = 列表「在库数量」卡 |
| 看板下改入库日期、点查询 | 看板自动刷新；四个 `stock-items/analytics/*` 请求带同一套筛选 |
| 页签模式「库存类型=客单」+ 看板 | 与列表筛选一致 |
| 点「重置」 | 筛选清空；看板按空条件重算；页签模式维度不关 |

列表与看板必须共用同一 WHERE（含数据权限）。抽 1 个筛选组合：列表 `qtyRepertoryTotal` = 看板「在库数量」。

## 三、口径 / 公式核对

```text
在库数量 = Σ qty_repertory（筛选全量，与列表卡一致）
原币金额 = Σ(qty_repertory × purchase_price) 按币别，不折算混加
周转天数 = ROUND(在库数量 / 近30天出库数量 × 30, 1)
  近30天出库：出库单 status∈{2,4}，数量 ActualQty>0 则用 ActualQty 否则 Quantity
呆滞料数量 = Σ qty_repertory（入库日≤今天−90 或无有效入库日）
趋势点 = 周期期末时点存量 max(0, qty_inbound − Σ出库(出库日≤asOf))
库龄桶 = 0–30 / 31–90 / 91–180 / 181–365 / 365+（无入库日不进饼）
```

| 核对 | 预期 |
|------|------|
| **足额（筛选结果合计 = 看板）** | 看板在库数量 = 列表标题下「在库数量」卡；有金额权限时，各原币 KPI = 该币别行 `qty_repertory × purchase_price` 之和（允许四舍五入到分的尾差） |
| 周转分母为 0 | 近 30 天无出库或在库为 0 时周转显示「—」，看板仍能加载 |
| 呆滞数量 | 与列表再加 `stagnantOnly=true` 后的在库数量卡一致 |
| 趋势 groupBy | 按天约 30 点、按周 12 点、按月 12 点；末点在库数量与 KPI 一致（无入库日裁剪时） |
| 库龄饼 | 分桶文案与物流分析一致；无入库日层不出现 |
| 排行下钻 | 点击 Top 行 → 切回列表；条数/数量（或当前原币金额）与该行一致 |
| 呆滞 KPI | 点击后切回列表并带呆滞筛选 |
| **超额拒绝** | **本功能不适用：** 看板只读，无核销/匹配/金额提交 |

饼图须同时显示 **数值 + 百分比**（总要求 §3.7）。金额按原币分列，禁止把不同原币直接相加当主数字（§3.8）。

## 四、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 数据权限收窄用户 | 看板在库数量 ≤ 该用户列表可见全量，不得大于 |
| 511 / 无采购金额权 | 金额「—」；周转天数与呆滞数量仍显示；饼图/排行默认数量 |
| 521 | 排行客户/业务员名为「—」；看板仍能加载；下钻仍按 Id |
