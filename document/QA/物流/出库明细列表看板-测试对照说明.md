## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有出库明细列表权限 | 可进入 `/inventory/stock-out/items`；搜索栏「查询 / 重置」后有 **看板** 按钮，再右侧是筛选设置齿轮 |
| 无对应菜单权限 | 不可进入，与现网一致 |
| 默认 | 列表；标题旁「共 N 条」可见 |
| 点「看板」 | 按钮文案变为「列表」；表格与分页隐藏；「共 N 条」隐藏；出现看板（Tag「筛选」+ KPI + 趋势 + 饼图 + Top10） |
| 再点「列表」 | 回到表格；标题旁条数恢复 |
| 看板态右侧帮助 | 为出库明细看板说明（非出库单列表帮助） |
| 列表态右侧帮助 | 恢复出库单 / 出库明细列表帮助 |

**本功能不适用：** 工作台左栏队列（总纲 §4.3）、多租户打印皮肤（§4.6）、看板写入/提交。

## 二、筛选联动

| 步骤 | 预期 |
|------|------|
| 列表筛状态=出库完成，再切看板 | 看板只统计状态 4；Network `items/analytics/*` 带 `status=4` |
| 看板下改出库日区间 | 看板自动刷新；四个 analytics 请求带同一 `stockOutDateFrom/To` |
| 页签模式「销售出库」+ 看板 | 含类型 10 与历史 1；与列表筛选一致 |
| 不选状态/类型（默认全部） | 看板含草稿、拣货中、已取消等当前能列出的行（**不**强制已完成销售） |
| 点「重置」 | 筛选清空；看板按空条件重算；页签模式维度不关 |

列表与看板必须共用同一 WHERE（含数据权限）。抽 1 个筛选组合：列表导出或翻页合计条目数 = 看板「出库条目数」。

## 三、口径 / 公式核对

出库数量：`ActualQty > 0 ? ActualQty : Quantity`  
原币行金额：`出库数量 × 销售单价`（扩展 SalesPrice>0，否则订单行 Price）  
折算美金（逐行）：

```text
若 SalesPriceUsd 有值：出库数量 × SalesPriceUsd
否则若订单行 Price>0 且 convert_price>0：出库数量 × convert_price
否则：出库数量 × 销售单价 按查询日财务汇率折 USD
```

| 核对 | 预期 |
|------|------|
| **足额（筛选结果逐行加总 = 看板）** | 抽当前筛选（建议已完成 + 销售 + 明确出库日）：看板出库条目数 = 列表总条数；有金额权限时，看板折算美金 ≈ 逐行按上式加总（允许四舍五入到分的尾差） |
| 原币分档 | 各币别原币合计 = 该币别行 `数量 × 单价` 之和；禁止把不同原币直接相加当主数字 |
| 出库客户数 | = 列表结果里头表有客户 ID 的去重数；无客户行不计入 |
| 趋势（按月） | 只含有出库日的行；无出库日行进 KPI 但不进趋势桶 |
| 出库类型饼 | 类型 1 与 10 合并为「销售出库」；扇区为金额（或脱敏下行数）+ 百分比 |
| Top10 客户 | 按折算美金降序；无客户行可出现「未关联客户」 |
| **超额拒绝** | **本功能不适用：** 看板只读，无核销/匹配/金额提交 |

饼图须同时显示 **数值 + 百分比**（总要求 §3.7）。金额主数字为折算美金（§3.8）。

## 四、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 数据权限收窄用户 | 看板条目数 ≤ 该用户列表可见全量，不得大于 |
| 521 采购向 / 无 `sales.amount.read` | 出库金额显示「—」；饼图/排行按行数；看板仍能加载 |
| 有金额权限且非 521 | 金额与原币分档可见 |

---

## 五、页签 / 帮助交叉

| 步骤 | 预期 |
|------|------|
| 页签模式开启后切看板 | 页签条仍在；点页签即改筛选并刷新看板 |
| 看板下点筛选齿轮关页签 | 页签消失；下拉恢复；看板跟当前值 |
| 右侧在「帮助」时切看板 | 帮助切到看板文案，不被迫切到操作页签 |

**本功能不适用：** 操作面板单击门控细节（出库明细本无操作页签）；左栏检索 preset。

## 六、回归 / 已知差异

| 项 | 说明 |
| --- | --- |
| 出库单头列表 | **无**本看板；不要在 `/inventory/stock-out` 头表找「看板」 |
| 物流分析「已出库」 | 强制状态 4 + 销售 10\|1；无 `SalesPriceUsd` 计 0。同筛「已完成+销售+同一出库日」时，本页美金 **≥** 物流卡（本页会回落 convert_price） |
| 销售分析「已出库」 | 仍按订单明细 × convert_price、订单创建日（本需求未改） |
| 筛选页签 | 与看板独立；偏好仍存 `crm.stock-out-item-list.tab-mode` |

**上线前：** 部署含本看板的版本后 **重启 CRM.API**；已登录用户刷新前端即可。无需新权限脚本、无 DDL。
