# 库存中心（在库汇总）— 测试对照说明

> **页面 / 路由：** 库存管理 → 库存中心 `/inventory/list`  
> **设计文档：** [库存中心-在库汇总-设计与实现](../../System/物流/库存中心-在库汇总-设计与实现.md)  
> **关联旧页：** 库存桶 `/inventory/bucket`（原库存中心分桶列表）

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 菜单「库存管理 → 库存中心」 | 进入 `/inventory/list`，标题为「库存中心」；右上角有「库存桶」按钮（浅底、右侧箭头，同进项发票「核销桌面」） |
| 点右上角「库存桶」 | 进入 `/inventory/bucket`，仍为分桶列表（可含在库数量 = 0） |
| 主菜单 | **无**「库存桶」菜单项 |
| 无登录 | 不可进入 |

**本功能不适用：** 独立 write 权限码（与原库存中心列表相同，随登录可见）。

---

## 二、数据范围与口径

| 步骤 | 预期 |
|------|------|
| 默认列表 | 仅在库数量 **&gt; 0** 的库存明细汇总；已出清层不出现 |
| 同一型号品牌、两条销售明细都有在库 | **合成一行**（未勾选拆分时） |
| 未过账入库 | 不进入本页 |
| 手工移库源行 | 不进入本页 |
| 采购敏感角色 | 金额列与金额卡片显示「—」；在库数量卡片仍显示数字；列表仍能加载 |

数据权限与库存明细列表相同（销售范围 ∨ 采购范围）。

---

## 三、拆分维度与搜索

| 步骤 | 预期 |
|------|------|
| 首次进入（无本地记忆） | 库存类型、仓库拆分均不勾；搜索栏只有型号、品牌 |
| 勾选「库存类型」 | 搜索栏出现类型下拉；列表多「库存类型」列；同一料牌按客单/备货/样品分行 |
| 勾选「仓库」 | 搜索栏出现仓库下拉；列表多「仓库」列 |
| 两项都勾 | 料牌 + 类型 + 仓 分行 |
| 取消「仓库」勾选 | 仓库下拉消失，仓库筛选值丢弃，不再按仓过滤 |
| 点「重置」 | 型号/品牌/当时出现的下拉清空；**拆分勾选保持** |
| 勾选拆分后 F5 | 勾选状态保持 |

---

## 四、金额列（原币分列）

公式：

```text
在库金额{币别} = Σ(组内采购原币=该币别 的 在库数量 × 采购单价)
在库数量 = Σ(组内在库数量)   // PCS，与币别无关
```

| 步骤 | 预期 |
|------|------|
| 筛选结果全是人民币 | 仅「库存金额RMB」列 |
| 同时有 RMB 与 USD 层 | 两列都出现；同一汇总行可两列都有数 |
| 某行没有 USD、结果集别处有 USD | 该行「库存金额USD」为 0.00 |
| 列顺序 | RMB → USD → EUR → HKD，再 JPY / GBP |

**本功能不适用：核销/匹配类足额成功与超额拒绝**（只读汇总，无提交金额）。

---

## 五、标题下统计卡片

口径与列表相同，按 **当前筛选全量** 合计（翻页不改变卡片数字）。

```text
在库数量 = Σ(筛选范围内 stock_item 在库数量)
库存金额{币别} = Σ(采购原币=该币别 的 在库数量 × 采购单价)
```

| 步骤 | 预期 |
|------|------|
| 标题下方 | 先「在库数量」，再按币别出「库存金额{币别}」卡片 |
| 仅人民币库存 | 数量卡 + 「库存金额RMB」；无 USD 卡 |
| 同时有 RMB 与 USD | 数量卡 + 两张金额卡；顺序与列表列一致 |
| 翻到第 2 页 | 卡片数字不变 |
| 改筛选后搜索 | 卡片随筛选变化 |
| 采购敏感角色 | 金额卡片为「—」；在库数量仍可见 |

## 六、回归 / 交叉

| 步骤 | 预期 |
|------|------|
| 本页 | **无**导出按钮、**无**点行进汇总明细；统计卡片为在库数量 + 原币金额（**无**折算 RMB / 周转天数） |
| 库存桶 | 财务卡片（含折算占用）、页签模式、导出、点行下钻仍在 |
| 库存明细 | 口径不变；可用「有库存」对照本页数量 |
| 微信端库存入口 | **本版不改** |

**本功能不适用：** 审批/核销桌面、多租户打印皮肤。
