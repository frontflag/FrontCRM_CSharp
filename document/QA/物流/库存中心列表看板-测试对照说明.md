## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 进入 `/inventory/list` | 搜索栏有「看板」按钮 |
| 点「看板」 | 按钮变「列表」；表格/分页/标题条数/标题下 KPI 卡隐藏；出现看板 |
| 再点「列表」 | 恢复列表与标题 KPI |
| 看板态帮助 | 为库存中心看板说明 |

**本功能不适用：** 工作台左栏（总纲 §4.3）、多租户打印（§4.6）、金额提交/核销（§4.5 超额拒绝）。

## 二、筛选联动

| 步骤 | 预期 |
|------|------|
| 筛型号后点搜索，再看板 | 看板 KPI 与列表 `onHandQtyTotal` 一致 |
| 仅勾选拆分、不选类型/仓库 | 看板集合 **不变**（与未勾选时相同） |

## 三、口径 / 公式核对

```text
在库数量 = Σ qty_repertory（筛选全量）
原币金额 = Σ(qty_repertory × purchase_price) 按币别
折算USD = Σ(qty_repertory × 折算美金单价)
  折算美金单价 = PO 行 convert_price > 0 ? convert_price : 入库快照 PurchasePriceUsd
库存条目 = COUNT(在库 stock_item 层)（每条计 1）
加权平均库龄 = ROUND( Σ(库龄天×在库数量) / Σ(在库数量), 1 )（无入库日不参与）
呆滞层数 = 入库日≤今天−90 或无入库日的在库层数
趋势点 = 各自然月月末时点存量（最近12个月）；金额趋势固定 RMB / USD
```

| 核对 | 预期 |
|------|------|
| KPI 与列表卡 | 看板在库数量、各原币金额 = 列表标题下统计卡；KPI **不含** 折算USD |
| 库龄饼 | 分桶 0–30 / 31–90 / 91–180 / 181–365 / 365+ |
| 呆滞与库龄 | 呆滞按层计数；库龄饼无入库日层不出现 |
| 趋势 | 在库数量 + RMB/USD 金额各 **12** 个点；末点与 KPI 一致；趋势仍为原币，无折算USD 图 |
| 分布/排行三档 | 「数量 / 金额 / 库存条目」可切换；数量为 PCS，库存条目为层数，二者一般不等 |
| 金额下拉 | 顺序为 RMB、USD、折算USD（其后才是其它原币）；「USD」≠「折算USD」 |
| 折算USD 复算 | 抽人民币+美元混合库存：折算USD 合计 = 各层 `qty × 折算美金单价` 之和（允许分位尾差）；**大于** 仅美元原币档 |
| 排行下钻 | 原币档：明细列表条数/数量或该原币金额与该行一致；折算USD 档：列表含各原币层，**不** 只剩美元 |
| 511 | 金额「—」且金额档（含折算USD）隐藏；**加权平均库龄仍显示**；数量与库存条目仍可切 |

**测试注意：** 「库存条目」与 KPI「在库数量」不是同一口径；一条库存明细可能数量很大，条目仍计 1。库龄分布在「库存条目」档也不含无入库日层（与数量档相同）。折算USD 用入库当时折算价，**不要**用当天财务汇率重算。

**已知口径差异：** 呆滞 KPI 含无入库日层；库龄饼（含库存条目档）不含无入库日层。物流分析「在库金额」是折算美元主数字；本页 KPI 仍按原币分列。

**本功能不适用：** 足额成功 + 超额拒绝（§4.5，只读看板）；左栏检索/操作面板门控（§4.4）；多租户打印（§4.6）。

## 四、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 数据权限收窄 | 看板在库数量 ≤ 该用户列表可见全量 |
| 511 / 无 `purchase.amount.read` | 金额脱敏；库龄与呆滞层数仍显示 |
