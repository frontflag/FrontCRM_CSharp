## 1.1 出库单列表 CSV 列与口径

| # | 步骤 | 期望 |
|---|------|------|
| 2a | 导出含状态=4、出库类型=20、出货方式=3 的行 | **状态=出库完成**，**出库类型=报关出库**，**出货方式=快递**（不得仍为 `4`/`20`/`3`） |
| 2b | 对照客户主档 | 含列「客户中文名称」「客户英文名称」，**无**原「客户」列；中文=官方中文名（空则客户名），英文=英文全称 |
| 2c | 对照销售订单行 / 出库明细扩展销售价 | 含列「销售单价」「销售单价币别」「金额币别」；单价为明细销售价（>0）否则订单行单价，多行去重逗号拼接；币别为 ISO 文案（如 USD） |
| 2d | 数量与销售单价均有值、头表金额为 0 | **金额 = 数量 × 销售单价**（多行则按行求和）；**金额币别 = 销售单价币别** |

```text
销售单价：出库明细扩展 SalesPrice > 0 → 用该价；否则销售订单行 Price（含明细扩展上的销售行，不限于出库单头）
销售单价币别：扩展 SalesCurrency > 0 → 否则销售订单行 Currency
金额：头表金额 ≠ 0 用头表；否则 Σ(出库数量 × 销售单价)
金额币别：与销售单价币别相同
```

本导出**不提交**核销/匹配金额，故总纲 §4.5「足额成功 / 超额拒绝」**本功能不适用**（无写入待核销余额的操作）。

## 1.2 库存明细列表 CSV 列与口径

| # | 步骤 | 期望 |
|---|------|------|
| 4a | 对照供应商主档 | 含列「供应商中文名称」「供应商英文名称」，**无**原「供应商」列；中文=官方中文名（空则简称，再回退在库层供应商快照），英文=英文全称 |
| 4b | 对照采购订单 | 含列「采购单号」，与该在库层关联的采购订单号一致（无关联则空） |
| 4c | 在库数量=100、在库单价=1.5 | **在库金额=150**；币别为 ISO 文案（如 USD），**在库金额币别 = 在库单价币别** |
| 4d | 在库数量=0 | **在库金额=0**（按当前在库数量×单价，不是入库量×单价） |

```text
在库单价 = 在库层采购单价快照
在库金额 = 当前在库数量 × 在库单价
在库金额币别 = 在库单价币别
```

## 4. 回归注意

| # | 说明 |
|---|------|
| A | **历史**导出日志中的 GUID 摘要不会自动改写；仅**新导出**生成业务名称摘要 |
| B | 失败导出（接口报错）不应写入成功导出日志 |
| C | 出库单列表页本身仍显示状态/类型码的筛选值；仅 **CSV 单元格** 为业务名称 |

## 5. 本功能不适用（总纲裁剪）

| 维度 | 说明 |
|------|------|
| 工作台 / 桌面（§4.3） | 本功能不适用：导出不是左栏队列桌面 |
| 页签模式 / 操作面板（§4.4） | 本功能不适用：页签见 [出库单列表-筛选页签模式-测试对照说明](./出库单列表-筛选页签模式-测试对照说明.md)；导出只跟当前筛选 |
| 金额核销足额/超额（§4.5） | 本功能不适用：导出不提交核销或匹配 |
| 多租户皮肤 / 打印（§4.6） | 本功能不适用：CSV 无租户皮肤 |
