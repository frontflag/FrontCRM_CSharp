# 到货通知列表 — 筛选页签模式 — 测试对照说明

> **页面：** `/arrival-notices`  
> **设计文档：** [到货通知列表-筛选页签模式-设计与实现](../../System/物流/到货通知列表-筛选页签模式-设计与实现.md)

---

## 一、入口

| 步骤 | 预期 |
|------|------|
| 进入页面（未开过页签） | 无页签条；搜索栏显示状态 / 到货类型下拉 |
| 点搜索栏齿轮（非底栏列设置） | 「关闭页签」禁用；「页签模式 ▸」含两项：全部状态、到货类型 |

---

## 二、开启与切换

| 步骤 | 预期 |
|------|------|
| 页签模式 → 状态 | 状态下拉隐藏；页签 6 格：全部 / 新建 / 未到货 / 到货待检 / 已质检 / 已入库 |
| 点「未到货」 | 立即查询；列表仅 status=10 |
| 再开「到货类型」 | 状态下拉恢复（值可保留）；类型下拉隐藏；页签变为全部 + 四类 |
| 关闭页签 | 页签消失；对应下拉恢复且值保留 |

---

## 三、与「搜索」按钮

| 步骤 | 预期 |
|------|------|
| 改采购单号 / 货代单号 / 预计到货日期不点搜索 | 不请求 |
| 点页签 | **立即**请求 |

---

## 四、持久化与主题

| 步骤 | 预期 |
|------|------|
| 开启某维度后 F5 | 仍为该维度页签 |
| 亮色未选中页签 | 约 `#E8EDF5` |
| 暗色未选中页签 | 深色层，不发白 |
