# 出库单列表 — 筛选页签模式 — 测试对照说明

> **页面：** `/stock-outs`  
> **设计文档：** [出库单列表-筛选页签模式-设计与实现](../../System/物流/出库单列表-筛选页签模式-设计与实现.md)

---

## 一、入口

| 步骤 | 预期 |
|------|------|
| 进入页面（未开过页签） | 无页签条；搜索栏显示状态 / 出库类型下拉 |
| 点搜索栏齿轮（非底栏列设置） | 「关闭页签」禁用；「页签模式 ▸」含两项：状态、出库类型 |

---

## 二、开启与切换

| 步骤 | 预期 |
|------|------|
| 页签模式 → 状态 | 状态下拉隐藏；页签 6 格：全部 / 草稿 / 待出库 / 准备出库 / **已取消** / 出库完成 |
| 点「待出库」 | 立即查询；列表仅该状态；URL query 带 `status` |
| 点「草稿」 | 能筛到 status=0（勿与「全部」混淆） |
| 再开「出库类型」 | 状态下拉恢复（值可保留）；类型下拉隐藏；页签变为全部 + 四类 |
| 关闭页签 | 页签消失；对应下拉恢复且值保留 |

---

## 三、与「搜索」按钮

| 步骤 | 预期 |
|------|------|
| 改文本/日期不点搜索 | 不请求（与现网一致；本版不改下拉即查） |
| 点页签 | **立即**请求 |

---

## 四、持久化与主题

| 步骤 | 预期 |
|------|------|
| 开启某维度后 F5 | 仍为该维度页签 |
| 亮色未选中页签 | 约 `#E8EDF5` |
| 暗色未选中页签 | 深色层，不发白 |

---

*出货方式、日期控件与下拉变更即查不在本版范围。点页签会清空右侧操作面板选中，见 [出库单列表-操作面板-测试对照说明](./出库单列表-操作面板-测试对照说明.md)。*
