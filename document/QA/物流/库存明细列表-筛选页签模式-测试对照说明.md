# 库存明细列表 — 筛选页签模式 — 测试对照说明

> **页面：** `/inventory/stock-items`  
> **设计文档：** [库存明细列表-筛选页签模式-设计与实现](../../System/物流/库存明细列表-筛选页签模式-设计与实现.md)

---

## 一、入口

| 步骤 | 预期 |
|------|------|
| 进入页面（未开过页签） | 无页签条；搜索栏含出库状态 / 是否有库存 / 仓库 / 业务员 / 采购员等 |
| 点搜索栏齿轮 | 「页签模式 ▸」仅三项：出库状态、是否有库存、仓库；**无**业务员、采购员 |

---

## 二、各维度

| 步骤 | 预期 |
|------|------|
| 页签模式 → 出库状态 | 状态下拉隐藏；页签：全部 / 未出库 / 部分出库 / 出库完成 |
| 页签模式 → 是否有库存 | 下拉隐藏；页签：**全部** / 有库存 / 无库存（「全部」= 不限制，等同下拉「空白」） |
| 点「全部」（有库存维度） | `stockPresence` 为空串；结果不限在库有无 |
| 启用仓 ≤10 → 仓库 | 仓库下拉隐藏；页签：全部 + 各仓 |
| 启用仓 >10 | 「仓库」禁用；偏好为仓库时回退下拉 |

---

## 三、与即查

| 步骤 | 预期 |
|------|------|
| 未开页签时改下拉/日期 | 仍立即查询 |
| 点页签 | **立即**请求 |
| 业务员 / 采购员 | 始终为下拉，不受页签模式影响 |

---

## 四、持久化与主题

| 步骤 | 预期 |
|------|------|
| 开启某维度后 F5 | 仍为该维度（仓库且 >10 时仅回退下拉展示） |
| 亮色未选中页签 | 约 `#E8EDF5` |
| 暗色未选中页签 | 深色层，不发白 |
