## 1. 入口与权限

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 有库存读权限进入 `/inventory/stock-items`（未开过页签） | 无页签条；搜索栏含出库状态 / 是否有库存 / **入库类型**（在入库单号前） / 仓库 / 业务员 / 采购员等；搜索栏末尾有齿轮（「列表筛选设置」） |
| 2 | 无库存读权限 | 不可进入本页（与列表既有门控一致） |
| 3 | 点搜索栏齿轮 | 「关闭页签」禁用；「页签模式 ▸」四项：出库状态、是否有库存、仓库、**入库类型**；**无**业务员、采购员 |

**本功能不适用：** 无 write 提交按钮（只改筛选展示形态）。

---

## 2. 页签、门控与持久化

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 页签模式 → 出库状态 | 状态下拉隐藏；页签：全部 / 未出库 / 部分出库 / 出库完成 |
| 2 | 页签模式 → 是否有库存 | 下拉隐藏；页签：**全部** / 有库存 / 无库存（「全部」= 不限制，等同下拉「空白」） |
| 3 | 点「全部」（有库存维度） | `stockPresence` 为空串；结果不限在库有无 |
| 4 | 页签模式 → 入库类型 | 入库类型下拉隐藏；页签：全部 / 采购入库 / 报关入库 / 退货入库 / 报废入库 |
| 5 | 点「报关入库」 | **立即**查询；请求带 `stockInType=20`；列表仅该类型 |
| 6 | 再开「出库状态」 | 入库类型下拉恢复（值可保留）；状态下拉隐藏；页签变为出库状态桶 |
| 7 | 启用仓 ≤10 → 仓库 | 仓库下拉隐藏；页签：全部 + 各仓 |
| 8 | 启用仓 >10 | 「仓库」菜单项禁用；偏好为仓库时回退下拉 |
| 9 | 关闭页签 | 页签消失；对应下拉恢复且值保留 |
| 10 | 开启某维度后 F5 | 仍为该维度（仓库且 >10 时仅回退下拉展示） |
| 11 | 未开页签时改下拉/日期 | 仍立即查询 |
| 12 | 业务员 / 采购员 | 始终为下拉，不受页签模式影响 |

---

## 3. 数据范围与脱敏

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 部门数据范围 | 页签只改筛选形态，列表范围与改前一致 |
| 2 | 采购 511 / 销售 521 脱敏 | 页签仍可用；供应商/客户等仍为 `—` |

---

## 4. 口径 / 金额边界

**本功能不适用：足额成功 / 超额拒绝。** 只改筛选 UI，无核销、匹配、金额提交。
