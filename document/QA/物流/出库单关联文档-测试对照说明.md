# 出库单关联文档 — 测试对照说明

> **页面 / 路由：** 仓储管理 → 出库单 `/inventory/stock-out`（`StockOutList`）；出库详情 `/inventory/stock-out/:id`（`StockOutDetail`）  
> **设计文档：** [出库单关联文档-设计与实现](../../System/物流/出库单关联文档-设计与实现.md)  
> **关联：** [出库单列表-操作面板-测试对照说明](./出库单列表-操作面板-测试对照说明.md)  
> **权限 / DDL：** 无新权限码。须执行 `upload_document."DocCategory"` 迁移并重启 API。

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有出库列表权限，展开右栏「操作」，单击一行 | 出库摘要与出货方式之间出现「文档」卡；本机第一次为**收起**（只见标题+份数+下箭头），上传区与文件列表不占高度 |
| 物流可写 | 展开后卡内有类型下拉（出货照片 / 出货签收单 / 其他）与上传 |
| 物流只读 | 展开后无上传区；已有文件可预览/下载，无删除 |
| 无出库列表权限 | 不能进入本页 |
| 打开出库详情（默认可停在「出库明细」） | 「关联文档」旁：有文件显示 `(n)`，无文件不显示括号；`n` 与文档列表份数一致 |
| 打开出库详情 → 「关联文档」 | 可写账号可上传；只读账号仅列表 |

---

## 二、分类与上传

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 类型选「出货照片」，选 1 张 jpg，点上传 | 成功；列表新增一行，行首标签「出货照片」 |
| 2 | 类型选「出货签收单」，上传 pdf | 新行行首「出货签收单」；与出货照片同列、不另开分组 |
| 3 | 类型选「其他」，上传 xlsx | 新行行首「其他」 |
| 4 | 连续上传多张（可混类型） | 列表依次增加行；操作面板标题总份数 = 行数；详情页签变为「关联文档 (n)」；**无**三个空组标题 |
| 5 | 单次超过 20 个文件 | 前端截断或后端拒绝；已成功文件仍按所选类型保存，行首标签与上传时选择一致 |
| 6 | 不选文件点上传 | 上传按钮不可用 |
| 7 | 列表操作面板与详情对同一出库单 | 文件集合、顺序、行首类型一致 |

默认类型：**出货照片**。草稿 / 待出库 / 出库完成均可上传。  
操作面板验收本节前须先点标题右侧箭头**展开**文档卡。

请求：`POST /api/v1/documents/upload`，`bizType=STOCK_OUT`，`bizId=出库单主键`，`docCategory` 为 `SHIP_PHOTO` / `POD` / `OTHER`。

---

## 三、列表、预览、删除

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 无任何附件 | 展开后单条空态「暂无」（操作面板）或「暂无文档」（详情）；**不**出现三个空组 |
| 2 | 操作面板：鼠标不在文件行上 | **不**显示「预览 / 下载 / 删除」；类型标签与文件名仍可见；文件行无单独边框，列表**无**统一外框 |
| 3 | 操作面板：鼠标移到该行 | 行尾浮现浅黄底工具条，含「预览 / 下载」；可写另有「删除」；移出后工具条隐藏 |
| 4 | 操作面板：点文件名（不必先等按钮） | 图片/PDF 可预览 |
| 5 | 操作面板：悬停后点下载 | 原文件名保存 |
| 6 | 操作面板：悬停后删除（可写） | 确认后该行消失；总份数减 1；详情页签 `(n)` 同步减少；刷新详情仍无该文件 |
| 7 | 历史迁移前上传、无分类的文件 | 仍在平铺列表中，行首标签为「其他」 |
| 8 | 多条不同时间上传 | 新上传的在上；行首标签颜色可区分三类（出货照片 / 签收单 / 其他） |
| 9 | 详情「关联文档」 | **常显**「预览 / 下载 / 删除」（可写才有删除）；不随悬停隐藏；类型下拉与文件名均为 13px / Noto Sans SC；文件名默认非主题蓝、悬停才变蓝带下划线；文件行无单独边框，整表一圈边框 |
| 10 | 销售/采购/客户/质检文档列表 | **仍常显**预览/下载/删除，不受本条悬停规则影响 |

## 四、操作面板门控（§4.4）

与 [出库单列表-操作面板](./出库单列表-操作面板-测试对照说明.md) 第二节相同：右栏收起单击不请求；在「帮助」单击不切回操作。  
选中行后文档卡随该出库单 `bizId` 切换；搜索/重置清空选中后文档卡不显示。

### 折叠（默认收起）

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 本机从未点过展开（或清掉该键后）选中一行 | 文档卡**收起**：标题「文档」+ 份数或「（无上传）」可见；上传区与文件列表不占高度；右侧为下箭头 |
| 2 | 该单有 n 份附件（n≥1），卡仍收起 | 标题为「文档（n）」；括号浅灰、数字绿；**不必展开**即可看到份数 |
| 3 | 点标题右侧下箭头 | 展开：可写出现类型下拉（`small`、13px）与上传；文件列表平铺；类型标签左缘与下拉左缘对齐；箭头变为上箭头 |
| 4 | 点标题右侧上箭头 | 正文隐藏，标题行保留计数与下箭头 |
| 5 | 展开后刷新页面或换另一行再回来 | 仍为上次的展开/收起（`localStorage` `frontcrm.stock-out-ops.docs-expanded`） |
| 6 | 收起状态下换行 | 份数随新出库单更新；展开/收起状态不因换行重置 |

## 五、数据范围与脱敏

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 销售 521 脱敏 | 文档卡仍加载；不因脱敏隐藏附件 |
| 2 | 列表数据范围外的出库单 | 不能通过改 `bizId` 在界面点到（无行则无面板） |

附件读写走文档 API + 出库数据范围，不另开权限码。

---

## 六、口径 / 公式核对

本功能 **不涉及金额、核销、匹配**。份数口径：

```text
标题总份数 / 详情页签 (n) = 未删除且 BizType=STOCK_OUT 且 BizId=本出库单 的 upload_document 行数
n = 0 时页签仅为「关联文档」，不带括号
列表顺序 = CreateTime 降序（新在上），不按 DocCategory 分桶
行首标签：SHIP_PHOTO → 出货照片；POD → 出货签收单；OTHER / 空 / 未知码 → 其他
```

---

## 七、通用维度（不适用项）

| 维度 | 说明 |
|------|------|
| 工作台 / 桌面左栏队列（§4.3） | **本功能不适用：** 非审批/报价/核销桌面 |
| 金额提交 / 核销 / 匹配足额与超额（§4.5） | **本功能不适用：** 不提交金额或核销 |
| 数据分析看板公式 | **本功能不适用** |
| 多租户皮肤 / 打印（§4.6） | **本功能不适用** |
| 页签模式 F5 持久化 | **本功能不适用：** 不控制列表页签模式；文档卡展开/收起另有本机记忆，见第四节折叠 |
| 上线前置（§4.7） | 须执行 `upload_document."DocCategory"` 迁移并重启 API；无新权限、不必重新登录 |

## 八、回归 / 交叉

| 步骤 | 预期 |
|------|------|
| 销售订单 / 采购订单 / 客户 / 质检详情文档 | 不显示行首类型标签；预览/下载/删除仍常显；上传不选类型时归 OTHER |
| 出库明细列表 `/inventory/stock-out/items` | **无** 本出库单文档上传入口 |
| 出库单列表行内详情 / 编辑 / 标记完成 | 仍可用；与文档卡互不替代 |
| 帮助页「出库单」 | 有业务说明：按类型上传；列表操作栏指向文件行可预览/下载/删除，详情行内按钮常显；无表名/权限码 |
