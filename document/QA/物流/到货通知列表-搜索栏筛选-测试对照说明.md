# 到货通知列表 — 搜索栏筛选 — 测试对照说明

> **页面 / 路由：** `/logistics/arrival-notices`（菜单：物流 → 到货通知）  
> **设计文档：** [到货通知列表-左栏检索-设计与实现](../../System/物流/到货通知列表-左栏检索-设计与实现.md) §1、§4  
> **关联：** [到货通知列表-左栏检索-测试对照说明](./到货通知列表-左栏检索-测试对照说明.md)、[到货通知列表-筛选页签模式-测试对照说明](./到货通知列表-筛选页签模式-测试对照说明.md)  
> **权限 / DDL：** 列表只读即可验收筛选；无新增迁移。销售方向 511 见 §四。

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有物流/到货通知列表权限，打开菜单 | 进入 `/logistics/arrival-notices`，搜索栏在标题下方、表格上方 |
| 无对应 read | 不可进入该页 |
| 搜索栏可见项（有采购敏感列权限） | 状态、到货类型、采购/到货通知单号、货代单号、**物料型号**、**供应商名称**、**采购币种**、预计到货日、查询、重置、齿轮 |
| 点「查询」 | `GET /api/v1/logistics/arrival-notices` 带当前条件；URL query 同步 |
| 点「重置」 | 清空全部 query（含左栏 preset 与三项新 keyword） |
| F5 | URL 中的三项条件仍生效 |

---

## 二、物料型号

| 步骤 | 预期 |
|------|------|
| 占位符 | 「物料型号」，无字段标题 |
| 输入通知快照上的型号片段，点查询 | 仅返回 `Pn` 包含该片段的行（大小写不敏感） |
| 通知快照为空、采购明细 `PN` 含该片段 | 仍能查出（回落采购明细） |
| 无匹配 | 空表，总数 0 |
| 与「所有逾期」preset 同时使用 | URL 含 `preset=overdue_all` + `pn=…`；结果同时满足逾期与型号 |

---

## 三、供应商名称（中英文）

| 步骤 | 预期 |
|------|------|
| 占位符 | 「供应商名称」 |
| 输入中文名片段（通知快照或档案正式名） | 命中对应供应商的到货通知 |
| 输入英文正式名片段 | **同样命中**（不要求先切语言） |
| 中文不匹配但英文匹配 | 能查出 |
| 无匹配 | 空表 |
| 与 preset / 型号 / 币种叠加 | AND；URL 同时带各 keyword |

---

## 四、数据范围与脱敏（511）

| 步骤 | 预期 |
|------|------|
| 销售方向、无采购敏感列权限 | 搜索栏 **不出现**「供应商名称」；列表供应商列为 `—` |
| 上述账号 URL 手工加 `vendorName=某供应商` | 后端忽略该参数，结果不按供应商收窄 |
| 上述账号仍可用物料型号、采购币种 | 两项可见且生效 |
| 操作面板 | 本功能不适用：筛选不改变右栏门控；点行仍按操作面板既有规则加载 |

---

## 五、采购币种（具体币种）

| 步骤 | 预期 |
|------|------|
| 下拉选项与顺序 | USD、RMB、HKD、EUR（与结算币别下拉一致）；可清空 |
| 选 USD 查询 | 仅采购明细币别为 USD（编码 2）的通知；无明细时按订单头币别 |
| 选 RMB / HKD / EUR | 分别只出对应币种 |
| 清空后查询 | 不再按币种过滤 |
| 禁止项 | 不是「人民币 / 外币」二元下拉；参数名为 `purchaseCurrency`，不是 `transactionCurrency` |
| 与 preset 叠加 | URL 如 `preset=todo_pending_qc&purchaseCurrency=2` |

---

## 六、与左栏 preset / 页签模式

| 步骤 | 预期 |
|------|------|
| 先填三项再点左栏「待质检」 | 保留 `pn` / `vendorName` / `purchaseCurrency`，写入 `preset` |
| 再点同一 preset | 清空全部 query（含三项） |
| 开启「状态」页签 | 三项输入仍在搜索栏；页签只替换状态下拉 |
| 本功能不适用：页签模式持久化细节 | 见 [筛选页签模式-测试对照说明](./到货通知列表-筛选页签模式-测试对照说明.md) |

---

## 七、回归 / 交叉

| 步骤 | 预期 |
|------|------|
| 原有单号、货代单号、状态、类型、预计日 | 行为不变 |
| 报关到货（类型 20）按型号 / 供应商 / 币种 | 与采购到货同一套规则（仍走采购明细/订单头币别） |
| 部门数据范围 | 筛选只在当前可见行内收窄，不放大范围 |

---

## 八、本功能不适用

- **本功能不适用：金额 / 核销 / 匹配足额与超额。** 搜索栏不提交金额，无核销或匹配动作。
- **本功能不适用：数据分析看板公式。**
- **本功能不适用：多租户打印皮肤。**
- **本功能不适用：审批/核销类工作台左右栏队列。** 左栏此处是 preset 检索，交叉见左栏检索对照说明。
