## 二、出库明细单号（列表 / 详情）

| 步骤 | 预期 |
|------|------|
| 打开出库明细列表 | 有「出库明细单号」列；形态 `{出库单号}-{正整数}`，如 `STO00221-1` |
| 同一出库单多行 | 序号从 1 连续，不重复 |
| 按出库明细单号筛选（完整号） | 只命中该行 |
| 按出库单号筛选 | 仍命中该单全部明细（与现网一致，不被明细号列破坏） |
| 状态后有「出库类型」下拉（销售/报关/退货/报废） | 选项与出库单列表相同；搜索栏齿轮可改为页签，见 [出库明细列表-筛选页签模式](./出库明细列表-筛选页签模式-测试对照说明.md) |
| 列表「出库类型」列 | 在「出货方式」前；标签与出库单列表一致（销售含历史 1 显示为销售出库） |
| 底栏列设置齿轮 + 行高（紧密/适中） | 在表体**下方**左侧，与分页同排；刷新后列显隐/顺序/行高保持 |
| 表头列标题 | 1920 / 1366 下无 `…` 省略 |
| 出库单号 / 装箱单号 | 默认同正文色；悬停才变色+下划线 |
| 选出库类型「销售出库」 | 含类型 10 与历史 1；请求带 `stockOutType=10` |
| 选报关 / 退货 / 报废 | 仅该类型；不含销售（含历史 1） |
| 物流分析出库卡下钻到本页 | 预填状态「出库完成」+ 销售出库 + 出库日区间 |
| 打开出库单详情 | 明细表能看到各行出库明细单号 |
| 新执行一笔装箱出库 | 新行立即有号，无需再跑回填 |
| 调拨虚拟出库（若列表可见） | 有 `{单号}-1`；装箱流程不展示此类单 |

## 三、装箱流程出库站（真实出库行）

准备：一张多行装箱单，其中一行装箱数量为 A（如 300,000），整箱拣货合计为 B（B > A）；该行已出库。

| 步骤 | 预期 |
|------|------|
| `/inventory/packing/items` 未点行 | 流程提示请单击装箱明细 |
| 单击数量为 A 的装箱行 | 该行高亮；出库站**不是**整箱 B 的单头卡 |
| 出库站每张卡 | 出库单号 + 出库明细单号 + 数量 = **该出库明细数量**（通常等于 A 或拆行后的子数量之和为 A） |
| 一装箱行拆多条拣货 | 出库站多卡，数量合计 = 该装箱行数量 |
| 同一装箱行历史上已被重复出库（多张出库单） | 多卡，各带本行数量与不同出库单号/明细号；**不**合并 |
| 已出库后再点装箱「出库」 | 拒绝，提示已出库不能重复出库；不新生成出库单。即使「刷新状态」后显示已备货，仍拒绝 |
| 装箱单列表点该箱再切到该明细单号 | 出库站与明细列表单击同一行一致 |
| 装箱详情点同一行 | 同上，三处一致 |
| 尚未出库的装箱行 | 出库站「未开始」，不出现其它销售行/其它箱的出库单 |
| 无拣货行、对不上出库明细 | 出库站「未开始」，不回退成该销售行全部出库单 |

## 四、工作台 / 流程门控

| 步骤 | 预期 |
|------|------|
| 右栏收起时单击装箱明细行 | 不强制打开右栏（与装箱单列表现网一致）；再展开「流程」可见已绑定内容 |
| 停在「帮助」时单击行 | 行选中；切到「流程」后看到该行流程（不要求单击瞬间切走帮助） |

| 刷新浏览器 | 需重新点行（不持久化选中行） |

**本功能不适用：左栏队列桌面、核销桌面顶栏 N/M。**

## 八、口径核对（数量）

```text
出库站卡片数量 = 该 stock_out_item 的 ActualQty（空则 Quantity）
一装箱行多出库明细时：Σ卡片数量 应等于该装箱行数量 × 重复出库次数
（重复出库 N 次且未拆行：N 张卡，每张 ≈ 装箱行数量）
禁止用 stock_out.TotalQuantity（整单/整箱）作为该装箱行出库站数量
```

出库明细单号：

```text
StockOutItemCode = StockOutCode + "-" + 组内行序（从 1，按 CreateTime、ItemId）
```

## 十一、已知口径差异 / 范围外

| 项 | 说明 |
|----|------|
| 与旧流程出库站 | 旧：销售行 + 装箱单号 → 单头与整单数量。新：装箱行 → 出库明细。属设计变更，不是缺陷 |
| 历史重复出库多卡 | 上线前已重复出过的箱，流程仍如实多卡；上线后禁止再出 |
| 出库单已取消 | 仅剩已取消出库时允许再次出库（未取消的有效出库仍拦截） |
| 出库单列表销售筛 vs 明细列表 | 单头列表 `== 10`；明细列表销售含 10\|1。不是缺陷 |
| 范围外 | 出库明细独立详情页；列级 `NOT NULL` |
