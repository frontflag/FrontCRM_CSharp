## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有出库列表权限进入本页 | 右栏页签 **操作 + 帮助**；首次进入默认 **操作**（若本地记得本页上次页签则恢复记忆，收起再展开仍默认操作） |
| 无出库列表权限 | 不能进入本页 |
| 物流只读（有列表、无物流写） | 可看操作面板；出货方式无「编辑」；未完成单无「标记完成」按钮 |
| 物流可写 | 出货方式有「编辑」；状态不是「出库完成」时有「标记完成」 |

## 二、页签与门控（§4.4）

| # | 步骤 | 预期 |
|---|------|------|
| 1 | 未选行 | 提示在「操作」页签下单击列表行 |
| 2 | 右栏收起，单击任意行 | 不展开、不高亮、**不**请求 `ops-aggregates` |
| 3 | 展开右栏，切到 **帮助**，单击行 | 行高亮 `so-item-row--active`，不切回操作、不请求 |
| 4 | 在 **操作** 页签单击行 | 请求 `GET /api/v1/stock-out/{id}/ops-aggregates`，展示卡片 |
| 5 | 帮助下已点行，再切回 **操作** | 补请求 aggregates |
| 6 | 搜索 / 重置 / 页签模式点某一页签 | 面板清空为未选行提示 |
| 7 | 分页后选中行仍在当前页 | 面板与该行同步 |
| 8 | 双击行 | 进出库详情；不与单击抢页签 |

筛选页签本身见 [出库单列表-筛选页签模式-测试对照说明](./出库单列表-筛选页签模式-测试对照说明.md)。左栏检索清空规则与搜索相同。

## 三、出库摘要

| # | 数据 | 预期 |
|---|------|------|
| 1 | 任意出库 | 琥珀单号可点进详情；状态文案与列表一致；类型为销售/报关/退货/报废图标 |
| 2 | 客户中英文均有 | 摘要一行显示 `中文 / 英文`，**无**「客户」标题 |
| 3 | 业务员 | 摘要一行显示业务员名称，**无**「业务员」标题；头表无值时与销售行一致 |
| 4 | 合计出库数量 | 有标题「合计数量」+ 数值**左对齐**；数值与列表「合计数量」一致 |
| 5 | 报关出库且有报关单 | 摘要多一行报关单号，点击进报关单详情；类型旁海关图标仍在 |
| 6 | 非报关出库 | **无**报关单号行 |

## 四、出货方式与编辑

| # | 条件 | 预期 |
|---|------|------|
| 1 | 选中任意行 | 卡内：出库日期、出货方式、快递公司、快递单号；空为 — |
| 2 | 物流可写 | 「编辑」在出货方式卡 **标题栏右侧**（文字 link/label，非卡底通栏蓝块），打开与操作列同一对话框 |
| 3 | 对话框出货方式改「快递」 | 快递公司可填 |
| 4 | 出货方式改「送货」或「自提」后保存 | 快递公司被清空；面板与列表同步为 — |
| 5 | 保存日期 / 方式 / 单号 | 列表列与面板一致 |
| 6 | 出库完成单 | 仍可编辑物流；不可再标记完成 |
| 7 | 详情页可编辑区 | 同样有快递公司，保存规则与列表弹窗一致 |

按箱出库（来源为装箱单）：编辑前快递公司可能为空（头表历史无列）；保存后头表有值，刷新列表列可见。

## 五、标记完成

| # | 条件 | 预期 |
|---|------|------|
| 1 | 待出库 / 准备出库 / 草稿，物流可写 | 「标记完成」主按钮；点开为现有对话框（客户、地址、装箱、日期、快递单号、备注） |
| 2 | 确认成功 | 状态变为「出库完成」；卡标题旁 **已完成 ✓**；无按钮；列表同步 |
| 3 | 已是出库完成 | 无按钮，仅 **已完成 ✓** |
| 4 | 物流只读且未完成 | 无按钮 |
| 5 | 操作列「标记完成」 | 仍可用；与右栏成功后状态一致 |

## 六、出库明细（1:N）

**布局：** 每条一组双列 Key:Value，不是窄栏表。

| # | 场景 | 预期 |
|---|------|------|
| 1 | 无明细 | 「暂无出库明细」 |
| 2 | 1～8 行 | 每组含：明细单号、装箱单号、货代单号、型号、品牌、数量、金额+币别 |
| 3 | 装箱单号有值 | 点击进装箱详情 |
| 4 | 出库明细单号 | 纯文本，不跳转 |
| 5 | 超过 8 行 | 只画前 8 组；底栏「还有 n 条，打开详情」进出库详情 |
| 6 | 金额有单价 | `数量×单价`，形态如 `1,200.00 USD`（币别上色、无货币符号） |
| 7 | 无单价 | 金额格 — |

## 七、销售订单明细 / 应收款

| # | 场景 | 预期 |
|---|------|------|
| 1 | 报关 / 退货 / 报废 | **无**「销售订单明细」「应收款」两卡 |
| 2 | 销售出库、扩展表有销售行 | 销售订单明细卡有组；明细号可点进销售订单详情并定位行 |
| 3 | 销售出库、状态不是出库完成 | 应收卡文案「尚未标记完成，暂无应收」 |
| 4 | 销售出库已完成、尚无应收 | 「暂无应收款」 |
| 5 | 销售出库已完成、有应收 | 每组行序：①应收单号单独一行；②出库数量 + 应收金额同一行；③收款核销状态单独一行；其后为收款已核销/待核销、发票核销状态、发票已核销/待核销 |
| 6 | 有收款读权限 | 应收单号可点进应收详情 |
| 7 | 无收款读权限 | 单号纯文本，卡片仍可见 |
| 8 | 应收超过 8 张 | 同明细卡截断规则 |

按箱出库（一头多销售行）：销售行卡组数与详情底部分组一致，不是只显示头表那一行。

## 九、口径 / 公式核对

本面板 **只读展示** 应收与出库金额，**不提交** 核销或匹配。

```text
出库行金额 = 明细销售单价 × 出库数量（无单价则 —）
应收金额、收款已核销、收款待核销、发票已核销、发票待核销
  = 与 GET /api/v1/stock-out/{id}/receivables 及详情应收表同一行
待核销（收款）= 应收金额 - 收款已核销（以接口字段为准，不在本页重算提交）
```

核销状态：0 未核销 / 1 部分 / 2 完成，文案与应收列表一致。

## 十一、通用维度（不适用项）

| 维度 | 说明 |
|------|------|
| 工作台 / 桌面左栏队列（§4.3） | **本功能不适用：** 非审批/报价/核销桌面 |
| 金额提交 / 核销 / 匹配足额与超额（§4.5） | **本功能不适用：** 不在本页提交核销或匹配金额；只读展示见第九节。足额成功与超额拒绝见收款核销、销项发票核销对照说明 |
| 数据分析看板公式 | **本功能不适用** |
| 多租户皮肤 / 打印（§4.6） | **本功能不适用** |
| 上线前置（§4.7） | 须执行 `stock_out."ExpressCompany"` 迁移并重启 API；无新权限、不必重新登录 |
