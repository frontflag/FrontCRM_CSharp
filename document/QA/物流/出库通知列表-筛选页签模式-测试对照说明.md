# 出库通知列表 — 筛选页签模式 — 测试对照说明

> **页面 / 路由：** `/stock-out-notifies`、`/inventory/stock-out-notifies`（同一组件）  
> **设计文档：** [出库通知列表-筛选页签模式-设计与实现](../../System/物流/出库通知列表-筛选页签模式-设计与实现.md)  
> **权限：** 路由 `sales-order.read` 或 `purchase-order.read`（OR）  
> **总纲：** [测试规范总纲](../测试规范总纲.md)

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有 `sales-order.read` 或 `purchase-order.read` 之一 | 可进入列表 |
| 两码皆无 | 不可进入该页 |
| 进入页面（未开过页签） | 无页签条；搜索栏显示状态 / 地域 / 出库类型下拉 |
| 点搜索栏齿轮（非底栏列设置） | 「关闭页签」禁用；「页签模式 ▸」含三项：状态、地域、出库类型 |

---

## 二、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 普通业务账号打开列表 | 仅本数据权限范围内的出库通知 |
| 销售敏感掩码开启 | 客户名、相关金额列为 `—`；列表仍可加载、页签/下拉仍可筛 |

---

## 三、开启与切换

| 步骤 | 预期 |
|------|------|
| 页签模式 → 状态 | 状态下拉隐藏；页签：全部 / 待报关 / 待装箱 / 已装箱 / 已出库 / **已取消** |
| 点「待装箱」 | 立即查询；列表仅该状态 |
| 再开「出库类型」 | 状态下拉恢复（值可保留）；类型下拉隐藏；页签变为全部 + 四类 |
| 关闭页签 | 页签消失；对应下拉恢复且值保留 |

---

## 四、出库类型文案与筛选（禁止兜底）

筛选项仍为四类（10 销售 / 20 报关 / 30 退货 / 40 报废），**不提供**「移库」「未知」筛选项。

| 步骤 | 预期 |
|------|------|
| 类型下拉或页签看四类文案 | 销售出库 / 报关出库 / 退货出库 / 报废出库，与码值 10/20/30/40 一一对应 |
| 点「销售出库」 | 请求 `stockOutType=10`；结果行类型均为 `10`（存量销售出库已刷为 `10`，库内无 `1`） |
| 列表中类型为 `3` 的行（若有） | 列显示「移库」，不会显示成「销售出库」 |
| 列表中类型为 `0` 或无法识别的行（若有） | 列显示「未知」，不会显示成「销售出库」 |
| 点「报关出库」 | 仅 `stockOutType=20` |

**本功能不适用：** 用「未知」或「移库」作为筛选项（筛选桶不包含这两类）。

---

## 五、与「搜索」按钮

| 步骤 | 预期 |
|------|------|
| 改文本/日期不点搜索 | 不请求（与现网一致；本版不改下拉即查） |
| 点页签 | **立即**请求 |

---

## 六、持久化与主题

| 步骤 | 预期 |
|------|------|
| 开启某维度后 F5 | 仍为该维度页签 |
| 亮色未选中页签 | 约 `#E8EDF5` |
| 暗色未选中页签 | 深色层，不发白 |

---

## 七、本功能不适用（总纲强制项）

| 维度 | 说明 |
|------|------|
| 金额 / 核销 / 匹配（总纲 §4.5） | 本功能不适用：页签筛选无金额提交、核销或匹配进度 |
| 多租户打印皮肤（总纲 §4.6） | 本功能不适用：无打印、无租户报表皮肤 |
| 左栏 shortcut preset | 本功能不适用：本列表无左栏检索 preset |
| 操作面板门控 | 本功能不适用：本对照仅覆盖筛选页签与类型文案；报关单右栏见另文 |
| 上线 SQL / 迁移 | 本功能不适用：仅前后端查询与文案，无新权限码、无 DDL |

---

## 八、已知口径差异

| 项 | 说明 |
|----|------|
| 出库类型存量 | `stock_out` / `stockout_notify` 已刷净，库内无 `1/2/4`；筛「销售出库」只查 `10`。展示代码仍认历史 `1`（阶段 C 前） |
| 装箱「类型须一致」 | 仍可能把未识别类型当成销售（`resolveNotifyStockOutType`），**不在本对照范围** |
