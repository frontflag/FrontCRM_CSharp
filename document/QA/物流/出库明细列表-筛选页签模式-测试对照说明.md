# 出库明细列表 — 筛选页签模式 — 测试对照说明

> **页面 / 路由：** `/inventory/stock-out/items`（出库明细）  
> **设计文档：** [出库明细列表-筛选页签模式-设计与实现](../../System/物流/出库明细列表-筛选页签模式-设计与实现.md)  
> **UI 规范：** [列表搜索栏规范 §10](../../PRD/规范/UI规范/列表搜索栏规范.md)  
> **关联 QA：** [出库明细单号与装箱流程出库站](./出库明细单号与装箱流程出库站-测试对照说明.md)、[出库单列表-筛选页签模式](./出库单列表-筛选页签模式-测试对照说明.md)

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有出库/库存列表只读 | 可进入出库明细；搜索栏末尾有齿轮「列表筛选设置」（非底栏列设置） |
| 无对应菜单权限 | 不可进入，与现网一致 |
| 进入页面（未开过页签） | 无页签条；状态 / 出库类型为下拉 |
| 点搜索栏齿轮 | 「关闭页签」禁用；「页签模式 ▸」两项：状态、出库类型 |

**本功能不适用：** 工作台左栏队列（§4.3）、操作列、复选篮子。

---

## 二、开启与切换

| 步骤 | 预期 |
|------|------|
| 页签模式 → 状态 | 状态下拉隐藏；页签 6 格：全部 / 草稿 / 待出库 / 准备出库 / 出库完成 / **已取消**（已取消在最右） |
| 点「出库完成」 | 立即查询；仅状态 4；请求带 `status=4` |
| 点「草稿」 | 能筛到 status=0（勿与「全部」混淆） |
| 再开「出库类型」 | 状态下拉恢复（值可保留）；类型下拉隐藏；页签变为全部 + 销售 / 报关 / 退货 / 报废 |
| 点「销售出库」 | 立即查询；含类型 10 与历史 1 |
| 关闭页签 | 页签消失；对应下拉恢复且值保留 |
| 点「重置」 | 筛选值清空；**页签模式维度不关**（仍显示页签条，「全部」高亮） |

---

## 三、与查询按钮 / 即查

| 步骤 | 预期 |
|------|------|
| 未开页签时改状态/类型下拉 | 立即查询（与现网出库明细一致） |
| 改文本不点查询 | 不请求 |
| 点页签 | **立即**请求 |

---

## 四、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 销售数据范围账号 | 页签切换后仍只见权限内明细 |
| 521 销售敏感 | 客户/业务员为 `—`；页签与列表仍能加载 |

---

## 五、金额 / 核销 / 匹配

**本功能不适用：不涉及核销、匹配、金额提交，无「足额成功 / 超额拒绝」。**

---

## 六、列表页签模式 / 打印皮肤

| 步骤 | 预期 |
|------|------|
| 开启某维度后 F5 | 仍为该维度页签（`crm.stock-out-item-list.tab-mode`，与出库单列表偏好互不影响） |
| 亮色未选中页签 | 约 `#E8EDF5` |
| 暗色未选中页签 | 深色层，不发白 |
| 底栏列设置齿轮 | 仍在表体下方；与搜索栏齿轮不是同一入口 |

**本功能不适用：多租户打印皮肤（§4.6）。**

---

## 七、回归 / 交叉

| 项 | 预期 |
