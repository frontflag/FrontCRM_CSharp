# 到货通知 — 编辑到货信息 — 测试对照说明

> **页面 / 路由：** `/logistics/arrival-notices`（菜单：物流 → 到货通知）  
> **设计文档：** [到货通知-编辑到货信息-设计与实现](../../System/物流/到货通知-编辑到货信息-设计与实现.md)  
> **关联：** [到货通知列表-操作面板-测试对照说明](./到货通知列表-操作面板-测试对照说明.md)  
> **权限 / DDL：** 无新权限码、无迁移。须重新登录后再测角色差异。

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 系统管理员 / 平台管理员 / 业务经理 | 操作列有「编辑到货信息」；面板有同名按钮 |
| 物流部总监或经理（主部门身份物流，组织角色总监/经理，物流数据读写） | 同上 |
| 物流部员工（`DEPT_EMPLOYEE`） | 无按钮；面板仍显示三字段 |
| 销售部总监 | 无按钮 |
| 物流总监但部门物流数据=只读 | 无按钮；`PATCH` 返回 403 |
| 系统/平台管理员/业务经理 + 物流只读部门 | **仍可改** |
| 无列表 read | 进不了页面 |
| 手工 `PATCH` 且无权 | 403「无权编辑到货信息」 |
| 无权账号改 URL 调接口改不可见行 | 404 或不改变数据 |

---

## 二、对话框与字段

| 步骤 | 预期 |
|------|------|
| 点操作列或面板「编辑到货信息」 | 弹出「编辑到货信息」；带入当前方式 / 公司 / 单号 |
| 三项均可空，保存 | 成功；列表方式、单号列与面板同步；状态/数量/日期不变 |
| 选快递，公司与单号可空，保存 | 成功 |
| 选送货/自提后保存 | 快递公司被清空（即使对话框里曾有值） |
| 清空方式后保存 | 方式、公司为空 |
| 取消 | 不写库 |
| 未到货 / 待检 / 已质检 / 已入库 各改一次 | 都能保存，流程状态不变 |
| 报关到货与采购到货 | 同一套 |

---

## 三、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 物流经理只看见本部门通知 | 只能改这些行；改其他 Id 失败 |
| 销售方向 511 | 面板仍加载；到货信息三字段**不脱敏**（非供应商/金额） |

---

## 四、操作面板门控

| 步骤 | 预期 |
|------|------|
| 右栏收起单击行 | 不打开对话框、不请求 aggregates |
| 「帮助」页签单击行 | 不高开帮助、不自动弹编辑窗 |
| 「操作」页签单击行 | 出现「到货信息」卡（在确认到货卡上方） |
| 保存后 | 当前行面板三字段立即更新 |

操作面板通用门控细节见 [操作面板-测试对照说明](./到货通知列表-操作面板-测试对照说明.md)。

---

## 五、回归

| 步骤 | 预期 |
|------|------|
| 确认到货 / 质检 / 明细 / 删除 | 行为不变 |
| 列表无「快递公司」列 | 改完公司只能在对话框或面板看到 |
| 左栏 preset / 搜索栏 | 不因本功能改变 |

---

## 六、本功能不适用

- **本功能不适用：金额 / 核销 / 匹配足额与超额。** 不提交金额。
- **本功能不适用：数据分析看板公式。**
- **本功能不适用：多租户打印皮肤。**
- **本功能不适用：审批/核销工作台左右栏队列。**
