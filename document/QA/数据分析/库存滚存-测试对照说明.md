# 库存滚存 — 测试对照说明

> **设计需求与实现**见：[库存滚存-设计与实现.md](../../EBS/物流/库存滚存-设计与实现.md)  
> **EBS 原业务规则**见：[库存滚存业务逻辑文档.md](../../EBS/物流/库存滚存业务逻辑文档.md)

| 项 | 内容 |
|----|------|
| 菜单路径 | 财务 → 库存报表 → 库存滚存 |
| 汇总路由 | `/finance/stock-accumulated` |
| 明细路由 | `/finance/stock-accumulated/items?month=yyyy-MM` |
| 权限 | `finance-accumulated.read`（兼容 `finance-receipt.read` 访问 API） |
| API | `GET /api/v1/finance/accumulated/search-options`、`/stock`、`/stock-items` |

---

## 一、数据口径

| 维度 | 规则 |
|------|------|
| 入库时间 | `stock_in.StockInDate` |
| 出库时间 | `stock_out.StockOutDate`，为空时回退 `stock_out.CreateTime` |
| 入库范围 | `StockInType = 10`（采购），`Status = 2`（已过账），`is_deleted = false` |
| 出库范围 | `Status IN (2, 4)`，`StockOutType IN (10, 1)`（销售出库），排除移库 `3` |
| 统计粒度 | `stock_in_item`；金额 = 数量 × USD 单价 |
| 入库单价 | `stock_item.PurchasePriceUsd` |
| 出库单价 | 优先 `stock_out_item_extend.PurchasePriceUsd`，为 0 时回查 `stock_item` |
| 出库数量 | 优先 `stock_out_item_extend.QtyStockOut`，否则 `ActualQty` / `Quantity` |
| 月份切分 | 业务自然月（默认 Asia/Shanghai） |

---

## 二、库存滚存汇总（按年 12 行）

**查询参数：** `year`（必填，如 `2026`）

**滚存公式（逐月）：**

- 1 月上期 = 该年之前累计入库 − 累计出库
- 2–12 月上期 = 上月结余
- 结余 = 上期 + 本期入库 − 本期出库

**返回字段：**

| 字段 | 说明 |
|------|------|
| `yearMonth` | yyyy-MM |
| `prvAmountTotal` | 上期金额 USD |
| `currentStockInAmountTotal` | 本期入库金额 USD |
| `currentStockOutAmountTotal` | 本期出库金额 USD |
| `balanceAmountTotal` | 结余金额 USD |
| `prvStockQty` / `stockInQty` / `stockOutQty` / `balanceStockQty` | 数量 |

固定 12 行；当年未来月份显示 0。

---

## 三、库存明细滚存（按月分页）

**查询参数：**

| 参数 | 必填 | 说明 |
|------|------|------|
| `month` | 是 | yyyy-MM |
| `queryKeywords` | 否 | 物料型号模糊 |
| `pn` | 否 | 物料型号 |
| `stockInCode` | 否 | 入库单号 |
| `stockInTimeStart` / `stockInTimeEnd` | 否 | 入库日期（限于所选月内） |
| `page` / `pageSize` | 否 | 默认 1 / 20 |

**数据范围：** 所选月内过账的采购入库明细行。

**单行公式：**

- 本期入库 = 行数量 × USD 单价
- 本期出库 = 本月关联出库数量 × USD 单价
- 上期出库 = 本月之前关联出库
- 结余数量 = 上期数量 + 本期入库 − 本期出库

---

## 四、金额脱敏

与财务分析一致：无采购/销售金额读权限且非管理员时，`maskAmounts = true`，金额字段为 `null`，前端显示 `—`。

---

## 五、权限脚本

执行 `scripts/finance_accumulated_read_permission_postgresql.sql` 写入 `finance-accumulated.read` 并授予已有付款/收款读权限的角色。
