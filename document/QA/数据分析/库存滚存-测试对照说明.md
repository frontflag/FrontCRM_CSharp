## 一、数据口径

| 维度 | 规则 |
|------|------|
| 入库时间 | `stock_in.StockInDate` |
| 出库时间 | `stock_out.StockOutDate`，为空时回退 `stock_out.CreateTime` |
| 入库范围 | `StockInType = 10`（采购），`Status = 2`（已过账），`is_deleted = false` |
| 出库范围 | `Status IN (2, 4)`，`StockOutType = 10`（销售出库），排除移库 `3`。代码仍 `OR` 历史 `1`，**库中已刷净** |
| 统计粒度 | `stock_in_item`；金额 = 数量 × USD 单价 |
| 入库单价 | `stock_item.PurchasePriceUsd` |
| 出库单价 | 优先 `stock_out_item_extend.PurchasePriceUsd`，为 0 时回查 `stock_item` |
| 出库数量 | 优先 `stock_out_item_extend.QtyStockOut`，否则 `ActualQty` / `Quantity` |
| 月份切分 | 业务自然月（默认 Asia/Shanghai） |

---

## 二、库存滚存汇总（按年 12 行）

**查询参数：** `year`（必填，如 `2026`）

**滚存公式（逐月）：**

- 1 月上期 = 该年之前累计入库 − 累计出库
- 2–12 月上期 = 上月结余
- 结余 = 上期 + 本期入库 − 本期出库

**返回字段：**

| 字段 | 说明 |
|------|------|
| `yearMonth` | yyyy-MM |
| `prvAmountTotal` | 上期金额 USD |
| `currentStockInAmountTotal` | 本期入库金额 USD |
| `currentStockOutAmountTotal` | 本期出库金额 USD |
| `balanceAmountTotal` | 结余金额 USD |
| `prvStockQty` / `stockInQty` / `stockOutQty` / `balanceStockQty` | 数量 |

固定 12 行；当年未来月份显示 0。

---

## 三、库存明细滚存（按月分页）

**查询参数：**

| 参数 | 必填 | 说明 |
|------|------|------|
| `month` | 是 | yyyy-MM |
| `queryKeywords` | 否 | 物料型号模糊 |
| `pn` | 否 | 物料型号 |
| `stockInCode` | 否 | 入库单号 |
| `stockInTimeStart` / `stockInTimeEnd` | 否 | 入库日期（限于所选月内） |
| `page` / `pageSize` | 否 | 默认 1 / 20 |

**数据范围：** 所选月内过账的采购入库明细行。

**单行公式：**

- 本期入库 = 行数量 × USD 单价
- 本期出库 = 本月关联出库数量 × USD 单价
- 上期出库 = 本月之前关联出库
- 结余数量 = 上期数量 + 本期入库 − 本期出库

**明细行字段：** `stockInItemId`、`stockInId`、`billCode`、`pn`、`stockInTime` 及数量/金额指标（见设计文档 §3.2）。

---

## 四、金额脱敏

与财务分析一致：无采购/销售金额读权限且非管理员时，`maskAmounts = true`，金额字段为 `null`，前端显示 `—`。

---

## 五、权限脚本

执行 `scripts/finance_accumulated_read_permission_postgresql.sql` 写入 `finance-accumulated.read` 并授予已有付款/收款读权限的角色。

## 六、UI 与交互验收

> 细则见 [库存滚存-设计与实现.md](../../System/财务/库存滚存-设计与实现.md) **§ 十五**。

### 6.1 库存滚存汇总

| # | 检查项 | 预期 |
|---|--------|------|
| 1 | 标题栏期间控件 | `[<]` 年份下拉 `[>]`；按钮提示「上一月」「下一月」 |
| 2 | 上一月 / 下一月 | 跨年时年份与数据刷新；同年仅切换行高亮 |
| 3 | 表格列顺序 | 年月 → 4 数量 → 4 金额(USD) → 操作 |
| 4 | 8 指标列等宽 | 表头完整显示；表格横向撑满内容区 |
| 5 | 单击行 | 高亮该月，不进入明细 |
| 6 | 双击行 | 进入 `/finance/stock-accumulated/items?month=yyyy-MM` |
| 7 | 操作列「明细」 | 单击进入对应月份明细 |
| 8 | 结余数量 | 橙色加粗；负数为纷红 |
| 9 | 结余金额 | 青色加粗；负数为纷红 |
| 10 | 上期/本期金额 | 正文色，不加粗 |

### 6.2 库存明细滚存

| # | 检查项 | 预期 |
|---|--------|------|
| 1 | 页头 | 左侧「返回汇总」；标题含所选月份 |
| 2 | 检索条 | `panel-search` 字段可筛选并分页刷新 |
| 3 | 列顺序 | 入库单号、物料型号、入库时间 → 4 数量 → 4 金额 |
| 4 | 入库单号链接 | 有 `stockInId` + `inventory.read`：单击 `billCode` 进入 `/inventory/stock-in/:id`；否则纯文本 |
| 5 | 单元格样式 | 与汇总页 §15.6 一致 |
| 6 | 脱敏 | `maskAmounts` 时金额为 `—` |

## 七、本功能不适用（总纲强制项）

| 维度 | 说明 |
|------|------|
| 金额 / 核销 / 匹配提交（总纲 §4.5） | 本功能不适用：滚存为只读统计，无核销或匹配提交；足额成功 / 超额拒绝不适用 |
| 工作台 / 桌面左栏（总纲 §4.3） | 本功能不适用：无审批/核销桌面队列 |
| 多租户打印皮肤（总纲 §4.6） | 本功能不适用：无打印、无租户报表皮肤 |
