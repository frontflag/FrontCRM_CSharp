# 数据分析看板 — 测试对照说明

本目录为 **测试人员** 编写，用于对照页面展示数据与后台统计口径是否一致。

| 页面 | 路由 | 说明文档 |
|------|------|----------|
| 销售分析 | `/reports/sales` | [销售分析-测试对照说明.md](./销售分析-测试对照说明.md) |

**使用方式：**

1. 在页面设置与文档一致的筛选条件（视角、日期、库存类型等）。
2. 按文档「统计公式」在数据库或业务列表中手工汇总/抽样核对。
3. 关注各文档末尾「测试注意」与「已知口径差异」。

**实现参考（开发用）：** `document/IMP/数据看板/` 下各统计方案文档；本文档侧重可执行的核对公式。
