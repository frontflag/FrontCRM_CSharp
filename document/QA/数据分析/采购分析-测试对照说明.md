# 采购分析 — 测试对照说明

| 项 | 内容 |
|----|------|
| 菜单路径 | 数据分析 → 采购分析 |
| 路由 | `/reports/purchase` |
| 页面副标题 | 按订单创建日、美元采购额（convert_total）统计 |
| 口径提示 | 排除取消/审核失败订单；成单金额为审核通过及以上 |
| API | `GET /api/v1/analytics/purchase/dashboard`、`/trends`、`/breakdowns` |

---

## 一、全局筛选

| 筛选项 | 参数 | 说明 |
|--------|------|------|
| 视角 | `viewLevel`：公司 / 部门 / 个人 | 由采购数据范围 `purchaseDataScope` 限制 |
| 日期区间 | `dateFrom`～`dateTo` | 默认约 6 个月；**含首尾日** |
| 趋势粒度 | `groupBy` | 仅趋势图 |
| 部门 / 采购员 | `departmentId` / `purchaseUserId` | 部门、个人视角下可选 |

**通用过滤：**

- 采购订单 `status` **排除**：审核失败（-1）、取消（-2）。
- 采购明细：`is_deleted = false` 且 `status ≠ -2`。
- 报价明细：`is_deleted = false`，报价单未删除，明细 `status ≠ 1`（已取消）。
- **采购类指标日期**：`purchase_order.create_time`。**报价类指标日期**：`quote_item.create_time`，或回退 `quote.quote_date` / `quote.create_time`。
- **待办不受日期区间限制**。

**金额脱敏：** 无 `purchase.amount.read` 等时金额 KPI 为 `—`；币别分解改按订单数。

**跟单专属范围：** 报价类 KPI 为 0 或空；仅采购订单类指标有效。

---

## 二、待办 KPI

| 字段名称 | 统计公式 | 统计说明 |
|----------|----------|----------|
| 应付款金额 | `payment_amount_not` 按行 `FromExtend`（Cost/ConvertPrice 或财务汇率）→ `TotalUsd` | 数据范围内有效采购明细未付款 **折算美金**合计。与日期无关，为当前应付余额。 |
| 待入库明细数 | `COUNT(purchase_order_item.id)` 且 `stock_in_progress_status IN (0,1)` | 入库进度为待入库(0)或部分入库(1)的明细**行数**。 |

---

## 三、统计概览 KPI

| 字段名称 | 统计公式 | 统计说明 |
|----------|----------|----------|
| 报价条目数 | `COUNT(quote_item)` | 区间内创建的报价明细行数（报价列表数据范围 + 视角）。跟单专属→0。 |
| 报价供应商数 | `COUNT(DISTINCT quote_item.vendor_id)`（非空） | 区间内报价涉及的去重供应商数。 |
| 报价→采购转化率 | `已转化报价明细数 / 报价条目数 × 100` | **已转化**：报价明细经 `sell_order_item_extend.quote_item_id` 关联到 `purchase_order_item`。**分母为 0**→空。 |
| 采购订单条目数 | `COUNT(purchase_order_item)` | 区间内创建的采购有效明细行数。 |
| 采购供应商数 | `COUNT(DISTINCT purchase_order.vendor_id)` | 区间内采购订单去重供应商（含未审核 PO）。 |
| 成单金额（已审核） | `SUM(purchase_order.convert_total)`，`status >= 10` | 区间内创建且已审核通过的 PO 美元总额。**USD**。 |
| 已入库金额 | `SUM(qty_receive_total × convert_price)`（已审核 PO 明细） | 已入库数量 × 行折算单价，**折算美金**。 |
| 已付款金额 | 已审核 PO 明细 `payment_amount_finish` → `FromExtend` → `TotalUsd` | 明细已付款 **折算美金**合计。 |

## 四、趋势图

| 图表名称 | 统计公式（每桶） | 日期轴 | 统计说明 |
|----------|------------------|--------|----------|
| 成单金额趋势 | `SUM(convert_total)`，`status >= 10` | PO 创建日 | 美元成单额。 |
| 已入库金额趋势 | `SUM(qty_receive_total × convert_price)` | PO 创建日 | 折算美金已入库额。 |
| 已付款金额趋势 | 桶内 `payment_amount_finish` → `FromExtend` → `TotalUsd` | PO 创建日 | 折算美金已付款额。 |
| 报价条目趋势 | `COUNT(quote_item)` | 报价明细/报价日 | 跟单专属→0。 |
| 订单条目趋势 | `COUNT(purchase_order_item)` | PO 创建日 | 采购明细条数。 |
| 报价供应商数趋势 | `COUNT(DISTINCT vendor_id)` | 报价 | 桶内去重供应商。 |
| 采购供应商数趋势 | `COUNT(DISTINCT vendor_id)` | PO 创建日 | 桶内去重供应商。 |
| 转化率趋势 | 桶内已转化报价 / 桶内报价 × 100 | 报价 | 与概览同口径。 |
| 应付趋势 | 桶内已审核明细 `payment_amount_not` → `FromExtend` → `TotalUsd` | PO 创建日 | 折算美金未付款。**≠ 待办应付款**（待办含未审核且不按日）。 |

## 五、分解图

**展示约定：** 各分解图须同时显示 **绝对量 + 百分比**；纯比率（如报价→采购转化率趋势）除外。总规见 [`数据看板总要求.md` §3.7](../../IMP/数据看板/数据看板总要求.md)。

### 5.1 订单主状态（柱状）

| 统计公式 | 统计说明 |
|----------|----------|
| 按 `purchase_order.status` 分组；未脱敏 `SUM(convert_total)`，脱敏 `COUNT(PO)` | 区间内全部非取消/失败 PO。状态含：新建、待审核、审核通过、待确认、已确认、进行中、采购完成等。 |

### 5.2 币别金额（成单已审核）（饼图）

| 统计公式 | 统计说明 |
|----------|----------|
| `status >= 10`，按 `currency` 分组；未脱敏 `SUM(convert_total)`，脱敏 `COUNT(PO)` | 已审核采购成单币别分布。 |

### 5.3 全链路环节（明细行）（饼图）

| 统计公式 | 统计说明 |
|----------|----------|
| 已审核 PO 有效明细，互斥瓶颈 `COUNT(行)` | 待入库 → 待付款 → 待进项开票 → 已完结。 |

**分类规则：**

1. `stock_in_progress_status < 2` → 待入库  
2. 否则 `payment_progress_status < 2` 或 `payment_amount_not > 0` → 待付款  
3.  否则 `invoice_progress_status < 2` 或 `purchase_invoice_to_be > 0` → 待进项开票  
4. 否则 → 已完结  

### 5.4 入库进度（明细行）（柱状）

| 统计公式 | 统计说明 |
|----------|----------|
| 按 `stock_in_progress_status` 分组 `COUNT(行)` | 0=待入库，1=部分入库，2=入库完成。含未审核 PO 明细。 |

## 七、测试核对清单

1. 缩短日期：概览/趋势/分解/排行变化；**待办应付款、待入库明细数不随区间缩短而减少**（除非数据被权限改变）。
2. 取消(-2)、审核失败(-1) PO 不参与统计。
3. 成单金额、排行、币别分解、全链路仅 **status >= 10**。
4. 报价指标用报价时间轴；PO 指标用 **订单创建日**。
5. 转化率：核对 `quote_item` 是否已链到 `purchase_order_item`。
6. 脱敏：金额 `—`，币别饼图按单数。
7. 跟单专属：报价 KPI 全 0。
8. 分解占比：主状态 / 币别 / 全链路 / 入库进度均同时显示数值与百分比。
