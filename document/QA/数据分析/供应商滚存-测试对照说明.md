## 一、与库存滚存 MVP 的共用口径

入库/出库时间、状态、类型、USD 单价、数量与金额计算与 [库存滚存-测试对照说明.md](./库存滚存-测试对照说明.md) **一致**，本节仅补充**供应商维度**规则。

---

## 二、供应商维度

| 维度 | 规则 |
|------|------|
| 入库供应商 | `coalesce(stock_in.VendorId, stock_item.VendorId)`；皆空 → **未指定**（`vendorId` 空字符串） |
| 出库供应商 | `coalesce(stock_out_item_extend.VendorId, 入库供应商)` |
| 匹配 | 出库供应商 ≠ 入库供应商 → **整笔出库不计入**任一供应商 |
| 名称展示 | 有 `VendorId` 时查 `vendor_info`（OfficialName → NickName → EnglishOfficialName → Code） |
| 关键词 | 搜 `vendor_info` 中/英文名、官方名与 **Code** |
| 排序 | 供应商名称升序，「未指定」排最后 |

---

## 三、供应商滚存汇总（按月分页）

**查询参数：** `month`（必填）、`queryKeywords`（可选）、`page` / `pageSize`

**列表范围：** 仅包含「当月有入库/出库动静」或「上期数量/金额非零」的供应商。

**单行公式（选定月 M、供应商 V）：**

- 上期 = M 月之前（归属 V）累计入库 − 累计出库
- 本期入库 / 出库 = M 月内归属 V 的入库 / 出库（出库须通过维度匹配）
- 结余 = 上期 + 本期入库 − 本期出库

---

## 四、供应商明细滚存（按月 + 供应商分页）

**查询参数：** `month`（必填）、`vendorId`（必填，空串=未指定）、`queryKeywords`、`pn`、`stockInCode`、入库日期范围、`page` / `pageSize`

**数据范围：** 所选月内、归属该供应商的采购入库明细行，**以及**所选月内有匹配出库、但入库时间可早于该月的明细行（与汇总「本期出库」下钻一致）。

**本期入库：** 仅当 `stock_in.StockInDate` 落在所选自然月内时计入行上的入库数量/金额；早于该月入库的同行仍展示，本期入库显示 0，本期出库照常统计。

**出库统计：** 仅计入通过供应商维度匹配的出库流水（与汇总一致）。

单行公式与库存明细滚存相同。

**明细行 API 字段：** 含 `stockInId`（入库单主键）、`billCode`（入库单号）等，与 [库存滚存-测试对照说明 §三](./库存滚存-测试对照说明.md) 明细字段一致。

**前端交互：** 列表「入库单号」列有 `stockInId` 时为链接，单击进入入库单详情 `/inventory/stock-in/:id`（详见设计文档 **§ 十五 §15.8**）。

---

## 五、金额脱敏

与库存滚存、财务分析一致：`maskAmounts = true` 时金额字段为 `null`，前端显示 `—`。

---

## 六、验收步骤（建议）

1. 选有采购入库的月份，打开供应商滚存汇总，确认有数据的供应商出现。
2. 选一无 `VendorId` 的入库单月份，确认出现「未指定」行（若有动静或上期）。
3. 关键词搜供应商简称，列表仅保留匹配项。
4. 有 `vendor.read` 时，点击有 `vendorId` 的供应商**名称**，应进入供应商详情页（`/vendors/:id`）；无权限或身份屏蔽 / 模块隐藏时为纯文本。「未指定」行名称不可点。
5. 点击某供应商「明细」，核对入库行均归属该供应商。
6. 在供应商明细滚存页，有 `inventory.read` 时点击任一有数据的**入库单号**，应进入对应入库单详情（`/inventory/stock-in/:id`）。
7. 手工抽一条出库：若 extend 写入与入库不一致的 VendorId，汇总与明细均不应计入该供应商出库。

## 七、UI 与交互验收

> 细则见 [库存滚存-设计与实现.md](../../System/财务/库存滚存-设计与实现.md) **§ 十五**。

### 7.1 供应商滚存汇总

| # | 检查项 | 预期 |
|---|--------|------|
| 1 | 标题栏期间控件 | `[<]` 月份选择器 `[>]`；按钮提示「上一月」「下一月」 |
| 2 | 上一月 / 下一月 | 月份变更后列表刷新（含跨年） |
| 3 | 检索条 | `panel-search`：供应商关键词、查询、重置 |
| 4 | 表格列顺序 | 供应商 → 4 数量 → 4 金额(USD) → 操作 |
| 5 | 8 指标列等宽 | 表头完整显示；表格横向撑满内容区 |
| 6 | 单击行 | 选中高亮，不进入明细 |
| 7 | 双击行 | 进入 `/finance/vendor-accumulated/items`，携带 `month`、`vendorId`、`vendorName` |
| 8 | 操作列「明细」 | 单击进入对应供应商明细 |
| 9 | 供应商名称链接 | 有 `vendorId` + `vendor.read` + 模块可见：单击名称进入 `/vendors/:id`；「未指定」或无权为纯文本 |
| 10 | 单元格样式 | 结余数量橙粗、结余金额青粗、负数纷红；上期/本期金额正文色 |

### 7.2 供应商明细滚存

| # | 检查项 | 预期 |
|---|--------|------|
| 1 | 页头 | 左侧「返回汇总」；标题中**供应商名为琥珀色** |
| 2 | 返回汇总 | 保留当前 `month` |
| 3 | 检索条 | 与库存明细滚存相同的 `panel-search` 字段 |
| 4 | 列顺序 | 入库单号、物料型号、入库时间 → 4 数量 → 4 金额 |
| 5 | 入库单号链接 | 有 `stockInId` + `inventory.read`：单击 `billCode` 进入 `/inventory/stock-in/:id`；否则纯文本 |
| 6 | 单元格样式 | 与汇总页一致 |
