# 财务分析 — 测试对照说明

| 项 | 内容 |
|----|------|
| 菜单路径 | 数据分析 → 财务分析 |
| 路由 | `/reports/finance` |
| 汇率提示 | 美元折算按查询日财务参数汇率 |
| 应收提示 | 应收 todo 为已出库账上余额，与销售看板 extend 口径不同 |
| API | `GET /api/v1/analytics/finance/dashboard`、`/trends`、`/breakdowns` |

---

## 一、全局筛选

| 筛选项 | 参数 | 说明 |
|--------|------|------|
| 视角 | 公司 / 部门 / 个人 | A 类财务范围 / B 类仅销采归属（无公司 Tab） |
| 截至 | `dateTo` | **已完成** KPI 与趋势的区间**结束日** |
| 区间起 | `dateFrom` | **已完成** KPI 与趋势的区间**开始日**（默认约 5 个月前） |
| 区间止（页面日期范围控件末端） | **不传给分析 API** | 仅下钻列表用；改区间止**不改变**看板 KPI/趋势 |
| 趋势粒度 | `groupBy` | 按日/周/月 |

**金额 KPI 结构：** 每项含 `totalUsd`（折算美元，页面主数字）与 `byCurrency[]`（原币分项）。脱敏时 `totalUsd` 为空、`byCurrency` 为空数组。

**美元折算：**

- PO/SO 扩展字段：优先用行 `convertPrice/price` 比例折算；否则用查询时刻财务参数汇率。
- 财务单据、应收：`UnitLocalToUsd(原币金额, 币别, 当日 usdToCny/Hkd/Eur)`。

## 二、待办（页面标注「截至所选日期」，实际为当前余额）

> **重要：** 后端待办四类指标**不按 `dateTo` 截断**，为查询时刻的未结清余额。测试时勿期望「改截至日」改变待办数字（与已完成区不同）。

### 2.1 应付款

| 字段名称 | 统计公式 | 统计说明 |
|----------|----------|----------|
| 应付款（USD 主值 + 原币分项） | `SUM(purchase_order_item_extend.payment_amount_not)`，按币别分组后折算 USD | 有效采购订单明细的未付款余额。PO 非取消/非审核失败；明细未删除且非取消。归属采购员（B 类还可按供应商采购员）。与采购看板待办应付款同源 extend 字段。 |

### 2.2 应收款

| 字段名称 | 统计公式 | 统计说明 |
|----------|----------|----------|
| 应收款 | `SUM(finance_receivable.verified_to_be)`，`is_deleted=false` | **财务应收台账**上「待核销余额」，仅统计已产生账上应收（通常已出库后）。**≠ 销售分析**中的 `receipt_amount_not`（订单 extend 未收款，含未出库部分）。 |

### 2.3 待开进项发票

| 字段名称 | 统计公式 | 统计说明 |
|----------|----------|----------|
| 待开进项发票 | `SUM(purchase_order_item_extend.purchase_invoice_to_be)` | 采购明细「待开进项票」余额；过滤规则同应付款。 |

### 2.4 待开销项发票

| 字段名称 | 统计公式 | 统计说明 |
|----------|----------|----------|
| 待开销项发票 | `SUM(sellorderitemextend.invoice_amount_not)` | 销售明细未开票余额；销售订单非取消/失败；明细 `status=0` 且未删除。 |

## 三、已完成（区间内）

**时间窗口：** `[dateFrom, dateTo]`（`dateTo` = 页面「截至」），**不是**日期范围控件的「区间止」。

### 3.1 已付款

| 字段名称 | 统计公式 | 统计说明 |
|----------|----------|----------|
| 已付款 | `SUM(finance_payment.payment_amount)` | 付款单：`status=100`（付款完成）、未删除、`payment_date` 在区间内。按 `payment_currency` 汇总原币再折算 USD。**不是** PO extend 的 `payment_amount_finish`。 |

### 3.2 已收款

| 字段名称 | 统计公式 | 统计说明 |
|----------|----------|----------|
| 已收款 | `SUM(finance_receipt.receipt_amount)` | 收款单：`status=3`（已收款）、未删除、`receipt_date` 在区间内。按 `receipt_currency` 折算。**不是** `finance_receivable.verified_done`。 |

### 3.3 已开进项发票

| 字段名称 | 统计公式 | 统计说明 |
|----------|----------|----------|
| 已开进项发票 | `SUM(finance_purchase_invoice.invoice_amount)` | 进项发票：`is_deleted=false`，`red_invoice_status=0`，`invoice_date` 在区间内。金额按 **RMB** 口径折算 USD（与 PO 原币可能不一致）。 |

### 3.4 已开销项发票

| 字段名称 | 统计公式 | 统计说明 |
|----------|----------|----------|
| 已开销项发票 | `SUM(finance_sell_invoice.invoice_total)` | 销项发票：未删除，`make_invoice_date` 在区间内。金额按 **RMB** 口径折算 USD。 |

## 五、待办原币构成（饼图）

指标下拉：应付款 / 应收款 / 待开进项发票 / 待开销项发票 — 分别对应待办四项的 **`byCurrency` 原币金额**（非 USD）。

| 饼图扇区 | 统计公式 | 统计说明 |
|----------|----------|----------|
| 各币别扇区 value | 该待办指标下，按 `currency` 汇总的**原币金额** | 来自 dashboard 待办同一数据源。 |
| 占比 ratio | `该币别原币 / 各币别原币之和 × 100` | 2 位小数。 |

**展示约定：** 图例须同时显示 **原币金额 + 百分比**（总规见 [`数据看板总要求.md` §3.7](../../IMP/数据看板/数据看板总要求.md)）。

### 已知缺陷（测试记录）

- 后端分解组键：`currency:payableAmount`、`currency:receivableAmount` 等。
- 前端匹配：`currency:payable`、`currency:receivable` 等。
- **键名不一致时饼图可能始终显示「暂无币别构成数据」**，即使 Network 中 breakdowns 有数据。核对时请以 API 响应 `groupKey` 与 UI 是否渲染为准。

## 六、视角与脱敏

| 模式 | 说明 |
|------|------|
| A 类（财务范围） | 公司/部门/个人按财务数据范围 |
| B 类（销采归属） | 无公司 Tab；采购侧按 `purchase_user_id`，销售侧按 `sales_user_id` |
| 金额脱敏 | 缺采购/销售金额读及财务单据读等时，全部 `totalUsd` 为 `—`，饼图为空，不可下钻 |

## 七、测试核对清单

1. **待办 vs 已完成时间语义**：改「截至」应影响已完成四项与趋势；**待办四项不应随之变化**（后端无日期截断）。
2. **区间止无效**：只改日期范围末端，KPI/趋势不变；下钻列表可能使用该末端。
3. **应收 vs 销售看板**：同一客户应用 `finance_receivable.verified_to_be` 与 SO `receipt_amount_not` 分别核对，预期可不同。
4. **已付/已收**：以付款单、收款单为准，不以 PO/SO extend 已付/已收字段为准。
5. **已完成区间**：`[区间起, 截至]`，与下钻列表日期参数可能不一致，分别记录。
6. **汇率**：折算用**查询时刻**财务汇率，非历史截至日汇率。
7. **进项/销项已完成票**：按 RMB 折算规则，与待办 extend 币别可能不同。
8. **饼图 groupKey**：验证是否存在前后端键名不匹配（见第五节）。

## 八、与销售/采购看板对照

| 指标 | 财务分析 | 销售/采购分析 |
|------|----------|---------------|
| 应收/应付待办 | 财务应收台账 / PO extend 未付 | 销售 extend 未收 / 同 PO extend |
| 已收/已付 | 收款单/付款单日期区间 | extend 已收/已付，按**订单创建日**区间 |
| 发票 | 财务发票单日期区间 | 销售分析仅「待开票 extend」 |
