## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有 `analytics-logistics.read` 或 `inventory.read` | 可进入物流分析 |
| 两码皆无 | 无菜单 / 无法进入 |
| 待入库下钻 | 需 `purchase-order.read` |
| 在库 / 出入库概况下钻 | 需 `inventory.read` |
| 入库金额原币「查看」 | 另需物流模式 + 公司视角 + 库存类型 `all` + 未 `maskAmounts`；无则整卡不可点且无「查看」 |
| 出库金额原币「查看」 | 另需物流模式 + 公司视角 + 库存类型 `all` + 未 `maskSalesAmounts`；无则整卡不可点且无「查看」 |
| 无 `purchase.amount.read` 或采购 511 脱敏 | `maskAmounts=true`：在库金额、**入库金额**、矩阵/排行金额为 `—`；页面仍能加载；入库金额无「查看」 |
| 无 `sales.amount.read` 或销售 521 脱敏 | `maskSalesAmounts=true`：**出库金额**为 `—`；入库金额不受影响；出库金额无「查看」 |

**本功能不适用：** 工作台左栏队列（§4.3）、列表页签模式 / 操作面板门控（§4.4）、多租户打印皮肤（§4.6）。  
**本功能不适用：核销/匹配提交的足额成功 + 超额拒绝（§4.5）** — 本页为看板统计，无核销或匹配提交。

## 二、全局筛选

| 筛选项 | 参数 | 说明 |
|--------|------|------|
| 视角 | 公司 / 部门 / 个人 | 物流数据范围 + 销采归属模式（B 类用户可能无「公司」Tab） |
| 库存类型 | `all` / `customerOrder` / `purchaseStock` | 全部 / 客单库存 / 采购库存（按 `stock_type` 或 PO 类型过滤） |
| 截至日期 | `dateTo` | **在库概览、库龄、矩阵、排行** 的库龄计算截止日 |
| 趋势区间 | `dateFrom`～`trendDateTo` | **出入库概况** + **入库/出库数量趋势**（未传 `trendDateTo` 时回落 `dateTo`） |
| 趋势粒度 | `groupBy` | 按日/周/月（仅趋势图） |
| 矩阵科目 | `matrixSubject` | 客户矩阵子列：销售员 / 供应商 / 采购员 / 品牌 |

**在库行纳入条件：**

- `stock_item.qty_repertory > 0`，未删除。
- 关联 `stock_in` 未删除。
- 排除调拨源类型 `transfer_type = ManualTransferSource`。
- 库龄：`max(0, dateTo − stock_in.stock_in_date)`（自然日）。

**金额：** `在库金额 = qty_repertory × purchase_price_usd`（USD 采购成本）。无采购金额读权限时 `maskAmounts=true`，金额显示 `—`。

## 三、待办 KPI

| 字段名称 | 统计公式 | 统计说明 |
|----------|----------|----------|
| 待入库数量(PCS) | `SUM( max(0, poi.qty − extend.qty_receive_total) )` 四舍五入为整数 | 采购订单有效明细的「订购量 − 已收货量」剩余之和。**当前 PO  backlog**，不受 `dateTo` 限制。仅统计未取消 PO、未取消明细、剩余 > 0。受库存类型（客单/备货 PO）与采购数据范围过滤。 |

**测试注意：** 不含「到货通知在途未建 PO 收货」等阶段；与在库快照是不同概念。

## 四、出入库概况（趋势区间 `dateFrom`～`trendDateTo`）

板块位于「待办」与「在库概览」之间。主数字为折算美金，可「查看本币」。

| 字段名称 | 统计公式 | 统计说明 |
|----------|----------|----------|
| 入库金额 | 原币：`SUM(入库数量 × 采购单价)` 按币别；`totalUsd`：`SUM(入库数量 × PurchasePriceUsd)` | 已过账采购入库（类型 10 或历史 1）；日期=`stock_in.StockInDate`；数量取入库行 `Quantity`。美金为**入库过账快照**，不按查询日汇率重算。 |
| 出库金额 | 原币：`SUM(出库数量 × 销售单价)` 按币别；`totalUsd`：`SUM(出库数量 × SalesPriceUsd)` | 仅状态 **4 出库完成** 的销售出库（类型 10 或历史 1）；日期=`stock_out.StockOutDate`；数量取出库行 `Quantity`。美金为**出库过账快照**；快照为空则该行美金为 0。 |

**纳入 / 排除：**

- 入库排除报关/退货/报废/调拨；须已过账。
- 出库排除准备出库(2)、报关/退货/报废/调拨。
- 库存类型三档与在库一致（样品仅「全部」）。

**测试注意：**

1. 改趋势起止应改变两卡；改截至日期、趋势区间结束不变时，两卡不应仅因截至日而变。
2. 客单 / 采购库存 / 全部 三套分别核对。
3. 入库卡脱敏与出库卡脱敏可不同（采购金额权 vs 销售金额权）。
4. **入库金额下钻（原币「查看」）**：非整卡点击。仅物流 `accessMode=logistics` + 公司视角 + 库存类型全部 + 未脱敏 + `inventory.read` 时，原币行右侧出现「查看」（右对齐）。点 RMB/USD（及其他 `byCurrency`）跳转 `/inventory/stock-in`：`stockInType=10`、`stockInDateStart`/`End` = 趋势起止（填入「入库日期」控件）、隐藏 `status=2`、隐藏 `itemCurrency`（筛选栏无币别/状态下拉）。列表顶栏有说明条与「退出下钻」；强制列表态；导出带上述隐藏条件。部门/个人、销采归属模式、客单/采购库存、511/`maskAmounts`、无 `inventory.read` 时均无「查看」。折算美元行无「查看」。
5. **出库金额下钻（原币「查看」）**：非整卡点击。仅物流 `accessMode=logistics` + 公司视角 + 库存类型全部 + 未 `maskSalesAmounts` + `inventory.read` 时，原币行右侧出现「查看」（右对齐）。点 RMB/USD（及其他 `byCurrency`）跳转 `/inventory/stock-out/items`：`stockOutType=10`、`stockOutDateFrom`/`To` = 趋势起止（填入「出库日期」控件）、筛选栏 **显示** `status=4`（出库完成）、隐藏 `salesCurrency`（筛选栏无币别下拉）。列表顶栏有说明条与「退出下钻」；强制列表态。部门/个人、销采归属模式、客单/采购库存、521/`maskSalesAmounts`、无 `inventory.read` 时均无「查看」。折算美元行无「查看」。出库明细列表 **无 CSV 导出按钮**；隐藏币别随 `GET /api/v1/stock-out/items` 与列表看板请求下发。

**入库金额原币「查看」对照：**

| 步骤 | 预期 |
|------|------|
| 物流模式 + 公司视角 + 库存类型全部 + 未脱敏 + `inventory.read` | 入库金额整卡不可点；原币行右侧有「查看」 |
| 点某一原币「查看」 | 进入 `/inventory/stock-in`：采购入库、入库日期=趋势起止（填入日期控件）、隐藏 `status=2` 与 `itemCurrency`（筛选栏无币别/状态）；顶栏说明条 +「退出下钻」；强制列表态 |
| 列表请求 | `GET /api/v1/stock-in` 含 `status=2`、`itemCurrency`、`stockInType=10`、`stockInDateStart`/`End` |
| 导出 | 同上隐藏条件一并带上 |
| 「退出下钻」 | URL 去掉 `drill` / `status` / `itemCurrency`；保留入库类型与入库日期 |
| 库存类型改为客单或采购库存 | 无「查看」 |
| 部门 / 个人，或 `accessMode=salesPurchaseOnly` | 无「查看」 |
| 采购 511 / `maskAmounts`，或无 `inventory.read` | 无「查看」 |
| 折算美元主数字 | 无「查看」 |

**出库金额原币「查看」对照：**

| 步骤 | 预期 |
|------|------|
| 物流模式 + 公司视角 + 库存类型全部 + 未销售脱敏 + `inventory.read` | 出库金额整卡不可点；原币行右侧有「查看」 |
| 点某一原币「查看」 | 进入 `/inventory/stock-out/items`：销售出库、出库日期=趋势起止、状态下拉为出库完成(4)、隐藏 `salesCurrency`；顶栏说明条 +「退出下钻」；强制列表态 |
| 列表请求 | `GET /api/v1/stock-out/items` 含 `status=4`、`salesCurrency`、`stockOutType=10`、`stockOutDateFrom`/`To` |
| 「退出下钻」 | URL 去掉 `drill` / `salesCurrency`；保留状态 4、销售出库与出库日期 |
| 库存类型改为客单或采购库存 | 无「查看」 |
| 部门 / 个人，或 `accessMode=salesPurchaseOnly` | 无「查看」 |
| 销售 521 / `maskSalesAmounts`，或无 `inventory.read` | 无「查看」 |
| 折算美元主数字 | 无「查看」 |

**本功能不适用：§4.5 足额/超额核销**（无提交金额）。

## 五、在库概览 KPI（截至 `dateTo`）

| 字段名称 | 统计公式 | 统计说明 |
|----------|----------|----------|
| 在库商品数量 | `SUM(qty_repertory)` | 符合范围的在库行现存数量合计（PCS）。 |
| 在库商品金额 | `SUM(qty_repertory × purchase_price_usd)` | USD 采购成本总值；脱敏为 `—`。 |
| 加权平均库龄 | `ROUND( Σ(库龄天×数量) / Σ(数量), 1 )` | 按数量加权的平均在库天数；总量为 0 时为空。库龄起算日为**入库日**。 |
| 客户数 | `COUNT(DISTINCT customer_id)`（非空） | 有客户锚点的在库行涉及的去重客户数；**无客户_id 的备货行不计入**。 |
| 销售员数 | `COUNT(DISTINCT salesperson_id)`（非空） | 去重销售员数。 |
| 供应商数 | `COUNT(DISTINCT vendor_id)`（非空） | 去重供应商数。 |
| 采购员数 | `COUNT(DISTINCT purchaser_id)`（非空） | 去重采购员数。 |
| 品牌数 | `COUNT(DISTINCT purchase_brand)`（非空） | 去重品牌数。 |

## 六、库龄分布（饼图）

| 桶名称 | 统计公式 | 统计说明 |
|--------|----------|----------|
| 0–30天 | `SUM(qty)`，`库龄 ≤ 30` | 按**数量**占比，非金额。 |
| 31–90天 | `SUM(qty)`，`31 ≤ 库龄 ≤ 90` | 同上。 |
| 91–180天 | `SUM(qty)`，`91 ≤ 库龄 ≤ 180` | 同上。 |
| 181–365天 | `SUM(qty)`，`181 ≤ 库龄 ≤ 365` | 同上。 |
| 365天以上 | `SUM(qty)`，`库龄 > 365` | 同上。 |

**占比：** `ratio = 桶数量 / 总在库数量 × 100`。五桶数量之和应等于「在库商品数量」。

**展示约定：** 图例须同时显示 **数量 + 百分比**（占比类补绝对量；总规见 [`数据看板总要求.md` §3.7](../../IMP/数据看板/数据看板总要求.md)）。

## 七、出入库数量趋势

分桶区间与出入库概况相同：`dateFrom`～`trendDateTo`；`groupBy` 控制日/周/月。

| 字段名称 | 统计公式 | 统计说明 |
|----------|----------|----------|
| 入库数量（每周期） | `ROUND(SUM(入库行 Quantity))` per period，`stock_in_date ∈ [周期)` | 与 **入库金额** 同窗同单据：已过账采购入库（类型 10/1）；数量取入库行 `Quantity`，不含金额乘积。 |
| 出库数量（每周期） | `ROUND(SUM(出库行 Quantity))` per period，`stock_out_date ∈ [周期)` | 与 **出库金额** 同窗同单据：状态 4 销售出库（类型 10/1）；数量取出库行 `Quantity`。 |

**测试注意：**

1. 各 period 入库件数之和应等于同窗 **入库金额** 对应行的数量总和（与金额卡独立核对）。
2. 各 period 出库件数之和应等于同窗 **出库金额** 对应行的数量总和。
3. 改趋势起止应同时改变两趋势图与出入库概况两卡；改截至日（趋势结束不变）不应单独改变趋势图。

**API 字段 `pendingStockInQty`：** 一期恒为 0，页面不展示，无需测试。

## 八、客户 × 统计科目矩阵

**父行（客户锚点）：** 按 `customer_id` 分组；无客户显示「无客户 / 备货」。

| 父行字段 | 统计公式 | 统计说明 |
|----------|----------|----------|
| 在库数量 | 组内 `SUM(qty_repertory)` | 该客户锚点下 PCS 合计。 |
| 在库金额 | 组内 `SUM(qty × purchase_price_usd)` | USD；脱敏为 `—`。 |
| 加权平均库龄 | 组内按数量加权平均库龄 | 同概览公式。 |

**子行（统计科目）：** 由 `matrixSubject` 决定分组键。

| matrixSubject | 子列标题 | 分组键 | 空值显示 |
|---------------|----------|--------|----------|
| salesperson | 销售员名称 | `salesperson_id` | 未分配销售员 |
| vendor | 供应商名称 | `vendor_id` | 未分配供应商 |
| purchaser | 采购员名称 | `purchaser_id` | 未分配采购员 |
| brand | 品牌名称 | `purchase_brand` | 未填品牌 |

子行指标公式与父行相同，在「客户 + 科目」子集上计算。父行数量应等于其子行数量之和（同一锚点内）。

**排序：** 父行、子行默认按在库金额降序（脱敏时按数量）。

## 十、测试核对清单

1. **截至日期**：改变 `dateTo` 应改变在库数量、金额、库龄、矩阵、排行；**待入库 PCS 与出入库概况不应仅因改截至日而变**（趋势结束不变时）。
2. **趋势区间**：改变起止应改变出入库概况两卡与入库/出库数量趋势；在库快照不随趋势起止单独变化（截至日不变时）。
3. **库存类型**：客单/采购/全部 三套数据分别核对；样品库存等仅在「全部」出现。
4. **库龄**：手工抽一行：`dateTo − stock_in_date` 与桶归属一致。
5. **矩阵**：切换科目会重新请求 API；子行合计=父行。
6. **趋势 vs 快照 vs 流量**：趋势与出入库概况按区间；快照按 `dateTo` 时点存量。
7. **脱敏**：采购侧金额为 `—` 时入库金额/在库金额/矩阵/排行金额为 `—`；仅销售侧脱敏时仅出库金额为 `—`。
8. **下钻**：入库/出库金额均用原币「查看」（见第四节）。客单/采购库存下两卡均无「查看」（列表无 `stock_type` 筛，属有意门控）。

## 十一、已知口径差异

| 差异 | 说明 |
|------|------|
| 出库金额 ≠ 销售分析「已出库金额」 | 物流卡：仓库出库完成日 + 仅状态 4 + 过账 `SalesPriceUsd`。销售卡：销售订单创建日 + 数量含准备出库(2)与完成(4) + `qty × convert_price`。 |
| 入库金额 ≠ 采购分析「已入库金额」 | 物流卡：入库单过账日 + 行数量 × 入库美金快照。采购卡：PO 创建日 + `qty_receive_total × convert_price`。 |
| 入库金额 ≠ 在库商品金额 | 前者为区间入库流量；后者为截至日现存 `qty_repertory ×` 采购美金。 |
| 入库趋势 vs 在库快照 | 入库趋势为区间入库单件数；在库为截至日 `qty_repertory`。已全部出清的入库不计入在库，但发生在趋势窗内仍计入入库趋势。 |
| 入库金额原币「查看」列表 ≠ KPI 该币合计 | KPI 按明细行金额分币；列表是单头。混币入库单只要含该原币行即入列，列表金额列含其他币明细。 |
| 出库金额原币「查看」数量口径 | KPI 用出库行 `Quantity`；列表数量优先 `ActualQty`，否则 `Quantity`。 |
| 下钻列表可能更宽 | **入库金额「查看」**已带已过账 `status=2` 与明细原币。**出库金额「查看」**已带出库完成 `status=4`、销售出库与隐藏销售原币。因库存类型门控，两路径都不再因客单/采购库存放宽。 |

## 十二、权限与上线

- 页面：`analytics-logistics.read` 或 `inventory.read`
- 待入库下钻：`purchase-order.read`
- 在库 / 出入库概况下钻：`inventory.read`
- 入库金额原币「查看」：上项 + 物流公司视角 + 库存类型全部 + 未采购脱敏
- 出库金额原币「查看」：上项 + 物流公司视角 + 库存类型全部 + 未销售脱敏
