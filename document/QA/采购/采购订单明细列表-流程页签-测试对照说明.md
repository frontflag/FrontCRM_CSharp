> **页面 / 路由：** `/purchase-order-items`、采购订单详情 `/purchase-orders/:id`  
> **设计文档：** [采购订单明细列表-流程页签-设计与实现](../../System/采购/采购订单明细列表-流程页签-设计与实现.md)  
> **UI 规范：** [流程页签规范](../../PRD/规范/UI规范/流程页签规范.md)、[流程页签.当前业务指示规范](../../PRD/规范/UI规范/流程页签.当前业务指示规范.md)  
> **权限：** 采购订单读（`purchase-order.read`）；与操作面板共用选中行 / aggregates，见 [操作面板-测试对照说明](./采购订单明细列表-操作面板-测试对照说明.md)

## 一、前置

- 账号可打开采购订单明细列表（非脱敏账号便于看供应商与金额）
- 右栏可见页签：**操作 / 流程 / 帮助**
- 采购订单详情右栏同样有 **操作 / 流程 / 帮助**；流程与列表同面板，由详情内选中（或默认首条）明细驱动；「采购订单明细」站标题旁有当前业务指示
- Network 可过滤 `detail-tab-aggregates`

---

## 二、交互门控

| 步骤 | 预期 |
|------|------|
| **A** 收起右栏后单击行 | 不展开、不选中、无 aggregates 请求 |
| **B** 展开 →「帮助」→ 单击行 | 行高亮；仍停在帮助；无请求 |
| **D** 在 B 之后点「流程」 | 出现（或复用）aggregates；展示纵向流程轴；「采购订单明细」站标题旁有橙色左指手势（当前业务指示），轨道仍为状态色圆点 |
| **C** 已在「流程」下单击另一行 | 请求/切换到新行；轴内容更新 |
| 在「操作」已加载后切「流程」 | **不再强制重复请求**；内容与同行一致 |
| 脱敏账号 | 单击不选中、不请求 |

---

## 三、节点与展示抽查

| 步骤 | 预期 |
|------|------|
| 站序 | 采购申请 → 采购明细 → 申请付款 → 付款 → 到货通知 → 质检 → 入库 → 进项发票 |
| 无下游的新明细 | 「采购明细」有卡；多数下游为空心「未开始」；无销售关联时「采购申请」亦空 |
| 有多张请款单 | 「申请付款」同站多卡，创建时间 **早→晚**；已取消不出现 |
| 已付款单据 | 「申请付款」与「付款」均可看到该单号 |
| 各站 | 「采购订单明细」站：**无**独立「供应商编号」行；供应商名称通栏，文案 `{名称} ({编号})`（例 `Acme Semi (V001)`）。其它站仍为「供应商名称 / 供应商编号」两格（有数据或行回退时） |
| 供应商可点 | 有 `vendor.read`（非身份屏蔽、未隐藏供应商管理）且卡上有供应商 ID：名称悬停橙色、无下划线、手型；点击 **新开页** 进供应商详情。无权限或脱敏：纯文本 |
| 创建日期 | `yy-MM-dd`（两位年、无时分），例 `26-08-01`；空为 `—` |
| 单号 | 默认同正文、无下划线；悬停橙色；点击仍跳转（非列表主题蓝链） |
| 申请付款 / 付款 / 进项发票 | 显示 **金额·币别**，不显示数量 |
| 到货 / 质检 / 入库 | 显示数量；不显示单价 |
| 入库卡片 | 第一行 **单号** 通栏；第二行左 **入库类型**、右 **状态**。采购入库显示「采购入库」，报关入库显示「报关入库」，移库显示「移库」，未识别显示「未知」（不得写成采购入库） |
| 描述 | 为空或隐藏 |
| 窄右栏 | 无横向滚动 |

---

## 四、站态

| 步骤 | 预期 |
|------|------|
| 某站无任何单据 | 空心 +「未开始」 |
| 某站有单据且存在未终态 | 实心进行中 |
| 某站全部单据终态 | 实心已完成 |

---

## 五、回归交叉

- 操作面板行为不被破坏（通知到货 / 申请付款仍在「操作」）。
- 双击行仍进入采购订单详情。
- 采购订单详情右侧「流程」入库卡布局与列表页一致。
- 脱敏（511）时供应商与金额为 `—`，流程轴仍加载。

## 六、本功能不适用（总纲强制项）

| 维度 | 说明 |
|------|------|
| 金额 / 核销 / 匹配（总纲 §4.5） | 本功能不适用：流程页签只读，无金额提交、核销或匹配 |
| 多租户打印皮肤（总纲 §4.6） | 本功能不适用 |
| 左栏 shortcut preset | 本功能不适用：本对照覆盖右栏流程，不含左栏检索 |
| 工作台左栏队列（总纲 §4.3） | 本功能不适用：本页非审批/核销桌面 |
| 上线 SQL / 迁移 | 本功能不适用：仅前端展示，无新权限码、无 DDL |
