## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 1 | 参数管理 → 采购参数 | 左栏可见「分面刷新」（原「刷新供应商」位置） |
| 2 | 无 read | 左栏无此项、不可进入 |
| 3 | 有 read 无 write | 可看五个开关，保存 403 或按钮不可用 |
| 4 | 有 write | 可保存 |

**本功能不适用：** 工作台/桌面（§4.3）、列表页签/操作面板（§4.4）、多租户皮肤/打印（§4.6）、金额核销提交（§4.5，本页只开关，不提交核销）。无需新 SQL / 迁移；改完不必重新登录（§4.7）。

---

## 二、页面与默认

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 进入分面刷新 | 五个开关：刷新供应商 / 物料型号 / 品牌 / 数量 / 单价 |
| 2 | 未配置过 | 供应商 = 不允许（沿用现网：改已完结客商身份风险高）；型号、品牌、数量、单价 = 允许（避免上线后行为倒退） |
| 3 | 改若干项并保存，刷新页面 | 保持刚保存的组合 |
| 4 | 只改供应商开关并保存 | 旧「允许刷新已完成业务节点」接口读到的值与供应商开关一致 |

---

## 三、业务联动

| 场景 | 开关 | 预期 |
|------|------|------|
| PO 下游有已入库到货且供应商不一致 | 供应商不允许 | 刷新供应商被阻断 |
| 同上 | 供应商允许 | 预检列出已完结单据；详情须确认才同步 |
| 有库存明细 | 型号不允许 | 刷新物料型号拦住 |
| 同上 | 型号允许 | 列出库存明细等，确认后覆盖并换堆 |
| 到货已入库 | 数量不允许 | 刷新数量拦住 |
| 入库已过账 / 已进项匹配 | 单价不允许 | 刷新单价拦住 |
| 行已完结 | （任意） | **刷新状态**仍可进行，不看本页开关 |

编辑采购订单换供应商保存：不要求详情页的确认标志；参数关时仍按原换供应商阻断。

---

## 四、回归

- 报价人数 / 报价员池 / 默认分配方式（含「允许指定采购」勾选） / 需求保护不受影响  
- 销售参数「刷新客户」不受影响  
- 开关为不允许时，原换供应商阻断口径不变
