# 采购订单明细列表 — 左栏检索 — 测试对照说明

> **页面：** `/purchase-order-items`  
> **设计文档：** [采购订单明细列表-左栏检索-设计与实现](../../System/采购/采购订单明细列表-左栏检索-设计与实现.md)

---

## 一、入口与布局

| 步骤 | 预期 |
|------|------|
| 进入 `/purchase-order-items`，左栏切到「检索」 | 四组：时间 / 待办 / 付款 / 入库 |
| 无 preset | 主栏可见日期 + 四维进度 |
| 选任一 preset | 主栏 chip 显示文案；日期与四维进度隐藏 |

交叉：页签模式与 preset 见 [筛选页签模式-测试对照说明](./采购订单明细列表-筛选页签模式-测试对照说明.md)。

---

## 二、交互

| 步骤 | 预期 |
|------|------|
| 点击「待提交审核」 | URL 含 `preset` + `quickFilter=pending_submit_audit`；列表刷新 |
| 再点同一项 / chip ✕ | **清空全部 query**，恢复默认列表 |
| 选 preset 后填型号点查询 | URL 保留 preset + `pn`；列表与看板均带该条件 |
| 「采购订单/明细号」输入主单号 | 命中该单下明细；placeholder 为「采购订单/明细号」；无「销售订单明细单号」输入框 |
| 「采购订单/明细号」输入明细号 | 命中对应采购明细行 |
| 选「近 7 日订单」 | URL 含 `preset=order_last_7_days`、`startDate/endDate`；**无** `quickFilter` |

---

## 三、业务口径抽查

| preset | 预期（摘要） |
|--------|----------------|
| 待提交审核 | 主单状态为新建/待审核/审核失败；无取消行 |
| 待供应商确认 | 主单 `status=20` |
| 待提交付款申请 | 可点「申请付款」的行（主单已确认、未付清、有可请款余额） |
| 待提交到货通知 | 主单已确认，且仍可通知到货数量 > 0 |
| 后付款订单 | 主单勾选后付款；可含进行中等非取消状态 |
| 已确认，未付款 | 主单已确认 + 付款进度未付 |
| 已入库 | 入库进度部分或完成 |
| 时间 preset | 仅限日期，**可含取消单**（与主栏选日期一致） |

---

## 四、看板

| 步骤 | 预期 |
|------|------|
| 选业务 preset 后切看板 | 看板请求带同一 `quickFilter` / keyword |
| 选时间 preset 后切看板 | 看板带同一 `startDate/endDate` |
