# 采购订单明细列表 — 左栏检索 — 测试对照说明

> **页面：** `/purchase-order-items`  
> **设计文档：** [采购订单明细列表-左栏检索-设计与实现](../../System/采购/采购订单明细列表-左栏检索-设计与实现.md)

文档筛选结果仍受采购订单数据权限约束，不会露出无权订单。

---

## 一、入口与布局

| 步骤 | 预期 |
|------|------|
| 进入 `/purchase-order-items`，左栏切到「检索」 | 五组：时间 / 待办 / 文档 / 付款 / 入库；「文档」仅为分组标题，不可点选 |
| 无 preset | 主栏可见日期 + 四维进度 |
| 选任一 preset | 主栏 chip 显示文案；日期与四维进度隐藏 |

交叉：页签模式与 preset 见 [筛选页签模式-测试对照说明](./采购订单明细列表-筛选页签模式-测试对照说明.md)。

---

## 二、交互

| 步骤 | 预期 |
|------|------|
| 点击「待提交审核」 | URL 含 `preset` + `quickFilter=pending_submit_audit`；列表刷新 |
| 再点同一项 / chip ✕ | **清空全部 query**，恢复默认列表 |
| 选 preset 后填型号点查询 | URL 保留 preset + `pn`；列表与看板均带该条件 |
| 「采购订单/明细号」输入主单号 | 命中该单下明细；placeholder 为「采购订单/明细号」；无「销售订单明细单号」输入框 |
| 「采购订单/明细号」输入明细号 | 命中对应采购明细行 |
| 选「近 7 日订单」 | URL 含 `preset=order_last_7_days`、`startDate/endDate`；**无** `quickFilter` |
| 点击「有上传文档」 | URL 含 `preset=has_purchase_order_docs`、`quickFilter=has_purchase_order_docs`；左栏「文档」组该项高亮；chip 文案为「有上传文档」 |

---

## 三、业务口径抽查

| preset | 预期（摘要） |
|--------|----------------|
| 待提交审核 | 主单状态为新建/待审核/审核失败；无取消行 |
| 待供应商确认 | 主单 `status=20` |
| 待提交付款申请 | 可点「申请付款」的行（主单已确认、未付清、有可请款余额） |
| 待提交到货通知 | 主单已确认，且仍可通知到货数量 > 0 |
| 后付款订单 | 主单勾选后付款；可含进行中等非取消状态 |
| 已确认，未付款 | 主单已确认 + 付款进度未付 |
| 已入库 | 入库进度部分或完成 |
| `has_purchase_order_docs` | 点「有上传文档」：详情「文档」Tab 有附件、且至少两行明细的订单 → **该单全部未取消明细**均在列表中；无附件订单的行不出现 |
| `no_purchase_order_docs` | 点「未上传文档」：详情「文档」Tab 无附件（或仅软删）的订单，其未取消明细均在列表；有附件订单的行不出现 |
| 时间 preset | 仅限日期，**可含取消单**（与主栏选日期一致） |

---

## 四、看板

| 步骤 | 预期 |
|------|------|
| 选业务 preset 后切看板 | 看板请求带同一 `quickFilter` / keyword |
| 选时间 preset 后切看板 | 看板带同一 `startDate/endDate` |
| 选「有上传文档」后切看板 | 看板带 `quickFilter=has_purchase_order_docs`；同一采购单多行会一起进看板 |

交叉：同一采购单有 1 份附件、3 行明细时，「有上传文档」应出现 3 行，不是 1 行。导出摘要为「有上传文档」/「未上传文档」。

---

## 五、采购敏感掩码

| 步骤 | 预期 |
|------|------|
| 采购敏感掩码账号进入列表 | 供应商 keyword 按既有规则隐藏或脱敏；preset（含「文档」组）与列表仍可用 |

---

## 六、本功能不适用

- **本功能不适用：工作台 / 桌面左栏队列（总纲 §4.3）。** 本页是列表左栏 preset，不是审批/核销桌面。
- **本功能不适用：金额提交 / 核销 / 匹配的足额成功与超额拒绝（总纲 §4.5）。** 快捷检索无金额提交。
- **本功能不适用：多租户皮肤 / 打印（总纲 §4.6）。** 不改打印与租户皮肤。
- **本功能不适用：上线前置 SQL / 迁移（总纲 §4.7）。** 无新表；发含本改动的 API + Web 即可。
