# 采购订单明细列表 — 采购利润 — 测试对照说明

> **页面 / 路由：** 采购管理 → 采购订单明细 `/purchase-order-items`；备货采购清单 `/stocking-purchase-items` 共用列；报关单详情「业务记录」嵌入采购表时同样有该列  
> **设计文档：** [采购订单明细列表-采购利润-设计与实现](../../System/采购/采购订单明细列表-采购利润-设计与实现.md)  
> **审核对照：** [审批桌面-测试对照说明](../审批/审批桌面-测试对照说明.md) 第五节（同一公式）  
> **导出对照：** [销售与采购订单明细列表导出-测试对照说明](../销售/销售与采购订单明细列表导出-测试对照说明.md)  
> **权限：** 进入列表需采购订单查看权限；本列仅跟采购金额权限（与单价、明细总额相同）。511 脱敏隐藏本列。**无新权限码。**

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有采购订单查看 + 有采购金额权限 | 列表模式可见「采购利润」列，在「明细总额」之后，单位 USD |
| 无采购订单查看权限 | 不能进入列表 |
| 有列表权限、无采购金额权限（或 511） | 单价、明细总额、采购利润均不显示；列表仍能加载 |
| 无销售金额权限、有采购金额权限 | **仍显示**采购利润（不要求销售金额权限） |
| 切到看板 | **无**采购利润 KPI / 排行；本列只在列表 |

---

## 二、列表展示

| 步骤 | 预期 |
|------|------|
| 客单采购行：有关联销售，两侧折算美金单价 &gt; 0 | 采购利润 =（销售折算美金单价 − 采购折算美金单价）× 本行数量，USD **2 位** |
| 采购折算价高于销售折算价 | 显示**负数**，不是 — |
| 无关联销售（备货 / 样品 / 手工行） | **—**，不是 0 |
| 有关联但任一侧折算美金单价缺失或 ≤ 0 | **—** |
| 一条销售对应两条采购 | 两行各自用**本行**采购折算价 × 本行数量；单行不必等于销售行 `PurchaseProfitExpected` |
| 列显隐 / 列宽拖动后刷新 | 与该列表既有列记忆一致（本列可隐藏；默认在明细总额后） |

Network：列表 `GET /api/v1/purchase-orders/items`（或既有明细列表接口），行字段 `purchaseProfitUsd`；无法计算时为 `null`。

---

## 三、口径 / 公式核对

```text
采购利润 = (销售折算美金单价 − 采购折算美金单价) × 本行采购数量
```

| 项 | 手工复算 |
|------|----------|
| 销售折算美金单价 | 关联销售明细 `convert_price` |
| 采购折算美金单价 | 本采购行 `convert_price` |
| 数量 | 本行「数量」列 |

四舍五入到分（远离 0）。**不是** EBS「销售总额 − 采购总额」，也**不是**销售明细 `PurchaseProfitExpected`（销售行下全部采购合计）。

与采购订单审核明细同一公式。审核 tip 文案为「销售单价折算USD / 采购单价折算USD」，数字应对上本列。

## 四、导出

| 步骤 | 预期 |
|------|------|
| 有金额权限导出采购订单明细 | CSV 在「行金额币别」之后有 **采购利润(USD)**；数值与列表一致（— 导出为空） |
| 511 / 无金额权限导出 | 该列为空 |
| 备货采购清单导出 | 同样有 **采购利润(USD)**；无销售关联的行为空 |

固定全量列，不跟列表列显隐。其它导出门控见导出对照说明。

---

## 五、数据范围与回归

| 步骤 | 预期 |
|------|------|
| 采购数据范围为「仅本人」 | 只出现范围内的行；本列不扩大可见行集 |
| 备货采购清单 | 有金额权限时可见本列；备货行通常为 — |
| 报关单详情 · 业务记录采购表 | 与主列表同一列定义，有金额权限时可见本列 |
| 采购订单审核 | 中栏 / 右栏「采购订单」页签数字与列表本行一致（同一公式） |
| 销售订单明细绩效 / 销售行采购利润 | **不必**与本列单行相等（销售行合计口径） |

## 六、本功能不适用

- **本功能不适用：§4.5 核销金额足额成功 / 超额拒绝**（本列只展示，不提交核销/匹配）。
- **本功能不适用：工作台 / 桌面左栏队列（§4.3）**（本功能是列表列；审核桌面见审批对照）。
- **本功能不适用：操作面板门控（§4.4 操作面板）**（点行拉操作/流程与本列无关）。
- **本功能不适用：多租户打印皮肤（§4.6）**。
- **本功能不适用：看板公式 / KPI**（明确不做看板统计）。

页签模式仍适用：**看板无此列，列表有此列**；F5 后看板/列表偏好与既有页签对照说明一致。
