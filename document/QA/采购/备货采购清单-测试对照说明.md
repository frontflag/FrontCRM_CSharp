# 备货采购清单 — 测试对照说明

> **页面 / 路由：** 采购管理 → 备货采购清单 `/stocking-purchase-items`；详情 `/stocking-purchase-items/:id`  
> **设计文档：** [备货采购清单-设计与实现](../../System/采购/备货采购清单-设计与实现.md)  
> **权限：** `purchase-order.read` + 采购侧身份（采购部 / 采购助理 / 采购运营或对应扩展角色）；无新权限码、无迁移

---

## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 采购部职员（有采购订单读权限）打开系统 | 采购管理下「采购订单明细」之后出现 **备货采购清单** |
| 采购助理 / 采购运营（有采购订单读权限） | 同样可见菜单，可进列表 |
| 系统管理员 | 可见、可进 |
| 仅物流/销售身份，即使有采购订单读权限 | **无**该菜单；直链 `/stocking-purchase-items` 回控制台 |
| 采购数据范围为「禁止」 | 不可进 |
| 无采购订单读权限的采购部人员 | 不可进 |

Network：列表 `GET /api/v1/purchase-orders/stocking-items`；导出 `GET /api/v1/purchase-orders/stocking-items/export`。

---

## 二、数据范围与脱敏

| 步骤 | 预期 |
|------|------|
| 采购员 A 的数据范围为「本人」，同事 B 有一张备货采购单 | A 在 **本页** 能看到 B 的备货明细（不受采购员约束） |
| 同上，A 打开 **采购订单明细** | 仍只看到范围内的单（含自己的备货行）；两页不一致属设计 |
| 客单采购 / 样品采购明细 | **本页不出现** |
| 金额脱敏角色 | 采购单价/行金额为 `—` 或 0，列表仍能加载；供应商名按现有采购脱敏 |
| 无库存读权限 | **仍显示**可用库存数量（本列不要求库存权限） |

---

## 三、列表与可用库存数量

| 步骤 | 预期 |
|------|------|
| 打开页面 | 标题「备货采购清单」；无看板切换、无左栏快捷筛选、无行勾选列；列名是「采购数量」「采购单价」「可用库存数量」；搜索栏有「有可用库存」勾选（默认不勾） |
| 勾选「有可用库存」 | 列表只剩可用库存数量 **大于 0** 的行；合计条数变小；Network 带 `hasAvailableStock=true` |
| 勾选后刷新页面（F5） | 勾选保持，结果仍只含可用库存数量 > 0 |
| 取消勾选 / 点重置 | 又出现可用库存数量为 0 的行；重置后勾选关闭 |
| 操作列 | 仅「详情」；无通知到货、申请付款 |
| 筛选订单类型 | **无**该下拉（已锁定备货） |
| 有备货库存的 PN+品牌 | 「可用库存数量」= 该 PN+品牌备货类型可用量合计（与库存中心同料备货可用量加总一致，手工移库源行不计） |
| 两张备货单同一 PN+品牌 | 两行可用库存数量 **相同** |
| PN 或品牌为空 | 可用库存数量为 0 |
| 列宽拖动后刷新 | 保持（独立于采购订单明细的列宽记忆） |

---

## 四、详情只读

| 步骤 | 预期 |
|------|------|
| 点「详情」或双击行 | 进入 `/stocking-purchase-items/:id`，并选中该明细行 |
| 详情页按钮 | **无**打印、编辑、删除、通知到货、申请付款、录入货代单号 |
| 从本页打开他人备货单 | 可查阅；改用地址栏打开 `/purchase-orders/:id` 且无该单数据范围时，写操作仍失败（原采购订单页权限不变） |

右侧辅助栏仅「帮助」，无操作/流程页签。

---

## 五、导出

| 步骤 | 预期 |
|------|------|
| 设筛选后点导出并确认 | 下载 CSV，文件名含「备货采购清单」；表头为「采购数量」「采购单价」「可用库存数量」 |
| 勾选「有可用库存」后导出 | CSV 行也仅含可用库存数量 &gt; 0 的记录 |
| 无金额权限 | 采购单价/金额列为空或掩码 |

导出日志可查到业务类型「备货采购清单」。

---

## 六、口径 / 公式核对

```text
列表行 = 采购订单明细 JOIN 主单 AND 主单 Type = 2
采购数量 = 采购订单明细 Qty（与采购订单明细页「数量」同源）
采购单价 = 采购订单明细 Cost（与采购订单明细页「单价」同源）
可用库存数量 = Σ(备货 StockType=2 且非手工移库源行 的 QtyRepertoryAvailable)
         匹配键 = Trim(PN) + Trim(品牌)，不区分大小写
勾选「有可用库存」→ 仅保留可用库存数量 > 0 的行
无匹配或键不完整 → 0（勾选「有可用库存」时这些行不出现）
```

**本功能不适用：金额核销/匹配足额成功与超额拒绝**（本页不提交金额、不核销）。

**本功能不适用：看板 / 左栏 preset / 页签模式与操作面板交叉**（首期无看板、无左栏检索、无操作面板）。筛选页签模式若开启（币别/进度），刷新后应保持（独立 localStorage 键，不含订单类型）。

**本功能不适用：多租户打印皮肤**（详情不提供打印）。

## 七、已知口径差异

| 项 | 说明 |
|------|------|
| 与采购订单明细比 | 本页备货行全员可见；采购订单明细仍按采购员范围。同一人两页看到的备货行可以不一致，属设计 |
| 可用库存数量 | 是 PN+品牌备货池可用量合计，不是本行采购数量、也不是本行已入库数 |
| 列名 | 仅本页叫「采购数量 / 采购单价 / 可用库存数量」；采购订单明细仍叫「数量 / 单价」 |

## 八、回归 / 交叉

| 步骤 | 预期 |
|------|------|
| 采购订单明细页 | 行为不变：仍按采购员范围；仍有到货/付款/看板；列名仍是「数量」「单价」；**无**「有可用库存」勾选 |
| 备货采购清单改列宽 | 不影响采购订单明细列宽 |
| 从清单进详情后再回列表 | 回到备货采购清单，不是采购订单明细 |
