# 采购订单后付款 — 测试对照说明

> **设计文档：** [采购订单后付款-设计与实现](../../System/采购订单后付款-设计与实现.md)  
> **前置：** 库表已执行 `scripts/ensure_purchaseorder_is_pay_later_postgresql.sql`（或等价迁移）

---

## 一、新建采购订单

| 步骤 | 预期 |
|------|------|
| 进入新建页 | 基本信息有「后付款」勾选，默认**未勾选**；旁有注释图标 |
| 鼠标移到注释图标 | tip：**客户付款后再给供应商付款** |
| 勾选「后付款」 | 勾选区域出现**橙色底** |
| 取消勾选 | 橙色底消失 |
| 勾选后保存新建 | 保存成功；详情标题区出现橙色 Tag「后付款」；hover tip 同上 |
| 不勾选保存 | 详情**无**「后付款」Tag |

---

## 二、编辑采购订单

| 步骤 | 预期 |
|------|------|
| 打开已勾选后付款的订单编辑 | 勾选为选中，橙色底可见 |
| 取消勾选并保存 | 详情 Tag 消失 |
| 再勾选并保存 | 详情 Tag 恢复 |
| 订单已确认且页面仍可编辑其它主表字段时 | 「后付款」仍可改（与编辑权限一致） |

---

## 三、申请付款（不拦截）

| 步骤 | 预期 |
|------|------|
| 后付款订单，满足原有申请付款条件 | **仍可**发起申请付款（无因后付款被禁用或阻断） |

---

## 四、边界

| 步骤 | 预期 |
|------|------|
| 采购订单列表 | 首期**无**「后付款」列、**无**筛选 |
| 供应商主数据账期 | 勾选后付款**不改变**供应商账期天数 |
| 历史订单（上线前） | 视为未勾选后付款 |
