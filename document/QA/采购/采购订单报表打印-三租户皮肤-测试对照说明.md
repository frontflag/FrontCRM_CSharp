## 一、入口与权限

| 步骤 | 预期 |
|------|------|
| 有采购订单查看权限，从列表或详情点「打印订单」 | 打开 `/purchase-orders/:id/report`，三栏与明细可见 |
| 无采购订单权限 | 进不了详情/报表，或回控制台 |
| 采购员**无**报表参数管理权限 | 仍能打开打印；Network 可见 `effective-style-version` 返回 200（非 403）；版式按生效版本 |
| 采购金额脱敏（无 `purchase.amount.read`） | 单价、数量、合计等金额为 `—`；版式仍加载；V2 汇总运费格亦为 `—` |
| 本页无提交按钮 | 无核销/匹配/保存 |

## 二、V1 / V2 切换

全局参数在「参数管理 → 报表参数」维护。打印页加载时读一次；改参数后须**重新打开/刷新报表页**才变。

| 步骤 | 预期 |
|------|------|
| 从未配置或非法值 | 打印为 **V1**（现网三租户皮肤） |
| 参数为 V1，打开打印 | 现网版式：卖方/买方/交付三栏；明细列与上线时一致 |
| 改为 V2 并保存，在 **semicore** 构建包刷新打印页 | 图1/PDF 版式：藏青顶栏底，「采购订单」白字 **16pt**，「PURCHASE ORDER」青色 **6.5pt**，「订单编号 / PO NO.」白字 **7pt**，右侧斜纹底纹，顶栏下青色渐变横线；条款浅底卡片；需方签章在左 |
| 改为 V2 并保存，在 **idesemi / ecoinf** 构建包刷新打印页 | **与该租户 V1 相同**（不换 PDF 版式） |
| 再改回 V1，刷新打印页 | 回到现网版式 |
| 改参数后不刷新已打开的打印页 | 仍显示打开时的版本（不在工具栏即时切换） |
| 销售订单 / 发票打印 | **本功能不适用其消费该参数**：版式不变 |
| 装箱单打印 | semicore 竖/横随参数（见 [装箱单对照](../物流/装箱单PackingList打印-三租户皮肤-测试对照说明.md)）；idesemi/ecoinf 仍 V1 |

## 三、范围与皮肤

在 **semicore / idesemi / ecoinf** 构建包打开 `/purchase-orders/:id/report`，与同租户 Packing List 对照。V1 三租户都要看；V2 只验收 **semicore 换版、另外两租户不变**。

| 检查项 | 期望 |
|--------|------|
| 租户差异（V1） | 三套观感明显不同（不只换 Logo） |
| 与 Packing 对齐 | 同租户 V1 主色一致。semicore 在 V2 时为 PDF 藏青/青，不再要求与 Packing 顶栏同构 |
| semicore | V1：深色顶栏（约 `#0D1F35`）。V2：藏青顶栏 + 白字「采购订单」16pt + 青色「PURCHASE ORDER」6.5pt |
| idesemi | V1：左大标题「采购订单」、右 Logo、青竖条。参数 V2 时**仍为此版式** |
| ecoinf | 绿强调（约 `#A8D070`）。参数 V2 时**仍为此版式** |
| 签章 | 印章在买方 / 需方侧（V2 左侧） |
| 打印 / PDF / 邮件 | 壳层隐藏；色块保留；截取 `.po-doc` |

同租户若仍为旧橙色而 Packing 已为新色系 → 不通过。

## 四、明细行（空白行）

| 步骤 | 预期 |
|------|------|
| 仅 1 行明细（如 `PO00262`） | 明细表只有这一行，紧接下方是「总计」（有金额权限时）；**无**补齐空行，**无**「以下空白」 |
| 多行明细（≥6） | 只打印实际行，行间无空行垫高 |
| 无明细 | 显示「暂无明细」，无空行、无「以下空白」 |

## 五、V2 顶栏字号与订购明细列宽

仅 **semicore + 参数 V2**。度量以 [报表规范-采购订单-V2](../../PRD/规范/业务规范/报表规范-采购订单-V2.md) §5.1、§5.5 为准。idesemi / ecoinf 不做本节。

| 步骤 | 预期 |
|------|------|
| 看顶栏右侧标题 | 「采购订单」白字 **16pt**；「PURCHASE ORDER」青字 **6.5pt**、宽字距；「订单编号 / PO NO.」白字 **7pt** |
| 看订购明细表头 | 藏青底、列间无白竖线。「序号」与「No.」、「数量」与「Qty」各占两行，**不得**按单字竖折；「批号 / Lot No.」「单价」「金额 / Amount」整格可读 |
| 看订购明细数据行 | 序号、批号、数量、单价、金额不折成竖条（如 `106,000`、`0.35` 一行）；MPN、厂牌不折行；「规格及描述」为最宽弹性列，可折行 |
| 先打开装箱单 V2（竖或横）再打开本页并刷新 | 订购明细列宽仍同上，不被装箱单检验表/明细的同名 class 带偏 |

## 六、V2 字段不丢

仅在 **semicore** 用同一张已确认采购订单，先看 V1 再切 V2 对照。idesemi / ecoinf 在参数为 V2 时不做本节（版式与 V1 相同）。

| V1 已出现 | V2 期望 |
|-----------|---------|
| Logo、我方公司名 | 顶栏 Logo；需方公司名 |
| 单号、日期 | 顶栏 PO NO + 元数据订单日期 / 采购单号 |
| 供应商名称/地址/电话 | 供方栏 |
| 我方名称/地址 | 需方栏；公司资料有联系人/电话/邮箱则填，否则 `—` |
| 收货人 + 收货地址 | 交付「交货地址 / Ship To」 |
| 最晚交期 | 交货日期 |
| 运输方式「送货/物流/快递」 | 贸易条款 / Incoterms |
| 「运费承担：供方承担」 | 文件要求旁保留 |
| 付款方式（订单备注） | 付款条款 / PAYMENT |
| 序号、产品名称、规格、品牌、单位、币种、数量、含税单价、税率、行金额 | V2 明细八列对齐 PDF：序号 / MPN(规格) / 厂牌 / 批号 / 规格及描述(产品名称) / 数量 / 单价 / 金额；币种在元数据，税费在汇总；单位不单列 |
| 总计数量、含税合计 | 表下总计 |
| 不含税 / 增值税 / 价税合计 | 汇总小计 / 税费 / 总额 |
| 服务条款全文 + 24 小时确认 | 条款区保留；文首法律效力句 |
| 合同编号 | `—`（无独立字段） |
| 汇总运费金额 | `—`（不编造 0.00） |

| 买方签章日期 | V1 需方印创建日；**V2 需方、供方「日期」均为下划线**，不印 `2026年8月23日` 这类创建日 |

抬头切换、含印章开关：V1/V2 行为与改版前一致。

## 七、口径 / 公式核对

本页**只展示**订单已落库金额，不提交核销或匹配。

```text
行含税合计 = 数量 × 含税单价
价税合计 = Σ行含税合计
不含税金额、增值税由订单税率拆分展示
```

| 用例 | 预期 |
|------|------|
| **足额（展示金额 = 订单行合计）** | 总计含税与订单一致（如 400 × 0.5926 = 237.04）；V2 总额与 V1 价税合计相同 |
| 超额 / 核销提交 | **本功能不适用：无核销、匹配、付款提交** |
