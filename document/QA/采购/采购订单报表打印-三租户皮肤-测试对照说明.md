## 1. 范围

在 **semicore / idesemi / ecoinf** 构建包打开 `/purchase-orders/:id/report`（列表「打印订单」或详情「打印订单」），与同租户 Packing List 对照。

---

## 2. 通过标准

| 检查项 | 期望 |
|--------|------|
| 租户差异 | 三套观感明显不同 |
| 与 Packing 对齐 | 同租户页眉/主色一致 |
| semicore | 深色顶栏（约 `#0D1F35`） |
| idesemi | 左大标题「采购订单」、右 Logo；青竖条 |
| ecoinf | 绿表头/附加条（约 `#A8D070`） |
| 签章 | 印章在买方（Buyer）侧 |
| 打印 / PDF / 邮件 | 壳层隐藏；色块保留 |

同租户若仍为旧橙色而 Packing 已为新色系 → 不通过。
