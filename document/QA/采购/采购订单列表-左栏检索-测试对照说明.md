# 采购订单列表 — 左栏检索 — 测试对照说明

> **页面 / 路由：** 采购管理 → 采购订单 `/purchase-orders`  
> **设计文档：** [采购订单列表-左栏检索-设计与实现](../../System/采购/采购订单列表-左栏检索-设计与实现.md)  
> **权限 / DDL：** 无新权限码、无新迁移。须部署含本改动的 API + Web。

文档筛选结果仍受采购订单数据权限约束，不会露出无权订单。

---

## 一、入口与布局

| 步骤 | 预期 |
|------|------|
| 进入 `/purchase-orders`，左栏切到「检索」 | 五组：时间 / 待办 / 文档 / 付款 / 入库；「文档」仅为分组标题，不可点选 |
| 主栏 | 订单类型 / 订单号 / 供应商 / 采购员 / 货代单号 / 备注；无 preset 时另有状态多选与创建日期 |
| 左栏不再是 | 空面板（此前仅明细列表有快捷检索） |

---

## 二、preset 与 URL

| 步骤 | 预期 |
|------|------|
| 点击「待提交付款申请」 | URL 含 `preset=pending_submit_payment_request`、`quickFilter=pending_submit_payment_request`；左栏高亮；主栏 chip 同文案；状态与日期隐藏 |
| 再点同一项或 chip ✕ | **清空全部 query**（含订单号等 keyword） |
| 选 preset 后填订单号、选「客单采购」点搜索 | URL 保留 preset + `code` + `orderType=1`；列表与看板均带 |
| 选「近 7 日订单」 | URL 含 `preset=order_last_7_days`、`startDate/endDate`；**无** `quickFilter` |
| 点击「有上传文档」 | URL 含 `preset=has_purchase_order_docs`、`quickFilter=has_purchase_order_docs` |

---

## 三、口径

| preset | 预期 |
|--------|------|
| `pending_submit_audit` | 主单新建、待审核或审核失败的订单 |
| `pending_vendor_confirm` | 主单待确认的订单 |
| `pay_later` | 主单勾选后付款的订单 |
| `has_purchase_order_docs` | 详情「文档」有未删除附件的订单；一单一行 |
| `no_purchase_order_docs` | 无附件（或仅软删）的订单 |
| `pending_submit_payment_request` 等行级项 | **该单至少一行**满足明细列表同口径则整单出现；同一订单只出现一次 |
| 时间 preset | 仅限主单创建日，可含取消单 |

交叉：同一采购单有 1 份附件、3 行明细时，订单列表「有上传文档」出现 **1 行**（明细列表为 3 行）。

---

## 四、看板

| 步骤 | 预期 |
|------|------|
| 选业务 preset 后切看板 | 看板带同一 `quickFilter` |
| 选时间 preset 后切看板 | 看板带同一 `startDate/endDate` |
| 选 preset 且订单类型为客单 | 看板同时带 `orderType=1` |

看板成单 KPI 仍按既有「审核通过及以上」口径，在当前筛选结果上再裁。

## 六、本功能不适用

- **本功能不适用：工作台 / 桌面左栏队列（总纲 §4.3）。** 本页是列表左栏 preset。
- **本功能不适用：金额提交 / 核销 / 匹配的足额成功与超额拒绝（总纲 §4.5）。** 快捷检索无金额提交。
- **本功能不适用：多租户皮肤 / 打印（总纲 §4.6）。** 不改打印与租户皮肤。
- **本功能不适用：上线前置 SQL / 迁移（总纲 §4.7）。** 无新表；发含本改动的 API + Web 即可。
