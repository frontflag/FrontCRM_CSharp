# 采购订单列表 — 右侧操作面板 — 测试对照说明

> **页面 / 路由：** 采购管理 → 采购订单 `/purchase-orders`  
> **设计文档：** [采购订单列表-操作面板-设计与实现](../../System/采购/采购订单列表-操作面板-设计与实现.md)  
> **门控规范（权威）：** [销售操作面板 §2.4](../../System/销售订单明细列表-操作面板-设计与实现.md)  
> **权限 / DDL：** 无新权限码、无新迁移。须部署含本改动的 Web。

文档筛选结果仍受采购订单数据权限约束；脱敏账号仍应能打开面板。

---

## 一、入口与布局

| 步骤 | 预期 |
|------|------|
| 进入 `/purchase-orders`，打开右侧辅助栏 | 页签为 **操作 / 帮助**；默认停在 **操作**（含旧「帮助」记忆） |
| 未点行 | 操作页签空态：「单击列表行查看采购订单与文档」 |
| 已在「操作」下单击一行 | 最上为「采购订单」卡片，其下为「文档」（非掩码账号） |
| 看板视图 | 无行可点；操作页签保持空态 |

---

## 二、交互门控（§2.4）

| 步骤 | 预期 |
|------|------|
| **A** 收起右侧辅助栏后单击某行 | 右栏**不**自动展开；Network **无**文档列表请求 |
| **B** 展开右栏 → 切到「帮助」→ 单击某行 | 仍停在「帮助」；Network **无**文档列表请求 |
| **D** 在 B 之后再点「操作」页签 | 出现文档列表请求（非掩码）；面板为采购订单 + 文档 |
| **C** 已在「操作」页签下单击另一行 | 立即按新订单拉文档；面板内容更新 |
| **E** 在「操作」页签下先选中一行 → 收起右栏 → 再展开 | 默认切到 **「操作」**；若选中仍在 store 则沿用 |
| **F** 选中行后点「搜索 / 重置」刷新列表 | 操作面板回到空态；需重新单击行 |

---

## 三、采购订单卡片

| 步骤 | 预期 |
|------|------|
| 编号与状态 | 同一行各约一半宽；编号可进该采购订单详情 |
| 状态 | 主单状态；**审核通过**或**待确认**时状态后浅灰斜体「（等待供应商确认）」；已确认及之后只显示状态 |
| 供应商 | 卡片最下一行加粗；脱敏为 `—` |
| 一单一行 | 同一订单只对应一张卡，不出现明细行字段（PN/数量等），无申请付款 / 到货通知 |

---

## 四、文档卡片

| 步骤 | 预期 |
|------|------|
| 有附件 | 标题「（n）」；展开可预览或确认下载 |
| 无附件 | 「（无上传）」；展开提示目前暂未有上传文档 |
| 与详情「文档」 | 同一订单、同一份数 |

---

## 五、mask511

| 步骤 | 预期 |
|------|------|
| 脱敏账号点行 | 采购订单卡仍出现；供应商名为 `—`；**不**显示文档卡 |

---

## 六、回归 / 交叉

| 步骤 | 预期 |
|------|------|
| 采购订单明细「操作」 | 仍为行级申请付款 / 到货通知，不受本页影响 |
| 采购订单详情「操作」 | 仍须点底部明细行 |
| 左栏检索 | 筛选与操作面板独立；点行仍须满足右栏「操作」门控才拉文档 |

---

## 七、本功能不适用

- **本功能不适用：工作台 / 桌面左栏队列（总纲 §4.3）。** 本页是列表右栏操作。
- **本功能不适用：金额提交 / 核销 / 匹配的足额成功与超额拒绝（总纲 §4.5）。** 本面板只读，无金额提交。
- **本功能不适用：多租户皮肤 / 打印（总纲 §4.6）。** 不改打印与租户皮肤。
- **本功能不适用：上线前置 SQL / 迁移（总纲 §4.7）。** 无新表；发含本改动的 Web 即可。
