# 采购订单状态流转（产品摘录）

对照实现：[采购订单主状态](../../../System/采购订单主状态.md)、[采购订单取消确认-设计与实现](../../../System/采购/采购订单取消确认-设计与实现.md)。

## 供应商确认

**待确认 → 已确认**

采购订单列表中，若主状态是 **待确认**，操作列显示「供应商确认」。点击后主状态改为 **已确认**。

## 取消确认

**已确认 → 待确认**（不是取消整张订单）

列表操作列与详情顶栏，仅当主状态是 **已确认** 时显示「取消确认」。确认后主单与明细回到 **待确认**，可再次点「供应商确认」。

若本单已有有效付款（含在途请款）、到货通知、已过账采购入库或进项发票，系统拦住并提示先处理这些单据。货代单号不影响。

「取消订单」只用于审核通过之前（新建 / 待审核 / 审核失败），把整单置为取消；与「取消确认」不是同一操作。
