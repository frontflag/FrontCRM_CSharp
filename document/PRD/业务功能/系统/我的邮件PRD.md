## 1. 背景与目标

员工在 FrontCRM 内处理个人/平台邮箱的往来信：收信、阅读、写信、回复、本地归档（星标/备注/草稿/删除），并把询盘类正文交给已有「解析需求」流程。

本板块是**个人工作台**，邮件按登录用户隔离。不替代完整邮箱客户端，也不改邮箱服务器上的已读、星标、删除。

---

## 2. 用户与入口

| 项 | 说明 |
|----|------|
| 使用者 | 已登录员工 |
| 入口 | 侧栏「我的」→「我的邮件」 |
| 前置 | 在「我的邮箱」至少配置并**验证成功**一条邮箱；公司需配置 IMAP 与最早同步日期后，平台邮箱才能收信 |
| 无邮箱 | 左栏提示「请设置个人邮箱」，写信/收信/通讯录/文件夹/筛选全部不可用 |

---

## 3. 功能范围

### 3.1 邮箱与同步

- 左栏下拉只列出**已验证**邮箱；默认第一项；记住该用户上次选择，不可清空为「全部」。
- **收信 / 读取邮件**：只同步当前选中邮箱的收件箱；完成后主区切到收件箱列表。
- 系统每日上午 08:30（上海时区）自动同步已验证 IMAP 邮箱；不拉取公司「最早同步邮件日期」之前的信。
- 同步只更新收件箱内容，**不覆盖**本系统星标、备注。

### 3.2 文件夹

| 文件夹 | 行为 |
|--------|------|
| 收件箱 | 显示本系统已同步的收件；名称后带未读数（含 0） |
| 草稿箱 | 本系统未发出的稿；双击回到写信页续写 |
| 已发送 | 本系统发出的信（不写回服务器已发送） |
| 已删除 | 本系统隐藏的信；可恢复；邮箱服务器原信仍在 |

未读数只统计收件箱。

### 3.3 列表与检索

- 主区列：已读/未读图标、星标、发件人、标题（后附正文起始摘要）、邮件备注、发送日期。
- 图标列、发件人列收窄到能看清内容；剩余宽度给标题，便于看摘要。
- 搜索匹配：标题、发件人、正文、摘要、备注、收件人。
- 左栏筛选：全部 / 未读 / 已读 / 星标 / 备注 + 收件日期；范围限于当前邮箱与当前文件夹。
- 单击选中；双击进入正文（草稿箱双击进入写信）。

### 3.4 阅读与本地标记

- 打开正文后本地标为已读，不改服务器已读。
- 「设置全部已读」：把**当前邮箱 + 当前文件夹**全部未读标为已读（不限当前页）。
- 星标、邮件备注只存在本系统；同步不丢失；不写回服务器。
- 备注最多 2000 字；有内容才能保存；已有备注才能清除（需确认）。空保存不能用来清空。
- 右栏当前信若有备注，在「内容提取」下方只读展示。

### 3.5 写邮件、回复、草稿

- 写信占主区。发件人只读，展示左栏当前选中邮箱地址。
- 实际发出走登录用户**默认平台邮箱**的 SMTP（展示发件人与真实发信账号可以不同）。
- 收件信息（发件人/收件人/抄送）与主题正文分属两块面板。
- 工具栏：左侧「返回」；右侧「保存草稿」「发送」（已有草稿时可删）。
- 回复：收件人=原发件人，主题补 `Re:`，正文引用原文。
- 草稿至少填收件人、主题或正文之一即可保存；再保存更新同一封；发出后本系统删除该草稿。
- 465 端口按隐式 SSL 发信。

### 3.6 删除与恢复

- 删除只从本系统列表隐藏，不删服务器邮件。
- 已删除中可「恢复到收件箱」（草稿恢复后仍在草稿箱）。
- 同步不会把本地已删的同一封再插回收件箱。

### 3.7 通讯录

- 列出当前数据权限范围内、有邮箱的客户/供应商联系人。
- 可按姓名、邮箱、公司名搜索。单击选中，双击写信并预填收件人。

### 3.8 内容提取

- 右栏「内容提取」把当前邮件正文交给已有「解析需求」流程，确认后进入新建需求。
- 需具备解析需求的业务权限，且已选中或打开一封邮件。

---

## 4. 本系统与邮箱服务器的边界

| 本系统做 | 本系统不做（本期） |
|----------|-------------------|
| 拉取收件箱并落库检索 | 改服务器已读 / 星标 / 删除 |
| 本地草稿、已发送、软删 | 把草稿/已发送写回 IMAP |
| 本地备注、星标、全部已读 | 附件下载落盘、发信带附件 |
| SMTP 发出新信/回复 | 完整抄送在正文页展示（正文页抄送显示「—」） |

侧栏菜单「草稿箱」（客户/供应商/需求草稿）与邮件草稿箱不是同一功能。

---

## 5. 界面要点

- 工作台：左「邮箱 / 收件列表」，右「邮箱功能 / 帮助」；进入默认左邮箱、右邮箱功能。
- 正文页：工具栏左右分置（左返回，右删除 + 蓝色回复）；邮件头、正文、备注为独立面板。
- 列表工具栏：搜索与查询在左，「读取邮件」「写邮件」在右。
- 左栏收件卡片本期不显示星标、备注、标题摘要。

---

## 6. 验收口径

- 无已验证邮箱时不能写信/收信，并引导去「我的邮箱」。
- 收信只同步当前选中邮箱，并回到收件箱列表。
- 打开未读信后面封图标变已读；「设置全部已读」后当前文件夹未读清零。
- 星标、备注在再次同步后仍在。
- 搜索能命中备注内容。
- 保存草稿后可在草稿箱打开续写；发送成功后草稿消失、已发送可看到。
- 删除后收件箱不再出现，已删除可恢复；服务器原信仍在。
- 有解析需求权限时，可从当前邮件进入新建需求。
