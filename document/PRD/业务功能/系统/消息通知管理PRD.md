## 1. 背景与目标

系统管理员需要把一条短消息发给**指定员工**（例如临时提醒、个别交代），而不是全员公告。接收人应在顶栏铃铛里看到，可稍后阅读，**不能**挡住登录。

本期做到：发送即送达、重要未读时铃铛摇动、未读计入铃铛角标、点开即已读、可一键全部已读。

---

## 2. 用户与入口

| 项 | 说明 |
|----|------|
| 发送人 | 仅系统管理员（SuperAdmin）。无独立权限码。 |
| 管理入口 | 侧栏 **运维管理** 组，紧挨「用户反馈」之后：「消息通知管理」。非管理员菜单不出现，直链进不去。 |
| 接收人 | 任意已登录员工看**发给自己**的通知。 |
| 用户入口 | 顶栏铃铛 → 右侧抽屉 Tab「系统消息」。 |
| 模拟登录 | 不摇铃铛、角标按 0、可浏览正文，但**不记已读**（含全部已读）。 |

---

## 3. 功能范围

### 3.1 发送（管理端）

- 右上角「发送消息」：选一名**启用中**员工，可勾选「重要」，填标题，正文可空，可附最多 9 张图片后发送。
- **发送即落库**，立刻出现在管理列表和对方铃铛里。
- 标题最多 100 字；正文最多 4000 字、纯文本；**正文与图片至少填一项**（允许只发图）。
- 图片：jpg / png / webp / gif，单张不超过 8MB，最多 9 张。发出后不能改图、不能删图。
- 一次只发给一个人。发出后不能改、不能撤回、不能删。
- 接收人下拉只列启用员工（账号 / 姓名）；停用、冻结不出现。发送时后端再校验一次。
- 「重要」提示：接收人未读时顶栏铃铛会摇动。库字段仍为 `is_urgent`，界面一律称「重要」。

### 3.2 管理列表与查询

| 列 | 规则 |
|----|------|
| 重要 | 仅重要行显示红色纸飞机图标；普通行为空 |
| 已读 | 已读绿 tag、未读橙 tag；管理端点开**不**改对方已读 |
| 接收人 | `账号 / 姓名`（无姓名则只显示账号） |
| 标题 | 全文 |
| 内容摘要 | 正文去空白后前 80 字，超出加「…」 |
| 发送时间 | 按显示时区 `YYYY-MM-DD HH:mm` |

- 已读行文字变灰；已读 tag 保持绿色。
- 筛选：是否重要、是否已读、接收人、标题或正文关键字、发送日期区间；可重置。
- 点行看完整标题 + 正文 + 附图；弹窗提示「管理端查看不会把对方标为已读」。无正文时只显示图片。

### 3.3 用户铃铛与「系统消息」

- 抽屉 Tab：**系统消息** \| **系统公告**。
- 打开抽屉：当前有未读系统通知 → 默认「系统消息」；否则默认「系统公告」。
- 系统消息卡片两行：第 1 行重要图标 + 标题，日期右对齐；第 2 行正文摘要（无正文则显示「N 张图片」）。整卡可点。
- 详情：正文（若有）+ 缩略图，点图全屏浏览。
- 列表日期：今日 / 昨日 + `HH:mm`，其它 `YY-MM-DD HH:mm`。详情日期：`YYYY-MM-DD HH:mm`。
- **点开卡片即记已读**（打开详情并调已读接口）。只开抽屉不点卡片仍未读。
- 已读卡片文字与图标变灰；悬停浅黄底。
- 各 Tab 未读角标：该类未读条数，超过 20 显示 `20+`。
- 底部「设置全部已读」：把当前 Tab 对应类型的未读全部标已读（系统消息 / 系统公告各调各自接口）。无未读时按钮不可用。
- **不**强制弹窗、**不**挡登录。系统通知不会出现在公告强制窗里。

### 3.4 顶栏角标与摇动

| 项 | 规则 |
|----|------|
| 角标数字 | 未读系统通知数 + 未读系统公告数 |
| 超过 20 | 显示 `20+`（不是 `99+`） |
| 摇动 | 仅当存在 **未读且重要** 的系统通知 |
| 不摇 | 仅有未读公告、或仅有未读普通通知 |
| 轮询 | 约 60 秒刷新未读摘要 |

### 3.5 已读口径

- 一对一行：`read_at` 为空 = 未读；有值 = 已读。
- 用户点开该条、或点「设置全部已读」才写 `read_at`。
- 管理端查看、只开抽屉看列表：**不**写已读。
- 模拟登录：读接口可浏览，写已读接口成功但不落库。

## 4. 非目标（本期不做）

| 项 | 说明 |
|----|------|
| 改已发 / 撤回 / 删除 | 无入口 |
| 群发 / 全员 / 按部门 | 一次一人 |
| 草稿 | 无草稿状态 |
| 附件 / Markdown / 富文本 | 不做 Markdown；仅 jpg/png/webp/gif 附图 |
| 强制弹窗挡登录 | 不做（那是系统公告） |
| 邮件 / 企微等站外触达 | 不做 |
| 阅读统计报表 / 未读名单导出 | 不做；管理列表已能按已读筛选 |
| 独立权限码 | 仅 SuperAdmin，不进角色授权 |

## 5. 与系统公告的关系

| | 系统通知（本功能） | 系统公告 |
|--|-------------------|----------|
| 受众 | 指定一人 | 全员可登录用户 |
| 登录 | 不挡 | 未读则强制弹窗 |
| 正文 | 纯文本 + 可选多图 | Markdown |
| 生命周期 | 发送即生效 | 草稿 → 发布 |
| 铃铛 | 「系统消息」Tab | 「系统公告」Tab |
| 角标 | 两者未读相加 | （计入同一角标） |
| 摇动 | 仅未读重要通知 | 公告不摇 |

控制台待办（邮箱引导、用户反馈等）**不**因系统通知增减。

---

## 6. 产品验收要点

1. 系统管理员能发给启用员工；非管理员看不到菜单、接口 403。  
2. 接收人铃铛出现该条；重要未读则摇；角标含通知 + 公告。  
3. 点卡片后已读、角标减 1；管理端点行对方仍未读。  
4. 「设置全部已读」后该 Tab 未读清零。  
5. 模拟登录不摇、不记已读。  
6. 登录不被系统通知挡住。
