# 报表规范 — 销售订单质保书 **V2**

> **版本标识：V2（与 V1 不是同一套版式）**  
> V1 为现网三租户皮肤，本文**不约束、不改写 V1**。V1 实现见 [销售订单质保书打印-设计与实现](../../../System/销售/销售订单质保书打印-设计与实现.md)。  
> 改 V2 观感时先改本文，再改 `SalesOrderWarrantyReportV2Body.vue` / V2 皮肤变量。  
> 配色与 chrome 对齐 [报表规范-采购订单-V2](./报表规范-采购订单-V2.md)。

| 项 | 内容 |
|----|------|
| 状态 | 已上线（semicore 消费） |
| 规范名称 | 报表规范-销售订单质保书-V2 |
| 适用对象 | 销售订单质保书打印 / 预览页，且全局参数 `System.Report.StyleVersion = V2`，且租户为 **semicore** |
| 模版基准 | 无独立 PDF；chrome 对齐 PO V2，业务字段对齐 V1 |
| 根 class | `.wty-doc.wty-doc--v2.po-doc.po-doc--v2.po-doc--so-wty-v2` |
| 页面 | `/sales-orders/:id/warranty`（工具栏切换中/英，默认中文） |

---

## 1. 适用范围

| 条件 | 版式 |
|------|------|
| 未配置 / 非法值 / 参数 **V1** | **V1**（现网三租户皮肤） |
| 参数 **V2** 且租户 **semicore** | **V2**（本文） |
| 参数 **V2** 且租户 **idesemi / ecoinf** | 仍为该租户 **V1** |

切换参数后须**重新打开或刷新**打印页。Logo / 印章仍走公司信息；语言由报表页工具栏切换（默认中文）。

---

## 2. V1 与 V2 对照（摘要）

| 项 | V1 | V2 |
|----|----|-----|
| 顶栏 | 租户深色顶栏 + 正文内 logo/公司名 | 藏青通栏 + 渐变线 |
| Meta | — | **2 格**：单据日期 + 销售订单号（标签随路由语言） |
| 标题 | 正文居中/左对齐大标题块 | head-right：主标题 + 跨语言副标题 |
| 交易方 | 两行「甲方 / 乙方」 | 分区「交易方 / Parties」+ 两栏 `po-v2__parties` |
| 条款 | 引言 + 说明列表（无分区标题） | **同 V1 顺序与文案**；不设 sec-hd |
| 货表 | 6 列，租户表头色 | 分区「货物明细 / Goods Information」+ 藏青表头 |
| 签章 | 双栏实线框 + 代表人/电话/地址 | **PO V2 虚线框样式** + **保留 V1 字段** |
| 空行 | 不补空行 | **同** |
| 分区标题语言 | — | **仅当前路由语言**（中文或英文） |

---

## 3. 顶栏与 Meta

| 区域 | 规范 |
|------|------|
| 左侧 | Logo + `YOUR RELIABLE SUPPLIER` |
| 右侧 | 主标题（路由语言 constants）；副标题（跨语言） |
| Meta（2 格） | 单据日期（`createTime`）；销售订单号（`sellOrderCode`） |
| Meta 标签 | 中文路由：单据日期 / 销售订单号；英文路由：Document Date / Sales Order No. |
| 公司名/地址 | **不在顶栏**；仅在交易方与签章区展示 |

## 5. 明细表

| 项 | 规范 |
|----|------|
| 列 | 与 V1 相同 6 列：P/N、Brand、Qty、DC、Customer P/N、Customer PO（中文路由用中文列名） |
