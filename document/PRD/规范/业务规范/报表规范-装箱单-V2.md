## 1. 适用范围（V2 才用本文）

| 条件 | 版式 |
|------|------|
| 未配置 / 非法值 / 参数 **V1** | **V1**（现网三租户竖版皮肤或 14 列横版）。**不要**套用本文色值与分区 |
| 参数 **V2** 且租户 **semicore** 且 **竖版** | **V2 竖版**（9 列中英表头） |
| 参数 **V2** 且租户 **semicore** 且 **横版** | **V2 横版**（本文 §5.5b；包装明细 14 列英文表头） |
| 参数 **V2** 且租户 **idesemi / ecoinf**（竖/横） | 仍为该租户 **V1**，与参数为 V1 时相同 |
| 销售订单 | **不读**样式版本，不适用本文 |
| 发票 | 另见 [报表规范-Invoice-V2](./报表规范-Invoice-V2.md) |
| 采购订单 | 另见 [报表规范-采购订单-V2](./报表规范-采购订单-V2.md) |

semicore + 参数 V2 时竖/横都走 V2 chrome（发货人/收货人、检验块、运输+汇总）。工具栏可切换方向；记忆仍写 `frontcrm.packingReport.orientation`。切换参数后须**重新打开或刷新**打印页。Logo / 抬头 / 印章仍走公司信息，与 V1/V2 版式无关。

V2 **不提供**中/英工具栏：页眉与竖版栏名为中英对照硬编码；横版包装明细表头按图1为英文。公司档案装箱备注中英文都有则都印。

## 2. V1 与 V2 对照（强制区分）

| 项 | **V1**（现网） | **V2**（本文） |
|----|----------------|----------------|
| 谁用 | 三租户；idesemi/ecoinf 在参数 V2 时仍用此列 | 仅 semicore + 参数 V2（竖版 + 横版） |
| 实现 | 竖版 `PackingReportSkin{Idesemi\|Ecoinf\|Semicore}`；横版 `PackingReportLandscapeDocument` | `PackingReportV2Body` + `PackingReportV2SkinIdesemi` / `PackingReportV2LandscapeSkinIdesemi` |
| 根 class | `.po-doc--idesemi` / `--ecoinf` / `--semicore`（**无** `--v2` / `--pl-v2`） | `.po-doc--v2.po-doc--pl-v2`；横版加 `--pl-v2-ls` |
| 纸张 | 默认横版 A4；可切竖版 | 竖版 A4 `210×297`；横版 A4 `297×210` |
| 顶栏 | 租户各自页眉 | **通栏藏青** `#090e1d`；「装箱单」白字 16pt；「PACKING LIST」青字 6.5pt；「装箱单号码 / Packing List No.」白字 7pt；右斜纹 |
| 顶栏下装饰 | 无统一渐变条 | 青色**渐变**横线（左实右淡），高 3.2px，顶栏下移 10px |
| 交易方 | **Bill To / Ship To 双客户地址** | **左发货人 = 我方公司**，**右收货人 = 客户**（不用 V1 双客户） |
| 明细列（竖版） | 6 列：No / PN / Brand / Qty / Carton / Remark | **9 列**：箱号、MPN、厂牌、批号、描述、数量、净重、毛重、尺寸。箱号在第一列，**不另开序号列** |
| 明细列（横版） | 14 列英/中随工具栏 | **14 列英文**（图1）：S/No.、CUSTOMER PO、PART NUMBER、CUSTOMER PN、Brand、QTY (PCS)、DC、CO、COD、SIZE、NW (KG)、GW (KG)、CARTON、Remark |
| 箱号空值 | 可空 | 空 `carton` 用行序 **01 / 02 / 03…** |
| 表头 | 随租户 | 藏青底、白字。竖版**列间无白色竖线**；横版包装明细表头有浅白竖线（对齐图1） |
| 数据行高 | 常规 | `line-height: 2.1` |
| 折行 | 随皮肤 | `table-layout: auto`；竖版表头中英各一行、**最多 2 行**（禁止按字竖折）；横版表头单行，行高可与内容行对齐；MPN、厂牌 **不折行**；描述弹性可折行 |
| 检验区 | `with-inspection` 显示 Outbound Inspection 五项 | **仍显示**：路由 `with-inspection` 时在明细之后、运输/汇总之前；五项中英对照；`without-inspection` 整区不出现 |
| 运输 / 汇总 | 无独立两栏（备注在表下） | 左运输资料 2fr / 右包装汇总 1fr |
| 签章 | 皮肤内发货/收货槽 | 两个**独立虚线框**；发货人左（可盖章）、收货人右 |
| 页脚 | 随皮肤 | 底部分隔线 + 灰色核对句；**无** PACKING LIST 徽章 |
| 中/英切换 | 工具栏切换 caption | V2 隐藏切换；竖版栏名中英对照，横版明细表头英文 |

V1 验收仍看三租户是否「不像同一张单只换了 Logo」。V2 验收看 semicore 竖/横是否符合本文，**不要**要求 idesemi/ecoinf 出现藏青顶栏。

## 5. 区块样式（自上而下）

### 5.1 顶栏

- 通栏藏青。左：Logo（高≤12mm）；无 Logo 时公司名青色。其下标语 `YOUR RELIABLE SUPPLIER`。Logo（或公司名）与标语水平居中对齐（`.po-v2__logo-stack`），整组仍靠顶栏左侧；竖版与横版相同。
- 右：「装箱单」16pt 白字；「PACKING LIST」6.5pt 青字宽字距；「装箱单号码 / Packing List No. {packing.code}」7pt 白字。竖版与横版相同。
- 右侧 45° 双向青色斜纹。

### 5.2 顶栏下渐变线 `.po-v2__fade`

- 紧贴 `</header>` 之后；相对顶栏下移 **10px**，高 **3.2px**。不要出现在「发货与收货」标题下。

### 5.3 元数据

四等分：单据日期、发票/订单号、贸易术语、运输方式。

| 栏 | 来源 |
|----|------|
| 单据日期 | 出库日期 |
| 发票/订单号 | 明细第一行非空 `customerPo`，否则出库 `sourceCode` / `sellOrderItemCode` |
| 贸易术语 | 无主数据字段 → **—**（不编造） |
| 运输方式 | 现网出货/交货方式展示（与 V1 同一解析） |

### 5.4 发货与收货

- 标题：「发货与收货信息 / SHIPPING PARTIES」+ 青竖条。
- 左 **发货人 / SHIPPER** = 当前抬头公司：名称、地址、联系人（法人）、电话、邮箱。
- 右 **收货人 / CONSIGNEE** = 客户名 + 装箱 Ship To（地址 / 联系人 / 电话）；邮箱无字段 → **—**。
- **禁止**再用 V1 的 Bill To / Ship To 双客户栏。销售脱敏时客户名为 **—**。

### 5.5 包装明细

| 列 | 来源 | 对齐 | 折行 |
|----|------|------|------|
| 箱号 Carton | `carton`，空则 `01` 起行序 | 居中 | **禁止折行** |
| 物料型号 / MPN | `pn` | 左，字重 700 | **禁止折行** |
| 厂牌 / Brand | `brand` | 左 | **禁止折行** |
| 批号 / Lot No. | `dc` | 居中 | **禁止折行** |
| 描述 / Description | `remark`，有客户型号则追加 | 左 | **允许折行** |
| 数量 Qty | `qty` | 右 | **禁止折行** |
| 净重 N.W. | 行 `nw`，有值带 `kg` | 右 | **禁止折行** |
| 毛重 G.W. | 行 `gw`，有值带 `kg` | 右 | **禁止折行** |
| 尺寸 Dimensions | 行 `size` | 居中 | **禁止折行** |

- 表头藏青、白字、居中；去掉表头白色竖分隔线。
- 竖版表头文案中英各一行（`<br />`），整格**最多 2 行**；`white-space: nowrap`，禁止 `break-all` 按字竖排。
- 检验表表头为单行「序号 / No.」「检验项目 / Item」「结果 / Result」，序号列 **50px**、结果列 **70px**，其余给检验项目；表头行高与内容行相同、**不折行**。包装明细竖版表头仍为中英两行，不套用本条。
- 横版包装明细表头单行，行高、内边距与内容行相同。
- 数据行浅蓝底；行高 `line-height: 2.1`。
- 无明细：一行「暂无明细 / No items」。**不补空行、不写「以下空白」**。

### 5.5b 横版包装明细（图1）

仅 semicore + 参数 V2 + **横版**。页眉 / 交易方 / 检验 / 运输汇总 / 签章与竖版相同；**仅明细表**换成 14 列英文表头（与 V1 横版列序一致，caption 固定英文、不随中/英工具栏）。

| 表头（图1） | 来源 | 对齐 | 折行 |
|-------------|------|------|------|
| S/No. | 行序 1… | 居中 | **禁止折行** |
| CUSTOMER PO | `customerPo` | 左 | 可 |
| PART NUMBER | `pn` | 左，字重 700 | **禁止折行** |
| CUSTOMER PN | `customerPn` | 左 | 可 |
| Brand | `brand` | 左 | **禁止折行** |
| QTY (PCS) | `qty` | 右 | **禁止折行** |
| DC | `dc` | 居中 | **禁止折行** |
| CO | `co` | 居中 | **禁止折行** |
| COD | `cod` | 居中 | **禁止折行** |
| SIZE | `size` | 居中 | **禁止折行** |
| NW (KG) | 行 `nw`，单位在表头，格内不写 kg | 右 | **禁止折行** |
| GW (KG) | 行 `gw`，同上 | 右 | **禁止折行** |
| CARTON | `carton`，空则 `01` 起行序 | 居中 | **禁止折行** |
| Remark | `remark` | 左 | **允许折行**；相对上一版再收至 80%，省下宽度全部给 Brand |

- 表头藏青、白字、居中、`nowrap`（最多 2 行）；列间浅白竖线（对齐图1）。
- 空值 **—**。无明细一行 colspan 14。

### 5.6 出库检验（仅 `with-inspection`）

- 位置：包装明细之后、运输/汇总之前。
- 表头单行不折行，行高、内边距与内容行相同。序号 / No. **50px**，结果 / Result **70px**（竖/横相同），省下宽度给检验项目 / Item。
- 五项与 V1 同源（`packingReportLabels` 中英配对成一行）。
- 结果列预留 ☐；检验员 / 检验日期手写线。
- `without-inspection`：**整块不渲染**。

### 5.7 运输 + 汇总

栅格 **2fr / 1fr**。

**左 · 运输资料**（标题底 = `--po-v2-legal`）

| 行 | 来源 |
|----|------|
| 运输标记 | 无字段 → **—** |
| 起运地 / 目的地 | 无字段 → **—** |
| 承运人/快递单号 | 出库快递公司（字典标签）+ 快递单号；都空则 **—** |
| 备注 | 公司档案装箱备注（中英都印）；都空则默认双语句：「所有货物应按合同与包装要求完成标识、包装和保护。 / All goods shall be marked, packed and protected…」 |

**右 · 包装汇总**（标题底 `--po-v2-panel`）

| 行 | 口径 |
|----|------|
| 总箱数 | **明细行数**（每行都有展示箱号，含补序） |
| 总数量 | Σ 行 `qty` |
| 总净重 / 总毛重 | 有任一行数值则求和并带 `kg`，否则 **—** |
| 总体积 | 无 CBM 字段 → **—**（不编造 0） |

### 5.8 包装声明

浅底 + 左 2.4px 青条。固定双语：所列货物、包装数量、重量与尺寸应与实际出运一致。

### 5.9 签章

- 两框并排，虚线边；左发货人可叠印章；右收货人只留盖章占位。
- 发货人、收货人「日期 / Date」均为下划线（竖版与横版相同），**不**印出库日期。元数据「单据日期」仍显示出库日期。

### 5.10 页脚

- 顶 1px `#c5d0d8`。
- 「装箱单（草案）/ Packing List Draft — 出运前请核对件数、重量、尺寸与运输资料。」
- **禁止**再放 SEMICORE · PACKING LIST 一类徽章。
