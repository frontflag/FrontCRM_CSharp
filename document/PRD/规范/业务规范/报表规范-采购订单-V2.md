## 2. V1 与 V2 对照（强制区分）

| 项 | **V1**（现网） | **V2**（本文） |
|----|----------------|----------------|
| 谁用 | 三租户；idesemi/ecoinf 在参数 V2 时仍用此列 | 仅 semicore + 参数 V2 |
| 实现 | `PurchaseOrderReportBody` + `PurchaseOrderReportSkin{Idesemi\|Ecoinf\|Semicore}` | `PurchaseOrderReportV2Body` + `PurchaseOrderReportV2SkinIdesemi` |
| 根 class | `.po-doc--idesemi` / `--ecoinf` / `--semicore`（**无** `--v2`） | `.po-doc--v2` |
| 顶栏 | 租户各自页眉（semicore 约 `#0D1F35` 深顶栏；idesemi 左大标题+青竖条；ecoinf 绿表） | **通栏藏青** `#090e1d`，右斜纹底纹；「采购订单」白字 16pt；「PURCHASE ORDER」青字 6.5pt 宽字距；「订单编号 / PO NO.」白字 7pt |
| 顶栏下装饰 | 无统一渐变条 | 青色**渐变**横线（左实右淡），高 3.2px，顶栏下移 10px |
| 元数据 | 无独立四栏条 | ORDER DATE / CONTRACT NO. / CURRENCY / PAYMENT，浅灰底 `#f5f7fa` |
| 交易方称谓 | 卖方 / 买方 / 交付（三栏或皮肤分区） | **需方 \| 供方** 两框；框顶 2.4px 青线 |
| 分区标题 | 皮肤自带色条或大标题 | 青竖条 `2.4×3.6mm` +「中文 / ENGLISH」 |
| 明细列 | 10 列：序号、产品名称、规格型号、品牌、单位、币种、数量、单价（含税）、税率、合计金额 | **8 列**：序号、MPN、厂牌、批号、规格及描述、数量、单价、金额。单位/币种/税率不单列 |
| 表头 | 随租户（绿/深紫/无色块等） | 藏青底、白字；**列间无白色竖线**（竖边与表头同色） |
| 数据行高 | 常规 | `line-height: 2.1`（约 1.5× 正文 1.4） |
| 列宽 / 折行 | 固定比例 | `table-layout: auto`；表头整格 **nowrap**（不按字竖折）；MPN、厂牌、序号/批号/数量/单价/金额单元格 **不折行**；描述列为弹性列，可收窄、可折行。样式必须挂在 `.po-doc--v2` 下，避免装箱单 V2 同名 class 串改列宽 |
| 金额区 | 表下「总计」+ 右侧价税表（不含税/增值税/价税合计/货币） | 右栏 **SUMMARY**：小计 / 税费 / 运费 / 总额；金额后带币别（`1,247.00 RMB`） |
| 交付信息 | 附加信息区多行文本 | 左栏 DELIVERY & QUALITY：Ship To / Delivery / Incoterms / Documentation |
| 条款 | 附加信息内「服务条款」连续编号段落 | 文首「文件效力」浅底+左青条；其下 **单色青线**；再 2 列 8 张条款卡 |
| 签章 | 皮肤内卖方/买方槽；印章在买方 | 两个**独立虚线框**；需方左（可盖章）、供方右 |
| 页脚 | 24 小时确认句在条款区末 | 底部分隔线 + 灰色确认句；**无** PROCUREMENT 徽章 |

V1 验收仍看三租户是否「不像同一张单只换了 Logo」。V2 验收只看 semicore 是否符合本文，**不要**要求 idesemi/ecoinf 出现藏青顶栏。

| Token | 色值 | 用途 |

| `--po-v2-wash` | `#f5f7fa` | 元数据条、交易方角色行 |
| `--po-v2-panel` | `#eaf6fb` | **仅**「金额汇总」标题底 |
| `--po-v2-row` | `#f4f9fc` | 明细数据行底 |
| `--po-v2-legal` | `#f3f7f9` | 「文件效力」底；「交付与质量要求」标题底（与文件效力相同） |

## 5. 区块样式（自上而下）

### 5.1 顶栏 `.po-v2__head`

- 通栏藏青；内边距约 `5.2mm 10mm 4.6mm`；左右顶对齐到底。
- **左**：Logo（高≤12mm、宽≤42mm）；无 Logo 时公司名 15pt / 800 / 青色。其下标语 `YOUR RELIABLE SUPPLIER`，6pt、字距 0.24em、白 78% 透明。Logo（或公司名）与标语在 `.po-v2__logo-stack` 内水平居中对齐，整组仍靠顶栏左侧。
- **右**（宽 88mm，右对齐）：
  - 「采购订单」16pt / 800 / 白 / 字距 0.16em
  - 「PURCHASE ORDER」6.5pt / 700 / 青 / 字距 0.46em
  - 「订单编号 / PO NO. {单号}」7pt / 白 / 不折行
- 右侧 45° 双向青色斜纹，左向透明遮罩，不挡文字。

### 5.2 顶栏下渐变线 `.po-v2__fade`

- 紧贴 `</header>` 之后。
- 相对顶栏下移 **10px**，高 **3.2px**（条款区实线不要用本类）。

### 5.3 元数据 `.po-v2__meta`

四等分：订单日期、合同编号、货币、付款条款。标签 6.5pt 加粗，值 9pt。无合同编号时值为 **—**。付款条款取订单备注。

### 5.4 交易方 `.po-v2__parties`

- 标题：「交易方信息 / PARTIES」+ 青竖条。
- 两列并排，中间共边；每框顶边 **2.4px** `--po-v2-line`。
- 左需方 / 右供方。角色行浅灰底。公司名 10pt / 800。地址、联系人、电话、邮箱 7.5pt 次要色。

### 5.5 订购明细 `.po-v2__grid`

| 列 | 对齐 | 折行 | 宽度策略 |
|----|------|------|----------|
| 序号 No. | 居中，两位补零 | 表头中英两行；单元格不折行 | 随表头/内容（`width: 1%` 收缩，不得压成竖条） |
| 物料型号 / MPN | 左，字重 700 | **禁止折行** | 随最长型号 |
| 厂牌 / Brand | 左 | **禁止折行** | 随厂牌 |
| 批号 / Lot No. | 居中 | 表头不按字折；单元格不折行 | 随表头/内容 |
| 规格及描述 / Description | 左 | **允许折行**（`break-word`） | **弹性列**，其余列变宽时本列收窄 |
| 数量 Qty | 右 | 表头中英两行；单元格不折行 | 随表头/数量 |
| 单价 | 右 | 表头与单元格不折行 | 随内容 |
| 金额 / Amount | 右 | 表头与单元格不折行 | 随内容 |

- 表头藏青、白字、居中；**去掉表头白色竖分隔线**（左右边与 navy 同色）。
- 数据行浅蓝底；行高 `line-height: 2.1`。
- 无明细：一行「暂无明细」。**不补空行、不写「以下空白」**。
- 无金额权限：数量 / 单价 / 金额为 **—**。
- 字段：MPN←规格 PN；描述←产品名称；批号←DateCode。

### 5.6 交付 + 汇总 `.po-v2__lower`

栅格 **2fr / 1fr**，间隙 2.5mm。

**左 · 交付与质量要求**

- 标题底色 = `--po-v2-legal`（与「文件效力」相同），**不要**用汇总标题的 `--po-v2-panel`。
- 行：交货地址、交货日期、贸易条款（现为固定「送货/物流/快递」）、文件要求（运费承担说明）。行间虚线 `#c5ced4`。

**右 · 金额汇总**

- 标题底 `--po-v2-panel`。
- 行：小计、税费、运费、订单总额（总额字重 800 / 9.5pt，顶实线）。
- **有金额时**：`{金额} {币别}`，如 `1,247.00 RMB`（币别在金额**后**）。无权限或运费无独立字段：只显示 **—**，不带币别。
- 明细行金额**不**强制带币别（币别已在元数据 CURRENCY）。

### 5.7 订单条款

1. 标题「订单条款 / PURCHASE ORDER TERMS」+ 青竖条。  
2. 「文件效力：…」浅底 + 左 2.4px 青条。  
3. **单色**青线（`--po-v2-line`，高 1.6px），位于文件效力与条款卡之间（相对文件效力上移约 8px 的视觉间距）。**禁止**再用渐变。  
4. 2×4 条款卡，白底细边框；标题加粗。文案见 `PURCHASE_ORDER_SERVICE_TERM_CARDS`（法务口径与 V1 条款同源，仅改卡片结构）。

### 5.8 签章 `.po-v2__sign`

- 两框并排，间隙 4mm；`1px dashed #b7c0c8`；最小高 32mm。
- 左需方：可叠印章（≤22mm）；右供方：只留「（盖章）」占位。
- 授权代表签字线 + 日期。需方、供方「日期」均为下划线，**不**印订单创建日。

### 5.9 页脚 `.po-v2__foot`

- 顶 1px `#c5d0d8`。
- 7pt `#9aa3ab`：「请在24小时内确认此合同并签字/盖章，谢谢！」
- **禁止**再放 PROCUREMENT 徽章。
