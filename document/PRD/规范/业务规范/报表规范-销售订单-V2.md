## 1. 适用范围

| 条件 | 版式 |
|------|------|
| 未配置 / 非法值 / 参数 **V1** | **V1**（现网三租户皮肤） |
| 参数 **V2** 且租户 **semicore** | **V2**（本文） |
| 参数 **V2** 且租户 **idesemi / ecoinf** | 仍为该租户 **V1** |

切换参数后须**重新打开或刷新**打印页。Logo / 抬头 / 印章仍走公司信息。

---

## 2. V1 与 V2 对照（摘要）

| 项 | V1 | V2 |
|----|----|-----|
| 顶栏 | 租户深色顶栏 + Meta 卡片 | 藏青通栏 + 渐变线 + 4 格 meta |
| Meta | 日期、单号 | 订单日期；合同号/付款 **—**；**货币**有值 |
| 交易方 | 卖方 / 买方 / 交付 **三栏** | **卖方 / 买方** 两栏；交付下迁 DELIVERY 面板 |
| 明细 | **10 列**含税 | **同 10 列**；藏青表头 |
| 金额 | 表内总计 + 价税小表 | **DELIVERY + SUMMARY**（小计/税费/运费/总额 + 币别） |
| 条款 | 5 条段落 + V1 确认句 | **同 5 条** + **「请在约定时间内确认…」** |
| 签章 | 卖方侧盖章 | **同** |
| 空行 | 不补空行、无「以下空白」 | **同** |
