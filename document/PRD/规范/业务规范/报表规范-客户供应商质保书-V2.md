# 报表规范 — 客户 / 供应商质保书 **V2**

> **版本标识：V2（与 V1 不是同一套版式）**  
> V1 为现网三租户皮肤，本文**不约束、不改写 V1**。V1 实现见 [客户供应商质保书打印-三租户皮肤-设计与实现](../../../System/主数据/客户供应商质保书打印-三租户皮肤-设计与实现.md)。  
> 改 V2 观感时先改本文，再改 `WarrantyLetterReportV2Body.vue` / V2 皮肤变量。  
> 配色与 chrome 对齐 [报表规范-采购订单-V2](./报表规范-采购订单-V2.md)、[报表规范-销售订单质保书-V2](./报表规范-销售订单质保书-V2.md)。

| 项 | 内容 |
|----|------|
| 状态 | 已上线（semicore 消费） |
| 规范名称 | 报表规范-客户供应商质保书-V2 |
| 适用对象 | 客户 / 供应商主数据质保书打印 / 预览页，且全局参数 `System.Report.StyleVersion = V2`，且租户为 **semicore** |
| 模版基准 | 无独立 PDF；chrome 对齐 PO V2 / SO 质保书 V2，业务字段对齐 V1 信笺 |
| 根 class | `.wty-doc.wty-doc--v2.po-doc.po-doc--v2.po-doc--letter-wty-v2` |

---

## 1. 适用范围

| 条件 | 版式 |
|------|------|
| 未配置 / 非法值 / 参数 **V1** | **V1**（现网三租户皮肤） |
| 参数 **V2** 且租户 **semicore** | **V2**（本文） |
| 参数 **V2** 且租户 **idesemi / ecoinf** | 仍为该租户 **V1** |

切换参数后须**重新打开或刷新**打印页。Logo / 印章仍走公司信息；语言由报表页工具栏切换（默认中文）。

---

## 2. V1 与 V2 对照（摘要）

| 项 | V1 | V2 |
|----|----|-----|
| 顶栏 | 租户深色顶栏 + 正文内标题 | 藏青通栏 + 渐变线 |
| Meta | 标题区右侧「文件编号 / 日期」 | **2 格**：**文件编号** + **单据日期**（标签随页内语言） |
| 收件方 | 实线框 `wty-doc__to` | 分区「收件方 / Recipient」+ 顶青线框 |
| 正文 | 段落列表（无分区标题） | **同 V1 文案与顺序**；`po-v2__wty-prose` 样式 |
| 货表 | — | **不适用**（信笺式无明细） |
| 签章 | 单栏实线框 + 印章 + 日期 | **PO V2 虚线框** + **保留 V1 单栏字段** |
| 分区标题语言 | — | **仅当前页内语言**（中文或英文） |

---

## 3. 顶栏与 Meta

| 区域 | 规范 |
|------|------|
| 左侧 | Logo + `YOUR RELIABLE SUPPLIER` |
| 右侧 | 主标题（页内语言）；副标题（跨语言，与 SO 质保书 V2 相同规则） |
| Meta（2 格） | **文件编号**（`QW-{客户/供应商编号}`）；**单据日期**（打印当日） |
| Meta 标签 | 中文：文件编号 / 单据日期；英文：Ref. No. / Document Date |
| 公司名 | **不在顶栏**；Logo 缺省时 fallback 用抬头公司名 |

---

## 4. 分区标题（单语）

| 中文 | 英文 |
|------|------|
| 收件方 | Recipient |
| 签章确认 | Signatures |

行前导标识：`po-v2__guide`（2.4×3.6mm 青竖条）。

收件方区内行标签仍用 V1 i18n（如「致（客户名称）：」/ `To (Customer):`），与 V1 字段一致。

---

## 5. 正文与签章

| 项 | 规范 |
|----|------|
| 正文 | `vendorWarrantyReportZh/En.ts` 段落；客户页与 V1 相同仍共用该文案 |
| 中文段落 | 首行缩进 2em |
| 签章 | **单栏**：需方（盖章）/ Buyer (Stamp) + 印章区 + 日期行；**无** SO 双栏甲乙签 |
| 印章 | 受工具栏「报表含印章」开关控制 |

## 7. 验证要点

- **客户**：semicore + V2 + 中文 — 藏青 chrome、Meta 两格、收件方 / 签章分区、单栏签章、段落与 V1 一致。
- **供应商**：同上，入口 `/vendors/:id/warranty`，收件方标签为供应商语义。
- semicore + V2 + 英文：分区标题与 Meta 标签全英；副标题为中文「质量保证书」。
- 打印 / **导出 PDF** 与 V1 同入口；PDF 仍截 `.wty-doc` 根节点。
- idesemi / ecoinf + V2 仍为 V1 三皮肤。
