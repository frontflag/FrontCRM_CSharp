# 流程页签 · 当前业务指示规范

本文约定右侧扩展栏 **「流程」** 页签（`r-flow`）地铁竖轴上，如何标注 **当前业务节点**（用户正在查看的那一行业务）。

> **状态：** 定稿（2026-08-07）  
> **关联：** [扩展面板.工作台规范](./扩展面板.工作台规范.md)  
> **共享实现：** `CRM.Web/src/components/Common/FlowYouAreHereMark.vue`、资源 `CRM.Web/src/assets/icons/flow-you-are-here-hand.png`、文案 `layout.flowPanel.youAreHere`

---

## 1. 目标

在全链路流程时间轴中，一眼标出 **「列表/详情当前选中业务」对应的业务站**，避免与上下游站点混淆。

| 概念 | 说明 |
|------|------|
| **当前业务节点** | 触发本次流程加载的那一行/那条业务 |
| **指示** | 仅出现在当前业务站标题旁；**不**占用轨道圆点位 |
| **文案语义** | 悬停 / `title` / `alt` 文案为 **「当前业务节点」**（英文 *Current business node*）；**禁止**再用「我在此」作悬停提示或文字胶囊 |

---

## 2. 适用范围与主节点映射

凡注册右侧 **「流程」**（`r-flow`）的页面均须标注当前业务指示：

| 路由 / 页面 | 流程面板 | 当前业务站 `key` | 站标题（中文） |
|-------------|----------|------------------|----------------|
| `SalesOrderItemList` 销售订单明细列表 | `SalesOrderItemFlowPanel` | `sellOrderItem` | 销售订单明细 |
| `SalesOrderDetail` 销售订单详情 | 同上（选中明细行） | `sellOrderItem` | 销售订单明细 |
| `PurchaseOrderItemList` 采购订单明细列表 | `PurchaseOrderItemFlowPanel` | `purchaseOrderItem` | 采购订单明细 |
| `PurchaseOrderDetail` 采购订单详情 | 同上（选中明细行） | `purchaseOrderItem` | 采购订单明细 |
| `PackingList` 装箱单列表 | `PackingListFlowPanel` → `PackingItemFlowPanel` | `packing` | 装箱 |
| `PackingDetail` 装箱单详情 | `PackingItemFlowPanel` | `packing` | 装箱 |
| `CustomsPendlistList` 待报关列表 | `CustomsPendlistFlowPanel` | `pendlist` | 待报关列表 |

新增带「流程」页签的页面时：在对应站标题旁挂载 `FlowYouAreHereMark`，并为该站加 `is-main`。

---

## 3. 视觉定稿

### 3.1 分工

| 位置 | 元素 | 规则 |
|------|------|------|
| **轨道（rail）** | 状态色圆点 | 与其它站点一致：`active` / `done` / `empty`；**禁止**用定位针/手势替换轨道点 |
| **站标题旁** | `FlowYouAreHereMark` | 仅当前业务站显示 |

### 3.2 指示图标

| 项 | 规范 |
|----|------|
| 图形 | 指向左的手势轮廓（「指着本站标题」） |
| 颜色 | **橙色**（约 `#FF8A00`），透明底 PNG |
| 尺寸 | 约 **28×22** px（`object-fit: contain`），须明显可辨 |
| 布局 | 紧挨站标题文字右侧；主节点标题加粗（`.is-main`） |
| 悬停提示 | **「当前业务节点」**（i18n：`layout.flowPanel.youAreHere`；英文 *Current business node*） |
| 禁止 | 「我在此」作悬停提示或浅蓝文字胶囊；珊瑚定位针作标题旁指示 |
| 可访问性 | `alt` / `title` 与悬停提示相同：均为「当前业务节点」 |

### 3.3 示意

```
  │
  ●  上游站点
  │
  ●  当前业务站  ☜（橙色左指手势）     ← 当前业务节点
  │     ┌ 小卡 … ┐
  │     └────────┘
  │
  ○  下游站点
  │
```

---

## 4. 交互

| 项 | 规则 |
|----|------|
| 何时出现 | 右栏展开且在「流程」页签，并已加载当前业务流程数据 |
| 未选行 / 空态 | 无指示图标 |
| 悬停指示图标 | 提示文案 **「当前业务节点」**（勿写「我在此」） |
| 切换明细（装箱列表顶栏切换） | 指示仍在「装箱」站（主节点不随切换改变） |

---

## 5. 自检清单

- [ ] 当前业务站轨道仍为状态色圆点
- [ ] 标题旁橙色左指手势醒目，无文字胶囊
- [ ] 悬停提示为「当前业务节点」（不是「我在此」）
- [ ] 非当前业务站无同类指示
- [ ] 本规范 §2 表中全部页面均已覆盖
