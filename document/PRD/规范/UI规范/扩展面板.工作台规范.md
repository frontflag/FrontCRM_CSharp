## 1. 结构概览

| 区域 | 典型页签 | Tab ID（实现） | i18n |
|------|----------|----------------|------|
| **左侧扩展面板** | 检索 / 收藏 / 历史；审批页为 **待审** | `l1` / `l2` / `l3`（审批：`l1`=`approvalDesktop.leftTab`） | `layout.auxTabs.search` 等 |
| **右侧扩展面板** | 操作 / 流程 / 帮助 / 业务专页（需求明细另含 **物料、客户**；需求列表/详情另含 **客户**）；审核桌面另含调查与 SO/PO 行 | `r-ops` / `r-flow` / `r4` / `r-material` / `r-customer` / `r-customer-intel` / `r-vendor-intel` / `r-approval-*-lines` | `layout.auxTabs.ops` 等 |

各路由在 `AppLayout.vue` 的 `watch(route.name)` 中注册当前页可用的 `leftTabs` / `rightTabs`；离开业务路由时恢复默认（右栏通常仅「帮助」）。

## 2. 展开时默认页签（定稿）

用户通过边条按钮、✕ 关闭后再展开、或 `toggleLeftPanel` / `toggleRightPanel` **由收起变为展开** 时：

| 侧 | 条件 | 行为 |
|----|------|------|
| **左栏** | 当前页 `leftTabs` 中含 **「检索」**（`id === 'l1'`） | 自动激活 **`l1`** |
| **右栏** | 当前页 `rightTabs` 中含 **「操作」**（`id === 'r-ops'`） | 自动激活 **`r-ops`** |

### 2.0 按路由记忆上次页签（定稿）

| 项 | 规则 |
|----|------|
| 存储 | `localStorage` 键 `frontcrm_aux_tabs_by_route_v1`，按 `route.name` 分别记左右 `tabId` |
| 写入 | 用户切换页签时；离开路由前再写一次 |
| 恢复 | 进入路由并完成 `rightTabs` 注册后：若记忆页签仍在当前页签列表中则激活，否则回落到该路由默认（如 `r-ops` / `r-flow` / `r4`） |
| 与展开默认 | **互不覆盖**：§2「收起→展开」仍优先 `l1` / `r-ops`；**再次进入页面**走本记忆 |
| 实现 | `useWorkspaceLayout.rememberAuxTabsForRoute` / `restoreAuxTabsForRoute`；`AppLayout` 路由 watch |

### 2.1 说明

1. **仅在一次「收起 → 展开」时触发**；面板已展开时切换页签不受影响。
2. **无对应页签时不切换**：例如仅「帮助」的页面展开右栏仍停留 `r4`；出库通知报关页签（`r-stock-out-customs`）无 `r-ops` 时不强制改页签。
3. **业务代码可覆盖**：展开后若需固定到其它页签，须在 **`toggleRightPanel(true)` 之后** 调用 `setRightActiveTab(...)`（参考 `StockOutNotifyList`、`CustomerList`）。
4. **与 §2.4 操作门控配合**：右栏展开且落在 `r-ops` 时，列表单击行才加载操作面板数据；用户在「帮助」页签下单击行仍不请求（见销售操作面板 §2.4 B）。

## 4. 左栏「检索」页签（摘要）

含 **`l1` 检索** 的模块包括但不限于：客户、供应商、需求、需求明细、销售订单、销售订单明细、采购订单明细、入库单、出库单等。具体字段与 preset 见各模块左栏检索设计文档。

**质检列表 / 新建质检（`QcList`、`QcCreate`）：** 左栏仍注册「检索」页签，**内容区为空**；筛选条件仅在列表主区 `search-bar`（与 URL query 同步），不在左栏重复表单。

## 6. 质检列表 · 操作页签（定稿）

**适用页面：** 质检列表 `/logistics/qc`（路由名 `QcList`）。**不含** 质检详情 `QcCreate`。

**实现索引：** `QcOpsPanel.vue`、`qcOpsPanel` store、`QcList.vue` 行交互与生成入库 handler。  
**设计与实现详述：** [质检列表-操作面板-设计与实现](../../System/物流/质检列表-操作面板-设计与实现.md)  
**测试对照：** [质检列表-操作面板-测试对照说明](../../QA/物流/质检列表-操作面板-测试对照说明.md)

### 6.1 页签与空态

| 项 | 规范 |
|----|------|
| 右栏页签 | **操作**（`r-ops`）+ **帮助**（`r4`）；进入本路由默认 **操作** |
| 未选行 | 文案「请在「操作」页签下单击列表行…」（`qcList.opsPanel.pickRow`） |
| 离开路由 | `qcOpsPanelStore.clear()` |

### 6.2 卡片结构（自上而下）

布局 token 遵循 [销售操作面板 §2.5](../../System/销售订单明细列表-操作面板-设计与实现.md)（`so-item-ops-panel.scss`）。

| 顺序 | 卡片标题 | 类型 | 说明 |
|------|----------|------|------|
| 1 | **质检摘要** | 概况 §2.5.3 | hero 质检单号 + 状态标签 + 双列 KV（见 §6.3） |
| 2 | **质检入库** | 操作 §2.5.3 | 「生成入库」主按钮 / 已完成 ✓ / hint（见 §6.4） |
| 3 | **采购订单** | 信息 §2.5.2 | 只读 KV；无采购时空态 |
| 4 | **到货通知** | 信息 §2.5.2 | 只读 KV；无通知时空态 |
| 5 | **入库** | 信息 §2.5.2 | 有记录 KV / 无记录空态 |

### 6.3 质检摘要字段

| 行 | 左列 | 右列 |
|----|------|------|
| — | 质检单号（琥珀 hero，可链详情） | 状态标签（`el-tag`） |
| 1 | 通过数量 | 拒收数量 |
| 2 | **可入库数量**（= `passQty`） | **质检图片**（图片附件张数，如「3 张」） |

- 数量类字段来自**列表行**，选中即展示，无需等待 aggregates。
- 质检图片张数：并行请求 `GET /api/v1/documents?bizType=QC&bizId={qcId}`，仅统计**图片类型**附件（与质检详情页、采购明细「质检图片」页签口径一致）。

### 6.4 质检入库 · 交互与状态

与销售订单明细操作面板 **§2.5.3 操作 + hint** 一致，三种态：

| 状态 | 判定 | UI |
|------|------|-----|
| **已完成** | 列表行 `stockInId` 或 aggregates 已有入库 | 标题旁「已完成 ✓」；**无**按钮 |
| **可执行** | 有物流写权限 + 未完成 + 质检未驳回 + `passQty > 0` | 主色「生成入库」 |
| **置灰** | 有写权限 + 业务阻断（驳回 / 无合格量） | 灰色按钮 + summary + 下一步 hint |
| **只读** | 无 `canWriteLogisticsData` + 未完成 | **仅 hint**，不渲染按钮 |

- 点击「生成入库」：与列表操作列 **同一套** `createStockIn` 流程（确认框 → 选仓 → 创建并完成入库 → 绑定 QC）。
- 逻辑：`utils/qcCreateStockInDisabledHint.ts`；文案 `qcList.opsPanel.createStockInHint*` / `createStockInNext*`。

### 6.5 列表行交互（§2.4 门控）

质检列表纳入全站 **操作页签门控**（[销售操作面板 §2.4](../../System/销售订单明细列表-操作面板-设计与实现.md)）：

| 场景 | 行为 |
|------|------|
| 右栏收起 + 单击行 | 忽略 |
| 展开 + 非「操作」页签 + 单击 | 仅 `setRowOnly` 高亮 |
| 展开 + 「操作」+ 单击 | `selectRow` → 请求 aggregates + 质检图片数 |
| 双击行 | 跳转质检详情 `QcCreate?qcId=`（与单击互不冲突） |
| 搜索 / 重置 / 筛选 | 清空右栏选中（`resetListRightPanelOnReload`） |
| 分页刷新 | `refreshFromListRows` 同步选中行与面板 |
| 采购 511 / 销售 521 脱敏 | **仍加载**操作面板（与列表同源）；敏感字段 / 链接为 `—`；按钮按角色权限 |

### 6.6 信息面板内单号链接（§2.5.4）

| 字段 | 跳转 |
|------|------|
| 质检单号（摘要 hero） | `QcCreate?qcId=` |
| 采购明细单号 | `PurchaseOrderDetail` + `purchaseOrderItemId` |
| 到货通知单号 | `ArrivalNoticeList?noticeId=` |
| 入库单号 | `StockInDetail` + `id` |

- 使用 `router-link` + **`link-text`**；脱敏时不渲染链接。
- 列表操作列「查看 / 生成入库 / 删除」**保留**；右栏为增强入口，不替代行内按钮。

### 6.7 数据请求

| 时机 | 请求 |
|------|------|
| 「操作」页签下单击行 / 切回「操作」且已有选中行 | `GET /api/v1/logistics/qcs/{id}/ops-aggregates` |
| 同上（并行） | `GET /api/v1/documents?bizType=QC&bizId={id}`（计图片张数） |

## 7. 「流程」页签 · 当前业务指示（摘要）

| 路由 | 主节点站 |
|------|----------|
| `SalesOrderItemList` / `SalesOrderDetail` | 销售订单明细 |
