# 扩展面板 · 工作台规范

本文约定 **AppLayout** 左右两侧扩展辅助栏（`aux-left` / `aux-right`）的 **页签注册** 与 **展开时默认页签** 行为。实现入口：`CRM.Web/src/composables/useWorkspaceLayout.ts`、`CRM.Web/src/layouts/AppLayout.vue`。

**关联：**

- 左栏「检索」快捷筛选：各列表 `*-左栏检索-设计与实现.md`、`*-筛选页签模式-设计与实现.md`

## 1. 结构概览

| 区域 | 典型页签 | Tab ID（实现） | i18n |
|------|----------|----------------|------|
| **左侧扩展面板** | 检索 / 收藏 / 历史 | `l1` / `l2` / `l3` | `layout.auxTabs.search` 等 |
| **右侧扩展面板** | 操作 / 帮助 / 业务专页 | `r-ops` / `r4` / 路由注册 | `layout.auxTabs.ops` 等 |

各路由在 `AppLayout.vue` 的 `watch(route.name)` 中注册当前页可用的 `leftTabs` / `rightTabs`；离开业务路由时恢复默认（右栏通常仅「帮助」）。

---

## 2. 展开时默认页签（定稿）

用户通过边条按钮、✕ 关闭后再展开、或 `toggleLeftPanel` / `toggleRightPanel` **由收起变为展开** 时：

| 侧 | 条件 | 行为 |
|----|------|------|
| **左栏** | 当前页 `leftTabs` 中含 **「检索」**（`id === 'l1'`） | 自动激活 **`l1`** |
| **右栏** | 当前页 `rightTabs` 中含 **「操作」**（`id === 'r-ops'`） | 自动激活 **`r-ops`** |

### 2.1 说明

1. **仅在一次「收起 → 展开」时触发**；面板已展开时切换页签不受影响。
2. **无对应页签时不切换**：例如仅「帮助」的页面展开右栏仍停留 `r4`；出库通知报关页签（`r-stock-out-customs`）无 `r-ops` 时不强制改页签。
3. **业务代码可覆盖**：展开后若需固定到其它页签，须在 **`toggleRightPanel(true)` 之后** 调用 `setRightActiveTab(...)`（参考 `StockOutNotifyList`、`CustomerList`）。
4. **与 §2.4 操作门控配合**：右栏展开且落在 `r-ops` 时，列表单击行才加载操作面板数据；用户在「帮助」页签下单击行仍不请求（见销售操作面板 §2.4 B）。

## 3. 右栏「操作」页签注册（摘要）

含 **`r-ops`** 的列表/详情路由（2026-07 定稿）：

| 路由 | 面板组件 |
|------|----------|
| `SalesOrderItemList` / `SalesOrderDetail` | `SalesOrderItemOpsPanel` |
| `PurchaseOrderItemList` / `PurchaseOrderDetail` | `PurchaseOrderItemOpsPanel` |
| `CustomsDeclarationList` | `CustomsDeclarationOpsPanel` |
| `ArrivalNoticeList` | `ArrivalNoticeOpsPanel` |

进入上述路由时除注册页签外，若当前 `rightActiveTabId` 非法，亦会校正为 `r-ops`（`AppLayout` 路由 watch）。

---

## 4. 左栏「检索」页签（摘要）

含 **`l1` 检索** 的模块包括但不限于：客户、供应商、需求、需求明细、销售订单、销售订单明细、采购订单明细、质检、入库单、出库单等。具体字段与 preset 见各模块左栏检索设计文档。
