# 扩展窗口页签 · 操作规范

本文约定工作台 **右侧扩展窗口**（`aux-right`）中 **「操作」页签**（`r-ops`）的视觉与排版。参考实现为 **销售订单详情** `/sales-orders/:id` 右栏「操作」。

**状态：** 已定稿  
**参考实现：** `SalesOrderDetail` + `SalesOrderItemOpsPanel`（`embedded`）  
**共享样式：** `CRM.Web/src/assets/styles/so-item-ops-panel.scss`  
**字段口径、门控、按钮何时出现：** [销售订单明细列表-操作面板-设计与实现](../../System/销售订单明细列表-操作面板-设计与实现.md)（列表与详情共用同一面板）

**关联：**

- 页签注册与展开默认：[扩展面板.工作台规范](./扩展面板.工作台规范.md)
- 只读「信息」页签（无按钮/进度）：[扩展窗口页签-信息规范](./扩展窗口页签-信息规范.md)
- 可点单号：[列表跳单号链接样式规范PRD](./列表跳单号链接样式规范PRD.md)
- 金额与币别后缀：[金额与币别代码显示范式](./金额与币别代码显示范式.md)
- 客户中英文只读：[供应商中英文名称只读展示规范PRD](./供应商中英文名称只读展示规范PRD.md) 的客户侧对应组件 `CustomerNameReadonlyText`

「扩展窗口」即 AppLayout 左右扩展辅助栏；本文只约束右栏 **操作页签内容区**，不改顶栏页签按钮。

## 1. 适用范围

| 适用 | 不适用 |
|------|--------|
| 右栏「操作」：摘要 + 推进单据（申请、通知、完成） | 「信息」页签（档案对照，见 [扩展窗口页签-信息规范](./扩展窗口页签-信息规范.md)） |
| 销售订单详情单击 **订单明细行** 驱动的面板 | 「流程」页签（地铁竖轴） |
| 与详情 **同一组件** 的销售订单明细列表 `/sales-order-items` | 「帮助」页签 |
| 其它列表操作面板（采购明细、质检、到货、出库等）的 **卡片层与控件样式** | 各页字段顺序与业务判定（仍写各模块设计文档） |

后续新「操作」页签须复用本文卡片类型与 token，不得另起白色投影抽屉或 20px 指标以外的第三套数字层级。

## 2. 外壳与卡片层（颜色）

操作页签 **必须** 嵌在 `aux-panel-tab-body`，使用 **embedded** 层。禁止 `.so-item-ops-panel` 独立灰底抽屉（`#f3f5f8` + 大投影）。

| 项 | 规范 |
|----|------|
| 根节点 | `.so-item-ops-root.so-item-ops-root--embedded`；详情/列表均传 `embedded` |
| 内容列 | `.so-item-ops-root__content--embedded`：纵向 `flex`，卡片间距 **12px**，`padding: 0` |
| 卡片 | `.ops-card` |
| 卡片背景 | `$layer-3`（浅色 `--crm-layer-3: #f8fafc`） |
| 边框 | `1px solid $border-panel` |
| 圆角 | **12px** |
| 阴影 | **无** |
| 标题 | `.ops-card__title`：14px / 600 |
| 标题区 | `.ops-card__head`：`12px 14px 0`；标题与右侧「已完成」横排 |
| 正文区 | `.ops-card__body`：`10px 14px 12px`（底与标题区顶留白同为 **12px**） |

## 3. 销售订单详情 · 卡片顺序（参考）

自上而下。条件卡不满足则 **整卡不渲染**（不留空壳）。

| 顺序 | 类型（本文） | 标题 | 显示条件 |
|------|--------------|------|----------|
| 1 | **概况** | 订单明细 | 已选明细行 |

| 3 | **双列 KV** | 备货库存 | 备货池可用合计 > 0 |
| 4 | **双列 KV + 色底** | 使用备货 | 有使用备货记录 |
| 5 | **操作 + 进度** | 采购申请 | 已选明细行 |
| 6 | **操作 + 进度** | 出库通知 | 已选明细行 |

未选行：13px 空态「请在「操作」页签下单击…」，不铺卡片。

## 4. 概况卡片

与信息页签概况 **同一套** `.ops-overview-line`（[扩展窗口页签-信息规范](./扩展窗口页签-信息规范.md) §4），操作页签用于行身份而不是客户档案。

| 项 | 规范 |
|----|------|
| 正文 | `.ops-card__body--overview`：纵向，行距 **6px** |
| **Hero** | `.ops-overview-line--hero`：明细编号；**18px / 700**；`$color-amber` |
| **其后各行** | `.ops-overview-line`：**13px / 500**，左对齐，**无「标签：」** |
| 空行 | 无内容则 **不占行**（如客户英文名为空或脱敏，不渲染该行） |
| 数量 | `{qty} pcs`：常规字重，**不用**强调色、**不加粗** |
| 单价 | 数值 + 空格 + 币别字母，见金额与币别范式 |

**销售订单详情行序（定稿）：** 销售订单明细编号（hero）→ 客户名称（`CustomerNameReadonlyText`）→ PN → 品牌 → 单价币别 → 数量 pcs。

概况卡 **无** 主操作按钮、**无** 状态标签网格。

## 5. 状态卡片

独立卡片，无 `.ops-card__title`。

| 项 | 规范 |
|----|------|
| 修饰 | `.ops-card--status-only`；正文 `.ops-card__body--status`（上内边距 10px） |
| 结构 | `.ops-status-tags` → `.ops-status-tags__row` → `el-tag` |
| 列 | **固定 3 列**网格；行间距 8px，列间距 8px |
| 单标签 | 仍占 **第一列 1/3 宽**，不得拉满整行 |
| 标签 | `effect="dark"`、`size="small"`；格内 `width: 100%` 居中 |
| 三态 | 扩展进度 0/1/2 → `el-tag` `type`：`info` / `warning` / `success`（`extendTriTagType`） |

**销售订单详情：** 两行 × 三列——采购 / 入库 / 出库；发货通知 / 收款 / 发票。

## 6. 双列 Key:Value 卡片（操作页签内的只读摘要）

用于备货库存、使用备货等。 **不是** 信息页签的一列「标签：值」清单。

| 项 | 规范 |
|----|------|
| 行 | `.ops-stock-region-row`：横向，间距 8px |
| 格 | `.ops-stock-region-cell`：各约 50%；**同行** `标签` + `：` + `值`，13px，左对齐 |
| 仅一字段 | 只放 **左格**，右半留空 |
| 标签色 | `$text-secondary` / embedded 下 `--crm-aux-hint` |
| 强调数量 | `.ops-kv__value--accent`：`$cyan-primary`、加粗（浅色约 `#0284c7`） |
| 整行合计 | `.ops-kv.ops-kv--divider`：顶部分隔线；标签左、值右；值可用 `.ops-kv__value--strong`（18px / 700） |
| 多组记录 | 组间 `.ops-stocking-usage-entry--divider` |

**使用备货** 额外色底（即使 embedded）：

| 项 | 规范 |
|----|------|
| 修饰 | `.ops-card--stocking-usage` |
| 背景 | `#fffbeb` |
| 边框 | `rgba(217, 119, 6, 0.14)` |

单号在值内 `router-link.link-text`，**不得**再配「查看 xxx」主按钮。

## 7. 操作 + 进度卡片

采购申请、出库通知等同构。

### 7.1 标题旁「已完成」

| 项 | 规范 |
|----|------|
| 类 | `.ops-card__done` |
| 字 | 12px / 600；色 `#67c23a` |
| 图标 | `CircleCheck`，14px |
| 完成态 | 标题旁展示「已完成 ✓」；**不渲染**主按钮、禁用提示、进度条 |

### 7.2 双列指标

| 项 | 规范 |
|----|------|
| 结构 | `.ops-metrics`：两列等分，间距 10px |
| 项 | `.ops-metrics__item`：上标签下数值，间距 4px |
| 标签 | 12px；次要色 |
| 数值 | **20px / 700**；正文色 |

**禁止**把信息页签的档案字段做成这一套大号指标。

### 7.3 进度条

| 项 | 规范 |
|----|------|
| 轨道 | `.ops-progress__track`：高 **10px**，全圆角；embedded 背景 `--crm-aux-tab-bg` |
| 采购 | `.ops-progress__bar--purchase`：`#f87171 → #ef4444` |
| 出库通知 | `.ops-progress__bar--stock-out`：`#38bdf8 → #0284c7` |
| 宽度 | `width: {0–100}%` |
| 显示时机 | **仅未完成**时渲染；已完成见 §7.1 / §7.6 |

### 7.4 提示与下一步

| 类 | 规范 |
|----|------|
| `.ops-status--warn` | 12px；危险色（阻断摘要） |
| `.ops-status--info` | 12px；`$cyan-primary` |
| `.ops-status--ok` | 12px；次要色 |
| `.ops-hint-list` | 12px 列表，左缩进 18px |
| `.ops-next-step` | 12px；圆角 8px；内边距 `8px 10px`；底 `rgba(56,189,248,.08)` / embedded `--crm-accent-005` |

### 7.5 主按钮

通栏，**一张操作卡最多一个**主按钮。

| 态 | 类 | 视觉 |
|----|-----|------|
| 可点 | `.ops-action-btn.ops-action-btn--primary` | 宽 100%；圆角 10px；内边距 `11px 14px`；14px / 600；底 **`#0f4c81`**；字白 |
| 置灰 | `.ops-action-btn--disabled` 或 `:disabled` | 底 `#e5e7eb`；字 `#9ca3af`；`cursor: not-allowed`；**opacity 保持 1** |
| 无权限且未完成 | **不渲染按钮**，只保留 hint（见各页设计文档） |

销售订单详情：未完成时「申请采购」「申请出库」分属两张卡。

### 7.6 完成态 · 生成对象单号（强制）

**参考实现：** 采购订单明细操作页签「申请付款」卡片（`OpsGeneratedDocsRow` + `付款单号`）。

操作 + 进度卡片进入 **「已完成」** 后，须在双列指标下方展示本卡片 **生成对象** 的业务单号；单击跳转对应详情/列表。未完成但已有单据时 **允许同样展示**（申请付款已如此）。

| 项 | 规范 |
|----|------|
| 位置 | 指标区下方、进度条/主按钮上方；与指标之间一条 **浅色横线**（`$border-panel`） |
| 结构 | 标签（如「付款单号」）+ `：` + 单号；多单号换行排列 |
| 字重 | 单号 **常规 400**，不加粗 |
| 链接 | `router-link` + `.link-text`，视觉同 [列表跳单号链接样式规范 PRD](./列表跳单号链接样式规范PRD.md) |
| 脱敏 | `maskSensitive` 时只显示纯文本，**不渲染链接** |
| 过滤 | 不列出已取消 / 已软删除单据 |
| 无单 | 不渲染该行（不出现空的「单号：」） |
| 完成态留白 | 不渲染进度条与主按钮后，卡片底留白与顶留白一致（标题区顶 12px / 正文底 12px） |

**各模块生成对象（操作页签）：**

| 卡片 | 标签 | 数据 | 跳转 |
|------|------|------|------|
| 申请付款 | 付款单号 | `aggregates.payments`（未删除、未取消） | `FinancePaymentDetail` |
| 到货通知 | 到货通知单号 | `aggregates.arrivalNotices` | `ArrivalNoticeList?noticeId=` |
| 采购申请 | 采购申请单号 | `aggregates.purchaseRequisitions`（非取消） | `PurchaseRequisitionDetail` |
| 出库通知 | 出库通知单号 | `aggregates.stockOutRequests`（非取消） | `StockOutNotifyDetail` |

信息类 KV 卡片（采购/质检/入库等）的单号仍走 §8 / 销售操作面板 **§2.5.4**，不改用本行布局。

## 8. 链接

与列表跳单号规范一致：`.link-text` 默认继承、无下划线；悬停主题蓝 + 下划线 + 手型。无权/脱敏不渲染链接。

---

## 9. 与「信息」页签的差异（强制）

| | 操作页签（本文） | 信息页签 |
|--|------------------|----------|
| 目的 | 推进单据 | 只读对照档案 |
| 概况 | 无标签 + hero 编号 | 同左（编码/客户号） |
| 其余 | 状态 3 列；双列 KV；大号指标 + 进度 + 主按钮 | **一列** 13px「标签：值」 |
| 色底卡 | 允许（如使用备货琥珀底） | 不用 |
| 主按钮 | `.ops-action-btn` | 无 |

## 10. 门控（交互，非视觉）

行单击是否请求数据：右栏展开且当前为 `r-ops`。细则见操作面板设计 **§2.4**、`useListRightOpsPanelInteraction`。视觉规范不改变该门控。

销售订单详情：单击主区 **订单明细** 表行绑定；与 `/sales-order-items` 共用 store / 组件。
