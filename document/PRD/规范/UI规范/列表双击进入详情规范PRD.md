# 列表双击进入详情规范 PRD

> **已合并**至 **[《列表交互规范》](./列表交互规范.md)**（§3 行级打开主记录）。本文档仅保留索引，避免历史链接失效。

## 现行规则摘要

| 操作 | 行为 |
|------|------|
| **双击**列表行 | 打开**详情页** |
| **Ctrl + 双击**列表行 | 打开**编辑页**（须具备与操作列「编辑」一致的写权限与编辑路由） |

完整适用范围、例外场景、操作列 `@dblclick.stop` 与实现示例见 **[列表交互规范.md](./列表交互规范.md)**。
