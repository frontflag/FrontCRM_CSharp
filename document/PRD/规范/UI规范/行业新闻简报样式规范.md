# 行业新闻简报样式规范

> **状态：** 已落地（控制台 `/dashboard`、历史页 `/industry-news`）  
> **设计 / 作业：** [行业新闻-设计与实现](../../../System/系统/行业新闻-设计与实现.md)  
> **QA：** [行业新闻-测试对照说明](../../../QA/系统/行业新闻-测试对照说明.md)  
> **帮助：** [控制台](../../../../help/pages/控制台_MENU_DASHBOARD.md)、[每日行业新闻](../../../../help/pages/每日行业新闻_MENU_INDUSTRY_NEWS.md)  
> **实现：** `IndustryNewsPanel.vue`、`IndustryNewsHistoryPage.vue`、`IndustryNewsBriefingView.vue`、`industryNewsMarkdown.ts`

统一控制台「行业新闻」卡片、今日弹层与历史页的版式。模型原文格式不稳定时，**展示层**按本文规范化，不要求先改提示词或重跑简报。

---

## 1. 适用范围

| 包含 | 不包含 |
|------|--------|
| 控制台风险预警下方的行业新闻卡片 | 物料情报里的行业新闻条目（`IndustryNewsItemView`） |
| 「查看今日」全文弹层（Markdown 五节 + 右侧目录） | 侧栏菜单、外链、评论 |
| 「每日行业新闻」历史页（左日期 / 右正文+目录） | 失败日期占位 |

---

## 2. 控制台卡片

与个人提成、业务总览、风险预警同级：白底、浅描边、圆角 12px、内边距约 16×20。

| 区域 | 样式 |
|------|------|
| 标题 | 「行业新闻」，15px、字重 600 |
| 元信息 | 标题右侧，12px 次要色。「今日简报 · N条」或「非今日简报 · N条」（N≤5） |
| 操作 | 右侧文字链，12px 主题色；悬停下划线。禁用为灰色、不可点。顺序：立即刷新（管理员）→ **查看历史** → **查看今日** |
| 「查看历史」 | 登录即可点；进应用内页签「每日行业新闻」，不新开浏览器标签 |
| 「查看今日」 | 登录可见；无简报时禁用；仍弹层，不跳历史页 |
| 「立即刷新」 | 仅系统管理员；生成中文案改为「生成中…」并禁用 |
| 空态 | 13px 次要色：「暂无简报，将于每日上午 8 点更新」或「今日暂无条目」 |

**禁止文案：** 「实时资讯」「15 分钟前」等即时感措辞。

### 2.1 条目行（最多 5 条）

一行两列，整行可点（与「查看今日」同一份当天全文）。**不展示**新闻发生日期：

```text
[分类标签]  标题（单行省略）
```

| 元素 | 样式 |
|------|------|
| 行 | 上下 8px；行间极浅分割线；手型光标 |
| 分类标签 | 11px、字重 600、圆角 4px、左右 6px；六维固定配色见下表 |
| 标题 | 13px、字重 600、主文字色；超出省略，不换行 |

**分类标签配色（强制）：**

| 分类 | 文字 | 底 |
|------|------|----|
| 行业动态 | `#3b5bdb` | `#edf2ff` |
| 关键厂商 | `#7048e8` | `#f3f0ff` |
| 行情价格 | `#e67700` | `#fff4e6` |
| 重组并购 | `#0b7285` | `#e3fafc` |
| 公司治理 | `#2b8a3e` | `#ebfbee` |
| 展会信息 | `#c2255c` | `#fff0f6` |
| 其它 / 未映射 | 常规文字色 | 填充色 |

## 3. 全文弹层

| 项 | 口径 |
|------|------|
| 标题 | 「行业新闻简报（M-D）」；无日期则「行业新闻简报」 |
| 宽度 | 920px |
| 主体 | 左正文 + 右目录；高度 `min(70vh, 640px)`，最小 280px |
| 非今日 | 正文顶警示色提示：「这是上一份成功简报。今日更新尚未完成。」 |
| 窄屏 | ≤640px 隐藏右侧目录 |

### 3.1 右侧目录

- 栏宽 148px，左边框分隔。
- 顶栏「目录」，11px 次要色。
- 二级标题（本周要闻 / 分类详述 / 行情速览 / 本周展望 / 内容总结）为一级目录；分类详述下的六维为缩进子项。
- 当前节主题色 + 字重 600；悬停同样变主题色。
- 点击平滑滚到对应标题。

### 3.2 正文排版（五节共用）

| 元素 | 样式 |
|------|------|
| 正文字号 | 13px，行高 1.7 |
| 二级标题 `h2` | 16px，棕色 `#8d4e16`；第一节无上边距 |
| 三级 / 分类名 | 14px、字重 600 |
| 段落 | 下边距 8px |
| 表格（行情速览） | 12px，细边框，单元格 6×8 |

标题前不要「一、二、三、四、五」；段落前不要阿拉伯序号。

## 4. 历史页「每日行业新闻」

从控制台「查看历史」进入，路由 `/industry-news`。**不加侧栏菜单**。顶栏页签标题为「每日行业新闻」；`?date=` 只换右侧正文，不新开页签。

| 区域 | 样式 |
|------|------|
| 整体 | 与控制台卡片同级的白底描边圆角容器；左右分栏，高度约 `calc(100vh - 132px)` |
| 左侧日期 | 栏宽 188px，右边框分隔。成功日倒序。主行 `YYYY-MM-DD` 13px 字重 600；副行「覆盖 M-D～M-D」11px 次要色 |
| 当前日 | 主题色浅底 |
| 失败日 | **不出现**，无灰色占位 |
| 右侧 | 与今日弹层相同的正文 + 148px 目录（`IndustryNewsBriefingView` `variant=page`） |
| 空态 | 「暂无历史简报」；某日无成功行：「这一天没有简报」 |
| 窄屏 | ≤640px 隐藏右侧目录（与弹层相同） |

「查看今日」仍走弹层，不跳本页。

## 5. 「本周要闻 Top 5」五角星（强制）

每条新闻**行首只保留一颗**五角星 `★`，作为条目引导，**不是**重要性计数。

| 模型原文（示例） | 展示 |
|------------------|------|
| `★★★ 2026-09-12 英伟达…` | `★ 2026-09-12 英伟达…` |
| `苹果秋季发布会… ★3` | `★ 苹果秋季发布会…` |
| `2026-09-12 ★3 英伟达…` | `★ 2026-09-12 英伟达…` |
| `- ★★ 标题`（列表） | `- ★ 标题` |

**禁止：**

- 连续多颗星（★★、★★★）
- 星后跟 1–3 表示重要性（`★3`、`★ 2`），无论在行首、日期后还是句末
- 给「分类详述」等其它节强制加行首星（其它节仅把连续星收成一颗，位置不动）

日期里的数字（如 `2026-09-12`）不得被当成星级吃掉。

---

## 6. 「内容总结」圆点与折行（强制）

### 6.1 一句一行 + 行首圆点

按 **句号**（`。` / 句末英文 `.`）或 **分号**（`；` / `;`）切句。每句单独一行，行首 **实心圆点**（`list-style: disc`），用于引导和强调。

小数点（`1.5`）、URL 中的点不切句。

```text
• 本周行业主线为"……拉动"。
• 摩根士丹利上调 WFE 预测……加剧全球竞争。
• 对采购团队建议：……替代机会；
• 对销售团队建议：……波动风险。
```

长句在容器内自动换行，仍算 **一条**（续行不再加圆点）。

### 6.2 冒号后折行、不加圆点

句中出现中文冒号 `：`（或非 URL/时刻的英文 `:`）时：

- **冒号留在当前行末**
- **冒号后的内容另起一行**
- **续行不加圆点**，仍属同一条（挂在同一圆点下）

```text
• 本周行业主线围绕 AI 资本化加速与分化展开：
  Anthropic 拟创纪录 IPO 及英伟达潜在巨额投资……审慎。
• 对采购团队建议：
  优先锁定 DDR5 及 HBM 长单，关注苹果供应链国产替代机会；
```

**不要**把冒号后拆成新的圆点条目。  
`http://`、`https://`、时刻 `12:30` 中的冒号不折行。

## 7. 其它节

| 节 | 样式要点 |
|------|----------|
| 分类详述 | 六维小标题 + 段落；不强制行首星或按句拆点 |
| 行情速览 | 四列表格：品类 / 本周变化 / 驱动因素 / 后市判断 |
| 本周展望 | 普通段落；不强制圆点列表 |

## 8. 实现约定

展示规范化在打开弹层或历史页时做，**不改库里的 markdown**：

| 文件 | 职责 |
|------|------|
| `industryNewsMarkdown.ts` | Top 5 收星、内容总结切句/圆点/冒号折行 |
| `IndustryNewsBriefingView.vue` | 弹层与历史页共用正文 + 目录 |
| `IndustryNewsPanel.vue` | 卡片、今日弹层、查看历史入口 |
| `IndustryNewsHistoryPage.vue` | 左日期、右正文 |

改样式时同步改本文与 QA 用例 16a / 16b。
