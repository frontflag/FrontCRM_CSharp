# 列表跳单号链接样式规范 PRD（V1.1）

## 1. 文档目的

统一业务列表、流水表、详情嵌套面板表格中 **可点击跳转的业务单号**（收款单号、应收单号、出库单号、销售订单号等）的视觉与交互：默认与同行普通文字一致，仅在悬停时呈现链接态，避免列表大面积常驻蓝色干扰阅读。

---

## 2. 适用范围

- 表格单元格内通过 `router-link` / `<a>` 跳转至 **其他业务详情页** 的单号、编码
- **典型场景**：收款核销流水、应收款列表、财务类流水表、详情页 Tab 内下游单据列表中的单号列

**不包含：**

- 操作列「查看 / 编辑」按钮（见 [列表操作按钮颜色规范 PRD](./列表操作按钮颜色规范PRD.md)）
- CaptionBar 标题中的主单号（见 [业务详情页面规范 §3.2](./业务详情页面规范.md)）
- 仅展示、不可跳转的单号文本

---

## 3. 交互与视觉（强制）

| 状态 | 文字颜色 | 下划线 | 光标 |
|------|----------|--------|------|
| **默认** | 继承单元格文字色（`color: inherit` 或 `var(--crm-table-text)`） | 无 | `default` |
| **`:hover`** | 主题蓝 `var(--el-color-primary)` | 有 | `pointer` |
| **鼠标移出** | 恢复默认 | 无 | `default` |

**原则：**

1. 默认态 **不得** 使用主题色/冰蓝色，避免与「已访问链接」或「强调编码」混淆；
2. 悬停态须同时具备 **变色 + 下划线 + 手型光标**，明确可点击；
3. 深浅主题下，默认色跟随表格正文（`--crm-table-text`），悬停色跟随 Element Plus 主色变量。

---

## 4. 实现约定

### 4.1 推荐 CSS 类名：`.link-text`

```scss
.link-text {
  color: inherit;
  text-decoration: none;
  cursor: default;

  &:hover {
    color: var(--el-color-primary);
    text-decoration: underline;
    cursor: pointer;
  }
}
```

- 财务模块可放在 `CRM.Web/src/views/Finance/finance-common.scss` 供各财务列表/流水页 `@import` 复用；
- 非财务列表页可复制同等规则，或后续抽取为全局工具类（评审时与现有 `.so-tab-link` 区分场景）。

### 4.2 模板结构

```vue
<router-link
  v-if="row.targetId && row.targetCode"
  class="link-text"
  :to="`/path/${row.targetId}`"
>
  {{ row.targetCode }}
</router-link>
<span v-else>{{ row.targetCode || '—' }}</span>
```

- 有目标主键且有权跳转时渲染 `router-link`；否则回退为普通 `span` 或 `—`；
- **单击**跳转；不与 [列表交互规范](./列表交互规范.md) 行级双击进详情冲突（列内链接须正常冒泡或按需 `@click.stop` 仅用于操作列）。

### 4.3 参考实现

| 页面 | 路径 | 说明 |
|------|------|------|
| 收款核销流水 | `CRM.Web/src/views/Finance/FinanceReceiptWriteOffLedgerPage.vue` | 收款单号、应收单号、出库单号、销售订单号四列 |
| 应收款列表 | `CRM.Web/src/views/Finance/FinanceReceivableList.vue` | 出库单号等（样式应对齐本章，逐步统一） |

## 5. 与 `.so-tab-link` 的区别

[业务详情页面规范 §7.4.7](./业务详情页面规范.md) 中的 **`.so-tab-link`** 用于销售/采购订单 **嵌套明细面板 Tab 内** 下游列表链接，当前为 **常驻主题色 + `font-weight: 500`**。

| 类名 | 默认外观 | 适用 |
|------|----------|------|
| **`.link-text`** | 与表格正文同色 | **独立列表页、流水表** 中单号跳转（本章规范） |
| **`.so-tab-link`** | 主题色、中等字重 | 详情页底部嵌套面板 Tab 内链接（既有约定，后续可评估是否统一为 `.link-text`） |

新建 **列表/流水类** 跳单号链接时 **优先使用 `.link-text`**；不得在未评审的情况下混用「默认蓝色链接」样式。

**例外：** 右侧「流程」页签卡片内的单号默认同正文、无下划线；悬停橙色、仍无下划线。见 [流程页签规范 §2.6](./流程页签规范.md)。

---

## 6. 验收自检

- [ ] 未悬停时，单号与相邻非链接列文字颜色一致；
- [ ] 悬停时变蓝、出现下划线、光标为手型；
- [ ] 移出后恢复默认，无残留下划线或蓝色；
- [ ] 无 `targetId` 时显示 `—` 或纯文本，不渲染空链接；
- [ ] 浅色/深色主题下对比度可读。
