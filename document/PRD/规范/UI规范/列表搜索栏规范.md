# 列表搜索栏规范

## 1. 定义与适用范围

**列表搜索栏**指数据列表页中、位于**页面标题区下方**、**数据表格上方**的一行（可多行折行）**筛选与检索控件带**：用于组合关键词、枚举筛选、日期区间与「搜索 / 重置」操作。

- **本规范来源**：`/customerlist`（`CustomerList.vue`）中 `.search-bar` 及其子元素的**布局与样式**（不含业务字段含义与各 `el-option` 数据）。
- **适用场景**：各类列表页（客户、供应商、订单、采购申请等）需与当前主站深色主题**视觉与间距一致**时，应优先复用本结构的 **类名与 SCSS 规则**；具体筛选项数量与顺序可按业务裁剪。

**不在本规范内**：列表页标题栏（`.page-header`）、表格与分页本体；全局 `crm-unified-list.scss` 中的表格皮肤。

## 2. 结构约定（DOM）

### 2.1 容器层级

```
.search-bar
  └── .search-left
        ├── .search-input-wrap
        │     ├── svg.search-icon（放大镜）
        │     └── input.search-input
        ├── el-select.status-select / el-select.filter-select（可多个；见 §9「交易币别」等固定二元/小枚举）
        ├── 日期区间控件（见 §5.2，固定复用客户列表「创建起 / 创建止」双输入样式）
        ├── button.btn-primary.btn-sm「搜索」
        └── button.btn-ghost.btn-sm「重置」
```

### 2.2 布局类职责

| 类名 | 职责 |
|------|------|
| `.search-bar` | 外层横向条：与表格之间留间距，右侧可预留扩展（当前实现多为单 `.search-left` 占满） |
| `.search-left` | **主的内容行**：`flex` + `flex-wrap`，控件横向排列，窄屏自动折行 |
| `.search-input-wrap` | 包裹**原生** `input` + 左侧内嵌搜索图标 |
| `.search-input` | 单行关键词输入，默认宽度见 §4；可用 BEM 修饰类（如 `--narrow`）在业务页收窄 |
| `.status-select` | `el-select` 深色皮肤与统一宽度；业务员等较长文案可加 `.status-select--sales` 加宽 |
| `.filter-select` | 固定小枚举下拉（如 **交易币别** §9）；默认 `width: 130px`，皮肤与 `.status-select` 一致 |
| 日期区间控件 | **必须**使用客户列表同款双日期输入控件（起始 + 分隔 + 结束），禁止改为 `type="daterange"` 单体控件 |
| `.btn-primary` / `.btn-ghost` | 搜索 / 重置；使用 **`.btn-sm`** 与列表页尺度匹配 |

- 字体：可按需引入 `Noto Sans SC`（与 `CustomerList.vue` 一致）。

## 4. 操作按钮

| 按钮 | 类 | 规范 |
|------|-----|------|
| 搜索 | `btn-primary btn-sm` | 青蓝渐变、白字、小尺寸（`padding: 6px 12px`; `font-size: 12px`）；`hover` 轻微上移 + 外发光（与客户列表一致） |
| 重置 | `btn-ghost btn-sm` | 透明底、边框 `$border-panel`、muted 字色；`hover` 边框与字色略提亮 |

## 5. Element Plus 与交互约定

| 项目 | 约定 |
|------|------|
| `el-select` | 列表页检索条内建议使用 **`:teleported="false"`**，避免下拉层级与侧栏/遮罩异常；`clearable` 按业务开启 |
| 筛选变更 | **下拉变更即搜**（`@change="handleSearch"`）可减少「点了筛选却忘点搜索」的落差；若后端压力大可改为仅按钮触发，但须统一产品行为 |
| 关键词 | `input` 使用 **`@keyup.enter="handleSearch"`** |
| 日期区间 | `@change` 内在业务侧写入查询参数并触发列表刷新（与客户列表 `onCreatedRangeChange` 模式一致） |

### 5.1 强制要求：字段标题显示方式

- **搜索字段不再使用引导标题**（不显示 `关键词 / 状态 / 类型 ...` 这类字段名前置文案）。
- 字段语义必须放在**控件内部**体现：
  - 文本框使用 `placeholder`（如 `客户名称 / 联系人...`）。
  - 下拉框使用 `placeholder`（如 `全部状态`、`全部行业`）。
  - 日期区间两端分别显示 `创建起 / 创建止`。

### 5.2 强制要求：时间区间控件统一

- 全列表页时间区间控件必须统一为**客户列表搜索栏同款**（双输入 + 中间分隔“至”）。
- 不允许在列表搜索栏改成单个 `el-date-picker type="daterange"` 作为默认实现。
- 统一行为：
  - `value-format="YYYY-MM-DD"`
  - 两端可清空（`clearable`）
  - `:teleported="false"`

## 6. 字段顺序（参考，非强制）

客户列表当前顺序为：

**关键词 → 状态 → 级别 → 类型 → 行业 → 业务员 → 创建日期区间 → 搜索 → 重置**

其他列表建议遵循：

1. **最广的文本检索**（关键词 / 单号）靠前；  
2. **高频枚举**（状态）次之；  
3. **辅助维度**（类型、人员、日期）随后；  
4. **搜索 / 重置**始终在同一行末尾（折行时尽量保持二者相邻）。

---

## 7. 扩展与裁剪

- **多个关键词框**：直接使用多个 `.search-input-wrap` + `.search-input`；可通过修饰类收窄宽度（如 `.search-input--narrow { width: 180px; }`）。
- **字段标题**：统一放在控件内部（placeholder），不再新增外置 `.filter-field-label`。
- **筛选项少**：仍建议使用相同 `.search-bar` / `.search-left` / 按钮样式，保持全站一致。
- **禁止**：在检索条内使用浅色未覆盖的 `el-input` 默认白底作为唯一主文本框（破坏深色规范）；应使用本规范的 **原生 `input.search-input`** 或同步做深度主题覆盖。

## 9. 交易币别筛选下拉（二元枚举）

> **状态：已落地** — 销售订单明细 `/sales-order-items`（`SalesOrderItemList.vue`）、采购订单明细 `/purchase-order-items`（`PurchaseOrderItemList.vue`）。其他需按「人民币 / 外币」粗粒度筛明细结算币别的列表，应复用本节 UI 与查询口径，勿在页面内自造第三套 value 文案。

### 9.1 业务含义

| 筛选项（界面文案） | 含义 |
|-------------------|------|
| **人民币** | 明细行结算币别 `Currency = 1`（`CurrencyCode.RMB`） |
| **外币** | 明细行结算币别 `Currency ≠ 1`（USD / EUR / HKD / JPY / GBP 等） |

与 [金额与币别代码显示范式](./金额与币别代码显示范式.md) 中「币别数字枚举 → 字母」一致：`1` 为人民币，其余均为外币。

### 9.2 UI 结构（强制）

- **控件**：`el-select`，类名 **`filter-select`**（宽度约 `130px`，深色皮肤与 §3 一致）。
- **配置**：`clearable`、`:teleported="false"`；**不使用**外置字段标题，占位符为 **`交易币别`**（i18n key 见下）。
- **选项**（固定两项，value 为英文小写代码，label 为中文产品文案）：

| `el-option` value | 界面 label（zh-CN） |
|------------------|---------------------|
| `rmb` | 人民币 |
| `foreign` | 外币 |

- **触发搜索**：与本页其他筛选项一致，由 **「查询」按钮** 触发（`runSearch` / `handleSearch`）；清空后点查询即取消该维度筛选。若全站该列表已约定下拉 `@change` 即搜，可统一改为即搜，但须在 PR 说明并与同页其他下拉行为一致。
- **重置**：「重置」须将 `filters.transactionCurrency` 置空并重新拉列表。

**模板参考（节选）：**

```vue
<el-select
  v-model="filters.transactionCurrency"
  clearable
  :placeholder="t('salesOrderItemList.filters.transactionCurrency')"
  class="filter-select"
  :teleported="false"
>
  <el-option :label="t('salesOrderItemList.filters.transactionCurrencyRmb')" value="rmb" />
  <el-option :label="t('salesOrderItemList.filters.transactionCurrencyForeign')" value="foreign" />
</el-select>
```

**样式参考（节选）：**

```scss
.filter-select {
  width: 130px;
  :deep(.el-select__wrapper) {
    background: $layer-2 !important;
    box-shadow: none !important;
    border: 1px solid $border-panel !important;
    border-radius: $border-radius-md !important;
  }
}
```

### 9.3 前端状态与请求参数

| 项目 | 约定 |
|------|------|
| 表单字段 | `filters.transactionCurrency: '' \| 'rmb' \| 'foreign'` |
| 请求 query | 仅在有值时传 `transactionCurrency=rmb` 或 `transactionCurrency=foreign` |
| API 封装 | `salesOrderApi.getItemLines({ ..., transactionCurrency?: 'rmb' \| 'foreign' })` → `GET /api/v1/sales-orders/items` |
| i18n（zh-CN） | `filters.transactionCurrency` = 交易币别；`transactionCurrencyRmb` = 人民币；`transactionCurrencyForeign` = 外币 |
| i18n（en-US） | `Transaction currency` / `RMB` / `Foreign currency` |

### 9.4 后端查询逻辑（强制口径）

| 层级 | 说明 |
|------|------|
| Controller | `[FromQuery] string? transactionCurrency` → 写入 `SellOrderItemLineQueryRequest.TransactionCurrency` |
| 列表查询 | `SalesOrderItemLineListQuery` 在已有 join 条件上追加： |
| `rmb`（及兼容 `cny`、`人民币`） | `item.Currency == (short)CurrencyCode.RMB` |
| `foreign`（及兼容 `外币`） | `item.Currency != (short)CurrencyCode.RMB` |
| 空 / 未传 | 不按币别过滤 |

**工程路径：**

- 请求 DTO：`CRM.Core/Interfaces/ISalesOrderService.cs` → `SellOrderItemLineQueryRequest.TransactionCurrency`
- 查询实现：`CRM.Infrastructure/SalesOrders/SalesOrderItemLineListQuery.cs`
- 接口入口：`CRM.API/Controllers/SalesOrdersController.cs` → `GET items`

### 9.5 字段顺序建议

在含「物料型号」文本检索的明细列表中，建议顺序为：

**… → 物料型号 → 交易币别 → 查询 → 重置**

（销售订单明细页当前实现与此一致。）

### 9.6 复用与禁止事项

- **应复用**：同一套 value（`rmb` / `foreign`）、同一后端过滤语义、同一 `filter-select` 皮肤。
- **禁止**：在搜索栏再增加「RMB / USD / EUR」逐项币别下拉冒充「交易币别」；细粒度 ISO 币别筛选属另一类需求，须单独 PRD 与参数名（如 `settlementCurrency`），不得覆盖本节二元口径。
- **扩展**：若采购订单明细、出库明细等列表需要相同「人民币 / 外币」筛选，复制 §9.2–§9.4 模式，按各模块明细表 `Currency` 字段落库位置实现查询，参数名可统一为 `transactionCurrency`。
- **页签模式**：交易币别可切换为筛选页签条，见 **§10**；开启页签时搜索栏内隐藏本下拉。

### 10.1 何时使用

| 适合 | 不适合 |
|------|--------|
| 搜索栏中**单选、选项少**（约 2～4 档 +「全部」）的枚举 / 进度下拉；若产品确认可等分展示，可放宽到更多档（如需求明细 6 态 +「全部」= 7 格） | 文本框、日期区间、多选、选项很多或动态人员的下拉 |
| 用户需在桶之间**频繁切换**并立即看结果 | 仅偶发筛选、且希望与「查询」按钮统一触发 |

### 10.2 交互基线（强制）

| 项 | 约定 |
|----|------|
| **单维度** | 同一列表同一时间只允许**一个**筛选项处于页签模式；切换维度即替换页签条，不清空其它筛选项的值 |
| **入口** | 搜索栏末尾（查询 / 重置 / 视图切换旁）提供齿轮菜单：「关闭页签」+「页签模式 ▸」子菜单列出可选维度 |
| **开启** | 选中某维度 → 隐藏对应 `el-select`，在**表格/看板上方**显示全宽页签条（与表顶贴合，去掉表格顶圆角） |
| **页签内容** | 首项为「全部」（清空该维度），其余与原下拉选项一一对应 |
| **点页签** | **立即查询**（写入 filter + 刷新列表/看板），不要求再点「查询」 |
| **关闭页签** | 恢复下拉；**保留**当前筛选值；「关闭页签」在未开启时禁用 |
| **偏好** | 用 `localStorage` 记住当前维度（键名按列表约定，如 `crm.so-item-list.tab-mode`） |

### 10.3 与左栏快捷检索（preset）并存时

若列表同时有左栏 preset，且 preset 会隐藏/禁用日期与进度类搜索项，则：

| 维度类型 | preset 激活时 |
|----------|----------------|
| **进度类**（与 preset 互斥的那些下拉） | **隐藏**页签条；「页签模式」子菜单中对应项也**隐藏**（不是禁用灰显） |
| **非互斥维度**（如 §9 交易币别；采购明细另含订单类型） | 页签条与菜单项**仍可**使用 |

清除 preset 后，按已保存偏好恢复进度类页签（若偏好仍是进度维度）。

### 10.4 视觉基线

| 项 | 约定 |
|----|------|
| 布局 | 页签等分占满内容区宽度；顶圆角、底边与表格齐平 |
| 未选中背景（亮色） | `#E8EDF5` |
| 未选中背景（暗色） | 使用主题层色（如 `var(--crm-layer-1)`），**禁止**沿用亮色浅底导致发白 |
| 选中态 | 顶边品牌色强调（如 cyan inset）+ 与 `layer-2` 的轻微混合；字重略加 |
