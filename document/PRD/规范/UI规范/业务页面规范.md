# 业务页面规范（总览）

本文档对**业务相关前端页面**（以列表、详情、筛选与表格行为主）所遵循的 UI 规范做**索引与引用**，具体条款以各子文档为准。

**适用范围：** 客户、供应商、询价/订单、库存、财务等业务模块中的列表页、详情页及其共用组件；实现时与代码注释中提及的《业务列表规范》等表述一致时，以对应链接文档为准。

**工程规范（强制）：** [import 路径大小写](../前端规范/import路径大小写规范.md) — Windows 开发时 `import` 路径须与磁盘目录名大小写完全一致，提交前须 `vue-tsc` / `npm run build`。

**操作列（强制对齐）：** 凡业务模块内 **含行级「操作」列** 的列表或详情内嵌表（`CrmDataTable` / `el-table` 末列固定操作区），均须完整实现 **[《列表操作列规范》](./列表操作列规范.md)**（列头 `<`/`>` 切换、收起态 `...` 下拉、展开态平铺、列宽与 `op-col` 等）；**调试页等** 仅在《列表操作列规范》**豁免**条款或 PRD 明示时可例外，并在代码注释中注明依据。
