# 业务详情页面规范

**文档版本**: 1.6  
**创建日期**: 2026-06-26  
**最后更新**: 2026-06-26  
**参考实现**: `CRM.Web/src/views/RFQ/RFQDetail.vue`（需求详情页）、`CRM.Web/src/views/RFQ/SalesOrderDetail.vue`（销售订单详情页）、`CRM.Web/src/views/RFQ/PurchaseOrderDetail.vue`（采购订单详情页）、`CRM.Web/src/views/Customer/CustomerDetail.vue`（客户详情页）、`CRM.Web/src/views/Vendor/VendorDetail.vue`（供应商详情页）  
**对齐页面**: `PurchaseOrderDetail.vue`（暗色区块/Tab 标题栏底色来源）

## 1. 定义与适用范围

**业务详情页**指展示单张业务单据（需求、销售订单、采购订单等）或主数据实体（客户、供应商等）的只读/轻操作页面，典型结构为：

```text
CaptionBar（顶栏）
  ↓
主信息区块 × N（基础信息、业务属性…）
  ↓
标签页区块（明细 / 文档 / 日志…）
  ↓
  ├─ 列表视图（内嵌表）
  └─ 面板视图（卡片化明细，可选）
```

- **顶栏基础布局**仍遵循 [详情 CaptionBar 规范](./详情CaptionBar规范.md)。
- **CaptionBar 左侧两行字段**分两类：**§3.1–§3.6 单据类**（需求、销售订单、采购订单等）；**§3.7 主数据类**（**仅**客户详情、供应商详情，见 §3.7.0）。
- **本文档**补充详情页在 CaptionBar 扩展、信息网格、Tab、列表/面板双视图上的**统一参数**，便于新详情页直接套用类名与色值。
- 无 Tab、无面板视图的简单详情页，可只采用 §3–§5；有子表明细切换时采用 §6–§8；有**嵌套明细面板**（双击行展开下游 Tab + 列表）时，面板内列表另见 **§7.4**。

## 3. CaptionBar 扩展

在 [详情 CaptionBar 规范](./详情CaptionBar规范.md) 基础上，CaptionBar **左侧文字区**分两类布局：

| 类型 | 章节 | 适用页面 |
|------|------|----------|
| **单据类** | §3.1–§3.6 | 需求、销售订单、采购订单等业务单据详情 |
| **主数据类** | **§3.7** | **仅**客户详情、供应商详情 |

**禁止混用：** 单据类页面**不得**采用 §3.7 的「全称 + 编码/等级」两行布局；客户/供应商详情**不得**采用 §3.3 的「主单状态 + 明细统计」副标题行。

---

### 3.1 整体结构（单据类）

**适用范围：** 需求、销售订单、采购订单等业务单据详情。客户/供应商见 **§3.7**。

```text
page-header
├─ header-left
│  ├─ btn-back（返回）
│  └─ rfq-title-group（或 {entity}-title-group）
│     ├─ rfq-avatar-lg（实体图标）
│     └─ 文字列
│        ├─ page-title-row → page-title-with-icons（标题行）
│        └─ title-meta.title-meta--caption.rfq-header-meta-row（副标题行）
└─ header-right（右侧操作组）
```

### 3.2 标题行 `page-title-with-icons`（单据类）

**适用范围：** 单据类详情页（§3.1）。主数据类见 **§3.7.2**。

**横向顺序（从左到右）：**

1. `h1.page-title` — **业务前缀 + 空格 + 主单号**（见 §3.2.1）
2. `btn-favorite-star` — 收藏
3. **主表标签区**（可选，见 §3.5）— 已打标签 chip + 「± 标签」按钮
4. **弱标签** `.source-tag`（可选）— 来源等；**无有效值时不渲染**

**不在标题行展示：** 主记录状态、明细报价统计 pill（已移至副标题行，见 §3.3）。

```text
[ 需求 RFQ00200 ] [ ☆ ] [ 重点跟进 ] [ 123 ] [ ± 标签 ] [ 来源 ]
```

| 控件 | 类名 / 组件 | 说明 |
|------|-------------|------|
| 主标题 | `h1.page-title` | 20px / semibold / `$text-primary` |
| 收藏 | `.btn-favorite-star` | 见 §3.4 |
| 标签 chip | `TagListDisplay` | 系统/自定义标签胶囊；无标签时不占位 |
| 打标签 | `.btn-secondary.rfq-header-add-tag-btn` | 图标 `±` + 文案「标签」；见 §3.5 |
| 来源 | `.source-tag` | 11px 弱标签；无值不渲染 |

**布局参数：**

```scss
.page-title-row {
  display: flex;
  align-items: center;
  gap: 10px;
  margin-bottom: 6px;
}
.page-title-with-icons {
  display: flex;
  align-items: center;
  gap: 8px;
  flex-wrap: wrap;
  min-width: 0;
}
.title-meta--caption {
  margin-top: 4px;
}
.rfq-header-meta-row {
  min-height: 28px;
}
```

#### 3.2.1 主标题文案格式（需求类）

| 项目 | 规范 |
|------|------|
| 格式 | `{业务前缀} {主单号}` — **前缀与单号之间一个半角空格** |
| 前缀 | i18n `rfqCodePrefix`；中文 **「需求」**（**不带冒号**） |
| 示例 | `需求 RFQ00200` |
| 加载中 | 无单号时回退为页面标题（如「RFQ 详情」） |
| 重复展示 | **CaptionBar 已展示单号时，基础信息区块不再重复「需求单号」字段** |

其他单据可沿用 `{实体简称} {单号}` 模式，前缀与冒号规则由业务 i18n 定义，但须保持**前缀与单号之间有空格**。

### 3.3 副标题行 `title-meta.title-meta--caption`（单据类）

**适用范围：** 单据类详情页（§3.1）。主数据类见 **§3.7.3**。

**放主单状态与明细统计**，不放客户名、不放标签操作。

**横向顺序（从左到右）：**

1. **主记录状态** — `el-tag`（与**同模块列表页「状态」列**样式一致，见 §3.3.1）
2. **明细报价统计 pill**（可选）— `.item-quote-stats-bar.item-quote-stats-bar--header`；仅 `count > 0` 的项展示；多项之间用 **`·`** 分隔

```text
[ 已分配 ] [ 待报价 1 行 · 已报价 1 行 ]
```

| 控件 | 组件 / 类名 | 说明 |
|------|-------------|------|
| 主记录状态 | `el-tag` | **`effect="dark"`** + **`size="small"`**；`:type` 与同模块列表状态列映射**完全一致**；**禁止**使用详情页自定义 `.status-badge` |
| 统计容器 | `.item-quote-stats-bar--header` | `margin/padding/border: 0`；透明底；`gap: 6px` |
| 统计分隔 | `.item-quote-stats__sep` | 字符 `·`；12px；`$text-muted` |
| 统计 pill | `.item-quote-stats__pill--pending` / `--quoted` / `--no-quote` | header 变体：11px；圆角胶囊 |

#### 3.3.1 主记录状态 — 对齐列表「状态」列

CaptionBar 副标题行的**主单状态**，须与对应业务**列表页状态列**使用同一套 Element Plus Tag 样式，保证详情与列表视觉一致（实心底 + 白字，如「已分配」橙色、`warning`）。

| 项目 | 规范 |
|------|------|
| 组件 | `<el-tag effect="dark" :type="getStatusType(status)" size="small">` |
| 文案 | 与列表状态列 i18n **同源**（如需求：`rfqList.status.*`） |
| 色型映射 | **复用列表页** `getStatusType` / 业务状态工具，**不得**在详情页单独维护一套半透明 `.status-badge` CSS |
| 参考实现 | 需求：`RFQDetail.vue` ↔ `RFQList.vue`；销售订单：`SalesOrderDetail.vue` ↔ `SalesOrderList.vue`（`salesOrderStatusTagType`） |

**需求（RFQ）主状态 `type` 映射（与 `RFQList.vue` 一致）：**

| status | `el-tag` type |
|--------|----------------|
| 0 待分配 | `info` |
| 1 已分配 | `warning` |
| 2 处理中 | `primary` |
| 3 已报价 | `success` |
| 4 已选中 | `success` |
| 5 已转单 | `success` |
| 6 / 7 已关闭 | `info` |
| 8 已取消 | `warning` |

**禁止：** 副标题行主状态使用 `.status-badge.status-{n}` 或详情页私有半透明描边样式（2026-06-26 前 RFQ 旧实现已废弃）。

**统计口径（需求明细）：** 与列表 `effectiveItemLineStatus` 一致；文案如「待报价 N 行」「已报价 N 行」「查无报价 N 行」。

**副标题行不再展示：** 客户名称（改在基础信息网格）；主表标签（改在标题行）。

```scss
.title-meta {
  display: flex;
  align-items: center;
  gap: 8px;
  flex-wrap: wrap;
}
```

### 3.4 收藏星标 `btn-favorite-star`

| 状态 | 视觉 |
|------|------|
| 未收藏 | 黄色 `#ffc94d` **虚线**描边星（`stroke-dasharray: 3 2.5`） |
| 已收藏 | 实心黄色 `#ffc94d` |
| 悬停 | `#ffd666` + `background: rgba(255, 201, 77, 0.12)` |
| 尺寸 | `.star-icon` 约 22×22px |

需设置 `aria-pressed`、`title` / `aria-label`（见 CaptionBar 规范）。收藏实体类型与 API 由业务模块定义（需求：`RFQ` + `favoriteApi`）。

### 3.5 主表标签区（需求详情参考）

**适用：** 具备主表标签能力的单据（需求 RFQ 已落地；见 [需求主表标签 PRD](../../业务功能/需求报价/需求主表标签PRD.md)）。

**展示条件：** `canUseRfqTagUi(user)` 且（已有标签 **或** 当前用户可编辑标签）。

| 项目 | 规范 |
|------|------|
| 容器 | `.rfq-header-tags-row.tags-row` — `inline-flex`；`gap: 8px`；与标题行 flex 子项对齐 |
| 已打标签 | `TagListDisplay` — 有标签时渲染；**无标签时不显示「暂无标签」占位** |
| 打标签按钮 | `.btn-secondary.rfq-header-add-tag-btn` |
| 按钮图标 | `.rfq-header-add-tag-icon` — 字符 **`±`**（非 `+`）；约 15px |
| 按钮文案 | **「标签」**（非「添加标签」） |
| 按钮样式 | 与顶栏次要按钮一致：`btn-secondary`（实线边框、浅底）；`padding: 6px 12px`；`font-size: 12px` |
| 交互 | 点击打开 `ApplyTagsDialog`；保存后刷新详情 |
| 权限 | 仅创建人/当前业务员可见按钮；上级/管理员仅看 chip（后端 `canEditRfqTags`） |

**不在标签区展示：** 说明性 hint 文案（如「标签为跟进中的主观标记…」）— CaptionBar 内不放长说明。

### 3.6 右侧操作组 `header-right`

**层级原则：** `btn-primary`（编辑）为 CaptionBar **唯一主操作**（青蓝渐变底 + 白字）；其余顶栏按钮均为**辅助按钮**，不得使用与编辑相同的 primary 底色。

**容器：** `display: flex`；`align-items: center`；`gap: 10px`。

**按钮顺序（从左到右）：**

1. **关闭 / 终止类** — `.btn-close-rfq` / `.btn-close-so`（或业务等价类；**无边框 ghost**，见 §3.6.1）
2. **其他常规辅助**（可选，如刷新）— `btn-secondary`（**线框浅底**，见 §3.6.1）
3. **编辑** — `btn-primary`（**主操作**，见 §3.6.1）
4. **更多** — `btn-more-actions`（危险项如下拉，如删除）

```text
[ 关闭需求 ] [ 刷新 ] [ 编辑 ] [ ⋯ ]
   ghost        线框     primary   图标
```

| 按钮 | 类名 | 角色 | 显隐（需求参考） |
|------|------|------|------------------|
| 关闭需求 | `.btn-close-rfq` | 终止类辅助 | 有写权限且非已关闭/已取消 |
| 编辑 | `.btn-primary` | **主操作** | 有写权限且状态为待分配/已分配 |
| 更多 | `.btn-more-actions` | 辅助 | 有写权限 |

| 按钮 | 类名 | 角色 | 显隐（销售订单参考） |
|------|------|------|----------------------|
| 取消订单 | `.btn-close-so` | 终止类辅助 | 可取消时 |
| 刷新 | `.btn-secondary` | 常规辅助 | 始终 |
| 编辑 | `.btn-primary` | **主操作** | 有写权限 |
| 更多 | `.btn-more-actions` | 辅助 | 有写权限 |

**与旧版差异：** 编辑使用 **`btn-primary`（有底色）**；关闭/取消使用 **无边框 ghost（无橙底、无外线框）**；编辑在关闭/取消按钮**右侧**。

#### 3.6.1 编辑区辅助按钮样式

CaptionBar 右侧「编辑」及其邻近按钮分 **三类**，新详情页须按类名套用，**禁止**终止类辅助按钮再使用橙色线框 secondary。

| 类型 | 类名 | 视觉 | 适用场景 |
|------|------|------|----------|
| **主操作** | `.btn-primary` | 青蓝渐变底 + 白字 + 浅色描边；`padding: 8px 14px`；13px；SVG + 文案 | **编辑**（全页唯一 primary） |
| **终止类辅助** | `.btn-close-rfq` / `.btn-close-so` | **`border: none`**；**`background: transparent`**；字/图标 **`$color-amber`**；悬停 `background: rgba(255,255,255,0.08)`（仍无边框） | 关闭需求、取消订单等**终止/撤销**语义 |
| **常规辅助** | `.btn-secondary` | 浅底 `rgba(255,255,255,0.05)` + **面板色线框** `$border-panel`；字 `$text-secondary`；悬停略提亮底/边框 | 刷新、导出等**非终止**次要操作 |
| **更多** | `.btn-more-actions` | 36×36 方钮；「⋯」；浅底 + 面板边框 | 删除等低频/危险操作入口 |

**禁止：**

- 终止类辅助使用 `btn-warning`（橙底）或带橙色/面板色**外线框**的 secondary；
- 除编辑外任意顶栏按钮使用 `btn-primary`；
- 刷新等常规辅助使用无边框 ghost（与终止类混淆）。

**终止类 ghost 参数（与 `RFQDetail.vue` / `SalesOrderDetail.vue` 一致）：**

```scss
.btn-close-rfq,
.btn-close-so {
  color: $color-amber;
  border: none;
  background: transparent;
  &:hover {
    background: rgba(255, 255, 255, 0.08);
    border: none;
  }
}
```

**常规辅助 `btn-secondary` 参数：**

```scss
.btn-secondary {
  display: inline-flex;
  align-items: center;
  gap: 6px;
  padding: 8px 14px;
  background: rgba(255, 255, 255, 0.05);
  border: 1px solid $border-panel;
  border-radius: $border-radius-md;
  color: $text-secondary;
  font-size: 13px;
  &:hover {
    background: rgba(255, 255, 255, 0.08);
    border-color: rgba(0, 212, 255, 0.25);
  }
}
```

**主操作 `btn-primary` 参数：** 见 RFQDetail 样式段；与客户详情「编辑 = btn-primary」一致。

**参考实现：** 需求 `RFQDetail.vue`（关闭 ghost + 编辑 primary）；销售订单 `SalesOrderDetail.vue`（取消 ghost + 刷新 secondary + 编辑 primary）。

### 3.7 主数据类 CaptionBar 左侧布局（客户 / 供应商）

#### 3.7.0 适用范围（强制）

| 项目 | 规范 |
|------|------|
| **适用页面** | **仅** `CustomerDetail.vue`（客户详情）、`VendorDetail.vue`（供应商详情） |
| **不适用** | 需求、销售订单、采购订单及一切**业务单据**详情页 — 须用 §3.2–§3.3 |
| **布局特征** | CaptionBar 左侧文字区固定 **2 行**：第 1 行实体全称 + 收藏 + 标签；第 2 行编码 + 等级类标识 |

#### 3.7.1 整体结构

```text
page-header
├─ header-left
│  ├─ btn-back（返回）
│  └─ customer-title-group          ← 客户/供应商共用容器类名
│     ├─ customer-avatar-lg         ← 实体首字头像
│     └─ 文字列
│        ├─ page-title-row → page-title-with-icons   ← 第 1 行
│        └─ title-meta.title-meta--caption
│           .customer-header-meta-row                ← 第 2 行
└─ header-right（右侧操作组，见 §3.6）
```

#### 3.7.2 第 1 行 — 主标题行 `page-title-with-icons`

**横向顺序（从左到右）：**

1. `h1.page-title` — **实体全称**（客户：`customerName`；供应商：主显示名称）
2. `PartyStatusIcons` — 冻结 / 黑名单等主数据状态图标（有则显示）
3. `btn-favorite-star` — 收藏（见 §3.4）
4. **标签区** — `TagListDisplay` + 「添加标签」按钮

```text
[ 电子元气 ] [ 冻结/黑名单图标 ] [ ☆ ] [ 标签 chip… ] [ 添加标签 ]
```

| 控件 | 类名 / 组件 | 说明 |
|------|-------------|------|
| 主标题 | `h1.page-title` | **仅实体全称**；20px / semibold / `$text-primary`；脱敏时回退「客户详情」等页面标题 |
| 状态图标 | `PartyStatusIcons` | `size="md"`；冻结、黑名单 |
| 收藏 | `.btn-favorite-star` | 见 §3.4 |
| 标签容器 | `.customer-header-tags-row.tags-row` | `inline-flex`；`gap: 6px`；与标题行 flex 对齐 |
| 已打标签 | `TagListDisplay` | 有标签时渲染 |
| 打标签 | `.btn-add-tag` | 文案「添加标签」；有写权限时显示 |

**第 1 行不放：** 客户/供应商编码、等级、主单状态、来源、明细统计。

**布局参数（与 §3.2 共用）：**

```scss
.page-title-row {
  display: flex;
  align-items: center;
  gap: 10px;
  margin-bottom: 6px;
}
.page-title-with-icons {
  display: flex;
  align-items: center;
  gap: 8px;
  flex-wrap: wrap;
  min-width: 0;
}
.customer-header-tags-row {
  flex-shrink: 0;
}
```

#### 3.7.3 第 2 行 — 副标题行 `title-meta.title-meta--caption`

**放主数据编码与等级类标识**，不放全称、不放标签操作、不放单据主状态。

**横向顺序（从左到右）：**

1. **主数据编码** — `.customer-code`（客户：`customerCode`；供应商：`code`）
2. **等级 / 级别标识** — `.level-badge`（客户：与列表「等级」列同源 `customerDict.levelLabel`；供应商：级别/身份类 badge，见 `VendorDetail.vue`）

```text
[ CUS0003H ] [ B级 ]
```

| 控件 | 类名 | 说明 |
|------|------|------|
| 编码 | `.customer-code` | 12px；`$text-muted`；无值 `—` |

## 12. 维护说明

1. 调整 RFQ 详情 UI 时，**同步更新本文档**与参考实现注释。
2. **CaptionBar 两行分工：**
   - **单据类（§3.2–§3.3）：** 标题行 = 前缀+单号、收藏、主表标签、「± 标签」、来源；副标题行 = 主单状态 + 明细统计 pill。
   - **主数据类（§3.7，仅客户/供应商）：** 第 1 行 = 实体全称、PartyStatusIcons、收藏、标签区；第 2 行 = 编码 + 等级 badge。**禁止**用于 RFQ/SO/PO。
3. **勿回退：** 单据类 — 主单状态/统计 pill 不要放回标题行；**勿**恢复 CaptionBar 自定义 `.status-badge`。主数据类 — 全称不要放在第 2 行；编码/等级不要放在第 1 行。
4. **右侧按钮（§3.6.1）：** 编辑 = 唯一 `btn-primary`；关闭/取消 = **无边框 ghost**（`.btn-close-rfq` / `.btn-close-so`）；刷新等 = `btn-secondary` 线框；顺序为终止类 → 常规辅助（可选）→ 编辑 → 更多。
5. 区分三类表头/标题栏底色：**区块 Tab** → `--crm-detail-section-header-bg`；**主 Tab 列表** → `--crm-table-header-bg`（§7.2）；**面板标题栏 + 面板内列表** → `--crm-detail-panel-card-head-bg`（§7.3 / §7.4；亮色 `#EBFBFF`）。
6. **面板列表 §7.4（2026-06-26 起）：** 销售订单「订单明细」与嵌套面板内表须 `size="small" stripe` + `--crm-detail-panel-card-head-bg`；更改日志等其它 Tab 仍用 §7.2；**勿**混用表头 token。
7. 主信息字段默认采用 **`info-grid--inline-labels`**；基础信息可用 **`info-grid--basic`**（§5.1）。
8. **基础信息创建元数据（2026-06-26 起）：** 创建日期、创建人放 **§4.2.1** 标题栏右侧 `.section-header__meta`（**单据类**基础信息）；与列表列口径一致；**勿**放入 CaptionBar 或 `info-grid` 单元格。
