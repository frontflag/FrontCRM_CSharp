# 流程页签规范

右侧扩展栏 **「流程」**（`r-flow`）地铁竖轴的页面注册、站序、卡片字段与跨页通用规则。当前业务指示（橙色左指手势）见 [流程页签.当前业务指示规范](./流程页签.当前业务指示规范.md)。页签注册与默认页见 [扩展面板.工作台规范](./扩展面板.工作台规范.md)。

> **视觉族：** `so-item-flow-panel.scss` + `StockBizTypeTag` + `FlowYouAreHereMark`

## 0. 最新变更（2026-08-31 ～ 2026-09-01）

相对此前仅覆盖销售/采购明细、装箱、待报关的口径，物流侧「流程」页签补齐如下。

| # | 变更 | 要点 |
|---|------|------|
| 1 | **新增页面：库存明细** | `/inventory/stock-items` 默认 `r-flow`。七站：采购明细 → 质检 → 入库 → **库存明细（当前）** → 出库通知 → 装箱 → 出库。只挂本层 `stockItemId`，不扩整张销售明细。不含销售明细、收款、开票、采购申请、到货、备货。 |
| 2 | **新增页面：出库通知** | `/inventory/stock-out/notify` 默认 `r-flow`，保留「客户」；报关出库时另出「报关单」页签。站序：销售明细 → **出库通知（当前）** → 库存明细 →（有卡才插入）备货库存 → 本通知装箱 → 本通知出库。库存含已出完（qty=0）绑定层。 |
| 3 | **新增页面：出库明细** | `/inventory/stock-out/items` 默认 `r-flow`，保留「客户」。**只做五站**：销售明细 → 出库通知 → 库存明细 → 装箱 → **出库（当前）**。不做收款/开票、采购/质检/入库、拣货、备货。以 `stock_out_item` 为锚向上游收口，不按销售行全量。 |
| 4 | **出入库类型标签 + 报关图标** | 类型用 `StockBizTypeTag`。**仅当类型为报关且已关联报关单 ID 时**才出海关图标；类型对但无报关单则只出标签。 |
| 5 | **出库类型回退** | 卡片 `stockOutType` 为 `0` / 空视为未返回，依次回退装箱主表、出库通知、列表行，避免出库站显示「—」。 |
| 6 | **装箱流程字段** | 出库通知站、装箱站：用「出库类型」替换申请人/创建人。出库站：状态后给出库类型；下一行创建日期 + 创建人。出库站仍列出库单号 + 出库明细单号。 |
| 7 | **出库明细站字段** | 与装箱出库站同构：单号=出库单号，并列明细单号；状态后出库类型；创建日期与创建人同一行。供应商/采购价/入库数量只出现在库存明细站。 |
| 8 | **本行收口** | 库存明细 / 出库通知 / 出库明细 / 装箱出库站：下游单据必须按当前行绑定，禁止用销售明细 `detail-tab-aggregates` 铺整单。 |
| 9 | **装箱/出库通知/出库明细右栏** | 无 `r-ops` 时进入页默认 `r-flow`。装箱列表/详情/明细列表、出库通知、出库明细均保留「客户」。库存明细仍为流程 + 帮助。 |

未改：销售/采购明细流程站序与操作+流程并存；待报关流程；当前业务指示视觉（手势、禁止「我在此」）。

## 2. 跨页通用规则

### 2.1 当前业务节点

轨道圆点只表示 `empty` / `active` / `done`。当前站标题旁挂 `FlowYouAreHereMark`，站容器加 `is-main`。细则见 [当前业务指示规范](./流程页签.当前业务指示规范.md)。

### 2.2 类型标签与报关图标

| 项 | 规则 |
|----|------|
| 组件 | `StockBizTypeTag`（`biz=in` 入库类型 / `biz=out` 出库类型） |
| 海关图标 | **类型解析为报关** 且 `customsDeclarationId` 非空才显示；可点进报关单 |
| 禁止 | 非报关类型出图标；报关类型但无报关单时出图标 |

### 2.3 出库类型回退

前端 `asBizType` 将 `0` / 空视为缺失。出库站取值顺序：本行/本接口字段 → 装箱单 `StockOutType` → 出库通知 → 列表行 `stockOutType`。装箱 `flow-stock-out-lines` 若未带类型，必须能回退到箱头，避免「—」。

### 2.4 本行收口

以触发流程的那一行业务主键为锚（库存层 / 出库通知 / 装箱明细 / 出库明细），向上游单线、向下游只带本行绑定单据。无上游销售行时该站为空，其余站仍按本行展示。

## 3. 物流克隆族站序（库存明细视觉）

库存明细、出库通知、出库明细共用同一套小卡皮肤。站序按页面裁剪，**不是**每页都铺销售全链路。

```
销售明细 → 出库通知 → 库存明细 → 装箱 → 出库
```

| 页面 | 采用的站 | 不出现 |
|------|----------|--------|
| 库存明细 | 采购明细、质检、入库、库存明细、出库通知、装箱、出库 | 销售明细、收款、开票、备货、拣货 |
| 出库通知 | 销售明细、出库通知、库存明细、（有卡才插入）备货库存、装箱、出库 | 采购/质检/入库、拣货、收款/开票 |
| 出库明细 | 销售明细、出库通知、库存明细、装箱、出库 | 采购/质检/入库、拣货、备货、收款/开票 |
| 装箱 | 销售明细、出库通知、装箱、拣货、出库 | 库存明细站（拣货单独一站） |

### 3.1 字段裁剪（克隆族）

| 站 | 客商 | 类型 | 人 | 数量/价 |
|----|------|------|----|---------|
| 销售明细 | 客户通栏 | 无 | 业务员 | 销售价、数量 |
| 出库通知 / 装箱 | 客户通栏 | 出库类型（替换申请人/创建人） | 不出人 | 本行数量 |
| 库存明细 | 供应商通栏；有客单才出客户 | 入库类型 + 出库类型 | 不出业务员 | 采购价、入库数量、出库数量 |
| 出库（出库明细页 / 装箱出库站） | 客户通栏 | 状态后给出库类型 | 创建日期与创建人同一行 | 本行出库数量；出库明细页/装箱出库站并列明细单号 |
| 拣货（仅装箱） | 按装箱既有卡片 | — | 创建人 | 本行拣货量 |

供应商、采购价、入库数量 **只在库存明细站** 出现。
