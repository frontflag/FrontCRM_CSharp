# 流程页签规范

右侧扩展栏 **「流程」**（`r-flow`）地铁竖轴的页面注册、站序、卡片字段与跨页通用规则。当前业务指示（橙色左指手势）见 [流程页签.当前业务指示规范](./流程页签.当前业务指示规范.md)。页签注册与默认页见 [扩展面板.工作台规范](./扩展面板.工作台规范.md)。

> **状态：** 定稿（2026-09-03）  
> **卡片视觉对照：** 装箱单列表 `/inventory/packing` 右栏「流程」（`PackingListFlowPanel` + `PackingItemFlowPanel`）  
> **销售明细站客户对照：** `/sales-order-items` 右栏「流程」·「销售订单明细」站（`SalesOrderItemFlowPanel`；销售订单详情同面板）  
> **采购明细站供应商对照：** `/purchase-order-items` 右栏「流程」·「采购订单明细」站（`PurchaseOrderItemFlowPanel`；采购订单详情同面板）  
> **视觉族：** `so-item-flow-panel.scss` + `StockBizTypeTag` + `FlowYouAreHereMark`

卡片 KV、单号链接、创建日期以装箱列表为准（§2.5～§2.7）。销售明细站客户排版与跳转以 `/sales-order-items` 为准（§2.8）。采购明细站供应商排版与跳转以 `/purchase-order-items` 为准（§2.9，镜像 §2.8）。皮肤类在 `so-item-flow-panel.scss`，其它 `r-flow` 页共用；创建日期统一 `formatFlowCardDate` / `formatDisplayDate2DigitYear`（`yy-MM-dd`）。

## 2. 跨页通用规则

### 2.1 当前业务节点

轨道圆点只表示 `empty` / `active` / `done`。当前站标题旁挂 `FlowYouAreHereMark`，站容器加 `is-main`。细则见 [当前业务指示规范](./流程页签.当前业务指示规范.md)。

### 2.2 类型标签与报关图标

| 项 | 规则 |
|----|------|
| 组件 | `StockBizTypeTag`（`biz=in` 入库类型 / `biz=out` 出库类型） |
| 海关图标 | **类型解析为报关** 且 `customsDeclarationId` 非空才显示；可点进报关单 |
| 禁止 | 非报关类型出图标；报关类型但无报关单时出图标 |

### 2.3 出库类型回退

前端 `asBizType` 将 `0` / 空视为缺失。出库站取值顺序：本行/本接口字段 → 装箱单 `StockOutType` → 出库通知 → 列表行 `stockOutType`。装箱 `flow-stock-out-lines` 若未带类型，必须能回退到箱头，避免「—」。

### 2.4 本行收口

以触发流程的那一行业务主键为锚（库存层 / 出库通知 / 装箱明细 / 出库明细），向上游单线、向下游只带本行绑定单据。无上游销售行时该站为空，其余站仍按本行展示。

### 2.5 卡片 KV 值不折行

对照：装箱列表 `/inventory/packing` 右栏「流程」。

| 项 | 规则 |
|----|------|
| 值 | `.so-item-flow-kv__value` **单行**；过长省略号（`ellipsis`） |
| 列数 | 网格固定 **1 行 2 列**（`repeat(2, minmax(0, 1fr))`） |
| 通栏 | `--full` 占整行（如客户名称） |
| 窄栏 | **不**随页签变窄改成一列 |

### 2.6 卡片单号

对照：装箱列表流程卡内可点单号（`router-link`）。**不**套用 [列表跳单号链接样式规范](./列表跳单号链接样式规范PRD.md) 的「悬停主题蓝 + 下划线」。

| 状态 | 颜色 | 下划线 | 光标 / 行为 |
|------|------|--------|-------------|
| **默认** | 与相邻正文同色（`color: inherit`） | 无 | 手型；点击跳转详情 |
| **悬停 / 键盘 `focus-visible`** | 橙色 `--crm-color-amber`（浅色 `#d97706` / 深色 `#c99a45`） | 无 | 同上 |
| **已访问** | 不单独变色（与默认相同） | 无 | 同上 |
| **脱敏 / 无路由** | 纯文本，不渲染链接 | — | 不可点 |

禁止：浏览器默认蓝链、常驻主题蓝、悬停下划线。曾试海军蓝 `--crm-blue-primary`，已废弃，以橙色为准。

### 2.7 卡片创建日期

对照：装箱列表流程卡「创建日期」。按配置展示时区。

| 项 | 规则 |
|----|------|
| **现行** | `yy-MM-dd`（两位年、无时分），例 `26-08-01` |
| **原口径** | `YYYY-MM-DD HH:mm`（已废弃） |
| **实现** | `formatDisplayDate2DigitYear`（`CRM.Web/src/utils/displayDateTime.ts`）；`sellOrderItemFlowPanel.ts` 的 `formatFlowCardDate`（装箱等页再导出） |
| **空值** | `—` |

装箱列表 / 详情 / 明细列表、销售订单明细、采购订单明细、待报关、库存明细、出库通知、出库明细的「流程」卡均已落地。

### 2.8 销售明细站客户

## 3. 物流克隆族站序（库存明细视觉）

库存明细、出库通知、出库明细共用同一套小卡皮肤。站序按页面裁剪，**不是**每页都铺销售全链路。

```
销售明细 → 出库通知 → 库存明细 → 装箱 → 出库
```

| 页面 | 采用的站 | 不出现 |
|------|----------|--------|
| 库存明细 | 采购明细、质检、入库、库存明细、出库通知、装箱、出库 | 销售明细、收款、开票、备货、拣货 |
| 出库通知 | 销售明细、出库通知、库存明细、（有卡才插入）备货库存、装箱、出库 | 采购/质检/入库、拣货、收款/开票 |
| 出库明细 | 销售明细、出库通知、库存明细、装箱、出库 | 采购/质检/入库、拣货、备货、收款/开票 |
| 装箱 | 销售明细、出库通知、装箱、拣货、出库 | 库存明细站（拣货单独一站） |

### 3.1 字段裁剪（克隆族）

| 站 | 客商 | 类型 | 人 | 数量/价 |
|----|------|------|----|---------|
| 销售明细 | 客户通栏 | 无 | 业务员 | 销售价、数量 |
| 出库通知 / 装箱 | 客户通栏 | 出库类型（替换申请人/创建人） | 不出人 | 本行数量 |
| 库存明细 | 供应商通栏；有客单才出客户 | 入库类型 + 出库类型 | 不出业务员 | 采购价、入库数量、出库数量 |
| 出库（出库明细页 / 装箱出库站） | 客户通栏 | 状态后给出库类型 | 创建日期与创建人同一行 | 本行出库数量；出库明细页/装箱出库站并列明细单号 |
| 拣货（仅装箱） | 按装箱既有卡片 | — | 创建人 | 本行拣货量 |

供应商、采购价、入库数量 **只在库存明细站** 出现。
