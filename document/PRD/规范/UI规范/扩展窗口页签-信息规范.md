# 扩展窗口页签 · 信息规范

本文约定工作台 **右侧扩展窗口**（`aux-right`）中 **只读「信息」类页签** 的视觉与排版。参考实现为需求明细列表 **「客户」** 页签。

**状态：** 已定稿  
**参考实现：** `/rfq-items` 等右栏「客户」（`r-customer`）→ `CustomerWorkspacePanel.vue`  
**共享样式：** `CRM.Web/src/assets/styles/so-item-ops-panel.scss`（`embedded` 卡片层）

**关联：**

- 页签注册与展开默认：[扩展面板.工作台规范](./扩展面板.工作台规范.md)
- 可点编码/名称链接：[列表跳单号链接样式规范PRD](./列表跳单号链接样式规范PRD.md)
- 操作页签（按钮、进度、双列指标、状态标签）：[扩展窗口页签-操作规范](./扩展窗口页签-操作规范.md)（**不适用**本规范的分组「标签：值」）
- 字段口径与权限：[需求明细列表-客户页签-设计与实现](../../System/需求/需求明细列表-客户页签-设计与实现.md)

「扩展窗口」即 AppLayout 左右扩展辅助栏；本文只约束右栏 **信息页签** 的内容区样式，不改顶栏页签按钮本身。

---

## 1. 适用范围

| 适用 | 不适用 |
|------|--------|
| 右栏只读摘要：对照主数据/档案，不发起业务动作 | 「操作」页签（主按钮、进度条、`.ops-metrics` 大号指标） |
| 卡片堆叠的概况 + 分组字段 | 「流程」页签（地铁竖轴） |
| 列表单击行驱动的绑定 | 「帮助」页签（Markdown，见 [扩展面板.帮助规范](./扩展面板.帮助规范.md)） |
| | 「物料 / 调查」等查询结果型页签（自行约定） |

后续同类页签（如供应商档案摘要）须按本文落地，不得各写一套字号与卡片层。

---

## 2. 外壳与卡片层（颜色）

信息页签 **必须** 嵌在右栏内容区（`aux-panel-tab-body`），使用 **embedded** 卡片层，与销售订单明细「操作」面板同色，禁止再套一层独立灰底抽屉（`.so-item-ops-panel` 的 `#f3f5f8` + 投影）。

| 项 | 规范 |
|----|------|
| 根节点 | `.so-item-ops-root.so-item-ops-root--embedded` |
| 内容列 | `.so-item-ops-root__content--embedded`：纵向 `flex`，卡片间距 **12px**，无额外内边距（由右栏容器负责） |
| 卡片 | `.ops-card` |
| 卡片背景 | `$layer-3`（浅色主题 `--crm-layer-3: #f8fafc`） |
| 卡片边框 | `1px solid $border-panel` |
| 圆角 | **12px** |
| 阴影 | **无**（`box-shadow: none`） |

---

## 3. 卡片类型与顺序

有数据时，**每一块主题一张独立卡片**，纵向堆叠。禁止把两个标题塞进同一张卡片。

| 顺序 | 类型 | 客户页签示例 | 正文排版 |
|------|------|----------------|----------|
| 1 | **概况** | 客户概况 | 无字段标签；首行 hero 编码，其后纯值行 |
| 2…n | **分组信息** | 基本信息、财务信息 | 左对齐 **标签：值**，一行一项 |

无权看完整档案时：只保留概况卡片（可见字段由业务文档裁剪）；不渲染后续分组卡片。

---

## 4. 概况卡片

对齐操作面板「订单明细」概况（见 [扩展窗口页签-操作规范](./扩展窗口页签-操作规范.md) §4），但整页签仍属信息页签（无状态标签网格、无操作按钮）。

| 项 | 规范 |
|----|------|
| 标题 | `.ops-card__title`：14px / 600，正文主色 |
| 标题区内边距 | `.ops-card__head`：`12px 14px 0` |
| 正文 | `.ops-card__body.ops-card__body--overview`：纵向，行距 **6px** |
| 正文区内边距 | `.ops-card__body`：`10px 14px 14px` |
| **Hero 首行** | `.ops-overview-line.ops-overview-line--hero`：业务主键/编号；**18px / 700**；颜色 `$color-amber`（`--crm-color-amber`，浅色约 `#d97706`） |
| **其后各行** | `.ops-overview-line`：**13px / 500**，左对齐，无「标签：」前缀 |
| 换行 | `word-break: break-word`；长中文名允许折行 |
| 空值 | 该行仍占位，文案 **—** |
| 可访问性 | 无标签行须设 `aria-label`（字段中文名） |

**客户页签行序（定稿）：** 编号（hero）→ 中文名称 → 英文名称 → 业务员。受限视图省略名称行。

---

## 5. 分组信息卡片（标签：值）

**不得**使用操作页签的 `.ops-metrics`（上标签 + 20px 大号数值、双列）或 `.ops-stock-region-row`（双列 Key:Value）。信息页签分组卡为一列清单。

| 项 | 规范 |
|----|------|
| 标题 | 同概况：14px / 600 |
| 行容器 | `.ops-kv-stack`：纵向，间距 **8px** |
| 单行 | `.ops-kv-line`：`flex` + `baseline`；**13px**；`line-height: 1.45` |
| 标签 | `.ops-kv__label`：不伸缩；颜色 `--crm-text-secondary`（约 `#64748b`） |
| 分隔 | `.ops-kv__sep`：全角 **：** |
| 值 | 紧随分隔符；主色；`overflow-wrap: anywhere` |
| 空值 | **—** |

---

## 6. 可点进详情

概况中的编码、名称等，**有权打开目标详情** 时用 `router-link` + **`.link-text`**：

| 项 | 规范 |
|----|------|
| 默认 | 继承所在行颜色（hero 行保持琥珀；普通行保持正文色）；无下划线；光标 `default` |
| 悬停 | 主题蓝 + 下划线 + `pointer`（[列表跳单号链接样式规范](./列表跳单号链接样式规范PRD.md)） |
| 跳转 | **当前页**进入详情（如 `/customers/:id`），不强制新开窗口 |
| 无权 / 脱敏 | **不渲染链接**，纯文本；接口不下发可用于绕过的主键 |

---

## 7. 空态与门控

| 项 | 规范 |
|----|------|
| 未选行 | 13px 提示单击列表行（如「请单击列表行查看客户」） |
| 无关联档案 | 概况位空态文案（如「该需求未关联客户档案」），不铺空卡片 |
| 加载失败 | 错误行，不得假装无数据 |
| 请求时机 | 右栏 **展开** 且当前为 **本信息页签** 才请求；在「物料 / 帮助」下单击行只绑定行、不打接口（与操作页签 §2.4 同一套 `useListRightOpsPanelInteraction`，`dataTabIds` 为本页签 id） |

---

## 8. 与「操作」页签的差异（强制）

| | 信息页签（本文） | 操作页签 |
|--|------------------|----------|
| 目的 | 只读对照档案 | 推进单据（申请、通知、完成） |
| 概况 | 无标签 + hero 编码 | 同左（订单明细等） |
| 其余卡片 | **一列**「标签：值」13px | 双列 KV、或 `.ops-metrics` 大号数 + 进度 + 主按钮 |
| 状态标签网格 | 无 | `.ops-status-tags` 最多三列 |
| 主操作按钮 | 无 | `.ops-action-btn` |

信息页签 **禁止** 把分组字段改成采购申请那种「上标签、下 20px 粗体」两列指标。
