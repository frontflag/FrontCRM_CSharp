## 1. 目标

统一记录三租户主题色，避免实现时各自取色、口径漂移。后续页面、报表、品牌条等凡涉及租户主色/背景/强调，应优先对照本表。

---

## 2. 色板定义

| 租户 ID | 主色 | 背景色 | 强调色 |
|---------|------|--------|--------|
| `semicore` | `#B3EEF6` | `#0D1F35` | `#020612` |
| `idesemi` | `#6DC5F6` | `#FFFFFF` | `#11161F` |
| `ecoinf` | `#A8D070` | `#FFFFFF` | `#101010` |

### 2.1 semicore

| Token | 色值 | 典型用途 |
|-------|------|----------|
| 主色 | `#B3EEF6` | 点缀线、分区竖条、高亮描边、QC 序号等 |
| 背景色 | `#0D1F35` | 顶栏、表头等深色底 |
| 强调色 | `#020612` | 深色点缀/对比描边（近黑海军） |

### 2.2 idesemi

| Token | 色值 | 典型用途 |
|-------|------|----------|
| 主色 | `#6DC5F6` | 分区竖条、勾选框描边等青点缀 |
| 背景色 | `#FFFFFF` | 页面/报表纸面底 |
| 强调色 | `#11161F` | 标题字色、深色对比 |

### 2.3 ecoinf

| Token | 色值 | 典型用途 |
|-------|------|----------|
| 主色 | `#A8D070` | Bill/Ship、明细表头、分区条等填充 |
| 背景色 | `#FFFFFF` | 页面/报表纸面底 |
| 强调色 | `#101010` | 公司名等关键标题字色 |

---

## 3. 使用约定

1. **租户键**与构建变量 `VITE_TENANT_ID` / `LOGIN_TENANT_ID` 一致（小写：`semicore`、`idesemi`、`ecoinf`）。
2. **组件文件名 ≠ 当前租户映射**：Packing / Invoice / 销售与采购订单报表等皮肤可能对调挂载，以各 `resolve*ReportSkin.ts` 与实现文档为准；色板仍按**业务租户**取色，而非按组件文件名。
3. 报表中若存在「主色浅底」变体（如 QC 子表头），可在主色基础上派生浅色，并在对应业务规范中单独注明；**本表只固化三基色**。
4. 变更色板时：先改本文档，再同步皮肤/CSS 变量与相关 PRD/System 文档。
