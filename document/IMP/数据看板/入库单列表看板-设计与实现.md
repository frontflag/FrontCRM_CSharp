## 一、定位与边界

| 维度 | 入库单列表看板（本文） | 物流分析「已入库」 | 采购分析「已入库」 |
| --- | --- | --- | --- |
| 统计粒度 | **`stock_in` 单头** | 过账采购入库 | 成单约束下的入库进度 |
| 筛选来源 | 入库单搜索栏全部条件 | 报表透镜 + 入库日 | 报表透镜 + 订单日 |
| 集合硬过滤 | **无**（跟筛选；仍排除移库 3） | 通常已过账 + 采购 | 成单约束 |
| 金额 | 采购单价 × 入库数量 | 过账快照（无快照常记 0） | 成单 / convert_price |
| 美金 | 快照 → convert_price → 查询日汇率 | 仅快照 | convert_price |

**产品原则：**

1. 看板统计范围 = **当前入库单列表筛选结果**（全量，非当前页）。
2. 列表分页与看板聚合共用 `StockInListFilter`（含数据权限、入库日 UTC 上界、排除移库）。
3. 计数按**单头**；金额按这些单下明细行 `Quantity × Price` 加总（**不用**头表 `TotalAmount` 回落 PO Cost）。
4. 金额无 `purchase.amount.read` 或触发 511 时脱敏；饼图/排名改按**单数**。
5. **不**做公司/部门/个人透镜，**不**改物流/销售分析「已入库」数据源，**不**做待办。

## 二、UI 与交互

| 项 | 需求 |
| --- | --- |
| 入口 | 搜索栏「看板 / 列表」切换（查询、重置之后） |
| `viewMode` | `list` \| `board`，默认 `list` |
| 看板模式 | `v-if` 挂载看板；`v-show` 隐藏表格与分页；标题旁「共 N 条」隐藏 |
| 筛选联动 | `boardFilters` ← 当前搜索栏；看板 `watch` 自动刷新 |
| 顶栏 | Tag「筛选」+ 口径提示 + 趋势粒度 天/周/月 + 刷新 |
| 帮助 | `useListBoardHelpOverride` → `help/pages/入库单看板_MENU_STOCK_IN_BOARD.md` |
| 页签模式 | **不做**（入库单列表无齿轮页签） |

布局：

```
┌─ Tag「筛选」+ 口径提示 + 天/周/月 + 刷新 ─┐
├─ KPI：入库供应商数 / 入库单数 / 入库金额（美金+原币）
├─ 趋势：入库单数 │ 入库金额（折算美金）
├─ 分布：入库类型饼图 │ 采购员饼图
└─ 排名：Top10 供应商 │ Top10 采购员
```

## 三、口径（已确认）

| 项 | 结论 |
| --- | --- |
| 金额 | **全部入库金额**：`入库采购单价 × 入库数量`。KPI / 趋势 / 饼图 / Top10 同一套，不用成单。 |
| 粒度 | **B**：计数叫 **入库单数**（单头），不是明细条目数。 |
| 集合 | **完全跟当前搜索栏筛选**。不硬过滤「已过账 + 采购」。 |
| 折算美金 | 优先 `stock_item.PurchasePriceUsd`（有在库行即用快照，含 0）；无在库行则 `入库数量 × PO convert_price`；再无则查询日财务汇率 |
| 日期轴 | `stock_in.StockInDate`。无日期不进趋势，仍进 KPI / 分布 / 排名 |
| 入库供应商数 | 头表 `VendorId` 去重；空不计 |
| 采购员 | 每张单取明细挂 PO 的**主采购员**（首个非空）；挂不上归「未分配采购员」；该单美金整笔记到该人 |
| 入库类型饼 | 金额（美金）；历史类型 `1` 与 `10` 合并为采购入库 |
| Top10 供应商 | 无供应商的单归「未关联供应商」 |
| 脱敏 | 511 **或** 无 `purchase.amount.read`：金额 `—`，饼图/排名按单数。511 时请求去掉 `vendorName` |

## 四、API

| Method | Path |
| --- | --- |
| GET | `/api/v1/stock-in/analytics/dashboard` |
| GET | `/api/v1/stock-in/analytics/trends?groupBy=day\|week\|month` |
| GET | `/api/v1/stock-in/analytics/breakdowns` |
| GET | `/api/v1/stock-in/analytics/rankings` |

查询参数与 `GET /api/v1/stock-in` / `StockInQueryRequest` 一致。权限与列表相同（JWT + 入库数据范围）；金额另判 `purchase.amount.read` / 511。路由须在 `{id}` **之前**注册。
