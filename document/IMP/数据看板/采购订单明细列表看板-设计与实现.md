> **路由**：`CRM.Web` → 采购订单明细列表  
> **参考实现**：[`订单列表统计看板-设计与实现.md`](./订单列表统计看板-设计与实现.md) §5.2（采购订单**主表**列表看板）；[`销售订单明细列表看板-设计与实现.md`](./销售订单明细列表看板-设计与实现.md)（销售明细，对称实现）

## 一、定位与边界

| 维度 | 明细列表看板（本文） | 采购订单列表看板 | 报表分析 `/reports/purchase` |
| --- | --- | --- | --- |
| 统计粒度 | **明细行**（`purchaseorderitem`） | 订单头（`purchaseorder`） | 域级 + 公司/部门/个人透镜 |
| 数据集 `dataset` | `listFilter`（默认） | — | 订单 Tab：`reportApproved` |
| 筛选来源 | 明细列表搜索栏全部条件 | 主表列表搜索栏 | 独立筛选 + Scope Tab |
| 成单约束 | **否**（跟筛选结果） | 订单头成单 | 订单 Tab：**是**（主单 status≥审核通过且明细有效） |
| 趋势 / groupBy | **不展示** | 主表看板含趋势 | 订单 Tab **展示** |
| UI Tag | 「筛选」 | — | 订单 Tab「成单」 |
| API 前缀 | `/api/v1/purchase-orders/items/analytics/*` | `/api/v1/purchase-orders/analytics/*` | 订单 Tab：`/api/v1/analytics/purchase/order-items/*` |
| 实现 | `PurchaseOrderItemListBoard.vue`（`mode=list`） | — | 同组件 `mode=report` |

**产品原则**：

1. 看板统计范围 = **当前明细列表筛选结果**（全量，非当前页）。
2. 列表分页与看板聚合 **共用** `PurchaseOrderItemListFilter`（含数据权限、日期 UTC 上界）。
3. 金额无权限时脱敏（`mask511` + `purchase.amount.read`），饼图改按**行数**占比。

## 二、设计需求（功能清单）

### 2.1 UI 与交互

| 项 | 需求 |
| --- | --- |
| 入口 | 搜索栏「看板 / 列表」切换按钮（`btn-board-active` 青色高亮，与主表列表一致） |
| `viewMode` | `list` \| `board`，默认 `list` |
| 看板模式 | `v-show` 隐藏明细表格与分页 |
| 筛选联动 | `boardFilters` ← `dateRange` + `filters`；看板 `watch` 自动刷新 |
| 看板组件 | `PurchaseOrderItemListBoard.vue` |

### 2.2 指标需求（四类呈现）

| 呈现类 | 内容 |
| --- | --- |
| **静态 KPI** | 成单（供应商/订单/明细/金额）、在库（供应商/明细/金额/最长库龄）、应付款（供应商/明细/金额 + 原币分档） |
| **趋势** | 成单订单数、成单明细数、成单明细金额 USD；`groupBy` = day/week/month |
| **分解** | 明细主状态条图（全量、逐码）+ 申请付款/付款/采购/入库/开票/币别/品牌/date_code/采购员饼图（成单） |
| **排行** | 6 张 Top10：供应商、物料（金额/Qty）、品牌（金额/Qty）、采购员；名称列加宽，金额/明细数可切换 |

### 2.3 看板布局

```
┌─ 工具条：口径提示 + groupBy + 刷新 ─────────────────────────┐
├─ KPI 组 A：成单（供应商 / 订单 / 明细 / 金额 + 原币分档）──────┤
├─ KPI 组 B：在库（供应商 / 明细 / 金额 / 最长库龄）────────────┤
├─ KPI 组 C：应付款（供应商 / 明细 / 金额 + 原币分档）───────────┤
├─ 趋势：成单订单数 │ 成单明细数 │ 成单明细金额（USD）───────────┤
├─ 分布：明细主状态条图 + 多张饼图 ──────────────────────────────┤
└─ 排行：6 张 Top10 表（名称加宽 + 金额/明细数切换）─────────────┘
```

## 四、统计口径（已确认）

### 4.1 成单

| 维度 | 口径 |
| --- | --- |
| 成单订单 | 主单 `status >= 10` |
| 成单明细行 | 同上 **且** `purchaseorderitem.status != -2`（未取消） |
| 成单供应商数 | 成单明细 `vendor_id` 去重 |
| 成单订单数 | 成单明细 `purchase_order_id` 去重 |
| 成单明细数 | 成单明细行 COUNT |
| 成单金额 | Σ `Qty × ConvertPrice`（USD） |

### 4.2 在库

| 指标 | 口径 |
| --- | --- |
| 在库供应商数 | 成单明细 → `stock_item.purchase_order_item_id` 且 `qty_repertory > 0` → `vendor_id` 去重 |
| 在库明细数 | 在库行 `purchase_order_item_id` 去重 |
| 在库金额 USD | Σ `qty_repertory × purchase_price_usd` |
| 最长库龄 | MAX(today − `stock_in.stock_in_date`) |

须 `ApplyStockItemListDataScopeAsync`。

### 4.3 应付款

| 指标 | 口径 |
| --- | --- |
| 应付款供应商数 | `PaymentAmountNot > 0` 的 `vendor_id` 去重 |
| 应付款明细数 | `PaymentAmountNot > 0` 的行数 |
| 应付款金额 USD | Σ `PaymentAmountNot × ConvertPrice / Cost` + `payableCurrencyLines[]` |

**不做应付款账龄**（与销售明细应收账龄不同）。

### 4.4 分布范围

| 图表 | 范围 |
| --- | --- |
| `itemStatus` | **全量筛选**（逐码分组） |
| 其余进度/币别/品牌/排行 | **仅成单明细** |

### 4.5 明细主状态展示（逐码 + i18n）

- 后端：`itemStatus` 按 `purchaseorderitem.status` 逐码分组，`key` 为状态码。
- 前端：`PO_ITEM_STATUS_I18N_KEY` → `purchaseOrderItemList.itemStatus.{new,pendingReview,approved,...}`。
- 未知码回退 API `label`。

### 4.6 申请付款进度

与列表 `paymentRequestProgressStatus` 一致：查 `FinancePaymentItem` + `FinancePayment`（排除 status -1/-2）。

## 五、趋势（Trend）

## 九、实现架构

```
PurchaseOrderItemList.vue（viewMode + boardFilters）
    └── PurchaseOrderItemListBoard.vue
            └── purchaseOrderItemAnalytics.ts
                    └── GET /api/v1/purchase-orders/items/analytics/*
                            └── PurchaseOrdersController
                                    └── IPurchaseOrderItemListQuery（partial）
                                            ├── PurchaseOrderItemListQuery.cs           ← 分页列表
                                            ├── PurchaseOrderItemListFilter.cs          ← 共用 WHERE
                                            ├── PurchaseOrderItemLineJoin.cs            ← join 行类型
                                            └── PurchaseOrderItemListAnalyticsQuery.cs  ← 聚合
```

**分层职责**：

| 层 | 职责 |
| --- | --- |
| **Controller** | 权限校验、`maskAmounts`、供应商/采购员筛参清空 |
| **Filter** | 日期 UTC、进度筛、数据范围 join |
| **AnalyticsQuery** | 成单/在库/应付款聚合；申请付款状态查财务表 |
| **Board.vue** | 并行拉取 4 端点；状态标签走 i18n 逐码映射 |
| **i18n** | `purchaseOrderItemList.board.*`（zh-CN / en-US） |

## 十二、验收要点

1. 同一筛选条件下，看板成单明细数 ≤ 列表 `totalCount`。
2. 切换筛选后看板自动刷新；`maskAmounts` 时金额 KPI 为 `—`、饼图按行数。
3. 明细主状态条图逐码展示，标签走现有 i18n。
4. 应付款不做账龄；在库金额用采购价 USD。
5. 排行表名称列可换行，金额/明细数切换正常。
