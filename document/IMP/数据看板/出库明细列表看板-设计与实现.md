## 一、定位与边界

| 维度 | 出库明细列表看板（本文） | 物流分析「已出库」 | 销售分析「已出库」 |
| --- | --- | --- | --- |
| 统计粒度 | **`stock_out_item` 行** | 完成态销售出库行 | 已审销售订单明细 |
| 筛选来源 | 出库明细搜索栏全部条件 | 报表透镜 + 出库日 | 报表透镜 + **订单创建日** |
| 集合硬过滤 | **无**（跟筛选） | 状态=4 + 类型 10\|1 | 成单约束 |
| 金额 | 销售单价 × 出库数量 | `Quantity × SalesPriceUsd`（无快照=0） | `qty_stock_out_actual × convert_price` |
| 美金 | 快照 → convert_price → 查询日汇率 | 仅快照 | convert_price |

**产品原则：**

1. 看板统计范围 = **当前明细列表筛选结果**（全量，非当前页）。
2. 列表分页与看板聚合共用 `StockOutItemListFilter`（含数据权限、出库日 UTC 上界）。
3. 金额无 `sales.amount.read` 或触发 521 时脱敏；饼图/排名改按**行数**。
4. **不**做公司/部门/个人透镜，**不**改销售分析「已出库」数据源。

## 二、UI 与交互

| 项 | 需求 |
| --- | --- |
| 入口 | 搜索栏「看板 / 列表」切换（查询、重置之后，筛选设置齿轮之前） |
| `viewMode` | `list` \| `board`，默认 `list` |
| 看板模式 | `v-if` 挂载看板；`v-show` 隐藏表格与分页；标题旁「共 N 条」隐藏 |
| 筛选联动 | `boardFilters` ← `buildQuery()`；看板 `watch` 自动刷新 |
| 顶栏 | Tag「筛选」+ 口径提示 + 趋势粒度 天/周/月 + 刷新 |
| 帮助 | `useListBoardHelpOverride` → `help/pages/出库明细看板_MENU_STOCK_OUT_ITEMS_BOARD.md` |

布局：

```
┌─ Tag「筛选」+ 口径提示 + 天/周/月 + 刷新 ─┐
├─ KPI：出库客户数 / 出库条目数 / 出库金额（美金+原币）
├─ 趋势：出库条目数 │ 出库金额（折算美金）
├─ 分布：出库类型饼图 │ 业务员饼图
└─ 排名：Top10 客户 │ Top10 业务员
```

## 三、口径（已确认）

| 项 | 结论 |
| --- | --- |
| 金额 | **全部**用出库金额：`销售单价 × 出库数量`。KPI / 趋势 / 饼图 / Top10 同一套。 |
| 集合 | **完全跟当前搜索栏筛选**。不硬过滤「已完成 + 销售」。 |
| 出库数量 | 与列表列一致：`ActualQty > 0 ? ActualQty : Quantity` |
| 销售单价 | 与列表相同：扩展 `SalesPrice > 0`，否则订单行 `Price` |
| 折算美金 | 优先扩展 `SalesPriceUsd`；无则 `出库数量 × 订单行 convert_price`；再无则查询日财务汇率 |
| 日期轴 | `stock_out.StockOutDate`。无出库日的行不进趋势，仍进 KPI / 分布 / 排名 |
| 出库客户数 | 头表 `customer_id` 去重；空客户不计入 |
| 业务员 | 关联销售订单业务员（与列表「业务员」列一致） |
| 出库类型饼 | 金额（美金）；历史类型 `1` 与 `10` 合并为销售出库 |
| Top10 客户 | 无客户且有金额的行归「未关联客户」 |
| 脱敏 | 521 或无 `sales.amount.read`：金额 `—`，饼图/排名按行数 |
