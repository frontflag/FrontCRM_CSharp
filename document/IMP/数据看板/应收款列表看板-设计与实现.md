## 一、定位与边界

| 维度 | 应收款列表看板（本文） | 财务报表 `/reports/finance` | 销售明细看板「应收」块 |
| --- | --- | --- | --- |
| 统计粒度 | **`finance_receivable` 行**（一完成出库单一行） | 域级透镜 | 销售明细 `receipt_amount_not` |
| 筛选来源 | 应收列表搜索栏全部条件 | 独立筛选 + Scope | 明细列表筛选 |
| API 前缀 | `/api/v1/finance/receivables/analytics/*` | `/api/v1/analytics/finance/*` | `/api/v1/sales-orders/items/analytics/*` |

**产品原则**：

1. 看板统计范围 = **当前列表筛选结果**（全量，非当前页）。进入页面时发票/收款核销状态默认不限；分析钻取 `onlyOpen=true` 时收款核销状态视为「待核销」。
2. 列表与看板共用同一 WHERE（含数据权限）。
3. 有 `finance-receipt.read` 即可看美金金额（不脱敏）。
4. 美金折算 = **产品主口径**关联销售订单明细 `convert_price`（折算美金单价）按价比折算（`FromExtend`：`local × convert_price / price`）；反映订单历史成交折算，**不以查询日财务汇率为主**。仅价比不可用时回落查询日财务参数汇率（与财务统计 / 销售分析待办应收 / 总要求 §四一致）。

## 二、UI 与交互

| 项 | 需求 |
| --- | --- |
| 入口 | 搜索栏「看板 / 列表」切换 |
| `viewMode` | `list` \| `board`，默认 `list` |
| 筛选 | keyword、发票核销状态、收款核销状态、**出库日期区间** |

## 三、口径（已确认）

### 3.1 金额双轨

| 轨道 | 字段 | 用途 |
| --- | --- | --- |
| 待核销 | `VerifiedToBe` → USD | KPI / 趋势线 / 分布默认 / 排名默认 / 账期饼（待核销模式） |
| 总额 | `Amount` → USD | KPI / 趋势线 / 分布切换 / 排名切换 / 账期饼（总额模式）；**单笔 Top10 固定总额** |

### 3.2 账龄

- 未核销 / 部分核销：`今天 − StockOutDate`（空则 CreateTime）
- 已核销：`最后一次写消 CreateTime − StockOutDate`
- 账期分组：`[0,10)` / `[10,30)` / `[30,60)` / `[60,90)` / `[90,180)` / `≥180`

### 3.3 趋势

- 时间轴：出库日（空则 CreateTime）
- 指标：客户数、出库记录条目数、待核销美金、总额美金；`groupBy` = day|week|month

### 3.4 分布

状态（收款核销状态）、币别、账期、业务员应收金额；金额均可随「待核销 \| 总额」切换。

### 3.5 排名 Top10

- 单笔最大应收（总额 USD + 核销状态标签）
- Top 客户 / Top 业务员（可切换待核销/总额）
