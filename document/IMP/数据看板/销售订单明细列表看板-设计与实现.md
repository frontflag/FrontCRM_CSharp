> **状态**：口径已确认，**已落地**（2026-07-13）  
> **范围**：`销售订单明细` 列表页（`/sales-order-items`）嵌入统计看板  
> **路由**：`CRM.Web` → 销售订单明细列表  
> **参考实现**：[`订单列表统计看板-设计与实现.md`](./订单列表统计看板-设计与实现.md) §5.1（销售订单**主表**列表看板）；[`采购订单明细列表看板-设计与实现.md`](./采购订单明细列表看板-设计与实现.md)（采购明细，对称实现）

## 一、定位与边界

| 维度 | 明细列表看板（本文） | 销售订单列表看板 | 报表分析 `/reports/sales` |
| --- | --- | --- | --- |
| 统计粒度 | **明细行**（`sellorderitem`） | 订单头（`sellorder`） | 域级 + 公司/部门/个人透镜 |
| 筛选来源 | 明细列表搜索栏全部条件 | 主表列表搜索栏 | 独立筛选 + Scope Tab |
| API 前缀 | `/api/v1/sales-orders/items/analytics/*` | `/api/v1/sales-orders/analytics/*` | `/api/v1/analytics/sales/*` |
| 典型场景 | 按 PN/进度/客户 SO 筛完后看行级 KPI、利润、在库、应收 | 按订单筛完后看成单客户/订单汇总 | 管理层跨周期分析 |

**产品原则**：

1. 看板统计范围 = **当前明细列表筛选结果**（全量，非当前页）。
2. 列表分页与看板聚合 **共用** `SalesOrderItemLineListFilter`（含数据权限、日期 UTC 上界）。
3. 金额/利润无权限时脱敏（`mask521` + `sales.amount.read`），饼图改按**行数**占比。

## 二、设计需求（功能清单）

### 2.1 UI 与交互

| 项 | 需求 |
| --- | --- |
| 入口 | 搜索栏「看板 / 列表」切换按钮（`btn-board-active` 青色高亮，与主表列表一致） |
| `viewMode` | `list` \| `board`，默认 `list` |
| 看板模式 | `v-show` 隐藏明细表格与分页；无顶部四卡 stat-row |
| 筛选联动 | `boardFilters` ← `dateRange` + `filters`；看板 `watch` 自动刷新 |
| 看板组件 | `SalesOrderItemListBoard.vue` |

### 2.2 指标需求（四类呈现）

| 呈现类 | 内容 |
| --- | --- |
| **静态 KPI** | 成单（客户/订单/明细/金额）、利润（采购/出库）、在库（客户/明细/金额/最长库龄）、应收（客户/明细/金额/最长账龄） |
| **趋势** | 成单订单数、成单明细数、成单明细金额 USD；`groupBy` = day/week/month |
| **分解** | 明细主状态条图（全量）+ 进度/币别/品牌/date_code/业务员饼图（成单） |
| **排行** | 6 张 Top10：客户、物料（金额/Qty）、品牌（金额/Qty）、业务员；名称列加宽，金额/明细数可切换 |

### 2.3 看板布局

```
┌─ 工具条：口径提示 + groupBy + 刷新 ─────────────────────────┐
├─ KPI 组 A：成单（客户 / 订单 / 明细 / 金额 + 原币分档）───────┤
├─ KPI 组 B：利润（采购利润、出库利润）──────────────────────────┤
├─ KPI 组 C：在库 ──────────────────────────────────────────────┤
├─ KPI 组 D：应收款 ────────────────────────────────────────────┤
├─ 趋势：成单订单数 │ 成单明细数 │ 成单明细金额（USD）──────────┤
├─ 分布：状态条图 + 多张饼图 ───────────────────────────────────┤
└─ 排行：6 张 Top10 表（名称加宽 + 金额/明细数切换）────────────┘
```

## 三、筛选条件（与明细列表一致）

须透传 `SellOrderItemLineQueryRequest` 全部字段（`SalesOrdersController.GetSellOrderItemLines` 形参）：

| 参数 | 说明 |
| --- | --- |
| `orderCreateStart` / `orderCreateEnd` | 主单创建日（UTC 含当日上界） |

**数据权限**：`ApplySellOrderDataScopeAsync` 作用于主单 join（与列表相同）。

## 四、统计口径（已确认）

### 4.1 成单

| 维度 | 口径 |
| --- | --- |
| 成单订单 | 主单 `status >= 10`（审核通过及以上） |
| 成单明细行 | 同上 **且** `sellorderitem.status = 0`（未取消行） |
| 成单客户数 | 成单明细 `customer_id` 去重 |
| 成单订单数 | 成单明细 `sell_order_id` 去重 |
| 成单明细数 | 成单明细行 COUNT |
| 成单金额 | Σ `Qty × ConvertPrice`（USD 行金额） |

### 4.2 利润

| 看板标签 | 扩展表字段 | 聚合 |
| --- | --- | --- |
| 采购利润 | `SalesProfitExpected` | 成单明细 SUM |
| 出库利润 | `ProfitOutBizUsd` | 成单明细 SUM |

无 extend 行按 0；无金额权限 KPI 为 `—`。

### 4.3 在库

| 指标 | 口径 |
| --- | --- |
| 在库客户数 | 成单明细 → `stock_item.sell_order_item_id` 且 `qty_repertory > 0` → `customer_id` 去重 |
| 在库明细数 | 在库行 `sell_order_item_id` 去重 |
| 在库金额 USD | Σ `qty_repertory × (sales_price_usd ?? 0)` |
| 最长库龄 | MAX(today − `stock_in.stock_in_date`) |

须 `ApplyStockItemListDataScopeAsync`；不含备货共享池。

### 4.4 应收款

| 指标 | 口径 |
| --- | --- |
| 应收客户数 | `ReceiptAmountNot > 0` 且 **已出库** 的 `customer_id` 去重 |
| 应收明细数 | 同上明细行数 |
| 应收金额 USD | Σ `ReceiptAmountNot` 折算 USD + `receivableCurrencyLines[]` |
| 最长账龄 | MAX(today − **最早出库日**)；仅统计「有待收且已出库」明细；无则 `—` |

出库日：关联已完成销售出库 `stock_out` 的 **最早** `StockOutDate`。

### 4.5 分布范围

| 图表 | 范围 |
| --- | --- |
| `itemStatus` | **全量筛选**（含未审核订单、取消行） |
| 进度/币别/品牌/date_code/业务员/排行 | **仅成单明细** |

### 4.6 明细主状态展示

- 销售明细仅 `status` 0（正常）/ 1（已取消）两档。
- 前端 `breakdownItemLabel` 映射 `salesOrderItemList.board.itemStatus.{normal,cancelled}`。

## 九、实现架构

```
SalesOrderItemList.vue（viewMode + boardFilters）
    └── SalesOrderItemListBoard.vue
            └── salesOrderItemAnalytics.ts
                    └── GET /api/v1/sales-orders/items/analytics/*
                            └── SalesOrdersController
                                    └── ISalesOrderItemLineListQuery（partial）
                                            ├── SalesOrderItemLineListQuery.cs      ← 分页列表
                                            ├── SalesOrderItemLineListFilter.cs     ← 共用 WHERE
                                            └── SalesOrderItemLineListAnalyticsQuery.cs ← 聚合
```

**分层职责**：

| 层 | 职责 |
| --- | --- |
| **Controller** | 权限校验、`maskAmounts`、Query 参数映射 |
| **Filter** | 日期 UTC、进度筛、数据范围 join 条件 |
| **AnalyticsQuery** | `LoadApprovedLineRowsAsync` / `LoadAllLineRowsAsync`、在库/出库日/应收聚合 |
| **Board.vue** | 并行拉取 4 端点；复用 `AnalyticsKpiGrid`、`AnalyticsTrendChart`、`AnalyticsBreakdownPieChart` |
| **i18n** | `salesOrderItemList.board.*`（zh-CN / en-US） |

## 十二、验收要点

1. 同一筛选条件下，看板成单明细数 ≤ 列表 `totalCount`（成单为子集）。
2. 切换筛选后看板自动刷新；`maskAmounts` 时金额 KPI 为 `—`、饼图按行数。
3. 明细主状态条图含取消行；进度饼图仅成单明细。
4. 应收最长账龄仅统计已出库且有待收明细。
5. 排行表名称列可换行，金额/明细数切换正常。
