## 一、定位与边界

| 维度 | 明细列表看板（`/sales-order-items`） | 报表「订单」Tab（`/reports/sales`） |
| --- | --- | --- |
| 统计粒度 | **明细行**（`sellorderitem`） | 同左 |
| 数据集 `dataset` | `listFilter`（默认） | `reportApproved` |
| 筛选来源 | 明细列表搜索栏全部条件 | 报表公司/部门/个人 + 日期 |
| 成单约束 | **否**（跟筛选结果，金额可含取消单等） | **是**（主单 status≥审核通过且明细有效） |
| 趋势 / groupBy | **不展示** | **展示** |
| UI Tag | 「筛选」 | 「成单」 |
| API 前缀 | `/api/v1/sales-orders/items/analytics/*` | `/api/v1/analytics/sales/order-items/*` |
| 实现 | 同一套 `ISalesOrderItemLineListQuery` + `SalesOrderItemListBoard.vue` | 同左（`mode=report`） |

**产品原则**：

1. 列表看板统计范围 = **当前明细列表筛选结果**（全量，非当前页）；**不成单**。
2. 报表订单 Tab = 报表透镜 + 日期 + **成单**；全量面板含趋势。
3. 列表分页与看板聚合 **共用** `SalesOrderItemLineListFilter`（含数据权限、日期 UTC 上界）。
4. 金额/利润无权限时脱敏（`mask521` + `sales.amount.read`），饼图改按**行数**占比（Mask 规则两侧一致）。

## 二、设计需求（功能清单）

### 2.1 UI 与交互（列表页）

| 项 | 需求 |
| --- | --- |
| 入口 | 搜索栏「看板 / 列表」切换按钮 |
| `viewMode` | `list` \| `board`，默认 `list` |
| 看板模式 | `v-show` 隐藏明细表格与分页；无顶部四卡 stat-row |
| 筛选联动 | `boardFilters` ← `dateRange` + `filters`；看板 `watch` 自动刷新 |
| 看板组件 | `SalesOrderItemListBoard.vue`（`mode=list`） |
| 顶栏 | Tag「筛选」+ 提示文案 + 刷新；**无** groupBy / 趋势 |

### 2.2 指标需求

| 呈现类 | 列表看板（listFilter） | 报表订单 Tab（reportApproved） |
| --- | --- | --- |
| **静态 KPI** | 订单概览 / 利润 / 在库 / 应收（跟筛选） | 成单概览 / 利润 / 在库 / 应收 |
| **趋势** | 无 | 成单订单数、明细数、金额；`groupBy` day/week/month |
| **分解** | 11 组（状态全量 + 进度等跟筛选） | 11 组（成单集合） |
| **排行** | 6 张 Top10 | 同左 |

### 2.3 看板布局（列表）

```
┌─ 工具条：Tag「筛选」+ 口径提示 + 刷新 ──────────────────────┐
├─ KPI 组 A：订单概览（客户 / 订单 / 明细 / 金额 + 原币分档）──┤
├─ KPI 组 B：利润 ──────────────────────────────────────────┤
├─ KPI 组 C：在库 ──────────────────────────────────────────┤
├─ KPI 组 D：应收款 ────────────────────────────────────────┤
├─ 分布：状态条图 + 多张饼图 ────────────────────────────────┤
└─ 排行：6 张 Top10 表 ─────────────────────────────────────┘
```

报表订单 Tab 在 KPI 与分解之间增加趋势三图 + 顶栏 groupBy。

## 三、筛选条件（与明细列表一致）

须透传 `SellOrderItemLineQueryRequest` 全部字段（列表 analytics 入口）：

| 参数 | 说明 |
| --- | --- |
| `orderCreateStart` / `orderCreateEnd` | 主单创建日（UTC 含当日上界） |
| `sellOrderCode` / `customerName` / `salesUserName` / `purchaseUserAccount` / … | 与列表一致 |
| `dataset` | `listFilter` \| `reportApproved`（列表默认 `listFilter`） |

报表入口不走列表筛选字段，由 `SalesAnalyticsResolvedScope` 填入：

| 字段 | 来源 |
| --- | --- |
| `AnalyticsDataset` | `reportApproved` |
| `AnalyticsViewLevel` / `AnalyticsDepartmentId` / `SalesUserId` | 报表透镜 |
| `OrderCreateStart` / `OrderCreateEnd` | 报表日期 |

**数据权限**：`ApplySellOrderDataScopeAsync` 作用于主单 join（与列表相同）。
