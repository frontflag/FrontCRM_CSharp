## 一、定位与边界

| 维度 | 需求明细列表看板（本文） | 报表分析 `/reports/sales` |
| --- | --- | --- |
| 统计粒度 | 筛选内明细行 + 关联主单字段 | 域级 + 公司/部门/个人透镜 |
| 筛选来源 | 明细列表搜索栏（全部筛选字段） | 独立日期 + Scope Tab |
| API 前缀 | `/api/v1/rfqs/items/analytics/*` | `/api/v1/analytics/sales/*` |
| 典型场景 | 筛完明细后看客户/转化/币别品牌/排行 | 管理层跨周期分析 |

**产品原则**：

1. 看板统计范围 = **当前明细列表筛选结果**（全量，非当前页）。
2. 列表分页与看板聚合 **共用** `RfqItemListFilter.BuildFilteredJoinQueryAsync`。
3. 本看板以**计数/比率**为主，无金额脱敏；客户名按 `mask521` + `customer.info.read` 脱敏。

## 四、统计口径（已确认）

### 4.1 客户 KPI

| 指标 | 口径 |
| --- | --- |
| 发布需求客户数 | 筛选内 `rfq.customer_id` 去重（非空） |
| 复询需求客户数 | 筛选结果内同客户 **≥2 张需求主单** |
| 复询需求数 | `Σ max(0, 该客户主单数 - 1)` |

### 4.2 需求 KPI

| 指标 | 口径 |
| --- | --- |
| 需求数 | 筛选内主单去重数 |
| 需求明细数 | 筛选内明细行数（`!is_deleted`） |

### 4.3 成单 KPI

| 指标 | 口径 |
| --- | --- |
| 成单明细数 | 筛选内明细存在链路：`sellorderitem`（`status=0`）→ `quote` → `rfqitem`，且 `sellorder.status >= 10`；按 `rfqitem.id` 去重 |
| 需求成单率 | `成单明细数 / 有效需求明细数 × 100%` |
| 有效需求明细数 | 筛选内明细，**仅排除 `status = 5`（查无报价）** |

### 4.4 趋势

时间轴：**`rfq.create_time`**。

| 序列 | 聚合 |
| --- | --- |
| 客户数 | 周期内 `customer_id` 去重 |
| 需求数 | 周期内主单去重 |
| 需求明细数 | 周期内明细 COUNT |

### 4.5 分布

| groupKey | 展示 | 计量 | 范围 |
| --- | --- | --- | --- |
| `rfqStatus` | 条图 | 主单去重数 | 筛选内明细关联主单 |
| `rfqType` | 饼图 | 主单去重数 | `rfq.rfq_type` |
| `targetType` | 饼图 | 主单去重数 | `rfq.target_type` |
| `industry` | 饼图 | 主单去重数 | `rfq.industry` 文本分桶 |
| `currency` | 饼图 | 明细数 | `rfqitem.price_currency` |
| `brand` | 饼图 | 明细数 | `rfqitem.brand`（空 → 未设置）；**展示 Top20，其余合并「其他」** |
| `assignedPurchaser` | 饼图 | 明细数 | 双采购员槽合并 |
| `quoteDistribution` | 饼图 | 明细数 | 有报价 / 查无报价(5) / 采购未处理(0 且无报价) |

**报价三档**（与 `effectiveRfqItemLineStatus` 一致）：

- **有报价**：非 5，且（`status≥1` 或存在 `quote.rfq_item_id`）
- **查无报价**：`status = 5`
- **采购未处理**：`status = 0` 且无报价

### 4.6 排行 Top10

| 表格 | 排序键 |
| --- | --- |
| 客户 | 需求明细数 |
| 业务员 | 需求明细数（`rfq.sales_user_id`） |
| MPN | 需求明细数 / 需求数量 |
| 品牌 | 需求明细数 / 需求数量 |

空 `mpn` / `brand` 归入「未设置」桶。
