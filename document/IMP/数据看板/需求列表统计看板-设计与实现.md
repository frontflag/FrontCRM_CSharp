## 一、定位与边界

| 维度 | 需求明细列表看板（`/rfq-items`） | 报表「需求」Tab（`/reports/sales`） |
| --- | --- | --- |
| 统计粒度 | 筛选内明细行 + 关联主单字段 | 同左 |
| 数据集 `dataset` | `listFilter`（默认） | `reportScope` |
| 筛选来源 | 明细列表搜索栏全部条件 | 报表公司/部门/个人 + 日期（主单 `rfq.create_time`） |
| 硬过滤 | **无** | **排除主单已取消** `rfq.status = 8` |
| 趋势 / groupBy | **不展示** | **展示** |
| UI Tag | 「筛选」 | 「报表」 |
| API 前缀 | `/api/v1/rfqs/items/analytics/*` | `/api/v1/analytics/sales/rfq-items/*` |
| 实现 | 同一套 `IRfqItemListQuery` + `RfqItemListBoard.vue` | 同左（`mode=report`） |

**产品原则**：

1. 列表看板 = **当前搜索栏筛选结果**（全量，非当前页）；无额外硬过滤。
2. 报表需求 Tab = 报表透镜 + 日期 + **排除已取消**；全量面板含趋势。
3. 列表分页与看板聚合 **共用** `RfqItemListFilter.BuildFilteredJoinQueryAsync`。
4. 以计数/比率为主；客户名按 `mask521` + `customer.info.read` 脱敏（两侧一致）。

## 三、筛选与 dataset

列表透传与 `GET /api/v1/rfqs/items` 一致；另加 `dataset=listFilter|reportScope`。

报表由 `SalesAnalyticsResolvedScope` 填入：

| 字段 | 来源 |
| --- | --- |
| `AnalyticsDataset` | `reportScope` |
| `AnalyticsViewLevel` / `AnalyticsDepartmentId` / `SalesUserId` | 报表透镜 |
| `StartDate` / `EndDate` | 报表日期（主单创建日） |

`reportScope` 在筛选末尾：`Status != Cancelled(8)` + 部门/个人透镜。
