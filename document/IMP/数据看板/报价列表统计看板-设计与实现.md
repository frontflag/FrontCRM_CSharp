## 一、定位与边界

| 维度 | 报价列表看板（本文） | 报表分析 `/reports/purchase` |
| --- | --- | --- |
| 统计粒度 | **方案 A**：并联需求明细 + 筛选内 quote / quoteitem | 同左 |
| 数据集 `dataset` | `listFilter`（默认） | 报价 Tab：`reportScope` |
| 筛选来源 | 报价列表搜索栏（keyword / status / 创建日期） | 独立日期 + Scope Tab |
| 趋势 / groupBy | **不展示** | 报价 Tab **展示** |
| UI Tag | 「筛选」 | 报价 Tab「报表」 |
| API 前缀 | `/api/v1/quotes/analytics/*` | 报价 Tab：`/api/v1/analytics/purchase/quotes/*` |
| 实现 | `QuoteListBoard.vue`（`mode=list`） | 同组件 `mode=report` |
| 典型场景 | 筛完报价后看供应商/响应/转化/采购员绩效 | 管理层跨周期分析 |

**产品原则**：

1. 看板统计范围与列表筛选联动（全量，非当前页）。
2. 列表分页与看板聚合 **共用** `QuoteListFilter`（抽离自 `QuoteListQuery`）。
3. 本看板以**计数/比率/时长**为主，无金额 KPI；客户名按 `mask521` + `customer.info.read` 脱敏；供应商按采购脱敏规则处理。

**统计范围（方案 A，已确认）**：

| 数据集 | 筛选约束 |
| --- | --- |
| **`listFilter`（列表）** | 并联需求：`keyword` + **`rfq.create_time`** + 数据权限；报价主表再叠 `status`（不裁剪并联需求） |
| **`reportScope`（报表）** | 报表透镜 + **`quote.create_time`**；并联需求仅保留该期内有报价的需求行；**不硬过滤** quote 主状态 |
| **报价行** `quoteitem` | 隶属筛选后 quote；用于供应商数、涂标/产地/包邮（分布按 quote 首条 brand 见 §4.5） |

> 列表：`status` **不裁剪**并联需求集：筛「新建报价」时，查无报价 / 采购未处理 / 需求报价率分母仍可见。

## 三、筛选条件

与 `GET /api/v1/quotes` 对齐（P0 扩展日期）：

| 参数 | 说明 |
| --- | --- |
| `keyword` | 报价单号、MPN、备注、需求编号、客户、业务员/采购员、明细品牌/料号（OR） |
| `status` | 报价主状态 `0` 新建 / `1` 成单 / `2` 关闭；**仅过滤 quote** |
| `startDate` / `endDate` | 关联需求 **`rfq.create_time`**（UTC 含止日上界）；列表与看板共用 |
| `rfqItemId` | 精确（API 已有；列表可选） |

**数据权限**：`IDataPermissionService.ApplyQuoteListDataScopeAsync`（与报价列表一致）。

## 四、统计口径（已确认）

### 4.1 计数粒度约定

| 术语 | 粒度 |
| --- | --- |
| **报价条目** | `quote` 主表条数 |
| **报价明细数**（排行条数） | 同上，`quote` 主表 COUNT |
| **品牌展示** | `quote` 下 **首条有效 `quoteitem.brand`**（与列表首行一致）；空 →「未设置」 |

### 4.2 供应商 KPI

| 指标 | 口径 |
| --- | --- |
| 提供报价的供应商数 | 筛选内 `quoteitem.vendor_id` 去重（非空） |

### 4.3 报价 KPI

| 指标 | 口径 |
| --- | --- |
| 报价条目数（有效） | 筛选内 **`quote` 主表**条数（查无报价不在 quote 表，自然排除） |
| 查无报价条目数 | 并联需求范围内 `rfqitem.status = 5` |
| 需求报价率 | `有 quote 的需求明细数 / 有效需求明细数 × 100%`（有效 = 排除 status=5） |
| 报价平均响应时间 | 有 quote 且非查无报价的明细：`首条 quote.create_time − rfq.create_time`，求平均，**单位：分钟** |
| 报价平均数 | `Σ(每需求明细 quote 条数) / 有 quote 需求明细数`，**保留 1 位小数**；排除查无报价、无 quote 明细 |

### 4.4 订单 KPI

| 指标 | 口径 |
| --- | --- |
| 成单数 | 筛选内成单**需求明细数**（`rfqitem.id` 去重） |
| 报价成单率 | `成单明细数 / 有 quote 需求明细数 × 100%`（分母排除查无报价） |

**成单链路**（与需求明细看板一致）：

`sellorderitem`（`status=0`）→ `quote` → `rfqitem`，且 `sellorder.status >= 10`（审核通过及以上，排除取消单）。

### 4.5 趋势（`groupBy` = day / week / month）

| 数据集 | 落桶键 |
| --- | --- |
| `listFilter` | **`rfq.create_time`**（列表看板默认不展示趋势；口径保留） |
| `reportScope` | **`quote.create_time`** |

| 序列 | `listFilter` | `reportScope` |
| --- | --- | --- |
| 报价供应商数 | 桶内需求关联 quoteitem 的 `vendor_id` 去重 | 桶内 quote 的 quoteitem `vendor_id` 去重 |
| 需求明细数 | 桶内并联需求 COUNT | 桶内 quote 关联 `rfqitem` 去重 |
| 有效报价数 | 桶内需求关联的 quote 条数 | 桶内 quote 主表 COUNT |

### 4.6 分布

| groupKey | 展示 | 计量 | 说明 |
| --- | --- | --- | --- |
| `quoteStatus` | 条图 | quote 主表 | 新建 / 成单 / 关闭 |
| `quoteDistribution` | 饼图 | 需求明细 | 有报价 / 查无报价(5) / 采购未处理(0 且无 quote) |
| `labelType` | 饼图 | quote 主表 | 首条 quoteitem：`0` 不涂标 / `1` 涂标 / `2` 待确定 |
| `waferOrigin` | 饼图 | quote 主表 | 首条 quoteitem 晶圆产地 |
| `packageOrigin` | 饼图 | quote 主表 | 首条 quoteitem 封装产地 |
| `freeShipping` | 饼图 | quote 主表 | 首条 quoteitem 包邮 是/否 |
| `brand` | 饼图 | quote 主表 | 首条 brand；**Top20 + 其他** |
| `assignedPurchaser` | 饼图 | 需求明细 | 分配采购员双槽合并 |
| `quotePurchaser` | 饼图 | quote 主表 | `purchase_user_id` |

**报价三档**（与 `RfqItemListAnalyticsQuery` / `effectiveRfqItemLineStatus` 一致）：

- **有报价**：status ≠ 5 且（status ≥ 1 或存在 `quote.rfq_item_id`）
- **查无报价**：status = 5
- **采购未处理**：status = 0 且无 quote

### 4.7 排行 Top10

| 表格 | 排序键 |
| --- | --- |
| 供应商 | 去重 `rfq_item_id` 数（经 quoteitem 关联） |
| 报价采购员（条目） | `quote.purchase_user_id`，quote 主表条数 |
| 报价采购员（报价率） | `quote 数 / 分配需求明细数 × 100%`；分配双槽各计 1 |
| MPN（条数） | `quote.mpn`，quote 主表条数 |
| MPN（Qty） | 按 `rfqitem.quantity` 汇总 |
| 品牌（条数） | 首条 brand，quote 主表条数 |
| 品牌（Qty） | 首条 brand，关联 `rfqitem.quantity` 汇总 |
