## 一、定位与边界

| 维度 | 收款记录列表看板（本文） | 财务分析「已收款」 | 应收款列表看板 |
| --- | --- | --- | --- |
| 统计粒度 | **`financereceipt` 单头** | 已确认收款趋势 / 应收 `verified_done` | `finance_receivable` 行 |
| 筛选来源 | 收款列表搜索栏全部条件 | 报表透镜 + 收款日 | 应收列表筛选 |
| 集合硬过滤 | **无**（完全跟筛选） | 通常仅确认（Status=3） | 跟筛选 |
| 金额 | 单头 `ReceiptAmount` 原币 | 明细折算路径（可含 `ReceiptConvertAmount` 当美金覆盖） | 待核销/总额折美金 |
| 美金 | **不做** | 有折算美金 | 有折算美金 |

**产品原则：**

1. 看板统计范围 = **当前收款列表筛选结果**（全量，非当前页）。
2. 列表分页与看板聚合共用 `FinanceReceiptListFilter`（含数据权限）。
3. 计数按**单头**；金额用单头 `ReceiptAmount`，**不用** `ReceiptConvertAmount`（核销额度原币）。
4. **不折算美金**，各原币独立合计 / 画图 / 排序。
5. 521 时金额与客户名脱敏；饼图/排名改按**单数**。
6. **不**做公司/部门/个人透镜，**不**改财务分析「已收款」数据源，**不**做待办。

## 二、UI 与交互

| 项 | 需求 |
| --- | --- |
| 入口 | 搜索栏「看板 / 列表」切换（查询之后、齿轮之前） |
| `viewMode` | `list` \| `board`，默认 `list` |
| 看板模式 | `v-if` 挂载看板；`v-show` 隐藏统计卡、表格与分页 |
| 筛选联动 | `boardFilters` ← 当前搜索栏（含页签）；看板 `watch` 自动刷新 |
| 顶栏 | Tag「筛选」+ 口径提示 + 趋势粒度 天/周/月 + 刷新 |
| 帮助 | `useListBoardHelpOverride` → `help/pages/收款记录看板_MENU_FINANCE_RECEIPT_BOARD.md` |
| 页签模式 | **跟随**现网齿轮页签 |

布局：

```
┌─ Tag「筛选」+ 口径提示 + 天/周/月 + 刷新 ─┐
├─ KPI：收款客户数 / 收款金额（各原币分行）
├─ 趋势：收款单数 │ 各原币收款金额（一币一张）
├─ 分布：核销状态（单数）│ 业务员（按原币分面）
└─ 排名：各原币 Top10 客户 │ 各原币 Top10 业务员
```

## 三、口径（已确认）

| 项 | 结论 |
| --- | --- |
| 集合 | **完全跟当前搜索栏**。不硬过滤「确认」。只要确认集合时，在状态下拉/页签选「确认」。 |
| 金额 | 单头 `ReceiptAmount` + `ReceiptCurrency`。禁止跨币相加。 |
| 日期筛选 | 列表现网：`CreateTime` |
| 趋势时间轴 | `ReceiptDate`。无日期不进趋势，仍进 KPI / 分布 / 排名 |
| 核销状态 | 与列表列同一套头表汇总，饼图按收款单数 |
| 业务员 | 头表 `SalesUserId`；空归「未分配业务员」 |
| 脱敏 | 对齐列表 521 |
