## 一、定位与边界

| 维度 | 付款记录列表看板（本文） | 收款记录列表看板 | 财务分析 |
| --- | --- | --- | --- |
| 统计粒度 | **`financepayment` 单头** + 明细货款 / 采购员拆分 | `financereceipt` 单头 | 域级透镜 |
| 筛选来源 | 付款列表搜索栏全部条件 | 收款列表筛选 | 报表透镜 |
| 集合硬过滤 | **无**（完全跟筛选） | 无 | 常仅确认 / 已付 |
| 金额 | 明细已付货款，不含费用 | 单头 `ReceiptAmount` | 可含折算美金 |
| 美金 | **不做** | 不做 | 有折算 |

**产品原则：**

1. 看板统计范围 = **当前付款列表筛选结果**（全量，非当前页）。
2. 列表分页与看板聚合共用 `FinancePaymentListFilter`（含数据权限）。
3. 计数按**单头**；金额用明细 `PaymentAmount` 合计，**不用** 单头 `PaymentAmount` / `PaymentTotalAmount`（完成时二者已含费用）。
4. **不折算美金**，各原币独立合计 / 画图 / 排序。
5. 511 时金额与供应商名脱敏；饼图/排名改按**单数**。
6. **不**做公司/部门/个人透镜，**不**改 `/reports/finance`，**不**做待办。

## 二、UI 与交互

| 项 | 需求 |
| --- | --- |
| 入口 | 搜索栏「看板 / 列表」切换（查询之后、齿轮之前） |
| `viewMode` | `list` \| `board`，默认 `list` |
| 看板模式 | `v-if` 挂载看板；`v-show` 隐藏统计卡、表格与分页 |
| 筛选联动 | `boardFilters` ← 当前搜索栏（含页签）；看板 `watch` 自动刷新 |
| 顶栏 | Tag「筛选」+ 口径提示 + 趋势粒度 天/周/月 + 刷新 |
| 帮助 | `useListBoardHelpOverride` → `help/pages/付款记录看板_MENU_FINANCE_PAYMENT_BOARD.md` |
| 页签模式 | **跟随**现网页签 |

布局：

```
┌─ Tag「筛选」+ 口径提示 + 天/周/月 + 刷新 ─┐
├─ KPI：付款供应商数 / 付款金额（各原币分行）
├─ 趋势：付款单数 │ 各原币付款金额（一币一张）
├─ 分布：核销状态（单数）│ 采购员（按原币分面）
└─ 排名：各原币 Top10 供应商 │ 各原币 Top10 采购员
```

## 三、口径（已确认）

| 项 | 结论 |
| --- | --- |
| 集合 | **完全跟当前搜索栏**。不硬过滤「付款完成」。只要已付集合时，在状态下拉/页签选「付款完成」。 |
| 金额 | 明细已付货款 `Σ(PaymentAmount)` + 单头 `PaymentCurrency`。禁止跨币相加。不含费用。 |
| 日期筛选 | 列表现网：`PaymentDate` |
| 趋势时间轴 | `PaymentDate`。无日期不进趋势，仍进 KPI / 分布 / 排名 |
| 核销状态 | 明细 min/max 汇总到整单，饼图按付款单数 |
| 采购员 | 明细归属采购订单采购员；空归「未分配采购员」；一张单可进多名采购员 |
| 脱敏 | 对齐列表 511 |

未付款明细已付为 0，仍计入供应商数、单数、核销饼。
