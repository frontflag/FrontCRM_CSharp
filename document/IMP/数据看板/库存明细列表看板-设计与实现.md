## 一、定位与边界

| 维度 | 库存明细列表看板（本文） | 库存中心列表看板 | 物流分析 Snapshot |
| --- | --- | --- | --- |
| 统计粒度 | **`stock_item` 明细行**（列表同一筛选） | 在库层（强制 `qty_repertory > 0`） | 在库层 + 报表透镜 |
| 筛选来源 | 库存明细搜索栏 + 页签 | 库存中心搜索栏 | 报表 Tab + 截至日 |
| 金额 | 原币分列 `qty×PurchasePrice` | 同左 | 折算 USD |
| 周转 | **数量**口径：在库 / 近 30 天出库 × 30 | — | — |
| 呆滞 | **在库数量** | 层数 | — |
| 趋势 | 时点存量；**尊重** `groupBy` | 固定 12 个月按月 | 入库流入 |

**产品原则：**

1. 看板统计范围 = **当前搜索栏与页签筛选结果的全量明细**（非当前页）。
2. 列表分页与看板共用 `InventoryStockItemListFilter`（含 `ApplyStockItemListDataScopeAsync`）。
3. 511 / 无 `purchase.amount.read`：金额「—」；**周转天数仍显示**；饼图/排行改按数量。
4. 521：排行客户/业务员名称脱敏，Id 仍可用于下钻。
5. **不**做公司/部门/个人透镜。

## 三、口径（已确认）

| 项 | 结论 |
| --- | --- |
| KPI 时点 | **今天**；在库数量 = 列表 `qtyRepertoryTotal` |
| 周转天数 | `ROUND(在库数量 / 近30天出库数量 × 30, 1)`；任一为 0 → null |
| 出库事件 | `stock_out_item` + 头 `status∈{2,4}`；数量 `ActualQty` 优先 |
| 呆滞数量 | 入库日 ≤ 今天−90 或无入库日的 `Σ qty_repertory` |
| 趋势 | 时点存量 `max(0, qty_inbound − Σ出库(出库日≤asOf))`；日 30 / 周 12 / 月 12；入库日起止相交裁剪 |
| 库龄饼 | `0–30 / 31–90 / 91–180 / 181–365 / 365+`；无入库日不进饼 |
| Top10 物料 | 型号 + 品牌 |
| 空客户 | 「无客户 / 备货」 |
