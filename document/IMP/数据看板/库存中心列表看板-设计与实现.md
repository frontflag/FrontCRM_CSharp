## 一、定位与边界

| 维度 | 库存中心列表看板（本文） | 物流分析 Snapshot | 库存桶财务卡 |
| --- | --- | --- | --- |
| 统计粒度 | **`stock_item` 在库层** | 在库层 + 报表透镜 | `stock` 分桶 |
| 筛选来源 | 库存中心搜索栏 | 报表 Tab + 截至日 | 库存桶搜索栏 |
| 金额 | 原币分列 `qty×PurchasePrice` | 折算 USD | 折算 RMB |
| 周转 | — | — | 折算 RMB |
| 库龄 KPI | **加权平均库龄**（天） | 加权平均库龄 | — |
| 趋势 | **时点存量**（最近 12 个月，按月） | 入库流入 / 二期日末曲线 | — |

**产品原则：**

1. 看板统计范围 = **当前搜索栏筛选结果的全量在库层**（非当前页）。
2. **拆分维度勾选**只影响列表分行，**不**改变看板集合。
3. 呆滞 = 入库日起算 ≥90 天的层数；库龄饼图分桶对齐物流分析。
4. 511 / 无 `purchase.amount.read`：金额「—」；**加权平均库龄仍显示**；饼图/排行改按数量。
5. **不**做公司/部门/个人透镜；**不**改微信库存页。

## 三、口径（已确认）

| 项 | 结论 |
| --- | --- |
| KPI 时点 | **今天**；与列表 `onHandQtyTotal` / `totalAmounts` 一致 |
| 趋势 | **时点存量**；最近 **12** 个月、**按月**；固定 **RMB / USD** 两图；按层回放 `qty_inbound − 累计出库` |
| 出库事件 | `stock_out_item` + 头 `status∈{2,4}`；数量 `ActualQty` 优先 |
| 加权平均库龄 | `ROUND(Σ(库龄天×在库数量)/Σ(在库数量),1)`；入库日起算；**无入库日不参与** |
| 呆滞 | 入库日 ≤ 今天−90 或无入库日的在库 **层数** |
| 库龄饼 | `0–30 / 31–90 / 91–180 / 181–365 / 365+`；无入库日不进饼 |
| Top10 物料 | 型号 + 品牌 |
| 空客户 | 「无客户 / 备货」 |
