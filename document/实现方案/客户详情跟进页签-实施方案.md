## 0. 背景

| 项 | 说明 |
|----|------|
| 占位 | `CustomerDetail` 一级页签 `followUp` 现为「即将推出」 |
| 任务已在 | `work_task`；桌面橙点是 **执行人=自己**；完成后写联系历史 |
| 本页 | 同一张表，按 **客户** 看全部执行人 |

**不做：** 联系历史搬家；需求/订单圆点；附件、周期、考核；时间线。

## 1. 分期

| 阶段 | 内容 | 完成标准 |
|------|------|----------|
| A | 客户维度月点 + 分页列表（含内容字段） | 非执行人也能列出同事任务；默认不含已取消；`includeCancelled=true` 才含 90 |
| B | 跟进页签左右栏 + 日历筛选 + 全部/含已取消/新建 | 点日期筛当天；点全部回全量；翻月不改列表 |
| C | 右侧正文 + 开始/完成/取消 + PATCH 标题内容 | 别人任务只读；完成仍写联系历史 |
| D | 深链、帮助、一级页签文档、QA | `?tab=followUp&taskId=` 能选中 |

## 2. 后端（阶段 A）

不要复用 `GET /work-calendar/month`（那是当前用户的需求+订单+任务）。

建议挂在客户资源下（先校验客户可见，与详情同一套数据权限）：

### 2.1 月圆点

`GET /api/v1/customers/{customerId}/work-tasks/month?year=&month=&includeCancelled=false`

返回该月有任务的日期及 `taskCount`。  
`includeCancelled=false`：状态 ∈ {10,20,30}；`true` 再含 90。软删不计。  
一天最多一个点。

### 2.2 分页列表

`GET /api/v1/customers/{customerId}/work-tasks?page=1&pageSize=50&startDate=&includeCancelled=false`

| 参数 | 说明 |
|------|------|
| `startDate` | 有则只该上海日；无则全部 |
| `includeCancelled` | 默认 false |
| 排序 | `start_date DESC, create_time DESC` |
| 分页 | 默认 50，上限 50 |

每行至少：`id, title, status, priority, startDate, assigneeUserId, assigneeUserName, createByUserId, content, contactHistoryId, canWrite`（创建人或执行人且调用方有写权限时 `canWrite=true`）。

### 2.3 单条（可选）

列表已带 `content` 则右侧不必再打详情。若拆详情：

`GET /api/v1/customers/{customerId}/work-tasks/{taskId}`

授权：**能看该客户** 且任务属于该客户。  
**禁止** 对同事任务走现有 `GET /api/v1/work-tasks/{id}`（`RequireVisibleTaskAsync` 会 403「不能查看他人任务」）。

### 2.4 写接口

继续：

- `POST /work-tasks`（body `objectId` 必须等于当前客户，前端锁定）
- `PATCH /work-tasks/{id}`
- `POST .../start|complete|cancel`

规则不变：写权限 + 创建人/执行人；完成写联系历史。

索引已有 `(object_type, object_id)`。

## 3. 前端（阶段 B / C）

| 文件 | 职责 |
|------|------|
| `CRM.Web/src/components/Customer/CustomerFollowUpPanel.vue` | 跟进页签 |
| `CustomerDetail.vue` | `followUp` 从占位改为挂面板（`v-show` + 首次进入再加载，同比画像/新闻） |
| `customerDetailPrimaryTabs.ts` | `followUp` 移出 `PLACEHOLDERS` |
| 月历 | 抽共用月格或本页复制紧凑格；**不要** 用桌面抽屉三块清单 |

交互：

1. 列表顶：**全部**（清除 `startDate`）、**含已取消** 开关（默认关）、有写权限时 **新建跟进**。  
2. 点月历某天：`startDate=该日`，列表刷新，尽量保持选中行。  
3. 翻月：只请求 month；当前 `startDate` 若仍在新月可保持选中高亮。  
4. 选中行 → 右栏绑定该行；`canWrite` 才显示开始/完成/取消与可编辑标题内容。  
5. 新建弹窗：客户只读当前客户；开始日默认所选日或今天；执行人默认自己。复用桌面表单字段即可，不必复制选客户。

| 本功能金额 | 不适用核销足额/超额 |
