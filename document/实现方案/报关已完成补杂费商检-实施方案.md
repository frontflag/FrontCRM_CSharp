## 0. 背景与不做

| 项 | 说明 |
|----|------|
| 现象 | `CDS00009` 类单据：已完成 + 已结关 + 已有到货通知。漏杂费/商检。设置海关状态回「未维护」报「报关单已完成，不能修改海关状态」 |
| 根因 | 拦住的是 `InternalStatus=已完成`，不是海关状态。已完成明细 PATCH 只放过采购美金价，杂费/商检被「已完成报关单不能修改明细」拒绝 |
| **不做** | 回退/人工改海关状态；解开已完成；允许非管理员改已完成费用；自动冲应付/发票 |

运维操作路径（落地后）：打开报关单详情 → 报关费用 → 管理员改行「杂费」「商检费」→ 保存（或试算）→ 看成功提示中的下游回写条数。

## 2. 后端（阶段 A / B）

### 2.1 `UpdateDeclarationItemAsync`（已完成）

文件：`CRM.Core/Services/CustomsV2FlowService.cs`

现逻辑：已完成则 `touchesOther`（含 OtherFee/InspectionFee）一律抛「已完成报关单不能修改明细」。

改为：

1. 仍禁止：HS、申报数量/单价、关税税率、增值税率。
2. `otherFee` / `inspectionFee`：仅当 `canCorrectLockedCostUsd==true`（SYS_ADMIN / SYS_MANAGER）允许。
3. `costUsd` / `costUsdManual`：维持现采购美金价更正。
4. 非管理员改杂费/商检：明确文案，例如「已完成报关单仅系统管理员或平台管理员可补录杂费或商检费。」
5. 写入杂费/商检后 `SaveChanges`，再调 `RecalculateDeclarationFeesAsync(..., canCorrectLockedCostUsd: true)`（保留代理费率快照 + `CascadeDeclarationItemAsync`）。不要只走 `ApplyLineFooterTotals`（那条路径不级联）。

管理员可在一次保存里同时改采购美金价和杂费。

### 2.2 已结关锁定、未完成（阶段 B）

同一方法的 `dec.FeesLocked` 分支：现已允许关务改杂费/商检，但只 `ApplyLineFooterTotals`，**不** `CascadeDeclarationItemAsync`。

已生成到货/入库的锁定单改杂费后库存成本会错。本版：杂费变化导致 P1 变化时，对该行调用 `CascadeDeclarationItemAsync`。仅改商检则不级联。

### 2.3 试算门控

`CustomsLockedCostUsdCorrection.EnsureCanRecalculate`：已完成 / 锁定下管理员已可试算。不必改枚举，复用 `canCorrectLockedCostUsd`。可把类注释扩成「采购美金价或杂费/商检补录」。

### 2.4 变更日志

`log_change_fldval` 增行字段：

| fieldName | 标签 | 记录码 |
|-----------|------|--------|
| `otherFee` | 杂费 | `{报关单号}-L{行号}` |
| `inspectionFee` | 商检费 | 同上 |

人手保存记登录账号。详情页现有变更日志接口可直接带出，无需新 API。

### 2.5 单测（建议）

`tests/CRM.Core.Tests/Services/` 新增或扩 `CustomsV2FlowService` / 现有费用测试：

| 用例 | 预期 |
|------|------|
| 已完成 + 管理员 + 杂费 0→100 | 成功；价税含 100；P1 变；级联被调用（或 mock 计数 >0） |
| 已完成 + 管理员 + 仅商检 | 成功；价税/P1 不变；级联 0 或等值跳过 |
| 已完成 + 非管理员 + 杂费 | 拒绝，文案含管理员 |
| 已完成 + 任何人 + 改关税率 | 仍拒绝 |
| 已作废 | 仍拒绝 |
| 锁定未完成 + 杂费 | P1 变且级联（阶段 B） |

金额：杂费足额写入成功即可；无核销提交。本功能不适用足额/超额核销。

## 5. 手工验收（CDS00009 类）

前置：SYS_MANAGER 或 SYS_ADMIN；报关单已完成、已结关、已有到货通知；杂费当前为 0。

| 步骤 | 预期 |
|------|------|
| 关务（非管理员）打开费用面板 | 杂费/商检只读 |
| 管理员改杂费并保存 | 成功；价税总额增加杂费；提示回写到货/入库/库存条数（有下游则 >0） |
| 到货通知、报关入库明细、库存采购价 | 含税单价 = 新 P1 |
| 海关状态 | 仍为已结关 |
| 流程状态 | 仍为已完成 |
| 仅补商检 | 保存成功；价税与库存单价不变 |
| 非管理员再保存杂费 | 后端拒绝 |
| 金额 | 本功能不适用核销足额/超额；只核对本单公式：价税 = 货款+关税+增值税+代理费+杂费 |
