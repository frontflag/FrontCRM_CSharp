---

## 0. 本期锁定的口径

| # | 议题 | 锁定 |
| --- | --- | --- |
| 1 | 日期窗口 | 结束日=昨天；开始日=昨天往前 1 天 |
| 2 | 谁可见 | 登录即可 |
| 3 | 点击 | 行 / 查看全部 → 当天全文；无历史列表、无机构外链 |
| 4 | 输出 | 卡片 JSON + 全文 Markdown；提示词按新模版，6 维 + 五节标题写死 |
| 5 | 厂商名单 | 优先关注样例，不封闭 |

## 1. 范围

| 做 | 不做 |
| --- | --- |
| 表 `industry_news_briefing` | 打开桌面现搜 |
| 场景 `industry.news.briefing`（联网） | 独立历史页 |
| `GET /api/v1/industry-news/latest` | 按人定制 |
| 控制台卡片 + 全文弹层 | 新侧栏菜单 |
| 上海 08:00 HostedService | Hangfire |
| `/system/ai-config` 改模版 + 手跑 | 为新闻单独建参数页 |

表只存 `items_json` + `markdown` 信封，不随模版增列。

---

## 2. 上线步骤

1. 执行 `scripts/ensure_industry_news_postgresql.sql`（或跑迁移 `20260914160000_IndustryNewsBriefing`）。  
2. 生产把场景厂商从 `mock` 改为已配置的 `moonshot`（及对应 model），保持 `enable_web_search=true`。  
3. 重启 CRM.API。  
4. 当天 08:00 后等待作业；或由 **SYS_ADMIN** 点控制台「立即刷新」/ `POST /api/v1/industry-news/run`（接口立即返回，后台生成，前端轮询 latest）。  
5. 登录打开控制台，风险预警下方应出现「行业新闻」。

## 3. 权限

| 码 | 谁有 | 用途 |
| --- | --- | --- |
| （无额外桌面权限） | 已登录 | 看卡片 / 读 latest |
| `biz.ai.industry_news.briefing` | SYS_ADMIN、biz_all；作业走 `InvokeSystemAsync` | 通用 AI 调用入口 |
| `SYS_ADMIN` 角色 | 系统管理员 | 控制台「立即刷新」/ 手动 `POST .../run` |
| `biz.ai.admin` | AI 管理员 | 改厂商/场景/模板；**不含**手跑 |
