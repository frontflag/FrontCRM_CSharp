## 第一期：财务付款（试点）

### 1.1 范围

解决截图场景：**编辑付款单 → 收款信息 → 供应商** 仅显示中文的问题。

| 页面 / 组件 | 改动要点 |
|-------------|----------|
| `FinancePaymentPayDialog.vue` | 供应商名称改为 `span=24`；使用 `VendorNameReadonlyField`（compact）；货代单号与供应商编号同排 |
| `FinancePaymentDetail.vue` | `formatVendorNameReadonly` + 保留编码型 `vendorName` 回查兜底；tooltip + 换行 |

### 1.2 新增基础设施

| 文件 | 说明 |
|------|------|
| `CRM.Web/src/utils/vendorDisplayName.ts` | `formatVendorNameReadonly`、`formatVendorNameReadonlyFromRow` |
| `CRM.Web/src/components/Vendor/VendorNameReadonlyField.vue` | 弹窗 compact / 详情 inline；textarea 1～2 行 + tooltip |

### 1.3 数据依赖（第一期已有）

- `FinancePayment.vendorEnglishName`：`[NotMapped]`，由 `FinancePaymentService.EnrichVendorCodesAsync` 从 `vendorinfo.EnglishOfficialName` 填充。
- 前端类型：`CRM.Web/src/api/finance.ts` · `FinancePayment.vendorEnglishName`。

### 1.4 弹窗布局（第一期定稿）

**调整前：**

```text
[ 供应商编号 span12 ] [ 供应商名称 span12 ]
[ 货代单号 span12   ]
```

**调整后：**

```text
[ 供应商编号 span12 ] [ 货代单号 span12 ]
[ 供应商名称 span24 — 中文 / 英文，textarea 1~2 行 ]
```
