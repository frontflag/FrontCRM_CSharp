## 0. 本期锁定口径（摘要）

| # | 议题 | 锁定 |
|---|------|------|
| 1 | 投票与回复 | 分离；一人一票不可改；回复不限 |
| 2 | 选项 | 最少 2、最多 20 |
| 3 | 截止 | 选填；截止后未投票可看结果；不可早于当天 |
| 4 | 投前看统计 | 作者/版主可看 |
| 5 | 多选上限 | 选填 |
| 6 | 发投票权限 | 同普通发帖 |
| 7 | 自定义板块 | type≥100；超管新建/排序/删空板 |
| 8 | 系统说明帖 | 见 [系统自动生成帖子规范](../System/协作/BBS系统自动生成帖子-规范.md)。操作说明正文不写管理员板块操作（新建、排序、版主、删板块） |

完整定稿见设计文档 §1.3、§5.1 与系统帖规范。

## 1. 范围

| 做 | 不做 |
|----|------|
| 主题/回复/置顶/关帖/软删 | @、铃铛桥接、微信 |
| 板块版主与自定义板块、拖放排序 | EBS 历史迁移 |
| 主题媒体、赞踩 | 回复附媒体、改票 |
| 投票帖（选项/单多选/截止/统计可见性） | 公示选民 |

---

## 2. 上线步骤

1. 部署含论坛代码的 API / Web。  
2. 确认 PostgreSQL 已执行 `scripts/ensure_bbs_postgresql.sql`，**或**启动 API 依赖 `BbsSchemaEnsure` 自动补齐（含 `kind` / poll 表）。  
3. **重启 API**。  
4. 刷新前端；用普通账号测发帖/回复/投票；用超管测板块设置与「系统更新」发帖。  
5. 按 [测试对照说明](../QA/协作/BBS论坛-测试对照说明.md) 冒烟。

---

## 3. 关键结构要点

| 对象 | 说明 |
|------|------|
| `bbs_subject` | 增 `kind`、`vote_mode`、`vote_max_choices`、`vote_deadline`、`vote_count` |
| `bbs_poll_option` / `bbs_poll_vote` / `bbs_poll_vote_item` | 选项与一人一票 |
| `bbs_board_moderator` | 版主、显示名、`sort_order`、软删 |
| `bbs_reaction` | 主题赞踩防重 |

## 5. 验收门控（冒烟）

- [ ] 登录可见论坛；发帖/回复成功  
- [ ] 置顶区与列表分离  
- [ ] 超管可新建板块并拖放排序；固定区不可拖  
- [ ] 发起投票：≥2 选项；投票一次成功；再投失败  
- [ ] 未投票普通用户看不到选项票数；投后可见；截止后未投也可见  
- [ ] 关帖后不可回复、不可投票  
- [ ] 论坛帖不增加系统公告/铃铛未读
