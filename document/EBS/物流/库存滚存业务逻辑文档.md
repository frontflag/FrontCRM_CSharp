# 库存滚存业务逻辑文档

## 一、功能概述

"滚存"是财务模块（BaseFinance）中的一种**库存月度滚动结余统计**功能。它按月累计计算采购入库和出库的金额与数量，展示各月度的**上期结余、本期入/出、期末结余**，用于财务对库存价值的持续追踪。

滚存模块包含 4 个子功能：

| 功能 | API | 说明 |
|------|-----|------|
| 客户滚存 | `GetCustomerAccumulatedListBySearch` | 按客户维度统计月度库存进出 |
| 客户滚存明细 | `GetCustomerAccumulatedItemListBySearch` | 按客户 + 年月展开明细 |
| 供应商滚存 | `GetVendorAccumulatedListBySearch` | 按供应商维度统计月度库存进出 |
| 供应商滚存明细 | `GetVendorAccumulatedItemListBySearch` | 按供应商 + 年月展开明细 |
| **库存滚存** | `GetStockAccumulatedListBySearch` | 全局库存月度滚存（按年份，展示1-12月） |
| **库存明细滚存** | `GetStockItemAccumulatedListBySearch` | 按入库记录明细展示滚存（按月份） |

## 二、库存滚存（StockAccumulatedList）

### 2.1 查询条件

| 参数 | 类型 | 说明 |
|------|------|------|
| `Year` | string | 必选，年份（如 "2026"） |

**必须选择年份**，否则报错 `"请选择年份！"`。

### 2.2 数据范围

- **仅统计采购入库**：`StockInV2.Type == EnumStockInType.Purchase`
- **金额使用折算美金单价**：`StockInV2.ConvertCost`
- **出库数据来源**：`PackingItem` 装箱出库明细

### 2.3 核心计算公式

#### 每月指标

```
本期入库金额 = Σ(该月入库数量 × 折算美金单价)
本期出库金额 = Σ(该月出库数量 × 对应入库记录的折算美金单价)
本期入库数量 = 该月入库总数
本期出库数量 = 该月出库总数
```

#### 滚存逻辑（逐月滚动）

**第1月（含之前所有数据）：**

```
上期金额 = 截至上年底累计入库金额 - 截至上年底累计出库金额
结余金额 = 上期金额 + 第1月入库金额 - 第1月出库金额
上期数量 = 截至上年底累计入库数量 - 截至上年底累计出库数量
结余数量 = 上期数量 + 第1月入库数量 - 第1月出库数量
```

**第2~12月（每个月的上期 = 上个月的结余）：**

```
上期金额 = 上月结余金额
结余金额 = 上期金额 + 本月入库金额 - 本月出库金额
上期数量 = 上月结余数量
结余数量 = 上期数量 + 本月入库数量 - 本月出库数量
```

### 2.4 返回字段

| 字段 | 说明 |
|------|------|
| `YearMonth` | 年月（yyyy-MM） |
| `PrvAmountTotal` | 上期金额（折算美金） |
| `CurrentStockInAmountTotal` | 本期入库金额（折算美金） |
| `CurrentStockOutAmountTotal` | 本期出库金额（折算美金） |
| `BalanceAmountTotal` | 结余金额（折算美金） |
| `PrvStockQty` | 上期数量 |
| `StockInQty` | 本期入库数量 |
| `StockOutQty` | 本期出库数量 |
| `BalanceStockQty` | 结余数量 |

### 2.5 计算流程

```
1. 根据年份确定时间范围（如 2026-01-01 ~ 2027-01-01）
2. 查询该年度所有出库记录（PackingItem），关联 StockInV2 获取 ConvertCost
3. 查询该年度所有入库记录（StockInV2, Type=Purchase）
4. 循环 1~12 月，逐月计算：
   a. 计算本月入库金额/数量
   b. 计算本月出库金额/数量
   c. 如果是1月，额外查询该年度之前的累计作为上期
   d. 如果是2~12月，上期直接取上月结余
   e. 计算结余
5. 返回12个月数据（不分页，固定12条）
```

## 三、库存明细滚存（StockItemAccumulatedList）

### 3.1 查询条件

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `Month` | string | 是 | 月份（yyyy-MM） |
| `QueryKeywords` | string | 否 | 模糊搜索物料型号 |
| `Pn` | string | 否 | 物料型号精确筛选 |
| `StockInCode` | string | 否 | 入库单号筛选 |
| `StockInTimeStart` | DateTime | 否 | 入库时间起 |
| `StockInTimeEnd` | DateTime | 否 | 入库时间止 |

### 3.2 数据范围

- 按所选月份查询 `StockInV2` 入库记录作为"本期"
- 查询该月之前的所有记录作为"上期"
- 每条入库记录独立计算

### 3.3 核心计算公式

对每条入库记录：

```
本期入库金额 = 入库记录.ConvertCost × 入库记录.Qty
本期出库金额 = 本期内该入库记录关联的出库数量 × ConvertCost

上期入库金额 = 该入库记录上期入库数量 × ConvertCost  （如果该记录在上月之前已存在）
上期出库金额 = 上期该入库记录关联的出库数量 × ConvertCost

上期金额 = 上期入库金额 - 上期出库金额
上期数量 = 上期入库数量 - 上期出库数量

结余金额 = 本期入库金额 + 上期入库金额 - 本期出库金额 - 上期出库金额
结余数量 = 上期数量 + 本期入库数量 - 本期出库数量
```

### 3.4 返回字段

| 字段 | 说明 |
|------|------|
| `BillCode` | 入库单号 |
| `PN` | 物料型号 |
| `StockInTime` | 入库时间 |
| `StockInQty` | 本期入库数量 |
| `StockOutQty` | 本期出库数量 |
| `PrvQty` | 上期结余数量 |
| `BalanceQty` | 结余数量（PrvQty + StockInQty - StockOutQty） |
| `PrvAmountTotal` | 上期金额 |
| `CurrentStockInAmountTotal` | 本期入库金额 |
| `CurrentStockOutAmountTotal` | 本期出库金额 |
| `BalanceAmountTotal` | 结余金额 |

## 四、客户滚存与供应商滚存

### 4.1 客户滚存

- **维度**：按客户（CustomerInfo.CustomerId）
- **数据来源**：`StockInV2`（入库）+ `PackingV2` + `PackingItem`（出库）
- **金额来源**：出库金额关联入库记录的 `ConvertCost`，入库金额使用 `ConvertCost × Qty`
- **查询条件**：必须选择年月（Month），支持关键词搜索客户名
- **维度过滤**：出库时 `PackingV2.CustomerId == StockInV2.CustomerId`

### 4.2 供应商滚存

- **维度**：按供应商（VendorInfo.VendorId）
- **数据来源**：`StockInV2`（入库）+ `PackingItem`（出库），通过 `VendorId` 关联
- **金额来源**：同客户滚存
- **查询条件**：必须选择年月（Month），支持关键词搜索供应商名
- **维度过滤**：出库时 `PackingItem.VendorId == StockInV2.VendorId`

## 五、涉及数据库表

| 表名 | 说明 | 关键字段 |
|------|------|----------|
| `StockInV2` | 入库记录 | Id, Qty, ConvertCost, CustomerId, VendorId, Type, CreateTime |
| `PackingV2` | 出库装箱主表 | Id, CustomerId, CreateTime |
| `PackingItem` | 出库装箱明细 | MainId, StockInId, Qty, VendorId, CreateTime |
| `CustomerInfo` | 客户信息 | CustomerId, Cname, Ename, OfficialName |
| `VendorInfo` | 供应商信息 | VendorId, Cname, Ename, OfficialName |

**注意**：所有滚存均只统计 `StockInV2.Type == Purchase`（采购入库）的数据。

## 八、业务要点总结

1. **纯查询功能**：所有滚存接口均为 GET 请求，只读不写，无新增/编辑/删除操作
2. **月滚存机制**：库存滚存按年展示12个月，每月结余自动滚入下月作为"上期"
3. **仅统计采购入库**：`Type == Purchase`，退货入库、报关入库等不纳入滚存
4. **折算美金计价**：金额统一使用 `ConvertCost`（折算美金单价）计算
5. **出库金额关联入库成本**：出库金额 = 出库数量 × 对应入库记录的 `ConvertCost`
6. **跨月累计**：库存滚存第1月会查询该年度之前的所有历史数据作为期初，保证滚存链条的连续性
