## 一、功能定位

库存滚存是财务模块中的**只读报表**功能，按月滚动统计采购入库与销售出库的数量与金额（USD），展示：

- **上期结余**：期初或上月结转
- **本期入库 / 本期出库**：当月发生额
- **期末结余**：上期 + 入库 − 出库

用于财务对**采购库存价值**的持续追踪，不参与过账、不写库。

### 1.1 本期范围（MVP）

| 功能 | 状态 | 说明 |
|------|------|------|
| 库存滚存（按年 12 月汇总） | ✅ 已实现 | 选年份，固定返回 12 行 |
| 库存明细滚存（按月分页） | ✅ 已实现 | 按 `stock_in_item` 展开，支持下钻 |
| 客户滚存 / 客户明细 | ⏳ 二期 | EBS 有，FrontCRM 未做 |
| 供应商滚存 / 供应商明细 | ⏳ 二期 | EBS 有，FrontCRM 未做 |
| Excel 导出 | ⏳ 二期 | MVP 不做 |

### 1.2 与 EBS 的差异摘要

| 维度 | EBS（原文档） | FrontCRM（本实现） |
|------|---------------|-------------------|
| 入库实体 | `StockInV2` 单行 | `stock_in` + `stock_in_item` + `stock_item` |
| 折算单价 | `ConvertCost` | `stock_item.PurchasePriceUsd` |
| 出库时间 | `PackingItem` / 装箱时间 | `stock_out.StockOutDate`（空则 `CreateTime`） |
| 出库数据源 | `PackingItem` | `stock_out` → `stock_out_item` → `stock_out_item_extend` |
| 出库关联入库 | `StockInId` | `stock_out_item_extend.StockInItemId` |
| API 前缀 | `BaseFinance/Accumulated/*` | `api/v1/finance/accumulated/*` |

## 二、已确认的设计口径

以下口径在需求讨论中已拍板，作为实现与测试的唯一依据。

### 2.1 时间与粒度

| # | 项 | 决定 |
|---|-----|------|
| 1 | 出库时间 | `stock_out.StockOutDate`；为空回退 `stock_out.CreateTime` |
| 2 | 入库时间 | `stock_in.StockInDate` |
| 3 | 统计粒度 | `stock_in_item`（入库明细行） |
| 4 | 月份边界 | 业务自然月，默认 `Asia/Shanghai`（可回退 `UTC+8` 固定偏移） |

### 2.2 数据过滤

| # | 项 | 决定 |
|---|-----|------|
| 5 | 入库类型 | 仅采购入库 `stock_in.StockInType = 10` |
| 6 | 排除类型 | 移库/报关/退货/报废入库均不统计 |
| 7 | 入库状态 | 仅已过账 `stock_in.Status = 2` |
| 8 | 出库状态 | `stock_out.Status IN (2, 4)`（已出库 / 已完成） |
| 9 | 出库类型 | 仅销售出库 `StockOutType IN (10, 1)`，排除移库虚拟出库 `3` |
| 10 | 软删除 | `is_deleted = true` 的记录排除 |

### 2.3 金额与数量

| # | 项 | 决定 |
|---|-----|------|
| 11 | 入库金额 | `stock_in_item.Quantity × stock_item.PurchasePriceUsd` |
| 12 | 出库数量 | 优先 `stock_out_item_extend.QtyStockOut`，否则 `ActualQty` / `Quantity` |
| 13 | 出库单价 | 优先 `stock_out_item_extend.PurchasePriceUsd`；为 0 时回查 `stock_item` |
| 14 | 出库金额 | 出库数量 × 出库单价（USD） |
| 15 | 金额展示 | 统一 USD，保留 2 位小数；数量为整数 |

### 2.4 权限、菜单与范围

| # | 项 | 决定 |
|---|-----|------|
| 16 | 数据范围 | 公司全量（不按部门/个人过滤） |
| 17 | 权限码 | `finance-accumulated.read`（API 兼容 `finance-receipt.read`） |
| 18 | 金额脱敏 | 与财务分析一致（`maskAmounts`） |
| 19 | 菜单位置 | 财务 → **库存报表** → 库存滚存（在「收款管理」之后） |
| 20 | 数据分析区「财务分析」 | 保持不动（`/reports/finance`） |

## 三、业务公式

### 3.1 库存滚存汇总（按年 12 行）

对每一年，循环 `month = 1..12`：

```
本期入库金额 = Σ(当月入库明细数量 × PurchasePriceUsd)
本期出库金额 = Σ(当月出库数量 × 出库 USD 单价)
本期入库数量 = 当月入库数量合计
本期出库数量 = 当月出库数量合计

若 month = 1：
  上期金额 = 当年 1 月 1 日（显示时区）之前累计入库金额 − 累计出库金额
  上期数量 = 同上（数量）
否则：
  上期金额 = 上月结余金额
  上期数量 = 上月结余数量

结余金额 = 上期金额 + 本期入库金额 − 本期出库金额
结余数量 = 上期数量 + 本期入库数量 − 本期出库数量
```

- 固定返回 **12 行**（不分页）
- 当年尚未到来的月份：指标为 **0**（仍占一行）

### 3.2 库存明细滚存（按月分页）

**数据范围：** 所选自然月内过账的采购入库明细（`stock_in_item`）。

对每条明细行：

```
本期入库数量 = stock_in_item.Quantity
本期入库金额 = 本期入库数量 × PurchasePriceUsd

本期出库数量 = 本月内、关联本 StockInItemId 的出库数量合计
本期出库金额 = Σ(本月出库数量 × 出库 USD 单价)

上期出库数量 = 本月之前、关联本 StockInItemId 的出库数量合计
上期出库金额 = Σ(上期出库数量 × 出库 USD 单价)

上期数量 = 0 − 上期出库数量        （本月新入库行，期初入库为 0）
上期金额 = 0 − 上期出库金额

结余数量 = 上期数量 + 本期入库数量 − 本期出库数量
结余金额 = 上期金额 + 本期入库金额 − 本期出库金额
```

**筛选参数：** `month`（必填）、`queryKeywords`、`pn`、`stockInCode`、`stockInTimeStart`、`stockInTimeEnd`、`page`、`pageSize`（默认 20，最大 100）。

## 四、系统架构

```
┌─────────────────────────────────────────────────────────────┐
│  CRM.Web                                                     │
│  FinanceStockAccumulatedList.vue      （年份 + 12 月表）      │
│  FinanceStockAccumulatedItemList.vue  （月份下钻 + 分页）     │
│  api/financeStockAccumulated.ts                              │
└──────────────────────────┬──────────────────────────────────┘
                           │ GET /api/v1/finance/accumulated/*
┌──────────────────────────▼──────────────────────────────────┐
│  CRM.API                                                     │
│  FinanceStockAccumulatedController                           │
│    · 权限 / 财务数据范围 / 金额脱敏                           │
└──────────────────────────┬──────────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────────┐
│  CRM.Infrastructure                                          │
│  FinanceStockAccumulatedQuery                                  │
│    · EF 加载入库/出库流水 → 内存按自然月聚合                    │
└──────────────────────────┬──────────────────────────────────┘
                           │
┌──────────────────────────▼──────────────────────────────────┐
│  PostgreSQL                                                  │
│  stock_in / stock_in_item / stock_item                       │
│  stock_out / stock_out_item / stock_out_item_extend          │
└─────────────────────────────────────────────────────────────┘

辅助：CRM.Core/Utilities/FinanceAccumulatedMonthBoundary.cs
      （自然月 UTC 边界，含 12 月跨年处理）
```

### 4.1 计算策略说明

- **汇总接口**：一次性加载全部符合条件的入库/出库流水，在内存中按 `FinanceAccumulatedMonthBoundary` 切月聚合，再滚动计算 12 个月。数据量为财务汇总级别，MVP 可接受。
- **明细接口**：先按月份与筛选条件对 `stock_in_item` 分页，再按页内 `StockInItemId` 批量加载关联出库流水计算行指标。

## 五、API 设计

**Controller：** `FinanceStockAccumulatedController`  
**路由前缀：** `api/v1/finance/accumulated`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/search-options` | 年份下拉（来自已过账采购入库的 `StockInDate.Year`） |
| GET | `/stock?year=2026` | 库存滚存汇总（12 行） |
| GET | `/stock-items?month=2026-01&...` | 库存明细滚存（分页） |

**鉴权：**

- `[RequireAnyPermission("finance-accumulated.read", "finance-receipt.read")]`
- `FinanceDataScope = 4` 时拒绝访问（与财务菜单一致）

**响应：**

- 统一 `ApiResponse<T>` 信封，JSON camelCase
- 汇总/明细均带 `maskAmounts`；脱敏时金额字段为 `null`
